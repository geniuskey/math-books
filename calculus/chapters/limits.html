Chapter 01

극한

미적분의 두 기둥인 미분과 적분은 둘 다 같은 질문에서 출발합니다. "그 값에 도달하지 않고 점점 다가가기만 하면 무엇이 보이는가?" 순간 속도는 시간 간격을 0으로 줄일 수 없어서, 곡선 아래 넓이는 직사각형을 무한히 잘게 쪼갤 수 없어서 생기는 질문입니다. 이 장은 그 질문에 답하는 도구인 극한(limit)을 다룹니다. 그래프를 확대하고, 표를 만들고, 한쪽에서만 다가가 보고, 끝내는 "충분히 가깝다"를 숫자 \(\varepsilon\)과 \(\delta\)로 못 박습니다. 이 장의 정의 하나가 책의 나머지 열다섯 장을 떠받칩니다.

  • \(\lim_{x\to a} f(x) = L\)을 "x가 a에 다가가면 f(x)가 L에 다가간다"로 읽고, 그래프 확대와 수치표로 극한을 추측한다. 그리고 표가 속이는 두 경우(표본 선택, 반올림 오차)를 안다.
  • 좌극한과 우극한을 구하고, 점프·진동·발산 때문에 극한이 존재하지 않는 경우를 구별한다.
  • 극한 법칙과 직접 대입을 쓰고, 0/0 꼴을 인수분해·유리화·통분으로 풀어낸다.
  • 조임 정리로 \(x^2\sin(1/x)\)처럼 법칙이 듣지 않는 극한을 구한다.
  • 무한대에서의 극한과 무한 극한을 계산하고, 수평·수직·비스듬한 점근선을 찾는다.
  • ε–δ 정의로 간단한 극한을 증명하고, 극한이 없음을 보이며, 합의 법칙을 증명한다.
이 수식이 없었다면"사라진 양의 유령"을 쫓아낸 정의

17세기 후반 뉴턴과 라이프니츠는 미적분을 거의 완성했지만, 그 바탕에는 "0은 아니지만 한없이 작은 양"이라는 애매한 개념이 깔려 있었습니다. 순간 속도를 구할 때 아주 작은 시간 \(h\)로 나눴다가(그러려면 \(h \ne 0\)), 계산 끝에서는 \(h\)를 0으로 버렸습니다(그러려면 \(h = 0\)). 1734년 아일랜드의 철학자 조지 버클리는 『분석가(The Analyst)』에서 이 모순을 꼬집으며 그 작은 양을 "사라진 양의 유령"이라고 불렀습니다. 계산은 맞는데 왜 맞는지 아무도 설명하지 못했던 것입니다.

답은 백 년 가까이 지나서 나왔습니다. 1821년 코시가 『해석학 강의(Cours d'analyse)』에서 극한과 연속을 "한없이 다가간다"는 말로 정리했고, 19세기 후반 바이어슈트라스와 그 학파가 이를 오늘날의 ε–δ 부등식으로 다듬었습니다. 이제 \(h\)는 0이 되지 않습니다. "\(h\)를 충분히 작게 하면 결과를 원하는 만큼 정확하게 할 수 있다"는 약속만 남습니다. 공학자가 날마다 쓰는 허용 오차의 언어와 똑같습니다.

순간 속도, 곡선 아래 넓이→0으로 나누기의 모순→극한: ε 안에 들게 하는 δ가 있다→미분·적분·급수의 단단한 토대

함수가 한 점에 다가갈 때

떨어지는 공의 순간 속도

공을 떨어뜨리면 \(t\)초 동안 떨어진 거리는 공기 저항을 무시할 때 \(s(t) = 4.9t^2\) m입니다. 2초 시점의 속도계 눈금은 얼마일까요? 속도는 "거리 ÷ 시간"인데, 한 순간에는 시간 간격이 0이라 나눌 수가 없습니다.

할 수 있는 일은 간격 \(h\)를 0이 아닌 작은 수로 두고 평균 속도를 구하는 것입니다. 2초에서 \(2+h\)초까지의 평균 속도는

$$v_{\text{avg}}(h) = \frac{s(2+h) - s(2)}{h} = \frac{4.9(4 + 4h + h^2) - 19.6}{h} = \frac{19.6h + 4.9h^2}{h} = 19.6 + 4.9h \qquad (h \ne 0).$$
간격 h (s)10.10.010.001→ 0
평균 속도 (m/s)24.520.0919.64919.6049→ 19.6

\(h = 0\)을 넣으면 \(0/0\)이라 아무 뜻이 없지만, \(h\)가 0에 다가갈 때 평균 속도는 19.6 m/s에 한없이 가까워집니다. 이 다가가는 값이 순간 속도이고, 이렇게 "도착하지 않고 다가가기만 할 때의 목적지"가 극한입니다.

정의 1.1 (극한, 직관적 정의) \(a\)를 포함하는 열린 구간에서(\(a\) 자체는 빼도 된다) 정의된 함수 \(f\)에 대해, \(x\)를 \(a\)에 충분히 가깝게(그러나 \(x \ne a\)) 하면 \(f(x)\)를 \(L\)에 원하는 만큼 가깝게 만들 수 있을 때
$$\lim_{x\to a} f(x) = L \qquad\text{또는}\qquad f(x) \to L \ (x \to a)$$
로 쓰고 "\(x\)가 \(a\)로 갈 때 \(f(x)\)의 극한은 \(L\)이다"라고 읽는다. "충분히"와 "원하는 만큼"을 숫자로 바꾼 엄밀한 정의는 7절의 정의 1.12다.

이 정의에서 가장 중요한 단어는 \(x \ne a\)입니다. 극한은 \(a\) 근처의 값만 보고, \(a\)에서의 값 \(f(a)\)는 보지 않습니다. \(f(a)\)가 정의되지 않아도, 엉뚱한 값이어도 극한은 똑같습니다. 순간 속도에서 \(h = 0\)일 때의 값은 애초에 없었습니다.

그래프로 극한을 보는 가장 직접적인 방법은 확대입니다. \(x = a\)를 가운데 둔 창을 점점 좁히면서, 창 안에서 \(f\)의 값이 얼마나 퍼져 있는지 봅니다. 극한이 있으면 창을 좁힐수록 값의 폭도 0으로 줄어들고, 그래프는 한 점(구멍이든 아니든)으로 모입니다. 극한이 없으면 아무리 확대해도 폭이 줄지 않습니다.

수치표로 극한 추측하기

그래프를 그리기 어려우면 표를 만듭니다. \(x = a + h\)에서 \(h\)를 0.1, 0.01, 0.001, …로 줄이고 양쪽(\(h > 0\)과 \(h \lt 0\))을 다 봅니다.

표는 빠르고 쓸모 있지만 증명이 아닙니다. 표가 틀린 답을 주는 전형적인 경우가 둘 있습니다.

표의 두 함정
  • 표본을 잘못 고르면. \(f(x) = \sin(\pi/x)\)에 \(x = 0.1, 0.01, 0.001, \dots\)를 넣으면 \(\sin(10\pi) = \sin(100\pi) = \cdots = 0\)이라 표에는 0만 나옵니다. 하지만 \(x = 2/5, 2/9, 2/13, \dots\), 즉 \(x = 2/(4n+1)\)에서는 \(\sin\bigl((4n + 1)\pi/2\bigr) = 1\)입니다. 0에 아무리 가까워도 값이 0과 1(과 −1) 사이를 오가므로 극한은 존재하지 않습니다.
  • \(h\)를 너무 작게 하면. 컴퓨터는 수를 약 16자리로만 기억합니다. \(\frac{1-\cos h}{h^2}\)의 극한은 \(\tfrac12\)인데, \(h = 10^{-8}\)이면 \(\cos h\)가 부동소수점으로 정확히 1이 되어 분자가 0, 표에는 0이 찍힙니다. 비슷한 두 수의 뺄셈에서 유효 숫자가 사라지는 상쇄 오차입니다(MathBook "수치 계산" 상쇄 오차 절).

한쪽 극한과 극한이 없는 경우

스위치를 켜는 순간의 전압

\(t = 0\)에 스위치를 켜서 회로에 5 V가 걸린다고 합시다. 전압은 \(t \lt 0\)에서 0, \(t \ge 0\)에서 5입니다. "\(t\)가 0으로 갈 때 전압의 극한"은 얼마일까요? 켜기 직전에서 보면 0, 켠 직후에서 보면 5입니다. 한 숫자로 답할 수 없지만, 어느 쪽에서 다가가는지 정하면 답이 생깁니다.

정의 1.2 (한쪽 극한) \(x\)를 \(a\)보다 작은 쪽에서 \(a\)에 충분히 가깝게 하면 \(f(x)\)를 \(L\)에 원하는 만큼 가깝게 할 수 있을 때 \(L\)을 좌극한(left-hand limit)이라 하고 \(\lim_{x\to a^-} f(x) = L\)로 쓴다. \(a\)보다 큰 쪽에서 다가가는 우극한(right-hand limit) \(\lim_{x\to a^+} f(x)\)도 같은 방식으로 정의한다. 둘을 묶어 한쪽 극한(one-sided limit)이라 한다.
정리 1.3 (양쪽 극한과 한쪽 극한)
$$\lim_{x\to a} f(x) = L \quad\Longleftrightarrow\quad \lim_{x\to a^-} f(x) = L \ \text{ 그리고 } \ \lim_{x\to a^+} f(x) = L.$$

증명 아이디어. (⇒) \(a\)의 양쪽 근처에서 \(f(x)\)가 \(L\)에 가까우면 한쪽 근처에서도 당연히 가깝다. (⇐) 왼쪽에서 \(a\)에 \(\delta_1\)만큼 가까우면 충분하고 오른쪽에서 \(\delta_2\)만큼 가까우면 충분하다면, 둘 중 작은 \(\min(\delta_1, \delta_2)\)만큼 가까우면 양쪽 어디서든 충분하다(7절의 정의로 쓰면 이 문장이 그대로 증명이다). ∎

스위치 전압은 좌극한 0, 우극한 5로 서로 다르므로 \(t \to 0\)의 극한이 없습니다. 극한이 존재하지 않는 경우는 크게 세 모양입니다.

정의 1.4 (무한 극한) \(x\)를 \(a\)에 충분히 가깝게(\(x \ne a\)) 하면 \(f(x)\)를 원하는 어떤 수보다도 크게 만들 수 있을 때 \(\lim_{x\to a} f(x) = \infty\)로 쓴다. \(-\infty\)와 한쪽 극한 \(\lim_{x\to a^\pm} f(x) = \pm\infty\)도 같은 방식이다. 이런 극한을 무한 극한(infinite limit)이라 한다. \(\infty\)는 수가 아니므로 무한 극한은 극한이 존재하지 않는 특별한 방식이다.
예제 1.2 (한쪽 극한 계산) \(g(x) = \dfrac{x^2 - x}{|x - 1|}\)의 \(x = 1\)에서의 좌극한, 우극한, 극한을 구하라.
  1. 분자를 묶으면 \(x^2 - x = x(x - 1)\).
  2. \(x > 1\)이면 \(|x - 1| = x - 1\)이므로 \(g(x) = x\). 따라서 \(\lim_{x\to 1^+} g(x) = 1\).
  3. \(x \lt 1\)이면 \(|x - 1| = -(x - 1)\)이므로 \(g(x) = -x\). 따라서 \(\lim_{x\to 1^-} g(x) = -1\).
  4. 좌극한 \(-1 \ne\) 우극한 \(1\)이므로 정리 1.3에 의해 \(\lim_{x\to 1} g(x)\)는 존재하지 않는다(점프).

극한 법칙과 대수적 계산

매번 표를 만들 수는 없다

공학 계산에 나오는 극한마다 그래프를 확대하고 표를 만들 수는 없습니다. 게다가 표는 추측일 뿐입니다. 이미 아는 극한 몇 개로부터 복잡한 식의 극한을 정확히 조립하는 규칙이 필요합니다.

정리 1.5 (극한 법칙(limit laws)) \(\lim_{x\to a} f(x) = L\), \(\lim_{x\to a} g(x) = M\)이 둘 다 존재하고 \(c\)가 상수이면
$$\begin{aligned} &\lim_{x\to a}\,[f(x) \pm g(x)] = L \pm M, &&\lim_{x\to a}\,c f(x) = cL, &&\lim_{x\to a}\,f(x)g(x) = LM,\\ &\lim_{x\to a}\frac{f(x)}{g(x)} = \frac{L}{M}\ (M \ne 0), &&\lim_{x\to a}\,[f(x)]^n = L^n, &&\lim_{x\to a}\sqrt[n]{f(x)} = \sqrt[n]{L}. \end{aligned}$$
\(n\)은 양의 정수. 마지막 식은 \(n\)이 짝수이면 \(L > 0\)일 때. 또 기본 극한 \(\lim_{x\to a} c = c\), \(\lim_{x\to a} x = a\).

합의 법칙은 7절에서 ε–δ로 증명한다. 곱과 몫도 같은 방식으로 증명되며, 거듭제곱은 곱의 법칙을 \(n\)번 쓴 것이다.

이 법칙과 두 기본 극한만으로 다항식과 유리식의 극한이 모두 나옵니다. 예를 들어 \(\lim_{x\to 2}(3x^2 - 5) = 3\cdot(\lim x)^2 - 5 = 3\cdot 4 - 5 = 7\)입니다. 결과는 그냥 대입한 값과 같습니다.

정리 1.6 (직접 대입(direct substitution)) \(p\)가 다항식이면 \(\lim_{x\to a}p(x) = p(a)\). \(r = p/q\)가 유리식이고 \(q(a) \ne 0\)이면 \(\lim_{x\to a}r(x) = r(a)\).

대입했더니 \(0/0\)이 나오면 그때부터가 진짜 문제입니다. 분자도 0, 분모도 0으로 가는 경쟁의 결과는 0일 수도, 7일 수도, ∞일 수도, 존재하지 않을 수도 있어서 \(0/0\)만 보고는 답을 알 수 없습니다. 이런 꼴을 부정형(indeterminate form)이라 부릅니다. 해결의 열쇠는 극한이 \(x \ne a\)인 점만 본다는 사실입니다.

정리 1.7 (근처에서 같은 함수는 극한이 같다) \(a\)를 포함하는 열린 구간의 \(x \ne a\)인 모든 점에서 \(f(x) = g(x)\)이고 \(\lim_{x\to a}g(x)\)가 존재하면, \(\lim_{x\to a}f(x) = \lim_{x\to a}g(x)\).

증명. 극한의 정의는 \(x \ne a\)인 점의 값만 쓰는데 그 값들이 똑같으므로 정의를 만족하는 \(L\)도 같다. ∎

그래서 0/0이 나오면 식을 변형해 분모를 0으로 만드는 인수를 소거합니다. 소거는 \(x \ne a\)일 때만 허용되지만, 정리 1.7 덕분에 극한에는 그것으로 충분합니다. 대표적인 기술 세 가지를 예제로 봅시다.

예제 1.3 (인수분해) \(\displaystyle \lim_{x\to 2}\frac{x^3 - 8}{x - 2}\)
  1. 대입하면 \(0/0\). 분자가 \(x = 2\)에서 0이므로 \((x - 2)\)를 인수로 갖는다.
  2. 세제곱의 차 공식: \(x^3 - 8 = (x - 2)(x^2 + 2x + 4)\).
  3. \(x \ne 2\)에서 \(\dfrac{x^3 - 8}{x - 2} = x^2 + 2x + 4\). 이 다항식에 대입하면 극한은 \(4 + 4 + 4 = 12\).
예제 1.4 (유리화(rationalization)) \(\displaystyle \lim_{x\to 0}\frac{\sqrt{x+9}-3}{x}\) (예제 1.1의 추측 확인)
  1. 근호가 있는 차 \(\sqrt{x+9} - 3\)에 켤레 \(\sqrt{x+9} + 3\)을 분자·분모에 곱한다.
  2. \(\dfrac{(\sqrt{x+9}-3)(\sqrt{x+9}+3)}{x(\sqrt{x+9}+3)} = \dfrac{(x + 9) - 9}{x(\sqrt{x+9}+3)} = \dfrac{x}{x(\sqrt{x+9}+3)} = \dfrac{1}{\sqrt{x+9}+3}\) (\(x \ne 0\)).
  3. 이제 대입할 수 있다: \(\dfrac{1}{\sqrt 9 + 3} = \dfrac16\). 표의 추측 0.16666…이 맞았다.

덤으로, 유리화한 식 \(1/(\sqrt{x+9}+3)\)에는 뺄셈이 없어서 \(x = 10^{-12}\)에서도 상쇄 오차 없이 정확하게 계산됩니다. 수치 계산에서 식을 변형하는 이유이기도 합니다.

예제 1.5 (통분) \(\displaystyle \lim_{x\to 3}\frac{\frac1x - \frac13}{x - 3}\)
  1. 분자를 통분하면 \(\dfrac1x - \dfrac13 = \dfrac{3 - x}{3x} = -\dfrac{x - 3}{3x}\).
  2. \(x \ne 3\)에서 전체 식은 \(-\dfrac{x-3}{3x}\cdot\dfrac{1}{x-3} = -\dfrac{1}{3x}\).
  3. 대입: \(-\dfrac{1}{9}\). (이 극한은 \(y = 1/x\)의 \(x = 3\)에서의 접선 기울기다. 3장에서 다시 만난다.)
법칙은 극한이 '존재할 때만' 쓴다 \(\lim_{x\to 0}\bigl[\sin(1/x) - \sin(1/x)\bigr] = 0\)이지만, 이것을 \(\lim\sin(1/x) - \lim\sin(1/x)\)로 쪼갤 수는 없습니다. 각각이 존재하지 않기 때문입니다. 마찬가지로 \(\infty - \infty\), \(0\cdot\infty\), \(\infty/\infty\)도 부정형입니다. "∞ − ∞ = 0"은 틀린 계산입니다(6절 예제 1.8에서 \(\sqrt{x^2+x} - x \to \tfrac12\)).

분모가 0으로 가는데 분자는 0이 아닌 수로 가면 사정이 전혀 다릅니다. 그때는 몫이 한없이 커지므로 극한은 \(\pm\infty\)(또는 좌우에서 부호가 달라 존재하지 않음)이고, 그래프에는 수직 점근선이 생깁니다. 아래 시뮬레이터에서 분자의 \(x = 1\)에서의 값을 0으로 맞추는 순간 점근선이 구멍으로 바뀝니다.

조임 정리

법칙이 듣지 않는 극한

\(\lim_{x\to 0}x^2\sin(1/x)\)를 곱의 법칙으로 \(\lim x^2\cdot\lim\sin(1/x)\)라 쓰려 해도 \(\lim\sin(1/x)\)가 존재하지 않아 막힙니다. 하지만 \(\sin\)은 무엇을 넣든 −1과 1 사이에 있습니다. 출렁이는 정도가 \(x^2\)에 갇혀 있다면 그 출렁임도 결국 0으로 눌리지 않을까요?

정리 1.8 (조임 정리(squeeze theorem)) \(a\)를 포함하는 열린 구간의 \(x \ne a\)인 점에서 \(g(x) \le f(x) \le h(x)\)이고
$$\lim_{x\to a} g(x) = \lim_{x\to a} h(x) = L \quad\text{이면}\quad \lim_{x\to a} f(x) = L.$$

증명. \(\varepsilon > 0\)을 주자. \(x\)가 \(a\)에 충분히 가까우면 \(g(x)\)와 \(h(x)\)가 둘 다 구간 \((L - \varepsilon, L + \varepsilon)\) 안에 있다(두 조건에서 나온 \(\delta\) 중 작은 것을 쓴다). 그러면 \(L - \varepsilon \lt g(x) \le f(x) \le h(x) \lt L + \varepsilon\)이므로 \(f(x)\)도 그 구간 안에 있다. ∎

예제 1.6 (조임 정리 쓰기) \(\displaystyle \lim_{x\to 0}x^2\sin\frac1x = 0\)을 보여라.
  1. 모든 \(x \ne 0\)에서 \(-1 \le \sin(1/x) \le 1\).
  2. 양변에 \(x^2 \ge 0\)을 곱하면(부등호 방향 그대로) \(-x^2 \le x^2\sin(1/x) \le x^2\).
  3. \(\lim_{x\to 0}(-x^2) = \lim_{x\to 0}x^2 = 0\)이므로 조임 정리에 의해 극한은 0이다.

같은 논리로 \(|f(x)| \le h(x)\)이고 \(h(x) \to 0\)이면 \(f(x) \to 0\)입니다(\(g = -h\)로 둔 조임 정리). 이 형태가 실전에서 가장 자주 쓰입니다.

조임 정리가 미적분에서 가장 빛나는 곳은 \(\lim_{x\to 0}\frac{\sin x}{x} = 1\)의 증명입니다. 부채꼴 넓이를 두 삼각형 넓이 사이에 끼워 넣는 이 증명은 2장 7절에서 시뮬레이터와 함께 합니다. 삼각 함수의 도함수가 모두 이 극한 하나에서 나옵니다.

무한대에서의 극한과 점근선

콘덴서는 결국 몇 볼트까지 차는가

저항 \(R\)을 거쳐 전압 \(V_0\)으로 콘덴서 \(C\)를 충전하면 전압은 \(V(t) = V_0(1 - e^{-t/RC})\)입니다. 이론상 이 전압은 \(V_0\)에 영원히 닿지 않습니다. 그런데 회로 설계자는 "충분히 오래 기다리면 \(V_0\)"이라고 말합니다. 이 말은 \(t \to \infty\)일 때의 극한입니다.

지금까지는 \(x\)가 유한한 수 \(a\)에 다가갔습니다. 이번에는 \(x\)가 한없이 커질 때 \(f(x)\)가 어떤 값에 자리를 잡는지 묻습니다.

정의 1.9 (무한대에서의 극한(limit at infinity)) \(x\)를 충분히 크게 하면 \(f(x)\)를 \(L\)에 원하는 만큼 가깝게 할 수 있을 때 \(\lim_{x\to\infty}f(x) = L\)로 쓴다. \(x \to -\infty\)도 같다. 이때 직선 \(y = L\)을 \(f\)의 그래프의 수평 점근선(horizontal asymptote)이라 한다.
정의 1.10 (수직 점근선(vertical asymptote)) 네 한쪽 극한 \(\lim_{x\to a^-}f(x)\), \(\lim_{x\to a^+}f(x)\) 중 적어도 하나가 \(\infty\) 또는 \(-\infty\)이면 직선 \(x = a\)를 수직 점근선이라 한다.

콘덴서의 경우 \(t \to \infty\)이면 \(e^{-t/RC} \to 0\)이므로 \(V(t) \to V_0\)이고, \(V = V_0\)이 수평 점근선입니다. 시정수 \(\tau = RC\)의 5배가 지나면 \(e^{-5} \approx 0.0067\)이라 99.3%까지 찹니다. "충분히 오래"를 숫자로 바꾼 셈입니다.

무한대에서의 극한에도 극한 법칙(정리 1.5)이 그대로 성립합니다. 여기에 기본 극한 하나를 더하면 유리식의 극한이 전부 풀립니다.

정리 1.11 (유리식의 무한대 극한) \(r > 0\)이면 \(\lim_{x\to\infty}\dfrac{1}{x^r} = 0\). 따라서 \(p(x) = a_m x^m + \cdots\), \(q(x) = b_n x^n + \cdots\) (\(a_m, b_n \ne 0\))에 대해
$$\lim_{x\to\pm\infty}\frac{p(x)}{q(x)} = \begin{cases} 0 & (m \lt n)\\[2pt] \dfrac{a_m}{b_n} & (m = n)\\[4pt] \pm\infty & (m > n,\ \text{부호는 } a_m/b_n \text{과 } x^{m-n}\text{의 부호로 정함})\end{cases}$$

증명 아이디어. 분자·분모를 분모의 최고차 \(x^n\)으로 나누면 \(1/x^r\) 꼴의 항은 모두 0으로 가고 최고차 계수만 남는다. ∎

예제 1.7 (최고차항으로 나누기) \(\displaystyle \lim_{x\to\infty} \frac{3x^2 - x}{2x^2 + 5}\)
  1. 분자·분모를 \(x^2\)으로 나눈다: \(\dfrac{3 - 1/x}{2 + 5/x^2}\).
  2. \(1/x \to 0\), \(5/x^2 \to 0\)이므로 극한은 \(\dfrac{3 - 0}{2 + 0} = \dfrac32\). 수평 점근선 \(y = 1.5\).
  3. 감각 확인: \(x = 100\)이면 \(\dfrac{29900}{20005} \approx 1.4946\). 아직 1.5보다 작다.
예제 1.8 (∞ − ∞ 꼴, 유리화) \(\displaystyle \lim_{x\to\infty}\bigl(\sqrt{x^2 + x} - x\bigr)\)
  1. 두 항이 모두 ∞로 가니 \(\infty - \infty\), 부정형이다.
  2. 켤레를 곱한다: \(\dfrac{(x^2 + x) - x^2}{\sqrt{x^2+x} + x} = \dfrac{x}{\sqrt{x^2+x} + x}\).
  3. 분자·분모를 \(x\)로 나눈다(\(x > 0\)이라 \(\sqrt{x^2+x}/x = \sqrt{1 + 1/x}\)): \(\dfrac{1}{\sqrt{1 + 1/x} + 1} \to \dfrac{1}{1 + 1} = \dfrac12\).
  4. 확인: \(x = 100\)이면 \(\sqrt{10100} - 100 \approx 0.49876\).
예제 1.9 (수직 점근선과 부호) \(f(x) = \dfrac{x + 1}{x^2 - 4}\)의 점근선을 모두 구하라.
  1. 분모 \(x^2 - 4 = (x-2)(x+2)\)가 0인 곳은 \(x = \pm 2\)이고, 거기서 분자는 3과 −1로 0이 아니다. 따라서 둘 다 수직 점근선이다.
  2. 부호: \(x \to 2^+\)이면 분자 → 3, 분모 → 0⁺이므로 \(+\infty\). \(x \to 2^-\)이면 분모 → 0⁻이므로 \(-\infty\).
  3. \(x \to -2^-\)(예: \(x = -2.1\), 분모 \(= 0.41 > 0\))이면 분자 → −1이므로 \(-\infty\). \(x \to -2^+\)이면 분모 \(\lt 0\)이므로 \(+\infty\).
  4. 분자 1차, 분모 2차이므로 \(x \to \pm\infty\)에서 0. 수평 점근선 \(y = 0\).

분자의 차수가 분모보다 정확히 1 크면 그래프는 기울어진 직선을 따라갑니다. 예를 들어 \(\frac{x^2+1}{x-1} = x + 1 + \frac{2}{x-1}\)이고 나머지 \(\frac{2}{x-1}\)이 0으로 가므로, 그래프는 \(x \to \pm\infty\)에서 직선 \(y = x + 1\)에 다가갑니다. 이 직선을 비스듬한 점근선(slant asymptote)이라 합니다. 또 하나 흔한 오해: 그래프는 수평 점근선을 가로질러도 됩니다. \(\frac{\sin x}{x}\)는 \(y = 0\)을 무한히 많이 지나면서 0으로 갑니다(\(|\sin x / x| \le 1/x\)와 조임 정리).

ε–δ 정의: "충분히 가깝다"를 숫자로

허용 오차를 지키려면 입력을 얼마나 정확히?

지름 \(d\)인 원판을 깎아 넓이 \(A = \pi d^2/4\)를 \(100\pi\) mm²(지름 20 mm)에 맞추려 합니다. 넓이 오차를 \(\pm 1\) mm² 안에 두려면 지름을 얼마나 정확하게 깎아야 할까요? 설계자는 출력의 허용 오차 \(\varepsilon\)을 먼저 정하고, 그것을 지키는 입력의 허용 오차 \(\delta\)를 찾습니다. 극한의 엄밀한 정의는 바로 이 대화입니다.

정의 1.1의 "충분히 가깝게"와 "원하는 만큼 가깝게"를 게임으로 바꿔 봅시다. 상대가 출력의 허용 오차 \(\varepsilon > 0\)을 아무리 작게 불러도, 나는 입력의 허용 오차 \(\delta > 0\)을 찾아 "\(x\)가 \(a\)에서 \(\delta\) 안에 있으면(\(x \ne a\)) \(f(x)\)는 \(L\)에서 \(\varepsilon\) 안에 있다"를 보장할 수 있어야 합니다. 모든 \(\varepsilon\)에 대해 이길 수 있으면 극한은 \(L\)입니다.

정의 1.12 (극한의 ε–δ 정의(epsilon-delta definition)) \(f\)가 \(a\)를 포함하는 열린 구간에서(\(a\)는 빼도 된다) 정의되어 있다고 하자. 모든 \(\varepsilon > 0\)에 대해 어떤 \(\delta > 0\)이 있어서
$$0 \lt |x - a| \lt \delta \quad\Longrightarrow\quad |f(x) - L| \lt \varepsilon$$
가 성립하면 \(\lim_{x\to a}f(x) = L\)이라 한다. 좌극한은 조건을 \(a - \delta \lt x \lt a\)로, 우극한은 \(a \lt x \lt a + \delta\)로 바꾼 것이다.
\(0 \lt |x - a|\)가 "\(x \ne a\)"를 적은 것이다. \(\delta\)는 \(\varepsilon\)에 따라 달라져도 된다(보통 \(\varepsilon\)이 작을수록 \(\delta\)도 작다).

증명은 보통 두 단계입니다. 먼저 초안에서 \(|f(x) - L|\)을 \(|x - a|\)로 표현해 \(\delta\)를 추측하고, 그다음 정리된 증명에서 그 \(\delta\)가 실제로 통함을 보입니다.

예제 1.10 (일차 함수) \(\lim_{x\to 2}(3x - 1) = 5\)를 ε–δ로 증명하라.
  1. 초안: \(|f(x) - L| = |3x - 1 - 5| = |3x - 6| = 3|x - 2|\). 이것이 \(\varepsilon\)보다 작으려면 \(|x - 2| \lt \varepsilon/3\)이면 된다.
  2. 증명: \(\varepsilon > 0\)이 주어지면 \(\delta = \varepsilon/3\)으로 둔다. \(0 \lt |x - 2| \lt \delta\)이면 \(|(3x - 1) - 5| = 3|x - 2| \lt 3\delta = \varepsilon\). ∎
  3. 해석: 기울기가 3이라 입력 오차가 3배로 불어난다. 그래서 입력은 출력 허용 오차의 1/3로 맞춰야 한다. 예를 들어 \(\varepsilon = 0.03\)이면 \(\delta = 0.01\).
예제 1.11 (이차 함수: δ를 미리 묶어 두기) \(\lim_{x\to 3}x^2 = 9\)를 증명하라.
  1. 초안: \(|x^2 - 9| = |x - 3|\,|x + 3|\). 문제는 \(|x + 3|\)이 \(x\)에 따라 변한다는 것이다.
  2. \(\delta \le 1\)로 미리 제한하면 \(|x - 3| \lt 1\)에서 \(2 \lt x \lt 4\), 따라서 \(|x + 3| \lt 7\).
  3. 그러면 \(|x^2 - 9| \lt 7|x - 3|\). 이것이 \(\varepsilon\)보다 작으려면 \(|x - 3| \lt \varepsilon/7\)이면 된다.
  4. 증명: \(\delta = \min(1, \varepsilon/7)\)로 둔다. \(0 \lt |x - 3| \lt \delta\)이면 \(|x + 3| \lt 7\)이고 \(|x^2 - 9| \lt 7\delta \le \varepsilon\). ∎

절 처음의 원판 문제도 같은 구조입니다. \(|A - 100\pi| = \tfrac{\pi}{4}|d - 20|\,|d + 20|\)이고, \(|d - 20| \lt 1\)이면 \(|d + 20| \lt 41\)이므로 \(|A - 100\pi| \lt \tfrac{41\pi}{4}|d - 20|\). \(\varepsilon = 1\) mm²이면 \(\delta = 4/(41\pi) \approx 0.031\) mm면 충분합니다.

ε–δ 정의는 극한이 없음을 보일 때도 씁니다. 정의를 부정하면 "어떤 \(\varepsilon > 0\)이 있어서, 어떤 \(\delta > 0\)을 골라도 \(0 \lt |x - a| \lt \delta\)인데 \(|f(x) - L| \ge \varepsilon\)인 \(x\)가 있다"입니다.

예제 1.12 (점프에는 어떤 L도 통하지 않는다) 스위치 함수 \(H(t) = 0\) (\(t \lt 0\)), \(H(t) = 1\) (\(t \ge 0\))에 대해 \(\lim_{t\to 0}H(t)\)가 존재하지 않음을 보여라.

\(\varepsilon = \tfrac12\)로 두자. 어떤 \(L\)과 \(\delta\)를 골라도 구간 \((-\delta, \delta)\)에는 \(H = 0\)인 점과 \(H = 1\)인 점이 다 있다. 두 값이 모두 \(L\)에서 \(\tfrac12\) 미만으로 떨어져 있다면 삼각 부등식으로 \(1 = |1 - 0| \le |1 - L| + |L - 0| \lt \tfrac12 + \tfrac12 = 1\)이 되어 모순이다. 따라서 어떤 \(L\)도 극한이 될 수 없다. ∎

정리 1.5의 증명 (합의 법칙) \(f(x) \to L\), \(g(x) \to M\)이라 하자. \(\varepsilon > 0\)이 주어지면 \(\varepsilon/2\)에 대해 \(0 \lt |x - a| \lt \delta_1 \Rightarrow |f(x) - L| \lt \varepsilon/2\), \(0 \lt |x - a| \lt \delta_2 \Rightarrow |g(x) - M| \lt \varepsilon/2\)인 \(\delta_1, \delta_2\)가 있다. \(\delta = \min(\delta_1, \delta_2)\)로 두면 \(0 \lt |x - a| \lt \delta\)일 때 삼각 부등식으로
$$|(f(x) + g(x)) - (L + M)| \le |f(x) - L| + |g(x) - M| \lt \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon. \ ∎$$

무한이 들어간 극한도 같은 틀로 적습니다. \(\lim_{x\to\infty}f(x) = L\)은 "모든 \(\varepsilon > 0\)에 대해 어떤 \(N\)이 있어 \(x > N \Rightarrow |f(x) - L| \lt \varepsilon\)", \(\lim_{x\to a}f(x) = \infty\)는 "모든 \(M\)에 대해 어떤 \(\delta > 0\)이 있어 \(0 \lt |x - a| \lt \delta \Rightarrow f(x) > M\)"입니다. 입력 쪽의 '가까움'(\(\delta\) 또는 \(N\))과 출력 쪽의 '가까움'(\(\varepsilon\) 또는 \(M\))을 바꿔 끼우기만 하면 됩니다. 수열의 극한(11장)은 \(x > N\) 대신 \(n > N\)인 같은 정의입니다. 이 도구가 쓰이는 곳

극한은 미적분 안에서 모든 정의의 재료이고, 미적분 밖에서는 "근사가 얼마나 좋은가"를 말하는 언어입니다.

수치 미분의 h 고르기 시뮬레이션 코드에서 도함수를 \(\frac{f(x+h) - f(x)}{h}\)로 근사할 때, \(h\)를 줄이면 근사 오차(대략 \(h\)에 비례)는 줄지만 상쇄 오차(대략 \(10^{-16}/h\)에 비례)는 커집니다. 두 오차의 합이 가장 작은 곳은 배정밀도에서 대략 \(h \approx 10^{-8}\)입니다. 2절 시뮬레이터의 V자 그래프가 바로 이 균형이고, 극한 "\(h \to 0\)"을 컴퓨터에서 흉내 낼 때 반드시 마주치는 한계입니다. 중심 차분 \(\frac{f(x+h) - f(x-h)}{2h}\)을 쓰면 근사 오차가 \(h^2\)에 비례해 더 큰 \(h\)에서 같은 정확도를 얻습니다.

핵심 정리

  1. \(\lim_{x\to a}f(x) = L\)은 \(x \ne a\)인 \(a\) 근처의 값만 본다. \(f(a)\)가 없거나 달라도 극한은 같다.
  2. 그래프 확대와 수치표는 극한을 추측하는 도구다. 표는 표본 선택(\(\sin(\pi/x)\))과 상쇄 오차(\((1 - \cos h)/h^2\)) 때문에 틀릴 수 있다.
  3. 양쪽 극한은 좌극한과 우극한이 같을 때만 존재한다. 극한이 없는 세 모양은 점프, 진동, 발산(\(\pm\infty\))이다.
  4. 극한 법칙(합·곱·몫·거듭제곱·근)은 각 극한이 존재할 때만 쓴다. 다항식·유리식은 직접 대입하고, 0/0이면 인수분해·유리화·통분으로 문제의 인수를 소거한다.
  5. 조임 정리: \(g \le f \le h\)이고 \(g, h \to L\)이면 \(f \to L\). 특히 \(|f| \le h \to 0\)이면 \(f \to 0\).
  6. \(x \to \pm\infty\)에서는 최고차항으로 나눈다. 수평 점근선은 무한대에서의 극한, 수직 점근선은 한쪽 무한 극한, 비스듬한 점근선은 차수가 1 큰 유리식에서 나온다.
  7. ε–δ 정의: 모든 \(\varepsilon > 0\)에 대해 \(0 \lt |x - a| \lt \delta \Rightarrow |f(x) - L| \lt \varepsilon\)인 \(\delta > 0\)이 있다. 출력 허용 오차를 지키는 입력 허용 오차가 언제나 있다는 뜻이다.

확인 퀴즈

Q1. \(\displaystyle \lim_{x\to 4}\frac{x - 4}{\sqrt x - 2}\)의 값은?

대입하면 0/0. \(x - 4 = (\sqrt x - 2)(\sqrt x + 2)\)로 인수분해하면 \(x \ne 4\)에서 식은 \(\sqrt x + 2\)이고, 대입하면 \(2 + 2 = 4\). 분모를 유리화해도 같은 결과가 나온다.

Q2. \(f(x) = \dfrac{|x - 1|}{x - 1}\)에 대해 옳은 것은?

\(x > 1\)이면 \(f(x) = 1\), \(x \lt 1\)이면 \(f(x) = -1\). 한쪽 극한은 각각 1과 −1로 존재하지만 서로 달라서 양쪽 극한은 없다(정리 1.3). \(f(1)\)이 정의되지 않는 것은 극한과 상관이 없다.

Q3. \(\displaystyle \lim_{x\to\infty} \frac{5x^3 - 2x}{2x^3 + x^2 + 7}\)의 값은?

분자·분모를 \(x^3\)으로 나누면 \(\dfrac{5 - 2/x^2}{2 + 1/x + 7/x^3} \to \dfrac52\). 차수가 같으면 최고차 계수의 비다(정리 1.11).

Q4. 수치표에서 \(\sin(\pi/x)\)를 \(x = 0.1, 0.01, 0.001, 0.0001\)에 대해 계산하면 모두 0이다. \(\lim_{x\to 0}\sin(\pi/x)\)는?

\(x = 1/n\)에서는 \(\sin(n\pi) = 0\)이지만 \(x = 2/(4n+1)\)에서는 \(\sin\bigl((4n + 1)\pi/2\bigr) = 1\)이다. 0에 아무리 가까워도 0과 1인 점이 다 있으므로 극한은 없다. 표는 표본을 고르는 방식에 따라 속일 수 있다.

Q5. \(\lim_{x\to 0}x\cos(1/x)\)를 구하는 가장 알맞은 방법과 값은?

\(\lim\cos(1/x)\)가 존재하지 않으므로 곱의 법칙은 쓸 수 없고, \(\cos\infty\)는 뜻이 없다. \(|\cos(1/x)| \le 1\)에서 \(|x\cos(1/x)| \le |x| \to 0\)이므로 조임 정리로 극한은 0이다. 진동은 남지만 진폭이 0으로 눌린다.

Q6. \(f(x) = \dfrac{x^2 - 1}{x^2 - x}\)의 수직 점근선은?

\(f(x) = \dfrac{(x - 1)(x + 1)}{x(x - 1)} = \dfrac{x+1}{x}\) (\(x \ne 0, 1\)). \(x = 1\)에서는 0/0이 소거되어 극한 2가 있으므로 구멍일 뿐이다. \(x = 0\)에서는 분자 → 1, 분모 → 0이므로 수직 점근선이다.

Q7. \(\lim_{x\to 2}(4x + 3) = 11\)에서 \(\varepsilon = 0.02\)일 때 합격하는 가장 큰 \(\delta\)는?

\(|(4x + 3) - 11| = 4|x - 2| \lt 0.02 \iff |x - 2| \lt 0.005\). 기울기 4가 입력 오차를 4배로 키우므로 \(\delta = \varepsilon/4\). 이보다 작은 \(\delta\)도 모두 합격이다.

Q8. \(\displaystyle \lim_{h\to 0}\frac{(2 + h)^2 - 4}{h}\)의 값은?

전개하면 \(\dfrac{4 + 4h + h^2 - 4}{h} = 4 + h\) (\(h \ne 0\))이고 \(h \to 0\)이면 4. 이것은 \(y = x^2\)의 \(x = 2\)에서의 접선 기울기, 즉 도함수 값이다(3장).
