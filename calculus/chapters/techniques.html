적분 기법

미적분의 기본 정리는 정적분을 "역도함수를 찾아 양 끝 값을 빼는 일"로 바꿔 주었습니다. 문제는 역도함수를 찾는 일이 미분처럼 기계적이지 않다는 것입니다. 곱의 미분은 공식 한 줄이지만 곱의 적분에는 공식이 없고, \(\sqrt{1-x^2}\)이나 \(\frac{1}{x^2-1}\)처럼 단순해 보이는 함수도 그대로는 적분표에 없습니다. 이 장은 적분을 아는 꼴로 바꾸는 네 가지 도구, 부분 적분·삼각 적분·삼각 치환·부분 분수를 익히고, 구간이 무한하거나 함수가 폭발하는 이상 적분을 다룬 다음, 어떤 기법으로도 닫힌 꼴이 나오지 않을 때 쓰는 수치 적분과 그 오차까지 갑니다.

  • \(\int u\,dv = uv - \int v\,du\)를 넓이 그림으로 이해하고, LIATE 순서·표 방법·순환형으로 부분 적분을 빠르게 한다.
  • \(\sin^m x\cos^n x\)와 \(\tan, \sec\)의 적분을 지수의 홀짝으로 분류해 풀고, 삼각 함수의 직교성을 확인한다.
  • \(\sqrt{a^2-x^2}, \sqrt{a^2+x^2}, \sqrt{x^2-a^2}\)를 기준 삼각형으로 치환하고, 결과를 다시 \(x\)로 되돌린다.
  • 유리 함수를 부분 분수로 쪼개(서로 다른 일차 인수·중근·기약 이차 인수) 로그와 arctan으로 적분한다.
  • 무한 구간과 무한 불연속의 이상 적분을 극한으로 정의하고, p-적분과 비교 판정으로 수렴·발산을 가린다.
  • 사다리꼴·중점·심프슨 공식을 쓰고, 오차가 \(n^{-2}\)와 \(n^{-4}\)로 줄어드는 이유와 오차 한계로 필요한 \(n\)을 정한다.

공장에서 깎은 축의 지름이 정규분포를 따른다면, 공차 ±1σ 안에 들어오는 부품의 비율은 종 모양 곡선 \(e^{-x^2/2}\) 아래 넓이입니다. 그런데 이 함수의 역도함수는 다항식·지수·로그·삼각 함수를 유한 번 조합한 어떤 식으로도 쓸 수 없습니다. 19세기에 리우빌(Joseph Liouville)이 이런 "초등 함수로 적분되지 않는 함수"를 판정하는 이론을 세웠고, \(e^{-x^2}\)은 그 대표 예입니다.

그래서 공학은 두 갈래 길을 갑니다. 하나는 적분을 아는 꼴로 바꾸는 기법입니다. 부분 적분·치환·부분 분수로 바꿀 수 있는 적분은 정확한 식이 나오고, 그 식이 설계 공식이 됩니다. 다른 하나는 바꿀 수 없는 적분을 정해진 정확도의 숫자로 계산하는 수치 적분입니다. 정규분포표, 계산기의 erf 버튼, 유한 요소 해석의 강성 행렬 적분이 모두 그 결과입니다. 이 장은 두 길을 다 걷습니다.

부분 적분: 곱의 법칙을 거꾸로

곱의 적분에는 공식이 없다

축전기에 지수적으로 줄어드는 전류 \(i(t) = I_0\,e^{-t/\tau}\)가 흐를 때, 시간 가중 평균 \(\int_0^\infty t\,e^{-t/\tau}\,dt\)는 전하가 평균적으로 언제 빠져나가는지 알려 줍니다. 그런데 \(t\)와 \(e^{-t/\tau}\)의 곱을 적분하는 공식은 없습니다. 미분에는 곱의 법칙이 있는데 적분에는 무엇이 대응할까요?

곱의 법칙 \((uv)' = u'v + uv'\)을 양변 적분하면 \(uv = \int u'v\,dx + \int uv'\,dx\)입니다. 이것을 정리하면 곱의 적분 하나를 다른 곱의 적분으로 바꾸는 식이 나옵니다. 바꾼 적분이 더 쉬우면 이긴 것입니다.

정리 9.1 (부분 적분) \(u, v\)가 \([a, b]\)에서 연속 미분 가능하면
$$\int u\,dv = uv - \int v\,du, \qquad \int_a^b u(x)v'(x)\,dx = \Big[u(x)v(x)\Big]_a^b - \int_a^b v(x)u'(x)\,dx.$$
\(du = u'(x)\,dx\), \(dv = v'(x)\,dx\). 적분할 곱을 "미분할 쪽 \(u\)"와 "적분할 쪽 \(dv\)"로 나누는 것이 전부다.

증명. \((uv)' = u'v + uv'\)은 연속이므로 미적분의 기본 정리(8장)에 의해 \(\int_a^b (uv)'\,dx = u(b)v(b) - u(a)v(a)\). 좌변을 둘로 나누고 \(\int_a^b u'v\,dx\)를 이항하면 된다. ∎

이름 그대로 부분 적분(integration by parts)은 피적분 함수의 일부만 적분합니다. 그림으로 보면 더 분명합니다. 가로축을 \(u\), 세로축을 \(v\)로 하는 평면에 \(x\)가 \(a\)에서 \(b\)로 갈 때의 점 \((u(x), v(x))\)을 찍으면 곡선이 하나 생깁니다. 곡선과 \(v\)축 사이 넓이가 \(\int u\,dv\), 곡선과 \(u\)축 사이 넓이가 \(\int v\,du\)이고, 둘을 합치면 큰 직사각형 \(u(b)v(b)\)에서 작은 직사각형 \(u(a)v(a)\)를 뺀 것입니다.

어느 쪽을 \(u\)로 고를지에는 경험칙이 있습니다. 미분하면 단순해지는 쪽을 \(u\)로, 적분해도 복잡해지지 않는 쪽을 \(dv\)로 고릅니다. 흔히 쓰는 순서는 LIATE(로그 → 역삼각 → 대수(다항식) → 삼각 → 지수)로, 앞에 있는 것일수록 \(u\)로 고릅니다. 로그와 역삼각 함수는 미분하면 유리 함수가 되어 단순해지고, 지수와 삼각 함수는 적분해도 모양이 그대로이기 때문입니다.

예제 9.1 (기본형 두 개)
  1. \(\int x e^x\,dx\): 다항식 \(x\)를 \(u\)로. \(u = x,\ dv = e^x dx\)이면 \(du = dx,\ v = e^x\). 따라서 \(\int xe^x\,dx = xe^x - \int e^x\,dx = (x-1)e^x + C\). 정적분 \(\int_0^1 xe^x\,dx = [(x-1)e^x]_0^1 = 0 - (-1) = 1\).
  2. \(\int \ln x\,dx\): 곱이 아닌 것 같지만 \(\ln x \cdot 1\)로 봅니다. \(u = \ln x,\ dv = dx\)이면 \(du = dx/x,\ v = x\). \(\int \ln x\,dx = x\ln x - \int x\cdot\tfrac{1}{x}\,dx = x\ln x - x + C\).
  3. 검산은 언제나 미분으로: \(\tfrac{d}{dx}(x\ln x - x) = \ln x + 1 - 1 = \ln x\). ✓ 같은 방법으로 \(\int \arctan x\,dx = x\arctan x - \tfrac12\ln(1+x^2) + C\)입니다.

다항식 차수가 높으면 부분 적분을 여러 번 해야 합니다. \(x^3e^x\)이라면 세 번입니다. 매번 \(u\)는 미분하고 \(dv\)는 적분하며 부호가 번갈아 바뀌므로, 이것을 표로 정리한 것이 표 방법(tabular integration)입니다. 왼쪽 열에 \(u\)를 0이 될 때까지 미분해 적고, 오른쪽 열에 \(dv\)를 거듭 적분해 적은 다음, 대각선으로 곱하며 부호 \(+, -, +, \dots\)를 붙여 더합니다.

예제 9.2 (표 방법) \(\int x^2\sin x\,dx\)와 \(\int_0^\pi x^2\sin x\,dx\)를 구하라.
  1. 미분 열: \(x^2 \to 2x \to 2 \to 0\). 적분 열: \(\sin x \to -\cos x \to -\sin x \to \cos x\).
  2. 대각선 곱에 부호 \(+,-,+\): \(+x^2(-\cos x) - 2x(-\sin x) + 2\cos x\). 따라서 \(\int x^2\sin x\,dx = -x^2\cos x + 2x\sin x + 2\cos x + C\).
  3. 정적분: \(x = \pi\)에서 \(\pi^2 + 0 - 2\), \(x = 0\)에서 \(0 + 0 + 2\). 답은 \(\pi^2 - 4 \approx 5.870\).

예제 9.3 (순환형) \(I = \int e^x\sin x\,dx\)를 구하라.

정리 9.2 (축소 공식) \(n \ge 2\)이면
$$\int \sin^n x\,dx = -\frac{1}{n}\sin^{n-1}x\cos x + \frac{n-1}{n}\int\sin^{n-2}x\,dx.$$

증명. \(u = \sin^{n-1}x,\ dv = \sin x\,dx\)로 부분 적분하면 \(\int\sin^n x\,dx = -\sin^{n-1}x\cos x + (n-1)\int\sin^{n-2}x\cos^2x\,dx\). \(\cos^2 x = 1 - \sin^2 x\)를 넣으면 우변에 \(-(n-1)\int\sin^n x\,dx\)가 생기고, 이항해 \(n\)으로 나눈다. ∎

이런 축소 공식(reduction formula)은 지수를 2씩 낮춰 결국 \(\int dx\)나 \(\int\sin x\,dx\)에 닿게 합니다. 정적분 \(\int_0^{\pi/2}\sin^n x\,dx\)에서는 첫 항이 양 끝에서 0이 되어 \(\frac{n-1}{n}\)을 곱하는 일만 남습니다. 예를 들어 \(\int_0^{\pi/2}\sin^4 x\,dx = \frac34\cdot\frac12\cdot\frac{\pi}{2} = \frac{3\pi}{16}\)입니다.

삼각 적분: 홀수 지수는 떼어 내고, 짝수 지수는 반각으로

교류 전력의 평균

저항 \(R\)에 전압 \(V_0\sin\omega t\)를 걸면 순간 전력은 \(\frac{V_0^2}{R}\sin^2\omega t\)입니다. 한 주기 평균 전력을 알려면 \(\int_0^{2\pi}\sin^2\theta\,d\theta\)가 필요합니다. 가정용 전기의 "220 V"가 최댓값이 아니라 실효값이라는 말도 이 적분에서 나옵니다.

\(\int\sin^m x\cos^n x\,dx\) 꼴은 지수의 홀짝으로 갈립니다. 핵심 도구는 피타고라스 항등식 \(\sin^2 + \cos^2 = 1\)과 반각 공식입니다.

$$\sin^2 x = \frac{1 - \cos 2x}{2}, \qquad \cos^2 x = \frac{1 + \cos 2x}{2}, \qquad \sin x\cos x = \frac{\sin 2x}{2}.$$
꼴방법치환
\(\sin x\)의 지수가 홀수\(\sin x\) 하나를 떼고 나머지를 \(1-\cos^2x\)로\(u = \cos x\)
\(\cos x\)의 지수가 홀수\(\cos x\) 하나를 떼고 나머지를 \(1-\sin^2x\)로\(u = \sin x\)
둘 다 짝수반각 공식으로 지수를 반으로 낮춘다(반복)
\(\tan^m x\sec^n x\), \(n\) 짝수\(\sec^2x\) 하나를 떼고 나머지를 \(1+\tan^2x\)로\(u = \tan x\)
\(\tan^m x\sec^n x\), \(m\) 홀수\(\sec x\tan x\)를 떼고 나머지 \(\tan^2x\)를 \(\sec^2x - 1\)로\(u = \sec x\)
예제 9.4 (홀수·짝수 지수)
  1. \(\int\sin^3 x\,dx = \int(1-\cos^2x)\sin x\,dx\). \(u = \cos x,\ du = -\sin x\,dx\)이면 \(-\int(1-u^2)\,du = -\cos x + \tfrac13\cos^3x + C\).
  2. \(\int\sin^2x\cos^3x\,dx = \int\sin^2x(1-\sin^2x)\cos x\,dx\). \(u = \sin x\)이면 \(\int(u^2 - u^4)\,du = \tfrac13\sin^3x - \tfrac15\sin^5x + C\).
  3. \(\int_0^{2\pi}\sin^2\theta\,d\theta = \int_0^{2\pi}\tfrac{1-\cos2\theta}{2}\,d\theta = \pi\). 한 주기 평균은 \(\pi/2\pi = 1/2\)이므로 평균 전력은 \(\frac{V_0^2}{2R}\), 실효값은 \(V_0/\sqrt2\)입니다. 220 V 실효값의 최댓값은 약 311 V입니다.
  4. \(\int\sec x\,dx\): 분자·분모에 \(\sec x + \tan x\)를 곱하면 분자가 분모의 도함수가 되어 \(\ln|\sec x + \tan x| + C\). 처음 보면 기교 같지만, 미분으로 검산할 수 있습니다.

삼각 적분에서 가장 쓸모 있는 결과는 서로 다른 진동수의 사인·코사인을 곱해 한 주기 적분하면 0이 된다는 사실입니다. 곱을 합으로 바꾸는 공식 \(\sin mx\sin nx = \tfrac12[\cos(m-n)x - \cos(m+n)x]\)를 쓰면 바로 증명됩니다.

정리 9.3 (삼각 함수의 직교성) 음이 아닌 정수 \(m, n\)에 대해
$$\int_{-\pi}^{\pi}\sin mx\sin nx\,dx = \int_{-\pi}^{\pi}\cos mx\cos nx\,dx = \begin{cases}0 & m \ne n\\ \pi & m = n \ge 1\end{cases}, \qquad \int_{-\pi}^{\pi}\sin mx\cos nx\,dx = 0.$$
\(m = n = 0\)이면 \(\int\cos 0\cdot\cos 0\,dx = 2\pi\).

증명. \(m \ne n\)이면 \(\sin mx\sin nx = \tfrac12[\cos(m-n)x - \cos(m+n)x]\)이고, 0이 아닌 정수 \(k\)에 대해 \(\int_{-\pi}^{\pi}\cos kx\,dx = \big[\tfrac{\sin kx}{k}\big]_{-\pi}^{\pi} = 0\). \(m = n\ge1\)이면 \(\tfrac12[1 - \cos2mx]\)의 적분으로 \(\pi\). \(\sin mx\cos nx\)는 홀함수라 대칭 구간에서 0이다. ∎

이 직교성(orthogonality)은 벡터의 내적이 0인 것과 같은 구조입니다. 함수 두 개의 "내적"을 \(\int f g\,dx\)로 정의하면 \(\sin x, \sin 2x, \dots\)는 서로 수직인 축이 되고, 신호를 이 축에 사영한 좌표가 푸리에 계수입니다(MathBook 푸리에, LinearBook 직교성).

삼각 치환: 근호를 삼각형의 한 변으로

원의 넓이를 적분으로

반지름 \(a\)인 원의 넓이가 \(\pi a^2\)이라는 것은 알지만, 원의 위쪽 반 \(y = \sqrt{a^2 - x^2}\) 아래 넓이를 적분으로 구하려 하면 막힙니다. \(u = a^2 - x^2\)로 치환하면 \(du = -2x\,dx\)인데 피적분 함수에 \(x\)가 없습니다. 근호를 없앨 다른 방법이 필요합니다.

8장의 치환은 "안쪽 함수의 도함수가 바깥에 있을 때" 쓰는 방법이었습니다. 삼각 치환(trigonometric substitution)은 방향이 반대입니다. \(x\) 자체를 \(\theta\)의 함수로 놓아서 근호 안이 완전제곱이 되게 만듭니다. 피타고라스 항등식 \(1 - \sin^2\theta = \cos^2\theta\), \(1 + \tan^2\theta = \sec^2\theta\), \(\sec^2\theta - 1 = \tan^2\theta\)가 세 가지 경우에 대응합니다.

정리 9.4 (삼각 치환) \(a > 0\)일 때
  • \(\sqrt{a^2 - x^2}\): \(x = a\sin\theta\), \(-\tfrac{\pi}{2} \le \theta \le \tfrac{\pi}{2}\)이면 \(\sqrt{a^2-x^2} = a\cos\theta\), \(dx = a\cos\theta\,d\theta\).
  • \(\sqrt{a^2 + x^2}\): \(x = a\tan\theta\), \(-\tfrac{\pi}{2} \lt \theta \lt \tfrac{\pi}{2}\)이면 \(\sqrt{a^2+x^2} = a\sec\theta\), \(dx = a\sec^2\theta\,d\theta\).
  • \(\sqrt{x^2 - a^2}\): \(x = a\sec\theta\), \(0 \le \theta \lt \tfrac{\pi}{2}\) (\(x \ge a\))이면 \(\sqrt{x^2-a^2} = a\tan\theta\), \(dx = a\sec\theta\tan\theta\,d\theta\).

각 범위에서 치환은 일대일이고 \(\cos\theta \ge 0\) 또는 \(\tan\theta \ge 0\)이라 근호를 벗길 때 절댓값이 필요 없다. 이것이 \(\theta\)의 범위를 정해 두는 이유다.

예제 9.5 (원의 넓이) \(\int_0^a\sqrt{a^2 - x^2}\,dx\)를 구하라.
  1. \(x = a\sin\theta\): \(x = 0 \to \theta = 0\), \(x = a \to \theta = \tfrac{\pi}{2}\). 피적분 함수는 \(a\cos\theta\cdot a\cos\theta\,d\theta\).
  2. \(a^2\int_0^{\pi/2}\cos^2\theta\,d\theta = a^2\int_0^{\pi/2}\tfrac{1+\cos2\theta}{2}\,d\theta = a^2\cdot\tfrac{\pi}{4}\). 사분원 넓이 \(\tfrac{\pi a^2}{4}\), 네 배 하면 \(\pi a^2\). ✓
  3. 부정적분으로 되돌리면 \(\int\sqrt{a^2-x^2}\,dx = \tfrac{a^2}{2}\theta + \tfrac{a^2}{2}\sin\theta\cos\theta + C = \tfrac{a^2}{2}\arcsin\tfrac{x}{a} + \tfrac{x}{2}\sqrt{a^2-x^2} + C\). 첫 항은 부채꼴, 둘째 항은 삼각형의 넓이입니다(아래 시뮬레이터).
예제 9.6 (선전하의 전기장) 길이 무한한 직선 위에 전하가 고르게 퍼져 있을 때, 거리 \(d\)인 점의 전기장 수직 성분에는 \(\int\frac{dx}{(x^2+d^2)^{3/2}}\)이 나옵니다.
  1. \(x = d\tan\theta\): \((x^2+d^2)^{3/2} = d^3\sec^3\theta\), \(dx = d\sec^2\theta\,d\theta\).
  2. \(\int\frac{d\sec^2\theta}{d^3\sec^3\theta}\,d\theta = \frac{1}{d^2}\int\cos\theta\,d\theta = \frac{\sin\theta}{d^2} + C\).
  3. 기준 삼각형에서 \(\sin\theta = \frac{x}{\sqrt{x^2+d^2}}\). 답: \(\frac{x}{d^2\sqrt{x^2+d^2}} + C\). 전 구간 \((-\infty, \infty)\)이면 \(\theta\)가 \(-\tfrac{\pi}{2}\)에서 \(\tfrac{\pi}{2}\)까지 가서 값은 \(\frac{2}{d^2}\)이고, 전기장이 \(1/d\)로 줄어드는 이유가 여기서 나옵니다. 유한 구간 예: \(d = 1\), \(\int_0^1\frac{dx}{(x^2+1)^{3/2}} = \frac{1}{\sqrt2} \approx 0.707\).

부분 분수: 유리 함수를 쪼개 적분하기

회로의 응답을 시간 영역으로

RLC 회로나 제어계의 응답을 라플라스 변환으로 풀면 \(\frac{s+5}{s^2+s-2}\) 같은 유리 함수가 나옵니다. 이것을 시간 함수로 되돌리려면, 또 로지스틱 방정식 \(\frac{dP}{P(1-P)} = r\,dt\)를 적분하려면, 분모가 인수분해된 유리 함수를 단순한 조각의 합으로 바꿔야 합니다.

통분의 역과정입니다. \(\frac{2}{x-1} - \frac{1}{x+2}\)을 통분하면 \(\frac{x+5}{(x-1)(x+2)}\)이므로, 거꾸로 오른쪽을 왼쪽처럼 쪼개면 각 조각은 \(\ln\)으로 바로 적분됩니다. 쪼갠 조각들을 부분 분수 분해(partial fraction decomposition)라 합니다.

정리 9.5 (부분 분수 분해) 실수 계수 다항식 \(P, Q\)에서 \(\deg P \lt \deg Q\)이고 \(Q\)를 일차 인수와 기약 이차 인수(판별식이 음수)의 곱으로 인수분해하면, \(\frac{P}{Q}\)는 다음 꼴의 합으로 유일하게 쓸 수 있다.
  • 일차 인수 \((x - r)^k\)마다: \(\frac{A_1}{x-r} + \frac{A_2}{(x-r)^2} + \cdots + \frac{A_k}{(x-r)^k}\)
  • 기약 이차 인수 \((x^2 + bx + c)^k\)마다: \(\frac{B_1x + C_1}{x^2+bx+c} + \cdots + \frac{B_kx + C_k}{(x^2+bx+c)^k}\)

\(\deg P \ge \deg Q\)이면 먼저 다항식 나눗셈으로 \(\frac{P}{Q} = S + \frac{R}{Q}\) (\(\deg R \lt \deg Q\))로 만든다. 증명 아이디어. 미지 계수의 개수가 \(\deg Q\)와 같고, 양변에 \(Q\)를 곱해 얻는 선형 연립방정식이 언제나 유일한 해를 가짐을 보인다(대수학의 기본 정리와 다항식의 서로소 성질을 쓴다).

분모가 서로 다른 일차 인수 \((x - r_1)\cdots(x - r_n)\)의 곱이면 계수를 구하는 지름길이 있습니다. \(A_i\)를 구하려면 양변에 \((x - r_i)\)를 곱하고 \(x = r_i\)를 넣습니다. 다른 조각은 모두 0이 되므로 \(A_i = \frac{P(r_i)}{\prod_{j\ne i}(r_i - r_j)} = \frac{P(r_i)}{Q'(r_i)}\)입니다. 원래 식에서 \((x - r_i)\)를 손가락으로 가리고 나머지에 \(r_i\)를 넣는 셈이라 헤비사이드 가리기 방법(Heaviside cover-up method)이라 부릅니다.

예제 9.7 (서로 다른 일차 인수) \(\int\frac{x+5}{x^2+x-2}\,dx\)를 구하라.
  1. 인수분해: \(x^2 + x - 2 = (x-1)(x+2)\). 분자 차수 1 \(\lt\) 분모 차수 2.
  2. 가리기: \(A = \frac{1+5}{1+2} = 2\) (\(x = 1\)), \(B = \frac{-2+5}{-2-1} = -1\) (\(x = -2\)).
  3. \(\int\Big(\frac{2}{x-1} - \frac{1}{x+2}\Big)dx = 2\ln|x-1| - \ln|x+2| + C = \ln\frac{(x-1)^2}{|x+2|} + C\).
예제 9.8 (중근과 기약 이차 인수)
  1. \(\frac{2x+1}{(x-1)^2(x+2)} = \frac{A}{x-1} + \frac{B}{(x-1)^2} + \frac{C}{x+2}\). 양변에 분모를 곱하면 \(2x+1 = A(x-1)(x+2) + B(x+2) + C(x-1)^2\). \(x = 1\): \(3 = 3B\), \(B = 1\). \(x = -2\): \(-3 = 9C\), \(C = -\tfrac13\). \(x^2\)의 계수: \(0 = A + C\), \(A = \tfrac13\). 적분은 \(\tfrac13\ln|x-1| - \frac{1}{x-1} - \tfrac13\ln|x+2| + C\). 중근 조각 \(\frac{1}{(x-1)^2}\)은 로그가 아니라 \(-\frac{1}{x-1}\)이 됩니다.
  2. \(\frac{1}{x(x^2+1)} = \frac{A}{x} + \frac{Bx + C}{x^2+1}\). \(1 = A(x^2+1) + (Bx+C)x\)에서 \(A = 1\), \(B = -1\), \(C = 0\). 적분은 \(\ln|x| - \tfrac12\ln(x^2+1) + C\). 기약 이차 조각의 분자가 \(x\)이면 로그, 상수이면 arctan이 됩니다.

공식이 아니라 순서

지금까지 기법을 하나씩 따로 연습했지만, 실제 적분은 이름표를 달고 오지 않습니다. \(\int\frac{x}{\sqrt{1-x^2}}dx\)는 삼각 치환으로도 풀리지만 단순 치환이 훨씬 빠르고, \(\int\frac{x^3}{x^2+1}dx\)는 부분 분수 전에 나눗셈부터 해야 합니다. 어떤 순서로 생각해야 할까요?

예제 9.9 (기법 고르기)
  1. \(\int\frac{x}{\sqrt{1-x^2}}dx\): \(u = 1 - x^2\)이면 \(du = -2x\,dx\)가 곁에 있다. \(-\tfrac12\int u^{-1/2}du = -\sqrt{1-x^2} + C\). 삼각 치환도 되지만 돌아가는 길입니다.
  2. \(\int\frac{x^3}{x^2+1}dx\): 나눗셈 \(\frac{x^3}{x^2+1} = x - \frac{x}{x^2+1}\). 답 \(\tfrac{x^2}{2} - \tfrac12\ln(x^2+1) + C\).
  3. \(\int e^{\sqrt x}dx\): \(t = \sqrt x\), \(dx = 2t\,dt\)로 \(2\int te^t\,dt = 2(t-1)e^t + C = 2(\sqrt x - 1)e^{\sqrt x} + C\). 치환 뒤 부분 적분입니다.
  4. \(\int\frac{dx}{x^2 + 4x + 8}\): 완전제곱 \((x+2)^2 + 4\)로 바꾸면 \(\tfrac12\arctan\frac{x+2}{2} + C\).

이상 적분: 무한까지 쌓은 넓이

지구를 떠나는 데 드는 일

질량 \(m\)인 로켓을 지표면(반지름 \(R\))에서 무한히 먼 곳까지 끌어올리는 데 필요한 일은 \(\int_R^\infty\frac{GMm}{r^2}dr\)입니다. 구간이 끝없이 이어지는데 답이 유한할 수 있을까요? 유한하다면 그 값이 로켓이 지구 중력을 벗어나는 탈출 속도를 정합니다.

7장의 정적분은 유한 구간에서 유계인 함수에 대한 것이었습니다. 둘 중 하나가 깨지면 리만 합으로 정의할 수 없으므로, 유한한 경우의 극한으로 정의합니다.

정의 9.6 (이상 적분)
  • 무한 구간. \(f\)가 모든 \([a, t]\)에서 적분 가능하면 \(\displaystyle\int_a^\infty f(x)\,dx = \lim_{t\to\infty}\int_a^t f(x)\,dx\). \(\int_{-\infty}^\infty f = \int_{-\infty}^c f + \int_c^\infty f\)이고 두 극한이 각각 존재해야 한다.
  • 무한 불연속. \(f\)가 \((a, b]\)에서 연속이고 \(x \to a^+\)에서 유계가 아니면 \(\displaystyle\int_a^b f(x)\,dx = \lim_{t\to a^+}\int_t^b f(x)\,dx\). 끝점 \(b\)나 구간 내부에서 폭발할 때도 같은 식으로, 내부라면 둘로 나눈다.

극한이 유한한 수로 존재하면 이상 적분(improper integral)이 수렴한다고 하고, 그렇지 않으면 발산한다고 한다.

어떤 꼬리 넓이가 유한한지 가르는 기준이 되는 것이 거듭제곱 함수입니다. 결과는 단순하지만 놀랍습니다. \(\frac{1}{x}\)과 \(\frac{1}{x^2}\)은 그래프로는 비슷해 보이는데, 꼬리 넓이는 한쪽이 무한, 한쪽이 1입니다.

정리 9.7 (p-적분)
$$\int_1^\infty\frac{dx}{x^p} = \begin{cases}\dfrac{1}{p-1} & p > 1\\[4pt] \infty & p \le 1\end{cases}, \qquad \int_0^1\frac{dx}{x^p} = \begin{cases}\dfrac{1}{1-p} & p \lt 1\\[4pt] \infty & p \ge 1\end{cases}.$$

증명. \(p \ne 1\)이면 \(\int_1^t x^{-p}dx = \frac{t^{1-p} - 1}{1-p}\). \(t\to\infty\)일 때 \(t^{1-p}\)은 \(p > 1\)이면 0으로, \(p \lt 1\)이면 \(\infty\)로 간다. \(p = 1\)이면 \(\int_1^t\frac{dx}{x} = \ln t \to \infty\). 두 번째 식도 \(\int_t^1 x^{-p}dx = \frac{1 - t^{1-p}}{1-p}\)에서 \(t \to 0^+\)으로 같다. ∎

이 두 적분을 p-적분(p-integral)이라 부릅니다. 두 식은 거울처럼 반대입니다. 무한대 쪽에서는 빨리 줄어드는 \(p > 1\)이, 0 쪽에서는 천천히 폭발하는 \(p \lt 1\)이 유한한 넓이를 줍니다. \(p = 1\)은 양쪽 모두 아슬아슬하게 발산합니다. 이 경계는 11장에서 급수 \(\sum\frac{1}{n^p}\)의 수렴 판정으로 그대로 이어집니다.

  3. 탈출 속도: \(\int_R^\infty\frac{GMm}{r^2}dr = \frac{GMm}{R}\). 이것을 운동 에너지 \(\tfrac12mv^2\)와 같게 놓으면 \(v = \sqrt{2GM/R}\). 지구는 \(GM \approx 3.986\times10^{14}\ \mathrm{m^3/s^2}\), \(R \approx 6.371\times10^6\ \mathrm{m}\)이라 \(v \approx 1.12\times10^4\ \mathrm{m/s}\), 약 11.2 km/s입니다.
  4. 함정: \(\int_{-1}^1\frac{dx}{x^2}\)에 기본 정리를 그대로 쓰면 \(\big[-\tfrac1x\big]_{-1}^1 = -2\)라는, 양수 함수의 넓이가 음수인 엉터리 답이 나옵니다. \(x = 0\)에서 폭발하므로 둘로 나눠야 하고, \(\int_0^1\frac{dx}{x^2}\)이 발산하므로 전체가 발산합니다.

역도함수를 구할 수 없을 때도 수렴 여부는 알 수 있습니다. 더 큰 함수의 넓이가 유한하면 작은 함수의 넓이도 유한하고, 더 작은 함수의 넓이가 무한하면 큰 함수의 넓이도 무한합니다.

정리 9.8 (비교 판정과 극한 비교 판정) \(x \ge a\)에서 \(f, g\)가 연속이고 \(0 \le f(x) \le g(x)\)이면
  • \(\int_a^\infty g\)가 수렴하면 \(\int_a^\infty f\)도 수렴하고, \(\int_a^\infty f\)가 발산하면 \(\int_a^\infty g\)도 발산한다(비교 판정(comparison test)).
  • \(f, g > 0\)이고 \(\lim_{x\to\infty}\frac{f(x)}{g(x)} = L\), \(0 \lt L \lt \infty\)이면 두 적분은 함께 수렴하거나 함께 발산한다(극한 비교 판정(limit comparison test)).

증명 아이디어. \(F(t) = \int_a^t f\)는 \(f \ge 0\)이라 증가 함수이고, \(F(t) \le \int_a^\infty g\)로 위로 유계다. 위로 유계인 증가 함수는 극한을 가진다(실수의 완비성). 극한 비교는 충분히 큰 \(x\)에서 \(\tfrac{L}{2}g \le f \le 2Lg\)임을 써서 첫째로 돌린다. ∎

예제 9.11 (비교로 판정하기)
  1. \(\int_1^\infty e^{-x^2}dx\): \(x \ge 1\)이면 \(x^2 \ge x\)이므로 \(e^{-x^2} \le e^{-x}\). \(\int_1^\infty e^{-x}dx = e^{-1}\)이 유한하므로 수렴하고, 값은 \(1/e \approx 0.368\)보다 작습니다(실제로는 약 0.1394).
  2. \(\int_1^\infty\frac{1 + \sin^2x}{x^2}dx\): 분자가 2 이하이므로 \(\le\int_1^\infty\frac{2}{x^2}dx = 2\). 수렴.
  3. \(\int_2^\infty\frac{dx}{\sqrt{x^3+1}}\): 큰 \(x\)에서 \(\frac{1}{\sqrt{x^3+1}}\big/\frac{1}{x^{3/2}} \to 1\). \(p = \tfrac32 > 1\)이므로 극한 비교로 수렴.
  4. \(\int_1^\infty\frac{x}{x^2+1}dx\): \(\frac{x}{x^2+1}\big/\frac1x \to 1\)이고 \(\int\frac{dx}{x}\)가 발산하므로 발산합니다.
감마 함수 \(\Gamma(s) = \int_0^\infty x^{s-1}e^{-x}dx\)는 \(s > 0\)에서 수렴하는 이상 적분입니다. 부분 적분 한 번으로 \(\Gamma(s+1) = s\Gamma(s)\)가 나오고 \(\Gamma(1) = 1\)이므로 \(\Gamma(n+1) = n!\)입니다. 팩토리얼을 정수가 아닌 수로 넓힌 이 함수는 확률 분포(감마·카이제곱·t 분포)의 정규화 상수에 등장합니다.

수치 적분: 사다리꼴과 심프슨

역도함수가 없을 때, 또는 함수가 표로만 있을 때

\(\int_0^1 e^{-x^2}dx\)는 닫힌 꼴이 없습니다. 실험에서 1초마다 잰 유량 데이터로 총 유출량을 구할 때는 함수 식조차 없습니다. 두 경우 모두 유한 개의 함숫값으로 적분을 근사해야 하고, 중요한 질문은 "얼마나 정확한가, 점을 두 배로 늘리면 오차가 얼마나 줄어드는가"입니다.

구간 \([a, b]\)를 폭 \(h = \frac{b-a}{n}\)인 \(n\)개 조각으로 나누고 \(x_i = a + ih\), \(f_i = f(x_i)\)라 합시다. 7장의 리만 합은 조각마다 함수를 상수로 바꿨습니다. 조각마다 직선으로 바꾸면 사다리꼴 공식, 두 조각마다 포물선으로 바꾸면 심프슨 공식입니다.

$$T_n = \frac{h}{2}\big[f_0 + 2f_1 + 2f_2 + \cdots + 2f_{n-1} + f_n\big], \qquad M_n = h\big[f(\bar x_1) + \cdots + f(\bar x_n)\big],$$ $$S_n = \frac{h}{3}\big[f_0 + 4f_1 + 2f_2 + 4f_3 + \cdots + 2f_{n-2} + 4f_{n-1} + f_n\big]\quad(n\ \text{짝수}).$$
\(\bar x_i\)는 \(i\)번째 조각의 가운데 점. 심프슨 가중치는 1, 4, 2, 4, …, 2, 4, 1이다.

사다리꼴 공식(trapezoidal rule)은 이웃한 두 점을 이은 사다리꼴의 넓이 합이고, 중점 공식(midpoint rule)은 가운데 높이의 직사각형 합입니다. 심프슨 공식(Simpson's rule)의 계수는 세 점 \((-h, f_0), (0, f_1), (h, f_2)\)을 지나는 포물선 \(Ax^2 + Bx + C\)를 적분해서 나옵니다: \(\int_{-h}^h(Ax^2+Bx+C)dx = \frac{2Ah^3}{3} + 2Ch\)이고, \(f_0 + f_2 = 2Ah^2 + 2C\), \(f_1 = C\)를 쓰면 이것이 \(\frac{h}{3}(f_0 + 4f_1 + f_2)\)입니다.

정리 9.9 (오차 한계) 구간 \([a, b]\)에서 \(|f''| \le K_2\), \(|f^{(4)}| \le K_4\)이면
$$|E_T| \le \frac{K_2(b-a)^3}{12n^2}, \qquad |E_M| \le \frac{K_2(b-a)^3}{24n^2}, \qquad |E_S| \le \frac{K_4(b-a)^5}{180n^4}.$$

증명 아이디어. 한 조각 \([0, h]\)에서 \(f\)를 직선으로 바꾼 오차는 테일러 전개(12장)로 \(-\frac{h^3}{12}f''(\xi)\)이고, 조각이 \(n\)개이므로 합치면 \(-\frac{(b-a)h^2}{12}f''(\bar\xi)\)다. 중점 공식은 같은 계산에서 \(+\frac{h^3}{24}f''\)로 부호가 반대이고 크기가 절반이다. 심프슨은 \(\tfrac{2M + T}{3}\)으로 두 \(h^2\) 오차를 상쇄한 것이라 \(h^4\) 항이 남는다. 그래서 심프슨은 3차 다항식까지 정확하다. ∎

여기서 중요한 것은 상수보다 지수입니다. 사다리꼴과 중점은 \(n\)을 2배로 늘리면 오차가 약 1/4로(오차 차수(order of accuracy) 2), 심프슨은 약 1/16로(차수 4) 줄어듭니다. 같은 정확도를 원한다면 차수가 높은 방법이 훨씬 적은 함숫값으로 끝납니다. 단, 차수는 \(f\)가 충분히 매끄러울 때만의 약속입니다. \(\sqrt{x}\)처럼 끝점에서 도함수가 폭발하면 심프슨도 차수가 떨어집니다.

적분표와 CAS: 닫힌 꼴이 없는 적분

컴퓨터에 물어보면 끝일까

오늘날 기호 계산 프로그램(CAS)은 이 장의 거의 모든 적분을 순식간에 풉니다. 그런데 \(\int e^{-x^2}dx\)를 물으면 \(\frac{\sqrt\pi}{2}\operatorname{erf}(x)\)라는, 처음 보는 함수가 돌아옵니다. 이것은 답일까요, 답을 미룬 것일까요?

적분표와 CAS는 이 장의 기법을 체계적으로 모아 둔 것입니다. 표를 쓸 때는 먼저 피적분 함수를 표의 꼴로 맞추고(치환·완전제곱), CAS 결과는 언제나 미분해서 검산하고 정의역을 확인합니다. CAS가 \(\int\frac{dx}{x} = \ln x\)라고 답하는 것은 복소 로그를 쓰기 때문이고, 실수 음수 구간에서는 \(\ln|x|\)이 필요합니다.

더 근본적인 사실은 모든 초등 함수의 역도함수가 초등 함수인 것은 아니라는 것입니다. \(e^{-x^2}\), \(\frac{\sin x}{x}\), \(\sin(x^2)\), \(\frac{1}{\ln x}\)의 역도함수는 초등 함수로 쓸 수 없습니다. 이런 비초등 적분(nonelementary integral)은 너무 자주 나오기 때문에 이름을 붙여 새 함수로 정의합니다.

정의 9.10 (적분으로 정의한 함수)
$$\operatorname{erf}(x) = \frac{2}{\sqrt\pi}\int_0^x e^{-t^2}dt, \qquad \operatorname{Si}(x) = \int_0^x\frac{\sin t}{t}dt, \qquad S(x) = \int_0^x\sin(t^2)\,dt.$$
오차 함수(error function) erf는 정규분포의 누적 확률, 사인 적분 Si는 신호의 깁스 현상과 안테나 해석, 프레넬 적분 \(S\)는 빛의 회절과 도로·철도의 완화 곡선(클로소이드)에 쓰인다.
기본 정리 1부(8장)에 의해 이 함수들은 미분 가능하고 \(\operatorname{erf}'(x) = \frac{2}{\sqrt\pi}e^{-x^2}\)이다. 닫힌 꼴이 없다는 것은 값을 모른다는 뜻이 아니라, 계산하는 방법이 수치 적분이나 급수라는 뜻이다.

값을 계산하는 한 가지 방법은 피적분 함수를 거듭제곱 급수로 펼쳐 항마다 적분하는 것입니다. \(e^{-t^2} = 1 - t^2 + \frac{t^4}{2!} - \cdots\)이므로

$$\int_0^x e^{-t^2}dt = x - \frac{x^3}{3} + \frac{x^5}{5\cdot2!} - \frac{x^7}{7\cdot3!} + \cdots = \sum_{k=0}^{\infty}\frac{(-1)^k x^{2k+1}}{(2k+1)\,k!}.$$
항마다 적분해도 되는 이유와 이 급수가 모든 \(x\)에서 수렴하는 이유는 12장에서 다룬다.

핵심 정리

  1. 부분 적분 \(\int u\,dv = uv - \int v\,du\)는 곱의 법칙의 적분형이다. 미분해 단순해지는 쪽을 \(u\)로(LIATE), 여러 번이면 표 방법, 원래 적분이 돌아오면 방정식으로 푼다.
  2. \(\sin^m\cos^n\)은 홀수 지수 쪽에서 하나를 떼어 치환하고, 둘 다 짝수면 반각 공식으로 낮춘다. 서로 다른 진동수의 사인·코사인은 한 주기에서 직교한다.
  3. 삼각 치환은 \(\sqrt{a^2-x^2}, \sqrt{a^2+x^2}, \sqrt{x^2-a^2}\)를 각각 \(x = a\sin\theta, a\tan\theta, a\sec\theta\)로 바꿔 근호를 없애고, 기준 삼각형으로 \(x\)에 되돌린다.
  4. 유리 함수는 (필요하면 나눗셈 뒤) 부분 분수로 쪼갠다. 서로 다른 일차 인수의 계수는 가리기 방법 \(A_i = P(r_i)/Q'(r_i)\)로 바로 나온다.
  5. 이상 적분은 유한 적분의 극한이다. \(\int_1^\infty x^{-p}\)는 \(p > 1\)에서, \(\int_0^1 x^{-p}\)는 \(p \lt 1\)에서 수렴한다. 역도함수가 없어도 비교 판정으로 수렴을 가린다.
  6. 사다리꼴·중점 공식의 오차는 \(O(n^{-2})\), 심프슨은 \(O(n^{-4})\)이다. 오차 한계 \(\frac{K(b-a)^3}{12n^2}\), \(\frac{K_4(b-a)^5}{180n^4}\)로 필요한 \(n\)을 미리 정한다.
  7. \(e^{-x^2}\), \(\frac{\sin x}{x}\) 같은 함수의 역도함수는 초등 함수가 아니다. erf·Si 같은 새 함수로 이름을 붙이고, 값은 수치 적분이나 급수로 계산한다.

확인 퀴즈

Q1. \(\int x\cos x\,dx\)는?

\(u = x,\ dv = \cos x\,dx\)이면 \(v = \sin x\). \(x\sin x - \int\sin x\,dx = x\sin x + \cos x + C\). 미분 검산: \(\sin x + x\cos x - \sin x = x\cos x\). ✓ 첫째 보기처럼 "따로 적분해서 곱하기"는 틀린 방법이다.

Q2. \(\int_0^{2\pi}\sin 3x\,\sin 5x\,dx\)의 값은?

\(\sin3x\sin5x = \tfrac12[\cos2x - \cos8x]\)이고 각 항은 한 주기의 정수 배 구간에서 적분하면 0이다. 진동수가 다른 사인끼리는 직교한다(정리 9.3). 구간 [0, 2π]도 길이 2π인 한 주기라 같은 결과다.

Q3. \(\int\frac{dx}{x^2\sqrt{9+x^2}}\)에 알맞은 치환은?

\(\sqrt{a^2 + x^2}\) 꼴(\(a = 3\))이므로 \(x = 3\tan\theta\)로 \(\sqrt{9 + 9\tan^2\theta} = 3\sec\theta\). \(u = 9 + x^2\)는 \(du = 2x\,dx\)인데 피적분 함수에 \(x\)가 분자로 없어서 맞지 않는다.

Q4. \(\frac{1}{x^2 - 1}\)의 부분 분수 분해는?

가리기: \(x = 1\)에서 \(\frac{1}{1+1} = \tfrac12\), \(x = -1\)에서 \(\frac{1}{-1-1} = -\tfrac12\). 통분해 검산하면 \(\tfrac12\cdot\frac{(x+1) - (x-1)}{x^2-1} = \frac{1}{x^2-1}\). ✓

Q5. 다음 이상 적분 중 수렴하는 것은?

무한 구간은 \(p > 1\)에서 수렴: \(p = 1.01\)이면 값은 \(\frac{1}{0.01} = 100\). 0 근처는 \(p \lt 1\)에서만 수렴하므로 \(p = 1\)과 \(1.01\)은 발산, 무한 구간의 \(p = \tfrac12\)도 발산이다.

Q6. \(\int_{-1}^{1}\frac{dx}{x^2}\)에 대한 설명으로 옳은 것은?

\(\frac{1}{x^2}\)은 [−1, 1]에서 연속이 아니라 기본 정리를 쓸 수 없다. \(\int_0^1 x^{-2}dx\)가 (\(p = 2 \ge 1\)) 발산하므로 전체가 발산한다. 양수 함수의 적분이 음수로 나온다면 무언가 잘못된 것이다. 또 \(1/x^2\)은 짝함수다.

Q7. 매끄러운 함수를 심프슨 공식으로 적분했더니 n = 10에서 오차가 \(3.2\times10^{-5}\)이었다. n = 20이면 오차는 대략?

심프슨의 오차는 \(n^{-4}\)에 비례하므로 n을 2배로 하면 \(2^4 = 16\)분의 1: \(3.2\times10^{-5}/16 = 2\times10^{-6}\). 사다리꼴이었다면 1/4인 \(8\times10^{-6}\)이다.

Q8. 학생 셋이 \(\int\sin x\cos x\,dx\)를 각각 \(\tfrac12\sin^2x + C\), \(-\tfrac12\cos^2x + C\), \(-\tfrac14\cos2x + C\)로 풀었다. 옳은 판단은?

\(\tfrac12\sin^2x - (-\tfrac12\cos^2x) = \tfrac12\)이고 \(-\tfrac14\cos2x = -\tfrac14(1 - 2\sin^2x) = \tfrac12\sin^2x - \tfrac14\)이다. 역도함수는 상수만큼의 자유가 있으므로 미분해서 \(\sin x\cos x\)가 되면 모두 맞다.
