Chapter 10

적분의 응용

정적분의 정의를 다시 읽으면 하나의 요리법이 보입니다. 전체를 얇게 자르고, 조각 하나를 근사하고, 더하고, 극한을 취한다. 7장에서는 이 요리법으로 곡선 아래 넓이를 구했지만, 조각이 꼭 직사각형일 필요는 없습니다. 원판이면 부피, 짧은 선분이면 길이, 얇은 물층이면 퍼 올리는 일, 가는 띠면 수압, 작은 질량이면 무게 중심, 작은 확률이면 기댓값이 됩니다. 이 장은 같은 요리법을 여러 재료에 써 보며, 무엇을 \(dx\) 하나로 잘라야 계산이 쉬워지는지 고르는 감각을 기릅니다.

  • 두 곡선 사이 넓이를 \(x\)로 자를지 \(y\)로 자를지 판단해 하나의 적분으로 세운다.
  • 단면적 \(A(x)\)로 부피를 구하고, 회전체를 원판·와셔·원통 껍질 중 알맞은 방법으로 계산한다.
  • 꺾은선 근사에서 곡선의 길이 공식 \(\int\sqrt{1+f'(x)^2}\,dx\)를 유도하고, 회전면의 넓이로 넓힌다.
  • 용수철·물 퍼 올리기의 일과 수문에 걸리는 수압을 "조각마다 힘 × 거리", "조각마다 압력 × 넓이"로 세운다.
  • 막대와 판의 질량 중심(도심)을 모멘트로 구하고, 파푸스 정리로 회전체 부피를 한 줄에 얻는다.
  • 확률 밀도 함수의 넓이로 확률을, 무게 중심으로 기댓값을 읽고, 소비자 잉여를 넓이로 계산한다.
이 수식이 없었다면포도주 통의 부피

1613년, 재혼을 앞두고 포도주를 사던 케플러(Johannes Kepler)는 상인이 통의 부피를 재는 방식에 의문을 품었습니다. 상인은 통 옆구리의 구멍으로 막대를 비스듬히 꽂아 반대편 바닥 모서리까지의 젖은 길이 하나만 읽고 값을 매겼습니다. 통의 배가 불룩하든 홀쭉하든 같은 길이면 같은 값이었습니다. 케플러는 통을 수많은 얇은 원판으로 잘라 그 부피를 더하는 방법으로 여러 회전체의 부피를 구했고, 1615년 『포도주 통의 새로운 입체 기하학』(Nova Stereometria Doliorum Vinariorum)을 펴냈습니다. 미적분이 체계화되기 반세기도 전의 일입니다.

얇게 잘라 더하는 이 생각은 지금도 공학 계산의 중심에 있습니다. 탱크의 눈금표, 댐과 수문의 설계 하중, 회전하는 부품의 관성, 항공기의 무게 중심, 제품 수명의 기댓값이 모두 "조각 하나의 식"을 세우고 적분하는 일입니다. 이 장에서는 케플러의 원판을 직접 쌓아 봅니다.

두 곡선 사이의 넓이: x로 자를까, y로 자를까

설계 도면의 굽은 판

레이저로 잘라 낼 금속 판의 윤곽이 두 곡선으로 주어졌습니다. 재료비와 무게를 계산하려면 판의 넓이가 필요합니다. 7장의 정적분은 곡선과 \(x\)축 사이 넓이였는데, 위아래가 모두 곡선이면 어떻게 할까요? 그리고 윤곽이 옆으로 누운 곡선 \(x = y^2\)이라면?

요리법을 그대로 따릅니다. 영역을 세로로 얇게 자르면 폭 \(\Delta x\)인 띠 하나의 높이는 "위 곡선 − 아래 곡선"입니다. 띠를 더하고 극한을 취하면 정적분입니다. 위아래가 아니라 좌우가 곡선으로 깔끔하게 정해지는 영역이면 가로로 자르고 \(y\)로 적분합니다.

정리 10.1 (두 곡선 사이의 넓이) \([a, b]\)에서 \(f, g\)가 연속이고 \(g(x) \le f(x)\)이면 두 곡선과 직선 \(x = a, x = b\)로 둘러싸인 영역의 넓이는
$$A = \int_a^b\big[f(x) - g(x)\big]\,dx = \int_a^b(\text{위} - \text{아래})\,dx.$$
마찬가지로 \([c, d]\)에서 \(q(y) \le p(y)\)이면 \(x = q(y)\)와 \(x = p(y)\) 사이 넓이는 \(\int_c^d\big[p(y) - q(y)\big]\,dy = \int_c^d(\text{오른쪽} - \text{왼쪽})\,dy\)이다. 두 곡선이 구간 안에서 교차하면 \(\int|f - g|\)로, 즉 교점에서 나눠 각 조각에서 위아래를 다시 정한다.
예제 10.1 (x로 자르기) \(y = x + 2\)와 \(y = x^2\)으로 둘러싸인 영역의 넓이를 구하라.
  1. 교점: \(x^2 = x + 2 \Rightarrow (x-2)(x+1) = 0\), \(x = -1, 2\). 그 사이에서 \(x = 0\)을 넣어 보면 \(2 > 0\)이므로 직선이 위입니다.
  2. \(A = \int_{-1}^2(x + 2 - x^2)\,dx = \Big[\tfrac{x^2}{2} + 2x - \tfrac{x^3}{3}\Big]_{-1}^2 = \tfrac{10}{3} - \big(-\tfrac{7}{6}\big) = \tfrac{9}{2}\).
예제 10.2 (y로 자르기) \(x = y^2\)과 \(y = x - 2\)로 둘러싸인 영역의 넓이를 구하라.
  1. 교점: \(y^2 = y + 2\)에서 \(y = -1, 2\). 가로 띠의 오른쪽은 직선 \(x = y + 2\), 왼쪽은 포물선 \(x = y^2\).
  2. \(A = \int_{-1}^2(y + 2 - y^2)\,dy = \tfrac92\). 예제 10.1과 같은 적분입니다. 실제로 이 영역은 예제 10.1의 영역을 직선 \(y = x\)에 대해 뒤집은 것입니다.
  3. \(x\)로 자르면: \(\int_0^1[\sqrt x - (-\sqrt x)]\,dx + \int_1^4[\sqrt x - (x-2)]\,dx = \tfrac43 + \tfrac{19}{6} = \tfrac92\). 같은 답이지만 일이 두 배입니다.

단면으로 구하는 부피

모양이 제각각인 물체의 부피

피라미드, 돌출된 콘크리트 기초, 비행기 동체의 한 구간처럼 회전체가 아닌 물체도 많습니다. 이런 물체의 부피는 어떻게 구할까요? 어느 방향으로 잘라 보니 단면의 넓이를 식으로 쓸 수 있다면 충분합니다.

물체를 \(x\)축에 수직인 평면으로 자른 단면의 넓이를 \(A(x)\)라 합시다. 두께 \(\Delta x\)인 얇은 조각의 부피는 거의 \(A(x)\,\Delta x\)이고, 이것을 더하면 리만 합, 극한을 취하면 정적분입니다. 이것이 단면적 방법(method of slicing)입니다.

정의 10.2 (단면적으로 정의한 부피) 물체가 \(a \le x \le b\) 사이에 있고, \(x\)에서의 단면적 \(A(x)\)가 연속이면 그 부피는
$$V = \int_a^b A(x)\,dx = \lim_{n\to\infty}\sum_{i=1}^n A(x_i^*)\,\Delta x.$$

따름 정리로, 두 물체의 모든 높이의 단면적이 같으면 부피도 같다. 이것을 카발리에리 원리(Cavalieri's principle)라 한다. 동전 더미를 비스듬히 밀어도 부피가 그대로인 것과 같다.

예제 10.3 (각뿔) 밑면이 한 변 \(a\)인 정사각형이고 높이가 \(h\)인 각뿔의 부피를 구하라.
  1. 꼭짓점에서 아래로 \(x\)만큼 내려간 곳의 단면은 한 변이 \(\frac{a}{h}x\)인 정사각형입니다(닮음). \(A(x) = \frac{a^2}{h^2}x^2\).
  2. \(V = \int_0^h\frac{a^2}{h^2}x^2\,dx = \frac{a^2}{h^2}\cdot\frac{h^3}{3} = \frac13a^2h\). 기둥 부피의 1/3이라는 공식이 적분에서 나옵니다. 꼭짓점을 옆으로 밀어도(빗각뿔) 단면적이 같으므로 카발리에리 원리로 부피는 그대로입니다.
예제 10.4 (정사각형 단면을 가진 물체) 밑면이 반지름 \(r\)인 원판이고, \(x\)축에 수직인 단면이 모두 정사각형인 물체의 부피를 구하라.
  1. \(x\)에서 원판을 가로지르는 현의 길이는 \(2\sqrt{r^2 - x^2}\)이고, 이것이 정사각형의 한 변입니다. \(A(x) = 4(r^2 - x^2)\).
  2. \(V = \int_{-r}^r4(r^2 - x^2)\,dx = 4\big(2r^3 - \tfrac23r^3\big) = \tfrac{16}{3}r^3\). 같은 밑면 위의 구의 부피 \(\frac43\pi r^3 \approx 4.19r^3\)보다 큰 \(5.33r^3\)입니다.

회전체: 원판과 와셔

평면 영역을 한 직선 둘레로 돌리면 회전체가 생깁니다. 회전축에 수직으로 자르면 단면이 원이므로 \(A(x) = \pi(\text{반지름})^2\)입니다. 영역 가운데가 비어 있으면 단면은 가운데 구멍이 뚫린 원, 즉 와셔(washer)가 됩니다.

정리 10.3 (원판·와셔 방법) \(0 \le g(x) \le f(x)\)인 영역 \(a \le x \le b\)를 \(x\)축 둘레로 회전한 입체의 부피는
$$V = \pi\int_a^b\big[f(x)^2 - g(x)^2\big]\,dx = \pi\int_a^b\big(R^2 - r^2\big)\,dx.$$
\(R = f(x)\)는 바깥 반지름, \(r = g(x)\)는 안쪽 반지름. \(g = 0\)이면 원판 방법(disk method), \(g > 0\)이면 와셔 방법(washer method)이다. 회전축이 \(y = k\)이면 반지름을 축에서 잰 거리 \(|f - k|\), \(|g - k|\)로 바꾼다.
\(\pi(R - r)^2\)이 아니다 와셔의 넓이는 큰 원에서 작은 원을 뺀 \(\pi R^2 - \pi r^2\)입니다. 반지름을 먼저 빼고 제곱하는 \(\pi(R - r)^2\)은 흔한 실수이고, 예를 들어 \(R = 2, r = 1\)이면 \(3\pi\)와 \(\pi\)로 세 배 차이가 납니다.
예제 10.5 (원판과 와셔)
  1. \(y = \sqrt x\), \(0 \le x \le 4\)를 \(x\)축 둘레로: \(V = \pi\int_0^4 x\,dx = 8\pi \approx 25.13\). 이 회전체는 포물면 그릇입니다.
  2. \(y = x\)와 \(y = x^2\) 사이(\(0 \le x \le 1\))를 \(x\)축 둘레로: \([0,1]\)에서 \(x \ge x^2\)이므로 \(R = x\), \(r = x^2\). \(V = \pi\int_0^1(x^2 - x^4)\,dx = \pi\big(\tfrac13 - \tfrac15\big) = \tfrac{2\pi}{15}\).
  3. 구: \(y = \sqrt{r^2 - x^2}\)를 돌리면 \(\pi\int_{-r}^r(r^2 - x^2)\,dx = \tfrac43\pi r^3\). 고대의 결과가 한 줄로 나옵니다.

원통 껍질: 축과 나란히 자르기

역함수를 구하기 힘들 때

\(y = 2x - x^2\)과 \(x\)축 사이 영역을 \(y\)축 둘레로 돌린 그릇 모양의 부피를 구해 봅시다. 와셔로 하려면 \(y\)축에 수직으로, 즉 \(y\)로 잘라야 하고, 그러려면 \(y = 2x - x^2\)을 \(x\)에 대해 풀어 \(x = 1 \pm\sqrt{1 - y}\)라는 두 반지름을 써야 합니다. \(y = \sin x\)처럼 역함수가 마땅치 않으면 더 곤란합니다.

이번에는 회전축과 나란하게 자릅니다. \(x\)에 있는 폭 \(\Delta x\), 높이 \(f(x)\)인 세로 띠를 \(y\)축 둘레로 돌리면 얇은 원통 껍질이 됩니다. 껍질을 칼로 세로로 갈라 펼치면 거의 직육면체이고, 가로가 둘레 \(2\pi x\), 세로가 높이 \(f(x)\), 두께가 \(\Delta x\)입니다.

정리 10.4 (원통 껍질 방법) \(0 \le a \lt b\)이고 \(f \ge 0\)이 연속일 때, \(y = f(x)\) 아래 영역 \(a \le x \le b\)를 \(y\)축 둘레로 회전한 입체의 부피는
$$V = \int_a^b 2\pi x\,f(x)\,dx = \int_a^b(\text{둘레})(\text{높이})\,dx.$$

유도. 반지름 \(x_{i-1}\)과 \(x_i\) 사이 껍질의 부피는 정확히 \(\pi(x_i^2 - x_{i-1}^2)f(\bar x_i) = 2\pi\bar x_i f(\bar x_i)\Delta x\)이다(\(\bar x_i\)는 가운데 점). 이 합은 \(2\pi xf(x)\)의 리만 합이므로 극한이 위 적분이다. 회전축이 \(x = k\)이면 \(x\) 대신 축까지 거리 \(|x - k|\)를 쓴다. 이 원통 껍질 방법(shell method)이 와셔 방법과 같은 값을 준다는 것도 증명할 수 있다.

예제 10.6 (껍질로 쉽게)
  1. \(y = 2x - x^2\), \(0 \le x \le 2\)를 \(y\)축 둘레로: \(V = 2\pi\int_0^2x(2x - x^2)\,dx = 2\pi\Big[\tfrac{2x^3}{3} - \tfrac{x^4}{4}\Big]_0^2 = 2\pi\cdot\tfrac43 = \tfrac{8\pi}{3}\).
  2. 와셔로 검산: \(y\)에서 바깥 반지름 \(1 + \sqrt{1-y}\), 안쪽 \(1 - \sqrt{1-y}\). \(R^2 - r^2 = 4\sqrt{1-y}\)이므로 \(\pi\int_0^1 4\sqrt{1-y}\,dy = \tfrac{8\pi}{3}\). ✓
  3. \(y = \sin x\), \(0 \le x \le \pi\)를 \(y\)축 둘레로: \(V = 2\pi\int_0^\pi x\sin x\,dx\). 부분 적분(9장)으로 \(\int_0^\pi x\sin x\,dx = [-x\cos x + \sin x]_0^\pi = \pi\), 따라서 \(V = 2\pi^2 \approx 19.74\). 와셔로는 arcsin이 필요한 문제입니다.

어느 방법을 고를까 회전축에 수직인 조각(와셔)은 축 방향 변수로, 나란한 조각(껍질)은 축에 수직인 변수로 적분합니다. 경계가 \(y = f(x)\)로 주어졌는데 \(y\)축 둘레로 돌린다면 보통 껍질이, \(x\)축 둘레라면 보통 와셔가 편합니다. 둘 다 세울 수 있으면 하나로 풀고 다른 하나로 검산하세요.

곡선의 길이

전선은 얼마나 필요한가

두 철탑 사이에 처진 송전선은 현수선 \(y = a\cosh(x/a)\)의 모양입니다. 철탑 사이 거리는 알지만, 처진 전선의 실제 길이는 그보다 깁니다. 자를 대고 잴 수 없는 곡선의 길이를 어떻게 계산할까요?

곡선 위에 점 \(n + 1\)개를 찍고 꺾은선으로 이으면, 선분 하나의 길이는 피타고라스 정리로 \(\sqrt{\Delta x^2 + \Delta y^2}\)입니다. 평균값 정리로 \(\Delta y = f'(x_i^*)\Delta x\)인 \(x_i^*\)가 조각마다 있으므로 선분 길이는 \(\sqrt{1 + f'(x_i^*)^2}\,\Delta x\)이고, 꺾은선 길이는 리만 합이 됩니다.

정리 10.5 (곡선의 길이) \(f'\)이 \([a, b]\)에서 연속이면 곡선 \(y = f(x)\)의 곡선의 길이(arc length)는
$$L = \int_a^b\sqrt{1 + f'(x)^2}\,dx = \int_a^b\sqrt{1 + \Big(\frac{dy}{dx}\Big)^2}\,dx.$$
기억하는 방법: \(ds = \sqrt{dx^2 + dy^2}\). 매개 곡선 \((x(t), y(t))\)이면 \(L = \int\sqrt{x'(t)^2 + y'(t)^2}\,dt\).

증명 아이디어. 위의 꺾은선 길이 \(\sum\sqrt{1 + f'(x_i^*)^2}\Delta x\)는 연속 함수 \(\sqrt{1 + f'^2}\)의 리만 합이므로, 분할을 잘게 하면 적분으로 수렴한다. 곡선의 길이를 "꺾은선 길이의 상한"으로 정의하면 이 극한이 그 값이다. ∎

예제 10.7 (닫힌 꼴이 나오는 경우)
  1. \(y = \tfrac23x^{3/2}\), \(0 \le x \le 3\): \(f' = \sqrt x\)이므로 \(\sqrt{1 + f'^2} = \sqrt{1+x}\). \(L = \Big[\tfrac23(1+x)^{3/2}\Big]_0^3 = \tfrac23(8 - 1) = \tfrac{14}{3} \approx 4.667\).
  2. 현수선 \(y = \cosh x\), \(-1 \le x \le 1\): \(1 + \sinh^2x = \cosh^2x\)이므로 \(L = \int_{-1}^1\cosh x\,dx = 2\sinh 1 \approx 2.350\). 같은 구간의 직선 거리 2보다 약 17.5% 깁니다.
  3. \(y = x^2\), \(0 \le x \le 2\): \(L = \int_0^2\sqrt{1 + 4x^2}\,dx\). 삼각 치환 \(2x = \tan\theta\)(9장)으로 \(\sqrt{17} + \tfrac14\ln(4 + \sqrt{17}) \approx 4.647\).

그러나 대부분의 곡선은 근호 때문에 닫힌 꼴이 나오지 않습니다. \(y = \sin x\)의 한 아치 길이 \(\int_0^\pi\sqrt{1 + \cos^2x}\,dx\)는 타원 적분이라 초등 함수로 쓸 수 없고, 수치 적분으로 약 3.820입니다. 실무에서 곡선 길이는 대개 꺾은선이나 심프슨 공식(9장)으로 계산합니다.

회전면의 넓이

곡선 \(y = f(x) \ge 0\)을 \(x\)축 둘레로 돌리면 곡면이 생기고, 그 넓이를 회전면의 넓이(surface area of revolution)라 합니다. 곡선의 짧은 조각 \(ds\)를 돌리면 반지름 \(f(x)\), 폭 \(ds\)인 띠가 되고, 그 넓이는 둘레 × 폭 \(= 2\pi f(x)\,ds\)입니다(정확히는 원뿔대 옆넓이 \(2\pi\bar r\,\ell\)).

정리 10.6 (회전면의 넓이) \(f \ge 0\)이고 \(f'\)이 연속이면 \(y = f(x)\), \(a \le x \le b\)를 \(x\)축 둘레로 돌린 곡면의 넓이는
$$S = \int_a^b 2\pi f(x)\sqrt{1 + f'(x)^2}\,dx = \int 2\pi\,(\text{반지름})\,ds.$$

흔한 실수는 \(ds\) 대신 \(dx\)를 쓰는 것이다. 그러면 곡면이 아니라 그 그림자 원기둥의 넓이를 구하게 된다.

예제 10.8 (구의 띠와 가브리엘의 뿔)
  1. 구 \(f = \sqrt{r^2 - x^2}\): \(f' = -x/f\)이므로 \(f\sqrt{1 + f'^2} = \sqrt{f^2 + x^2} = r\). 따라서 \(x = c\)와 \(x = d\) 사이 띠의 넓이는 \(2\pi r(d - c)\)로 높이에만 비례합니다. 전체 구는 \(2\pi r\cdot 2r = 4\pi r^2\). 아르키메데스가 알았던 "구와 외접 원기둥의 옆넓이가 같다"는 결과입니다.
  2. \(y = 1/x\), \(x \ge 1\)을 돌린 나팔: 부피는 \(\pi\int_1^\infty\frac{dx}{x^2} = \pi\)로 유한한데, 겉넓이는 \(2\pi\int_1^\infty\frac1x\sqrt{1 + \frac{1}{x^4}}\,dx \ge 2\pi\int_1^\infty\frac{dx}{x} = \infty\)입니다(9장 이상 적분의 비교 판정). 페인트 π만큼이면 안을 가득 채울 수 있는데, 겉을 칠하기에는 아무리 많아도 모자란다는 역설로 유명합니다. 수학적 넓이와 실제 페인트 두께를 섞어 생각해서 생기는 역설입니다.

일과 유체 압력

물탱크를 비우는 펌프

지하 물탱크를 비울 펌프를 고르려면 필요한 에너지를 알아야 합니다. 물 전체를 한 덩어리로 들어 올리는 것이 아니라, 바닥의 물은 멀리, 위의 물은 조금만 올리면 됩니다. 거리가 물의 높이마다 다를 때 "일 = 힘 × 거리"를 어떻게 쓸까요?

힘이 일정하면 일은 \(W = Fd\)입니다. 힘이 위치에 따라 변하면 짧은 구간 \(\Delta x\)에서는 힘을 일정하다고 보고 \(F(x)\Delta x\)를 더합니다.

정의 10.7 (변하는 힘이 하는 일) 직선 위에서 위치 \(x\)에 따라 연속인 힘 \(F(x)\)가 물체를 \(a\)에서 \(b\)로 옮길 때 하는 일(work)은
$$W = \int_a^b F(x)\,dx \quad[\mathrm{J} = \mathrm{N\cdot m}].$$
거리가 조각마다 다른 경우(물 퍼 올리기)에는 반대로 물체를 조각으로 자른다. 높이 \(y\)의 얇은 층의 무게 \(\rho g A(y)\Delta y\)에 그 층이 올라갈 거리 \(D(y)\)를 곱해 더하면 \(W = \int\rho g\,A(y)\,D(y)\,dy\).
예제 10.9 (용수철) 용수철을 자연 길이에서 0.05 m 늘이는 데 10 N이 든다. 0.05 m 늘어난 상태에서 0.15 m 늘어난 상태까지 늘이는 일은?
  1. 훅의 법칙(Hooke's law) \(F = kx\)에서 \(10 = k(0.05)\), \(k = 200\ \mathrm{N/m}\).
  2. \(W = \int_{0.05}^{0.15}200x\,dx = 100\big(0.15^2 - 0.05^2\big) = 100(0.0225 - 0.0025) = 2\ \mathrm{J}\). 처음 0.05 m를 늘이는 일은 0.25 J에 불과한데, 같은 힘의 증가가 뒤쪽에서는 더 긴 거리에 걸치기 때문입니다.
예제 10.10 (원뿔 탱크 퍼 올리기) 그림 10-3의 탱크에 물(\(\rho = 1000\ \mathrm{kg/m^3}\))이 가득 차 있다. 물을 모두 탱크 꼭대기로 퍼 올리는 일은? (\(g = 9.8\ \mathrm{m/s^2}\))
  1. 높이 \(y\)의 반지름은 닮음으로 \(y/2\), 단면적 \(A(y) = \pi y^2/4\), 거리 \(4 - y\).
  2. \(W = \int_0^4\rho g\,\frac{\pi y^2}{4}(4 - y)\,dy = \frac{\rho g\pi}{4}\Big[\frac{4y^3}{3} - \frac{y^4}{4}\Big]_0^4 = \frac{\rho g\pi}{4}\cdot\frac{64}{3} = \frac{16\pi}{3}\rho g\).
  3. 수치: \(\frac{16\pi}{3}\times 9800 \approx 1.642\times10^5\ \mathrm{J}\), 약 164 kJ. 물의 질량은 \(\rho\cdot\frac13\pi(2^2)(4) \approx 16{,}755\ \mathrm{kg}\)이므로 평균으로 \(W/(mg) \approx 1.0\ \mathrm{m}\)씩 올린 셈입니다. 원뿔의 무게 중심이 꼭짓점에서 높이의 3/4, 즉 꼭대기 1 m 아래에 있기 때문입니다(8절).

정리 10.8 (수직 판에 걸리는 유체의 힘) 밀도 \(\rho\)인 액체 속에 수직으로 잠긴 판이 깊이 \(h = c\)에서 \(h = d\)까지 있고, 깊이 \(h\)에서 판의 폭이 \(w(h)\)이면 판 한쪽에 걸리는 힘은

\(A\)는 판의 넓이, \(\bar h\)는 판의 도심(8절)의 깊이. 즉 힘은 "도심 깊이의 압력 × 넓이"와 같다.
예제 10.11 (수문) 폭 3 m, 높이 2 m인 직사각형 수문의 윗변이 수면에 있다. 수문에 걸리는 힘은?

질량 중심과 파푸스 정리

어디를 받치면 균형이 맞을까

항공기는 화물과 연료를 실을 때마다 무게 중심을 다시 계산해 허용 범위 안에 있는지 확인합니다. 크레인이 비대칭 부재를 들어 올릴 때도 고리를 무게 중심 바로 위에 걸어야 부재가 기울지 않습니다. 질량이 연속적으로 퍼져 있을 때 그 "평균 위치"는 어떻게 구할까요?

시소를 생각합시다. 질량 \(m_i\)가 위치 \(x_i\)에 있으면 받침점 \(\bar x\)에 대한 돌림힘의 합 \(\sum m_i(x_i - \bar x)\)가 0일 때 균형이 맞으므로 \(\bar x = \frac{\sum m_ix_i}{\sum m_i}\)입니다. 분자 \(\sum m_ix_i\)를 원점에 대한 모멘트(moment)라 합니다. 질량이 연속으로 퍼져 있으면 합이 적분이 됩니다.

정의 10.9 (질량 중심) 선밀도 \(\rho(x)\)인 막대 \([a, b]\)의 질량 중심(center of mass)은
$$\bar x = \frac{M_0}{m} = \frac{\int_a^b x\,\rho(x)\,dx}{\int_a^b\rho(x)\,dx}.$$
밀도가 고른 판(라미나)의 질량 중심은 밀도와 무관한 순수한 기하학적 점이며 도심(centroid)이라 부른다.
정리 10.10 (판의 도심) \(g \le f\)인 영역 \(a \le x \le b\)의 넓이가 \(A = \int_a^b(f - g)\,dx\)이면
$$\bar x = \frac1A\int_a^b x\,\big[f(x) - g(x)\big]\,dx, \qquad \bar y = \frac1A\int_a^b\frac12\big[f(x)^2 - g(x)^2\big]\,dx.$$

유도. 폭 \(\Delta x\)인 세로 띠의 질량은 \(\rho(f - g)\Delta x\)이고, 그 띠의 질량 중심은 \(x\), 높이로는 띠의 가운데 \(\frac{f+g}{2}\)에 있다. 그래서 \(y\)축 방향 모멘트에는 \(\frac{f+g}{2}(f - g) = \frac12(f^2 - g^2)\)이 들어간다. 밀도 \(\rho\)는 분자·분모에서 약분된다. ∎

예제 10.12 (도심 계산)
  1. \(y = x^2\) 아래, \(0 \le x \le 1\): \(A = \tfrac13\). \(\bar x = 3\int_0^1x^3\,dx = \tfrac34\), \(\bar y = 3\int_0^1\tfrac12x^4\,dx = \tfrac{3}{10}\). 도심 \((0.75, 0.3)\)은 판의 오른쪽 아래, 질량이 많은 쪽에 있습니다.
  2. 반지름 \(r\)인 반원판 \(y = \sqrt{r^2 - x^2}\): 대칭으로 \(\bar x = 0\). \(\bar y = \frac{2}{\pi r^2}\int_{-r}^r\tfrac12(r^2 - x^2)\,dx = \frac{2}{\pi r^2}\cdot\frac{2r^3}{3} = \frac{4r}{3\pi} \approx 0.424r\).

도심을 알면 회전체의 부피가 한 줄로 나옵니다. 영역을 축 둘레로 돌리면 영역의 모든 점이 원을 그리는데, 평균적으로는 도심이 그리는 원의 둘레만큼 움직입니다.

정리 10.11 (파푸스 정리) 평면 영역을 그 영역과 만나지 않는 같은 평면 위의 직선 둘레로 돌려 만든 입체의 부피는
$$V = 2\pi\,d\,A$$
\(A\)는 영역의 넓이, \(d\)는 도심에서 회전축까지의 거리. 즉 "넓이 × 도심이 움직인 거리".

증명. 축을 \(y\)축으로 놓고 영역이 \(x \ge 0\)에 있다고 하면, 껍질 방법으로 \(V = \int 2\pi x(f - g)\,dx = 2\pi\cdot A\bar x\)이다(정리 10.10의 \(\bar x\) 정의). ∎ 이 파푸스 정리(Pappus's centroid theorem)는 4세기 알렉산드리아의 파푸스가 남긴 책에 실려 있다.

예제 10.13 (토러스) 반지름 \(r\)인 원판을, 중심에서 \(R\) (\(R > r\)) 떨어진 축 둘레로 돌린 도넛 모양(토러스)의 부피는 \(V = 2\pi R\cdot\pi r^2 = 2\pi^2Rr^2\)입니다. \(R = 3\), \(r = 1\)이면 \(6\pi^2 \approx 59.22\). 반원판(\(\bar y = 4r/3\pi\))을 지름 둘레로 돌리면 \(2\pi\cdot\frac{4r}{3\pi}\cdot\frac{\pi r^2}{2} = \frac43\pi r^3\), 구의 부피가 다시 나옵니다.

확률 밀도, 기댓값, 그리고 경제

부품의 수명을 넓이로 읽기

어떤 LED 드라이버의 수명은 평균 1000시간인 지수분포를 따른다고 합니다. 2000시간 넘게 버틸 확률은? 시간은 연속이라 "정확히 1500.000…시간에 고장 날 확률"은 0입니다. 확률을 점이 아니라 구간에, 곡선 아래 넓이로 주어야 합니다.

정의 10.12 (확률 밀도 함수와 기댓값) \(f(x) \ge 0\)이고 \(\int_{-\infty}^\infty f(x)\,dx = 1\)인 함수 \(f\)를 연속 확률 변수 \(X\)의 확률 밀도 함수(probability density function, PDF)라 하고
$$P(a \le X \le b) = \int_a^b f(x)\,dx, \qquad E[X] = \mu = \int_{-\infty}^\infty x\,f(x)\,dx, \qquad \operatorname{Var}X = \int_{-\infty}^\infty(x - \mu)^2f(x)\,dx.$$

기댓값(expected value)의 식은 정의 10.9의 질량 중심과 똑같다. 전체 "질량"이 1이니 분모가 없을 뿐이다. 즉 기댓값은 밀도 곡선 아래 영역을 막대로 보았을 때의 균형점이고, 분산은 관성 모멘트에 해당한다.

예제 10.14 (지수분포 수명) 평균 수명 \(m = 1000\) h인 지수분포 \(f(t) = \frac1m e^{-t/m}\) (\(t \ge 0\)).
  1. 정규화: \(\int_0^\infty\frac1me^{-t/m}dt = 1\). ✓ (9장 이상 적분)
  2. \(P(T > 2000) = \int_{2000}^\infty\frac1me^{-t/m}dt = e^{-2} \approx 0.135\). 평균보다 오래 버틸 확률은 \(e^{-1} \approx 0.368\)로, 절반보다 작습니다.
  3. 기댓값: 부분 적분으로 \(\int_0^\infty t\cdot\frac1me^{-t/m}dt = m\). 중앙값은 \(P(T \le t) = \tfrac12\)에서 \(m\ln2 \approx 693\) h. 오른쪽으로 긴 꼬리가 균형점을 중앙값보다 오른쪽으로 끌어당깁니다.

같은 계산이 경제와 교통에서도 나옵니다. 수요 곡선 \(p = D(q)\)는 \(q\)번째 단위에 소비자가 낼 용의가 있는 최고 가격입니다. 시장 가격 \(P\)에 \(Q\)개가 팔리면, 소비자가 "낼 용의가 있던 금액"과 "실제 낸 금액"의 차이의 합이 소비자 잉여(consumer surplus)입니다.

$$\text{CS} = \int_0^Q\big[D(q) - P\big]\,dq.$$
예제 10.15 (소비자 잉여) 수요 \(D(q) = 100 - 0.5q\) (원)이고 시장 가격이 40원이면 \(100 - 0.5Q = 40\)에서 \(Q = 120\). \(\text{CS} = \int_0^{120}(60 - 0.5q)\,dq = 60\cdot120 - 0.25\cdot120^2 = 7200 - 3600 = 3600\)원. 수요 곡선, 가격선, 세로축이 만드는 삼각형 넓이 \(\tfrac12\cdot120\cdot60\)과 같습니다.
교통량도 넓이다 교차로를 지나는 차량의 흐름률 \(q(t)\) (대/분)이 시간마다 바뀌면, 출근 시간 한 시간 동안 지나간 차량 수는 \(\int q(t)\,dt\)입니다. 8장의 순변화량 정리가 그대로 쓰이고, 들어오는 흐름과 나가는 흐름의 적분 차이가 대기 행렬의 길이가 됩니다.

핵심 정리

  1. 모든 응용의 공통 구조: 얇은 조각 하나의 양 ≈ (그 조각에서의 값) × \(\Delta x\), 더하고 극한을 취하면 정적분이다.
  2. 두 곡선 사이 넓이는 \(\int(\text{위} - \text{아래})dx\) 또는 \(\int(\text{오른쪽} - \text{왼쪽})dy\). 경계 식이 한 가지로 유지되는 방향으로 자른다.
  3. 부피 \(V = \int A(x)dx\). 회전체는 와셔 \(\pi\int(R^2 - r^2)dx\)(축에 수직) 또는 껍질 \(2\pi\int(\text{반지름})(\text{높이})dx\)(축과 나란히).
  4. 곡선 길이 \(L = \int\sqrt{1 + f'^2}dx\), 회전면 넓이 \(S = 2\pi\int f\sqrt{1 + f'^2}dx\). 대부분 닫힌 꼴이 없어 수치로 계산한다.
  5. 일 \(W = \int F\,dx\). 거리가 조각마다 다르면 물체를 층으로 잘라 \(\int\rho gA(y)D(y)dy\). 수직 판의 수압 \(F = \int\rho ghw(h)dh = \rho g\bar hA\).
  6. 질량 중심 \(\bar x = \int x\,dm/\int dm\). 고른 판의 도심은 \(\bar x = \frac1A\int x(f-g)dx\), \(\bar y = \frac1A\int\frac12(f^2 - g^2)dx\). 파푸스: \(V = 2\pi dA\).
  7. 확률 밀도의 넓이가 확률, 균형점이 기댓값이다. 소비자 잉여는 수요 곡선과 가격선 사이 넓이다.

확인 퀴즈

Q1. \(y = x\)와 \(y = x^2\)으로 둘러싸인 영역의 넓이는?

교점 x = 0, 1, 그 사이에서 x ≥ x². \(\int_0^1(x - x^2)dx = \tfrac12 - \tfrac13 = \tfrac16\). 2π/15는 같은 영역을 x축 둘레로 돌린 와셔 부피다.

Q2. \(y = \sqrt x\), \(0 \le x \le 4\)를 \(x\)축 둘레로 돌린 입체의 부피는?

원판 방법: \(\pi\int_0^4(\sqrt x)^2dx = \pi\int_0^4x\,dx = \pi\cdot8\). 반지름이 \(\sqrt x\)이므로 넓이 \(\pi x\)로 제곱을 먼저 하는 것을 잊지 말 것.

Q3. \(y = f(x) \ge 0\), \(1 \le x \le 3\) 아래 영역을 직선 \(x = -1\) 둘레로 돌린 부피를 껍질로 쓰면?

껍질의 반지름은 회전축까지의 거리다. 축 x = −1에서 x까지의 거리는 x − (−1) = x + 1. 마지막 보기는 x축 둘레 원판 부피다.

Q4. 곡선 \(y = \tfrac23x^{3/2}\)의 \(0 \le x \le 3\) 부분의 길이는?

\(f' = \sqrt x\), \(\sqrt{1 + x}\)를 적분하면 \(\tfrac23[(1+x)^{3/2}]_0^3 = \tfrac23(8 - 1) = \tfrac{14}{3} \approx 4.67\). 양 끝을 잇는 선분 길이 \(\sqrt{9 + 12} = \sqrt{21} \approx 4.58\)보다 약간 길어야 맞다.

Q5. 용수철 상수 200 N/m인 용수철을 자연 길이에서 0.1 m 늘이는 일은?

\(\int_0^{0.1}200x\,dx = 100(0.1)^2 = 1\) J. 최대 힘 20 N에 거리 0.1 m를 곱한 2 J은 힘이 처음부터 20 N이라고 본 과대 추정이고, 실제 일은 그 절반(삼각형 넓이)이다.

Q6. 수직 수문을 그대로 두고 수위만 올려서, 수문 도심의 깊이가 2 m에서 6 m가 되었다. 수문에 걸리는 힘은?

\(F = \rho g\bar hA\)이고 넓이 A는 그대로이므로 힘은 도심 깊이에 비례해 3배가 된다. 압력이 깊이에 비례(1차)하므로 제곱이 아니다.

Q7. 반지름 1인 원판을, 원의 중심에서 3만큼 떨어진 축 둘레로 돌린 토러스의 부피는?

파푸스 정리: 넓이 \(\pi\cdot1^2\) × 도심이 움직인 거리 \(2\pi\cdot3\) = \(6\pi^2 \approx 59.2\).

Q8. 평균 수명 1000시간인 지수분포를 따르는 부품이 1000시간 넘게 버틸 확률은?

\(\int_{1000}^\infty\tfrac{1}{1000}e^{-t/1000}dt = e^{-1} \approx 0.368\). 평균이 중앙값(693 h)보다 오른쪽에 있기 때문에 평균보다 오래 버틸 확률은 절반보다 작다. 0.135는 2000시간을 넘길 확률이다.
