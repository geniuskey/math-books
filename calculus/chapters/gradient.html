Chapter 14

기울기 벡터와 최적화

13장의 편도함수는 동쪽과 북쪽, 두 방향의 기울기만 알려 주었습니다. 그런데 산에서 길을 잃은 등산객이 묻는 것은 "어느 쪽이 가장 가파른가", "어느 쪽으로 가면 높이가 그대로인가"입니다. 놀랍게도 편도함수 두 개를 벡터로 묶기만 하면 모든 방향의 기울기가 내적 하나로 나옵니다. 이 벡터가 그래디언트입니다. 그래디언트는 가장 가파른 오르막을 가리키고, 등고선에 수직이며, 그 길이가 최대 기울기입니다. 이 장은 그래디언트로 곡면의 꼭대기·바닥·고개를 찾고 분류하며, 제약이 있는 최적화(라그랑주 승수)와 컴퓨터가 수백만 변수의 함수를 최소화하는 방법(경사 하강법)까지 갑니다.

  • 방향 도함수를 정의하고, \(D_{\mathbf{u}}f = \nabla f\cdot\mathbf{u}\)로 계산한다.
  • 그래디언트가 가장 가파른 오르막 방향이고 등고선(등위면)에 수직임을 증명하고, 등위면의 접평면을 구한다.
  • 임계점을 찾고, 헤세 행렬과 판별식 \(D = f_{xx}f_{yy} - f_{xy}^2\)으로 극소·극대·안장점을 분류한다.
  • 닫힌 유계 영역에서 내부 임계점과 경계를 모두 조사해 최댓값·최솟값을 구한다.
  • 라그랑주 승수법으로 제약 조건이 있는 최적화를 풀고, 승수를 "그림자 가격"으로 해석한다.
  • 경사 하강법의 학습률이 수렴과 발산을 가르는 조건을 이차 함수에서 유도하고, 최소제곱 회귀를 편도함수로 유도한다.
이 수식이 없었다면스스로 배우는 신경망

음성 인식, 번역, 이미지 분류 모델은 수백만~수천억 개의 가중치를 가진 함수입니다. "학습"이란 훈련 데이터에 대한 오차 \(E(w_1, \dots, w_n)\)를 가장 작게 만드는 가중치를 찾는 일이고, 변수가 이렇게 많으면 모든 조합을 시험하거나 \(\nabla E = \mathbf{0}\)을 손으로 푸는 것은 불가능합니다.

그 대신 쓰는 방법은 1847년 코시가 연립 방정식을 풀기 위해 제안한 아이디어와 같습니다. 지금 서 있는 곳에서 그래디언트를 계산해 가장 가파른 내리막 방향으로 조금 걷고, 이를 반복합니다. 오차 역전파는 그래디언트를 연쇄 법칙(13장)으로 효율적으로 계산하는 방법일 뿐이고, 실제로 가중치를 움직이는 것은 이 장의 경사 하강법입니다.

오차 함수 E(w₁, …, wₙ)→변수 수백만 개→그래디언트 ∇E와 경사 하강→학습된 모델

방향 도함수: 아무 방향의 기울기

북동쪽으로 걸으면 얼마나 오르나

지형 \(z = f(x, y)\)에서 \(f_x\)는 동쪽, \(f_y\)는 북쪽으로 걸을 때의 기울기입니다. 등산로가 북동쪽으로 나 있다면 그 길의 경사는 얼마일까요? 방향마다 새로 극한을 계산해야 할까요?

정의 14.1 (방향 도함수) 단위 벡터 \(\mathbf{u} = (u_1, u_2)\) (\(|\mathbf{u}| = 1\)) 방향으로의 \(f\)의 방향 도함수(directional derivative)는
$$D_{\mathbf{u}}f(a, b) = \lim_{h \to 0}\frac{f(a + hu_1,\, b + hu_2) - f(a, b)}{h}$$
이다. \(\mathbf{u} = (1, 0)\)이면 \(f_x\), \(\mathbf{u} = (0, 1)\)이면 \(f_y\)가 된다. 단위 벡터를 쓰는 이유는 \(h\)가 실제로 걸은 거리가 되게 하기 위해서다.
정리 14.2 (방향 도함수 = 그래디언트와의 내적) \(f\)가 \((a, b)\)에서 미분 가능하면
$$D_{\mathbf{u}}f(a, b) = f_x(a, b)\,u_1 + f_y(a, b)\,u_2 = \nabla f(a, b)\cdot\mathbf{u}, \qquad \nabla f = (f_x,\, f_y).$$
벡터 \(\nabla f\)("델 에프", "그래드 에프")를 \(f\)의 그래디언트(gradient)라 한다. 변수가 \(n\)개이면 \(\nabla f = (\partial f/\partial x_1, \dots, \partial f/\partial x_n)\).

증명. \(g(h) = f(a + hu_1, b + hu_2)\)라 하면 \(D_{\mathbf{u}}f = g'(0)\)이다. 경로 \(x = a + hu_1\), \(y = b + hu_2\)에 대해 연쇄 법칙(정리 13.11)을 쓰면 \(g'(0) = f_x\cdot u_1 + f_y\cdot u_2\). ∎

미분 가능성이 중요합니다. 13장의 \(xy/(x^2 + y^2)\)처럼 편도함수만 있는 함수에서는 이 공식이 틀린 답을 줍니다. 미분 가능하면 두 숫자 \(f_x, f_y\)가 무한히 많은 방향의 기울기를 모두 결정합니다. 곡면이 그 점 근처에서 평면이기 때문입니다.

예제 14.1 (방향 도함수 계산) \(f(x, y) = x^2y + y^3\)의 점 \((1, 2)\)에서 벡터 \(\mathbf{v} = (3, 4)\) 방향의 방향 도함수를 구하라.
  1. 단위 벡터로: \(|\mathbf{v}| = 5\)이므로 \(\mathbf{u} = (3/5, 4/5)\). 이 단계를 빼먹으면 답이 5배가 된다.
  2. 그래디언트: \(f_x = 2xy = 4\), \(f_y = x^2 + 3y^2 = 13\), \(\nabla f(1, 2) = (4, 13)\).
  3. 내적: \(D_{\mathbf{u}}f = 4\cdot\tfrac35 + 13\cdot\tfrac45 = \tfrac{12 + 52}{5} = 12.8\).
  4. 비교: 같은 점에서 가장 큰 방향 도함수는 \(|\nabla f| = \sqrt{16 + 169} = \sqrt{185} \approx 13.60\) (다음 절). \(\mathbf{u}\)가 \(\nabla f\)와 이루는 각이 작아(약 19.8°) 최댓값에 가깝다.

그래디언트: 가장 가파른 방향, 등고선에 수직

정리 14.2의 내적을 각도로 쓰면 그래디언트의 세 가지 성질이 한꺼번에 나옵니다. \(\theta\)를 \(\nabla f\)와 \(\mathbf{u}\) 사이의 각이라 하면

$$D_{\mathbf{u}}f = \nabla f\cdot\mathbf{u} = |\nabla f|\,|\mathbf{u}|\cos\theta = |\nabla f|\cos\theta.$$
정리 14.3 (최대 증가 방향) \(f\)가 미분 가능하고 \(\nabla f(\mathbf{a}) \ne \mathbf{0}\)이면
  1. \(D_{\mathbf{u}}f\)의 최댓값은 \(|\nabla f|\)이고, \(\mathbf{u} = \nabla f/|\nabla f|\)일 때(\(\theta = 0\)) 얻는다. 이것이 가장 가파른 오르막 방향(direction of steepest ascent)이다.
  2. 최솟값은 \(-|\nabla f|\)이고, \(\mathbf{u} = -\nabla f/|\nabla f|\)에서 얻는다(가장 가파른 내리막).
  3. \(\mathbf{u} \perp \nabla f\)(\(\theta = 90°\))이면 \(D_{\mathbf{u}}f = 0\). 이 방향으로는 높이가 순간적으로 변하지 않는다.

증명. \(-1 \le \cos\theta \le 1\)이고 등호는 각각 \(\theta = \pi\), \(\theta = 0\)에서만 성립한다(코시–슈바르츠 부등식). ∎

정리 14.4 (그래디언트는 등위선에 수직) \(f\)가 미분 가능하고 \(\mathbf{r}(t)\)가 등위선 \(f(x, y) = k\) 위의 미분 가능한 곡선이면, 그 곡선의 접선 벡터 \(\mathbf{r}'(t)\)는 \(\nabla f(\mathbf{r}(t))\)와 수직이다.

증명. 곡선 위에서 \(f(\mathbf{r}(t)) = k\)이므로 양변을 \(t\)로 미분하면 연쇄 법칙으로 \(\nabla f\cdot\mathbf{r}'(t) = 0\). ∎

예제 14.2 (등산객의 선택) 산의 높이가 \(z = 1000 - 0.005x^2 - 0.01y^2\) (m, x는 동쪽, y는 북쪽, 단위 m)이다. 등산객이 \((60, 40)\)에 있다.
  1. 높이 \(z = 1000 - 18 - 16 = 966\) m. 그래디언트 \(\nabla z = (-0.01x, -0.02y) = (-0.6, -0.8)\), \(|\nabla z| = 1\).
  2. 가장 가파른 오르막은 \((-0.6, -0.8)\) 방향이고, 그 기울기는 1 (45°). 정상 \((0, 0)\)을 곧장 향하는 방향 \((-60, -40)/\sqrt{5200} \approx (-0.83, -0.55)\)와 다르다. 타원형 산에서는 가장 가파른 길이 정상을 똑바로 가리키지 않는다.
  3. 동쪽 \((1, 0)\)으로 걸으면 \(D_{\mathbf{u}}z = -0.6\): 1 m 걸을 때 0.6 m 내려간다(경사각 \(\arctan 0.6 \approx 31°\)).
  4. 높이를 유지하려면 \(\nabla z\)에 수직인 \(\pm(0.8, -0.6)\) 방향, 즉 등고선을 따라 걷는다.

등위면의 접평면

정리 14.4는 변수가 셋이어도 그대로입니다. \(F(x, y, z) = k\)인 등위면 위의 모든 곡선에 대해 \(\nabla F\cdot\mathbf{r}'(t) = 0\)이므로, 그래디언트는 등위면 위 모든 접선 방향과 수직입니다. 즉 \(\nabla F\)가 곡면의 법선 벡터(normal vector)이고, 이것으로 접평면을 바로 쓸 수 있습니다.

정리 14.5 (등위면의 접평면) \(F\)가 미분 가능하고 등위면 \(F(x, y, z) = k\) 위의 점 \(P_0 = (x_0, y_0, z_0)\)에서 \(\nabla F(P_0) \ne \mathbf{0}\)이면 \(P_0\)에서의 접평면은
$$F_x(P_0)(x - x_0) + F_y(P_0)(y - y_0) + F_z(P_0)(z - z_0) = 0,$$
법선은 \(\mathbf{r}(t) = P_0 + t\,\nabla F(P_0)\)이다. 그래프 \(z = f(x, y)\)는 \(F = f(x, y) - z = 0\)인 등위면이므로 \(\nabla F = (f_x, f_y, -1)\)이고, 이것은 13장의 접평면 공식과 같다.
예제 14.3 (타원체의 접평면) 타원체 \(\dfrac{x^2}{4} + y^2 + \dfrac{z^2}{9} = 3\) 위의 점 \((-2, 1, -3)\)에서 접평면과 법선을 구하라.
  1. 점 확인: \(4/4 + 1 + 9/9 = 3\). ✓
  2. \(\nabla F = (x/2,\; 2y,\; 2z/9) = (-1,\; 2,\; -2/3)\).
  3. 접평면: \(-(x + 2) + 2(y - 1) - \tfrac23(z + 3) = 0\). 양변에 \(-3\)을 곱해 정리하면 \(3x - 6y + 2z + 18 = 0\). 점을 넣으면 \(-6 - 6 - 6 + 18 = 0\). ✓
  4. 법선: \((x, y, z) = (-2, 1, -3) + t(-1, 2, -\tfrac23)\). 이 방향은 원점에서 점으로 가는 방향 \((-2, 1, -3)\)과 평행하지 않다. 구가 아니면 법선은 중심을 지나지 않는다.

극값과 안장점: 헤세 행렬로 분류하기

평평한 곳이 다 바닥은 아니다

공정 수율 \(Y(T, p)\)를 온도와 압력의 함수로 모델링했습니다. 수율이 최대인 조건을 찾으려면 어디를 봐야 할까요? 일변수처럼 기울기가 0인 곳을 찾으면 되지만, 2차원에는 꼭대기와 바닥 말고 고개(한 방향으로는 꼭대기, 다른 방향으로는 바닥)라는 세 번째 종류가 있습니다.

정의 14.6 (극값과 임계점) \((a, b)\) 근처의 모든 점에서 \(f(x, y) \le f(a, b)\)이면 \(f(a, b)\)는 극댓값, \(\ge\)이면 극솟값이다. \(\nabla f(a, b) = \mathbf{0}\)이거나 편도함수가 없는 점을 임계점이라 하고, 임계점인데 극값이 아닌 점, 즉 어느 방향으로는 올라가고 어느 방향으로는 내려가는 점을 안장점(saddle point)이라 한다.
정리 14.7 (페르마 정리의 다변수 판) \(f\)가 \((a, b)\)에서 극값을 갖고 편도함수가 있으면 \(\nabla f(a, b) = \mathbf{0}\).

증명. \(g(x) = f(x, b)\)는 \(x = a\)에서 일변수 극값을 가지므로 \(g'(a) = f_x(a, b) = 0\). \(f_y\)도 같다. ∎ 극값이면 접평면이 수평이라는 뜻이다. 역은 성립하지 않는다(안장점).

임계점의 종류를 가리려면 2차 항을 봐야 합니다. 임계점에서 1차 항이 사라지므로 2차 테일러 전개(12장의 다변수 판)는

$$f(a + h, b + k) \approx f(a, b) + \tfrac12\left(f_{xx}h^2 + 2f_{xy}hk + f_{yy}k^2\right) = f(a, b) + \tfrac12\,\mathbf{h}^{\mathsf T}H\,\mathbf{h}, \qquad H = \begin{bmatrix}f_{xx} & f_{xy}\\ f_{xy} & f_{yy}\end{bmatrix}.$$
\(H\)를 헤세 행렬(Hessian matrix)이라 한다. 클레로 정리(13장)로 대칭 행렬이다. 이차 형식 \(\mathbf{h}^{\mathsf T}H\mathbf{h}\)의 부호가 모든 방향에서 양수인지, 음수인지, 섞여 있는지가 임계점의 종류를 정한다.
정리 14.8 (2계 편도함수 판정) \(f\)의 2계 편도함수가 \((a, b)\) 근처에서 연속이고 \(\nabla f(a, b) = \mathbf{0}\)이라 하자. 판별식(discriminant) \(D = f_{xx}f_{yy} - f_{xy}^2 = \det H\)에 대해
  1. \(D > 0\)이고 \(f_{xx} > 0\)이면 극소.
  2. \(D > 0\)이고 \(f_{xx} \lt 0\)이면 극대.
  3. \(D \lt 0\)이면 안장점.
  4. \(D = 0\)이면 이 판정으로는 알 수 없다.

증명 아이디어. \(A = f_{xx} \ne 0\)일 때 완전제곱하면 \(Ah^2 + 2Bhk + Ck^2 = A\left(h + \tfrac{B}{A}k\right)^2 + \tfrac{AC - B^2}{A}k^2 = A\left(h + \tfrac{B}{A}k\right)^2 + \tfrac{D}{A}k^2\). \(D > 0\)이면 두 항의 부호가 \(A\)와 같아 이차 형식이 한 부호(정부호)이고, \(D \lt 0\)이면 두 항의 부호가 반대라 방향에 따라 부호가 바뀐다. 2계 편도함수가 연속이므로 임계점 근처에서 \(f\)의 부호 구조가 이 이차 형식을 따른다. ∎ 선형대수로 말하면 \(D = \lambda_1\lambda_2\)(고유값의 곱)이고, 판정은 헤세 행렬의 고유값 부호를 보는 것이다.

예제 14.4 (임계점 찾고 분류하기) \(f(x, y) = x^3 + y^3 - 3xy\).
  1. \(\nabla f = (3x^2 - 3y,\; 3y^2 - 3x) = \mathbf{0}\)에서 \(y = x^2\), 이를 둘째 식에 넣으면 \(x^4 = x\), \(x(x^3 - 1) = 0\). 실수해는 \(x = 0, 1\)이므로 임계점은 \((0, 0)\), \((1, 1)\).
  2. \(f_{xx} = 6x\), \(f_{yy} = 6y\), \(f_{xy} = -3\), \(D = 36xy - 9\).
  3. \((0, 0)\): \(D = -9 \lt 0\) → 안장점. 실제로 \(f(t, t) = 2t^3 - 3t^2 \lt 0\)이고 \(f(t, -t) = 3t^2 > 0\) (작은 \(t \ne 0\)).
  4. \((1, 1)\): \(D = 27 > 0\), \(f_{xx} = 6 > 0\) → 극소, \(f(1, 1) = -1\). 극솟값이지만 최솟값은 아니다. \(f(-t, 0) = -t^3 \to -\infty\).
예제 14.5 (D = 0이면 판정 불가) \(x^4 + y^4\), \(-(x^4 + y^4)\), \(x^4 - y^4\)는 셋 다 원점이 임계점이고 헤세 행렬이 영행렬이라 \(D = 0\)입니다. 그런데 각각 극소, 극대, 안장점입니다. \(D = 0\)일 때는 더 높은 차수의 항을 보거나 함수를 직접 분석해야 합니다. "원숭이 안장" \(x^3 - 3xy^2\)도 \(D = 0\)인 안장점으로, 내리막이 세 갈래입니다.

닫힌 영역의 최대·최소

판의 가장 뜨거운 점

원판 모양 금속판의 온도 분포를 알 때 가장 뜨거운 점과 가장 차가운 점을 찾아야 합니다. 판 안쪽의 임계점만 보면 될까요? 일변수의 닫힌 구간에서 끝점을 따로 확인했듯이(6장), 2차원에서는 끝점이 경계 곡선 전체가 됩니다.

정리 14.9 (최대·최소 정리, 2변수) \(f\)가 닫히고 유계인 집합 \(D \subset \mathbb{R}^2\)에서 연속이면 \(f\)는 \(D\)에서 최댓값과 최솟값을 갖는다. 그 값은 (1) \(D\) 내부의 임계점 또는 (2) \(D\)의 경계 위에서 나타난다.

"닫힌"은 경계를 포함한다는 뜻, "유계"는 어떤 원 안에 들어간다는 뜻입니다. 둘 중 하나라도 빠지면 최댓값이 없을 수 있습니다(열린 원판에서 \(x\), 평면 전체에서 \(x^2 + y^2\)). 절차는 일변수와 같습니다.

  1. 내부의 임계점에서 \(f\)의 값을 구한다(종류를 판정할 필요는 없다).
  2. 경계를 매개화해 일변수 최적화 문제로 바꾸고, 그 최댓값·최솟값(꼭짓점 포함)을 구한다.
  3. 모든 후보 중 가장 큰 값이 최댓값, 가장 작은 값이 최솟값이다.
예제 14.6 (원판 위의 온도) 원판 \(x^2 + y^2 \le 1\) 위의 온도 \(T(x, y) = x^2 + 2y^2 - x\)의 최댓값과 최솟값을 구하라.
  1. 내부: \(\nabla T = (2x - 1,\; 4y) = \mathbf{0}\)에서 \((\tfrac12, 0)\). 원판 안에 있고 \(T = \tfrac14 - \tfrac12 = -\tfrac14\).
  2. 경계: \(x = \cos t\), \(y = \sin t\)이면 \(T = \cos^2t + 2\sin^2t - \cos t = 2 - \cos^2t - \cos t\). \(c = \cos t \in [-1, 1]\)로 두면 \(g(c) = 2 - c^2 - c\).
  3. \(g'(c) = -2c - 1 = 0\)에서 \(c = -\tfrac12\), \(g = 2 - \tfrac14 + \tfrac12 = \tfrac94\). 끝점: \(g(1) = 0\), \(g(-1) = 2\).
  4. 후보값 \(-\tfrac14, \tfrac94, 0, 2\)를 비교하면 최댓값 \(\tfrac94\) (점 \((-\tfrac12, \pm\tfrac{\sqrt3}{2})\)), 최솟값 \(-\tfrac14\) (점 \((\tfrac12, 0)\)).

라그랑주 승수법: 제약 곡선에 접하는 등고선

정해진 통나무에서 가장 강한 보

지름 \(d\)인 원형 통나무에서 직사각형 단면(폭 \(w\), 높이 \(h\))의 보를 켜 냅니다. 보의 굽힘 강도는 \(wh^2\)에 비례합니다. 단면은 원 안에 들어가야 하므로 \(w^2 + h^2 = d^2\)이라는 제약 조건(constraint)이 있습니다. 제약을 풀어 한 변수로 줄일 수도 있지만, 제약이 복잡하거나 변수가 많으면 그럴 수 없습니다.

등고선 그림에서 생각하면 답이 보입니다. 제약 곡선 \(g = c\)를 따라 걸으며 \(f\)의 등고선을 가로지르면 \(f\)가 계속 변합니다. \(f\)가 최대인 곳에서는 더 이상 새 등고선을 가로지르지 않습니다. 즉 그 점에서 제약 곡선이 \(f\)의 등고선에 접합니다. 두 곡선이 접하면 법선이 평행하고, 법선은 그래디언트이므로 \(\nabla f \parallel \nabla g\)입니다.

정리 14.10 (라그랑주 승수법) \(f\)와 \(g\)가 \(C^1\)이고, 제약 \(g(x, y) = c\) 위에서 \(f\)가 점 \(P\)에서 극값을 가지며 \(\nabla g(P) \ne \mathbf{0}\)이면, 어떤 수 \(\lambda\)가 있어
$$\nabla f(P) = \lambda\,\nabla g(P), \qquad g(P) = c.$$
\(\lambda\)를 라그랑주 승수(Lagrange multiplier)라 한다. 미지수 \(x, y, \lambda\) 셋에 방정식 셋(성분 둘 + 제약)이다. 변수 \(n\)개, 제약 \(m\)개이면 \(\nabla f = \lambda_1\nabla g_1 + \cdots + \lambda_m\nabla g_m\).

증명. \(\nabla g(P) \ne \mathbf{0}\)이면 음함수 정리로 \(P\) 근처의 제약 곡선을 미분 가능한 곡선 \(\mathbf{r}(t)\), \(\mathbf{r}(0) = P\), \(\mathbf{r}'(0) \ne \mathbf{0}\)으로 쓸 수 있다. \(f(\mathbf{r}(t))\)는 \(t = 0\)에서 극값이므로 \(\nabla f(P)\cdot\mathbf{r}'(0) = 0\). 또 \(g(\mathbf{r}(t)) = c\)이므로 \(\nabla g(P)\cdot\mathbf{r}'(0) = 0\). 평면에서 같은 영이 아닌 벡터 \(\mathbf{r}'(0)\)에 수직인 두 벡터는 평행하므로 \(\nabla f(P) = \lambda\nabla g(P)\). ∎

예제 14.7 (타원 위의 최대 곱) 타원 \(\dfrac{x^2}{8} + \dfrac{y^2}{2} = 1\) 위에서 \(f = xy\)의 최댓값과 최솟값을 구하라.
  1. \(\nabla f = (y, x)\), \(\nabla g = (x/4, y)\). 조건 \(y = \lambda x/4\), \(x = \lambda y\).
  2. 둘을 합치면 \(y = \lambda^2y/4\). \(y = 0\)이면 \(x = 0\)인데 타원 위의 점이 아니므로 \(y \ne 0\), \(\lambda^2 = 4\), \(\lambda = \pm 2\).
  3. \(\lambda = 2\): \(x = 2y\), 제약에 넣으면 \(4y^2/8 + y^2/2 = y^2 = 1\), 점 \((2, 1)\), \((-2, -1)\), \(f = 2\). \(\lambda = -2\): \(x = -2y\), 점 \((2, -1)\), \((-2, 1)\), \(f = -2\).
  4. 타원은 닫힌 유계 곡선이라 최대·최소가 있다. 최댓값 2, 최솟값 −2.
예제 14.8 (통나무에서 켜 낸 보) \(w^2 + h^2 = d^2\) 아래에서 \(wh^2\)을 최대로 하라.
  1. \(\nabla(wh^2) = (h^2,\; 2wh)\), \(\nabla(w^2 + h^2) = (2w,\; 2h)\). 조건 \(h^2 = 2\lambda w\), \(2wh = 2\lambda h\).
  2. \(h \ne 0\)이므로 둘째 식에서 \(\lambda = w\), 첫째 식에 넣으면 \(h^2 = 2w^2\), \(h = \sqrt2\,w\).
  3. 제약에 넣으면 \(3w^2 = d^2\): \(w = d/\sqrt3\), \(h = d\sqrt{2/3}\). 지름 30 cm 통나무면 폭 약 17.3 cm, 높이 약 24.5 cm.
  4. 최적 단면의 높이 : 폭 = √2 : 1 ≈ 1.41 : 1. 정사각형 단면(1 : 1)보다 세로로 긴 보가 강하다.

승수 \(\lambda\)는 계산 도구에 그치지 않습니다. 최적값 \(f^*\)를 제약 상수 \(c\)의 함수로 보면 \(\dfrac{df^*}{dc} = \lambda\)가 성립합니다(최적점이 \(c\)에 매끄럽게 따라 움직일 때). 제약을 한 단위 풀어 주면 최적값이 \(\lambda\)만큼 좋아진다는 뜻이라, 경제학에서는 \(\lambda\)를 그림자 가격(shadow price)이라 부릅니다. 예제 14.7에서 제약을 \(x^2/8 + y^2/2 = c\)로 바꾸면 최댓점은 \((2\sqrt c, \sqrt c)\), \(f^* = 2c\)이므로 \(df^*/dc = 2 = \lambda\)입니다.

경사 하강법: 학습률과 수렴 속도

∇f = 0을 풀 수 없을 때

지금까지는 \(\nabla f = \mathbf{0}\)을 손으로 풀었습니다. 변수가 백만 개이고 \(f\)가 데이터로 정의된 함수라면 그럴 수 없습니다. 할 수 있는 것은 현재 위치에서 \(f\)와 \(\nabla f\)를 계산하는 것뿐입니다. 이것만으로 바닥을 찾을 수 있을까요?

정리 14.3에 따르면 \(-\nabla f\)가 가장 가파른 내리막입니다. 그 방향으로 조금 가고, 다시 그래디언트를 계산하고, 또 갑니다.

$$\mathbf{x}_{k+1} = \mathbf{x}_k - \eta\,\nabla f(\mathbf{x}_k).$$
\(\eta > 0\)를 학습률(learning rate) 또는 보폭이라 한다. 이 반복이 경사 하강법(gradient descent)이다. MathBook 최적화 장이 학습률의 세 영역을 그림으로 보였다면, 여기서는 그 경계를 정확히 계산한다.

\(\eta\)가 너무 작으면 느리고, 너무 크면 골짜기를 넘어 튕겨 나갑니다. 경계가 어디인지는 이차 함수에서 정확히 계산할 수 있고, 매끄러운 함수의 극소점 근처는 2차 테일러 전개로 이차 함수처럼 생겼으므로 이 계산이 일반적인 경우의 국소적인 그림이 됩니다.

정리 14.11 (이차 함수 위의 경사 하강) \(f(\mathbf{x}) = \tfrac12\mathbf{x}^{\mathsf T}A\mathbf{x}\), \(A\)는 고유값이 \(0 \lt \mu = \lambda_{\min} \le \cdots \le \lambda_{\max} = L\)인 대칭 행렬이라 하자. 경사 하강법은
  1. \(0 \lt \eta \lt 2/L\)일 때, 그리고 그때만 모든 출발점에서 최솟점 \(\mathbf{0}\)으로 수렴한다.
  2. 오차는 매 단계 \(\rho(\eta) = \max_i|1 - \eta\lambda_i| = \max(|1 - \eta\mu|, |1 - \eta L|)\)배 이하로 준다.
  3. \(\rho\)를 가장 작게 하는 학습률은 \(\eta^* = \dfrac{2}{L + \mu}\)이고, 그때 \(\rho^* = \dfrac{L - \mu}{L + \mu} = \dfrac{\kappa - 1}{\kappa + 1}\), \(\kappa = L/\mu\)는 조건수(condition number)다.

증명. \(\nabla f = A\mathbf{x}\)이므로 \(\mathbf{x}_{k+1} = (I - \eta A)\mathbf{x}_k\). \(A\)의 고유벡터(직교, 스펙트럼 정리)로 전개하면 각 성분이 따로 \(1 - \eta\lambda_i\)배씩 된다. 모든 \(|1 - \eta\lambda_i| \lt 1\)이어야 수렴하고, 이는 \(\eta\lambda_{\max} \lt 2\)와 같다. \(\rho(\eta)\)는 \(1 - \eta\mu\)(감소)와 \(\eta L - 1\)(증가)의 최댓값이므로 둘이 같아지는 \(\eta = 2/(L + \mu)\)에서 최소다. ∎

예제 14.9 (길쭉한 골짜기) \(f = x^2 + 10y^2\).
  1. \(\nabla f = (2x, 20y)\), 헤세 행렬 \(\operatorname{diag}(2, 20)\): \(\mu = 2\), \(L = 20\), \(\kappa = 10\).
  2. 갱신은 \(x \leftarrow (1 - 2\eta)x\), \(y \leftarrow (1 - 20\eta)y\). 수렴 조건 \(\eta \lt 2/20 = 0.1\).
  3. \(\eta = 0.05\)이면 배율은 0.9와 0. \(y\)는 한 번에 0이 되지만 \(x\)는 매번 10%씩만 준다. \(\eta = 0.11\)이면 \(y\)의 배율이 \(-1.2\)라 지그재그로 발산한다.
  4. 최적 \(\eta^* = 2/22 = 1/11 \approx 0.091\)에서 두 배율이 \(9/11\)과 \(-9/11\), 수렴률 \(\rho^* = 9/11 \approx 0.818\). 오차를 \(10^{-6}\)배로 줄이려면 \(k \ge \ln 10^6/\ln(11/9) \approx 68.9\), 약 69번 반복.

최소제곱 회귀: 편도함수 두 개로 직선 맞추기

점들을 가장 잘 지나는 직선

센서의 입력 \(x_i\)와 출력 \(y_i\)를 몇 번 재어 검량선 \(y = mx + b\)를 만들려 합니다. 측정에 잡음이 있어 모든 점을 지나는 직선은 없습니다. "가장 잘 맞는" 직선을 어떻게 정의하고 찾을까요?

각 점에서 직선과의 세로 차이 \(r_i = y_i - (mx_i + b)\)를 잔차(residual)라 합니다. 잔차의 제곱합을 가장 작게 하는 직선을 고르는 것이 최소제곱법(least squares)입니다. 오차 함수는 두 변수 \(m, b\)의 이차 함수입니다.

$$E(m, b) = \sum_{i=1}^{n}\bigl(y_i - mx_i - b\bigr)^2.$$
정리 14.12 (정규 방정식) \(x_i\)가 모두 같지는 않으면 \(E(m, b)\)는 유일한 최솟점을 가지며, 그 점은
$$\Bigl(\sum x_i^2\Bigr)m + \Bigl(\sum x_i\Bigr)b = \sum x_iy_i, \qquad \Bigl(\sum x_i\Bigr)m + n\,b = \sum y_i$$
의 해다. 이 연립 방정식을 정규 방정식(normal equations)이라 한다.

증명. \(\partial E/\partial m = -2\sum x_i(y_i - mx_i - b) = 0\), \(\partial E/\partial b = -2\sum(y_i - mx_i - b) = 0\)을 정리하면 위 식이다. 헤세 행렬은 \(H = 2\begin{bmatrix}\sum x_i^2 & \sum x_i\\ \sum x_i & n\end{bmatrix}\)로 상수이고, \(\det(H/2) = n\sum x_i^2 - (\sum x_i)^2 = n\sum(x_i - \bar x)^2 > 0\), \(\sum x_i^2 > 0\)이므로 정리 14.8에서 극소다. \(E\)는 이차 함수이고 \(H\)가 양의 정부호라 \(E\)는 볼록 그릇 모양이므로, 이 극소가 유일한 최솟점이다. ∎

둘째 식을 \(n\)으로 나누면 \(\bar y = m\bar x + b\): 최소제곱 직선은 언제나 데이터의 무게 중심 \((\bar x, \bar y)\)를 지납니다. 선형대수로 보면 정규 방정식은 \(A^{\mathsf T}A\hat{\mathbf{x}} = A^{\mathsf T}\mathbf{y}\)이고, 미적분의 "그래디언트 = 0"이 기하의 "잔차가 열공간에 수직"과 같은 말이라는 것을 LinearBook 최소제곱에서 볼 수 있습니다.

예제 14.10 (네 점에 직선 맞추기) 점 \((0, 1), (1, 3), (2, 4), (3, 4)\).
  1. 합: \(n = 4\), \(\sum x = 6\), \(\sum x^2 = 14\), \(\sum y = 12\), \(\sum xy = 0 + 3 + 8 + 12 = 23\).
  2. 정규 방정식: \(14m + 6b = 23\), \(6m + 4b = 12\).
  3. 둘째 식에서 \(b = 3 - 1.5m\). 첫째 식에 넣으면 \(14m + 18 - 9m = 23\), \(m = 1\), \(b = 1.5\). 직선 \(y = x + 1.5\).
  4. 잔차: \(-0.5, 0.5, 0.5, -0.5\). 합이 0(둘째 정규 방정식)이고, \(\sum x_ir_i = 0 + 0.5 + 1 - 1.5 = 0\)(첫째 정규 방정식). 최소 제곱합 \(E = 1\).
  5. 검산: 무게 중심 \((1.5, 3)\)이 직선 위에 있다. \(1.5 + 1.5 = 3\). ✓

핵심 정리

  1. 방향 도함수 \(D_{\mathbf{u}}f = \nabla f\cdot\mathbf{u}\) (\(|\mathbf{u}| = 1\), \(f\) 미분 가능). 편도함수 두 개가 모든 방향의 기울기를 정한다.
  2. \(\nabla f\)는 가장 가파른 오르막 방향이고 그 기울기는 \(|\nabla f|\)다. \(-\nabla f\)는 가장 가파른 내리막, 수직 방향은 기울기 0.
  3. \(\nabla f\)는 등위선·등위면에 수직이다. 등위면 \(F = k\)의 접평면은 \(\nabla F(P_0)\cdot(\mathbf{x} - P_0) = 0\).
  4. 극값에서 \(\nabla f = \mathbf{0}\). 판별식 \(D = f_{xx}f_{yy} - f_{xy}^2\): \(D > 0\)이면 \(f_{xx}\)의 부호로 극소/극대, \(D \lt 0\)이면 안장점, \(D = 0\)이면 판정 불가. 헤세 행렬의 고유값 부호와 같은 판정이다.
  5. 닫힌 유계 영역의 최대·최소는 내부 임계점과 경계(꼭짓점 포함)의 후보를 모두 비교해 찾는다.
  6. 제약 \(g = c\) 위의 극값에서 \(\nabla f = \lambda\nabla g\): 등고선이 제약 곡선에 접한다. \(\lambda = df^*/dc\)는 그림자 가격이다.
  7. 경사 하강 \(\mathbf{x} \leftarrow \mathbf{x} - \eta\nabla f\)는 이차 함수에서 \(\eta \lt 2/L\)일 때 수렴하고, 최적 수렴률은 \((\kappa - 1)/(\kappa + 1)\). 최소제곱 직선은 \(\partial E/\partial m = \partial E/\partial b = 0\)인 정규 방정식의 해다.

확인 퀴즈

Q1. \(f(x, y) = x^2 + y^2\)가 점 \((1, 1)\)에서 가장 빨리 증가하는 방향과 그 변화율은?

\(\nabla f = (2x, 2y) = (2, 2)\). 가장 빠른 증가는 \(\nabla f\) 방향 \((1, 1)/\sqrt2\)이고 변화율은 \(|\nabla f| = 2\sqrt2 \approx 2.83\). 원점에서 멀어지는 방향이니 그릇의 벽을 곧장 오른다.

Q2. 미분 가능한 \(f\)의 한 점에서 \(\nabla f = (3, -4)\)다. 방향 도함수가 0인 단위 벡터는?

\(D_{\mathbf{u}}f = \nabla f\cdot\mathbf{u} = 0\)이려면 \(\mathbf{u} \perp \nabla f\). \((3, -4)\cdot(4, 3) = 12 - 12 = 0\). 반대 방향 \((-4, -3)/5\)도 답이다. 이 방향이 등고선의 접선 방향이다.

Q3. \(f(x, y) = x^2 + 4xy + y^2\)의 원점은?

\(f_{xx} = 2\), \(f_{yy} = 2\), \(f_{xy} = 4\)이므로 \(D = 4 - 16 = -12 \lt 0\), 안장점. 두 축 방향으로는 오르막이지만 \(y = -x\) 방향으로는 \(f(t, -t) = -2t^2\)으로 내리막이다. \(f_{xx} > 0\)만 보고 극소라 하면 틀린다.

Q4. 임계점에서 \(D = f_{xx}f_{yy} - f_{xy}^2 = 0\)이다. 옳은 것은?

\(x^4 + y^4\)(극소), \(-x^4 - y^4\)(극대), \(x^4 - y^4\)(안장점) 모두 원점에서 \(D = 0\)이다(예제 14.5). 2차 근사가 퇴화해 더 높은 차수의 항이 모양을 정한다.

Q5. 원 \(x^2 + y^2 = 2\) 위에서 \(f = x + y\)의 최댓값과 그때의 라그랑주 승수 λ는?

\((1, 1) = \lambda(2x, 2y)\)에서 \(x = y = 1/(2\lambda)\). 제약에 넣으면 \(2/(4\lambda^2) = 2\), \(\lambda = \pm 1/2\). \(\lambda = 1/2\)이면 점 \((1, 1)\), \(f = 2\)가 최대. 검산: 제약을 \(x^2 + y^2 = c\)로 두면 \(f^* = \sqrt{2c}\), \(df^*/dc = 1/\sqrt{2c} = 1/2\) (c = 2). 그림자 가격과 일치한다.

Q6. \(f(x, y) = 5x^2 + \tfrac12 y^2\)에 고정 학습률 경사 하강법을 쓸 때 모든 출발점에서 수렴하는 η의 범위는?

헤세 행렬 \(\operatorname{diag}(10, 1)\)이라 \(L = 10\). 정리 14.11에서 \(\eta \lt 2/L = 0.2\). 이때 \(x\)는 \(1 - 10\eta\)배, \(y\)는 \(1 - \eta\)배가 되므로, 가장 가파른 방향의 곡률이 학습률의 상한을 정한다.

Q7. 구면 \(x^2 + y^2 + z^2 = 14\) 위의 점 \((1, 2, 3)\)에서의 접평면은?

\(\nabla F = (2x, 2y, 2z) = (2, 4, 6)\). 접평면 \(2(x - 1) + 4(y - 2) + 6(z - 3) = 0\)을 2로 나누면 \(x + 2y + 3z = 1 + 4 + 9 = 14\). 구에서는 법선이 반지름 방향 \((1, 2, 3)\)이다.

Q8. 원점을 지나는 직선 \(y = mx\)를 점 \((1, 2)\), \((2, 3)\)에 최소제곱으로 맞추면 m은?

\(E(m) = \sum(y_i - mx_i)^2\), \(E'(m) = -2\sum x_i(y_i - mx_i) = 0\)에서 \(m = \sum x_iy_i/\sum x_i^2 = (2 + 6)/(1 + 4) = 8/5 = 1.6\). 절편이 없으니 정규 방정식이 하나뿐이다.
