# CalculusBook 챕터 작성 가이드

CalculusBook은 [MathBook(foundations)](../foundations/CONTRIBUTING.md), [LinearBook](../linear/CONTRIBUTING.md)과 같은 엔진(`MB`)으로 쓰는 미적분 교과서다. **이 문서에 없는 규칙과 `MB` API 전체는 `../foundations/CONTRIBUTING.md`를 따르고, 빌드·수식 규칙은 `../linear/CONTRIBUTING.md`와 같다.** 문체·구성·그림·시뮬레이터 수준의 본보기는 `../linear/chapters/eigen.html`이다.

## 기여물의 라이선스

코드는 MIT, 교재 콘텐츠는 CC BY 4.0. 다른 교재의 문장·그림·연습문제를 옮겨 오지 않는다. 역사·수치는 확인된 사실만 쓴다(확실하지 않으면 쓰지 않는다).

## 구조

빌드 없이 열리는 정적 페이지다. `index.html` + `chapters/<slug>.html` + `css/style.css`(MathBook 스타일, 색만 진분홍 `#c2255c`·파랑 `#1971c2`) + `js/common.js`(전역 `MB`, 장 목록 `CHAPTERS`). classic script만 쓴다(ES module 금지).

- 장 목록은 `js/common.js`의 `CHAPTERS`에 있다. 아직 쓰지 않은 장은 `planned: true`로 두면 목차에만 보이고 링크·검색·이전/다음에서 빠진다.
- 용어는 `js/glossary-data.js`에 추가한다(시리즈 공통 v1: `ko`, `en`, `abbr`, `def`, `chapters`). 본문에서 처음 나오는 용어는 `<span class="term">…</span>`.

## 원칙: 그림 → 계산 → 쓰임

CalculusBook은 대학 미적분 1년(일변수 미적분 + 다변수·벡터 미적분)을 **빠짐없이** 다룬다. 모든 개념을 **그래프로 먼저 보고(확대하고, 끌고, 쌓고), 손으로 계산하고, 공학에서 쓰이는 곳**까지 잇는다. 미적분의 두 눈, **변화율(미분)과 누적(적분)**이 결국 하나라는 이야기를 책 전체의 줄기로 삼는다.

- 한국어, 대상은 공대 1학년과 미적분을 다시 공부하는 엔지니어. 영어 원어는 `<span class="en">(Derivative)</span>`처럼 병기.
- 장 첫머리는 `.origin`("이 수식이 없었다면")으로 연다. 각 절은 가능하면 `.problem`으로 시작한다.
- 흐름: 문제 → 그림(SVG) → **조작하는 시뮬레이터** → 정의·정리(KaTeX) → **손으로 푸는 예제**(`.callout` 안에 단계별) → 쓰이는 곳(`.uses`) → 핵심 정리 → 확인 퀴즈(6–8문항).
- 교과서다운 엄밀함: 정의와 정리는 `<div class="callout deep"><strong>정리 3.2 (곱의 법칙)</strong> …</div>`처럼 **장 번호.순번**을 붙이고, 증명은 짧으면 본문에, 길면 핵심 아이디어만 쓴다. 예제도 `예제 3.1`처럼 번호를 붙인다. 그림은 `그림 3-1.`.
- 장마다 시뮬레이터 6–8개. 숫자를 바꾸거나 점을 끌면 그림이 바로 반응해야 한다. `MB.plane`(끄는 점), `MB.chart`, `MB.loop`(애니메이션)를 적극 쓴다. 단계별 과정(리만 합 세분, 뉴턴 반복, 이분법…)은 "다음 단계" 버튼이나 슬라이더로 한 단계씩 보여 준다.
- 3차원(곡면·벡터장·중적분)은 캔버스에 직접 그린다: 등고선/히트맵(`MB.colormap`)과, 끌어서 돌리는 간단한 사영(회전 행렬 → 2D, 뒤에서부터 칠하기)으로 충분하다. WebGL·외부 라이브러리는 쓰지 않는다.
- MathBook의 "무한을 길들이기"(`../../foundations/chapters/limits.html`)나 "최적화"(`optimization.html`)와 겹치는 내용은 더 깊이 다루고 필요하면 링크한다. 선형대수가 필요한 곳(헤세 행렬, 야코비안, 선형 근사)은 `../../linear/chapters/symmetric.html`, `determinants.html` 등으로 링크한다.
- 색은 CSS 변수와 `MB.palette()`만. 라이트/다크 모두 확인. 폭 360px에서 가로 스크롤 금지. SVG는 `viewBox`만 주고 width/height 생략.
- 시뮬레이터 `id`는 `sim-<장 접두사>-<이름>`, 캔버스·입력 등 요소 id도 같은 접두사를 붙인다(`lm-cv-zoom`, `lm-h`). 이 장 전용 CSS 클래스도 접두사를 붙인다(`.lm-msg`). 절 `id`는 의미 있는 영어 슬러그로 짓고 바꾸지 않는다.

## 장별 설계

각 장은 아래 절을 모두 다룬다(순서·제목은 다듬어도 된다). 시뮬레이터 아이디어는 최소 목록이다.

**01 극한** — 함수가 한 점에 다가갈 때의 값 / 그래프를 확대하기, 수치표(h → 0) / 한쪽 극한과 극한이 없는 경우(점프, 진동 sin(1/x), 발산) / 극한 법칙과 대수적 계산(인수분해, 유리화) / 조임 정리 / 무한대에서의 극한과 점근선(수평·수직) / ε–δ 정의(ε을 주면 δ를 고르는 게임). 시뮬: 확대경 줌, h 표 만들기, 한쪽 극한 비교, 조임 정리, 점근선, ε–δ 게임.
**02 연속성** — 연속의 정의 세 조건 / 불연속의 종류(제거 가능·점프·무한) / 연속 함수의 대수와 합성 / 중간값 정리와 이분법(근 찾기) / 최대·최소 정리 / 중요한 극한 sin x / x → 1, (1+1/n)ⁿ → e, 복리 / 균등 연속은 다루지 않는다. 시뮬: 불연속 고치기, 이분법 단계, 중간값 정리(등산로 문제), sin x/x 부채꼴 넓이, 복리 → e.
**03 도함수** — 할선에서 접선(점 끌기) / 도함수 정의와 극한 계산 / 미분 가능성과 연속(|x|, 뾰족점, 수직 접선) / 도함수 함수의 그래프(f에서 f′ 그리기) / 거듭제곱·상수배·합·곱·몫의 법칙 / 고계 도함수, 위치–속도–가속도 / 라이프니츠 표기. 시뮬: 할선 → 접선, f′ 그리기 탐험, 미분 불가능 점 확대, 곱의 법칙 넓이 그림, 위치–속도–가속도 동기화.
**04 연쇄 법칙과 초월 함수** — 합성 함수와 연쇄 법칙(톱니바퀴 비유) / 삼각 함수의 도함수(단위원) / 지수 함수 eˣ의 특별함과 ln의 도함수 / 역함수의 도함수(반사) / 음함수 미분(원, 엽선) / 로그 미분 / 관련 변화율(사다리, 풍선, 원뿔 물탱크) / 쌍곡선 함수는 짧게. 시뮬: 연쇄 법칙 배율 체인, sin과 cos 도함수 동기, aˣ의 기울기/값 비가 상수인 a 찾기(e), 음함수 접선, 사다리 관련 변화율 애니메이션.
**05 평균값 정리와 그래프** — 롤의 정리 / 평균값 정리(과속 단속 구간) / 증가·감소 판정과 1계 도함수 판정 / 오목성, 2계 도함수 판정, 변곡점 / 로피탈 정리(0/0, ∞/∞, 다른 꼴로 바꾸기) / 도함수로 그래프 그리기 종합 / 극한 성장 비교(로그 ≪ 거듭제곱 ≪ 지수). 시뮬: 평균값 정리 점 찾기, f·f′·f″ 세 그래프 동기, 로피탈 확대(분자·분모를 직선으로), 성장 경주.
**06 최적화와 근사** — 닫힌 구간 방법 / 최적화 문제 세우기(상자, 캔, 울타리, 빛의 굴절: 페르마 원리와 스넬 법칙) / 선형 근사와 접선 / 미분 dy와 오차 전파(상대 오차) / 뉴턴 방법(수렴과 실패) / 2차 근사 맛보기(12장 예고). 시뮬: 상자 부피 최적화, 최소 시간 경로(굴절), 선형 근사 오차 줌, 오차 전파 계산기, 뉴턴 방법 단계·실패 사례.
**07 정적분** — 속도 그래프 아래 넓이 = 이동 거리 / 시그마 표기와 합 공식 / 리만 합(왼쪽·오른쪽·중점, n 슬라이더) / 정적분 정의, 적분 가능성 / 부호 있는 넓이와 성질(선형성, 구간 가법성, 비교) / 정적분의 평균값 / 수치 적분 맛보기(오차가 n에 따라 줄어드는 속도). 시뮬: 리만 합 n 바꾸기, 왼쪽·오른쪽·중점 오차 로그 그래프, 부호 있는 넓이, 평균값 높이, 속도→거리.
**08 미적분의 기본 정리** — 누적 함수 A(x) = ∫ₐˣ f(t)dt / 기본 정리 1부(A′ = f)와 그림 증명 / 2부(∫ₐᵇ f = F(b) − F(a)) / 부정적분과 기본 공식표 / 치환 적분(정적분의 한계 바꾸기) / 순변화량 정리(유량→부피, 전류→전하) / 상한이 함수인 미분. 시뮬: 누적 함수 그리기(f를 끌면 A가 바뀜), A의 기울기 = f 확인, 치환 적분 넓이 보존 변환, 물탱크 유량–부피.
**09 적분 기법** — 부분 적분(LIATE, 표 방법, 순환형) / 삼각 적분과 삼각 치환 / 부분 분수 / 적분 전략 정리 / 이상 적분(무한 구간, 무한 불연속, p-적분, 비교 판정) / 수치 적분: 사다리꼴·심프슨과 오차 차수 / 적분표·CAS 쓰기. 시뮬: 부분 적분 넓이 그림(uv 직사각형), 삼각 치환 삼각형, 이상 적분 꼬리 넓이(1/x vs 1/x²), 사다리꼴·심프슨 오차 비교, 부분 분수 분해기.
**10 적분의 응용** — 두 곡선 사이 넓이(x·y로 자르기) / 부피: 단면, 원판·와셔, 원통 껍질 / 곡선의 길이 / 회전면의 넓이(짧게) / 일(용수철, 물 퍼올리기), 유체 압력 / 질량 중심과 파푸스 정리 / 확률 밀도와 기댓값 / 교통·경제 응용(소비자 잉여는 짧게). 시뮬: 회전체 와셔 쌓기(3D 사영), 원통 껍질, 곡선 길이 꺾은선 근사, 물 퍼올리기 일, 무게 중심 균형.
**11 수열과 급수** — 수열의 극한, 단조 수렴 정리 / 급수와 부분합, 기하 급수(제논, 반복 소수) / 발산 판정, 조화 급수의 발산 / 적분 판정과 p-급수 / 비교·극한 비교 판정 / 교대 급수와 오차 한계, 절대·조건 수렴(재배열 정리는 짧게) / 비 판정과 근 판정 / 판정법 고르기. 시뮬: 부분합 그래프, 기하 급수 정사각형 쪼개기, 조화 급수 vs 적분, 교대 급수 진동, 판정법 선택기.
**12 거듭제곱 급수와 테일러 전개** — 거듭제곱 급수와 수렴 반지름/구간 / 급수의 미분·적분, 1/(1−x)에서 ln, arctan 얻기 / 테일러·매클로린 급수 / 테일러 다항식과 나머지 항(라그랑주 오차) / eˣ, sin, cos, ln(1+x), (1+x)ᵏ 이항 급수 / 오일러 공식 e^{iθ} / 응용: 상대론 근사, 진자 근사, 계산기의 sin, 적분할 수 없는 함수(e^{−x²}). 시뮬: 테일러 다항식 차수 슬라이더, 수렴 반지름(복소 특이점 거리), 나머지 오차, 오일러 공식 나선, 진자 근사 비교.
**13 다변수 함수와 편미분** — 2변수 함수, 곡면과 등고선(지도) / 다변수 극한과 연속(경로마다 다른 극한) / 편도함수(단면의 기울기) / 고계 편도함수와 클레로 정리 / 접평면과 선형 근사, 미분 가능성 / 전미분과 오차 전파 / 다변수 연쇄 법칙, 음함수 미분 / 열·파동 방정식 맛보기. 시뮬: 곡면–등고선 회전 뷰, 단면 슬라이스(x 고정·y 고정), 경로 극한 비교, 접평면 확대, 연쇄 법칙 경로 위 변화율.
**14 기울기 벡터와 최적화** — 방향 도함수 / 그래디언트: 가장 가파른 방향, 등고선과 수직 / 등위면의 접평면 / 극값과 안장점, 헤세 행렬과 2계 판정(LinearBook 13장 링크) / 닫힌 영역의 최대·최소 / 라그랑주 승수법(접하는 등고선) / 경사 하강법과 학습률 / 최소제곱 회귀 유도. 시뮬: 방향 도함수 나침반, 그래디언트 장 + 등고선, 임계점 분류, 라그랑주 접점 찾기, 경사 하강 학습률 비교.
**15 중적분** — 직사각형 위 이중 적분(부피, 리만 합 기둥) / 반복 적분과 푸비니 정리 / 일반 영역과 적분 순서 바꾸기 / 극좌표 이중 적분(가우스 적분 ∫e^{−x²} = √π) / 삼중 적분, 원기둥·구면 좌표 / 변수 변환과 야코비안(LinearBook 10장 링크) / 응용: 질량, 질량 중심, 관성 모멘트, 확률. 시뮬: 기둥 리만 합(3D 사영), 적분 순서 바꾸기 영역 자르기, 극좌표 격자 넓이 요소, 야코비안 격자 변형, 관성 모멘트 회전.
**16 벡터 미적분** — 벡터장(바람, 유체, 중력) / 선적분(스칼라·벡터), 일 / 보존장, 퍼텐셜, 선적분 기본 정리, 경로 독립 / 그린 정리(순환과 넓이, 플라니미터) / 회전과 발산(작은 바람개비, 작은 상자) / 매개 곡면과 면적분, 플럭스 / 스토크스 정리, 발산 정리 / 맥스웰 방정식으로 마무리. 시뮬: 벡터장 + 입자 흐름, 경로를 그려 일 계산, 보존장 경로 독립 확인, 그린 정리 순환 = 회전의 합, 발산·회전 탐침.
**17 용어집 & 종합 퀴즈** — 미분 공식·적분 공식 한눈표, 급수 판정법 고르기, 좌표계 변환표, 용어 검색, 전 범위 종합 퀴즈(장마다 1–2문항).

소스에는 `<title>`과 `<meta name="description">`(한 줄)만 쓴다. canonical·Open Graph 태그는 `tools/build.mjs`가 `calculus/book.json`의 `meta`로 생성하고, 수식은 빌드가 `tools/katex.mjs`로 미리 렌더링한다. 그래서 다음을 지킨다. 어기면 `npm test`나 빌드가 실패한다.

- canonical·`og:` 태그, KaTeX `<link>`/`<script>`를 소스에 넣지 않는다.
- **스크립트가 수식을 DOM에 넣지 않는다.** 인라인 `<script>` 안에 `\(`·`\[`·`$$`가 있으면 검사가 실패한다. 시뮬레이터의 식 출력은 HTML(`<sup>`, `<sub>`, `·`, `−`, `√`, `∫`)로 만든다. `MB.tex`는 쓰지 않는다.
- 수식 안에서 `<` 바로 뒤에 글자가 오면 브라우저가 태그로 읽는다. `a<b` 대신 `a \lt b` 또는 `a < b`(공백).
- 수식 안의 HTML 엔티티는 `&amp; &lt; &gt; &nbsp; &middot; &times; &minus;`와 숫자 엔티티만 쓴다.
