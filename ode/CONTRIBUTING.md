# ODEBook 챕터 작성 가이드

ODEBook은 [MathBook(foundations)](../foundations/CONTRIBUTING.md), [LinearBook](../linear/CONTRIBUTING.md), [CalculusBook](../calculus/CONTRIBUTING.md)과 같은 엔진(`MB`)으로 쓰는 미분방정식 교과서다. **이 문서에 없는 규칙과 `MB` API 전체는 `../foundations/CONTRIBUTING.md`를 따르고, 빌드·수식 규칙은 `../calculus/CONTRIBUTING.md`와 같다.** 문체·구성·그림·시뮬레이터 수준의 본보기는 `../calculus/chapters/fundamental.html`과 `../linear/chapters/eigen.html`이다.

## 기여물의 라이선스

코드는 MIT, 교재 콘텐츠는 CC BY 4.0. 다른 교재의 문장·그림·연습문제를 옮겨 오지 않는다. 역사·수치는 확인된 사실만 쓴다(확실하지 않으면 쓰지 않는다).

## 구조

빌드 없이 열리는 정적 페이지다. `index.html` + `chapters/<slug>.html` + `css/style.css`(MathBook 스타일, 색만 주황 `#e8590c`·청록 `#0c8599`) + `js/common.js`(전역 `MB`, 장 목록 `CHAPTERS`). classic script만 쓴다(ES module 금지).

- 장 목록은 `js/common.js`의 `CHAPTERS`에 있다.
- 용어는 `js/glossary-data.js`에 추가한다(시리즈 공통 v1: `ko`, `en`, `abbr`, `def`, `chapters`). 본문에서 처음 나오는 용어는 `<span class="term">…</span>`.
- ODE 수치 적분은 `MB.rk4(f, y0, t0, dt, n)`·`MB.euler`(형식 `[[t, y[]], …]`)를 쓴다. 고유값·행렬은 `MB.mat`, 복소수는 `MB.cx`, FFT는 엔진의 FFT 헬퍼를 쓴다. 엔진에 없는 것은 장 스크립트 안에 작게 만든다(`js/common.js`는 고치지 않는다).

## 원칙: 법칙 → 그림 → 해 → 쓰임

ODEBook은 공대 2학년 공업수학의 미분방정식 한 학기(+ 연립·비선형 동역학, 편미분방정식 입문)를 **빠짐없이** 다룬다. 모든 방정식을 **물리 법칙에서 세우고(모델링), 방향장·위상 평면으로 먼저 보고, 손으로 풀고, 수치로 확인하고, 회로·기계·열·생태에서 쓰이는 곳**까지 잇는다. 책 전체의 줄기는 "미분방정식은 **지금 상태가 다음 순간을 정하는 규칙**이고, 해는 그 규칙을 따라 그린 곡선"이라는 관점이다. 선형 방정식에서는 **지수 함수 e^{λt}와 고유값**이, 비선형에서는 **평형점과 안정성**이 주인공이다.

- 한국어, 대상은 공대 2학년과 미분방정식을 다시 공부하는 엔지니어. 영어 원어는 `<span class="en">(Direction Field)</span>`처럼 병기.
- 장 첫머리는 `.origin`("이 수식이 없었다면")으로 연다. 각 절은 가능하면 `.problem`으로 시작한다.
- 흐름: 문제 → 모델(법칙에서 방정식 세우기) → 그림(SVG) → **조작하는 시뮬레이터** → 정의·정리(KaTeX) → **손으로 푸는 예제**(`.callout` 안에 단계별) → 쓰이는 곳(`.uses`) → 핵심 정리 → 확인 퀴즈(6–8문항).
- 교과서다운 엄밀함: 정의와 정리는 `<div class="callout deep"><strong>정리 3.2 (적분 인자)</strong> …</div>`처럼 **장 번호.순번**을 붙이고, 증명은 짧으면 본문에, 길면 핵심 아이디어만 쓴다. 예제도 `예제 3.1`처럼 번호를 붙인다. 그림은 `그림 3-1.`. 손으로 푼 해는 반드시 수치(RK4)로 맞는지 확인한 뒤 쓴다.
- 장마다 시뮬레이터 6–8개. 숫자를 바꾸거나 점을 끌면 그림이 바로 반응해야 한다. 방향장 위를 클릭/끌어 초기값을 놓으면 해곡선이 그려지는 상호작용, 시간에 따라 움직이는 물리 장면(`MB.loop`: 용수철, 진자, 탱크, 회로)과 그래프를 나란히(`.split`) 동기화하는 구성을 적극 쓴다. `MB.plane`(끄는 점), `MB.chart`, `MB.loop`.
- 3차원(로렌즈 끌개, 열 방정식 곡면)은 캔버스에 직접 그린다: 히트맵(`MB.colormap`)과 끌어서 돌리는 간단한 사영으로 충분하다. WebGL·외부 라이브러리는 쓰지 않는다.
- 앞 책과 겹치는 곳은 더 깊이 다루고 링크한다: 적분 기법 `../../calculus/chapters/techniques.html`, 테일러 `../../calculus/chapters/taylor.html`, 고유값 `../../linear/chapters/eigen.html`, 행렬 지수와 동역학 `../../linear/chapters/dynamics.html`, MathBook의 미분방정식 개관 `../../foundations/chapters/ode.html`, 푸리에는 `../../foundations/chapters/fourier.html`. 링크 전에 파일이 실제로 있는지 확인한다(`ls ../linear/chapters`).
- 색은 CSS 변수와 `MB.palette()`만. 라이트/다크 모두 확인. 폭 360px에서 가로 스크롤 금지. SVG는 `viewBox`만 주고 width/height 생략.
- 시뮬레이터 `id`는 `sim-<장 접두사>-<이름>`, 캔버스·입력 등 요소 id도 같은 접두사를 붙인다(`md-cv-field`, `md-k`). 이 장 전용 CSS 클래스도 접두사를 붙인다(`.md-msg`). 절 `id`는 의미 있는 영어 슬러그로 짓고 바꾸지 않는다.

## 장별 설계

각 장은 아래 절을 모두 다룬다(순서·제목은 다듬어도 된다). 시뮬레이터 아이디어는 최소 목록이다.

**01 미분방정식과 모델링** — 변화율로 쓰는 법칙(낙하, 인구, 냉각, 방사성 붕괴) / 상미분·편미분, 계수, 선형·비선형 / 해, 일반해와 특수해, 해곡선 족 / 초기값 문제 / 방향장(기울기 장)과 등경사선 / 해를 대입해 확인하기 / 오일러 방법 첫걸음(접선을 따라 걷기) / 모델링의 순서(가정 → 방정식 → 해 → 검증). 시뮬: 방향장 클릭해 해곡선 그리기, 등경사선, 공기 저항 낙하와 종단 속도, 해곡선 족의 매개변수 c, 오일러 걸음 h 바꾸기, 모델 맞추기(데이터에 k 맞추기).
**02 변수분리형 방정식** — 분리와 적분, 상수 해를 잃지 않기 / 지수 성장·붕괴, 반감기, 탄소 연대 측정 / 뉴턴 냉각 법칙(커피, 사망 시각 추정) / 로지스틱 성장과 수용력 / 토리첼리 법칙(탱크 비우기) / 음함수 해와 해의 정의 구간 / 직교 궤적 / 동차형 y′ = F(y/x) 치환. 시뮬: 반감기 붕괴 입자 vs 곡선, 커피 식히기, 로지스틱 r·K, 탱크 비우기 애니메이션, 직교 궤적 족, 정의 구간이 끊기는 해.
**03 1계 선형 방정식과 완전 방정식** — 표준형 y′ + p(t)y = g(t) / 적분 인자 μ = e^{∫p}의 유도 / RC·RL 회로(충전·방전, 시상수) / 혼합 탱크 / 과도 응답 + 정상 상태(사인 입력) / 해의 구조: 동차해 + 특수해 / 완전 방정식과 판정 M_y = N_x, 퍼텐셜 / 적분 인자로 완전하게 만들기 / 베르누이 방정식. 시뮬: RC 충전 회로 + 그래프, 시상수 읽기, 혼합 탱크 농도, 사인 입력 과도→정상, 완전 방정식 퍼텐셜 등고선, 베르누이 치환 비교.
**04 해의 존재와 자율 방정식** — 존재·유일성 정리(피카르–린델뢰프) / 피카르 반복 / 유일성이 깨지는 예(y′ = √y, 물 새는 양동이) / 유한 시간 폭발(y′ = y²) / 자율 방정식과 위상선 / 평형점과 안정성 판정(f′ 부호) / 수확이 있는 로지스틱과 분기(안장–마디 맛보기) / 스위치처럼 동작하는 쌍안정. 시뮬: 피카르 반복 단계, 비유일 해 다발, 폭발 시간 vs 초기값, 위상선 + 해곡선 동기, 수확률 h 슬라이더 분기도, 쌍안정 스위치.
**05 수치 해법** — 오일러 방법과 국소·전역 오차 / 오차 차수의 로그–로그 기울기 / 개선 오일러(호인), 중점법 / 룽게–쿠타 4차 / 연립·고계 방정식에 적용 / 적응 간격(RK45 아이디어) / 안정성 영역과 강성, 음적 오일러 / 에너지 보존(심플렉틱 오일러로 궤도 계산 비교). 시뮬: 세 방법 나란히, 오차–h 로그 그래프, RK4 기울기 네 개 그림, 강성 방정식 폭발 vs 음적, 행성 궤도 에너지 드리프트, 적응 간격 점 찍기.
**06 2계 선형 방정식** — 2계 방정식과 초기 조건 두 개 / 선형성과 중첩 원리 / 기본해 집합과 론스키안, 아벨 정리 / 상수계수 동차: 특성 방정식 / 서로 다른 실근, 중근(te^{rt}), 복소근(e^{αt}cos βt) / 계수 내리기 / 코시–오일러 방정식 / 고계 선형 방정식 맛보기. 시뮬: 특성근 복소평면 점 끌기 ↔ 해 모양, 중첩 슬라이더, 론스키안 0 판정, 초기 조건 두 개 맞추기, 근 경로(b 변화).
**07 자유 진동** — 훅의 법칙과 뉴턴 2법칙으로 mx″ + cx′ + kx = 0 / 단진동, 고유 진동수, 진폭과 위상(A cos(ωt − φ)) / 감쇠 세 영역과 판별식 / 감쇠비 ζ, 로그 감소율 / 에너지와 감쇠(위상 평면 나선) / 진자의 작은 진동 / RLC 회로와 기계 상사 / 자동차 서스펜션, 도어 클로저(임계 감쇠). 시뮬: 용수철–질량 애니메이션 + x(t), 감쇠 c 슬라이더 세 영역, 위상 평면 궤적, 에너지 막대, RLC ↔ 기계 상사 표, 측정 데이터에서 ζ 읽기.
**08 강제 진동과 공진** — 비동차 방정식의 해 구조 / 미정계수법(다항식·지수·사인, 겹칠 때 t 곱하기) / 매개변수 변환법 / 사인 강제력과 정상 응답 진폭·위상 / 맥놀이 / 공진(비감쇠 t sin ωt), 감쇠 공진 피크 / 주파수 응답 곡선과 Q 인자, 반치폭 / 응용: 타코마 다리는 공진이 아니라 공탄성 플러터임을 정확히 말하기, 라디오 동조, 진동 절연. 시뮬: 강제 진동 애니메이션(구동 진동수 ω), 맥놀이, 주파수 응답 곡선 + 위상, 공진 성장, 진동 절연(전달률), 미정계수 꼴 고르기.
**09 라플라스 변환** — 적분 변환의 아이디어(미분을 곱셈으로) / 정의와 수렴, 지수 차수 / 기본 변환표 유도 / 선형성, 미분의 변환 / s-이동, t-이동 / 부분 분수와 역변환(복소근, 중근) / 초기값 문제 풀이 흐름도 / 연립 방정식에 적용 / 최종값·초기값 정리. 시뮬: e^{−st}f(t) 넓이로 F(s) 그리기, 변환 쌍 탐색기, s-이동 = 감쇠 곱하기, 부분 분수 분해기, IVP 세 단계 흐름, 최종값 정리 확인.
**10 불연속 입력과 전달 함수** — 단위 계단 함수와 스위치 / 구간별 입력, t-이동 / 디랙 델타와 충격(망치로 치기) / 충격 응답 / 합성곱과 합성곱 정리(과거 입력의 메아리) / 전달 함수 H(s), 극점과 영점 / s-평면 극점 위치와 응답 모양, 안정성 / 주파수 응답 H(iω), 보드 선도 / 1차·2차 시스템 계단 응답(오버슈트, 정착 시간) / PID 맛보기. 시뮬: 스위치 켜고 끄기 응답, 충격 크기·폭 → 델타, 합성곱 슬라이딩, s-평면 극점 끌기 ↔ 충격 응답, 보드 선도, 2차 계단 응답 오버슈트.
**11 연립 선형 방정식** — 고계를 1계 연립으로 / x′ = Ax와 고유값 방법(LinearBook 고유값 장 링크) / 서로 다른 실 고유값: 마디·안장 / 복소 고유값: 나선·중심 / 중복 고유값: 퇴화 마디, 일반화 고유벡터 / 대각합–행렬식 평면 지도 / 행렬 지수 e^{At} / 비동차 연립(매개변수 변환) / 응용: 두 탱크, 결합 진동자와 정규 모드. 시뮬: 위상 평면 + 고유벡터 직선, 행렬 성분 슬라이더 ↔ 대각합–행렬식 평면 점, 결합 진자 정규 모드, 두 탱크 농도, e^{At} 급수 항.
**12 비선형 시스템과 안정성** — 평형점과 야코비안 선형화, 하트만–그로브만(쌍곡 평형점) / 진자: 위상 평면, 분리선, 회전 운동 / 로트카–볼테라 포식자–피식자, 보존량 / 경쟁 모델과 공존·배제 / 리아푸노프 함수 / 한계 순환, 푸앵카레–벤딕슨(아이디어) / 반 데어 폴 진동자 / SIR 전염병 모델. 시뮬: 진자 위상 평면 + 애니메이션, 로트카–볼테라 궤도, 경쟁 모델 매개변수, 선형화 확대경(평형점 근처), 반 데어 폴 μ, SIR 정점 시기.
**13 분기와 혼돈** — 1차원 분기 정규형: 안장–마디, 초임계·아임계 갈퀴, 횡단 / 이력 현상 / 호프 분기 / 푸앵카레 단면과 사상 / 강제 감쇠 진자(더핑) / 로렌즈 방정식과 끌개, 초기값 민감성, 리아푸노프 지수 아이디어 / 로지스틱 사상과 주기 배가, 파이겐바움 상수(값은 확인된 4.669…만) / 예측의 한계. 시뮬: 분기도 그리기(매개변수 슬라이더), 이력 고리, 호프 분기 나선→순환, 로렌즈 끌개 회전 + 두 궤적 벌어짐, 로지스틱 사상 분기도 확대, 더핑 푸앵카레 단면.
**14 급수해와 특수 함수** — 보통점에서 거듭제곱 급수 해(점화식) / 에어리 방정식 / 수렴 반지름과 특이점 거리 / 정칙 특이점과 지표 방정식 / 프로베니우스 방법(근의 차가 정수일 때 아이디어) / 르장드르 방정식과 다항식(직교성) / 베셀 방정식과 베셀 함수, 영점 / 원형 북의 진동 모드. 시뮬: 급수해 항 수 늘리기, 점화식 계수 표, 에어리 함수 진동–감쇠, 르장드르 다항식, 베셀 함수와 영점, 북 진동 모드 애니메이션.
**15 경계값 문제와 푸리에 급수** — 초기값 vs 경계값(해가 없거나 무수히 많은 경우) / 고유값 문제 y″ + λy = 0, 기둥의 좌굴(오일러 하중) / 스튀름–리우빌 문제, 고유함수의 직교성 / 함수 내적과 직교 전개 / 푸리에 급수, 사인·코사인 급수, 짝·홀 확장 / 수렴 정리와 기브스 현상 / 파세발 등식 / 강제 경계값 문제를 고유함수 전개로 풀기. 시뮬: 슈팅 방법으로 경계 맞추기, 고유함수 모드, 좌굴 하중, 푸리에 급수 항 추가, 기브스 오버슈트, 계수 막대(스펙트럼).
**16 편미분방정식 입문** — 열 방정식 유도(푸리에 법칙) / 변수분리법과 고유함수 전개 / 경계 조건(디리클레·노이만) / 파동 방정식, 줄의 진동과 배음, 달랑베르 해 / 라플라스 방정식과 정상 상태 온도 / 유한 차분법(명시적 방법)과 안정성 조건 r ≤ 1/2, CFL / 응용: 반도체 확산, 악기 줄, 정전기 퍼텐셜. 시뮬: 막대 온도 히트맵 시간 진행, 모드별 감쇠 속도, 줄 뜯기 + 배음, 달랑베르 두 파 진행, 판 정상 상태 온도(반복 완화), 유한 차분 r > 1/2 불안정.
**17 용어집 & 종합 퀴즈** — 방정식 꼴 → 풀이법 고르기 도우미, 특성근 ↔ 해 모양 한눈표, 라플라스 변환표, 평형점 분류 지도(대각합–행렬식), 용어 검색, 전 범위 종합 퀴즈(장마다 2문항).

소스에는 `<title>`과 `<meta name="description">`(한 줄)만 쓴다. canonical·Open Graph 태그는 `tools/build.mjs`가 `ode/book.json`의 `meta`로 생성하고, 수식은 빌드가 `tools/katex.mjs`로 미리 렌더링한다. 그래서 다음을 지킨다. 어기면 `npm test`나 빌드가 실패한다.

- canonical·`og:` 태그, KaTeX `<link>`/`<script>`를 소스에 넣지 않는다.
- **스크립트가 수식을 DOM에 넣지 않는다.** 인라인 `<script>` 안에 `\(`·`\[`·`$$`가 있으면 검사가 실패한다. 시뮬레이터의 식 출력은 HTML(`<sup>`, `<sub>`, `·`, `−`, `√`, `∫`)로 만든다. `MB.tex`는 쓰지 않는다.
- 수식 안에서 `<` 바로 뒤에 글자가 오면 브라우저가 태그로 읽는다. `a<b` 대신 `a \lt b` 또는 `a < b`(공백).
- 수식 안의 HTML 엔티티는 `&amp; &lt; &gt; &nbsp; &middot; &times; &minus;`와 숫자 엔티티만 쓴다.
