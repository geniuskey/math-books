Chapter 09

라플라스 변환

6~8장에서는 2계 선형 방정식을 특성 방정식으로 풀고, 강제항이 있으면 미정계수법이나 매개변수 변환법으로 특수해를 찾은 다음, 마지막에 초기 조건 두 개로 상수를 맞췄습니다. 세 단계가 따로 놀고, 강제항이 바뀔 때마다 요령도 바뀝니다. 이 장의 라플라스 변환은 이 모든 과정을 하나의 기계적인 절차로 묶습니다. 함수 \(f(t)\)를 새 변수 \(s\)의 함수 \(F(s)\)로 옮기면 미분은 \(s\)를 곱하는 일이 되고, 초기 조건은 처음부터 식에 들어가며, 미분방정식은 \(Y(s)\)에 대한 대수 방정식이 됩니다. 풀고 나서 표를 거꾸로 읽어 \(y(t)\)로 돌아오면 끝입니다.

  • 라플라스 변환을 정의하고, 지수 차수 조건에서 변환이 존재함을 보이며, \(e^{-st}f(t)\) 아래 넓이로 \(F(s)\)를 읽는다.
  • \(t^n\), \(e^{at}\), \(\sin\omega t\), \(\cos\omega t\)의 변환을 직접 유도하고 변환표를 만든다.
  • 선형성, 미분의 변환 \(\mathcal{L}\{f'\} = sF - f(0)\), 적분의 변환, \(t\) 곱하기의 규칙을 증명하고 쓴다.
  • s-이동(지수 감쇠를 곱하면 \(F\)가 옆으로 이동)과 t-이동(지연은 \(e^{-as}\) 곱하기)을 쓴다.
  • 부분 분수로 역변환한다: 서로 다른 실근, 중근, 복소근 각각의 꼴을 안다.
  • 초기값 문제와 연립 방정식을 변환 → 대수 → 역변환의 세 단계로 풀고, 최종값·초기값 정리로 답을 검산한다.
이 수식이 없었다면회로를 손으로 해석하는 공학

스위치가 달린 회로, 여러 개의 코일과 축전기가 얽힌 필터, 전신선처럼 길게 늘어진 선로를 해석하려면 연립 미분방정식을 초기 조건과 함께 풀어야 합니다. 방정식마다 특수해의 꼴을 추측하는 방식으로는 손이 금방 모자랍니다. 19세기 말 헤비사이드(Oliver Heaviside)는 전신 문제를 다루며 미분 기호 \(d/dt\)를 그냥 문자 \(p\)처럼 다루어 대수로 계산하는 연산자 계산법(operational calculus)을 썼습니다. 답은 잘 맞았지만 왜 맞는지에 대한 근거는 당시 엄밀하지 않았습니다.

그 근거가 된 것이 라플라스(Pierre-Simon Laplace)의 이름이 붙은 적분 \(\int_0^\infty e^{-st}f(t)\,dt\)입니다. 이후 수학자들이 헤비사이드의 계산을 이 적분 변환의 성질로 정당화했고, 오늘날 회로 이론과 제어 공학의 \(s\)-영역 언어(임피던스 \(sL\), \(1/(sC)\), 전달 함수)는 모두 여기서 나왔습니다.

회로의 미분방정식 + 초기 조건→미분 = s 곱하기→ℒ{f′} = sF − f(0)→대수 방정식 + 변환표

적분 변환의 아이디어: 미분을 곱셈으로

곱셈이 어려우면 로그로 바꾼다

계산기가 없던 시절 큰 수의 곱 \(xy\)는 로그표로 계산했습니다. \(\ln x\)와 \(\ln y\)를 표에서 찾아 더하고, 그 합을 표에서 거꾸로 찾으면 \(xy\)입니다. 어려운 연산(곱셈)을 쉬운 연산(덧셈)으로 바꾸는 변환, 쉬운 세계에서 계산, 그리고 되돌아오기. 미분방정식에도 이런 변환이 있을까요? 미분이라는 어려운 연산을 곱셈으로 바꿔 주는 변환이 있다면, \(y'' + 3y' + 2y = 6\)은 그냥 일차 방정식이 될 것입니다.

그런 변환의 후보를 찾아봅시다. 함수 \(f(t)\)에 어떤 핵(kernel) \(K(s, t)\)를 곱해 \(t\)에 대해 적분하면 \(s\)의 함수가 나옵니다. 이런 것을 적분 변환(integral transform)이라 합니다. 미분이 곱셈이 되려면 부분 적분 한 번에 \(f'\)의 적분이 \(f\)의 적분의 상수배로 바뀌어야 하는데, 이것은 \(\partial K/\partial t\)가 \(K\)의 상수배일 때, 즉 핵이 지수 함수 \(e^{-st}\)일 때 일어납니다.

$$\int_0^\infty e^{-st} f'(t)\,dt = \Big[e^{-st}f(t)\Big]_0^\infty + s\int_0^\infty e^{-st}f(t)\,dt = -f(0) + s\,F(s).$$
경계항은 \(t \to \infty\)에서 \(e^{-st}f(t) \to 0\)이면 \(-f(0)\)만 남는다. 미분이 \(s\) 곱하기로 바뀌었고, 초기값 \(f(0)\)이 저절로 따라 들어왔다.

적분 구간을 \([0, \infty)\)로 잡은 데도 까닭이 있습니다. 초기값 문제는 \(t = 0\)에서 출발해 앞으로만 가므로 과거(\(t \lt 0\))는 필요 없고, 경계항에 남는 것이 정확히 출발점의 값입니다. 이 장 전체의 계획은 그림 9-1의 한 장으로 요약됩니다.

정의와 수렴: 지수 차수

정의 9.1 (라플라스 변환) \(t \ge 0\)에서 정의된 함수 \(f(t)\)에 대해
$$F(s) = \mathcal{L}\{f(t)\} = \int_0^\infty e^{-st} f(t)\,dt = \lim_{T\to\infty}\int_0^T e^{-st}f(t)\,dt$$
가 수렴하는 \(s\)에서 \(F\)를 \(f\)의 라플라스 변환이라 한다. 관례로 시간 함수는 소문자, 변환은 같은 글자의 대문자로 쓴다(\(y \leftrightarrow Y\), \(g \leftrightarrow G\)). 이 장에서 \(s\)는 우선 실수로 생각하고, 극점을 다룰 때 복소수로 넓힌다.

정의를 그림으로 읽으면 이렇습니다. \(s\)를 하나 고르면 \(e^{-st}\)는 \(t = 0\)에서 1이고 시간이 갈수록 줄어드는 가중치입니다. \(F(s)\)는 이 가중치를 곱한 곡선 \(e^{-st}f(t)\) 아래의 넓이입니다. \(s\)가 크면 가중치가 빨리 죽어 \(t = 0\) 근처만 세고, \(s\)가 작으면 먼 미래까지 셉니다. 아래 시뮬레이터에서 \(s\)를 움직이며 넓이를 재면 아래 그래프에 \(F(s)\)가 한 점씩 그려집니다.

예제 9.1 (첫 변환들) \(\mathcal{L}\{1\}\), \(\mathcal{L}\{e^{at}\}\), \(\mathcal{L}\{t\}\)를 구하라.
  1. \(\displaystyle\int_0^T e^{-st}\,dt = \frac{1 - e^{-sT}}{s} \to \frac1s\) (\(s > 0\)). \(s \le 0\)이면 적분이 무한대로 발산한다.
  2. \(\displaystyle\int_0^\infty e^{-st}e^{at}\,dt = \int_0^\infty e^{-(s-a)t}\,dt = \frac{1}{s - a}\) (\(s > a\)). 1번은 \(a = 0\)인 경우다.
  3. 부분 적분(\(u = t\), \(dv = e^{-st}dt\)): \(\displaystyle\int_0^\infty te^{-st}\,dt = \Big[-\frac{t e^{-st}}{s}\Big]_0^\infty + \frac1s\int_0^\infty e^{-st}\,dt = 0 + \frac{1}{s^2}\) (\(s > 0\)).
  4. 수치 확인: \(s = 2\)에서 \(\int_0^\infty te^{-2t}\,dt = 0.25 = 1/2^2\). ✓

예제에서 보듯 변환은 보통 어떤 \(s_0\)보다 큰 \(s\)에서만 존재합니다. 어떤 함수가 변환을 가지려면 \(f\)가 \(e^{-st}\)보다 빨리 자라지 않아야 합니다.

정의 9.2 (구간별 연속, 지수 차수) \(f\)가 모든 유한 구간 \([0, T]\)에서 유한 개의 점을 빼고 연속이고 그 점들에서 좌우 극한이 유한하면 구간별 연속(piecewise continuous)이라 한다. 상수 \(M > 0\), \(a\), \(T_0\)가 있어 \(t \ge T_0\)에서 \(|f(t)| \le Me^{at}\)이면 \(f\)는 지수 차수(exponential order) \(a\)라 한다.
정리 9.3 (변환의 존재) \(f\)가 \([0, \infty)\)에서 구간별 연속이고 지수 차수 \(a\)이면 \(\mathcal{L}\{f\}(s)\)는 모든 \(s > a\)에서 존재하고, \(s \to \infty\)일 때 \(F(s) \to 0\)이다.

증명. \([0, T_0]\)에서는 구간별 연속 함수가 유계라 적분이 유한하다. \(t \ge T_0\)에서는 \(|e^{-st}f(t)| \le Me^{-(s-a)t}\)이고 \(\int_{T_0}^\infty Me^{-(s-a)t}\,dt \lt \infty\)이므로(\(s > a\)) 비교 판정법으로 절대 수렴한다. 같은 부등식으로 \(|F(s)| \le K/s + M/(s - a)\) 꼴의 상계를 얻으니(\(K\)는 \([0,T_0]\)에서 \(|f|\)의 최댓값) \(s \to \infty\)에서 \(F \to 0\)이다. ∎

다항식, 지수 함수, 사인·코사인과 이들의 곱·합은 모두 지수 차수이므로 공학에서 만나는 입력은 거의 다 변환을 가집니다. 계단처럼 끊어지는 함수도 구간별 연속이면 괜찮습니다. 이것이 10장에서 스위치 입력을 다루는 바탕입니다.

변환이 없는 함수 \(e^{t^2}\)은 어떤 \(e^{at}\)보다도 빨리 자라서 \(e^{-st}e^{t^2} = e^{t(t - s)}\)이 \(t > s\)부터 커지기만 하므로 적분이 발산합니다. \(1/t\)은 \(t = 0\) 근처에서 적분할 수 없어(구간별 연속이 아님) 역시 변환이 없습니다. 반대로 정리 9.3의 조건은 충분조건일 뿐이라, \(t^{-1/2}\)처럼 0에서 무한대지만 적분 가능한 함수는 변환 \(\sqrt{\pi/s}\)를 가집니다.

\(F(s) \to 0\)은 쓸모 있는 검산 도구입니다. 계산 끝에 \(\mathcal{L}\{f\} = s/(s+1)\)처럼 \(s \to \infty\)에서 0으로 가지 않는 답이 나오면 보통의 함수의 변환이 아니므로 어디선가 틀린 것입니다(10장의 델타 함수는 예외로, 보통 함수가 아닙니다).

기본 변환표 유도

매번 적분하지 않으려면

로그표가 쓸모 있는 것은 한 번 만들어 두면 계속 쓰기 때문입니다. 라플라스 변환도 자주 나오는 함수 몇 개의 변환을 한 번 유도해 두면, 나머지는 다음 절의 성질(선형성·이동·미분)로 조립할 수 있습니다. 어떤 함수들을 표에 넣어야 할까요? 6~8장의 해에 나온 것, 즉 \(t^n\), \(e^{at}\), \(\cos\omega t\), \(\sin\omega t\)와 그 곱이면 충분합니다.

예제 9.2 (거듭제곱) \(\mathcal{L}\{t^n\} = \dfrac{n!}{s^{n+1}}\) (\(s > 0\), \(n = 0, 1, 2, \dots\))임을 보여라.
  1. 부분 적분 \(u = t^n\), \(dv = e^{-st}dt\): \(\displaystyle\int_0^\infty t^n e^{-st}\,dt = \Big[-\frac{t^n e^{-st}}{s}\Big]_0^\infty + \frac{n}{s}\int_0^\infty t^{n-1}e^{-st}\,dt\).
  2. 경계항은 0이다(\(n \ge 1\)이면 \(t = 0\)에서 0, \(t \to \infty\)에서 지수 감쇠가 다항식을 이긴다). 그래서 \(\mathcal{L}\{t^n\} = \frac{n}{s}\mathcal{L}\{t^{n-1}\}\).
  3. \(\mathcal{L}\{1\} = 1/s\)에서 시작해 되풀이하면 \(\mathcal{L}\{t^n\} = \frac{n}{s}\cdot\frac{n-1}{s}\cdots\frac{1}{s}\cdot\frac1s = \frac{n!}{s^{n+1}}\).
  4. 수치 확인: \(s = 2\)에서 \(\int_0^\infty t^3e^{-2t}\,dt = 0.375 = 3!/2^4\). ✓ 정수가 아닌 지수에서는 \(n!\) 대신 감마 함수 \(\Gamma(n+1)\)이 들어간다.
예제 9.3 (사인과 코사인: 오일러 공식으로 한 번에) \(\mathcal{L}\{\cos\omega t\}\)와 \(\mathcal{L}\{\sin\omega t\}\)를 구하라.
  1. 예제 9.1의 \(\frac{1}{s-a}\)는 \(a\)가 복소수여도 성립한다(\(s > \operatorname{Re}a\)). \(a = i\omega\)를 넣으면 \(\mathcal{L}\{e^{i\omega t}\} = \dfrac{1}{s - i\omega} = \dfrac{s + i\omega}{s^2 + \omega^2}\).
  2. \(e^{i\omega t} = \cos\omega t + i\sin\omega t\)이고 변환은 선형이므로 실수부와 허수부를 비교한다.
  3. \(\mathcal{L}\{\cos\omega t\} = \dfrac{s}{s^2 + \omega^2}\), \(\mathcal{L}\{\sin\omega t\} = \dfrac{\omega}{s^2 + \omega^2}\) (\(s > 0\)).
  4. 같은 방법으로 \(\cosh at = \frac12(e^{at} + e^{-at})\)이면 \(\mathcal{L}\{\cosh at\} = \frac12\bigl(\frac{1}{s-a} + \frac{1}{s+a}\bigr) = \frac{s}{s^2 - a^2}\), \(\mathcal{L}\{\sinh at\} = \frac{a}{s^2 - a^2}\) (\(s > |a|\)).

선형성과 미분의 변환

정리 9.4 (선형성) \(\mathcal{L}\{f\}\), \(\mathcal{L}\{g\}\)가 \(s > a\)에서 존재하면 상수 \(\alpha\), \(\beta\)에 대해 \(\mathcal{L}\{\alpha f + \beta g\} = \alpha F + \beta G\). 역변환도 선형이다. (적분이 선형이므로 바로 나온다.)
예제 9.4 (선형성으로 조립) \(\mathcal{L}\{3 - 2e^{-t} + 5\sin 2t\} = \dfrac3s - \dfrac{2}{s+1} + \dfrac{10}{s^2+4}\). 수치 확인: \(s = 2\)에서 양변 모두 \(2.0833\). ✓

이제 이 장의 주인공입니다. 1절의 부분 적분을 엄밀하게 쓰고, 한 번 더 써서 2계 도함수까지 갑니다.

정리 9.5 (미분의 변환) \(f\)가 \([0, \infty)\)에서 연속이고 지수 차수 \(a\)이며 \(f'\)이 구간별 연속이면 \(s > a\)에서
$$\mathcal{L}\{f'\} = sF(s) - f(0).$$
같은 조건을 \(f'\)에도 두면
$$\mathcal{L}\{f''\} = s^2F(s) - sf(0) - f'(0),\qquad \mathcal{L}\{f^{(n)}\} = s^nF(s) - s^{n-1}f(0) - \cdots - f^{(n-1)}(0).$$

증명. \(\int_0^T e^{-st}f'(t)\,dt = \big[e^{-st}f(t)\big]_0^T + s\int_0^T e^{-st}f(t)\,dt\)(\(f'\)이 끊어지는 점이 있으면 구간을 나눠 부분 적분하고, \(f\)가 연속이라 중간 경계항이 상쇄된다). \(|e^{-sT}f(T)| \le Me^{-(s-a)T} \to 0\)이므로 \(T \to \infty\)에서 \(-f(0) + sF(s)\). 2계는 \(f'\)에 1계 공식을 쓴 뒤 \(\mathcal{L}\{f'\}\)를 넣는다: \(s(sF - f(0)) - f'(0)\). ∎

이 공식이 미분방정식을 대수로 바꾸는 엔진입니다. 미분 한 번마다 \(s\)가 하나 곱해지고, 그 대가로 초기값이 하나씩 빠집니다. 6~8장에서는 일반해를 먼저 구하고 나중에 초기 조건으로 상수를 맞췄지만, 여기서는 초기 조건이 변환 단계에서 이미 들어갑니다.

예제 9.5 (미분 공식으로 변환 얻기) \(\mathcal{L}\{\cos\omega t\} = \frac{s}{s^2+\omega^2}\)만 알 때 \(\mathcal{L}\{\sin\omega t\}\)를 구하라.
  1. \(f = \cos\omega t\)이면 \(f' = -\omega\sin\omega t\), \(f(0) = 1\).
  2. 정리 9.5: \(-\omega\,\mathcal{L}\{\sin\omega t\} = s\cdot\frac{s}{s^2+\omega^2} - 1 = \frac{-\omega^2}{s^2+\omega^2}\).
  3. 따라서 \(\mathcal{L}\{\sin\omega t\} = \frac{\omega}{s^2+\omega^2}\). 예제 9.3과 같다.

미분이 \(s\) 곱하기라면 적분은 \(s\)로 나누기여야 자연스럽습니다. 또 \(s\) 쪽에서 미분하면 \(t\) 쪽에서는 무엇이 될까요?

정리 9.6 (적분의 변환) \(f\)가 구간별 연속이고 지수 차수이면 \(\displaystyle\mathcal{L}\Big\{\int_0^t f(\tau)\,d\tau\Big\} = \frac{F(s)}{s}.\)

증명. \(g(t) = \int_0^t f\)로 두면 \(g\)는 연속이고 \(g' = f\)(구간별), \(g(0) = 0\)이다. 정리 9.5로 \(F = sG - 0\). ∎

정리 9.7 (\(t\) 곱하기 = \(s\)에 대한 미분) \(\mathcal{L}\{t f(t)\} = -F'(s)\), 일반적으로 \(\mathcal{L}\{t^n f(t)\} = (-1)^n F^{(n)}(s)\).

증명. \(F(s) = \int_0^\infty e^{-st}f(t)\,dt\)를 적분 기호 안에서 \(s\)로 미분하면(수렴 영역 안에서 균등 수렴으로 정당화된다) \(\frac{\partial}{\partial s}e^{-st} = -te^{-st}\)이므로 \(F'(s) = -\int_0^\infty e^{-st}\,t f(t)\,dt\). ∎

예제 9.6 (공진 항의 변환) \(\mathcal{L}\{t\sin\omega t\}\)와 \(\mathcal{L}\{t\cos\omega t\}\)를 구하라.
  1. \(-\frac{d}{ds}\frac{\omega}{s^2+\omega^2} = \frac{2\omega s}{(s^2+\omega^2)^2}\), \(-\frac{d}{ds}\frac{s}{s^2+\omega^2} = -\frac{(s^2+\omega^2) - 2s^2}{(s^2+\omega^2)^2} = \frac{s^2-\omega^2}{(s^2+\omega^2)^2}\).
  2. 수치 확인(\(\omega = 3\), \(s = 2\)): \(\int_0^\infty te^{-2t}\sin 3t\,dt = 0.07101 = 12/169\). ✓
  3. 두 식을 조합하면 \(\frac{1}{2\omega^3}\bigl(\sin\omega t - \omega t\cos\omega t\bigr) \leftrightarrow \frac{1}{(s^2+\omega^2)^2}\). 8장의 비감쇠 공진에서 나온 \(t\cos\omega t\) 항이 바로 이 겹친 극점 \(\pm i\omega\)에서 온다.

s-이동과 t-이동

감쇠 진동의 변환을 새로 적분해야 할까

7장의 부족 감쇠 진동 \(e^{-2t}\cos 3t\)를 변환하려면 \(\int_0^\infty e^{-st}e^{-2t}\cos 3t\,dt\)를 계산해야 합니다. 그런데 \(e^{-st}e^{-2t} = e^{-(s+2)t}\)이니 이것은 \(\cos 3t\)의 변환에서 \(s\) 자리에 \(s + 2\)를 넣은 것뿐입니다. 지수 함수를 곱하는 일은 \(s\)축 위에서 무엇을 할까요?

정리 9.8 (s-이동, 제1 이동 정리) \(\mathcal{L}\{f\} = F(s)\) (\(s > a_0\))이면
$$\mathcal{L}\{e^{at}f(t)\} = F(s - a)\qquad (s > a_0 + a).$$

증명. \(\int_0^\infty e^{-st}e^{at}f(t)\,dt = \int_0^\infty e^{-(s-a)t}f(t)\,dt = F(s - a)\). ∎

시간 쪽에서 \(e^{at}\)를 곱하면 \(s\) 쪽에서는 \(F\)의 그래프가 \(a\)만큼 오른쪽으로 옮겨 가고, 극점도 모두 \(a\)만큼 이동합니다. \(a \lt 0\)(감쇠)이면 극점이 왼쪽으로 갑니다. 그림 9-2의 지도에서 왼쪽으로 갈수록 빨리 사라지는 항이 되는 이유가 바로 이것입니다. 표 9-1의 \(t^ne^{at}\), \(e^{at}\cos\omega t\), \(e^{at}\sin\omega t\)는 모두 이 정리로 얻었습니다.

예제 9.7 (s-이동 앞뒤로)
  1. \(\mathcal{L}\{e^{-2t}\cos 3t\} = \dfrac{s+2}{(s+2)^2 + 9}\). 극점은 \(-2 \pm 3i\).
  2. 역변환 \(\mathcal{L}^{-1}\Big\{\dfrac{2s + 3}{s^2 + 4s + 13}\Big\}\): 완전제곱 \(s^2 + 4s + 13 = (s+2)^2 + 9\). 분자를 \(s + 2\)로 맞추면 \(2s + 3 = 2(s+2) - 1\).
  3. \(\dfrac{2(s+2)}{(s+2)^2+9} - \dfrac13\cdot\dfrac{3}{(s+2)^2+9}\) \(\Rightarrow\) \(f(t) = e^{-2t}\bigl(2\cos 3t - \tfrac13\sin 3t\bigr)\).
  4. 검산: \(s = 2\)에서 수치 적분 \(\int_0^\infty e^{-2t}f(t)\,dt = 0.28\)이고 \(F(2) = \frac{2\cdot2+3}{4+8+13} = \frac{7}{25} = 0.28\). ✓

부분 분수와 역변환

표에 없는 꼴로 끝나는 계산

미분방정식을 변환해 \(Y(s)\)를 풀면 보통 \(\dfrac{5s - 1}{s^2 - s - 2}\) 같은 유리 함수가 나옵니다. 이 꼴은 표에 없습니다. 하지만 분모를 \((s+1)(s-2)\)로 인수분해하고 \(\dfrac{A}{s+1} + \dfrac{B}{s-2}\)처럼 쪼갤 수 있다면 각 조각은 표의 \(e^{at}\) 줄입니다. 유리 함수를 표의 조각으로 쪼개는 방법이 부분 분수(partial fractions)입니다(CalculusBook: 적분 기법에서 적분에 쓴 것과 같은 도구).

역변환은 "\(\mathcal{L}\{f\} = F\)인 \(f\)"입니다. 이것이 잘 정의되려면 \(F\)가 \(f\)를 하나로 정해야 합니다.

정리 9.10 (역변환의 유일성, 레르흐) 구간별 연속이고 지수 차수인 두 함수 \(f\), \(g\)의 변환이 어떤 \(s > s_0\)에서 모두 같으면 \(f\)와 \(g\)는 끊어지는 점을 빼고 같다. 따라서 연속 함수의 범위에서 \(\mathcal{L}^{-1}\{F\}\)는 하나로 정해진다. (증명은 이 책의 범위를 넘는다.)

분모 \(Q(s)\)의 차수가 분자 \(P(s)\)보다 높은 유리 함수(진분수)를 생각합니다. 분모의 인수 모양에 따라 세 가지 경우가 있습니다.

\(y'' + 3y' + 2y = 6\), \(y(0) = 1\), \(y'(0) = 0\). 6·8장 방식으로는 특성근 \(-1, -2\)로 동차해를 쓰고, 상수 특수해 \(y_p = 3\)을 찾고, 일반해에 초기 조건 두 개를 넣어 연립 방정식을 풉니다. 라플라스 변환으로는 이 세 일이 한 줄의 대수가 됩니다.

예제 9.11 (서로 다른 실근) \(y'' + 3y' + 2y = 6\), \(y(0) = 1\), \(y'(0) = 0\)을 풀어라.

탱크 A와 B가 바닥의 관으로 이어져 있고, B에는 배수구가 있습니다. 관을 지나는 유량은 수위 차에 비례하고(\(k(x - y)\)), 배수 유량은 B의 수위에 비례합니다(\(dy\)). A만 채워 두고 밸브를 열면 두 수위는 어떻게 변할까요? 미지 함수가 둘이고 서로의 식에 들어 있습니다.

모델은 \(x' = -k(x - y)\), \(y' = k(x - y) - dy\)입니다. 라플라스 변환은 연립 미분방정식도 연립 일차 방정식으로 바꿉니다. 각 식을 변환하면

$$\begin{aligned}(s + k)X - kY &= x_0,\\ -kX + (s + k + d)Y &= y_0.\end{aligned}$$

정리 9.11 (초기값 정리) \(f\)와 \(f'\)이 지수 차수이고 변환을 가지면 \(\displaystyle f(0^+) = \lim_{s\to\infty} sF(s)\).

아이디어. 같은 식 \(sF(s) - f(0) = \int_0^\infty e^{-st}f'(t)\,dt\)에서 \(s \to 0\)이면 오른쪽은 \(\int_0^\infty f'\,dt = f(\infty) - f(0)\). 극점 조건은 \(f\)가 실제로 수렴해서 극한을 바꿔 쓸 수 있게 해 주는 조건이다. ∎

핵심 정리

  1. \(\mathcal{L}\{f\} = F(s) = \int_0^\infty e^{-st}f(t)\,dt\)는 가중치 \(e^{-st}\)를 곱한 곡선 아래 넓이다. 구간별 연속이고 지수 차수 \(a\)인 함수는 \(s > a\)에서 변환을 가지며 \(F(s) \to 0\)이다.
  2. 기본표: \(1 \to 1/s\), \(t^n \to n!/s^{n+1}\), \(e^{at} \to 1/(s-a)\), \(\cos\omega t \to s/(s^2+\omega^2)\), \(\sin\omega t \to \omega/(s^2+\omega^2)\). 극점의 실수부는 성장·감쇠, 허수부는 진동수다.
  3. 미분의 변환 \(\mathcal{L}\{f'\} = sF - f(0)\), \(\mathcal{L}\{f''\} = s^2F - sf(0) - f'(0)\): 미분은 \(s\) 곱하기이고 초기값이 저절로 들어간다. 적분은 \(F/s\), \(t\) 곱하기는 \(-F'(s)\).
  4. s-이동 \(\mathcal{L}\{e^{at}f\} = F(s-a)\)는 극점을 \(a\)만큼 옮긴다. t-이동 \(\mathcal{L}\{u(t-a)f(t-a)\} = e^{-as}F(s)\)는 지연을 곱셈으로 바꾼다.
  5. 역변환은 부분 분수: 서로 다른 극점은 가리기로 \(Ae^{pt}\), 겹친 극점은 \(t^ke^{pt}\), 복소 극점은 완전제곱으로 \(e^{\alpha t}(B\cos\beta t + C\sin\beta t)\).
  6. 초기값 문제: 변환 → \(Y(s)\)에 대한 대수 → 부분 분수 → 역변환. 연립 방정식은 연립 일차 방정식이 되고, 그 행렬식이 특성 다항식이다.
  7. 초기값 정리 \(f(0^+) = \lim_{s\to\infty}sF\), 최종값 정리 \(f(\infty) = \lim_{s\to0}sF\)(\(sF\)의 극점이 모두 왼쪽 반평면에 있을 때만).

확인 퀴즈

Q1. \(\mathcal{L}\{t^2e^{3t}\}\)은?

\(\mathcal{L}\{t^2\} = 2!/s^3\)에 s-이동(정리 9.8)으로 \(s \to s - 3\). \(e^{3t}\)는 극점을 오른쪽으로 3만큼 옮긴다.

Q2. \(y'' - y = 0\), \(y(0) = 2\), \(y'(0) = 0\)을 변환하면 \(Y(s)\)는?

\(s^2Y - 2s - 0 - Y = 0\)이므로 \(Y = 2s/(s^2-1)\), 즉 \(y = 2\cosh t\). 초기값 정리로 검산: \(\lim_{s\to\infty} sY = 2 = y(0)\).

Q3. \(\mathcal{L}^{-1}\Big\{\dfrac{3}{s(s+3)}\Big\}\)은?

가리기: \(s = 0\)에서 \(3/3 = 1\), \(s = -3\)에서 \(3/(-3) = -1\). 따라서 \(1/s - 1/(s+3)\), \(f = 1 - e^{-3t}\). 정리 9.6으로 보면 \(e^{-3t}\)의 변환 \(1/(s+3)\)을 \(s\)로 나눈 것의 3배이므로 \(3\int_0^te^{-3\tau}d\tau\)와 같다.

Q4. \(F(s) = \dfrac{s + 1}{(s+1)^2 + 16}\)의 역변환과 극점은?

\(\cos 4t \leftrightarrow s/(s^2+16)\)에 \(s \to s + 1\)(\(e^{-t}\) 곱하기). 극점은 \((s+1)^2 = -16\), 즉 \(s = -1 \pm 4i\). 실수부 \(-1\)이 감쇠율, 허수부 4가 각진동수다.

Q5. \(\dfrac{1}{(s-2)^3}\)의 역변환에 나오는 항은?

\(t^n e^{at} \leftrightarrow n!/(s-a)^{n+1}\)에서 \(n = 2\): \(t^2e^{2t} \leftrightarrow 2/(s-2)^3\). 따라서 \(\frac12t^2e^{2t}\). 이미 표의 꼴이라 부분 분수가 필요 없다.

Q6. \(Y(s) = \dfrac{4}{s(s^2 + 2s + 2)}\)일 때 \(\lim_{t\to\infty}y(t)\)는?

\(sY = 4/(s^2+2s+2)\)의 극점은 \(-1 \pm i\)로 왼쪽 반평면에 있으므로 최종값 정리를 쓸 수 있다. \(s \to 0\): \(4/2 = 2\).

Q7. \(Y(s) = \dfrac{1}{s(s^2 + 4)}\)에 최종값 정리를 쓰면 \(\lim_{s\to 0}sY = 1/4\)이다. 실제 \(y(t)\)는?

\(sY = 1/(s^2+4)\)의 극점 \(\pm 2i\)가 허수축 위에 있어 정리 9.12의 조건이 깨진다. 부분 분수로 \(\frac14\cdot\frac1s - \frac14\cdot\frac{s}{s^2+4}\), 즉 \(y = \frac14(1 - \cos 2t)\)는 0과 1/2 사이를 오간다. 1/4은 진동의 평균일 뿐이다.

Q8. 연립 방정식 \(x' = y\), \(y' = -x\)를 라플라스 변환으로 풀 때 \(X(s)\), \(Y(s)\)의 공통 분모는?

\(sX - Y = x_0\), \(X + sY = y_0\)의 행렬식은 \(s^2 + 1 = \det(sI - A)\), \(A = \begin{bmatrix}0&1\\-1&0\end{bmatrix}\). 극점 \(\pm i\)이므로 해는 단진동(원 궤도)이다.
