Chapter 06

2계 선형 방정식

뉴턴의 제2법칙 \(F = ma\)에서 가속도는 위치의 2계 도함수입니다. 그래서 용수철, 진자, 서스펜션, RLC 회로, 건물의 흔들림처럼 관성이 있는 모든 계는 2계 방정식으로 쓰입니다. 1~5장의 1계 방정식은 "지금 위치가 다음 순간을 정한다"였지만, 2계에서는 위치와 속도 두 가지가 함께 미래를 정합니다. 이 장은 그중 가장 중요한 부류인 2계 선형 방정식의 해가 어떤 구조를 가지는지(두 해의 일차결합), 두 해가 정말 다른지 판정하는 법(론스키안), 그리고 계수가 상수일 때 해를 대수 방정식 하나로 찾는 법(특성 방정식)을 다룹니다. 7·8장의 진동과 공진은 모두 이 장의 결과를 물리로 읽는 일입니다.

  • 2계 방정식에 초기 조건이 두 개 필요한 이유를 설명하고, 선형 방정식의 존재·유일성 정리를 쓴다.
  • 선형 연산자 \(L[y] = y'' + py' + qy\)의 선형성에서 중첩 원리를 유도하고, 비선형 방정식에서는 깨지는 것을 확인한다.
  • 론스키안으로 기본해 집합을 판정하고, 아벨 정리로 론스키안이 0이 아닌 상태가 유지됨을 보인다.
  • 상수계수 동차 방정식을 특성 방정식으로 풀고, 서로 다른 실근·중근·복소근의 세 경우를 근의 위치와 해의 모양으로 연결한다.
  • 한 해를 알 때 계수 내리기로 두 번째 해를 구하고, 코시–오일러 방정식을 \(t^m\) 시도와 로그 치환으로 푼다.
  • 같은 방법을 3계 이상의 상수계수 선형 방정식으로 확장한다.
이 수식이 없었다면흔들림이 멈추는 자동차 서스펜션

과속 방지턱을 넘은 차체는 몇 번 출렁이다 멈춥니다. 서스펜션 설계자는 이 출렁임이 몇 번, 얼마나 빨리 사라질지를 부품을 만들기 전에 알아야 합니다. 차체의 위치 \(x\)는 \(mx'' + cx' + kx = 0\)을 따르고, 이 장의 방법은 이 질문을 \(mr^2 + cr + k = 0\)이라는 이차방정식의 근이 어디 있느냐로 바꿉니다. 근이 복소수면 출렁이고, 실수면 출렁이지 않고 가라앉습니다. 근의 실수부가 사라지는 빠르기, 허수부가 출렁이는 진동수입니다.

상수계수 선형 방정식을 지수 함수 \(e^{rt}\)를 대입해 대수 방정식으로 바꾸는 방법은 18세기 오일러(Leonhard Euler)가 체계화했습니다. 같은 생각이 전기 회로의 과도 응답, 제어기의 극점 배치, 구조물의 고유 진동 해석에 그대로 쓰입니다.

F = ma→my″ + cy′ + ky = 0→mr² + cr + k = 0의 근→출렁임의 빠르기와 진동수

2계 방정식과 초기 조건 두 개

같은 위치에서 놓았는데 다르게 움직인다

용수철에 매단 추를 평형점에서 0.5 m 아래로 당겨 가만히 놓을 때와, 같은 자리에서 아래로 툭 쳐서 놓을 때는 운동이 다릅니다. 처음 위치만으로는 미래가 정해지지 않습니다. 몇 가지를 알려 줘야 할까요?

질량 \(m\)인 추에 용수철 힘 \(-ky\)(훅의 법칙)와 속도에 비례하는 저항 \(-cy'\), 그리고 외력 \(F(t)\)가 작용하면 뉴턴의 제2법칙으로 \(my'' = -cy' - ky + F(t)\)입니다. 이를 정리한 꼴이 이 장의 주인공입니다.

정의 6.1 (2계 선형 방정식) 구간 \(I\)에서
$$y'' + p(t)\,y' + q(t)\,y = g(t)$$
꼴의 방정식을 (표준형) 2계 선형 미분방정식이라 한다. \(g \equiv 0\)이면 동차(homogeneous), 아니면 비동차라 한다. \(y\)와 그 도함수가 모두 1차로만, 계수(\(t\)의 함수)와 곱해져서 나타나는 것이 "선형"의 뜻이다. \(a(t)y'' + b(t)y' + c(t)y = f(t)\)는 \(a(t) \ne 0\)인 곳에서 \(a\)로 나누어 표준형으로 만든다.

1계 방정식 \(y' = f(t, y)\)는 한 점 \((t_0, y_0)\)를 주면 방향장을 따라 해곡선이 하나로 정해졌습니다(4장). 2계 방정식은 5장에서 본 것처럼 상태 \((y, y')\)의 1계 연립과 같으므로, 처음 상태, 곧 위치와 속도를 모두 주어야 합니다.

정리 6.2 (선형 방정식의 존재·유일성) \(p, q, g\)가 열린 구간 \(I\)에서 연속이고 \(t_0 \in I\)이면, 임의의 \(y_0, y_1\)에 대해 초기값 문제
$$y'' + p(t)y' + q(t)y = g(t),\qquad y(t_0) = y_0,\quad y'(t_0) = y_1$$
의 해가 구간 \(I\) 전체에서 존재하고 유일하다.

1계 연립으로 바꾸면 피카르–린델뢰프 정리(4장)가 해의 존재와 유일성을 준다. 비선형 방정식과 달리 해가 \(I\) 안에서 폭발하지 않는다는 점(정의 구간이 계수의 연속 구간 전체)이 선형 방정식의 특권이다.

아래 시뮬레이터에서 \(t = 0\)의 점(위치)과 기울기 손잡이(속도)를 따로 끌어 보세요. '해 족 보기'로 같은 위치·다른 속도, 또는 같은 속도·다른 위치의 해들을 함께 그리면 조건 하나로는 해가 정해지지 않는다는 것이 보입니다.

선형성과 중첩 원리

두 해를 더해도 해일까

현악기 줄을 두 가지 방식으로 튕긴 진동을 각각 녹음했습니다. 두 방식으로 동시에 튕기면 소리는 두 녹음을 더한 것과 같을까요? 선형 방정식이면 "예", 비선형이면 "아니요"입니다.

좌변을 함수에 함수를 대응시키는 기계로 보면 편합니다. \(L[y] = y'' + p(t)y' + q(t)y\)라 쓰면 동차 방정식은 \(L[y] = 0\), 비동차는 \(L[y] = g\)입니다. 미분이 선형이므로(\((c_1y_1 + c_2y_2)' = c_1y_1' + c_2y_2'\))

$$L[c_1y_1 + c_2y_2] = c_1L[y_1] + c_2L[y_2].$$
\(L\)이 선형 연산자(linear operator)라는 뜻이다. \(p, q\)가 \(t\)의 함수여도 상관없다. \(y^2\), \(\sin y\), \(yy'\) 같은 항이 있으면 이 등식이 깨진다.
정리 6.3 (중첩 원리) \(y_1, y_2\)가 동차 방정식 \(L[y] = 0\)의 해이면 임의의 상수 \(c_1, c_2\)에 대해 \(c_1y_1 + c_2y_2\)도 해다. 따라서 동차 방정식의 해 전체는 함수들의 벡터 공간을 이룬다(LinearBook: 부분공간).
예제 6.1 (중첩 확인) \(y_1 = \cos 2t\), \(y_2 = \sin 2t\)가 \(y'' + 4y = 0\)의 해임을 보이고, \(y = 3\cos 2t - \sin 2t\)도 해인지 확인하라.
  1. \(y_1'' = -4\cos 2t\)이므로 \(y_1'' + 4y_1 = 0\). 같은 방법으로 \(y_2'' = -4\sin 2t\), \(y_2'' + 4y_2 = 0\).
  2. \(y'' = -12\cos 2t + 4\sin 2t = -4(3\cos 2t - \sin 2t) = -4y\). 해다. 정리 6.3이 계산 없이 보장하는 결과다.
  3. 반례: \(y'' = -y^3\)(비선형)에서 \(y\)가 해라도 \(2y\)는 \((2y)'' = 2y'' = -2y^3 \ne -(2y)^3 = -8y^3\)이라 해가 아니다. 진폭을 두 배로 하면 진동의 빠르기까지 바뀐다.

중첩 원리의 실용적 뜻은 이렇습니다. 처음 상태 \((1, 0)\)에서 출발한 해 \(y_1\)과 \((0, 1)\)에서 출발한 해 \(y_2\)를 한 번씩만 구해 두면, 아무 처음 상태 \((a, b)\)의 해는 \(ay_1 + by_2\)입니다. 이 결합도 해이고 처음 상태가 \((a, b)\)이므로, 정리 6.2의 유일성에 의해 바로 그 해입니다. 아래 시뮬레이터에서 선형 방정식의 결합(주황)이 처음 상태 \((c_1, c_2)\)로 직접 푼 해(검은 가는 선)와 완전히 겹치고, 비선형 방정식에서는 갈라지는 것을 보세요.

기본해 집합과 론스키안, 아벨 정리

중첩 원리는 해 두 개로 많은 해를 만들게 해 주지만, 두 해가 "본질적으로 다를" 때만 모든 해를 만들 수 있습니다. \(y_1 = e^{-t}\)와 \(y_2 = 3e^{-t}\)를 결합하면 \(Ce^{-t}\)밖에 나오지 않습니다.

정의 6.4 (선형 독립, 기본해 집합, 론스키안) 두 함수가 구간 \(I\)에서 \(c_1y_1 + c_2y_2 \equiv 0\)이 \(c_1 = c_2 = 0\)일 때만 성립하면 선형 독립(linearly independent)이라 한다(둘 중 하나가 다른 것의 상수배가 아니라는 뜻). \(L[y] = 0\)의 선형 독립인 두 해의 쌍을 기본해 집합(fundamental set of solutions)이라 한다. 두 함수의 론스키안(Wronskian)은
$$W(y_1, y_2)(t) = \det\begin{bmatrix} y_1 & y_2\\ y_1' & y_2'\end{bmatrix} = y_1y_2' - y_1'y_2.$$

론스키안이 왜 나오는지는 초기 조건을 맞추는 계산에서 보입니다. 일반해 \(y = c_1y_1 + c_2y_2\)가 \(y(t_0) = y_0\), \(y'(t_0) = y_1^0\)을 만족하려면

$$\begin{bmatrix} y_1(t_0) & y_2(t_0)\\ y_1'(t_0) & y_2'(t_0)\end{bmatrix}\begin{bmatrix}c_1\\ c_2\end{bmatrix} = \begin{bmatrix}y_0\\ y_1^0\end{bmatrix}$$
이 연립 일차방정식이 모든 오른쪽 벡터에 대해 풀릴 필요충분조건은 계수 행렬의 행렬식, 곧 \(W(t_0)\)가 0이 아닌 것이다(LinearBook: 행렬식).

기하적으로 \(W(t)\)는 두 해의 상태 벡터 \((y_1, y_1')\)과 \((y_2, y_2')\)이 위상 평면에서 만드는 평행사변형의 부호 있는 넓이입니다. 넓이가 0이 아니면 두 상태 벡터가 평면을 펼치므로 아무 처음 상태든 그 결합으로 쓸 수 있습니다.

정리 6.5 (일반해) \(y_1, y_2\)가 \(I\)에서 \(L[y] = 0\)의 해이고 어떤 \(t_0 \in I\)에서 \(W(y_1, y_2)(t_0) \ne 0\)이면, 이 방정식의 모든 해는 \(y = c_1y_1 + c_2y_2\) 꼴이다. 이것을 일반해(general solution)라 한다. 따라서 해 공간은 정확히 2차원이다.

증명. 아무 해 \(\phi\)를 잡고 \(c_1, c_2\)를 \(c_1y_1 + c_2y_2\)가 \(t_0\)에서 \(\phi\)와 같은 값·같은 도함수를 갖도록 고른다(\(W(t_0) \ne 0\)이라 가능). 두 해가 같은 초기 조건을 가지므로 정리 6.2의 유일성으로 \(\phi \equiv c_1y_1 + c_2y_2\). ∎

그런데 \(W\)가 한 점에서 0이 아니면 다른 점에서는 어떨까요? 해의 론스키안은 스스로 간단한 1계 방정식을 따릅니다. \(W' = y_1y_2'' - y_1''y_2\)에 \(y_i'' = -py_i' - qy_i\)를 넣으면 \(q\) 항은 지워지고 \(W' = -p(y_1y_2' - y_1'y_2) = -pW\)가 남습니다.

정리 6.6 (아벨 정리) \(y_1, y_2\)가 \(I\)에서 \(y'' + p(t)y' + q(t)y = 0\)의 해이면
$$W(t) = W(t_0)\,\exp\!\left(-\int_{t_0}^{t} p(s)\,ds\right).$$
따라서 해의 론스키안은 \(I\)에서 항상 0이거나 한 번도 0이 아니다. 한 점에서만 확인하면 충분하다.
예제 6.2 (론스키안과 아벨 정리) \(t > 0\)에서 \(t^2y'' + 2ty' - 2y = 0\)의 두 해 \(y_1 = t\), \(y_2 = t^{-2}\)에 대해 \(W\)를 계산하고 아벨 정리와 비교하라.
  1. 확인: \(y_2'' = 6t^{-4}\)이므로 \(t^2\cdot 6t^{-4} + 2t\cdot(-2t^{-3}) - 2t^{-2} = (6 - 4 - 2)t^{-2} = 0\). \(y_1 = t\)는 \(0 + 2t - 2t = 0\).
  2. \(W = t\cdot(-2t^{-3}) - 1\cdot t^{-2} = -3t^{-2}\). \(t > 0\)에서 한 번도 0이 아니므로 기본해 집합이다.
  3. 표준형으로 나누면 \(p(t) = 2/t\). 아벨 정리: \(W(t) = W(1)\exp(-\int_1^t 2/s\,ds) = -3\,e^{-2\ln t} = -3t^{-2}\). 일치한다.
주의: 해가 아닌 함수의 론스키안 정리 6.6은 같은 방정식의 해에만 성립합니다. \(y_1 = t^2\), \(y_2 = t|t|\)는 \((-1, 1)\)에서 선형 독립이지만(\(t \gt 0\)에서는 같고 \(t \lt 0\)에서는 부호가 반대) 론스키안이 모든 점에서 0입니다. 연속 계수를 가진 2계 선형 방정식 하나가 이 둘을 모두 해로 가질 수는 없다는 뜻입니다.

상수계수 동차 방정식: 특성 방정식

미분해도 모양이 그대로인 함수

\(ay'' + by' + cy = 0\)은 \(y\)와 \(y'\), \(y''\)의 상수배 합이 0이라는 뜻입니다. 그러려면 \(y\)와 그 도함수들이 서로 상수배 관계여야 합니다. 미분해도 상수배만 되는 함수는? 지수 함수 \(e^{rt}\)입니다.

\(y = e^{rt}\)를 넣으면 \(y' = re^{rt}\), \(y'' = r^2e^{rt}\)이므로 \((ar^2 + br + c)e^{rt} = 0\). \(e^{rt}\)는 0이 아니므로 다음 대수 방정식만 풀면 됩니다.

정의 6.7 (특성 방정식) \(ay'' + by' + cy = 0\)(\(a \ne 0\))에 대해
$$ar^2 + br + c = 0$$
을 특성 방정식(characteristic equation), 그 근을 특성근(characteristic roots)이라 한다. 미분 연산 \(d/dt\)를 문자 \(r\)로 바꿔 쓴 것과 같다. 판별식 \(D = b^2 - 4ac\)의 부호가 세 경우를 가른다.

예제 6.3 (서로 다른 실근) \(y'' + y' - 6y = 0\), \(y(0) = 1\), \(y'(0) = 0\)을 풀어라.
  1. 특성 방정식 \(r^2 + r - 6 = (r - 2)(r + 3) = 0\), 근 \(r = 2, -3\). 일반해 \(y = c_1e^{2t} + c_2e^{-3t}\).
  2. 초기 조건: \(c_1 + c_2 = 1\), \(2c_1 - 3c_2 = 0\). 풀면 \(c_1 = 3/5\), \(c_2 = 2/5\).
  3. \(y = \frac35e^{2t} + \frac25e^{-3t}\). 검산: \(y(1) = 0.6e^2 + 0.4e^{-3} = 4.4533\)이고 RK4로 푼 값과 소수 여섯째 자리까지 같다.
  4. 해석: 근 하나가 양수이므로 처음 상태가 무엇이든(특별히 \(c_1 = 0\)인 경우 빼고) 해는 \(e^{2t}\)로 커진다. 음의 근 \(-3\)의 성분은 금방 사라진다.

복소근의 경우는 오일러 공식 \(e^{i\theta} = \cos\theta + i\sin\theta\)(MathBook: 복소수)로 이해합니다. \(r = \alpha + i\beta\)이면 \(e^{rt} = e^{\alpha t}(\cos\beta t + i\sin\beta t)\)는 복소수 값의 해입니다. \(L\)의 계수가 실수이므로 \(L[u + iv] = L[u] + iL[v] = 0\)에서 실수부 \(u = e^{\alpha t}\cos\beta t\)와 허수부 \(v = e^{\alpha t}\sin\beta t\)가 따로따로 실수 해가 됩니다. 켤레근 \(\alpha - i\beta\)는 같은 두 함수를 주므로 새 정보가 없습니다.

아래 시뮬레이터에서 특성근을 복소평면 위에서 직접 끌어 보세요. 근 하나를 실수축에서 떼어 내면 짝(켤레)이 따라오고, 실수축에 놓으면 두 근이 따로 움직입니다. 오른쪽에 그 근을 가진 방정식과 해가 그려집니다.

중근: 왜 \(te^{rt}\)인가

\(D = 0\)이면 특성근이 \(r = -b/2a\) 하나뿐이라 \(e^{rt}\)라는 해 하나만 얻습니다. 두 번째 해는 어디서 올까요? 두 가지 방법으로 찾을 수 있습니다.

① 극한으로. 서로 다른 두 근 \(r_1 = r - \varepsilon/2\), \(r_2 = r + \varepsilon/2\)를 가진 방정식에서는 \(\dfrac{e^{r_2t} - e^{r_1t}}{r_2 - r_1}\)도 (중첩 원리로) 해입니다. \(\varepsilon \to 0\)이면 이것은 \(e^{rt}\)를 \(r\)에 대해 미분한 것, 곧 \(\dfrac{\partial}{\partial r}e^{rt} = te^{rt}\)로 갑니다. 두 근이 합쳐지는 순간, 두 지수의 차분이 \(t\)를 곱한 지수가 됩니다.

② 직접 대입으로. \(y = v(t)e^{rt}\)라 두면 \(y' = (v' + rv)e^{rt}\), \(y'' = (v'' + 2rv' + r^2v)e^{rt}\). \(ay'' + by' + cy\)에 넣고 정리하면

$$\bigl[a v'' + (2ar + b)v' + (ar^2 + br + c)v\bigr]e^{rt} = 0.$$
중근이면 \(ar^2 + br + c = 0\)이고 \(2ar + b = 0\)(꼭짓점)이므로 \(av'' = 0\), 곧 \(v = c_1 + c_2t\). 두 번째 해 \(te^{rt}\)가 나온다. 이것이 7절 계수 내리기의 특수한 경우다.
예제 6.4 (중근) \(y'' + 4y' + 4y = 0\), \(y(0) = 1\), \(y'(0) = 0\)을 풀어라.
  1. \(r^2 + 4r + 4 = (r + 2)^2 = 0\), 중근 \(r = -2\). 일반해 \(y = (c_1 + c_2t)e^{-2t}\).
  2. \(y(0) = c_1 = 1\). \(y' = (c_2 - 2c_1 - 2c_2t)e^{-2t}\)이므로 \(y'(0) = c_2 - 2 = 0\), \(c_2 = 2\).
  3. \(y = (1 + 2t)e^{-2t}\). \(y(2) = 5e^{-4} = 0.0916\)이고 RK4 결과와 일치한다. 진동하지 않고 한 번도 0을 지나지 않은 채 가라앉는다.

예제 6.5 (복소근) \(y'' + 2y' + 5y = 0\), \(y(0) = 1\), \(y'(0) = 0\)을 풀어라.

예제 6.6 (진폭과 위상) \(y'' + 9y = 0\), \(y(0) = 1\), \(y'(0) = 6\)의 해를 \(R\cos(3t - \phi)\) 꼴로 써라.
  1. \(r = \pm 3i\), 일반해 \(c_1\cos 3t + c_2\sin 3t\). 초기 조건에서 \(c_1 = 1\), \(3c_2 = 6\), \(c_2 = 2\).
  2. \(R\cos(3t - \phi) = R\cos\phi\cos 3t + R\sin\phi\sin 3t\)와 비교하면 \(R\cos\phi = 1\), \(R\sin\phi = 2\). 따라서 \(R = \sqrt5 \approx 2.236\), \(\phi = \arctan 2 \approx 1.107\) rad.
  3. \(y = \sqrt5\cos(3t - 1.107)\). 진폭 \(\sqrt5\)는 처음 위치 1보다 크다. 처음 속도가 있어서 더 멀리까지 간다. 7장의 진폭·위상 표현이다.

용수철 \(y'' + by' + cy = 0\)에서 강성 \(c\)를 고정하고 감쇠 \(b\)를 0부터 키우면 근이 어떻게 움직일까요? \(b \lt 2\sqrt c\)이면 근은 \(-\frac b2 \pm i\sqrt{c - b^2/4}\)이고 \(|r|^2 = \frac{b^2}{4} + c - \frac{b^2}{4} = c\)이므로 반지름 \(\sqrt c\)인 원 위를 왼쪽으로 돕니다. \(b = 2\sqrt c\)에서 두 근이 실수축 \(-\sqrt c\)에서 만나고(중근), 그보다 크면 하나는 0 쪽으로, 하나는 \(-\infty\) 쪽으로 갈라집니다. 이 궤적을 근 경로(root locus)라 합니다.

해가 0으로 가는 빠르기는 가장 오른쪽 근의 실수부가 정합니다. 원 위에서는 \(b\)를 키울수록 실수부 \(-b/2\)가 더 음수가 되어 빨라지지만, 갈라진 뒤에는 오른쪽 근 \(\frac{-b + \sqrt{b^2 - 4c}}{2}\)가 0 쪽으로 다가가 오히려 느려집니다. 그래서 감쇠를 너무 세게 해도 늦게 선다. 지수 감쇠율 \(|\text{Re}\,r|\)이 가장 큰 것은 두 근이 만나는 \(b = 2\sqrt c\), 7장의 임계 감쇠입니다. 다만 "허용 오차 안에 들어오는 시간"으로 재면 살짝 넘쳤다 돌아오는 부족 감쇠가 더 빠를 수 있다는 것을 7장에서 확인합니다.

계수 내리기: 한 해에서 두 번째 해로

계수가 변하면 특성 방정식이 없다

\(t^2y'' + 2ty' - 2y = 0\)처럼 계수가 \(t\)에 의존하면 \(e^{rt}\)를 넣어도 \(t\)가 지워지지 않습니다. 일반적인 방법은 없지만, 운 좋게(또는 추측으로) 해 하나 \(y_1\)을 알면 두 번째 해는 항상 구할 수 있습니다.

중근에서 했던 것처럼 \(y = v(t)\,y_1(t)\)로 두고 \(y'' + py' + qy = 0\)에 넣습니다. \(y' = v'y_1 + vy_1'\), \(y'' = v''y_1 + 2v'y_1' + vy_1''\)이므로

$$v''y_1 + v'(2y_1' + py_1) + v\underbrace{(y_1'' + py_1' + qy_1)}_{=\,0} = 0.$$
\(v\) 자체는 사라지고 \(w = v'\)에 대한 1계 방정식 \(y_1w' + (2y_1' + py_1)w = 0\)이 남는다. 2계가 1계로 "내려간다". 3장의 변수분리(적분 인자)로 풀린다.
정리 6.9 (계수 내리기) \(y_1\)이 \(I\)에서 0이 아닌 \(y'' + p(t)y' + q(t)y = 0\)의 해이면
$$y_2(t) = y_1(t)\int\frac{e^{-\int p(t)\,dt}}{y_1(t)^2}\,dt$$
도 해이고, \(W(y_1, y_2) = e^{-\int p\,dt} \ne 0\)이라 \(y_1, y_2\)는 기본해 집합이다.

유도. \(w' / w = -2y_1'/y_1 - p\)를 적분하면 \(w = y_1^{-2}e^{-\int p}\), \(v = \int w\). 론스키안은 \(W = y_1(vy_1)' - y_1'(vy_1) = y_1^2v' = e^{-\int p}\). 아벨 정리와 같은 꼴이다. ∎

예제 6.7 (계수 내리기) \(y_1 = t\)가 \(t^2y'' + 2ty' - 2y = 0\)(\(t > 0\))의 해임을 이용해 두 번째 해를 구하라.
  1. 표준형: \(y'' + \frac2t y' - \frac{2}{t^2}y = 0\), \(p = 2/t\). \(e^{-\int p} = e^{-2\ln t} = t^{-2}\).
  2. \(v' = \dfrac{t^{-2}}{t^2} = t^{-4}\), \(v = -\frac13t^{-3}\) (상수는 \(y_1\)의 배수를 더할 뿐이라 버린다).
  3. \(y_2 = vy_1 = -\frac13t^{-2}\). 상수배를 버리면 \(y_2 = t^{-2}\). 예제 6.2에서 확인한 해다. 일반해 \(y = c_1t + c_2t^{-2}\).

중근의 \(te^{rt}\)도 이 공식으로 나옵니다. \(y'' + by' + cy = 0\)(\(a = 1\))에서 \(y_1 = e^{rt}\), \(r = -b/2\)이면 \(e^{-\int b} = e^{-bt} = e^{2rt}\)이므로 \(v' = e^{2rt}/e^{2rt} = 1\), \(v = t\)입니다.

코시–오일러 방정식

원판 위의 온도, 축대칭 응력

원형 판의 정상 상태 온도나 두꺼운 원통의 응력을 극좌표로 쓰면 반지름 \(r\)에 대해 \(r^2R'' + rR' - n^2R = 0\) 같은 방정식이 나옵니다. 계수가 변수의 거듭제곱과 차수가 맞게 곱해져 있습니다. 이런 방정식은 특성 방정식과 거의 같은 방법으로 풀립니다.

정의 6.10 (코시–오일러 방정식) \(t > 0\)에서
$$at^2y'' + bty' + cy = 0\qquad(a, b, c\ \text{상수})$$
꼴을 코시–오일러 방정식(Cauchy–Euler equation) 또는 등차원 방정식이라 한다. \(t\)의 크기를 몇 배로 바꿔도(\(t \to kt\)) 방정식 모양이 그대로다.

\(t\)를 곱할 때마다 미분이 한 번씩 붙어 있으므로 \(t^m\)이 알맞은 시도입니다. \(y = t^m\)이면 \(ty' = mt^m\), \(t^2y'' = m(m - 1)t^m\)이므로

$$am(m - 1) + bm + c = 0 \quad\Longleftrightarrow\quad am^2 + (b - a)m + c = 0.$$
이 방정식을 지표 방정식(indicial equation)이라 부른다(14장 프로베니우스 방법의 이름). \(b\)가 아니라 \(b - a\)가 1차 계수라는 점에 주의.

더 깊은 이유는 치환 \(t = e^s\)(\(s = \ln t\))입니다. 연쇄 법칙으로 \(t\frac{dy}{dt} = \frac{dy}{ds}\), \(t^2\frac{d^2y}{dt^2} = \frac{d^2y}{ds^2} - \frac{dy}{ds}\)이므로 방정식은 상수계수 방정식 \(a\ddot Y + (b - a)\dot Y + cY = 0\)이 됩니다(점은 \(s\)에 대한 미분). 그래서 4절의 세 경우가 \(e^{ms} = t^m\)으로 그대로 옮겨 옵니다.

정리 6.11 (코시–오일러 방정식의 일반해) 지표 방정식의 근에 따라 \(t > 0\)에서
  • 서로 다른 실근 \(m_1, m_2\): \(y = c_1t^{m_1} + c_2t^{m_2}\)
  • 중근 \(m\): \(y = (c_1 + c_2\ln t)\,t^m\)
  • 복소근 \(\alpha \pm i\beta\): \(y = t^\alpha\bigl(c_1\cos(\beta\ln t) + c_2\sin(\beta\ln t)\bigr)\)
예제 6.8 (코시–오일러, 세 경우)
  1. \(t^2y'' - 2y = 0\): \(m(m - 1) - 2 = (m - 2)(m + 1) = 0\), \(y = c_1t^2 + c_2t^{-1}\). \(y(1) = 1\), \(y'(1) = 0\)이면 \(c_1 + c_2 = 1\), \(2c_1 - c_2 = 0\)에서 \(y = \frac13t^2 + \frac23t^{-1}\), \(y(3) = 3 + \frac29 = 3.2222\)(RK4와 일치).

고계 선형 방정식 맛보기

지금까지의 이야기는 \(n\)계로 그대로 확장됩니다. \(y^{(n)} + p_{n-1}(t)y^{(n-1)} + \cdots + p_0(t)y = 0\)의 초기값 문제에는 \(y, y', \dots, y^{(n-1)}\)의 처음 값 \(n\)개가 필요하고, 해 공간은 \(n\)차원이며, \(n\)개의 해가 기본해 집합인지는 \(n \times n\) 론스키안 \(\det[y_j^{(i)}]\)으로 판정합니다.

정리 6.12 (상수계수 n계 동차 방정식) \(a_ny^{(n)} + \cdots + a_1y' + a_0y = 0\)의 특성 다항식 \(a_nr^n + \cdots + a_1r + a_0\)의 근 \(r\)이 중복도 \(k\)를 가지면 \(e^{rt}, te^{rt}, \dots, t^{k-1}e^{rt}\)가 해이고, 복소근 \(\alpha \pm i\beta\)(중복도 \(k\))는 \(t^je^{\alpha t}\cos\beta t\), \(t^je^{\alpha t}\sin\beta t\)(\(j = 0, \dots, k - 1\))를 준다. 이렇게 얻은 \(n\)개의 함수가 기본해 집합이다.
예제 6.9 (3계 방정식) \(y''' - 6y'' + 11y' - 6y = 0\), \(y(0) = 0\), \(y'(0) = 0\), \(y''(0) = 2\)를 풀어라.
  1. 특성 다항식 \(r^3 - 6r^2 + 11r - 6 = (r - 1)(r - 2)(r - 3)\). 일반해 \(y = c_1e^t + c_2e^{2t} + c_3e^{3t}\).
  2. 초기 조건: \(c_1 + c_2 + c_3 = 0\), \(c_1 + 2c_2 + 3c_3 = 0\), \(c_1 + 4c_2 + 9c_3 = 2\). 풀면 \(c_1 = 1\), \(c_2 = -2\), \(c_3 = 1\).
  3. \(y = e^t - 2e^{2t} + e^{3t} = e^t(e^t - 1)^2\). \(y(1) = 8.0257\)(RK4와 일치). 계수 행렬이 반데르몽드 행렬이라 근이 서로 다르면 항상 풀린다.

공학에서 가장 흔한 고계 방정식은 보의 처짐 \(EI\,y'''' = w(x)\)(4계)입니다. 동차 부분 \(y'''' = 0\)은 특성근 0이 4중근이라 해가 \(1, x, x^2, x^3\)이고, 양 끝의 지지 조건 네 개(처짐·기울기·모멘트·전단력)가 이 넷의 계수를 정합니다. 또 \(y'''' - k^4y = 0\)(진동하는 보)은 근이 \(\pm k, \pm ik\)라 해가 \(e^{kx}, e^{-kx}, \cos kx, \sin kx\)의 결합입니다. 고계 방정식은 결국 1계 연립(11장)으로 바꾸어 행렬의 고유값 문제로 보는 것이 가장 깔끔합니다. 특성 다항식이 바로 그 행렬의 특성 다항식입니다.

핵심 정리

  1. 2계 방정식의 상태는 위치와 속도의 쌍이라 초기 조건이 두 개 필요하다. \(p, q, g\)가 \(I\)에서 연속이면 선형 초기값 문제의 해는 \(I\) 전체에서 존재하고 유일하다.
  2. \(L[y] = y'' + py' + qy\)는 선형 연산자다. 동차 방정식의 해들의 일차결합도 해(중첩 원리)이고, 해 공간은 2차원 벡터 공간이다. 비선형 방정식에서는 중첩이 깨진다.
  3. 론스키안 \(W = y_1y_2' - y_1'y_2\)는 상태 벡터 두 개가 만드는 넓이다. 한 점에서 \(W \ne 0\)이면 기본해 집합이고 모든 해가 \(c_1y_1 + c_2y_2\)다. 아벨 정리 \(W = W(t_0)e^{-\int p}\) 때문에 해의 론스키안은 늘 0이거나 한 번도 0이 아니다.
  4. 상수계수 \(ay'' + by' + cy = 0\)은 \(e^{rt}\)를 넣어 특성 방정식 \(ar^2 + br + c = 0\)으로 푼다. 실근 \(r_1 \ne r_2\): \(c_1e^{r_1t} + c_2e^{r_2t}\), 중근: \((c_1 + c_2t)e^{rt}\), 복소근 \(\alpha \pm i\beta\): \(e^{\alpha t}(c_1\cos\beta t + c_2\sin\beta t)\).
  5. 근의 실수부는 성장·감쇠, 허수부는 진동수다. 모든 근이 왼쪽 반평면에 있으면 모든 해가 0으로 간다. 감쇠 b를 키우면 근은 반지름 √c인 원을 돌아 \(b = 2\sqrt c\)에서 만난 뒤 갈라지고, 지수 감쇠율이 가장 큰 것은 그 만나는 점이다(허용 띠 안 정착 시간은 7장에서 따로 본다).
  6. 중근의 \(te^{rt}\)는 두 근이 합쳐지는 극한(\(\partial_r e^{rt}\))이자 계수 내리기의 결과다. 해 하나 \(y_1\)을 알면 \(y_2 = y_1\int e^{-\int p}/y_1^2\,dt\).
  7. 코시–오일러 방정식 \(at^2y'' + bty' + cy = 0\)은 \(t^m\)을 넣어 지표 방정식 \(am^2 + (b - a)m + c = 0\)으로 풀며, \(s = \ln t\)로 바꾸면 상수계수 방정식이다. 중근은 \(t^m\ln t\), 복소근은 \(t^\alpha\cos(\beta\ln t)\)를 준다.
  8. n계 상수계수 방정식은 특성 다항식의 근으로 풀고, 중복도 k인 근은 \(t^je^{rt}\)(\(j \lt k\))를 준다.

확인 퀴즈

Q1. \(y'' - 4y = 0\)의 일반해는?

특성 방정식 \(r^2 - 4 = 0\), \(r = \pm 2\)(서로 다른 실근). \(c_1\cos 2t + c_2\sin 2t\)는 \(y'' + 4y = 0\)의 해다.

Q2. \(y'' + 6y' + 9y = 0\), \(y(0) = 2\), \(y'(0) = -5\)의 해는?

\((r + 3)^2 = 0\), 중근 −3. \(y = (c_1 + c_2t)e^{-3t}\), \(y(0) = c_1 = 2\), \(y'(0) = c_2 - 3c_1 = c_2 - 6 = -5\)이므로 \(c_2 = 1\). \(y'(0)\)이 곧 \(c_2\)는 아니라는 점에 주의.

Q3. \(y'' + 4y' + 13y = 0\)의 해는 어떤 모양인가?

\(r = \frac{-4 \pm\sqrt{16 - 52}}{2} = -2 \pm 3i\). \(\alpha = -2\)는 포락선 \(e^{-2t}\), \(\beta = 3\)은 각진동수라 주기 \(2\pi/3\).

Q4. \(W(e^t, te^t)\)는?

\(e^t\cdot(e^t + te^t) - e^t\cdot te^t = e^{2t}\). 한 번도 0이 아니므로 \(y'' - 2y' + y = 0\)의 기본해 집합이다. 아벨 정리로도 \(p = -2\)에서 \(W = Ce^{2t}\).

Q5. \(t > 0\)에서 \(y'' + \frac1t y' + q(t)y = 0\)의 두 해의 론스키안이 \(W(1) = 3\)이다. \(W(3)\)은?

아벨 정리: \(W(t) = W(1)\exp(-\int_1^t ds/s) = 3/t\). \(W(3) = 1\). \(q\)는 공식에 나타나지 않는다.

Q6. \(t^2y'' + ty' - 9y = 0\)(\(t > 0\))의 일반해는?

지표 방정식 \(m(m - 1) + m - 9 = m^2 - 9 = 0\), \(m = \pm 3\). 코시–오일러 방정식의 해는 지수가 아니라 거듭제곱이다.

Q7. 연속 계수 \(p, q\)를 가진 \(y'' + py' + qy = 0\)의 두 해에 대해 \((-1, 1)\)에서 론스키안이 될 수 없는 것은?

아벨 정리에 따라 해의 론스키안은 \(W(t_0)e^{-\int p}\) 꼴이라 구간에서 항상 0이거나 한 번도 0이 아니다. \(W = t\)는 \(t = 0\)에서만 0이라 불가능하다.

Q8. \(y_1\), \(y_2\)가 모두 \(y'' + y = \sin t\)의 해일 때 옳은 것은?

\(L[y_1 - y_2] = \sin t - \sin t = 0\). 반면 \(L[y_1 + y_2] = 2\sin t\)라 비동차 방정식의 해는 더해서 같은 방정식의 해가 되지 않는다. 이것이 8장의 "일반해 = 동차해 + 특수해 하나"의 근거다.
