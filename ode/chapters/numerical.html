수치 해법

2~4장에서 푼 방정식은 운이 좋은 경우였습니다. 변수가 분리되거나, 선형이거나, 적분 인자가 보였습니다. \(y' = t - y^2\)처럼 한 글자만 바꿔도 기본 함수로 쓸 수 있는 해는 사라집니다. 그래도 4장의 존재·유일성 정리는 해가 있다고 말해 줍니다. 이 장은 그 해를 숫자로 만드는 법입니다. 1장에서 맛본 오일러 방법, 곧 "지금의 기울기로 조금 걷기"를 출발점으로 삼아, 왜 그것이 느린지(오차 차수 1), 기울기를 몇 번 더 재면 얼마나 빨라지는지(룽게–쿠타 4차), 걸음 폭을 스스로 고르는 법(적응 간격), 그리고 걸음 폭을 아무리 줄여도 터지는 방정식(강성)과 오래 돌리면 에너지가 새는 궤도(심플렉틱 적분)까지 다룹니다.

  • 오일러 방법을 테일러 전개로 유도하고, 국소 절단 오차 \(O(h^2)\)가 전역 오차 \(O(h)\)로 쌓이는 과정을 설명한다.
  • 오차–간격 로그–로그 그래프의 기울기로 방법의 차수를 읽고, 계산 비용과 정확도를 비교한다.
  • 개선 오일러(호인), 중점법, 룽게–쿠타 4차의 기울기 조합을 그림으로 이해하고 한 걸음을 손으로 계산한다.
  • 고계 방정식을 1계 연립으로 바꾸어 같은 방법을 벡터에 적용한다.
  • 내장 쌍으로 국소 오차를 추정해 걸음 폭을 자동으로 조절하는 원리를 안다.
  • 시험 방정식 \(y' = \lambda y\)로 안정성 영역을 그리고, 강성 방정식에서 음적 오일러가 필요한 이유와 심플렉틱 방법이 에너지를 지키는 이유를 설명한다.

대기의 운동 방정식, 행성 세 개가 서로 끌어당기는 삼체 문제, 트랜지스터 수천 개가 얽힌 회로의 방정식은 손으로 풀리는 꼴이 아닙니다. 삼체 문제는 일반적인 경우 기본 함수로 쓸 수 있는 해가 없다고 알려져 있습니다. 그런데도 우리는 내일의 기압 배치를 예보하고, 탐사선을 수년 뒤의 행성 근처로 보내고, 칩을 만들기 전에 회로를 시뮬레이션합니다. 모두 "지금 상태와 변화율에서 조금 뒤의 상태를 계산하고, 이를 수백만 번 되풀이하는" 수치 적분 덕분입니다.

이 아이디어의 뿌리는 오일러(Leonhard Euler)의 18세기 적분학 교재에 있고, 기울기를 한 걸음 안에서 여러 번 재는 방법은 19세기 말 룽게(Carl Runge)가 제안하고 20세기 초 쿠타(Martin Wilhelm Kutta)가 체계화했습니다. 오늘날 MATLAB의 ode45나 SciPy의 solve_ivp 기본값은 이 계열에 걸음 폭 자동 조절을 더한 방법입니다.

y′ = f(t, y)→기울기로 한 걸음→yₙ₊₁ = yₙ + h·(기울기의 가중 평균)→예보·궤도·회로 시뮬레이션

오일러 방법과 국소·전역 오차

걸음을 반으로 줄이면 오차는 얼마나 줄까

1장에서 오일러 방법으로 \(y' = y\), \(y(0) = 1\)을 \(h = 0.1\)로 풀면 \(y(1) \approx 2.5937\)이었습니다. 참값 \(e = 2.7183\)과 0.12만큼 차이가 납니다. 소수 넷째 자리까지 맞추려면 \(h\)를 얼마로 해야 할까요? 그러려면 오차가 \(h\)에 따라 어떤 법칙으로 줄어드는지 알아야 합니다.

초기값 문제 \(y' = f(t, y)\), \(y(t_0) = y_0\)의 해를 시각 \(t_n = t_0 + nh\)에서의 근삿값 \(y_n\)으로 구합니다. \(h\)를 걸음 폭(step size)이라 합니다. 해 \(y(t)\)를 \(t_n\)에서 테일러 전개하면(CalculusBook 12장)

$$y(t_n + h) = y(t_n) + h\,y'(t_n) + \frac{h^2}{2}y''(\xi_n) = y(t_n) + h\,f(t_n, y(t_n)) + \frac{h^2}{2}y''(\xi_n)$$
\(\xi_n\)은 \(t_n\)과 \(t_{n+1}\) 사이의 어떤 점(테일러 정리의 라그랑주 나머지). 미분방정식 덕분에 \(y'\)은 \(f\)로 바로 계산된다.

마지막 항을 버리고, 모르는 \(y(t_n)\) 대신 이미 계산한 \(y_n\)을 넣은 것이 오일러 방법입니다.

정의 5.1 (오일러 방법) 걸음 폭 \(h\)와 \(t_n = t_0 + nh\)에 대해
$$y_{n+1} = y_n + h\,f(t_n, y_n), \qquad n = 0, 1, 2, \dots$$
로 근삿값을 만드는 방법을 (전진) 오일러 방법이라 한다. 한 걸음에 \(f\)를 한 번 계산한다.

버린 항이 오차의 원천입니다. 그런데 오차에는 두 종류가 있다는 것을 구별해야 합니다. 한 걸음에서 새로 생기는 오차와, 지금까지 쌓인 오차입니다.

정의 5.2 (국소 절단 오차와 전역 오차) \(u_n(t)\)를 점 \((t_n, y_n)\)을 지나는 미분방정식의 정확한 해라 하자. 한 걸음의 국소 절단 오차(local truncation error)는 \(\tau_{n+1} = u_n(t_{n+1}) - y_{n+1}\), 곧 맞는 점에서 출발해 한 걸음만 걸었을 때의 오차다. 전역 오차(global error)는 원래 해와의 차이 \(E_n = y(t_n) - y_n\)이다.

국소 오차는 위의 테일러 나머지 그 자체라서 \(|\tau_{n+1}| \le \frac{M}{2}h^2\)(\(M = \max|y''|\))입니다. 구간 \([t_0, T]\)를 지나려면 \(N = (T - t_0)/h\)걸음이 필요하니, 국소 오차를 그냥 더하면 \(N\cdot\frac{M}{2}h^2 = \frac{M(T - t_0)}{2}h\), 즉 \(h\)의 1제곱입니다. 실제로는 앞선 오차가 다음 걸음에서 해곡선의 벌어짐에 따라 커지거나 줄어드므로 한 가지 인자가 더 붙습니다.

정리 5.3 (오일러 방법의 오차) \(f\)가 \(y\)에 대해 립시츠 상수 \(L\)을 가지고(\(|f(t, y) - f(t, z)| \le L|y - z|\)), 해가 \(|y''| \le M\)을 만족하면 \(t_n \le T\)인 모든 \(n\)에 대해
$$|E_n| = |y(t_n) - y_n| \le \frac{Mh}{2L}\left(e^{L(t_n - t_0)} - 1\right).$$

증명의 핵심. 참 해의 테일러 전개에서 오일러 식을 빼면 \(E_{n+1} = E_n + h\bigl(f(t_n, y(t_n)) - f(t_n, y_n)\bigr) + \frac{h^2}{2}y''(\xi_n)\). 립시츠 조건으로 \(|E_{n+1}| \le (1 + hL)|E_n| + \frac{M}{2}h^2\). 이 부등식을 \(E_0 = 0\)부터 되풀이하면 등비수열의 합 \(\frac{M}{2}h^2\cdot\frac{(1 + hL)^n - 1}{hL}\)이 나오고, \(1 + hL \le e^{hL}\)을 쓰면 위 식이다. ∎

정리의 메시지는 둘입니다. 첫째, 전역 오차는 \(h\)에 비례합니다. \(h\)를 반으로 줄이면 오차도 반이 됩니다. 국소 오차는 \(h^2\)인데 걸음 수가 \(1/h\)이므로 하나가 깎입니다. 둘째, \(e^{L(t - t_0)}\) 인자 때문에 해곡선이 서로 벌어지는 방정식(\(\partial f/\partial y > 0\))에서는 오래 적분할수록 오차가 지수적으로 커질 수 있습니다. 해곡선이 모이는 방정식에서는 이 상한이 지나치게 비관적입니다.

예제 5.1 (오차가 h에 비례하는지 확인) \(y' = y\), \(y(0) = 1\)을 오일러 방법으로 풀어 \(y(1)\)을 근사하라. \(h = 0.1\)과 \(h = 0.05\)를 비교하라.
  1. \(f = y\)이므로 \(y_{n+1} = y_n + hy_n = (1 + h)y_n\), 곧 \(y_N = (1 + h)^N\)이다.
  2. \(h = 0.1\), \(N = 10\): \(1.1^{10} = 2.593742\). 오차 \(e - 2.593742 = 0.124539\).
  3. \(h = 0.05\), \(N = 20\): \(1.05^{20} = 2.653298\). 오차 \(0.064984\).
  4. 비율 \(0.124539 / 0.064984 = 1.92\). \(h\)를 반으로 줄였더니 오차가 거의 반이 되었다. 오차 \(10^{-4}\)를 원하면 \(h\)를 약 \(0.1\times 0.1245/10^{-4} \approx 10^{-4}\)까지, 즉 1만 걸음 가까이 줄여야 한다. 오일러 방법이 "정확하지만 느리다"는 말의 정량적 뜻이다.

오차 차수: 로그–로그 그래프의 기울기

정리 5.3은 오일러 방법의 오차가 \(Ch\) 꼴이라는 것을 말합니다. 더 좋은 방법은 \(Ch^2\), \(Ch^4\)처럼 \(h\)의 더 높은 거듭제곱으로 줄어듭니다. 이 지수를 방법의 차수라 합니다.

정의 5.4 (방법의 차수) 충분히 매끄러운 \(f\)에 대해 국소 절단 오차가 \(O(h^{p+1})\)이고, 따라서 고정된 구간에서 전역 오차가 \(|E_N| \le Ch^p\)이면 그 방법을 p차 방법(method of order p)이라 한다. 오일러 방법은 1차다.

\(E \approx Ch^p\)의 양변에 로그를 취하면 \(\log E \approx \log C + p\log h\). 그래서 오차를 \(h\)에 대해 로그–로그 눈금으로 그리면 직선이 되고, 그 기울기가 차수 \(p\)입니다. 두 간격 \(h\)와 \(h/2\)의 오차만 있어도 \(p \approx \log_2(E_h / E_{h/2})\)로 차수를 추정할 수 있습니다. 예제 5.1에서 \(\log_2 1.92 = 0.94\), 1에 가깝습니다.

이 기울기는 새 프로그램을 검증하는 가장 강력한 도구입니다. RK4를 구현했는데 기울기가 4가 아니라 1로 나오면 어딘가에 버그가 있습니다(흔히 \(k_2\)를 계산할 때 \(t + h/2\) 대신 \(t\)를 넣은 경우). 반대로 \(h\)를 너무 줄이면 오차가 더 이상 줄지 않고 들쭉날쭉해지는 바닥이 나타납니다. 컴퓨터의 실수가 약 16자리만 저장하기 때문에 생기는 반올림 오차로, 걸음 수가 많을수록 쌓입니다(MathBook: 컴퓨터는 어떻게 틀리는가).

개선 오일러(호인)와 중점법

기울기를 한 번 더 재면

오일러 방법은 구간의 왼쪽 끝 기울기만 씁니다. 해가 휘어 있으면 걸음 내내 그 기울기가 틀려 갑니다. 적분에서 왼쪽 직사각형 합보다 사다리꼴 공식이나 중점 공식이 훨씬 정확했던 것(CalculusBook 7장)과 같은 처방을 쓸 수 있지 않을까요?

미분방정식을 한 걸음 적분하면 \(y(t_{n+1}) = y(t_n) + \int_{t_n}^{t_{n+1}} f(t, y(t))\,dt\)입니다. 오일러 방법은 이 적분을 왼쪽 직사각형으로 근사한 것입니다. 사다리꼴 공식을 쓰면 오른쪽 끝의 기울기 \(f(t_{n+1}, y_{n+1})\)이 필요한데, 그 \(y_{n+1}\)이 바로 지금 구하려는 값입니다. 해결책은 오일러로 먼저 어림해서(예측) 그 점의 기울기를 재고, 평균을 쓰는(수정) 것입니다.

정의 5.5 (호인 방법과 중점법)

개선 오일러(호인) 방법(Heun's method): 예측–수정 두 단계.

$$k_1 = f(t_n, y_n),\quad k_2 = f(t_n + h,\ y_n + hk_1),\quad y_{n+1} = y_n + \frac{h}{2}(k_1 + k_2).$$

중점법(midpoint method): 반 걸음 가서 기울기를 잰 뒤 그 기울기로 처음부터 한 걸음.

$$k_1 = f(t_n, y_n),\quad k_2 = f\!\left(t_n + \tfrac{h}{2},\ y_n + \tfrac{h}{2}k_1\right),\quad y_{n+1} = y_n + hk_2.$$
둘 다 한 걸음에 \(f\)를 두 번 계산하는 2단 룽게–쿠타 방법이다.

왜 2차일까요? 참 해의 테일러 전개를 2차 항까지 쓰면 \(y(t + h) = y + hf + \frac{h^2}{2}(f_t + f_y f) + O(h^3)\)입니다(연쇄 법칙으로 \(y'' = f_t + f_y y' = f_t + f_y f\)). 한편 호인의 \(k_2\)를 전개하면 \(k_2 = f + h(f_t + f_y f) + O(h^2)\)이므로 \(y + \frac{h}{2}(k_1 + k_2) = y + hf + \frac{h^2}{2}(f_t + f_y f) + O(h^3)\). 2차 항까지 정확히 일치합니다.

정리 5.6 (2단 방법의 2차 조건) \(y_{n+1} = y_n + h(b_1k_1 + b_2k_2)\), \(k_2 = f(t_n + ch,\ y_n + chk_1)\) 꼴의 방법이 2차일 필요충분조건은 \(b_1 + b_2 = 1\), \(b_2c = \frac12\)이다. 호인은 \(b_1 = b_2 = \frac12, c = 1\), 중점법은 \(b_1 = 0, b_2 = 1, c = \frac12\)이다. 국소 오차는 \(O(h^3)\), 전역 오차는 \(O(h^2)\)이다.

룽게–쿠타 4차: 기울기 네 개의 가중 평균

같은 생각을 더 밀고 나가면, 한 걸음 안에서 기울기를 네 번 재서 테일러 전개의 4차 항까지 맞출 수 있습니다. 이것이 공학 계산의 표준 도구인 룽게–쿠타 4차 방법(classical Runge–Kutta, RK4)입니다.

정의 5.7 (RK4)
$$\begin{aligned} k_1 &= f(t_n,\ y_n), & k_2 &= f\!\left(t_n + \tfrac{h}{2},\ y_n + \tfrac{h}{2}k_1\right),\\ k_3 &= f\!\left(t_n + \tfrac{h}{2},\ y_n + \tfrac{h}{2}k_2\right), & k_4 &= f(t_n + h,\ y_n + hk_3),\end{aligned}$$ $$y_{n+1} = y_n + \frac{h}{6}\left(k_1 + 2k_2 + 2k_3 + k_4\right).$$
\(k_1\): 왼쪽 끝, \(k_2\): \(k_1\)로 반 걸음 간 중점, \(k_3\): \(k_2\)로 다시 반 걸음 간 중점, \(k_4\): \(k_3\)로 한 걸음 간 오른쪽 끝의 기울기. 한 걸음에 \(f\)를 네 번 계산한다.

가중치 \(1, 2, 2, 1\)(합 6)이 낯익습니다. \(f\)가 \(t\)에만 의존하면(\(y' = f(t)\)) \(k_2 = k_3 = f(t_n + h/2)\)이고 RK4는 \(\frac{h}{6}\bigl(f(t_n) + 4f(t_n + \frac h2) + f(t_n + h)\bigr)\), 바로 심프슨 공식입니다. 심프슨 공식이 4차인 것처럼 RK4도 4차입니다.

정리 5.8 (RK4는 4차) \(f\)가 충분히 매끄러우면 RK4의 국소 절단 오차는 \(O(h^5)\), 전역 오차는 \(O(h^4)\)이다.

선형 방정식에서 확인. 일반적인 증명은 다변수 테일러 전개의 긴 계산이지만, \(y' = \lambda y\)에서는 바로 보인다. \(z = h\lambda\)라 하면 \(hk_1 = zy_n\), \(hk_2 = z(1 + \frac z2)y_n\), \(hk_3 = z(1 + \frac z2 + \frac{z^2}{4})y_n\), \(hk_4 = z(1 + z + \frac{z^2}{2} + \frac{z^3}{4})y_n\). 가중 평균을 정리하면 \(y_{n+1} = \left(1 + z + \frac{z^2}{2} + \frac{z^3}{6} + \frac{z^4}{24}\right)y_n\)이고, 이는 참 해의 한 걸음 인자 \(e^z\)의 테일러 다항식 4차까지와 정확히 같다. 차이는 \(z^5/120\)부터다. ∎

큰 각도로 흔들리는 진자의 주기

길이 \(L\)인 진자의 각도는 \(\theta'' = -\frac{g}{L}\sin\theta\)를 따릅니다. 작은 각도에서는 \(\sin\theta \approx \theta\)로 단진동(7장)이 되어 주기가 \(2\pi\sqrt{L/g}\)이지만, 90°에서 놓으면 얼마일까요? 이 방정식은 2계이고 비선형입니다. 지금까지의 방법은 1계 스칼라 방정식용이었습니다.

요령은 두 가지입니다. 첫째, 고계 방정식은 1계 연립으로 바꿉니다. 각도 \(\theta\)와 각속도 \(\omega = \theta'\)를 함께 상태로 보면 \(\theta' = \omega\), \(\omega' = -\frac{g}{L}\sin\theta\)입니다. 일반적으로 \(y^{(m)} = F(t, y, y', \dots, y^{(m-1)})\)은 \(\mathbf{u} = (y, y', \dots, y^{(m-1)})\)로 두면 \(\mathbf{u}' = \mathbf{f}(t, \mathbf{u})\) 꼴의 1계 연립이 됩니다(11장에서 다시 씁니다). 둘째, 오일러·호인·RK4의 식은 그대로 벡터에 적용됩니다. \(y_n\)을 벡터 \(\mathbf{u}_n\)으로, \(f\)를 벡터 함수로 읽기만 하면 됩니다.

적응 간격: 걸음 폭을 스스로 고르기

혜성은 태양 근처에서만 빠르다

이심률이 큰 타원 궤도를 도는 혜성은 태양에서 멀 때는 느릿느릿 움직이다가 근일점을 순식간에 지나갑니다. 고정된 \(h\)를 쓰면 근일점에 맞춰 \(h\)를 아주 작게 해야 하는데, 그러면 궤도 대부분에서 걸음을 낭비합니다. 어려운 곳에서만 촘촘히 걸을 수는 없을까요?

걸음 폭을 고르려면 지금 걸음의 오차를 알아야 하는데, 참 해를 모르니 오차를 직접 잴 수는 없습니다. 대신 차수가 다른 두 방법으로 같은 걸음을 계산해 그 차이를 오차의 추정값으로 씁니다. 차수가 높은 쪽이 훨씬 정확하므로 차이는 거의 낮은 쪽의 오차입니다.

정의 5.9 (내장 쌍과 걸음 폭 조절) 같은 기울기 \(k_1, \dots, k_s\)를 다른 가중치로 조합해 \(p\)차 근사 \(y_{n+1}\)과 \(p + 1\)차 근사 \(\hat y_{n+1}\)을 함께 만드는 룽게–쿠타 공식을 내장 쌍(embedded pair)이라 한다. 오차 추정 \(\mathrm{err} = |\hat y_{n+1} - y_{n+1}|\)를 허용 오차 \(\mathrm{tol}\)과 비교해
  • \(\mathrm{err} \le \mathrm{tol}\)이면 걸음을 받아들이고(정확한 쪽 \(\hat y\)를 쓴다),
  • 그렇지 않으면 버리고 더 작은 \(h\)로 다시 시도한다.
  • 어느 경우든 다음 걸음 폭은 \(h_{\text{new}} = 0.9\,h\,(\mathrm{tol}/\mathrm{err})^{1/(p+1)}\)로 정한다.

마지막 식의 뜻은 간단합니다. 국소 오차가 \(Ch^{p+1}\)에 비례하므로, 오차를 \(\mathrm{tol}\)로 맞추려면 \(h\)에 \((\mathrm{tol}/\mathrm{err})^{1/(p+1)}\)을 곱하면 됩니다. 0.9는 다음 걸음이 다시 버려지지 않도록 두는 안전 계수입니다. 실무의 표준은 6단 공식 안에 4차와 5차 근사를 함께 담은 RK45 계열이며, ode45와 solve_ivp의 기본값인 도르만드–프린스 쌍(Dormand–Prince)도 그중 하나입니다.

안정성 영역과 강성, 음적 오일러

정확도는 충분한데 해가 터진다

회로에 아주 빨리 사라지는 과도 성분(시상수 1 μs)과 천천히 변하는 신호(주기 1 ms)가 함께 있습니다. 우리가 보고 싶은 것은 느린 신호뿐이라 \(h = 10\) μs면 충분해 보입니다. 그런데 오일러 방법으로 돌리면 몇 걸음 만에 값이 \(10^{30}\)으로 튑니다. 이미 사라진 빠른 성분이 왜 계산을 망칠까요?

이 현상을 이해하는 열쇠는 가장 단순한 방정식, 시험 방정식 \(y' = \lambda y\)입니다. \(\lambda\)는 복소수일 수도 있습니다(진동하는 성분). 실수부가 음수면 참 해 \(e^{\lambda t}\)는 0으로 줄어듭니다. 수치 해도 줄어드는가가 질문입니다. 앞 절의 계산처럼 어떤 룽게–쿠타 방법도 이 방정식에서는 \(y_{n+1} = R(z)\,y_n\), \(z = h\lambda\) 꼴이 됩니다.

정의 5.10 (안정성 함수와 절대 안정 영역) 시험 방정식에 적용한 한 걸음 인자 \(R(z)\)를 그 방법의 안정성 함수(stability function), 복소평면에서 \(|R(z)| \le 1\)인 \(z = h\lambda\)의 집합을 절대 안정 영역(region of absolute stability)이라 한다.
$$R_{\text{오일러}} = 1 + z,\quad R_{\text{호인}} = 1 + z + \tfrac{z^2}{2},\quad R_{\text{RK4}} = 1 + z + \tfrac{z^2}{2} + \tfrac{z^3}{6} + \tfrac{z^4}{24},\quad R_{\text{음적 오일러}} = \frac{1}{1 - z}.$$
정리 5.11 (오일러 방법의 안정 조건) 오일러 방법의 절대 안정 영역은 \(-1\)을 중심으로 하는 반지름 1인 원판 \(|1 + z| \le 1\)이다. 특히 \(\lambda \lt 0\)인 실수이면 수치 해가 줄어들 조건은
$$h \le \frac{2}{|\lambda|}$$
이고, \(h > 2/|\lambda|\)이면 \(|y_n| = |1 + h\lambda|^n|y_0|\)가 부호를 바꾸며 지수적으로 커진다. 순허수 \(\lambda = i\omega\)(감쇠 없는 진동)에서는 어떤 \(h > 0\)도 \(|1 + i h\omega| > 1\)이라 진폭이 항상 커진다.

RK4의 영역은 더 넓어서 실수축에서는 \(-2.785 \le z \le 0\), 허수축에서는 \(|z| \le 2\sqrt2 \approx 2.83\)까지 안정합니다. 그래도 크기가 유한하다는 점은 같습니다. 명시적 방법(다음 값을 이미 아는 값으로만 계산하는 방법)의 \(R(z)\)는 다항식이고, 다항식은 \(|z| \to \infty\)에서 커지므로 영역은 언제나 유한합니다.

정의 5.12 (강성) 해의 관심 있는 부분은 천천히 변하는데, 방정식(의 야코비안)에 실수부가 크게 음수인 고유값이 있어서 명시적 방법의 걸음 폭이 정확도가 아니라 안정성 때문에 제한되는 문제를 강성(stiff) 문제라 한다. 시상수의 비가 클수록(예: 1 μs와 1 ms) 강성이 심하다.

처방은 오른쪽 끝의 기울기를 쓰는 것입니다. \(y_{n+1} = y_n + hf(t_{n+1}, y_{n+1})\)은 구하려는 \(y_{n+1}\)이 양변에 있는 방정식이라 매 걸음 그것을 풀어야 합니다(선형이면 나눗셈 한 번, 비선형이면 뉴턴 반복). 대신 시험 방정식에서 \(y_{n+1} = y_n + hλy_{n+1}\), 곧 \(R(z) = 1/(1 - z)\)이고, \(\operatorname{Re}z \lt 0\)이면 \(|1 - z| > 1\)이라 언제나 \(|R| \lt 1\)입니다.

정리 5.13 (음적 오일러는 A-안정) 음적 오일러 방법(backward Euler) \(y_{n+1} = y_n + h f(t_{n+1}, y_{n+1})\)의 절대 안정 영역은 왼쪽 반평면 \(\operatorname{Re} z \le 0\)을 모두 포함한다. 이런 방법을 A-안정(A-stable)이라 한다. 따라서 감쇠하는 성분이 아무리 빨라도 \(h\)는 정확도만으로 고를 수 있다. 정확도는 오일러와 같은 1차다.
예제 5.5 (강성 방정식, λ = 50) 위 방정식을 \(t = 2\)까지 풀어 참값 \(y(2) = \cos 2 - e^{-100} = -0.41615\)와 비교하라.

  2. 오일러 \(h = 0.03\) (\(h\lambda = 1.5\)): \(y(2) \approx -0.4253\). 안정하다.

에너지 보존: 심플렉틱 오일러와 궤도 계산

행성이 태양에서 멀어진다

원 궤도를 도는 행성을 오일러 방법으로 \(h = 0.05\)(한 바퀴에 약 126걸음)로 계산하면 열 바퀴 뒤 궤도 반지름이 1에서 3.09로 커집니다. 걸음을 줄이면 늦출 수는 있지만, 오래 돌리면 결국 행성은 날아가 버립니다. 물리 법칙은 에너지를 보존하는데 왜 수치 해는 그러지 않을까요?

용수철 \(x'' = -x\)(위상 평면의 원 운동)에서 정확히 계산해 볼 수 있습니다. 오일러 방법은 \(x_{n+1} = x_n + hv_n\), \(v_{n+1} = v_n - hx_n\)이고, 에너지 \(x^2 + v^2\)를 계산하면

$$x_{n+1}^2 + v_{n+1}^2 = (x_n + hv_n)^2 + (v_n - hx_n)^2 = (1 + h^2)\,(x_n^2 + v_n^2).$$
교차항 \(2hx_nv_n\)이 서로 지워진다. 매 걸음 에너지가 정확히 \(1 + h^2\)배가 된다. 정리 5.11의 순허수 경우 \(|1 + ih|^2 = 1 + h^2\)와 같은 이야기다.

\(h = 0.1\)로 100걸음(\(t = 10\), 1.6바퀴)이면 \(1.01^{100} = 2.70\)배, 에너지가 거의 세 배가 됩니다. 이제 아주 작은 수정을 해 봅시다. 속도를 먼저 갱신하고, 새 속도로 위치를 갱신합니다.

정의 5.14 (심플렉틱 오일러) \(x'' = a(x)\)(가속도가 위치에만 의존)에 대해
$$v_{n+1} = v_n + h\,a(x_n),\qquad x_{n+1} = x_n + h\,v_{n+1}$$
로 걷는 방법을 심플렉틱 오일러(symplectic Euler) 또는 반음적 오일러라 한다. 계산량은 오일러와 똑같고 차수도 1차다.

\(x'' = -x\)에서 한 걸음은 행렬 \(\begin{bmatrix}x_{n+1}\\v_{n+1}\end{bmatrix} = \begin{bmatrix}1 - h^2 & h\\ -h & 1\end{bmatrix}\begin{bmatrix}x_n\\v_n\end{bmatrix}\)이고 행렬식은 \((1 - h^2) + h^2 = 1\)입니다. 오일러 행렬 \(\begin{bmatrix}1 & h\\ -h & 1\end{bmatrix}\)의 행렬식은 \(1 + h^2\)입니다. 행렬식이 1이라는 것은 위상 평면의 넓이를 보존한다는 뜻이고(LinearBook: 행렬식), 이것이 2차원에서 "심플렉틱"의 의미입니다. 참 해의 흐름도 넓이를 보존하는데(해밀턴 계의 리우빌 정리), 오일러는 이 성질을 깨고 심플렉틱 오일러는 지킵니다.

정리 5.15 (심플렉틱 오일러의 보존량) \(x'' = -x\)에 심플렉틱 오일러를 쓰면 \(|h| \lt 2\)일 때 수정된 에너지
$$\tilde E = x_n^2 + v_n^2 - h\,x_nv_n$$
가 모든 \(n\)에서 정확히 일정하다. 따라서 참 에너지 \(x^2 + v^2\)는 \(h\)에 비례하는 폭으로 진동할 뿐 한 방향으로 새지 않는다.

확인. \(x' = (1 - h^2)x + hv\), \(v' = -hx + v\)를 \(x'^2 + v'^2 - hx'v'\)에 넣어 전개하면 \(x^2\)의 계수는 \((1 - h^2)^2 + h^2 + h(1 - h^2)h = 1\), \(v^2\)의 계수는 \(h^2 + 1 - h^2 = 1\), \(xv\)의 계수는 \(2h(1 - h^2) - 2h - h(1 - h^2) + h^3 = -h\)이다. ∎

RK4는 어떨까요? 정확도가 높아 에너지 오차가 매우 작지만 심플렉틱은 아닙니다. \(x'' = -x\)에서 \(|R(ih)|^2 = 1 - h^6/72 + h^8/576\)이라 에너지가 매 걸음 아주 조금씩 줄어듭니다(\(h = 0.1\)이면 걸음당 \(1.4\times10^{-8}\)). 짧은 계산에서는 RK4가 압도적으로 낫지만, 수억 걸음을 도는 태양계 장기 적분이나 분자 동역학에서는 이 꾸준한 표류가 문제가 되어 심플렉틱 방법(속도 베를레 등)을 씁니다. 게임 물리 엔진이 흔히 반음적 오일러를 쓰는 것도 같은 이유입니다.

핵심 정리

  1. 오일러 방법 \(y_{n+1} = y_n + hf(t_n, y_n)\)은 테일러 전개를 1차에서 자른 것이다. 국소 절단 오차는 \(O(h^2)\), 걸음 \(1/h\)개가 쌓인 전역 오차는 \(O(h)\)이고, 상한에 \(e^{L(t - t_0)}\) 인자가 붙는다.
  2. 전역 오차가 \(Ch^p\)이면 p차 방법이다. 오차–간격 로그–로그 그래프의 기울기가 p이고, \(\log_2(E_h/E_{h/2})\)로 추정한다. 너무 작은 h에서는 반올림 오차의 바닥이 나타난다.
  3. 호인(예측–수정, 사다리꼴)과 중점법은 기울기 두 개로 2차, RK4는 기울기 네 개 \((k_1 + 2k_2 + 2k_3 + k_4)/6\)로 4차다. \(y' = f(t)\)이면 RK4는 심프슨 공식이다.
  4. 고계 방정식은 상태 벡터 \((y, y', \dots)\)의 1계 연립으로 바꾸면 같은 공식이 벡터에 그대로 적용된다.
  5. 적응 간격은 내장 쌍(4차·5차)의 차이로 국소 오차를 추정하고 \(h \leftarrow 0.9h(\mathrm{tol}/\mathrm{err})^{1/5}\)로 걸음을 조절한다. 어려운 구간에서만 촘촘히 걷는다.
  6. 시험 방정식 \(y' = \lambda y\)에서 \(y_{n+1} = R(h\lambda)y_n\). 오일러는 \(|1 + h\lambda| \le 1\), 실수 \(\lambda \lt 0\)이면 \(h \le 2/|\lambda|\). 명시적 방법의 안정 영역은 유한하다.
  7. 강성 문제는 사라진 빠른 성분이 걸음 폭을 묶는 문제다. 음적 오일러 \(R = 1/(1 - z)\)는 A-안정이라 h를 정확도만으로 고를 수 있다.
  8. 오일러는 용수철의 에너지를 매 걸음 \(1 + h^2\)배로 키운다. 심플렉틱 오일러는 위상 평면의 넓이를 보존하고 수정된 에너지를 정확히 지켜, 장기 궤도 계산에서 에너지가 새지 않는다.

확인 퀴즈

Q1. 오일러 방법으로 \(h = 0.02\)일 때 \(y(1)\)의 오차가 \(0.008\)이었다. \(h = 0.005\)로 줄이면 오차는 대략?

오일러는 1차라 전역 오차가 h에 비례한다. h가 1/4이 되면 오차도 약 1/4, 0.008/4 = 0.002. 0.0005는 2차 방법(1/16)일 때의 답이다.

Q2. 어떤 방법의 오차를 로그–로그 그래프에 그렸더니 \(h = 0.1\)에서 \(3.2\times10^{-5}\), \(h = 0.05\)에서 \(2.0\times10^{-6}\)이었다. 이 방법의 차수는?

비율 3.2×10⁻⁵ / 2.0×10⁻⁶ = 16 = 2⁴. h를 반으로 줄여 오차가 16분의 1이 되었으므로 4차다. RK4가 이렇게 행동한다.

Q3. \(y' = 2y\), \(y(0) = 1\)에 호인 방법을 \(h = 0.5\)로 한 걸음 쓰면 \(y_1\)은?

\(k_1 = 2\), 예측점 \(y = 1 + 0.5\cdot 2 = 2\)에서 \(k_2 = 4\). \(y_1 = 1 + 0.25(2 + 4) = 2.5\). \(R(z) = 1 + z + z^2/2\)에 \(z = 1\)을 넣은 값과 같다. 참값은 \(e^1 = 2.718\).

Q4. RK4가 \(y' = f(t)\)(우변이 \(y\)에 무관)에 적용되면 어떤 적분 공식과 같아지는가?

\(k_2 = k_3 = f(t_n + h/2)\)이므로 \(\frac h6(f_n + 4f_{n+1/2} + f_{n+1})\), 심프슨 공식이다. 호인은 사다리꼴, 중점법은 중점 공식, 오일러는 왼쪽 직사각형에 대응한다.

Q5. \(y' = -200y\)를 명시적 오일러로 안정하게 풀 수 있는 가장 큰 걸음 폭은?

\(|1 + h\lambda| \le 1\), \(\lambda = -200\)이면 \(0 \le 200h \le 2\), 곧 \(h \le 0.01\). h = 0.005는 진동 없이 줄어드는 조건 \(h\lambda \ge -1\)이다. 음적 오일러를 쓰면 제한이 없다.

Q6. 강성 문제에 대한 설명으로 옳은 것은?

강성은 정확도 때문이 아니라 안정성 때문에 h가 작아야 하는 상황이다. 해 자체는 매끄러운데, 큰 음의 고유값이 명시적 방법의 안정 영역 밖으로 hλ를 밀어낸다. 처방은 음적(A-안정) 방법이다.

Q7. \(x'' = -x\)를 오일러 방법 \(h = 0.2\)로 50걸음 계산하면 에너지 \(x^2 + v^2\)는 처음의 몇 배가 되는가?

매 걸음 정확히 \(1 + h^2 = 1.04\)배가 된다. \(1.04^{50} = 7.11\). 심플렉틱 오일러를 쓰면 \(x^2 + v^2 - hxv\)가 정확히 보존되어 에너지는 일정한 띠 안에 머문다.

Q8. 적응 간격 4(5)차 쌍에서 오차 추정이 허용 오차의 32배였다. 안전 계수를 빼면 다음 시도의 걸음 폭은 지금의 몇 배인가?

국소 오차가 \(h^5\)에 비례하므로 \(h_{\text{new}} = h(\mathrm{tol}/\mathrm{err})^{1/5} = h\cdot(1/32)^{1/5} = h/2\). 오차가 32배 크면 걸음을 반으로 줄이면 된다. 이 걸음은 버리고 다시 계산한다.
