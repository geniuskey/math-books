급수해와 특수 함수

6장의 상수계수 방정식은 \(e^{rt}\)를 넣으면 특성 방정식이 나와 깔끔하게 풀렸습니다. 그런데 원형 막, 구형 물체 둘레의 퍼텐셜, 선형 퍼텐셜 속의 양자 입자를 다루면 계수가 \(x\)에 따라 변하는 방정식 \(y'' + p(x)y' + q(x)y = 0\)이 나오고, 지수 함수는 더 이상 해가 아닙니다. 이 장의 생각은 단순합니다. 해를 모르면 해를 거듭제곱 급수 \(\sum a_nx^n\)로 두고 계수를 하나씩 정하자. 방정식이 계수 사이의 점화식으로 바뀌고, 그 점화식이 낳은 급수가 에어리 함수, 르장드르 다항식, 베셀 함수 같은 특수 함수가 됩니다.

  • 보통점에서 거듭제곱 급수를 대입하고 첨자를 맞춰 점화식을 세우고, 첫 몇 항으로 해를 쓴다.
  • 에어리 방정식 \(y'' = xy\)를 급수로 풀고, \(x > 0\)의 지수적 행동과 \(x \lt 0\)의 진동을 설명한다.
  • 급수해의 수렴 반지름이 복소평면에서 가장 가까운 특이점까지의 거리 이상임을 쓰고, 실수축에 특이점이 없는데도 수렴이 멈추는 이유를 말한다.
  • 정칙 특이점을 판별하고 지표 방정식으로 프로베니우스 해 \(x^r\sum a_nx^n\)의 지수 \(r\)을 구하며, 근의 차가 정수일 때 로그 항이 생길 수 있음을 안다.
  • 르장드르 방정식에서 다항식 해 \(P_\ell\)이 나오는 이유와 직교성 \(\int_{-1}^1 P_mP_n\,dx = \frac{2}{2n+1}\delta_{mn}\)을 확인한다.
  • 베셀 함수 \(J_\nu\)의 급수와 영점을 구하고, 원형 북의 고유 진동수 \(\omega_{nm} = c\,j_{nm}/a\)로 잇는다.
이 수식이 없었다면원형 진동판의 설계

스피커 콘, 마이크와 압력 센서의 원형 진동판, 팀파니와 북은 모두 가장자리가 고정된 원형 막입니다. 어떤 진동수로 울리는지, 진동판의 어디가 가만히 있는지(마디선)를 알아야 소리와 감도를 설계할 수 있습니다. 직사각형 막이라면 사인 함수로 끝나지만, 원형 막을 극좌표로 변수분리하면 반지름 방향에서 \(r^2R'' + rR' + (k^2r^2 - n^2)R = 0\)이라는, 계수가 \(r\)에 따라 변하는 방정식이 나옵니다.

이 방정식의 해는 사인·지수 같은 기본 함수로 쓸 수 없습니다. 급수로 풀어 얻은 함수에 베셀(Friedrich Wilhelm Bessel)의 이름이 붙었습니다. 베셀은 천문학자로서 행성 운동의 섭동 계산에서 이 함수들을 체계적으로 연구했습니다. 원형 막의 고유 진동수는 베셀 함수의 영점으로 정해지고, 그 비가 정수가 아니어서 북은 현악기처럼 또렷한 음높이를 내지 않습니다.

보통점에서의 거듭제곱 급수 해

특성 방정식이 통하지 않는 방정식

\(y'' - xy' - y = 0\)에 \(y = e^{rx}\)를 넣으면 \(r^2 - xr - 1 = 0\)이 됩니다. \(r\)이 \(x\)에 따라 달라져야 하니 \(e^{rx}\)는 해가 아닙니다. 6장의 방법은 계수가 상수라서 통했던 것입니다. 그래도 해는 있습니다(4장의 존재 정리). 그 해를 어떻게 손에 쥘까요?

12장 미적분의 테일러 전개(CalculusBook 테일러 전개)를 떠올립시다. 매끄러운 함수는 한 점 근처에서 \(y = \sum_{n\ge0} a_n(x - x_0)^n\)으로 쓸 수 있고, \(a_n = y^{(n)}(x_0)/n!\)입니다. 해가 이런 급수라고 가정하고 방정식에 넣어 \(a_n\)을 정하는 것이 급수해법입니다. 먼저 이 방법이 언제 통하는지 정합니다.

정의 14.1 (보통점과 특이점) \(P(x)y'' + Q(x)y' + R(x)y = 0\)을 \(y'' + p(x)y' + q(x)y = 0\)(\(p = Q/P,\ q = R/P\))으로 쓴다. \(p\)와 \(q\)가 \(x_0\)에서 해석적이면(\(x_0\) 근처에서 수렴하는 거듭제곱 급수로 쓸 수 있으면) \(x_0\)을 보통점(ordinary point), 그렇지 않으면 특이점(singular point)이라 한다. 다항식 계수이면 \(P(x_0) \ne 0\)인 점이 보통점이다.

보통점 \(x_0 = 0\)에서의 계산 순서는 늘 같습니다.

  1. \(y = \sum a_nx^n\), \(y' = \sum na_nx^{n-1}\), \(y'' = \sum n(n-1)a_nx^{n-2}\)을 넣는다.
  2. 각 합의 첨자를 옮겨 모든 항을 \(x^n\)의 계수로 맞춘다(\(y''\)의 합은 \(n \to n + 2\)).
  3. 모든 \(n\)에 대해 \(x^n\)의 계수가 0이어야 한다(거듭제곱 급수의 유일성). 이것이 점화식이다.
  4. \(a_0 = y(0)\), \(a_1 = y'(0)\)는 자유롭고, 나머지는 점화식이 정한다. 2계 방정식의 일반해에 상수가 둘인 것과 맞는다.
예제 14.1 (상수계수 방정식을 급수로: \(y'' + y = 0\)) 급수로 풀어 이미 아는 답과 맞는지 확인하라.
  1. \(y'' = \sum_{n\ge0}(n+2)(n+1)a_{n+2}x^n\)이므로 \(\sum\bigl[(n+2)(n+1)a_{n+2} + a_n\bigr]x^n = 0\).
  2. 점화식: \(a_{n+2} = -\dfrac{a_n}{(n+2)(n+1)}\). 짝수 첨자는 \(a_0\)에서, 홀수 첨자는 \(a_1\)에서만 나온다.
  3. \(a_2 = -\frac{a_0}{2!}\), \(a_4 = \frac{a_0}{4!}\), …, \(a_3 = -\frac{a_1}{3!}\), \(a_5 = \frac{a_1}{5!}\), …
  4. \(y = a_0\bigl(1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \cdots\bigr) + a_1\bigl(x - \frac{x^3}{3!} + \cdots\bigr) = a_0\cos x + a_1\sin x\). 특성 방정식과 같은 답이다.
예제 14.2 (\(y'' - xy' - y = 0\)) 문제의 방정식을 풀어라.
  1. \(xy' = \sum na_nx^n\)은 첨자를 옮길 필요가 없다. 따라서 \(\sum\bigl[(n+2)(n+1)a_{n+2} - na_n - a_n\bigr]x^n = 0\).
  2. 점화식: \((n+2)(n+1)a_{n+2} = (n+1)a_n\), 즉 \(a_{n+2} = \dfrac{a_n}{n+2}\).
  3. 짝수: \(a_2 = \frac{a_0}{2}\), \(a_4 = \frac{a_0}{2\cdot4}\), \(a_{2k} = \frac{a_0}{2^k k!}\). 따라서 \(y_1 = \sum\frac{(x^2/2)^k}{k!} = e^{x^2/2}\). 대입해 보면 \(y_1' = xy_1\), \(y_1'' = (1 + x^2)y_1\)이고 \(y_1'' - xy_1' - y_1 = 0\)이 맞다.
  4. 홀수: \(a_3 = \frac{a_1}{3}\), \(a_5 = \frac{a_1}{15}\), \(a_7 = \frac{a_1}{105}\), … 이므로 \(y_2 = x + \frac{x^3}{3} + \frac{x^5}{15} + \frac{x^7}{105} + \cdots\). 이 급수는 기본 함수로 깔끔히 쓰이지 않지만(오차 함수와 관련), 급수 자체가 해다.
  5. 수치 확인: \(y(0) = 1,\ y'(0) = 0\)으로 RK4를 \(x = 1.5\)까지 적분하면 3.080217, \(e^{1.125} = 3.080217\).

아래 시뮬레이터에서 항의 개수 \(N\)을 늘려 가며 부분합이 참 해(수치 적분)에 붙어 가는 모습을 보세요. 부분합은 \(x = 0\) 근처에서 먼저 맞고, 항이 늘수록 맞는 구간이 바깥으로 넓어집니다. 다만 마지막 예인 \((1 - x)y' = y\)에서는 아무리 늘려도 \(|x| \lt 1\) 밖으로 나가지 못합니다. 그 이유가 3절의 주제입니다.

에어리 방정식: 진동과 감쇠가 만나는 곳

무지개 가장자리의 밝기

기하 광학은 무지개 각도에서 빛이 무한히 밝다고 예측합니다. 광선이 모이는 경계(꼭짓점, 코스틱)에서 광선 수가 갑자기 바뀌기 때문입니다. 실제 무지개는 유한하게 밝고, 안쪽에 희미한 띠(과잉 무지개)가 줄지어 있습니다. 1838년 에어리(George Biddell Airy)는 코스틱 근처 빛의 세기를 파동으로 계산하며 지금 그의 이름이 붙은 적분을 다루었습니다. 같은 방정식이 기울어진 퍼텐셜 속의 양자 입자에도 나옵니다.

$$y'' = xy.$$
\(x > 0\)이면 \(y''\)이 \(y\)와 같은 부호라 해가 지수처럼 휘어 나가고, \(x \lt 0\)이면 반대 부호라 \(y'' + |x|y = 0\)인 진동이 된다. 한 방정식 안에 두 성격이 \(x = 0\)을 경계로 붙어 있다.

\(x = 0\)은 보통점입니다(계수가 다항식). 급수를 넣으면 \(y'' = \sum(n+2)(n+1)a_{n+2}x^n\), \(xy = \sum a_{n-1}x^n\)(\(n \ge 1\))이므로 \(x^0\)의 계수에서 \(2a_2 = 0\), 나머지에서

$$a_{n+2} = \frac{a_{n-1}}{(n+2)(n+1)} \quad (n \ge 1), \qquad a_2 = 0.$$
세 칸 점화식: \(a_0 \to a_3 \to a_6 \to \cdots\), \(a_1 \to a_4 \to a_7 \to \cdots\), \(a_2 = a_5 = a_8 = \cdots = 0\).
예제 14.3 (에어리 방정식의 두 기본해) 두 기본해의 첫 세 항을 구하라.
  1. \(a_0 = 1,\ a_1 = 0\): \(a_3 = \frac{1}{3\cdot2} = \frac16\), \(a_6 = \frac{a_3}{6\cdot5} = \frac{1}{180}\), \(a_9 = \frac{a_6}{9\cdot8} = \frac{1}{12960}\). \(y_1 = 1 + \frac{x^3}{6} + \frac{x^6}{180} + \frac{x^9}{12960} + \cdots\).
  2. \(a_0 = 0,\ a_1 = 1\): \(a_4 = \frac{1}{4\cdot3} = \frac1{12}\), \(a_7 = \frac{a_4}{7\cdot6} = \frac1{504}\). \(y_2 = x + \frac{x^4}{12} + \frac{x^7}{504} + \cdots\).
  3. 분모가 \(n^2\)처럼 자라므로 계수는 계승보다 빨리 줄고, 두 급수는 모든 \(x\)에서 수렴한다.
  4. 물리에서 쓰는 표준 해는 \(x \to +\infty\)에서 0으로 가는 에어리 함수 \(\mathrm{Ai}(x) = c_1y_1 - c_2y_2\)와, 커지는 \(\mathrm{Bi}(x)\)이다. 여기서 \(c_1 = \mathrm{Ai}(0) \approx 0.35503\), \(c_2 = -\mathrm{Ai}'(0) \approx 0.25882\). 급수로 계산한 \(\mathrm{Ai}(1) = 0.135292\)는 표의 값과 여섯 자리까지 같다.

\(x \lt 0\)에서 진동의 "국소 진동수"는 \(\sqrt{|x|}\)입니다. \(y'' + |x|y = 0\)에서 \(|x|\)를 잠시 상수로 보면 \(\cos(\sqrt{|x|}\,x)\) 꼴이기 때문입니다. 그래서 왼쪽으로 갈수록 진동이 빨라지고, 진폭은 에너지 보존 비슷한 논리로 \(|x|^{-1/4}\)처럼 줄어듭니다. 정밀한 근사(WKB)는 \(\mathrm{Ai}(x) \approx \pi^{-1/2}|x|^{-1/4}\sin\bigl(\tfrac23|x|^{3/2} + \tfrac\pi4\bigr)\)입니다. \(\mathrm{Ai}\)의 영점은 \(-2.338,\ -4.088,\ -5.521, \dots\)으로 점점 촘촘해집니다.

급수가 끝나야 한다: 에르미트 방정식과 양자화

원자 속 용수철의 에너지는 왜 띄엄띄엄한가

분자의 결합은 작은 진동에서 용수철처럼 행동합니다. 양자역학에서 이 진동자의 파동 함수는 슈뢰딩거 방정식을 따르고, 무차원 변수로 쓰면 \(\psi'' + (\varepsilon - x^2)\psi = 0\)이 됩니다. 파동 함수는 \(x \to \pm\infty\)에서 0으로 가야 확률로 해석할 수 있습니다. 이 조건 하나가 에너지 \(\varepsilon\)를 띄엄띄엄한 값으로 묶습니다. 급수해가 그 이유를 가장 직접적으로 보여 줍니다.

큰 \(|x|\)에서 \(\psi'' \approx x^2\psi\)이므로 \(\psi \approx e^{-x^2/2}\)처럼 줄어드는 해를 기대하고 \(\psi = y(x)e^{-x^2/2}\)로 두면, \(y\)는 에르미트 방정식을 만족합니다.

$$y'' - 2xy' + 2\lambda y = 0, \qquad \varepsilon = 2\lambda + 1.$$
점화식: \(a_{n+2} = \dfrac{2(n - \lambda)}{(n+2)(n+1)}\,a_n\).

급수가 끝나지 않으면 큰 \(n\)에서 \(a_{n+2}/a_n \approx 2/n\)인데, 이것은 \(e^{x^2} = \sum\frac{x^{2k}}{k!}\)의 계수 비와 같습니다. 그러면 \(y \sim e^{x^2}\)이 되어 \(\psi = ye^{-x^2/2} \sim e^{x^2/2}\)가 무한대로 커집니다. 파동 함수가 0으로 가려면 급수가 다항식으로 끝나야 하고, 그러려면 \(\lambda = n\)이 0 이상의 정수여야 합니다. 따라서 \(\varepsilon = 2n + 1\), 즉 진동자의 에너지는 \(\hbar\omega\bigl(n + \tfrac12\bigr)\)로 양자화됩니다.

예제 14.4 (λ = 4의 다항식 해) \(\lambda = 4\)일 때 짝수 해를 구하라.
  1. \(a_0 = 1\): \(a_2 = \frac{2(0 - 4)}{2\cdot1} = -4\), \(a_4 = \frac{2(2 - 4)}{4\cdot3}a_2 = -\frac13\cdot(-4) = \frac43\), \(a_6 = \frac{2(4 - 4)}{6\cdot5}a_4 = 0\).
  2. \(y = 1 - 4x^2 + \frac43x^4\). 최고차 계수를 \(2^4 = 16\)으로 맞추면 물리학에서 쓰는 에르미트 다항식 \(H_4 = 16x^4 - 48x^2 + 12\)이다(\(12y\)).
  3. 검산: \(y'' - 2xy' + 8y = (-8 + 16x^2) - 2x(-8x + \frac{16}{3}x^3) + 8 - 32x^2 + \frac{32}{3}x^4 = 0\).

르장드르 방정식에서 "극에서 유한"이라는 조건이 \(\lambda\)를 정수로 묶은 것과 똑같은 구조입니다. 경계 조건이 매개변수를 고유값으로 바꾸는 이 현상은 15장의 고유값 문제에서 일반 이론이 됩니다. 앞 절의 점화식 계수표 시뮬레이터에서 에르미트를 골라 λ를 정수와 비정수로 바꿔 보세요.

수렴 반지름과 특이점까지의 거리

실수축에 아무 문제가 없는데 수렴이 멈춘다

\((1 + x^2)y'' + 2xy' = 0\)은 모든 실수 \(x\)에서 \(1 + x^2 \ne 0\)이라 특이점이 없어 보입니다. 그런데 \(x = 0\)에서 급수로 풀면 그 급수는 \(|x| \lt 1\)에서만 수렴합니다. 1이라는 숫자는 어디서 왔을까요?

답은 복소평면에 있습니다. \(1 + x^2 = 0\)은 \(x = \pm i\)에서 성립하고, 원점에서 \(\pm i\)까지의 거리가 1입니다. 거듭제곱 급수는 원판 위에서 수렴하므로, 실수축 위의 구간이 아니라 복소평면의 원이 수렴 범위를 정합니다.

정리 14.2 (급수해의 존재와 수렴 반지름) \(x_0\)이 \(y'' + p(x)y' + q(x)y = 0\)의 보통점이고 \(p, q\)의 \(x_0\) 둘레 급수가 \(|x - x_0| \lt R\)에서 수렴하면, 임의의 \(a_0, a_1\)에 대해 해 \(y = \sum a_n(x - x_0)^n\)이 유일하게 존재하고 이 급수도 \(|x - x_0| \lt R\)에서 수렴한다. 특히 \(p, q\)가 다항식의 비이면 수렴 반지름은 \(x_0\)에서 복소평면의 가장 가까운 특이점까지의 거리 이상이다.
예제 14.5 (아크탄젠트를 낳는 방정식) \((1 + x^2)y'' + 2xy' = 0,\ y(0) = 0,\ y'(0) = 1\)을 풀고 \(x_0\)에서의 수렴 반지름을 구하라.
  1. 왼쪽은 \(\bigl((1 + x^2)y'\bigr)'\)이다. 따라서 \((1 + x^2)y' = C\), \(y' = \frac{C}{1 + x^2}\), \(y = C\arctan x + D\). 초기 조건으로 \(y = \arctan x\).
  2. 급수: \(\arctan x = x - \frac{x^3}{3} + \frac{x^5}{5} - \cdots\). 계수의 크기가 \(1/n\)이므로 반지름은 1이고, 실제로 \(x = 1.2\)에서 부분합은 진동하며 발산한다.
  3. 정리 14.2: 특이점은 \(\pm i\). \(x_0\) 둘레 급수의 반지름은 \(|x_0 - i| = \sqrt{1 + x_0^2}\) 이상이고, \(\arctan\)이 \(\pm i\)에서 실제로 발산하므로 정확히 \(\sqrt{1 + x_0^2}\)이다. \(x_0 = 1\)이면 \(\sqrt2 \approx 1.414\).
  4. 수치 확인: \(x_0 = 1\) 둘레 급수 40항을 \(x = 1.5\)에서 더하면 0.9827937, \(\arctan 1.5 = 0.9827937\).

같은 이유로 르장드르 방정식 \((1 - x^2)y'' - 2xy' + \lambda(\lambda + 1)y = 0\)의 원점 둘레 급수는 특이점 \(x = \pm1\) 때문에 반지름이 1이고, 에어리·에르미트처럼 계수가 다항식이고 \(P(x) = 1\)인 방정식은 특이점이 없어 반지름이 무한대입니다. 아래 시뮬레이터에서 전개 중심 \(x_0\)을 끌어 수렴 원이 커지고 작아지는 것을 보세요.

정칙 특이점과 지표 방정식

원판의 중심에서

원형 막의 반지름 방정식 \(r^2R'' + rR' + (k^2r^2 - n^2)R = 0\)을 \(R''\)의 계수로 나누면 \(p = 1/r\), \(q = k^2 - n^2/r^2\)이라 중심 \(r = 0\)이 특이점입니다. 그런데 우리가 가장 알고 싶은 곳이 바로 막의 중심입니다. 특이점에서는 거듭제곱 급수 해가 없을 수도 있습니다. 해가 \(r^{-n}\)처럼 터지거나 \(\ln r\)을 품을 수 있기 때문입니다.

모든 특이점이 다루기 어려운 것은 아닙니다. 6장의 코시–오일러 방정식 \(x^2y'' + p_0xy' + q_0y = 0\)은 \(x = 0\)이 특이점이지만 \(y = x^r\)을 넣으면 \(r(r - 1) + p_0r + q_0 = 0\)이 되어 바로 풀렸습니다. 특이점 근처에서 방정식이 코시–오일러 방정식처럼 생겼다면, 해도 \(x^r\) 곱하기 급수처럼 생겼으리라 기대할 수 있습니다.

정의 14.3 (정칙 특이점과 지표 방정식) \(x_0 = 0\)이 \(y'' + p(x)y' + q(x)y = 0\)의 특이점이고, \(xp(x)\)와 \(x^2q(x)\)가 0에서 해석적이면 0을 정칙 특이점(regular singular point)이라 한다. 그렇지 않은 특이점은 비정칙(irregular) 특이점이다. \(p_0 = \lim_{x\to0}xp(x)\), \(q_0 = \lim_{x\to0}x^2q(x)\)로 놓은
$$r(r - 1) + p_0r + q_0 = 0$$
을 지표 방정식(indicial equation), 그 근 \(r_1 \ge r_2\)(실수일 때)를 지표라 한다.
예제 14.6 (\(2xy'' + y' + y = 0\)) 0이 정칙 특이점임을 보이고 두 해를 구하라.
  1. \(p = \frac{1}{2x}\), \(q = \frac{1}{2x}\). \(xp = \frac12\), \(x^2q = \frac x2\)는 해석적이므로 정칙 특이점이다. \(p_0 = \frac12,\ q_0 = 0\).
  2. 지표 방정식: \(r(r - 1) + \frac r2 = 0\), \(r\bigl(r - \frac12\bigr) = 0\). 지표 \(r_1 = \frac12,\ r_2 = 0\). 차가 정수가 아니다.
  3. \(y = \sum a_nx^{n+r}\)을 넣고 \(x^{n+r-1}\)의 계수를 모으면 \(2(n+r)(n+r-1)a_n + (n+r)a_n + a_{n-1} = 0\), 즉 \((n + r)(2n + 2r - 1)a_n = -a_{n-1}\).
  4. \(r = 0\): \(a_n = -\frac{a_{n-1}}{n(2n-1)}\). \(a_0 = 1\)이면 \(1,\ -1,\ \frac16,\ -\frac1{90}, \dots\), 즉 \(y_1 = 1 - x + \frac{x^2}{6} - \frac{x^3}{90} + \cdots = \cos\sqrt{2x}\).
  5. \(r = \frac12\): \(a_n = -\frac{a_{n-1}}{n(2n+1)}\). \(1,\ -\frac13,\ \frac1{30}, \dots\), 즉 \(y_2 = x^{1/2}\bigl(1 - \frac x3 + \frac{x^2}{30} - \cdots\bigr) = \frac{\sin\sqrt{2x}}{\sqrt2}\).
  6. 수치 확인: \(x = 0.5\)에서 \(y_1\)의 값과 기울기로 출발해 RK4로 \(x = 3\)까지 적분하면 \(-0.769906\), \(\cos\sqrt6 = -0.769906\).

지표의 모양은 해가 특이점 근처에서 어떻게 생겼는지를 말해 줍니다. 아래 시뮬레이터는 가장 단순한 경우인 코시–오일러 방정식 \(x^2y'' + p_0xy' + q_0y = 0\)으로 이것을 보여 줍니다. \(p_0, q_0\)을 바꾸면 지표 방정식의 포물선이 움직이고, 근의 종류에 따라 해의 모양이 바뀝니다.

프로베니우스 방법

정칙 특이점에서 해를 \(y = x^r\sum_{n\ge0}a_nx^n\ (a_0 \ne 0)\)으로 두고 계수를 정하는 방법을 프로베니우스 방법(Frobenius method)이라 합니다. 1870년대 프로베니우스(Ferdinand Georg Frobenius)가 이 방법을 체계화했습니다. 가장 낮은 차수의 계수를 모으면 지표 방정식이 나오고, 그다음 차수부터는 점화식이 나옵니다. 문제는 두 번째 해입니다.

정리 14.4 (프로베니우스) 0이 정칙 특이점이고 \(xp(x),\ x^2q(x)\)의 급수가 \(|x| \lt R\)에서 수렴하며, 지표 \(r_1 \ge r_2\)가 실수라 하자. \(0 \lt x \lt R\)에서
  1. \(y_1 = x^{r_1}\sum_{n\ge0}a_nx^n\)(\(a_0 = 1\)) 꼴의 해가 늘 있다.
  2. \(r_1 - r_2\)가 정수가 아니면 \(y_2 = x^{r_2}\sum b_nx^n\)도 해이고 \(y_1, y_2\)는 독립이다.
  3. \(r_1 = r_2\)이면 \(y_2 = y_1\ln x + x^{r_1}\sum_{n\ge1}b_nx^n\).
  4. \(r_1 - r_2\)가 양의 정수이면 \(y_2 = C\,y_1\ln x + x^{r_2}\sum_{n\ge0}b_nx^n\)이고, 상수 \(C\)는 0일 수도 있다.
모든 급수는 \(|x| \lt R\)에서 수렴한다.

근의 차가 정수일 때 문제가 생기는 이유는 점화식을 보면 알 수 있습니다. 일반적으로 점화식은 \(F(n + r)a_n = (\text{앞 계수들의 식})\)의 꼴이고, \(F(r)\)이 지표 다항식입니다. \(r = r_2\)로 계산하다 \(n = r_1 - r_2\)에 이르면 \(F(r_2 + n) = F(r_1) = 0\)이 되어 그 계수를 정할 수 없습니다. 오른쪽도 우연히 0이면 \(a_n\)을 아무 값으로나 두고 넘어가면 되고(\(C = 0\)), 0이 아니면 거듭제곱 급수만으로는 해를 만들 수 없어 \(\ln x\)가 끼어듭니다. 중근이면 아예 두 번째 지표가 없으니 로그가 반드시 필요합니다. 로그 해를 실제로 구하는 데는 6장의 계수 내리기(\(y_2 = y_1\int\frac{e^{-\int p}}{y_1^2}dx\))를 쓸 수 있습니다.

예제 14.7 (차가 정수인데 로그가 없는 경우: 베셀 \(\nu = \tfrac12\)) \(x^2y'' + xy' + (x^2 - \frac14)y = 0\)의 두 해를 구하라.
  1. \(p_0 = 1,\ q_0 = -\frac14\). 지표 방정식 \(r^2 - \frac14 = 0\), \(r = \pm\frac12\). 차가 1(정수)이다.
  2. 점화식은 \(\bigl((n + r)^2 - \frac14\bigr)a_n = -a_{n-2}\)(\(x^2\cdot y\) 항이 두 칸 옮김). \(r = -\frac12\)에서 \(n = 1\)이면 왼쪽 계수 \(\frac14 - \frac14 = 0\)인데 오른쪽 \(a_{-1} = 0\)이라 문제없다. 로그가 필요 없다(\(C = 0\)).
  3. \(r = -\frac12,\ a_0 = 1,\ a_1 = 0\): \(a_n = -\frac{a_{n-2}}{n(n-1)}\)이므로 \(a_2 = -\frac12\), \(a_4 = \frac1{24}\), … 즉 \(y = x^{-1/2}\cos x\). 같은 방식으로 \(r = \frac12\)에서 \(x^{-1/2}\sin x\).
  4. 표준 정규화로 \(J_{1/2}(x) = \sqrt{\frac{2}{\pi x}}\sin x\), \(J_{-1/2}(x) = \sqrt{\frac{2}{\pi x}}\cos x\). 다음 절의 일반 급수에 \(x = 2\)를 넣어 계산한 값 0.513016, \(-0.234786\)이 이 닫힌 꼴과 같다.
주의: 비정칙 특이점 \(x^3y'' + y = 0\)의 \(x = 0\)처럼 \(x^2q(x) = 1/x\)가 해석적이지 않으면 프로베니우스 급수가 존재한다는 보장이 없습니다. 이런 점에서는 해가 \(e^{c/x}\)처럼 본질적으로 특이한 모양을 가질 수 있습니다. 공학에서 만나는 베셀·르장드르·초기하 방정식은 다행히 모두 정칙 특이점만 가집니다.

르장드르 방정식과 다항식

구 둘레의 퍼텐셜

대전된 구나 행성 둘레의 퍼텐셜, 구 둘레의 정상 상태 온도는 라플라스 방정식을 따릅니다. 구면 좌표에서 축대칭인 해를 \(u = R(\rho)\Theta(\theta)\)로 변수분리하고 \(x = \cos\theta\)로 바꾸면, 각도 부분이 다음 방정식을 만족해야 합니다. 그리고 북극(\(x = 1\))과 남극(\(x = -1\))에서 해가 유한해야 합니다.

$$(1 - x^2)y'' - 2xy' + \lambda(\lambda + 1)y = 0, \qquad -1 \le x \le 1.$$
\(x = \pm1\)은 정칙 특이점, \(x = 0\)은 보통점. 르장드르(Adrien-Marie Legendre)가 18세기 후반 행성의 중력 인력을 연구하며 이 다항식들을 도입했다.

원점 둘레 급수를 넣으면 \(y'' - x^2y'' - 2xy' + \lambda(\lambda+1)y\)에서 \(x^n\)의 계수가 \((n+2)(n+1)a_{n+2} - n(n-1)a_n - 2na_n + \lambda(\lambda+1)a_n\)이므로

$$a_{n+2} = \frac{n(n+1) - \lambda(\lambda + 1)}{(n+2)(n+1)}\,a_n = \frac{(n - \lambda)(n + \lambda + 1)}{(n+2)(n+1)}\,a_n.$$

분자에 \((n - \lambda)\)가 있습니다. \(\lambda = \ell\)이 0 이상의 정수이면 \(a_{\ell+2} = a_{\ell+4} = \cdots = 0\)이 되어, \(\ell\)과 같은 홀짝의 급수가 \(\ell\)차 다항식으로 끝납니다. 끝나지 않는 급수는 \(n\)이 커질 때 \(a_{n+2}/a_n \to 1\)이라 \(x = \pm1\)에서 발산합니다(로그처럼 천천히). 그래서 양 끝에서 유한한 해는 \(\lambda\)가 정수일 때의 다항식뿐입니다. 이 다항식을 \(P_\ell(1) = 1\)로 정규화한 것이 르장드르 다항식입니다.

르장드르 다항식은 로드리게스 공식 \(P_\ell(x) = \frac{1}{2^\ell\,\ell!}\frac{d^\ell}{dx^\ell}(x^2 - 1)^\ell\)으로도 쓸 수 있고, 무엇보다 서로 직교합니다.

정리 14.5 (르장드르 다항식의 직교성)
$$\int_{-1}^{1}P_m(x)P_n(x)\,dx = \begin{cases} 0 & m \ne n \\[2pt] \dfrac{2}{2n + 1} & m = n \end{cases}$$

증명 (\(m \ne n\)). 방정식은 \(\bigl((1 - x^2)P_n'\bigr)' = -n(n+1)P_n\)으로 쓸 수 있다(스튀름–리우빌 꼴). 이 식에 \(P_m\)을, \(m\)에 대한 같은 식에 \(P_n\)을 곱해 빼고 \([-1, 1]\)에서 적분하면 왼쪽은 부분 적분으로 \(\bigl[(1 - x^2)(P_mP_n' - P_nP_m')\bigr]_{-1}^1 = 0\)(양 끝에서 \(1 - x^2 = 0\))이 되고, 오른쪽은 \(\bigl(m(m+1) - n(n+1)\bigr)\int P_mP_n\,dx\)이다. \(m \ne n\)이면 괄호가 0이 아니므로 적분이 0이다. ∎

직교성 덕분에 \([-1, 1]\)의 함수를 \(f = \sum c_\ell P_\ell\)로 전개할 수 있고, 계수는 \(c_\ell = \frac{2\ell + 1}{2}\int_{-1}^1 fP_\ell\,dx\)로 하나씩 읽힙니다. 15장의 푸리에 급수와 같은 구조입니다(15장). 행성의 중력장과 안테나 복사 패턴을 이런 전개로 나타냅니다.

베셀 방정식과 베셀 함수

원형 막의 반지름 방정식에서 \(x = kr\)로 바꾸면 베셀 방정식이 됩니다.

$$x^2y'' + xy' + (x^2 - \nu^2)y = 0.$$
\(\nu \ge 0\)을 차수라 한다. 원형 막에서는 각도 방향의 마디 수 \(n\)이 차수다.

\(x = 0\)은 정칙 특이점이고 \(p_0 = 1,\ q_0 = -\nu^2\)이므로 지표 방정식은 \(r^2 - \nu^2 = 0\), \(r = \pm\nu\)입니다. \(r = \nu\)로 \(y = \sum a_nx^{n+\nu}\)를 넣으면 \(x^2y\) 항이 두 칸 옮겨져 \(\bigl((n + \nu)^2 - \nu^2\bigr)a_n = n(n + 2\nu)a_n = -a_{n-2}\)이고, \(a_1 = 0\)이므로 홀수 계수는 모두 0입니다. 짝수 계수를 정리하고 \(a_0 = \frac{1}{2^\nu\Gamma(\nu + 1)}\)로 정규화하면

정의 14.6 (제1종 베셀 함수)
$$J_\nu(x) = \sum_{k=0}^{\infty}\frac{(-1)^k}{k!\,\Gamma(k + \nu + 1)}\left(\frac x2\right)^{2k + \nu}.$$
이 급수는 모든 \(x\)에서 수렴한다. \(\nu\)가 정수가 아니면 \(J_{-\nu}\)가 두 번째 독립해이고, \(\nu = n\)이 정수이면 \(J_{-n} = (-1)^nJ_n\)이라 독립이 아니어서 로그 항을 가진 제2종 베셀 함수 \(Y_n\)이 두 번째 해가 된다. \(Y_n\)은 \(x \to 0\)에서 \(-\infty\)(또는 \(x^{-n}\)처럼)로 발산한다.
예제 14.9 (\(J_0\)의 첫 항과 값) \(J_0\)의 급수를 쓰고 \(J_0(1)\)을 소수 넷째 자리까지 구하라.

원형 북의 진동 모드

북은 왜 기타처럼 음이 또렷하지 않을까

기타 줄의 고유 진동수는 기본음의 1, 2, 3, … 배라서 귀는 이를 하나의 음높이로 듣습니다. 원형 북의 진동수도 이렇게 정수비일까요? 막의 파동 방정식을 원판에서 풀어 확인합시다.

반지름 \(a\)인 막의 변위 \(u(r, \theta, t)\)는 파동 방정식 \(u_{tt} = c^2\nabla^2u\)를 따르고, 가장자리에서 \(u(a, \theta, t) = 0\)입니다(16장에서 유도). \(u = R(r)\cos(n\theta)\cos(\omega t)\)로 변수분리하면 \(\nabla^2u = -(\omega/c)^2u\)에서

$$r^2R'' + rR' + (k^2r^2 - n^2)R = 0, \qquad k = \frac{\omega}{c}.$$
\(\cos(n\theta)\)가 한 바퀴 돌아 제자리에 오려면 \(n\)은 정수다. \(x = kr\)로 바꾸면 차수 \(n\)인 베셀 방정식이다.

중심 \(r = 0\)에서 유한해야 하므로 \(Y_n\)은 버리고 \(R = J_n(kr)\)만 남습니다. 가장자리 조건 \(J_n(ka) = 0\)에서 \(ka\)는 \(J_n\)의 영점이어야 하므로

정리 14.7 (원형 막의 고유 진동수) 가장자리가 고정된 반지름 \(a\)인 원형 막의 고유 모드는
$$u_{nm} = J_n\!\left(\frac{j_{nm}\,r}{a}\right)\cos(n\theta)\cos(\omega_{nm}t), \qquad \omega_{nm} = \frac{c\,j_{nm}}{a}$$
이다(\(n = 0, 1, 2, \dots\), \(m = 1, 2, \dots\)). 모드 \((n, m)\)에는 지름 방향의 마디선이 \(n\)개, 가장자리를 뺀 원형 마디선이 \(m - 1\)개 있다.
예제 14.10 (진동수의 비) 기본 모드 \((0, 1)\)에 대한 다른 모드의 진동수 비를 구하라.

핵심 정리

  1. 보통점(\(p, q\)가 해석적인 점)에서는 \(y = \sum a_n(x - x_0)^n\)을 넣고 첨자를 맞춰 점화식을 얻는다. \(a_0, a_1\)이 두 개의 자유 상수다.
  2. 점화식의 모양이 해의 성격을 말한다: 두 칸이면 짝·홀 해, 분자가 0이 되면 다항식 해(에르미트, 르장드르), 계수 비가 수렴 반지름.
  3. 에어리 방정식 \(y'' = xy\)는 세 칸 점화식 \(a_{n+2} = a_{n-1}/((n+2)(n+1))\)을 가지며, \(x \lt 0\)에서 국소 진동수 \(\sqrt{|x|}\)로 진동하고 \(x > 0\)에서 지수처럼 행동한다.
  4. 급수해의 수렴 반지름은 복소평면에서 가장 가까운 특이점까지의 거리 이상이다. \((1 + x^2)y'' + 2xy' = 0\)의 해 \(\arctan x\)는 \(\pm i\) 때문에 원점 둘레 반지름이 1이다.
  5. \(xp,\ x^2q\)가 해석적이면 정칙 특이점. 지표 방정식 \(r(r-1) + p_0r + q_0 = 0\)이 해 \(x^r\sum a_nx^n\)의 지수를 준다.
  6. 프로베니우스: 지표의 차가 정수가 아니면 급수해 둘, 중근이면 \(\ln x\) 항이 반드시, 차가 양의 정수이면 \(\ln x\) 항이 생길 수도 있다(베셀 \(\nu = \frac12\)에서는 생기지 않는다).
  7. 르장드르 방정식은 \(\lambda = \ell\)이 정수일 때만 \([-1, 1]\)에서 유한한 해(다항식 \(P_\ell\))를 가지고, \(\int_{-1}^1P_mP_n\,dx = \frac{2}{2n+1}\delta_{mn}\).
  8. 베셀 함수 \(J_\nu = \sum\frac{(-1)^k}{k!\Gamma(k+\nu+1)}(x/2)^{2k+\nu}\)는 큰 \(x\)에서 \(\sqrt{2/(\pi x)}\cos(x - \nu\pi/2 - \pi/4)\). 원형 막의 고유 진동수는 \(\omega_{nm} = c\,j_{nm}/a\)이고 그 비(1, 1.593, 2.136, 2.295, …)는 정수가 아니다.

확인 퀴즈

Q1. \(y'' + y = 0\)에 \(y = \sum a_nx^n\)을 넣어 얻는 점화식은?

\(y''\)의 \(x^n\) 계수는 \((n+2)(n+1)a_{n+2}\)이고 이것이 \(-a_n\)과 같아야 한다. 이 점화식이 cos, sin의 테일러 계수를 준다. 넷째는 에어리 방정식(부호 반대)의 꼴이다.

Q2. \((x^2 + 4)y'' + xy' + y = 0\)의 \(x_0 = 1\) 둘레 급수해의 수렴 반지름으로 보장되는 최솟값은?

특이점은 \(x^2 + 4 = 0\)인 \(\pm2i\). \(1\)에서 \(2i\)까지 거리는 \(\sqrt{1 + 4} = \sqrt5\). 실수축에 특이점이 없어도 복소 특이점이 반지름을 제한한다.

Q3. 에어리 방정식 \(y'' = xy\)의 해가 \(x \lt 0\)에서 진동하는 이유로 가장 알맞은 것은?

\(x \lt 0\)이면 \(y'' = -|x|y\)로 용수철 같은 복원력이 생기고, 그 "강성" \(|x|\)이 커질수록 빨리 진동한다. 급수는 모든 \(x\)에서 수렴하고, 0은 보통점이며, \(y'\) 항은 없다.

Q4. \(x^2y'' + 3xy' + y = 0\)의 지표 방정식의 근과 두 번째 해의 모양은?

\(p_0 = 3,\ q_0 = 1\): \(r(r-1) + 3r + 1 = r^2 + 2r + 1 = (r + 1)^2\). 중근 \(r = -1\)이므로 해는 \(x^{-1}\)과 \(x^{-1}\ln x\).

Q5. 르장드르 방정식 \((1 - x^2)y'' - 2xy' + \lambda(\lambda+1)y = 0\)에서 \([-1, 1]\) 전체에서 유한한 해가 있으려면?

점화식 분자 \((n - \lambda)(n + \lambda + 1)\)이 0이 되어야 급수가 끝난다. 끝나지 않으면 계수 비가 1로 가서 \(x = \pm1\)에서 발산한다. 구의 극에서 퍼텐셜이 유한해야 하므로 물리적으로 다항식만 남는다.

Q6. \(\int_{-1}^{1}P_2(x)^2\,dx\)의 값은?

정리 14.5에서 \(n = 2\): \(\frac{2}{2\cdot2 + 1} = \frac25\). 직접 계산해도 \(\int_{-1}^1\frac14(3x^2 - 1)^2dx = \frac14\left(\frac{18}{5} - 4 + 2\right) = \frac25\).

Q7. 원형 막의 반지름 방향 해로 \(J_n(kr)\)만 쓰고 \(Y_n(kr)\)을 버리는 이유는?

\(Y_n\)도 해이고 진동하며 영점도 있다. 하지만 지표 방정식의 로그·음의 거듭제곱 해라서 중심에서 무한대가 된다. 막(구멍 없음)에서는 버리고, 가운데가 뚫린 고리 모양 막에서는 \(J_n\)과 \(Y_n\)을 함께 쓴다.

Q8. 기본 진동수가 200 Hz인 이상적인 원형 막에서 모드 (1, 1)의 진동수는 대략?

\(\omega_{11}/\omega_{01} = j_{11}/j_{01} = 3.8317/2.4048 = 1.593\)이므로 \(200\times1.593 \approx 319\) Hz. 459 Hz는 (0, 2) 모드(비 2.295)다. 기타 줄처럼 정수배가 아니다.
