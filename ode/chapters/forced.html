Chapter 08

강제 진동과 공진

7장의 진동자는 처음에 한 번 당겨 놓은 뒤 혼자 흔들렸습니다. 현실의 진동자는 대개 계속 밀립니다. 회전하는 모터의 불균형, 울퉁불퉁한 도로, 교류 전원, 라디오 안테나에 닿는 전파가 모두 시간에 따라 변하는 외력 \(F(t)\)입니다. 그러면 방정식은 \(mx'' + cx' + kx = F(t)\)의 비동차 방정식이 됩니다. 이 장에서는 비동차 방정식의 해를 "동차해 + 특수해"로 쪼개는 구조를 세우고, 특수해를 찾는 두 방법(미정계수법, 매개변수 변환법)을 익힌 뒤, 외력이 사인파일 때 나타나는 현상들(정상 응답, 맥놀이, 공진(resonance))을 주파수 응답 곡선 하나로 묶습니다.

  • 비동차 선형 방정식의 일반해가 \(x_h + x_p\)임을 증명하고, 감쇠계에서 \(x_h\)는 과도 응답, \(x_p\)는 정상 응답이 됨을 설명한다.
  • 미정계수법의 시험 함수 꼴을 고르고, 외력이 동차해와 겹치면 \(t\)를 곱하는 규칙을 쓴다.
  • 매개변수 변환법(론스키안 공식)으로 \(\sec t\)처럼 미정계수법이 안 되는 외력을 푼다.
  • 사인 외력의 정상 응답 진폭과 위상 지연을 복소수 방법으로 유도하고 맥놀이와 공진 \(t\sin\omega_0 t\)를 설명한다.
  • 주파수 응답 곡선에서 공진 봉우리, Q 인자, 반치폭을 읽고 \(Q \approx \omega_0/\Delta\omega\)를 확인한다.
  • 타코마 다리 붕괴(공탄성 플러터), 라디오 동조, 진동 절연(\(r > \sqrt2\))을 정확히 설명한다.
이 수식이 없었다면라디오 수신기

안테나에는 수많은 방송국의 전파가 동시에 닿습니다. 각 방송은 자기 반송 주파수로 진동하는 아주 약한 전압이고, 모두 한 줄의 도선 위에 겹쳐 있습니다. 수신기가 이 가운데 하나만 골라 키우지 못하면 소리는 뒤섞인 잡음일 뿐입니다.

해법은 이 장의 방정식입니다. 코일과 축전기로 만든 동조 회로는 \(Lq'' + Rq' + q/C = v(t)\)를 따르고, 응답 진폭은 구동 주파수가 고유 주파수 \(1/(2\pi\sqrt{LC})\)와 같을 때만 크게 솟습니다. 가변 축전기의 손잡이를 돌려 \(C\)를 바꾸면 이 봉우리가 원하는 방송국으로 옮겨 가고, 회로의 Q 인자가 높을수록 이웃 방송은 깊이 눌립니다. 같은 공진은 다리와 기계에서는 피해야 할 위험이지만, 회로에서는 신호를 골라내는 가장 값싼 필터입니다.

비동차 방정식의 해 구조

모터를 켜면 받침대는 어떻게 흔들리나

탄성 받침대 위의 펌프를 켜는 순간, 받침대는 잠시 불규칙하게 흔들리다가 곧 모터의 회전과 같은 박자로 일정하게 흔들립니다. 처음의 불규칙한 흔들림은 어디서 오고, 나중의 일정한 흔들림은 얼마나 클까요? 두 부분을 따로 계산할 수 있을까요?

외력 \(F(t)\)를 받는 질량–용수철–감쇠기는 7장의 모델에 힘 하나만 더하면 됩니다.

$$mx'' + cx' + kx = F(t).$$
오른쪽이 0이 아니므로 비동차 방정식(nonhomogeneous equation)이다. \(F \equiv 0\)으로 둔 \(mx'' + cx' + kx = 0\)을 대응하는 동차 방정식이라 한다.
정리 8.1 (비동차 선형 방정식의 일반해) \(x_p\)가 \(L[x] = x'' + p(t)x' + q(t)x = g(t)\)의 해 하나이고 \(x_1, x_2\)가 동차 방정식 \(L[x] = 0\)의 기본해 집합이면, 비동차 방정식의 모든 해는
$$x(t) = \underbrace{C_1x_1(t) + C_2x_2(t)}_{x_h} + x_p(t)$$
의 꼴이다. \(x_p\)를 특수해(particular solution)라 부른다.

증명. \(x\)가 아무 해이면 선형성으로 \(L[x - x_p] = L[x] - L[x_p] = g - g = 0\). 따라서 \(x - x_p\)는 동차해이고, 6장의 정리로 \(C_1x_1 + C_2x_2\)로 쓸 수 있다. 거꾸로 이 꼴의 함수는 \(L[\cdot] = 0 + g\)이므로 해다. ∎

이 정리 덕분에 일은 둘로 나뉩니다. 동차해 \(x_h\)는 6·7장에서 이미 압니다. 남은 일은 특수해 하나를 어떻게든 찾는 것이고, 초기 조건은 마지막에 \(C_1, C_2\)로 맞춥니다. 또 외력이 \(g = g_1 + g_2\)처럼 합이면 각각의 특수해를 더하면 됩니다(중첩 원리).

감쇠가 있으면(\(c > 0\)) 7장에서 본 대로 모든 동차해는 지수적으로 0으로 갑니다. 그래서 오래 지나면 초기 조건과 상관없이 \(x(t) \approx x_p(t)\)만 남습니다. 3장에서 1계 회로로 본 것과 같은 구조로, 사라지는 \(x_h\) 부분을 과도 응답, 남는 \(x_p\) 부분을 정상 상태 응답이라 부릅니다.

미정계수법

특수해를 "짐작"할 수 있을까

상수계수 연산자 \(L[y] = ay'' + by' + cy\)에 다항식을 넣으면 다항식, 지수 함수를 넣으면 같은 지수 함수, 사인을 넣으면 사인과 코사인이 나옵니다. 그렇다면 \(L[y] = 4t^2\)의 해도 다항식이 아닐까요? 계수만 모르는 꼴을 넣고 맞추면 됩니다.

미정계수법(method of undetermined coefficients)은 외력 \(g(t)\)가 다항식, 지수 함수, 사인·코사인과 이들의 곱일 때 쓰는 방법입니다. 이런 함수들은 미분해도 같은 종류의 유한 개 함수로만 바뀌기 때문에, 그 함수들의 일차 결합을 시험 함수로 넣으면 연립 일차 방정식 하나로 계수가 정해집니다.

정리 8.2 (미정계수법의 시험 함수) 상수계수 방정식 \(ay'' + by' + cy = g(t)\)에서
g(t)시험 함수 yp
\(P_n(t)\) (n차 다항식)\(t^s(A_nt^n + \cdots + A_1t + A_0)\)
\(P_n(t)e^{\alpha t}\)\(t^s(A_nt^n + \cdots + A_0)e^{\alpha t}\)
\(e^{\alpha t}\bigl(P_n(t)\cos\beta t + Q_m(t)\sin\beta t\bigr)\)\(t^se^{\alpha t}\bigl(R_N(t)\cos\beta t + S_N(t)\sin\beta t\bigr)\), \(N = \max(n, m)\)
여기서 \(s\)는 \(\alpha + i\beta\)(다항식이면 0, 실지수면 \(\alpha\))가 특성 방정식의 근으로 나타나는 중복도(0, 1, 2)다. 이 \(t^s\)를 곱하는 규칙을 수정 규칙(modification rule)이라 한다.

수정 규칙이 필요한 까닭은 간단합니다. 시험 함수가 동차해이면 \(L[y_p] = 0\)이 되어 \(g\)를 만들 수 없습니다. 예를 들어 \(y'' + 3y' + 2y = e^{-t}\)에서 \(Ae^{-t}\)를 넣으면 \(-1\)이 특성근이므로 \(L[Ae^{-t}] = A(1 - 3 + 2)e^{-t} = 0\)입니다. 이때 \(t\)를 곱한 \(Ate^{-t}\)는 동차해가 아니면서 \(L\)을 거치면 \(e^{-t}\)을 만들어 냅니다. 6장의 중근에서 \(te^{rt}\)가 나온 것과 같은 이유입니다.

예제 8.1 (다항식 외력과 초기값 문제) \(y'' + 3y' + 2y = 4t^2\), \(y(0) = 0\), \(y'(0) = 0\)을 풀어라.
  1. 동차해: \(r^2 + 3r + 2 = (r + 1)(r + 2)\), \(y_h = C_1e^{-t} + C_2e^{-2t}\). 0은 특성근이 아니므로 \(s = 0\).
  2. 시험 함수 \(y_p = At^2 + Bt + C\). \(y_p' = 2At + B\), \(y_p'' = 2A\). 대입하면 \(2At^2 + (6A + 2B)t + (2A + 3B + 2C) = 4t^2\).
  3. 계수 비교: \(2A = 4\), \(6A + 2B = 0\), \(2A + 3B + 2C = 0\)에서 \(A = 2\), \(B = -6\), \(C = 7\). \(y_p = 2t^2 - 6t + 7\).
  4. 초기 조건: \(C_1 + C_2 + 7 = 0\), \(-C_1 - 2C_2 - 6 = 0\)에서 \(C_1 = -8\), \(C_2 = 1\). 따라서 \(y = 2t^2 - 6t + 7 - 8e^{-t} + e^{-2t}\).
  5. 수치 확인(RK4, \(t = 2\)): 두 값 모두 \(1.93563\).
예제 8.2 (겹칠 때 t 곱하기) (가) \(y'' + 3y' + 2y = e^{-t}\), (나) \(y'' + 2y' + y = 6e^{-t}\), (다) \(y'' + 4y = 3\cos 2t\)의 특수해를 구하라.
  1. (가) \(-1\)이 단근이므로 \(s = 1\), \(y_p = Ate^{-t}\). \(y_p' = A(1 - t)e^{-t}\), \(y_p'' = A(t - 2)e^{-t}\). 대입: \(A[(t - 2) + 3(1 - t) + 2t]e^{-t} = Ae^{-t}\)이므로 \(A = 1\), \(y_p = te^{-t}\).
  2. (나) \(r^2 + 2r + 1 = (r + 1)^2\), \(-1\)이 중근이므로 \(s = 2\), \(y_p = At^2e^{-t}\). 대입하면 \(L[t^2e^{-t}] = 2e^{-t}\)이므로 \(A = 3\), \(y_p = 3t^2e^{-t}\).
  3. (다) \(\pm 2i\)가 특성근이므로 \(s = 1\), \(y_p = t(A\cos 2t + B\sin 2t)\). 대입하면 \(-4A\sin 2t + 4B\cos 2t = 3\cos 2t\)이므로 \(A = 0\), \(B = 3/4\). \(y_p = \frac34t\sin 2t\). 진폭이 \(t\)에 비례해 끝없이 커진다. 이것이 5절의 공진이다.
  4. 수치 확인(RK4, \(t = 1.3\), 같은 초기값): (가) 0.35429, (다) 0.50261로 닫힌 꼴과 같다.
미정계수법이 안 되는 경우 외력이 \(\sec t\), \(\ln t\), \(1/t\)처럼 미분할 때마다 새로운 종류의 함수가 끝없이 생기면 유한 개의 시험 함수로 닫히지 않습니다. 또 계수가 상수가 아닌 방정식(예: 코시–오일러)에는 표가 맞지 않습니다. 이럴 때는 다음 절의 매개변수 변환법을 씁니다.

매개변수 변환법

외력이 \(\sec t\)라면

\(y'' + y = \sec t\)의 특수해를 미정계수법으로 짐작하려 하면 \(\sec t\)를 미분할 때마다 \(\sec t\tan t\), \(\sec t\tan^2 t\), …가 끝없이 나옵니다. 짐작 대신 공식이 필요합니다.

라그랑주(Joseph-Louis Lagrange)의 아이디어는 동차해 \(C_1y_1 + C_2y_2\)의 상수를 함수로 풀어 주는 것입니다. \(y_p = u_1(t)y_1 + u_2(t)y_2\)로 놓고, 미분이 복잡해지지 않도록 조건 \(u_1'y_1 + u_2'y_2 = 0\)을 하나 더 겁니다. 그러면 \(y_p' = u_1y_1' + u_2y_2'\)이고, 방정식에 넣으면 \(y_1, y_2\)가 동차해라서 남는 것은 \(u_1'y_1' + u_2'y_2' = g\)뿐입니다.

정리 8.3 (매개변수 변환법) \(y'' + p(t)y' + q(t)y = g(t)\)의 동차 기본해 \(y_1, y_2\)의 론스키안을 \(W = y_1y_2' - y_1'y_2\)라 하면
$$y_p(t) = -y_1(t)\int\frac{y_2(t)g(t)}{W(t)}\,dt + y_2(t)\int\frac{y_1(t)g(t)}{W(t)}\,dt$$
는 특수해다. 이 방법을 매개변수 변환법(variation of parameters)이라 한다.

증명. 두 조건 \(u_1'y_1 + u_2'y_2 = 0\), \(u_1'y_1' + u_2'y_2' = g\)는 \(u_1', u_2'\)에 대한 연립 일차 방정식이고, 계수 행렬식이 \(W \ne 0\)이므로 크라메르 공식으로 \(u_1' = -y_2g/W\), \(u_2' = y_1g/W\). 적분하면 된다. 이렇게 만든 \(y_p\)를 방정식에 넣으면 \(L[y_p] = u_1L[y_1] + u_2L[y_2] + (u_1'y_1' + u_2'y_2') = g\). ∎

\(u_1, u_2\)는 "지금 이 순간의 \(y\)와 \(y'\)을 동시에 맞추는 동차해의 계수"입니다. 조건 \(u_1'y_1 + u_2'y_2 = 0\) 덕분에 \(t^*\)에서 계수를 얼려 만든 동차해 \(u_1(t^*)y_1 + u_2(t^*)y_2\)는 그 순간 \(y_p\)와 값도 기울기도 같습니다. 외력이 계수를 조금씩 밀어 옮기고, 해는 그렇게 갈아타는 동차해들을 이어 붙인 곡선입니다. 아래 시뮬레이터의 점선이 그 "얼린 동차해"입니다.

예제 8.3 (\(y'' + y = \sec t\)) \(|t| \lt \pi/2\)에서 특수해를 구하라.
  1. \(y_1 = \cos t\), \(y_2 = \sin t\), \(W = \cos^2 t + \sin^2 t = 1\).
  2. \(u_1 = -\int \sin t\sec t\,dt = -\int\tan t\,dt = \ln|\cos t|\), \(u_2 = \int\cos t\sec t\,dt = t\).
  3. \(y_p = \cos t\,\ln|\cos t| + t\sin t\). \(y_p(0) = 0\), \(y_p'(0) = 0\)이므로 이것이 바로 영 초기값 문제의 해다.
  4. 수치 확인(RK4, \(t = 1.3\)): 두 값 모두 0.89989. \(t \to \pi/2\)이면 \(\sec t\)가 무한대로 가지만 \(y_p\)는 \(\pi/2\)로 다가가 유한하다.
합성곱 꼴 상수계수 \(y'' + \omega^2y = g\)에서 정적분으로 쓰면 \(y_p(t) = \frac1\omega\int_0^t \sin\omega(t - s)\,g(s)\,ds\)이고, 이는 영 초기 조건의 해입니다. "과거의 각 순간 \(s\)에 받은 충격 \(g(s)\,ds\)가 그 뒤로 \(\sin\omega(t - s)/\omega\)로 울린다"는 뜻입니다. 이 꼴은 10장에서 합성곱과 충격 응답으로 다시 만납니다.

사인 강제력과 정상 응답: 진폭과 위상

공학에서 가장 중요한 외력은 사인파 \(F(t) = F_0\cos\omega t\)입니다. 회전체의 불균형, 교류 전원, 음파가 모두 이 꼴이고, 푸리에 급수(15장)로 주기적인 외력을 사인파의 합으로 쪼갤 수 있으므로 사인파 하나에 대한 응답을 알면 나머지는 중첩으로 얻습니다.

미정계수법으로 \(A\cos\omega t + B\sin\omega t\)를 넣어도 되지만, 복소수가 더 깔끔합니다. \(F_0\cos\omega t = \operatorname{Re}(F_0e^{i\omega t})\)이므로 \(mz'' + cz' + kz = F_0e^{i\omega t}\)를 풀고 실수부를 취합니다. \(z = Xe^{i\omega t}\)를 넣으면 미분이 \(i\omega\) 곱하기가 되어

$$(k - m\omega^2 + ic\omega)\,X = F_0\quad\Longrightarrow\quad X = \frac{F_0}{k - m\omega^2 + ic\omega}.$$
미분방정식이 복소수 나눗셈 하나가 됐다. \(X\)의 크기가 진폭, 편각의 음수가 위상 지연이다.
정리 8.4 (정상 응답의 진폭과 위상) \(c > 0\)일 때 \(mx'' + cx' + kx = F_0\cos\omega t\)의 정상 응답은 \(x_p = X\cos(\omega t - \varphi)\)이고
$$X = \frac{F_0}{\sqrt{(k - m\omega^2)^2 + (c\omega)^2}},\qquad \tan\varphi = \frac{c\omega}{k - m\omega^2},\quad 0 \lt \varphi \lt \pi.$$
\(r = \omega/\omega_0\), \(\zeta\)로 쓰면 정적 처짐 \(F_0/k\)에 대한 비는
$$M(r) = \frac{X}{F_0/k} = \frac{1}{\sqrt{(1 - r^2)^2 + (2\zeta r)^2}},\qquad \tan\varphi = \frac{2\zeta r}{1 - r^2}.$$
\(M\)을 진폭비(amplitude ratio, magnification factor), \(\varphi\)를 위상 지연(phase lag)이라 한다.

세 영역으로 읽으면 물리가 보입니다.

  • 느리게 밀 때(\(r \ll 1\)): \(M \approx 1\), \(\varphi \approx 0\). 관성과 감쇠는 거의 역할이 없고 용수철이 힘을 받아 \(x \approx F/k\). 강성 지배 영역이다.
  • 고유 진동수에서(\(r = 1\)): \(M = 1/(2\zeta)\), \(\varphi = 90°\). 관성과 용수철이 서로 상쇄되어 감쇠만 힘을 버틴다. 감쇠가 작으면 응답이 매우 크다.
  • 빠르게 밀 때(\(r \gg 1\)): \(M \approx 1/r^2\), \(\varphi \approx 180°\). 질량이 따라오지 못해 외력과 거의 반대로 조금만 움직인다. 질량 지배 영역이다.
예제 8.4 (정상 응답) \(x'' + 2x' + 5x = 10\cos t\)의 정상 응답을 진폭–위상 꼴로 써라.
  1. 시험 함수 \(A\cos t + B\sin t\)(\(\pm i\)는 특성근 \(-1 \pm 2i\)가 아니다). 대입: \((5 - 1)A + 2B = 10\), \((5 - 1)B - 2A = 0\). 따라서 \(B = A/2\), \(5A = 10\), \(A = 2\), \(B = 1\).
  2. \(x_p = 2\cos t + \sin t = \sqrt5\cos(t - \varphi)\), \(\tan\varphi = 1/2\), \(\varphi \approx 26.57°\).
  3. 정리 8.4로 검산: \(X = 10/\sqrt{(5 - 1)^2 + 2^2} = 10/\sqrt{20} = \sqrt5 \approx 2.236\). \(\tan\varphi = 2/4\). ✓
  4. 복소수로: \(X = 10/(4 + 2i) = 10(4 - 2i)/20 = 2 - i\). \(\operatorname{Re}((2 - i)e^{it}) = 2\cos t + \sin t\). 같은 답이 나눗셈 한 번으로 나온다.

맥놀이

기타 줄을 맞출 때 들리는 "웅웅"

기타 두 줄을 거의 같은 음으로 함께 튕기면 소리가 커졌다 작아졌다를 천천히 되풀이합니다. 두 음이 가까워질수록 이 울렁임은 느려지고, 완전히 같아지면 사라집니다. 조율하는 사람은 이 울렁임이 멈출 때까지 줄을 조입니다. 무엇이 이런 느린 박자를 만들까요?

감쇠가 없는 진동자 \(x'' + \omega_0^2x = F_0\cos\omega t\)를 정지 상태에서 고유 진동수와 가까운 \(\omega \ne \omega_0\)로 밀어 봅시다. 특수해 \(\frac{F_0}{\omega_0^2 - \omega^2}\cos\omega t\)에 초기 조건 \(x(0) = x'(0) = 0\)을 맞추는 동차해를 더하면

$$x(t) = \frac{F_0}{\omega_0^2 - \omega^2}\bigl(\cos\omega t - \cos\omega_0t\bigr) = \underbrace{\frac{2F_0}{\omega_0^2 - \omega^2}\sin\frac{(\omega_0 - \omega)t}{2}}_{\text{천천히 변하는 진폭}}\ \sin\frac{(\omega_0 + \omega)t}{2}.$$
두 번째 등호는 \(\cos a - \cos b = -2\sin\frac{a+b}{2}\sin\frac{a-b}{2}\)이다. 빠른 진동 \(\sin\frac{\omega_0+\omega}{2}t\)를 느린 포락선이 감싼다.

이 현상을 맥놀이(beats)라 합니다. 포락선의 크기 \(|\sin\frac{(\omega_0 - \omega)t}{2}|\)는 주기 \(2\pi/|\omega_0 - \omega|\)로 커졌다 작아지므로, 소리의 세기가 울렁이는 횟수(맥놀이 진동수)는 \(|f_0 - f|\) Hz입니다. 두 진동수가 가까울수록 느리게, 그러나 더 크게(\(\omega_0^2 - \omega^2\)이 작아지므로) 울렁입니다. 에너지가 외력에서 진동자로 들어갔다가 위상이 어긋나면 다시 외력 쪽으로 돌아가는 주고받기가 되풀이되는 것입니다.

예제 8.5 (맥놀이 손으로 풀기) \(x'' + 100x = 19\cos 9t\), \(x(0) = x'(0) = 0\).
  1. 특수해 \(A\cos 9t\): \((100 - 81)A = 19\), \(A = 1\). 일반해 \(x = \cos 9t + C_1\cos 10t + C_2\sin 10t\).
  2. \(x(0) = 1 + C_1 = 0\), \(x'(0) = 10C_2 = 0\). 따라서 \(x = \cos 9t - \cos 10t = 2\sin(t/2)\sin(9.5t)\).
  3. 포락선 최대 2(외력만으로 정적으로 밀었을 때 \(19/100 = 0.19\)의 약 10배), 맥놀이 주기 \(2\pi/1 \approx 6.28\) s.
  4. 수치 확인(RK4, \(t = 1.3\)): 두 값 모두 \(-0.25985\).

공진: 비감쇠 t sin ω₀t와 감쇠 공진 봉우리

그네를 미는 박자

그네를 그네의 박자에 맞춰 밀면 작은 힘으로도 점점 높이 올라갑니다. 엉뚱한 박자로 밀면 아무리 세게 밀어도 크게 흔들리지 않습니다. 박자가 정확히 맞으면 진폭은 끝없이 커질까요? 마찰이 있으면 어디서 멈출까요?

맥놀이 식에서 \(\omega \to \omega_0\)의 극한을 취하면(로피탈) 또는 수정 규칙으로 직접 풀면, 감쇠 없는 공진의 해가 나옵니다.

정리 8.5 (비감쇠 공진) \(x'' + \omega_0^2x = F_0\cos\omega_0t\), \(x(0) = x'(0) = 0\)의 해는
$$x(t) = \frac{F_0}{2\omega_0}\,t\sin\omega_0t.$$
진폭은 \(t\)에 비례해 끝없이 커진다. 이처럼 구동 진동수가 고유 진동수와 같아 응답이 크게 커지는 현상을 공진이라 한다.

증명. \(\pm i\omega_0\)가 특성근이므로 \(x_p = t(A\cos\omega_0t + B\sin\omega_0t)\). 대입하면 \(2\omega_0(-A\sin\omega_0t + B\cos\omega_0t) = F_0\cos\omega_0t\)에서 \(A = 0\), \(B = F_0/(2\omega_0)\). \(x_p(0) = 0\), \(x_p'(0) = 0\)이므로 동차해를 더할 필요가 없다. ∎

에너지로 보면 이유가 분명합니다. 외력이 하는 일률은 \(F\cdot v\)이고, 공진에서는 속도가 외력과 같은 박자로 움직이므로(위상 지연 90°, 즉 변위는 늦고 속도는 맞음) 매 주기 일이 양수로 쌓입니다. 감쇠가 있으면 감쇠가 빼앗는 에너지 \(cv^2\)이 진폭의 제곱으로 커지므로, 어느 진폭에서 넣는 일과 빼앗기는 일이 같아져 성장이 멈춥니다.

정리 8.6 (감쇠 공진 봉우리) \(0 \lt \zeta \lt 1/\sqrt2\)이면 진폭비 \(M(r)\)는
$$r_{\rm peak} = \sqrt{1 - 2\zeta^2},\qquad M_{\max} = \frac{1}{2\zeta\sqrt{1 - \zeta^2}}$$
에서 최대다. 이 진동수 \(\omega_r = \omega_0\sqrt{1 - 2\zeta^2}\)을 공진 진동수(resonant frequency)라 한다. \(\zeta \ge 1/\sqrt2\)이면 봉우리가 없고 \(M\)은 \(r\)에 따라 감소한다.

증명. \(M\)이 최대인 곳은 \(D(u) = (1 - u)^2 + 4\zeta^2u\) (\(u = r^2\))가 최소인 곳이다. \(D'(u) = -2(1 - u) + 4\zeta^2 = 0\)에서 \(u = 1 - 2\zeta^2\), 이 값이 양수일 조건이 \(\zeta \lt 1/\sqrt2\). 대입하면 \(D = 4\zeta^4 + 4\zeta^2(1 - 2\zeta^2) = 4\zeta^2(1 - \zeta^2)\). ∎

세 진동수 \(\omega_r \lt \omega_d \lt \omega_0\)(감쇠가 있을 때)는 서로 다르지만, 감쇠가 작으면 모두 거의 같습니다. 예를 들어 \(\zeta = 0.1\)이면 \(r_{\rm peak} = 0.990\), \(M_{\max} = 5.03\)으로 \(1/(2\zeta) = 5\)와 거의 같습니다.

예제 8.6 (공진 성장과 포화) \(x'' + cx' + 100x = 10\cos 10t\), 영 초기값. (가) \(c = 0\)일 때 진폭이 1이 되는 시각은? (나) \(c = 1\)이면 진폭은 얼마에서 멈추는가?
  1. (가) 정리 8.5로 \(x = \frac{10}{20}t\sin 10t = 0.5t\sin 10t\). 진폭 \(0.5t = 1\)에서 \(t = 2\) s. 수치 확인(RK4, \(t = 1.3\)): 0.27311.
  2. (나) \(\omega = \omega_0\)이면 \(k - m\omega^2 = 0\)이므로 정리 8.4에서 \(X = F_0/(c\omega) = 10/10 = 1\). \(\zeta = c/(2\sqrt{mk}) = 0.05\).
  3. 과도 응답은 \(e^{-\zeta\omega_0t} = e^{-0.5t}\)로 사라지므로, 진폭은 대략 \(1 - e^{-0.5t}\) 꼴로 1에 다가간다. 시상수 \(1/(\zeta\omega_0) = 2\) s. RK4로 \(t > 25\) s의 최대 진폭은 1.0000.

주파수 응답 곡선, Q 인자, 반치폭

정리 8.4의 \(M(r)\)과 \(\varphi(r)\)를 \(r\)의 함수로 그린 것을 주파수 응답(frequency response) 곡선이라 합니다. 진동계, 회로, 스피커, 센서의 사양서에 빠짐없이 실리는 그림입니다. 한 장에 정적 응답(\(r \to 0\)), 공진 봉우리, 고주파 차단이 모두 들어 있습니다.

봉우리가 얼마나 뾰족한지를 재는 수가 Q 인자입니다. 봉우리 높이의 \(1/\sqrt2\)배(에너지로는 절반, 그래서 '반전력') 이상인 진동수 구간의 폭을 반치폭(half-power bandwidth) \(\Delta\omega\)라 합니다.

정의 8.7 (Q 인자)와 정리 8.8 (반치폭) 감쇠 진동자의 Q 인자(quality factor)를 \(Q = \dfrac{1}{2\zeta}\)로 정의한다. \(\zeta\)가 작으면 \(M(r) = M_{\max}/\sqrt2\)인 두 진동수는 \(r \approx 1 \mp \zeta\)이고
$$\frac{\Delta\omega}{\omega_0} \approx 2\zeta = \frac1Q,\qquad Q \approx \frac{\omega_0}{\Delta\omega}.$$

증명의 요지. \(M^2 = M_{\max}^2/2\)를 \(u = r^2\)로 풀면 \((1 - u)^2 + 4\zeta^2u = 8\zeta^2(1 - \zeta^2)\), 즉 \(u = 1 - 2\zeta^2 \pm 2\zeta\sqrt{1 - \zeta^2}\). \(\zeta\)가 작으면 \(u \approx 1 \pm 2\zeta\), \(r \approx 1 \pm \zeta\). ∎

정확한 값과 비교하면 근사가 얼마나 좋은지 보입니다. \(\zeta = 0.1\)이면 반전력 진동수는 \(r = 0.884\)와 \(1.086\)이고 폭 \(\Delta r = 0.202\)로, \(2\zeta = 0.2\)와 1% 차이입니다. \(\zeta = 0.05\)이면 폭 0.1003으로 거의 정확합니다. 그래서 실험에서는 응답 곡선의 봉우리 폭을 재서 \(\zeta = \Delta\omega/(2\omega_0)\)로 감쇠를 구합니다. 7장의 로그 감소율이 시간 영역에서 감쇠를 재는 방법이라면, 이것은 주파수 영역의 방법입니다.

Q는 에너지로도 읽힙니다. 감쇠가 작을 때 \(Q \approx 2\pi\times\)(저장된 에너지)/(한 주기에 잃는 에너지)이고, 자유 진동이 \(e^{-\pi}\)배로 줄 때까지의 진동 횟수가 약 \(Q\)번입니다. 수정 진동자처럼 Q가 매우 큰 진동자는 봉우리가 극도로 좁아 정확한 시계와 필터에 쓰입니다.

그림 8-3에 대한 주의 곡선들이 한 점에서 만나는 것은 \(r = 0\)뿐입니다. \(r = \sqrt2\)에서 모든 곡선이 만나는 것은 진폭비 \(M\)이 아니라 다음 절의 전달률 \(T(r)\)의 성질입니다. 두 그래프를 헷갈리지 않도록 하세요.

타코마 내로스 다리: 공진이 아니라 플러터

1940년 11월 7일, 미국 워싱턴주의 타코마 내로스 다리가 개통 넉 달 만에 바람 속에서 크게 비틀리다 무너졌습니다. 이 장면의 필름은 "공진"의 예로 흔히 소개되지만, 이는 정확하지 않습니다. 공진은 외부에서 정해진 주기로 미는 힘이 고유 진동수와 맞을 때 생기는데, 그날의 바람은 주기적으로 미는 힘이 아니라 비교적 꾸준한 바람이었습니다. 1991년 빌라(K. Y. Billah)와 스캔런(R. H. Scanlan)은 American Journal of Physics에 실은 논문에서 물리학 교과서들의 이 설명을 바로잡았습니다.

실제 원인은 공탄성 플러터(aeroelastic flutter)입니다. 다리 상판이 비틀리면 그 각도에 따라 바람이 상판에 주는 힘이 바뀌고, 그 힘이 다시 비틀림을 키우는 방향으로 작용했습니다. 방정식으로 쓰면 외력 항이 따로 있는 것이 아니라, 공기력이 운동 자체에 의존해 감쇠 항의 부호를 실질적으로 음수로 바꾸는 것입니다. 7장의 말로는 \(c_{\rm eff} \lt 0\)인 진동자이고, 특성근의 실수부가 양수가 되어 작은 흔들림이 지수적으로 커집니다. 이것은 강제 진동이 아니라 자려 진동(스스로 키우는 진동)이며, 풍속이 어떤 임계값을 넘을 때 안정성이 깨지는 문제입니다. 이후의 현수교는 풍동 시험으로 이 임계 풍속을 확인하고, 상판의 단면을 공기역학적으로 설계합니다.

공진과 플러터 구별하기 공진: \(mx'' + cx' + kx = F_0\cos\omega t\), \(c > 0\)이면 진폭은 유한한 \(F_0/(c\omega_0)\)에서 멈춘다. 플러터: \(mx'' + c_{\rm eff}x' + kx = 0\), \(c_{\rm eff} \lt 0\)이면 외력이 없어도 진폭이 \(e^{|c_{\rm eff}|t/2m}\)로 자란다(실제로는 비선형 효과가 진폭을 제한하거나 구조가 파괴된다). 앞쪽은 이 장의 주제, 뒤쪽은 12장의 안정성과 13장의 호프 분기로 이어진다.

라디오 동조

직렬 RLC 회로에 안테나 전압 \(v(t) = V_0\cos\omega t\)를 걸면 전류의 진폭은 \(\omega_0 = 1/\sqrt{LC}\)에서 최대 \(V_0/R\)이 되고, 7장의 상사대로 \(Q = \frac{1}{R}\sqrt{L/C}\)입니다. 반치폭 \(\Delta\omega = \omega_0/Q = R/L\)보다 멀리 떨어진 방송은 크게 줄어듭니다. 가변 축전기로 \(C\)를 바꾸면 봉우리가 움직입니다.

예제 8.7 (중파 방송 동조 범위) \(L = 240\) μH인 코일로 중파 AM 방송(대략 0.53~1.7 MHz)을 모두 받으려면 가변 축전기의 범위는?
  1. \(f_0 = \frac{1}{2\pi\sqrt{LC}}\)에서 \(C = \frac{1}{(2\pi f_0)^2L}\).
  2. \(f_0 = 530\) kHz: \(C = 1/\bigl((2\pi\cdot 5.3\times10^5)^2\cdot 2.4\times10^{-4}\bigr) \approx 376\) pF.
  3. \(f_0 = 1700\) kHz: \(C \approx 36.5\) pF. 1 MHz는 약 106 pF.
  4. 진동수 비가 약 3.2배이므로 \(C\)의 비는 그 제곱인 약 10배가 필요하다(\(f \propto 1/\sqrt C\)).

진동 절연: 받침대가 힘을 줄이려면

펌프의 진동이 바닥으로 새지 않게

회전하는 펌프는 불균형 때문에 운전 진동수로 흔들리는 힘을 냅니다. 고무나 스프링 받침대 위에 올리면 바닥으로 전해지는 힘이 줄어들까요? 받침대를 잘못 고르면 오히려 커질 수도 있을까요?

기계(질량 \(m\))가 받침대(\(k\), \(c\)) 위에서 \(F_0\cos\omega t\)의 힘을 받으면, 바닥으로 전해지는 힘은 용수철 힘과 감쇠 힘의 합 \(kx + cx'\)입니다. 정상 상태에서 그 진폭을 외력 진폭으로 나눈 비를 전달률(transmissibility)이라 합니다.

정리 8.9 (힘 전달률과 절연 조건)
$$T(r) = \frac{|kx + cx'|_{\max}}{F_0} = \frac{\sqrt{1 + (2\zeta r)^2}}{\sqrt{(1 - r^2)^2 + (2\zeta r)^2}}.$$
모든 \(\zeta\)에 대해 \(T(\sqrt2) = 1\)이고, \(r > \sqrt2\)일 때만 \(T \lt 1\)이다. 즉 진동 절연(vibration isolation)은 받침대의 고유 진동수가 운전 진동수의 \(1/\sqrt2\)배보다 낮을 때만 된다. 이 영역에서는 감쇠가 클수록 \(T\)가 오히려 커진다.

증명. \(x = X\cos(\omega t - \varphi)\)이면 \(kx + cx'\)의 진폭은 \(X\sqrt{k^2 + (c\omega)^2} = XK\sqrt{1 + (2\zeta r)^2}\)이고 \(X = (F_0/k)M(r)\)이다. \(T = 1\)은 \((1 - r^2)^2 = 1\), 즉 \(r^2 = 2\). ∎

예제 8.8 (받침대 고르기) 1800 rpm으로 도는 펌프의 힘이 바닥에 10%만 전해지게 하려면 받침대의 정적 처짐은 얼마여야 하는가? 감쇠는 작다고 보고 무시한다.
  1. 운전 진동수 \(\omega = 1800/60 \times 2\pi = 30 \times 2\pi \approx 188.5\) rad/s.
  2. \(\zeta \approx 0\)이면 \(T = 1/(r^2 - 1) = 0.1\), \(r^2 = 11\), \(r \approx 3.317\). 받침대의 \(\omega_0 = 188.5/3.317 \approx 56.8\) rad/s(약 9.0 Hz).
  3. 7장 예제 7.1처럼 \(\omega_0^2 = g/\delta\)이므로 \(\delta = 9.81/56.8^2 \approx 3.0\) mm. 기계를 올렸을 때 받침대가 3 mm 이상 눌리는 부드러운 받침대를 고른다.
  4. 실제로 \(\zeta = 0.1\)이면 \(T \approx 0.12\)로 조금 커진다. 하지만 펌프를 켜고 끌 때 회전수가 \(r = 1\)을 지나가므로, 그 순간의 공진을 누르려면 어느 정도 감쇠가 필요하다. 절연 설계는 이 둘의 타협이다.

이 도구가 쓰이는 곳

"사인파를 넣으면 같은 진동수의 사인파가 나오고, 진폭과 위상만 바뀐다"는 사실이 선형 시스템 공학 전체의 바탕입니다. 이 장의 \(M(r)\)과 \(\varphi(r)\)는 10장의 전달 함수 \(H(i\omega)\)의 크기와 편각이며, 진동·음향·제어·통신의 사양서는 모두 이 언어로 쓰입니다.

지진계와 가속도계: 같은 진동자, 다른 영역 센서 안의 작은 질량–용수철도 이 장의 진동자입니다. 고유 진동수보다 훨씬 높은 진동을 재면(\(r \gg 1\)) 질량이 거의 제자리에 머물러 상자에 대한 상대 변위가 곧 바닥의 변위가 됩니다. 장주기 지진계는 이 원리로 고유 진동수를 낮게 잡습니다. 거꾸로 고유 진동수보다 훨씬 낮은 진동을 재면(\(r \ll 1\)) 상대 변위가 바닥의 가속도에 비례하므로 가속도계가 됩니다. 스마트폰의 MEMS 가속도계는 고유 진동수를 높게 잡아 이 영역을 씁니다. 같은 방정식에서 강성 지배와 질량 지배라는 두 끝을 골라 쓰는 셈입니다.

핵심 정리

  1. 비동차 선형 방정식의 일반해는 \(x = x_h + x_p\). 감쇠계에서 \(x_h\)는 사라지는 과도 응답, \(x_p\)는 남는 정상 응답이다. 외력이 합이면 특수해도 합(중첩).
  2. 미정계수법: 외력과 같은 종류의 시험 함수를 넣고 계수를 맞춘다. \(g\)의 지수 \(\alpha + i\beta\)가 특성근과 \(s\)번 겹치면 \(t^s\)를 곱한다(수정 규칙).
  3. 매개변수 변환법: \(y_p = -y_1\int y_2g/W + y_2\int y_1g/W\). \(\sec t\) 같은 외력이나 변수계수 방정식에도 쓴다. \(y'' + y = \sec t\)이면 \(y_p = \cos t\ln|\cos t| + t\sin t\).
  4. 사인 외력: \(X = F_0/(k - m\omega^2 + ic\omega)\). 진폭비 \(M = 1/\sqrt{(1 - r^2)^2 + (2\zeta r)^2}\), 위상 지연 \(\tan\varphi = 2\zeta r/(1 - r^2)\), \(r = 1\)에서 \(\varphi = 90°\).
  5. 맥놀이: \(\cos\omega t - \cos\omega_0t = 2\sin\frac{(\omega_0 - \omega)t}{2}\sin\frac{(\omega_0 + \omega)t}{2}\), 주기 \(2\pi/|\omega_0 - \omega|\). 비감쇠 공진은 \(\frac{F_0}{2\omega_0}t\sin\omega_0t\)로 직선 성장.
  6. 감쇠 공진 봉우리 \(r = \sqrt{1 - 2\zeta^2}\), \(M_{\max} = 1/(2\zeta\sqrt{1 - \zeta^2})\). \(Q = 1/(2\zeta) \approx \omega_0/\Delta\omega\)(반치폭).
  7. 타코마 다리는 외부 주기력의 공진이 아니라 공기력이 유효 감쇠를 음수로 만든 플러터(자려 진동)였다. 진동 절연은 \(r > \sqrt2\)에서만 되고, 그 영역에서 감쇠는 전달률을 키운다.

확인 퀴즈

Q1. \(y'' - 4y = 3e^{2t}\)의 특수해로 알맞은 시험 함수는?

특성근은 \(\pm 2\)이고 2가 단근이므로 \(s = 1\). \(Ae^{2t}\)는 동차해라 \(L[Ae^{2t}] = 0\)이다. 계산하면 \(L[te^{2t}] = 4e^{2t}\)이므로 \(A = 3/4\), \(y_p = \frac34te^{2t}\).

Q2. \(y'' + y = 2\sin t\)의 특수해 꼴은?

\(\pm i\)가 특성근이므로 \(t\)를 곱한다. 대입하면 \(-2A\sin t + 2B\cos t = 2\sin t\)에서 \(A = -1\), \(B = 0\): \(y_p = -t\cos t\). 사인만 남기는 꼴 \(At\sin t\)로는 맞출 수 없다.

Q3. 감쇠 없는 진동자 \(x'' + 100x = \cos 9.8t\)를 정지 상태에서 밀기 시작했다. 맥놀이 주기는?

\(\omega_0 = 10\), \(\omega = 9.8\)이므로 포락선 \(|\sin(0.1t)|\)의 주기 \(2\pi/0.2 \approx 31.4\) s. 0.63 s는 빠른 진동의 주기 \(2\pi/9.9\)에 가깝다.

Q4. \(x'' + 2x' + 5x = 10\cos t\)의 정상 응답 진폭은?

\(X = 10/\sqrt{(5 - 1)^2 + 2^2} = 10/\sqrt{20} = \sqrt5\). 감쇠가 있으므로 진폭은 유한하고, 과도 응답 \(e^{-t}(\cdots)\)은 사라진다.

Q5. 고유 진동수 1000 rad/s, 감쇠비 \(\zeta = 0.02\)인 진동자의 Q 인자와 반치폭은 대략?

\(Q = 1/(2\zeta) = 25\), \(\Delta\omega \approx 2\zeta\omega_0 = \omega_0/Q = 40\) rad/s. 정확한 반전력 진동수는 \(r = 0.9794\), \(1.0194\)로 폭 0.0400.

Q6. 감쇠 진동자를 정확히 고유 진동수 \(\omega_0\)로 밀 때, 정상 상태에서 변위는 외력보다 위상이 얼마나 늦는가?

\(r = 1\)이면 \(\tan\varphi = 2\zeta/0\)이므로 \(\varphi = 90°\), 감쇠비와 무관하다. 그래서 속도가 외력과 같은 박자가 되어 외력이 매 순간 양의 일을 한다.

Q7. 받침대가 바닥으로 전해지는 힘을 줄이는(T < 1) 조건은?

\(T(r) \lt 1 \iff r > \sqrt2\)이고 이는 감쇠와 무관하다. 딱딱한 받침대(높은 \(\omega_0\))는 \(r\)이 작아 오히려 힘을 전하거나 키운다. \(r = 1\)은 최악의 경우다.

Q8. 타코마 내로스 다리 붕괴(1940)에 대한 설명으로 가장 정확한 것은?

그날의 바람은 주기적 외력이 아니었다. 공기력이 운동에 의존해 유효 감쇠를 음수로 만들었고, 외력 없이도 진동이 지수적으로 자랐다. 방정식으로는 \(F_0\cos\omega t\)가 아니라 \(c_{\rm eff} \lt 0\)인 문제다.
