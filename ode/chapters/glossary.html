용어집 & 종합 퀴즈

열여섯 장 동안 방향장, 적분 인자, 특성근, 공진, 전달 함수, 안장과 나선, 분기, 고유함수 같은 많은 이름을 만났습니다. 처음 보는 방정식 앞에서 실제로 필요한 질문은 대개 둘입니다. "이 꼴은 어떤 방법으로 풀지?"와 "풀지 않고도 해가 어떤 모양일지 알 수 있을까?" 이 장은 풀이법 고르기 도우미로 시작해, 특성근과 해 모양의 대응, 라플라스 변환표, 평형점 분류 지도를 한곳에 모으고, 용어를 검색한 뒤, 전 범위 종합 퀴즈로 마무리합니다.

  • 방정식의 계수·선형성·계수의 종류·입력·자율성을 보고 알맞은 풀이법과 해당 절을 찾는다.
  • 특성근(극점, 고유값)의 위치만 보고 해가 감쇠·진동·발산하는지 말한다.
  • 라플라스 변환쌍과 성질을 표에서 찾아 초기값 문제를 대수 문제로 바꾼다.
  • 대각합과 행렬식으로 2차원 평형점을 분류하고, 비선형 시스템의 선형화가 어디까지 믿을 만한지 판단한다.
  • 미분방정식 용어를 검색하고, 종합 퀴즈로 약한 장을 찾아 돌아간다.

풀이법 고르기 도우미

미분방정식은 "풀이법이 정해진 꼴"과 "그림과 수치로 봐야 하는 꼴"로 크게 나뉩니다. 먼저 물어볼 것은 늘 같습니다. 몇 계인가, 선형인가, 계수가 상수인가, 우변(입력)이 무엇인가, t가 식에 직접 나오는가. 아래에서 방정식의 특징을 고르면 먼저 써 볼 방법(강조된 칸)과 대안, 그리고 그 방법을 다룬 절로 가는 링크가 나옵니다.

특성근 ↔ 해 모양 한눈표

상수계수 선형 방정식 \(ay'' + by' + cy = 0\)에 \(y = e^{rt}\)를 넣으면 특성 방정식 \(ar^2 + br + c = 0\)이 나오고, 해의 모양은 근 \(r\)이 복소평면 어디에 있는가로 전부 정해집니다. 실수부는 커지거나 줄어드는 빠르기, 허수부는 진동의 각진동수입니다. 같은 그림이 세 번 나옵니다. 2계 방정식의 특성근(6장), 전달 함수의 극점(10장), 연립 방정식 \(\mathbf x' = A\mathbf x\)의 고유값(11장)입니다.

평형점 분류 지도: 대각합–행렬식 평면

2×2 선형 연립 \(\mathbf x' = A\mathbf x\)의 고유값은 특성 방정식 \(\lambda^2 - \tau\lambda + \Delta = 0\)의 근입니다(\(\tau = \operatorname{tr}A\), \(\Delta = \det A\)). 그러니 원점의 종류는 두 숫자 \(\tau, \Delta\)로 정해지고, 평면 위의 지도 하나에 모두 담깁니다(11장). 2계 방정식 \(y'' + cy' + ky = 0\)은 \(\mathbf x = (y, y')\)로 쓰면 \(\tau = -c\), \(\Delta = k\)이므로, 7장의 감쇠 세 영역도 이 지도의 왼쪽 절반에 그대로 들어 있습니다.

$$\lambda_{1,2} = \frac{\tau \pm \sqrt{\tau^2 - 4\Delta}}{2},\qquad \lambda_1 + \lambda_2 = \tau,\qquad \lambda_1\lambda_2 = \Delta.$$

비선형 시스템에서 이 지도를 쓰는 법 비선형 시스템 \(\mathbf x' = \mathbf f(\mathbf x)\)는 평형점 \(\mathbf x^*\)에서 야코비 행렬 \(J = D\mathbf f(\mathbf x^*)\)의 \((\tau, \Delta)\)를 이 지도에 찍습니다. 점이 넓은 영역(안장·마디·나선)에 있으면 평형점이 쌍곡이라 하트만–그로브만 정리에 따라 비선형계도 같은 종류입니다. 점이 경계, 특히 중심(\(\tau = 0\))에 있으면 선형화로는 판정할 수 없고, 보존량이나 리아푸노프 함수로 따로 확인해야 합니다(12장 선형화, 12장 리아푸노프). 매개변수를 바꿀 때 점이 세로축을 가로지르는 순간이 호프 분기(13장)입니다. 1차원 자율 방정식 \(y' = f(y)\)에서는 지도 대신 \(f'(y^*)\)의 부호 하나로 충분합니다(4장).
