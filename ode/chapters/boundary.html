Chapter 15

경계값 문제와 푸리에 급수

지금까지의 미분방정식은 모두 한 순간에서 출발했습니다. 처음 위치와 처음 속도를 주면 해가 하나로 정해지고, 우리는 그 해를 시간을 따라 그려 나갔습니다. 그런데 기타 줄은 양 끝이 묶여 있고, 기둥은 바닥과 천장에 고정되어 있으며, 막대의 온도는 양 끝에서 정해집니다. 조건이 두 지점에 나뉘어 있는 이런 문제를 경계값 문제라고 합니다. 경계값 문제는 해가 없을 수도, 무수히 많을 수도 있고, 바로 그 "해가 생기는 특별한 값"이 줄의 음높이와 기둥이 무너지는 하중을 정합니다. 이 장은 그 특별한 값(고유값)과 짝을 이루는 함수(고유함수)를 찾고, 고유함수들이 서로 직교한다는 사실에서 임의의 함수를 사인과 코사인으로 쪼개는 푸리에 급수를 얻습니다. 다음 장의 편미분방정식은 모두 이 도구 위에 서 있습니다.

  • 초기값 문제와 경계값 문제의 차이를 설명하고, 경계값 문제의 해가 없거나 무수히 많은 경우를 구별한다.
  • 슈팅 방법으로 경계값 문제를 초기값 문제의 근 찾기로 바꾸어 푼다.
  • 고유값 문제 \(y'' + \lambda y = 0\)을 여러 경계 조건에서 풀고, 기둥의 오일러 좌굴 하중을 유도한다.
  • 스튀름–리우빌 문제의 고유값이 실수이고 고유함수가 가중 직교함을 증명한다.
  • 함수 내적으로 직교 전개의 계수를 구하고, 푸리에 급수·사인 급수·코사인 급수를 짝·홀 확장으로 이해한다.
  • 수렴 정리, 기브스 현상, 파세발 등식을 설명하고, 강제 경계값 문제를 고유함수 전개로 푼다.
이 수식이 없었다면가늘고 높은 기둥

굵은 돌기둥은 짓눌려 부서질 때까지 버팁니다. 그러나 가늘고 긴 철 기둥은 재료가 버틸 수 있는 응력에 한참 못 미치는 하중에서 갑자기 옆으로 휘며 무너집니다. 이 현상이 좌굴입니다. 좌굴 하중은 재료의 강도가 아니라 경계값 문제가 0이 아닌 해를 갖기 시작하는 하중, 즉 고유값으로 정해집니다. 오일러(Leonhard Euler)는 18세기에 탄성 곡선을 연구하며 이 하중이 \(\pi^2 EI/L^2\)임을 보였습니다.

같은 수학은 기타 줄이 내는 음의 높이, 원자 안 전자의 에너지 준위, 막대가 식는 속도도 정합니다. 그리고 고유함수가 서로 직교한다는 성질 덕분에, 아무리 복잡한 초기 모양도 고유함수의 합으로 쪼개 각 성분을 따로 다룰 수 있습니다. 19세기 초 푸리에(Joseph Fourier)가 열 전도를 풀며 이 방법을 체계화했습니다.

초기값 대 경계값: 해가 없거나 무수히 많을 때

목표에 떨어지는 포물선

대포를 쏠 때 포수가 정하는 것은 처음 높이와 처음 속도입니다. 이것은 초기값 문제입니다. 하지만 포수가 실제로 원하는 것은 "300 m 앞의 목표에 떨어지는" 궤적, 즉 출발점과 도착점이 정해진 궤적입니다. 처음 기울기는 모르고, 대신 끝에서의 값을 압니다. 이런 문제도 늘 해가 하나일까요?

2계 방정식 \(y'' = f(x, y, y')\)에 대해 조건 두 개를 한 점에서 주면 초기값 문제, 두 점에서 나누어 주면 경계값 문제입니다.

정의 15.1 (2점 경계값 문제) 구간 \([a, b]\)에서 2계 방정식 \(y'' = f(x, y, y')\)와 양 끝의 조건
$$\alpha_1 y(a) + \beta_1 y'(a) = \gamma_1,\qquad \alpha_2 y(b) + \beta_2 y'(b) = \gamma_2$$
를 함께 푸는 문제를 2점 경계값 문제라 한다. \(\beta = 0\)이면 값을 주는 디리클레 조건(Dirichlet), \(\alpha = 0\)이면 기울기를 주는 노이만 조건(Neumann), 둘 다 0이 아니면 로뱅 조건(Robin)이라 한다. \(\gamma_1 = \gamma_2 = 0\)이고 방정식이 선형 동차이면 동차 경계값 문제다.

4장의 존재·유일성 정리(피카르–린델뢰프)는 초기값 문제에만 해당합니다. 경계값 문제에서는 아주 단순한 방정식에서도 세 가지가 모두 일어납니다.

예제 15.1 (같은 방정식, 세 가지 운명) \(y'' + y = 0\)의 일반해는 \(y = c_1\cos x + c_2\sin x\)이다. 왼쪽 조건 \(y(0) = 0\)에서 \(c_1 = 0\), 즉 \(y = c_2\sin x\).
  1. \(y(\pi/2) = 1\): \(c_2 = 1\). 해가 하나, \(y = \sin x\).
  2. \(y(\pi) = 1\): \(c_2\sin\pi = 0 \ne 1\). \(c_2\)를 어떻게 골라도 맞지 않는다. 해가 없다.
  3. \(y(\pi) = 0\): \(c_2\sin\pi = 0\)은 모든 \(c_2\)에서 성립한다. 해가 무수히 많다, \(y = c\sin x\).
(나)와 (다)의 차이는 오른쪽 값뿐이다. 구간의 길이가 마침 \(\pi\)라서 동차 문제(오른쪽 값 0)가 0이 아닌 해 \(\sin x\)를 가지기 때문에 이런 일이 생긴다.

이 관찰은 선형 경계값 문제 전체에 대한 정리로 바뀝니다. 증명은 일반해 \(y = y_p + c_1y_1 + c_2y_2\)를 두 경계 조건에 넣으면 \(c_1, c_2\)에 대한 2×2 연립 방정식이 된다는 데서 바로 나옵니다. 계수 행렬이 가역이면 해가 하나이고, 특이하면 해가 없거나 무수히 많습니다. 행렬이 특이하다는 것은 곧 동차 문제가 자명하지 않은 해를 가진다는 뜻입니다.

정리 15.2 (선형 경계값 문제의 양자택일) \(p, q, g\)가 \([a, b]\)에서 연속일 때 \(y'' + p(x)y' + q(x)y = g(x)\)와 위의 경계 조건에 대해 다음 중 정확히 하나가 성립한다.
  1. 대응하는 동차 문제(\(g = 0\), \(\gamma_1 = \gamma_2 = 0\))의 해가 \(y \equiv 0\)뿐이다. 그러면 모든 \(g, \gamma_1, \gamma_2\)에 대해 해가 꼭 하나 있다.
  2. 동차 문제가 0이 아닌 해를 가진다. 그러면 비동차 문제는 해가 없거나 무수히 많다.

손으로 풀 수 없는 경계값 문제는 어떻게 풀까요? 가장 직관적인 방법은 포수처럼 하는 것입니다. 처음 기울기 \(s\)를 하나 골라 초기값 문제로 쏘고(5장의 RK4), 도착점에서 얼마나 빗나갔는지 \(F(s) = y(b; s) - B\)를 잽니다. 그러면 경계값 문제는 한 변수 방정식 \(F(s) = 0\)의 근 찾기가 되고, 할선법으로 \(s\)를 고쳐 나가면 됩니다. 이것이 슈팅 방법(shooting method)입니다.

$$s_{k+1} = s_k - F(s_k)\,\frac{s_k - s_{k-1}}{F(s_k) - F(s_{k-1})}$$
선형 방정식이면 \(F(s)\)가 \(s\)의 1차 함수이므로 할선법이 한 번에 정확히 맞춘다. 비선형이면 \(F\)가 굽어 있어 몇 번 반복해야 하고, 근이 여럿일 수도 있다.
예제 15.2 (해가 둘인 비선형 경계값 문제) \(y'' = \tfrac32 y^2\), \(y(0) = 4\), \(y(1) = 1\).
  1. \(y = 4/(1 + x)^2\)을 넣어 본다. \(y'' = 24/(1+x)^4\)이고 \(\tfrac32 y^2 = \tfrac32\cdot 16/(1+x)^4 = 24/(1+x)^4\). 경계값도 \(y(0) = 4\), \(y(1) = 1\)로 맞다. 이 해의 처음 기울기는 \(y'(0) = -8\).
  2. 슈팅 함수 \(F(s)\)를 RK4로 그려 보면 \(s = -8\) 말고도 \(s \approx -35.86\)에서 한 번 더 0을 지난다. 이 두 번째 해는 처음에 가파르게 내려가 음수까지 내려갔다가 다시 올라와 \(y(1) = 1\)에 닿는다.
  3. 선형 문제의 양자택일(정리 15.2)은 비선형 문제에는 해당하지 않는다. 비선형 경계값 문제는 해가 둘일 수도 있다.

고유값 문제 y″ + λy = 0

줄은 어떤 모양으로만 떨 수 있는가

길이 \(L\)인 줄의 양 끝이 묶여 있습니다. 줄이 한 모양을 유지한 채 크기만 진동하려면, 그 모양 \(y(x)\)는 \(y'' = -\lambda y\)(휨의 정도가 변위에 비례)와 \(y(0) = y(L) = 0\)을 만족해야 합니다(16장에서 유도). \(\lambda\)는 진동수의 제곱에 비례합니다. 그런데 예제 15.1에서 보았듯이 이 동차 문제는 대부분의 \(\lambda\)에서 \(y \equiv 0\)밖에 해가 없습니다. 어떤 \(\lambda\)에서 줄이 실제로 떨 수 있을까요?

정의 15.3 (고유값과 고유함수) 매개변수 \(\lambda\)를 포함한 동차 경계값 문제가 \(y \not\equiv 0\)인 해를 가지는 \(\lambda\)를 고유값, 그때의 해 \(y\)를 그 고유값에 대응하는 고유함수(eigenfunction)라 한다. 고유함수의 상수배도 고유함수다.

행렬의 고유값 \(A\mathbf v = \lambda\mathbf v\)(LinearBook 고유값 장)과 같은 모양입니다. 연산자 \(-\frac{d^2}{dx^2}\)가 행렬 자리에, 함수 \(y\)가 벡터 자리에 있고, 경계 조건이 "어떤 함수들의 공간에서 연산자가 작용하는가"를 정합니다.

정리 15.4 (디리클레 고유값 문제) \(y'' + \lambda y = 0\), \(y(0) = 0\), \(y(L) = 0\)의 고유값과 고유함수는
$$\lambda_n = \left(\frac{n\pi}{L}\right)^2,\qquad y_n(x) = \sin\frac{n\pi x}{L},\qquad n = 1, 2, 3, \ldots$$

증명. \(\lambda\)의 부호로 나눈다. (i) \(\lambda = -\kappa^2 \lt 0\): \(y = c_1\cosh\kappa x + c_2\sinh\kappa x\). \(y(0) = 0\)에서 \(c_1 = 0\), \(y(L) = c_2\sinh\kappa L = 0\)인데 \(\sinh\kappa L > 0\)이므로 \(c_2 = 0\). (ii) \(\lambda = 0\): \(y = c_1 + c_2x\)이고 두 조건에서 \(c_1 = c_2 = 0\). (iii) \(\lambda = k^2 > 0\): \(y = c_1\cos kx + c_2\sin kx\), \(c_1 = 0\), \(c_2\sin kL = 0\). \(c_2 \ne 0\)이려면 \(\sin kL = 0\), 즉 \(kL = n\pi\). ∎

경계 조건이 바뀌면 고유값도 바뀝니다. 같은 방식으로 풀면 다음 표를 얻습니다(구간 \([0, L]\)).

고유값을 슈팅으로 찾을 수도 있습니다. 왼쪽 조건만 맞춘 해 \(y(x; \lambda)\)를 쏘고, 오른쪽 조건이 얼마나 빗나가는지를 \(\lambda\)의 함수로 그리면 그 함수의 0이 고유값입니다. 아래 시뮬레이터에서 \(\lambda\)를 움직여 보세요. 고유값을 지날 때마다 해곡선의 내부 영점이 하나씩 늘어납니다.

기둥의 좌굴: 오일러 하중

지름 20 mm, 길이 2 m의 강철 봉

강철의 항복 응력을 250 MPa로 잡으면, 지름 20 mm 봉(단면적 약 314 mm²)은 짓눌려 항복하기까지 약 78 kN을 버팁니다. 그런데 이 봉을 길이 2 m로 세우고 위에서 누르면 4 kN도 안 되는 하중에서 옆으로 휘어 버립니다. 무엇이 이 하중을 정할까요?

길이 \(L\)인 곧은 기둥의 양 끝을 핀(회전은 자유, 옆으로는 고정)으로 받치고 위에서 축 하중 \(P\)로 누릅니다. 기둥이 옆으로 \(y(x)\)만큼 휘었다고 하면, 높이 \(x\)의 단면에는 하중 \(P\)가 팔 길이 \(y\)로 만드는 굽힘 모멘트 \(M = -Py\)가 걸립니다. 보 이론에서 곡률은 모멘트에 비례하므로(작은 처짐에서 곡률 ≈ \(y''\)) \(EI\,y'' = M\)입니다. 여기서 \(E\)는 탄성 계수, \(I\)는 단면 2차 모멘트입니다.

$$EI\,y'' + P\,y = 0,\qquad y(0) = 0,\quad y(L) = 0.$$
\(\lambda = P/EI\)로 두면 정리 15.4의 고유값 문제 그 자체다. \(P\)가 고유값에 닿기 전에는 \(y \equiv 0\)(곧은 기둥)만 평형이고, 닿는 순간 휜 모양 \(\sin(\pi x/L)\)도 평형이 된다.
정리 15.5 (오일러 좌굴 하중) 양끝 핀 지지 기둥이 곧은 평형 말고 휜 평형을 가지기 시작하는 가장 작은 하중은
$$P_{\text{cr}} = \lambda_1 EI = \frac{\pi^2 EI}{L^2}$$
이다. 다른 지지 조건에서는 \(L\) 대신 유효 길이 \(KL\)을 쓴다: 한끝 고정·한끝 자유 \(K = 2\), 한끝 고정·한끝 핀 \(K \approx 0.699\), 양끝 고정 \(K = 0.5\).

더 큰 고유값 \(4P_{\text{cr}}, 9P_{\text{cr}}, \ldots\)도 휜 평형을 주지만, 하중을 0에서 서서히 올리면 가장 먼저 닿는 \(P_{\text{cr}}\)에서 이미 무너지므로 실제로 중요한 것은 첫 고유값입니다. 한끝 고정·한끝 핀의 \(K\)는 4계 보 방정식을 풀면 나오는 조건 \(\tan kL = kL\)의 가장 작은 양의 근 \(kL \approx 4.4934\)에서 \(K = \pi/4.4934 \approx 0.699\)로 얻습니다.

예제 15.3 (강철 봉의 좌굴 하중) \(E = 200\) GPa, 지름 \(d = 20\) mm, 길이 \(L = 2\) m인 양끝 핀 강철 봉.
  1. 원형 단면의 2차 모멘트: \(I = \pi d^4/64 = \pi(0.02)^4/64 \approx 7.854\times10^{-9}\) m⁴. 그러면 \(EI \approx 1571\) N·m².
  2. \(P_{\text{cr}} = \pi^2(1571)/2^2 \approx 3876\) N ≈ 3.88 kN. 문제 상자의 항복 하중 78 kN의 5%에 불과하다.
  3. 길이를 절반(1 m)으로 줄이면 \(L^2\)이 1/4이 되어 \(P_{\text{cr}} \approx 15.5\) kN. 같은 2 m라도 아래를 땅에 단단히 묻고 위를 자유롭게 두면(\(K = 2\)) 969 N밖에 되지 않는다.

실제 기둥은 완전히 곧지 않습니다. 처음부터 \(e_0\sin(\pi x/L)\)만큼 굽은 기둥을 누르면 방정식이 \(EI(y - y_0)'' + Py = 0\)이 되고, 풀면 처짐의 크기가 \(e_0/(1 - P/P_{\text{cr}})\)입니다. 하중이 임계값에 다가갈수록 처짐이 끝없이 커집니다. 이것이 좌굴이 "갑자기" 오는 것처럼 보이는 이유입니다.

스튀름–리우빌 문제와 고유함수의 직교성

굵기가 변하는 막대, 밀도가 다른 줄

단면적이 위치마다 다른 막대의 열 전도, 밀도가 고르지 않은 줄의 진동, 원형 북의 반지름 방향 모양(14장의 베셀 방정식)은 모두 \(y'' + \lambda y = 0\)보다 복잡한 계수를 가집니다. 고유함수를 식으로 쓸 수 없을 때도 사인 함수가 가졌던 좋은 성질, 특히 "서로 직교한다"는 성질이 남아 있을까요?

정의 15.6 (정칙 스튀름–리우빌 문제) \([a, b]\)에서 \(p, p', q, w\)가 연속이고 \(p > 0\), \(w > 0\)일 때
$$\bigl(p(x)\,y'\bigr)' + q(x)\,y + \lambda\,w(x)\,y = 0,\qquad \alpha_1 y(a) + \beta_1 y'(a) = 0,\quad \alpha_2 y(b) + \beta_2 y'(b) = 0$$
(각 조건에서 \(\alpha_i, \beta_i\)가 둘 다 0은 아님)를 스튀름–리우빌 문제(Sturm–Liouville problem)라 하고, \(w\)를 가중 함수(weight function)라 한다.

\(p = 1, q = 0, w = 1\)이면 \(y'' + \lambda y = 0\)입니다. 르장드르 방정식 \(((1 - x^2)y')' + \lambda y = 0\)과 베셀 방정식 \((xy')' - \frac{\nu^2}{x}y + \lambda xy = 0\)(14장)도 이 꼴인데, 끝점에서 \(p = 0\)이 되어 특이 스튀름–리우빌 문제라 부르고 경계 조건 대신 "끝점에서 유계"를 요구합니다. 계수가 \(y'' + P(x)y' + Q(x)y + \lambda R(x)y = 0\)처럼 주어져도 \(\mu = e^{\int P}\)를 곱하면 늘 이 꼴로 바꿀 수 있습니다(3장의 적분 인자와 같은 요령).

정리 15.7 (정칙 스튀름–리우빌 문제의 성질)
  1. 고유값은 모두 실수이고, 단순하며(고유값 하나에 고유함수는 상수배를 빼고 하나), \(\lambda_1 \lt \lambda_2 \lt \cdots \to \infty\)로 늘어선다.
  2. \(n\)번째 고유함수 \(\phi_n\)은 \((a, b)\) 안에 영점을 정확히 \(n - 1\)개 가진다.
  3. 서로 다른 고유값의 고유함수는 가중 함수 \(w\)에 대해 직교한다: \(\displaystyle\int_a^b \phi_m(x)\phi_n(x)\,w(x)\,dx = 0\) \((m \ne n)\).

셋째 성질의 증명은 짧고, 이 장 전체의 핵심입니다. 연산자 \(\mathcal L y = (py')' + qy\)라 두면 부분 적분 두 번으로 라그랑주 항등식을 얻습니다.

$$\int_a^b \bigl(u\,\mathcal L v - v\,\mathcal L u\bigr)\,dx = \Bigl[p\,(u v' - v u')\Bigr]_a^b.$$
\(u, v\)가 같은 경계 조건 \(\alpha y + \beta y' = 0\)을 만족하면 각 끝점에서 벡터 \((u, u')\)와 \((v, v')\)가 모두 \((\alpha, \beta)\)에 수직이라 서로 평행하고, 그래서 \(uv' - vu' = 0\)이다. 오른쪽이 사라진다.

직교성의 증명. \(\mathcal L\phi_m = -\lambda_m w\phi_m\), \(\mathcal L\phi_n = -\lambda_n w\phi_n\)을 항등식에 넣으면 \(0 = \int(\phi_m\mathcal L\phi_n - \phi_n\mathcal L\phi_m) = (\lambda_m - \lambda_n)\int_a^b \phi_m\phi_n w\,dx\). \(\lambda_m \ne \lambda_n\)이므로 적분이 0이다. ∎ 고유값이 실수인 것도 같은 항등식에 \(u = \phi\), \(v = \bar\phi\)를 넣으면 \((\lambda - \bar\lambda)\int|\phi|^2 w = 0\)에서 나옵니다.

라그랑주 항등식의 오른쪽이 사라진다는 것은 \(\langle u, \mathcal L v\rangle = \langle \mathcal L u, v\rangle\), 즉 \(\mathcal L\)이 경계 조건과 함께 대칭(자기 수반)이라는 뜻입니다. 대칭 행렬의 고유값이 실수이고 고유벡터가 직교한다는 스펙트럼 정리의 무한 차원판입니다.

예제 15.4 (고유값이 고르게 놓이지 않는 로뱅 문제) \(y'' + \lambda y = 0\), \(y(0) = 0\), \(y'(1) + y(1) = 0\).
  1. \(\lambda \le 0\)이면 자명한 해뿐임을 정리 15.4처럼 확인할 수 있다. \(\lambda = k^2 > 0\)이면 \(y(0) = 0\)에서 \(y = \sin kx\).

함수의 내적과 직교 전개

함수를 성분으로 쪼갤 수 있다면

3차원 벡터 \(\mathbf v\)를 직교 기저 \(\mathbf e_1, \mathbf e_2, \mathbf e_3\)로 쓰려면 연립 방정식을 풀 필요 없이 내적 하나로 성분을 읽습니다: \(c_k = \mathbf v\cdot\mathbf e_k/\|\mathbf e_k\|^2\). 고유함수들이 "직교"한다면, 함수도 같은 방식으로 고유함수 성분으로 쪼갤 수 있지 않을까요?

구간 \([a, b]\)에서 정의된 함수를 무한히 많은 성분을 가진 벡터로 봅니다. 점 \(x_1, \ldots, x_N\)에서의 값 \((f(x_1), \ldots, f(x_N))\)이 벡터이고, 두 벡터의 내적 \(\sum f(x_i)g(x_i)\Delta x\)에서 \(N \to \infty\)로 보낸 극한이 적분입니다.

정의 15.8 (함수 내적과 노름) 가중 함수 \(w > 0\)에 대해
$$\langle f, g\rangle_w = \int_a^b f(x)\,g(x)\,w(x)\,dx,\qquad \|f\| = \sqrt{\langle f, f\rangle_w}$$
를 함수 내적(inner product)과 노름이라 한다. \(\langle f, g\rangle_w = 0\)이면 \(f\)와 \(g\)는 직교한다. 서로 직교하는 함수의 모임 \(\{\phi_n\}\)을 직교 함수계라 한다.

\(f = \sum c_n\phi_n\)이라고 가정하고 양변에 \(\phi_m\)을 내적하면, 직교성 때문에 \(m = n\)인 항 하나만 남습니다. 그래서 계수는 연립 방정식 없이 하나씩 따로 정해집니다.

$$f(x) = \sum_{n} c_n\,\phi_n(x),\qquad c_n = \frac{\langle f, \phi_n\rangle_w}{\langle \phi_n, \phi_n\rangle_w} = \frac{\int_a^b f\,\phi_n\,w\,dx}{\int_a^b \phi_n^2\,w\,dx}.$$
이렇게 정한 급수를 \(f\)의 일반화 푸리에 급수 또는 고유함수 전개라 한다. \(c_n\phi_n\)은 \(f\)를 \(\phi_n\) 방향으로 정사영한 것이다.

정사영이라는 관점은 계수의 또 다른 뜻을 알려 줍니다. LinearBook 직교성 장에서 정사영은 부분공간에서 가장 가까운 점이었습니다. 함수에서도 같습니다.

정리 15.9 (최량 근사와 베셀 부등식) 직교 함수계 \(\phi_1, \ldots, \phi_N\)의 일차결합 \(\sum_{n\le N} d_n\phi_n\) 중에서 \(\|f - \sum d_n\phi_n\|\)을 가장 작게 하는 것은 \(d_n = c_n\)(위의 계수)일 때다. 또한
$$\sum_{n=1}^{N} c_n^2\,\|\phi_n\|^2 \le \|f\|^2\qquad\text{(베셀 부등식)}.$$

증명. \(\|f - \sum d_n\phi_n\|^2 = \|f\|^2 - 2\sum d_n\langle f, \phi_n\rangle + \sum d_n^2\|\phi_n\|^2 = \|f\|^2 - \sum c_n^2\|\phi_n\|^2 + \sum (d_n - c_n)^2\|\phi_n\|^2\). 마지막 합은 \(d_n = c_n\)일 때 0으로 가장 작고, 이때 왼쪽이 0 이상이므로 부등식이 나온다. ∎

항을 하나 더하면 앞의 계수를 다시 계산할 필요가 없다는 점도 중요합니다. 직교성 덕분에 \(c_n\)은 \(N\)과 상관없습니다. 다항식 \(1, x, x^2, \ldots\)처럼 직교하지 않는 함수로 최소제곱 근사를 하면 항을 더할 때마다 모든 계수가 바뀝니다.

예제 15.5 (상수 1을 사인으로) \([0, 1]\)에서 \(f = 1\)을 \(\phi_n = \sin n\pi x\)로 전개하라.
  1. \(\|\phi_n\|^2 = \int_0^1\sin^2 n\pi x\,dx = \tfrac12\).
  2. \(\langle 1, \phi_n\rangle = \int_0^1\sin n\pi x\,dx = \frac{1 - \cos n\pi}{n\pi} = \frac{1 - (-1)^n}{n\pi}\). 홀수 \(n\)이면 \(2/(n\pi)\), 짝수이면 0.
  3. \(c_n = 4/(n\pi)\) (홀수 \(n\)), 즉 \(1 = \frac4\pi\bigl(\sin\pi x + \frac13\sin3\pi x + \frac15\sin5\pi x + \cdots\bigr)\), \(0 \lt x \lt 1\).
  4. \(x = \tfrac12\)을 넣으면 \(1 = \frac4\pi(1 - \frac13 + \frac15 - \cdots)\), 즉 라이프니츠 급수 \(1 - \frac13 + \frac15 - \cdots = \frac\pi4\)가 덤으로 나온다.

푸리에 급수: 사인·코사인 급수와 짝·홀 확장

한 주기의 모양을 배음으로

전력 전자 회로의 사각파 전압, 톱니파 스캔 신호, 바이올린 음의 파형은 모두 주기 함수입니다. 각 주파수 성분이 얼마나 들어 있는지 알면, 회로가 각 성분에 어떻게 반응하는지(8장의 주파수 응답) 따로 계산해 더할 수 있습니다.

주기 조건의 고유함수 \(1, \cos\frac{n\pi x}{L}, \sin\frac{n\pi x}{L}\)은 \([-L, L]\)에서 서로 직교합니다(정리 15.7). 이 직교 함수계로 전개한 것이 고전적인 푸리에 급수입니다.

정의 15.10 (푸리에 급수) 주기 \(2L\)인 함수 \(f\)의 푸리에 급수(Fourier series)는
$$f(x) \sim \frac{a_0}{2} + \sum_{n=1}^\infty\Bigl(a_n\cos\frac{n\pi x}{L} + b_n\sin\frac{n\pi x}{L}\Bigr),$$ $$a_n = \frac1L\int_{-L}^{L} f(x)\cos\frac{n\pi x}{L}\,dx,\qquad b_n = \frac1L\int_{-L}^{L} f(x)\sin\frac{n\pi x}{L}\,dx.$$
\(\|\cos\|^2 = \|\sin\|^2 = L\)이고 \(\|1\|^2 = 2L\)이라서 \(a_0\)에 \(\tfrac12\)이 붙는다. \(a_0/2\)는 한 주기의 평균값이다. \(\sim\)은 "이 급수가 대응한다"는 뜻이고, 언제 등호가 되는지는 다음 절에서 다룬다.

짝함수 \(f(-x) = f(x)\)이면 \(f\sin\)이 홀함수라 \(b_n = 0\), 코사인만 남습니다. 홀함수이면 \(a_n = 0\), 사인만 남습니다. 이 사실을 거꾸로 쓰면 \([0, L]\)에서만 정의된 함수(막대의 온도, 줄의 모양)를 세 가지 방식으로 전개할 수 있습니다.

정리 15.11 (푸리에 급수의 수렴) 주기 \(2L\)인 \(f\)가 구간별로 매끄럽다(한 주기 안에서 \(f\)와 \(f'\)이 유한 개의 점을 빼고 연속이고, 그 점들에서 좌우 극한이 있다)고 하자.
  1. 푸리에 급수는 모든 \(x\)에서 \(\tfrac12\bigl(f(x^+) + f(x^-)\bigr)\)로 수렴한다. \(f\)가 연속인 점에서는 \(f(x)\)로 수렴한다.
  2. \(f\)가 모든 곳에서 연속(주기 확장까지 포함)이면 수렴은 균등하다: \(\max|f - S_N| \to 0\).

파세발 등식: 에너지는 계수에 나뉘어 담긴다

항 몇 개면 충분한가

신호를 압축하거나 진동을 해석할 때 묻는 것은 "처음 몇 개의 배음이 전체 에너지의 몇 %를 담는가"입니다. 베셀 부등식(정리 15.9)은 계수의 제곱합이 전체 에너지를 넘지 않는다고만 말했습니다. 언제 정확히 같아질까요?

정리 15.13 (파세발 등식) \(f\)와 \(f^2\)이 \([-L, L]\)에서 적분 가능하면
$$\frac1L\int_{-L}^{L} f(x)^2\,dx = \frac{a_0^2}{2} + \sum_{n=1}^\infty\bigl(a_n^2 + b_n^2\bigr).$$
사인 급수만 쓰는 반구간 전개라면 \(\frac2L\int_0^L f^2\,dx = \sum b_n^2\). 이때 \(\|f - S_N\|^2 = \frac L2\sum_{n>N}b_n^2 \to 0\), 즉 부분합은 평균 제곱의 뜻으로 \(f\)에 수렴한다.

파세발 등식은 피타고라스 정리의 무한 차원판입니다. 서로 직교하는 성분으로 쪼갠 벡터의 길이 제곱은 성분 길이 제곱의 합입니다. 베셀 부등식이 등식이 된다는 것은 삼각 함수계가 완비하다는 뜻, 즉 빠진 방향이 없다는 뜻입니다. 직교성과 완비성이 함께 있어야 "모든 함수를 전개할 수 있다"가 성립합니다.

예제 15.7 (바젤 문제) 예제 15.6의 톱니파 \(f = x\) (\(-\pi \lt x \lt \pi\))에 파세발 등식을 써라.
  1. 왼쪽: \(\frac1\pi\int_{-\pi}^\pi x^2\,dx = \frac1\pi\cdot\frac{2\pi^3}{3} = \frac{2\pi^2}{3}\).
  2. 오른쪽: \(b_n^2 = 4/n^2\)이므로 \(\sum 4/n^2\).
  3. 같다고 놓으면 \(\displaystyle\sum_{n=1}^\infty\frac1{n^2} = \frac{\pi^2}{6}\). 오일러가 처음 구한 이 합이 푸리에 급수 한 줄에서 나온다.
  4. 에너지 분배: 첫 항 \(b_1^2 = 4\)는 전체 \(2\pi^2/3 \approx 6.58\)의 약 61%뿐이다. 같은 계산을 \(x(\pi - x)\)의 사인 급수로 하면 첫 항이 99.86%를 담는다. 매끄러운 함수일수록 에너지가 낮은 차수에 몰린다.

장력 1로 당긴 줄(길이 π)의 양 끝을 묶고 위치마다 다른 하중 \(f(x)\)를 얹습니다. 줄이 탄성 기초 위에 놓여 있거나, 줄 전체가 진동수 \(\sqrt\mu\)로 흔들리고 있으면 방정식에 \(\mu y\) 항이 붙습니다. \(y'' + \mu y = -f(x)\), \(y(0) = y(\pi) = 0\). 하중이 복잡해도 풀 수 있을까요? 언제 해가 터질까요?

8장의 강제 진동에서 우리는 입력을 사인 성분으로 나누어 각 성분의 응답을 더했습니다. 공간에서도 똑같이 합니다. 핵심은 고유함수 \(\phi_n = \sin nx\)에 연산자가 작용하면 그냥 수가 곱해진다는 것입니다: \(\phi_n'' + \mu\phi_n = (\mu - n^2)\phi_n\).

  1. 하중을 고유함수로 전개한다: \(f(x) = \sum f_n\sin nx\), \(f_n = \frac2\pi\int_0^\pi f\sin nx\,dx\).
  2. 해도 같은 꼴로 둔다: \(y = \sum c_n\sin nx\). 경계 조건은 저절로 맞는다.
  3. 방정식에 넣으면 \(\sum c_n(\mu - n^2)\sin nx = -\sum f_n\sin nx\). 직교성으로 성분마다 비교한다.
$$c_n = \frac{f_n}{n^2 - \mu}\qquad\Longrightarrow\qquad y(x) = \sum_{n=1}^\infty\frac{f_n}{\lambda_n - \mu}\,\phi_n(x).$$
미분방정식이 성분마다 나눗셈 하나로 바뀌었다. \(1/(\lambda_n - \mu)\)는 \(n\)번째 모드의 증폭률이다. \(\mu\)가 고유값 \(\lambda_n = n^2\)에 다가가면 그 모드가 공진처럼 커진다.
정리 15.14 (프레드홀름 양자택일) \(\mu\)가 고유값이 아니면 \(y'' + \mu y = -f\), \(y(0) = y(\pi) = 0\)은 모든 연속 \(f\)에 대해 해가 꼭 하나 있다. \(\mu = \lambda_k\)이면 해는 \(\langle f, \phi_k\rangle = 0\)일 때만 존재하고, 그때는 \(c_k\)가 임의라 해가 무수히 많다.

정리 15.2를 성분의 언어로 다시 쓴 것입니다. 하중이 공진 모드와 직교하면, 즉 그 모드를 "밀지" 않으면 공진 조건에서도 해가 있습니다. 기타 줄의 한가운데를 튕기면 가운데가 마디인 2배음이 생기지 않는 것과 같은 원리입니다(16장).

  2. \(c_n = f_n/n^2 = 2(-1)^{n+1}/n^3\). 하중 계수는 \(1/n\)로 느리게 줄었지만 해의 계수는 \(1/n^3\)으로 빠르게 준다. 두 번 적분하면 매끄러워진다.

  4. 기둥의 좌굴은 EIy″ + Py = 0의 첫 고유값: Pcr = π²EI/(KL)². 처음 굽음은 1/(1 − P/Pcr)로 확대된다.
  5. 스튀름–리우빌 문제 (py′)′ + qy + λwy = 0은 실수이고 늘어서는 고유값, n − 1개의 영점, 가중 직교성을 가진다. 증명의 열쇠는 라그랑주 항등식(연산자의 대칭성)이다.
  6. 직교 전개의 계수는 cₙ = ⟨f, φₙ⟩/⟨φₙ, φₙ⟩, 즉 정사영이고 최소제곱의 뜻에서 최량 근사다. 반구간 전개에서 홀 확장은 사인 급수, 짝 확장은 코사인 급수를 준다.
  7. 구간별로 매끄러운 함수의 푸리에 급수는 점프에서 좌우 극한의 평균으로 수렴한다. 점프마다 약 8.95%의 기브스 넘침이 남는다. 계수 감소는 1/n(점프), 1/n²(꺾임), 1/n³ 순으로 매끄러움을 반영한다.

확인 퀴즈

Q1. \(y'' + 4y = 0\), \(y(0) = 0\), \(y(\pi/2) = 3\)의 해는?

\(y(0) = 0\)에서 \(y = c\sin 2x\). \(x = \pi/2\)에서 \(\sin\pi = 0\)이므로 \(y(\pi/2) = 0 \ne 3\). 구간 길이 \(\pi/2\)가 마침 \(\lambda = 4\)의 고유값을 만드는 길이라서 동차 문제가 0이 아닌 해를 가지고, 오른쪽 값이 0이 아니면 해가 없다(정리 15.2).

Q2. \(y'' + \lambda y = 0\), \(y(0) = 0\), \(y'(L) = 0\)의 가장 작은 고유값은?

\(y = \sin kx\)이고 \(y'(L) = k\cos kL = 0\)에서 \(kL = \pi/2, 3\pi/2, \ldots\). 가장 작은 값은 \(k = \pi/(2L)\), \(\lambda_1 = \pi^2/(4L^2)\). 한끝이 자유로운 줄(또는 한끝 고정 기둥)은 양끝 고정보다 고유값이 1/4이다.

Q3. 양끝 핀으로 받친 기둥의 길이를 두 배로 하고, 아래쪽만 바닥에 고정하고 위를 자유롭게 바꾸었다. 좌굴 하중은 원래의 몇 배인가?

\(P_{\text{cr}} = \pi^2EI/(KL)^2\). 원래는 \(KL = L\). 바꾼 뒤에는 \(K = 2\), 길이 \(2L\)이므로 \(KL = 4L\), 하중은 \(1/16\)배.

Q4. 스튀름–리우빌 문제의 고유함수 직교성 증명에서 경계 조건은 어떤 역할을 하는가?

두 고유함수가 같은 조건 \(\alpha y + \beta y' = 0\)을 만족하면 각 끝에서 \(uv' - vu' = 0\)이다. 그러면 \((\lambda_m - \lambda_n)\int\phi_m\phi_n w = 0\)만 남아 직교성이 나온다. 경계 조건이 연산자를 대칭으로 만드는 것이다.

Q5. \(f(x) = x\)를 \([0, \pi]\)에서 반구간 전개할 때, 계수가 더 빨리 줄어드는 쪽과 그 이유는?

홀 확장은 \(x = \pi\)에서 \(\pi\)에서 \(-\pi\)로 뛰어 계수가 \(2/n\)으로 줄고, 짝 확장은 \(|x|\)의 주기 확장(삼각파)으로 연속이라 계수가 \(1/n^2\)로 준다. 같은 \([0, \pi]\) 위의 함수라도 확장에 따라 수렴 속도가 다르다.

Q6. 사각파의 푸리에 부분합에서 항 수를 10배로 늘리면 점프 근처의 넘침(기브스 귀)은?

첫 극대 위치는 \(\pi/(N + 1)\)로 좁아지지만 높이는 \(\frac2\pi\mathrm{Si}(\pi) \approx 1.179\)로 간다(점프 2의 8.95%). 각 점에서는 수렴하지만 균등 수렴은 아니다. 넘침을 없애려면 페예르 합 같은 창을 쓴다.

Q7. \([0, \pi]\)에서 \(f = 1\)의 사인 급수 \(\frac4\pi\sum_{n\,\text{홀수}}\frac{\sin nx}{n}\)에 파세발 등식 \(\frac2\pi\int_0^\pi f^2dx = \sum b_n^2\)을 쓰면 얻는 합은?

왼쪽은 \(\frac2\pi\cdot\pi = 2\), 오른쪽은 \(\frac{16}{\pi^2}\sum_{\text{홀수}}\frac1{n^2}\). 따라서 \(\sum_{\text{홀수}}1/n^2 = \pi^2/8\). 짝수 항까지 더하면 \(\frac{\pi^2}{8}\cdot\frac43 = \frac{\pi^2}{6}\)으로 바젤 합과 맞는다.

Q8. \(y'' + 4y = -\sin x\), \(y(0) = y(\pi) = 0\)의 해는?

μ = 4 = λ₂는 고유값이지만 하중 \(\sin x\)는 \(\phi_2 = \sin 2x\)와 직교하므로 해가 있다(정리 15.14). \(c_1 = f_1/(1 - 4) = -1/3\)이고 \(c_2\)는 임의. 검산: \(y = -\frac13\sin x\)이면 \(y'' + 4y = \frac13\sin x - \frac43\sin x = -\sin x\).
