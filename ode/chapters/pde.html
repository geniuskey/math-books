편미분방정식 입문

막대의 온도는 시간에만 달려 있지 않고 위치에도 달려 있습니다. 줄의 변위도, 판의 퍼텐셜도 마찬가지입니다. 미지 함수가 변수 둘 이상에 달려 있고 그 편도함수 사이의 관계로 법칙이 쓰이면 편미분방정식입니다. 이 장은 공학의 세 기본 편미분방정식인 열 방정식, 파동 방정식, 라플라스 방정식을 물리 법칙에서 세우고, 15장의 고유함수 전개로 풉니다. 열쇠는 변수분리입니다. 해를 공간 모양 × 시간 변화로 쪼개면 공간 부분은 15장의 고유값 문제가, 시간 부분은 1장부터 다뤄 온 상미분방정식이 됩니다. 마지막으로 컴퓨터가 이 방정식들을 격자 위에서 푸는 방법과, 시간 간격을 잘못 고르면 해가 터지는 이유를 봅니다.

  • 푸리에의 열전도 법칙과 에너지 보존에서 열 방정식 \(u_t = \alpha u_{xx}\)를, 장력의 균형에서 파동 방정식 \(u_{tt} = c^2u_{xx}\)를 유도한다.
  • 변수분리법으로 편미분방정식을 고유값 문제와 상미분방정식으로 나누고, 초기 조건을 푸리에 급수로 맞춘다.
  • 디리클레·노이만·비동차 경계 조건에서 열 방정식을 풀고, 높은 모드일수록 빨리 사라지는 이유를 설명한다.
  • 줄의 정규 모드와 배음, 튕기는 위치와 배음 구성의 관계, 달랑베르 해와 끝에서의 반사를 이해한다.
  • 라플라스 방정식을 사각 판에서 풀고, 평균값 성질과 최대 원리로 정상 상태를 해석한다.
  • 명시적 유한 차분법을 구성하고 안정성 조건 \(r \le 1/2\)과 CFL 조건 \(c\Delta t/\Delta x \le 1\)을 폰 노이만 분석으로 유도한다.

트랜지스터를 만들려면 실리콘 웨이퍼 표면에서 불순물(도펀트) 원자를 정해진 깊이까지 넣어야 합니다. 고온의 확산로에서 도펀트는 농도가 높은 곳에서 낮은 곳으로 퍼져 들어가는데, 이 퍼짐을 지배하는 것이 열 방정식과 같은 꼴의 확산 방정식입니다. 접합 깊이를 마이크로미터 이하로 맞추려면 몇 분, 몇 도에서 확산시켜야 하는지를 이 방정식의 해 \(\operatorname{erfc}\)와 가우스 분포가 알려 줍니다.

이 방정식이 처음 정식화된 것은 열에 대해서였습니다. 푸리에(Joseph Fourier)는 1822년 『열의 해석적 이론』에서 열 흐름이 온도 기울기에 비례한다는 법칙으로 열 방정식을 세우고, 해를 사인 급수로 전개해 풀었습니다. 같은 방법이 줄의 진동, 정전기 퍼텐셜, 확산에 그대로 쓰입니다.

국소 법칙 (플럭스 ∝ 기울기)→편미분방정식→변수분리 + 고유함수 전개→모드마다 따로 푸는 상미분방정식

열 방정식: 푸리에 법칙에서

한쪽 끝을 불에 댄 쇠막대

쇠막대 한쪽을 불에 대면 손잡이 쪽이 서서히 뜨거워집니다. 막대의 온도 \(u(x, t)\)는 위치 \(x\)와 시간 \(t\) 두 변수의 함수입니다. 3장의 뉴턴 냉각 법칙은 물체 전체를 온도 하나로 보았기 때문에 이 "퍼짐"을 설명하지 못합니다. 위치마다 다른 온도가 어떻게 시간에 따라 변할까요?

모델링의 순서(1장)를 따릅니다. 옆면이 단열된 가는 막대(단면적 \(A\), 밀도 \(\rho\), 비열 \(c_p\), 열전도도 \(k\))를 생각합니다.

  1. 구성 법칙 (푸리에 법칙): 단위 면적당 열 흐름(열 플럭스)은 온도 기울기에 비례하고, 뜨거운 쪽에서 찬 쪽으로 흐른다. \(q = -k\,u_x\).
  2. 보존 법칙: 짧은 구간 \([x, x + \Delta x]\)에 쌓이는 열에너지의 변화율 = 왼쪽으로 들어오는 열 − 오른쪽으로 나가는 열. \(\rho c_pA\Delta x\,u_t = A\bigl(q(x) - q(x + \Delta x)\bigr)\).
  3. \(\Delta x\)로 나누고 \(\Delta x \to 0\): \(\rho c_p u_t = -q_x = k\,u_{xx}\).
정의 16.1 (1차원 열 방정식)
$$u_t = \alpha\,u_{xx},\qquad \alpha = \frac{k}{\rho c_p}$$
을 열 방정식(heat equation)이라 하고, \(\alpha\)(m²/s)를 열확산율(thermal diffusivity)이라 한다. 구리의 열확산율은 약 \(1.1\times10^{-4}\) m²/s다. 같은 꼴의 방정식이 물질의 확산(픽의 법칙, \(\alpha\) 대신 확산 계수 \(D\))에도 성립한다.

방정식은 한 문장으로 읽힙니다. 온도 그래프가 아래로 볼록한 곳(\(u_{xx} > 0\), 주변보다 찬 골짜기)은 데워지고, 위로 볼록한 곳(봉우리)은 식는다. 그래서 열 방정식은 모든 굴곡을 평평하게 펴는 방향으로 움직이고, 뾰족한 굴곡일수록 \(|u_{xx}|\)가 커서 빨리 펴집니다. 이 관찰이 다음 절의 "높은 모드일수록 빨리 사라진다"는 결론의 예고입니다.

상미분방정식에서 초기값 하나가 해를 정했듯이, 열 방정식에는 초기 조건 \(u(x, 0) = f(x)\)와 양 끝의 경계 조건이 함께 필요합니다. 이 묶음을 초기–경계값 문제라 합니다.

변수분리법과 고유함수 전개

양 끝을 얼음물에 담근 막대

길이 \(L\)인 막대의 처음 온도 분포가 \(f(x)\)이고, 양 끝을 0 °C로 유지합니다. \(u_t = \alpha u_{xx}\), \(u(0, t) = u(L, t) = 0\), \(u(x, 0) = f(x)\). 변수가 둘인 함수를 어떻게 찾을까요?

모양이 변하지 않고 크기만 변하는 해부터 찾습니다. \(u(x, t) = X(x)\,T(t)\)라 두면 \(XT' = \alpha X''T\)이고, 양변을 \(\alpha XT\)로 나누면

$$\frac{T'(t)}{\alpha\,T(t)} = \frac{X''(x)}{X(x)} = -\lambda.$$
왼쪽은 \(t\)만의 함수, 오른쪽은 \(x\)만의 함수다. 둘이 모든 \(x, t\)에서 같으려면 둘 다 같은 상수여야 한다. 그 상수를 \(-\lambda\)로 둔다. 이것이 변수분리법(separation of variables)의 핵심 한 줄이다.

편미분방정식 하나가 상미분방정식 둘로 갈라졌습니다.

  • 공간: \(X'' + \lambda X = 0\), \(X(0) = X(L) = 0\). 경계 조건이 \(u\)에서 \(X\)로 그대로 넘어온다. 이것은 15장의 고유값 문제(정리 15.4)이고, \(\lambda_n = (n\pi/L)^2\), \(X_n = \sin(n\pi x/L)\).
  • 시간: \(T' = -\alpha\lambda_nT\). 2장의 지수 붕괴이고 \(T_n = e^{-\alpha\lambda_nt}\).

곱 \(u_n = e^{-\alpha(n\pi/L)^2t}\sin(n\pi x/L)\)는 방정식과 경계 조건을 모두 만족합니다. 방정식과 경계 조건이 선형 동차이므로 이들의 일차결합도 해입니다(중첩 원리, 6장). 남은 것은 초기 조건뿐이고, 그것은 15장의 사인 급수가 맞춰 줍니다.

정리 16.2 (양끝 0 °C 막대의 해) \(f\)가 \([0, L]\)에서 구간별로 매끄러우면
$$u(x, t) = \sum_{n=1}^\infty b_n\,e^{-\alpha(n\pi/L)^2t}\,\sin\frac{n\pi x}{L},\qquad b_n = \frac2L\int_0^L f(x)\sin\frac{n\pi x}{L}\,dx$$
는 \(t > 0\)에서 열 방정식과 경계 조건을 만족하고 \(t \to 0^+\)일 때 \(f\)로 간다. \(t > 0\)이면 급수가 아주 빨리 수렴해 \(u\)는 \(x\)에 대해 무한히 매끄럽다.

마지막 문장이 열 방정식의 성격입니다. 처음 분포가 불연속이어도(뜨거운 조각과 찬 조각을 맞붙여도) 아주 짧은 시간 뒤에는 매끄러워집니다. 계수에 \(e^{-\alpha n^2\pi^2t/L^2}\)이 곱해져 높은 \(n\)이 순식간에 사라지기 때문입니다.

예제 16.1 (두 모드로 된 처음 온도) \(L = 1\) m, \(\alpha = 1.0\times10^{-4}\) m²/s(구리에 가까운 값)인 막대의 처음 온도가 \(f(x) = 100\sin\pi x + 50\sin3\pi x\) (°C)이고 양 끝이 0 °C다. \(t = 600\) s(10분)에 가운데 온도는?
  1. \(f\)가 이미 사인 급수이므로 \(b_1 = 100\), \(b_3 = 50\), 나머지 0.
  2. 각 모드의 시상수 \(\tau_n = L^2/(\alpha n^2\pi^2)\): \(\tau_1 = 1/(10^{-4}\pi^2) \approx 1013\) s, \(\tau_3 = \tau_1/9 \approx 113\) s.
  3. \(u(\tfrac12, 600) = 100e^{-600/1013}\sin\tfrac\pi2 + 50e^{-600/113}\sin\tfrac{3\pi}{2} \approx 100(0.553) - 50(0.0049) \approx 55.1\) °C.
  4. 10분 뒤 3번 모드는 처음의 0.5%만 남았다. 처음 모양이 무엇이었든 시간이 지나면 \(\sin\pi x\) 모양 하나로 수렴한다. (유한 차분으로 계산해도 55.07 °C.)
예제 16.2 (고르게 뜨거운 막대) 처음 온도가 어디나 \(100\) °C이고 양 끝을 0 °C로 낮추었다.
  1. 15장 예제 15.5에서 \(1 = \frac4\pi\sum_{n\,\text{홀수}}\frac1n\sin\frac{n\pi x}{L}\)이므로 \(b_n = \frac{400}{n\pi}\) (홀수 \(n\)).
  2. \(u(x, t) = \frac{400}{\pi}\sum_{n\,\text{홀수}}\frac1n e^{-\alpha n^2\pi^2t/L^2}\sin\frac{n\pi x}{L}\).
  3. 가운데가 50 °C까지 식는 시각: 무차원 시간 \(\tau = \alpha t/L^2\)으로 쓰면 첫 항만으로 \(\frac{400}{\pi}e^{-\pi^2\tau} = 50\), \(\tau \approx 0.0947\). 모든 항을 쓴 값도 0.0947이다. 위 막대라면 \(t \approx 947\) s.
  4. \(\tau\)로 쓰면 결과가 막대 길이와 재료에 상관없다. 길이를 절반으로 줄이면 같은 식힘에 걸리는 시간은 1/4이다(\(t \propto L^2\)).

모드별 감쇠: 높은 모드가 먼저 죽는다

정리 16.2의 각 항은 서로 간섭하지 않고 자기 속도로 감쇠합니다. \(n\)번째 모드의 감쇠율은 \(\alpha n^2\pi^2/L^2\), 즉 \(n^2\)에 비례합니다. 3번 모드는 1번 모드보다 9배, 10번 모드는 100배 빨리 사라집니다. 로그 축에서 각 계수 \(\ln|b_n(t)|\)는 기울기 \(-n^2\pi^2\)인 직선입니다.

이 사실에서 공학적으로 중요한 결론 세 가지가 나옵니다.

  1. 긴 시간에는 첫 모드만 남는다. \(t \gg \tau_2\)이면 \(u \approx b_1e^{-t/\tau_1}\sin(\pi x/L)\). 식는 물체의 온도는 결국 하나의 지수 함수로 떨어지고, 그 시상수가 \(\tau_1 = L^2/(\alpha\pi^2)\)이다. 3장의 뉴턴 냉각이 "충분히 오래 지난 뒤"의 근사로 정당화된다.
  2. 크기는 \(L^2\)으로 늘어난다. 두께가 두 배인 벽은 열이 퍼지는 데 네 배 걸린다. 칠면조를 굽는 시간, 강철 담금질 시간이 크기의 제곱에 비례하는 이유다.
  3. 거꾸로 가는 열 방정식은 풀 수 없다. 시간을 뒤로 돌리면 \(e^{+n^2\pi^2\tau}\)가 곱해져 측정 오차의 높은 모드가 폭발한다. 흐려진 온도 분포에서 처음 분포를 복원하는 문제는 불량 조건이다.

경계 조건: 디리클레, 노이만, 그리고 정상 상태

단열재로 감싼 끝, 다른 온도로 유지한 끝

실제 막대의 끝은 늘 얼음물에 담겨 있지 않습니다. 한쪽은 보온재로 감싸여 열이 드나들지 못하고, 다른 쪽은 엔진 블록에 붙어 90 °C를 유지할 수도 있습니다. 경계 조건이 바뀌면 해는 어떻게 바뀔까요?

경계 조건물리적 뜻공간 고유함수긴 시간 뒤
디리클레 u = 0끝을 정해진 온도로 유지sin(nπx/L), n ≥ 1u → 0
노이만 ux = 0단열: 열 플럭스 0cos(nπx/L), n ≥ 0u → 처음 평균값
비동차 디리클레 u(0) = T₁, u(L) = T₂양 끝을 다른 온도로정상 해 + sin 급수u → 직선
로뱅 ux = −h(u − T∞)표면에서 대류 냉각sin(kₙx), tan 방정식의 근u → T∞

노이만 조건에서는 \(n = 0\) 모드(상수, \(\lambda_0 = 0\))가 감쇠하지 않습니다. 그 계수가 \(a_0/2 = \frac1L\int_0^L f\,dx\), 즉 처음 평균 온도입니다. 열이 빠져나갈 곳이 없으니 총 열량이 보존되고, 결국 그 열량이 고르게 퍼진 상태가 됩니다. 실제로 \(\frac{d}{dt}\int_0^L u\,dx = \alpha\int_0^L u_{xx}\,dx = \alpha[u_x]_0^L = 0\)입니다.

비동차 경계 조건은 변수분리를 바로 쓸 수 없습니다(0이 아닌 경계값은 \(X(0)T(t) = T_1\)을 모든 \(t\)에서 만족시킬 수 없음). 대신 해를 두 부분으로 나눕니다. 시간에 따라 변하지 않는 정상 상태 \(u_s(x)\)는 \(u_s'' = 0\)이므로 직선 \(u_s = T_1 + (T_2 - T_1)x/L\)이고, 나머지 \(v = u - u_s\)는 동차 경계 조건을 만족하므로 정리 16.2로 풀립니다.

$$u(x, t) = \underbrace{T_1 + (T_2 - T_1)\frac xL}_{\text{정상 상태}} + \underbrace{\sum_{n=1}^\infty b_n e^{-\alpha(n\pi/L)^2t}\sin\frac{n\pi x}{L}}_{\text{과도 상태}},\qquad b_n = \frac2L\int_0^L\bigl(f - u_s\bigr)\sin\frac{n\pi x}{L}\,dx.$$
3장의 "과도 응답 + 정상 상태" 구조가 공간으로 넓어진 것이다. 과도 부분은 첫 모드의 시상수 \(\tau_1\)로 사라진다.
예제 16.3 (한쪽은 끓는 물, 한쪽은 얼음물) 처음에 어디나 0 °C인 막대(\(L = 1\))의 왼쪽 끝을 100 °C, 오른쪽 끝을 0 °C로 유지한다.
  1. 정상 상태: \(u_s = 100(1 - x)\).
  2. 과도 부분의 처음 값: \(f - u_s = -100(1 - x)\). 사인 계수는 \(b_n = -200\int_0^1(1 - x)\sin n\pi x\,dx = -\frac{200}{n\pi}\).
  3. \(u = 100(1 - x) - \frac{200}{\pi}\sum_{n\ge1}\frac1n e^{-n^2\pi^2\alpha t}\sin n\pi x\). 위 시뮬레이터에서 경계 조건 '왼쪽 100 · 오른쪽 0'을 고르면 어떤 처음 분포든 이 직선으로 다가가는 것을 볼 수 있다.

파동 방정식: 줄의 진동과 배음

기타 줄의 음높이

기타 줄을 튕기면 한 가지 높이의 음이 납니다. 줄을 더 세게 감으면(장력↑) 음이 올라가고, 프렛을 눌러 줄을 짧게 하면 역시 올라가며, 굵은 줄(선밀도↑)은 낮은 음을 냅니다. 그리고 같은 음이라도 브리지 가까이 튕기면 날카롭고, 가운데를 튕기면 부드럽습니다. 이 모든 것을 한 방정식이 설명할 수 있을까요?

장력 \(T\), 선밀도 \(\rho\)(kg/m)인 줄의 작은 옆변위 \(u(x, t)\)를 봅니다. 짧은 조각 \([x, x + \Delta x]\)의 양 끝을 장력이 줄 방향으로 당기고, 그 세로 성분은 기울기가 작을 때 \(T\sin\theta \approx Tu_x\)입니다. 뉴턴 2법칙을 세로 방향으로 쓰면

$$\rho\,\Delta x\,u_{tt} = T\,u_x(x + \Delta x, t) - T\,u_x(x, t)\quad\Longrightarrow\quad u_{tt} = c^2u_{xx},\qquad c = \sqrt{T/\rho}.$$
이것이 파동 방정식(wave equation)이다. \(c\)는 줄을 따라 파동이 달리는 속도(m/s)다. 열 방정식과 달리 시간에 대해 2계이므로 초기 변위 \(u(x, 0) = f(x)\)와 초기 속도 \(u_t(x, 0) = g(x)\) 두 개가 필요하다.

양 끝을 고정한 줄(\(u(0, t) = u(L, t) = 0\))에 변수분리를 쓰면 공간은 같은 고유값 문제 \(X_n = \sin(n\pi x/L)\)이고, 시간은 \(T'' + c^2\lambda_nT = 0\), 7장의 단진동입니다. 열에서는 모드가 감쇠했지만 파동에서는 각자의 진동수로 진동합니다.

정리 16.3 (고정된 줄의 해와 정규 모드)
$$u(x, t) = \sum_{n=1}^\infty\Bigl(A_n\cos\omega_nt + B_n\sin\omega_nt\Bigr)\sin\frac{n\pi x}{L},\qquad \omega_n = \frac{n\pi c}{L},$$ $$A_n = \frac2L\int_0^L f(x)\sin\frac{n\pi x}{L}\,dx,\qquad B_n = \frac{2}{\omega_nL}\int_0^L g(x)\sin\frac{n\pi x}{L}\,dx.$$
각 항을 정규 모드(normal mode)라 한다. \(n\)번째 모드의 진동수는 \(f_n = \omega_n/2\pi = nc/(2L) = \frac{n}{2L}\sqrt{T/\rho}\)로, 기본 진동수 \(f_1\)의 정수배다.

정수배 진동수 \(f_1, 2f_1, 3f_1, \ldots\)를 배음(harmonics)이라 합니다. 진동수가 정확히 정수배라서 줄의 소리는 주기 \(1/f_1\)의 주기 신호이고, 우리 귀는 이것을 높이가 분명한 음으로 듣습니다. 원형 북(14장의 베셀 함수)은 모드 진동수가 정수배가 아니라서 음높이가 덜 분명합니다. 공식 \(f_1 = \frac{1}{2L}\sqrt{T/\rho}\)는 문제 상자의 세 관찰(장력↑, 길이↓, 굵기↓이면 음↑)을 그대로 담고 있습니다.

예제 16.4 (튕긴 줄의 배음 구성) 길이 \(L\)인 줄의 위치 \(x = p\)를 높이 \(h\)로 당겼다가 놓는다(\(g = 0\)). 처음 모양은 \((0, 0)\), \((p, h)\), \((L, 0)\)을 잇는 삼각형이다.
  1. \(B_n = 0\). \(A_n = \frac2L\int_0^L f\sin\frac{n\pi x}{L}\,dx\)를 두 구간으로 나누어 부분 적분하면 \(A_n = \dfrac{2hL^2}{\pi^2n^2p(L - p)}\sin\dfrac{n\pi p}{L}\).
  2. 계수는 \(1/n^2\)로 줄어든다(삼각형은 연속이지만 꺾여 있다, 15장 표).
  3. \(\sin(n\pi p/L) = 0\)인 배음은 빠진다. 가운데(\(p = L/2\))를 튕기면 짝수 배음이 모두 없고 \(A_3/A_1 = -1/9\). \(p = L/5\)이면 5, 10, 15번째 배음이 없다.
  4. 끝 가까이(\(p\) 작게) 튕기면 \(\sin(n\pi p/L) \approx n\pi p/L\)이 \(n\)과 함께 커져서 높은 배음이 상대적으로 많아진다. 소리가 날카로워진다.

숫자로 감을 잡아 봅시다. 줄 길이 0.65 m에서 110 Hz(라 음)를 내려면 \(c = 2Lf_1 = 143\) m/s가 필요하고, 선밀도가 5 g/m인 줄이라면 장력은 \(T = \rho c^2 \approx 102\) N입니다.

달랑베르 해: 두 방향으로 달리는 파

긴 줄의 한 곳을 꼬집으면

아주 긴 빨랫줄의 한가운데를 살짝 들었다 놓으면 볼록한 모양이 두 개로 갈라져 양쪽으로 달려갑니다. 사인 급수로도 이것을 설명할 수 있지만, 더 직접적인 그림이 있습니다.

변수를 \(\xi = x - ct\), \(\eta = x + ct\)로 바꾸면 연쇄 법칙(CalculusBook 연쇄 법칙)으로 \(u_{tt} - c^2u_{xx} = -4c^2u_{\xi\eta}\)입니다. 그래서 파동 방정식은 \(u_{\xi\eta} = 0\)이 되고, 이것을 \(\eta\)로 적분한 뒤 \(\xi\)로 적분하면 일반해가 나옵니다.

정리 16.4 (달랑베르 공식) 무한히 긴 줄에서 \(u_{tt} = c^2u_{xx}\), \(u(x, 0) = f(x)\), \(u_t(x, 0) = g(x)\)의 해는
$$u(x, t) = \frac{f(x - ct) + f(x + ct)}{2} + \frac1{2c}\int_{x - ct}^{x + ct} g(s)\,ds.$$
일반해는 \(u = F(x - ct) + G(x + ct)\), 즉 오른쪽으로 속도 \(c\)로 달리는 모양과 왼쪽으로 달리는 모양의 합이다.

공식에서 두 가지를 읽을 수 있습니다. 첫째, 정지 상태에서 놓은(\(g = 0\)) 처음 모양은 높이가 절반인 두 개로 갈라져 반대 방향으로 달립니다. 둘째, 점 \((x, t)\)의 값은 처음 시각의 구간 \([x - ct, x + ct]\)에만 달려 있습니다. 이 구간을 의존 영역(domain of dependence)이라 하고, 그 경계 \(x \pm ct = \) 상수인 직선을 특성선(characteristics)이라 합니다. 신호는 \(c\)보다 빨리 퍼지지 않습니다. 열 방정식과의 결정적인 차이로, 열 방정식에서는 한 점을 데우면 \(t > 0\)인 순간 모든 곳의 온도가 (아주 조금이라도) 오릅니다.

끝에서의 반사. \(x = 0\)이 고정된 반무한 줄은 처음 모양을 원점에 대해 홀 확장한 무한 줄과 같습니다. 홀함수의 달랑베르 해는 늘 \(u(0, t) = 0\)이기 때문입니다. 그래서 고정 끝에 닿은 파는 뒤집혀서 돌아옵니다. 자유 끝(\(u_x = 0\))은 짝 확장이므로 뒤집히지 않고 돌아옵니다. 15장의 짝·홀 확장이 여기서 물리적 반사가 됩니다.

라플라스 방정식: 정상 상태 온도

네 변의 온도가 다른 금속판

정사각형 금속판의 윗변은 100 °C 증기관에, 나머지 세 변은 0 °C 냉각수관에 붙어 있습니다. 오래 기다리면 판 안의 온도가 더는 변하지 않는 상태에 이릅니다. 판 한가운데의 온도는 몇 도일까요?

2차원 열 방정식은 \(u_t = \alpha(u_{xx} + u_{yy})\)입니다. 정상 상태에서는 \(u_t = 0\)이므로

$$\nabla^2u = u_{xx} + u_{yy} = 0.$$
이것이 라플라스 방정식(Laplace equation)이고, 해를 조화 함수라 한다. 전하가 없는 공간의 정전기 퍼텐셜, 비압축·비회전 유체의 속도 퍼텐셜, 막의 정적 처짐도 같은 방정식을 따른다(CalculusBook 벡터 미적분의 발산과 기울기).

사각 판 \(0 \le x, y \le L\)에서 윗변만 \(u(x, L) = f(x)\)이고 다른 세 변이 0이라 합시다. \(u = X(x)Y(y)\)로 두면 \(X''/X = -Y''/Y = -\lambda\). 옆 두 변의 조건이 \(X\)의 고유값 문제를 만들어 \(X_n = \sin(n\pi x/L)\)이고, \(Y'' = \lambda_nY\), \(Y(0) = 0\)에서 \(Y_n = \sinh(n\pi y/L)\)입니다. 이번에는 진동도 감쇠도 아닌 쌍곡 사인이 나옵니다.

$$u(x, y) = \sum_{n=1}^\infty b_n\frac{\sinh(n\pi y/L)}{\sinh n\pi}\sin\frac{n\pi x}{L},\qquad b_n = \frac2L\int_0^L f(x)\sin\frac{n\pi x}{L}\,dx.$$
네 변이 모두 0이 아니면 한 변씩 풀어 더한다(중첩).
정리 16.5 (평균값 성질과 최대 원리) 조화 함수 \(u\)의 한 점에서의 값은 그 점을 중심으로 하는 (영역 안의) 모든 원 위의 평균값과 같다. 따라서 \(u\)의 최댓값과 최솟값은 영역의 경계에서만 나타난다. 특히 경계값이 같은 두 해는 같다(유일성).

최대 원리는 직관과 맞습니다. 열원이 없는 판의 내부가 가장자리보다 뜨거울 수는 없습니다. 평균값 성질은 수치 해법도 알려 줍니다. 격자에서 "각 점 = 상하좌우 네 이웃의 평균"을 되풀이해 고치면 해로 수렴합니다. 이것이 야코비 반복이고, 고친 값을 즉시 쓰면 가우스–자이델, 고칠 양을 \(\omega\)배 과장하면 SOR(축차 과완화)입니다.

예제 16.5 (판 한가운데의 온도) 위 문제 상자에서 \(f = 100\).
  1. \(b_n = 400/(n\pi)\) (홀수 \(n\)). 가운데 \((L/2, L/2)\)에서 \(u = \sum\frac{400}{n\pi}\frac{\sinh(n\pi/2)}{\sinh n\pi}\sin\frac{n\pi}{2}\). 첫 항이 25.37, 모든 항을 더하면 정확히 25.00 °C.
  2. 급수 없이 얻는 방법: 판을 90°씩 돌리면 "윗변 100"이 "오른쪽 변 100" 등 네 문제가 되고, 넷을 더하면 네 변 모두 100인 문제(해는 어디나 100)가 된다. 대칭으로 네 문제의 가운데 값이 같으므로 각각 100/4 = 25.
  3. 일반적으로 정사각형 판의 가운데 온도는 네 변 온도의 평균이다.

유한 차분법과 안정성 조건

급수로 풀 수 없는 막대

열전도도가 온도에 따라 변하거나, 막대 모양이 불규칙하거나, 열원이 시간에 따라 바뀌면 변수분리가 통하지 않습니다. 컴퓨터는 막대를 격자로 자르고 시간을 한 걸음씩 나아가며 풉니다. 그런데 시간 걸음을 조금만 크게 잡아도 결과가 톱니 모양으로 폭발합니다. 왜 그럴까요?

격자 \(x_i = i\Delta x\), \(t^k = k\Delta t\)에서 \(u_i^k \approx u(x_i, t^k)\)라 하고, 시간 미분은 앞차분, 공간 2계 미분은 중심 차분으로 바꿉니다(5장의 오일러 방법을 각 격자점에 쓴 것).

$$\frac{u_i^{k+1} - u_i^k}{\Delta t} = \alpha\,\frac{u_{i+1}^k - 2u_i^k + u_{i-1}^k}{\Delta x^2}\quad\Longrightarrow\quad u_i^{k+1} = u_i^k + r\bigl(u_{i+1}^k - 2u_i^k + u_{i-1}^k\bigr),\qquad r = \frac{\alpha\,\Delta t}{\Delta x^2}.$$
다음 시각의 값을 지금 값 세 개로 바로 계산하므로 명시적 방법이라 하고, 흔히 FTCS(시간 전진, 공간 중심)라 부른다. \(r\)은 격자 푸리에 수다.

그림의 논증을 정확하게 만드는 것이 폰 노이만 안정성 분석입니다. 격자 위의 푸리에 모드 \(u_i^k = G^k e^{\mathrm i\theta i}\)를 넣으면 모드마다 한 걸음에 곱해지는 증폭 인자 \(G\)가 나옵니다.

$$G(\theta) = 1 + r\bigl(e^{\mathrm i\theta} - 2 + e^{-\mathrm i\theta}\bigr) = 1 - 4r\sin^2\frac\theta2,\qquad 0 \le \theta \le \pi.$$
정리 16.6 (FTCS의 안정성 조건) 열 방정식의 명시적 방법이 모든 모드에서 \(|G| \le 1\)일 필요충분조건은
$$r = \frac{\alpha\,\Delta t}{\Delta x^2} \le \frac12.$$

증명. \(G\)는 \(\theta\)에 대해 감소하고 가장 작은 값은 가장 높은 격자 모드 \(\theta = \pi\)(점마다 부호가 바뀌는 톱니)에서 \(G(\pi) = 1 - 4r\)이다. \(G \le 1\)은 늘 성립하고, \(G(\pi) \ge -1 \iff r \le 1/2\). ∎

이 조건은 꽤 가혹합니다. 정확도를 위해 \(\Delta x\)를 절반으로 줄이면 \(\Delta t\)는 1/4로 줄여야 하고, 전체 계산량은 8배가 됩니다. 그래서 실무에서는 다음 시각 값들을 연립 방정식으로 함께 푸는 음적 방법(뒤 오일러, 크랭크–니콜슨)을 자주 씁니다. 이들은 어떤 \(r\)에서도 안정합니다. 5장의 강성 방정식에서 본 이야기가 편미분방정식에서 그대로 되풀이됩니다. 높은 공간 모드의 감쇠율 \(\alpha n^2\pi^2/L^2\)이 매우 커서 시스템이 강성하기 때문입니다.

핵심 정리

  1. 열 방정식 ut = αuxx는 푸리에 법칙 q = −kux와 에너지 보존에서 나온다. α = k/(ρcp). 온도의 봉우리는 식고 골짜기는 데워진다.
  2. 변수분리 u = X(x)T(t)는 PDE를 공간 고유값 문제와 시간 ODE로 나눈다. 해는 Σbₙe−α(nπ/L)²tsin(nπx/L)이고 bₙ은 처음 온도의 사인 계수다.
  3. n번째 모드의 감쇠율은 n²에 비례한다. 긴 시간에는 첫 모드만 남고(시상수 L²/(απ²)), 퍼짐 시간은 L²에 비례하며, 시간을 거꾸로 푸는 문제는 불량 조건이다.
  4. 디리클레는 사인, 노이만은 코사인(평균 보존), 비동차 경계 조건은 정상 상태(직선) + 과도 상태로 푼다.
  5. 파동 방정식 utt = c²uxx, c = √(T/ρ). 고정된 줄의 모드 진동수는 fₙ = nc/(2L)로 정수배 배음이다. 튕기는 위치 p에서 sin(nπp/L) = 0인 배음이 빠진다.
  6. 달랑베르 해 u = ½[f(x − ct) + f(x + ct)] + (1/2c)∫g. 신호는 특성선을 따라 속도 c로 간다. 고정 끝은 홀 확장(뒤집힌 반사), 자유 끝은 짝 확장이다.
  7. 라플라스 방정식 ∇²u = 0은 정상 상태다. 조화 함수는 평균값 성질과 최대 원리를 가지고, 정사각형 판의 가운데 값은 네 변 온도의 평균이다. 반복 완화(야코비·가우스–자이델·SOR)가 평균값 성질의 이산판이다.
  8. 명시적 FTCS는 r = αΔt/Δx² ≤ 1/2일 때만 안정하다(G(π) = 1 − 4r). 파동의 명시적 방법은 CFL 조건 cΔt/Δx ≤ 1이 필요하다. 수치 의존 영역이 진짜 의존 영역을 품어야 한다.

확인 퀴즈

Q1. 양끝이 0 °C인 막대(\(L = 1\))의 처음 온도가 \(f(x) = 20\sin 2\pi x\)다. \(u(x, t)\)는?

처음 온도가 이미 2번 고유함수이므로 그 모드 하나만 \(e^{-\alpha\lambda_2t}\), \(\lambda_2 = (2\pi)^2 = 4\pi^2\)로 감쇠한다. 코사인 진동은 파동 방정식의 시간 부분이다.

Q2. 같은 재료의 막대 길이를 3배로 늘렸다. 처음 모양이 같을 때 같은 비율만큼 식는 데 걸리는 시간은?

해는 무차원 시간 \(\tau = \alpha t/L^2\)로만 쓰인다. 같은 \(\tau\)에 이르려면 \(t \propto L^2\)이므로 9배. 퍼지는 거리가 \(\sqrt{\alpha t}\)에 비례하는 것과 같은 말이다.

Q3. 양끝을 단열한 막대의 처음 온도가 왼쪽 절반 80 °C, 오른쪽 절반 20 °C다. 아주 오래 뒤의 온도는?

노이만 조건에서는 \(\lambda_0 = 0\)인 상수 모드가 감쇠하지 않고, 그 값은 처음 평균 \(\frac1L\int f = 50\)이다. 열이 빠져나갈 곳이 없어 총 열량이 보존된다.

Q4. 줄의 장력을 4배로 하면 기본 진동수는?

\(f_1 = \frac{1}{2L}\sqrt{T/\rho}\)이므로 \(\sqrt4 = 2\)배. 진동수가 두 배면 한 옥타브 위다.

Q5. 양끝 고정 줄의 \(x = L/3\) 지점을 당겼다 놓았다. 소리에 들어 있지 않은 배음은?

\(A_n \propto \sin(n\pi/3)/n^2\)이고 \(n\)이 3의 배수이면 0이다. 그 모드들은 튕긴 점이 마디라서 처음 모양에서 그 모드 성분이 생기지 않는다.

Q6. 무한 줄을 정지 상태에서 높이 2인 혹 모양으로 놓았다. 충분히 오랜 뒤의 모습은?

\(g = 0\)이면 \(u = \frac12[f(x - ct) + f(x + ct)]\). 모양은 그대로, 높이는 절반으로 갈라져 양쪽으로 간다. 퍼지며 납작해지는 것은 열 방정식의 행동이다.

Q7. 정사각형 판의 네 변을 각각 0, 40, 60, 100 °C로 유지한다. 정상 상태에서 판 한가운데 온도는?

중첩과 90° 회전 대칭으로 가운데 값은 네 변 온도의 평균이다: \((0 + 40 + 60 + 100)/4 = 50\). 라플라스 방정식의 해는 경계값만으로 유일하게 정해진다(최대 원리).

Q8. 열 방정식을 FTCS로 풀고 있다. \(\Delta x = 0.01\), \(\alpha = 1\)일 때 안정한 가장 큰 시간 간격은?

\(r = \alpha\Delta t/\Delta x^2 \le 1/2\)이므로 \(\Delta t \le \Delta x^2/2 = 10^{-4}/2 = 5\times10^{-5}\). \(10^{-4}\)이면 \(r = 1\), \(G(\pi) = -3\)으로 톱니가 걸음마다 3배씩 자란다.
