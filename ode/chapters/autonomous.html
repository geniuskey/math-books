Chapter 04

해의 존재와 자율 방정식

지금까지는 방정식을 받으면 곧바로 풀었습니다. 그런데 풀기 전에 물어야 할 것이 있습니다. 해가 정말 있는가, 그리고 하나뿐인가? 수치 해법은 언제나 숫자를 내놓지만, 해가 없거나 여러 개인 문제에서는 그 숫자가 아무 뜻이 없습니다. 이 장의 앞부분은 이 질문에 답하는 존재·유일성 정리와 그 증명의 엔진인 피카르 반복, 그리고 정리의 조건이 깨질 때 일어나는 일(해가 갈라지거나 유한 시간에 폭발)을 봅니다. 뒷부분은 해를 구하지 않고도 해의 운명을 읽는 방법입니다. 오른쪽이 \(y\)에만 달린 자율 방정식 \(y' = f(y)\)는 직선 하나 위의 화살표, 위상선으로 모든 해를 요약할 수 있고, 평형점의 안정성은 \(f'\)의 부호 하나로 정해집니다. 매개변수가 바뀌면 평형점이 갑자기 사라지는 분기가 일어나는데, 이것이 어장이 무너지는 방식이자 생물학적 스위치가 동작하는 방식입니다.

  • 피카르–린델뢰프 정리의 조건(연속성, 립시츠 조건)과 보장 구간 \(h = \min(a, b/M)\)을 설명한다.
  • 초기값 문제를 적분 방정식으로 바꾸고, 피카르 반복으로 근사해를 만들어 수렴을 확인한다.
  • \(y' = \sqrt y\)와 물 새는 양동이에서 유일성이 깨지는 이유를 립시츠 조건으로 설명한다.
  • \(y' = y^2\)의 유한 시간 폭발을 계산하고, 선형 방정식과 대비한다.
  • 자율 방정식의 위상선을 그리고, 평형점을 \(f'(y^*)\)의 부호로 안정·불안정·반안정으로 분류한다.
  • 수확이 있는 로지스틱 모델에서 안장–마디 분기와 최대 지속 생산량 \(rK/4\)를 유도한다.
  • 쌍안정 시스템이 펄스 입력으로 상태를 바꾸는 스위치(기억 소자)로 동작함을 이해한다.
이 수식이 없었다면어획 한도와 생물학적 스위치

물고기 개체 수를 로지스틱 모델로 보면, 매년 일정량 \(h\)를 잡는 어장은 \(y' = ry(1 - y/K) - h\)를 따릅니다. 이 방정식의 해를 손으로 구하지 않아도 위상선 하나로 놀라운 사실을 알 수 있습니다. 어획량을 조금씩 늘리면 개체 수는 조금씩 줄다가, 어느 임계값 \(rK/4\)를 넘는 순간 평형점 자체가 사라져 개체군이 0으로 무너집니다. 어획량을 임계값 바로 아래로 되돌려도 이미 줄어든 개체군은 회복되지 않을 수 있습니다. 1992년 캐나다 정부가 뉴펀들랜드 연안의 북대서양 대구 어업을 중단(모라토리엄)한 뒤에도 자원이 오랫동안 회복되지 않은 사례는, 실제 원인이 이 단순한 모델보다 훨씬 복잡하더라도, "평형점이 사라지는 문턱"을 경계해야 하는 이유로 자주 거론됩니다.

같은 수학이 반대 방향으로도 쓰입니다. 평형점 두 개가 공존하는 쌍안정 시스템은 짧은 자극으로 한 상태에서 다른 상태로 넘어가 그대로 머무르므로 1비트를 기억합니다. 2000년 가드너(T. S. Gardner), 캔터(C. R. Cantor), 콜린스(J. J. Collins)는 서로를 억제하는 두 유전자로 대장균 안에 이런 유전자 토글 스위치를 만들었다고 보고했습니다.

수치 해법은 거짓말을 할 수 있다

\(y' = \sqrt{|y|}\), \(y(0) = 0\)을 RK4로 풀면 컴퓨터는 \(y \equiv 0\)을 내놓습니다. 그런데 \(y = t^2/4\)도 이 초기값 문제의 해입니다(대입해 보세요: \(y' = t/2 = \sqrt{t^2/4}\)). 어느 쪽이 "진짜" 해일까요? 물리 모델이라면 이 질문은 "이 시스템의 미래가 현재로 결정되는가"라는 질문입니다. 수치 해를 믿으려면 먼저 해가 하나뿐임을 알아야 합니다.

초기값 문제 \(y' = f(t, y)\), \(y(t_0) = y_0\)을 생각합니다. 먼저 존재는 놀랍도록 약한 조건으로 보장됩니다.

정리 4.1 (페아노 존재 정리) \(f\)가 \((t_0, y_0)\)를 포함하는 직사각형에서 연속이면, \(t_0\)를 포함하는 어떤 구간에서 초기값 문제의 해가 적어도 하나 존재한다.

연속성만으로는 유일성이 보장되지 않습니다. 위의 \(\sqrt{|y|}\)가 바로 그런 예입니다. 유일성을 위해서는 \(f\)가 \(y\) 방향으로 "너무 가파르게" 변하지 않아야 합니다.

정의 4.1 (립시츠 조건) 영역 \(R\)의 모든 \((t, y_1)\), \((t, y_2)\)에 대해
$$|f(t, y_1) - f(t, y_2)| \le L\,|y_1 - y_2|$$
인 상수 \(L\)이 있으면 \(f\)가 \(R\)에서 \(y\)에 대해 립시츠 조건(Lipschitz condition)을 만족한다고 한다. \(\partial f/\partial y\)가 \(R\)(볼록 영역)에서 연속이고 \(|\partial f/\partial y| \le L\)이면 평균값 정리로 립시츠 조건이 성립한다.
정리 4.2 (피카르–린델뢰프 존재·유일성 정리) 직사각형 \(R = \{|t - t_0| \le a,\ |y - y_0| \le b\}\)에서 \(f\)가 연속이고 \(y\)에 대해 립시츠 조건을 만족한다고 하자(예: \(f\)와 \(\partial f/\partial y\)가 \(R\)에서 연속). \(M = \max_R |f|\)이라 하면 구간
$$|t - t_0| \le h,\qquad h = \min\left(a,\ \frac{b}{M}\right)$$
에서 초기값 문제의 해가 정확히 하나 존재한다.

보장 구간 \(h\)의 뜻은 그림 4-1이 보여 줍니다. 해의 기울기는 \(R\) 안에서 \(|y'| \le M\)이므로, 해곡선은 \((t_0, y_0)\)에서 기울기 \(\pm M\)인 두 직선이 만드는 쐐기 안에 갇힙니다. 쐐기가 직사각형의 위아래 변(\(|y - y_0| = b\))에 닿기 전까지, 즉 \(|t - t_0| \le b/M\)까지는 해가 \(R\)을 벗어나지 않으므로 \(f\)에 대한 가정이 계속 유효합니다. 이것은 국소적 정리입니다. 해가 더 멀리까지 존재할 수도 있지만 정리는 거기까지만 약속합니다.

예제 4.1 (보장 구간은 보수적이다) \(y' = y^2\), \(y(0) = 1\)에 정리 4.2를 적용하라.
  1. \(f = y^2\), \(\partial f/\partial y = 2y\)는 어디서나 연속이므로 어떤 직사각형에서도 조건을 만족한다. \(a\)는 아무리 커도 된다.
  2. \(R\)에서 \(M = \max y^2 = (1 + b)^2\). 따라서 \(h = \min\bigl(a, \frac{b}{(1 + b)^2}\bigr)\).
  3. \(b/(1 + b)^2\)는 \(b = 1\)에서 최대 \(1/4\). 정리가 보장하는 것은 \(|t| \le 1/4\)뿐이다.
  4. 실제 해 \(y = 1/(1 - t)\)는 \(t \lt 1\)에서 존재한다(4절). 정리는 1/4만 약속했지만 해는 그보다 오래 산다. 그리고 \(t = 1\)에서는 정말로 끝난다.

유일성의 기하적 의미는 단순합니다. 두 해곡선은 교차하거나 접할 수 없습니다. 만약 두 해가 한 점에서 만나면, 그 점을 초기값으로 하는 문제의 해가 두 개가 되기 때문입니다. 1장에서 방향장 위에 그린 해곡선들이 서로 겹치지 않았던 것은 이 정리 덕분입니다. 선형 방정식은 이보다 강해서, 계수가 연속인 구간 전체에서 해가 존재하고 유일합니다(3장 정리 3.1).

피카르 반복: 해를 한 겹씩 다듬기

정리 4.2의 증명은 해를 직접 만들어 보입니다. 첫걸음은 미분방정식을 적분 방정식으로 바꾸는 것입니다. 미적분의 기본 정리로

$$y' = f(t, y),\ y(t_0) = y_0 \iff y(t) = y_0 + \int_{t_0}^{t} f\bigl(s, y(s)\bigr)\,ds.$$
오른쪽의 \(y\)는 모르는 함수이므로 아직 풀이가 아니다. 하지만 오른쪽에 "대충 맞는" \(y\)를 넣으면 "조금 더 맞는" \(y\)가 나온다.
정의 4.2 (피카르 반복) \(y_0(t) \equiv y_0\)에서 시작해
$$y_{n+1}(t) = y_0 + \int_{t_0}^{t} f\bigl(s, y_n(s)\bigr)\,ds,\qquad n = 0, 1, 2, \ldots$$
로 함수열을 만드는 것을 피카르 반복(Picard iteration) 또는 축차 근사라 한다.

증명의 핵심 아이디어. 연속한 두 근사의 차이를 보면, 립시츠 조건으로

$$|y_{n+1}(t) - y_n(t)| \le \int_{t_0}^{t} \bigl|f(s, y_n) - f(s, y_{n-1})\bigr|\,ds \le L\int_{t_0}^{t} |y_n - y_{n-1}|\,ds.$$

이것을 되풀이하면 \(|y_{n+1} - y_n| \le \dfrac{M L^n |t - t_0|^{n+1}}{(n+1)!}\)이고, 오른쪽은 \(e^{L|t - t_0|}\)의 테일러 급수 항이라 합이 수렴합니다. 그래서 \(y_n\)은 어떤 함수 \(y\)로 고르게 수렴하고, 그 극한이 적분 방정식을 만족합니다. 유일성도 같은 부등식에서 나옵니다. 두 해의 차 \(w = |y - z|\)가 \(w \le L\int w\)를 만족하면 \(w \equiv 0\)이어야 합니다(그뢴월 부등식). 핵심은 언제나 립시츠 상수 \(L\)이 오차의 증폭을 제한한다는 것입니다.

예제 4.2 (지수 함수가 저절로 나온다) \(y' = y\), \(y(0) = 1\)에 피카르 반복을 적용하라.
  1. \(y_0 = 1\). \(y_1 = 1 + \int_0^t 1\,ds = 1 + t\).
  2. \(y_2 = 1 + \int_0^t (1 + s)\,ds = 1 + t + \frac{t^2}{2}\). \(y_3 = 1 + t + \frac{t^2}{2} + \frac{t^3}{6}\).
  3. 귀납적으로 \(y_n = \sum_{k=0}^n \frac{t^k}{k!}\). 이것은 \(e^t\)의 테일러 다항식이다(CalculusBook 테일러). 반복 한 번에 항 하나씩 맞춰진다.
예제 4.3 \(y' = 2t(1 + y)\), \(y(0) = 0\)의 피카르 반복 세 번을 구하고 정확한 해와 비교하라.
  1. \(y_1 = \int_0^t 2s\,ds = t^2\). \(y_2 = \int_0^t 2s(1 + s^2)\,ds = t^2 + \frac{t^4}{2}\).
  2. \(y_3 = \int_0^t 2s\bigl(1 + s^2 + \frac{s^4}{2}\bigr)ds = t^2 + \frac{t^4}{2} + \frac{t^6}{6}\).
  3. 정확한 해는 변수분리로 \(\ln(1 + y) = t^2\), \(y = e^{t^2} - 1 = t^2 + \frac{t^4}{2!} + \frac{t^6}{3!} + \cdots\). \(t = 1\)에서 \(y_3 = 1.6667\), 정확한 값 \(e - 1 = 1.7183\).

피카르 반복은 실제 계산법으로는 느립니다(적분을 반복해야 하고, 비선형이면 식이 금방 복잡해집니다). 하지만 "해가 존재한다"는 것을 구성적으로 보여 주고, 근사가 \(t_0\) 근처부터 점점 넓게 맞아 들어가는 모습은 국소 존재 정리의 뜻을 그대로 보여 줍니다.

유일성이 깨질 때: √y와 물 새는 양동이

\(f(y) = \sqrt y\)(\(y \ge 0\))는 연속이지만 \(y = 0\)에서 립시츠가 아닙니다. \(\frac{\sqrt{y} - \sqrt0}{y - 0} = \frac{1}{\sqrt y} \to \infty\)이므로 어떤 상수 \(L\)로도 막을 수 없습니다. 기울기 \(f\)는 0 근처에서 무한히 가파르게 커집니다. 그 결과 해가 \(y = 0\)에 "머물다가 아무 때나 떠날" 수 있습니다.

예제 4.4 (해의 다발) \(y' = \sqrt y\), \(y(0) = 0\)의 해를 모두 구하라.
  1. \(y \equiv 0\)은 해다.
  2. \(y > 0\)인 곳에서 변수분리: \(y^{-1/2}dy = dt\), \(2\sqrt y = t - c\), \(y = \frac{(t - c)^2}{4}\) (\(t \ge c\)).
  3. 이어 붙이기: 임의의 \(c \ge 0\)에 대해 \(y_c(t) = 0\) (\(t \le c\)), \(\frac{(t - c)^2}{4}\) (\(t > c\))는 \(t = c\)에서 값과 도함수(0)가 이어지므로 해다.
  4. 따라서 해가 무수히 많다. 초기 상태가 미래를 결정하지 못한다. 정리 4.2의 조건이 실패하는 곳(\(y = 0\))에서 정확히 유일성이 깨진다.

여기서 \(y = 0\)이 아닌 점, 예를 들어 \(y(0) = 1\)에서 출발하면 \(\partial f/\partial y = \frac{1}{2\sqrt y}\)가 그 근처에서 연속이므로 해는 유일합니다. 문제는 오직 립시츠 조건이 깨지는 \(y = 0\)뿐입니다. 아래 시뮬레이터에서 출발 시각 \(c\)를 끌어 보면, 모든 곡선이 같은 초기값을 가지면서도 서로 다른 미래로 갈라집니다. 같은 실험을 립시츠인 \(f = y\)로 하면 0에서 떠나는 해는 없습니다.

물 새는 양동이: 과거는 결정되지 않는다

양동이는 언제 비었나

바닥에 구멍이 난 양동이가 빈 채로 놓여 있습니다. 이 양동이가 언제 비었는지 알 수 있을까요? 토리첼리 법칙(2장)에 따르면 수위 \(h\)는 \(h' = -k\sqrt h\)를 따릅니다. 미래로는 문제없이 풀리지만, 과거로 거슬러 올라가면 \(h = 0\)에서 유일성이 깨집니다.

\(h > 0\)이면 \(2\sqrt h = 2\sqrt{h_0} - kt\), 즉 \(\sqrt{h} = \sqrt{h_0} - \frac{k}{2}t\)이므로 양동이는 유한 시각 \(T = 2\sqrt{h_0}/k\)에 비고, 그 뒤로는 \(h \equiv 0\)입니다. 이것은 지수 감쇠와 다릅니다. 지수 함수 \(e^{-t}\)는 결코 0이 되지 않지만, \(\sqrt h\) 법칙은 립시츠가 아니라서 유한 시간에 정확히 0이 될 수 있습니다. 그 대가로 \(h = 0\)인 상태에서는 "언제 비었는가"라는 과거를 복원할 수 없습니다.

예제 4.5 \(k = 0.2\)(단위 \(\sqrt{\text{m}}/\text{s}\))일 때 처음 수위 1 m, 0.64 m, 0.25 m인 세 양동이가 비는 시각을 구하라.
  1. \(T = 2\sqrt{h_0}/k = 10\sqrt{h_0}\). 각각 \(T = 10\), \(8\), \(5\) s.
  2. \(t = 12\) s에 세 양동이는 모두 \(h = 0\)으로 같은 상태다. 지금 상태만으로는 각각 \(T = 10, 8, 5\) 중 어느 것이었는지, 아니면 처음부터 비어 있었는지 구별할 수 없다.
  3. 수학적으로: 시각 12에서 \(h = 0\)을 초기값으로 거꾸로 풀면, \(T \le 12\)인 모든 \(T\)에 대해 \(h(t) = \frac{k^2}{4}(T - t)^2\)(\(t \le T\))가 해다.

유한 시간 폭발

매끄러운 방정식의 해가 사라진다

\(y' = y^2\)는 \(f\)도 \(\partial f/\partial y\)도 어디서나 연속인, 아무 문제 없어 보이는 방정식입니다. 그런데 \(y(0) = 1\)에서 출발한 해는 \(t = 1\)에서 무한대가 됩니다. 정리 4.2가 "국소적"이라고 한 이유가 이것입니다.

변수분리로 \(-1/y = t - 1/y_0\), 즉

$$y(t) = \frac{y_0}{1 - y_0t},\qquad T^* = \frac{1}{y_0}\quad (y_0 > 0).$$
\(t \to T^{*-}\)이면 \(y \to \infty\). 해는 \((-\infty, T^*)\)에서만 정의된다. 초기값이 클수록 일찍 폭발한다.

왜 폭발할까요? 선형 성장 \(y' = y\)에서는 크기가 두 배가 되는 데 걸리는 시간이 늘 \(\ln 2\)로 같습니다. 그런데 \(y' = y^2\)에서는 \(y\)가 클수록 상대 성장률 \(y'/y = y\)도 커져서, 두 배가 되는 시간이 점점 짧아집니다. 1에서 2까지 1/2, 2에서 4까지 1/4, 4에서 8까지 1/8 … 이 시간들의 합이 \(1/2 + 1/4 + \cdots = 1\)로 유한합니다. 무한히 많은 배가가 유한 시간 안에 끝나는 것입니다.

정리 4.3 (최대 존재 구간) \(f\)와 \(\partial f/\partial y\)가 평면 전체에서 연속이면 초기값 문제의 해는 최대 구간 \((T_-, T_+)\)까지 유일하게 연장된다. \(T_+ \lt \infty\)이면 \(t \to T_+\)일 때 반드시 \(|y(t)| \to \infty\)이다. 즉 해가 끝나는 이유는 폭발뿐이다.

거듭제곱 \(y' = y^p\)(\(y_0 > 0\))로 일반화하면 \(y^{1-p} = y_0^{1-p} - (p - 1)t\)이므로 \(p > 1\)이면 폭발 시각 \(T^* = \dfrac{y_0^{1-p}}{p - 1}\)이 있고, \(p \le 1\)이면 폭발하지 않습니다. 선형보다 빨리 자라는 피드백은 폭발할 수 있다는 것이 일반적인 교훈입니다. 엄밀히는 \(\int^\infty dy/f(y) \lt \infty\)이면 폭발합니다.

예제 4.6 다음 해의 폭발 시각을 구하라. (가) \(y' = 1 + y^2\), \(y(0) = 0\). (나) \(y' = y^3\), \(y(0) = 1\).
  1. (가) \(\arctan y = t\), \(y = \tan t\). \(t = \pi/2 \approx 1.571\)에서 폭발. 일반적으로 \(y(0) = y_0\)이면 \(T^* = \pi/2 - \arctan y_0\). 이 방정식은 \(y = 0\)에서도 기울기 1을 가져 결코 쉬지 않는다.
  2. (나) \(y^{-2} = 1 - 2t\), \(y = (1 - 2t)^{-1/2}\). \(T^* = 1/2\). \(t = 0.4\)에서 \(y = \sqrt5 \approx 2.236\)(RK4 2.236068).
폭발은 모델이 끝나는 신호 실제 물리량은 무한대가 되지 않습니다. \(y' = y^2\) 꼴의 폭발이 나오면 "그 시각 근처에서 모델이 무시한 효과(포화, 자원 고갈, 상변화)가 반드시 중요해진다"고 읽어야 합니다. 또 수치 해법은 폭발 시각을 지나도 계속 숫자를 내놓거나 오버플로로 멈출 뿐, "해가 여기서 끝났다"고 알려 주지 않습니다.

자율 방정식과 위상선

해를 구하지 않고 해의 운명 알기

\(y' = -y(y - 1)(y - 2)\)를 변수분리로 풀면 부분 분수와 로그가 얽힌 음함수가 나오고, 그것으로는 "\(y(0) = 1.3\)이면 결국 어디로 가는가" 같은 질문에 답하기 어렵습니다. 그런데 오른쪽 \(f(y)\)의 부호만 보면 답이 바로 나옵니다. \(1 \lt y \lt 2\)에서 \(f > 0\)이므로 \(y\)는 증가하고, 2를 넘을 수 없으므로 2로 다가갑니다.

정의 4.3 (자율 방정식, 평형점, 위상선) 오른쪽이 \(t\)를 직접 포함하지 않는 \(y' = f(y)\)를 자율 방정식(autonomous equation)이라 한다. \(f(y^*) = 0\)인 \(y^*\)를 평형점(equilibrium point)이라 하고, 이때 상수 함수 \(y \equiv y^*\)는 해(평형해)다. \(y\)축 위에 평형점을 찍고, \(f > 0\)인 구간에 위쪽(증가), \(f \lt 0\)인 구간에 아래쪽(감소) 화살표를 그린 그림을 위상선(phase line)이라 한다.
정리 4.4 (자율 방정식의 해의 성질) \(f\)가 연속 미분 가능하면
  1. 시간 이동: \(y(t)\)가 해이면 \(y(t - c)\)도 해다. 그래서 해곡선들은 서로 가로로 평행 이동한 모양이다.
  2. 단조성: 평형해가 아닌 해는 평형점을 지나지 못하므로(유일성) \(f\)의 부호가 일정한 구간에 머물고, 그래서 엄격히 증가하거나 감소한다. 진동할 수 없다.
  3. 운명: 유계인 해는 \(t \to \infty\)에서 평형점으로 수렴한다. 유계가 아니면 \(\pm\infty\)로 간다(유한 시간에 폭발할 수도 있다).

증명(1). \(z(t) = y(t - c)\)이면 \(z'(t) = y'(t - c) = f(y(t - c)) = f(z(t))\). \(f\)가 \(t\)를 포함하지 않기 때문에 성립한다. (3) 단조 유계 수열처럼 극한 \(L\)이 있고, \(y' = f(y) \to f(L)\)이 0이 아니면 \(y\)가 유계일 수 없으므로 \(f(L) = 0\). ∎

1차원 자율 방정식의 해는 진동도, 혼돈도 할 수 없습니다. 위상선 위의 점은 화살표를 따라 한 방향으로만 미끄러질 수 있기 때문입니다. 진동이 나타나려면 2차원(12장), 혼돈이 나타나려면 3차원(13장)이 필요합니다.

해곡선의 오목성도 \(f\)에서 바로 읽힙니다. 연쇄 법칙으로 \(y'' = f'(y)\,y' = f'(y)f(y)\)이므로, \(f\)의 극값(\(f' = 0\))에 해당하는 \(y\)에서 해곡선이 변곡합니다. 로지스틱 방정식 \(y' = ry(1 - y/K)\)에서 \(f\)는 \(y = K/2\)에서 최대이므로, S자 곡선은 정확히 수용력의 절반에서 꺾입니다. 성장 속도가 가장 빠른 개체 수이기도 합니다(7절에서 중요해집니다).

평형점의 안정성: f′의 부호 하나로

평형점 근처에서 해가 어떻게 움직이는지가 공학에서 가장 중요한 질문입니다. 작은 교란을 받은 시스템이 원래 상태로 돌아오는가, 아니면 멀어지는가?

정의 4.4 (안정성) 평형점 \(y^*\) 근처에서 출발한 모든 해가 \(t \to \infty\)에서 \(y^*\)로 수렴하면 \(y^*\)를 점근 안정(asymptotically stable), 근처에서 출발한 해 중 멀어지는 것이 있으면 불안정(unstable)이라 한다. 한쪽에서는 다가오고 다른 쪽에서는 멀어지면 반안정(semistable)이라 한다.

위상선에서는 화살표가 양쪽에서 들어오면 안정, 양쪽으로 나가면 불안정입니다. 이것을 계산으로 바꾸는 것이 선형화입니다. \(y = y^* + \delta\)로 두고 테일러 전개하면 \(f(y^* + \delta) = f(y^*) + f'(y^*)\delta + O(\delta^2) = f'(y^*)\delta + O(\delta^2)\)이므로, 작은 교란 \(\delta\)는

$$\delta' \approx f'(y^*)\,\delta \;\Longrightarrow\; \delta(t) \approx \delta_0\,e^{f'(y^*)\,t}$$
교란은 지수적으로 줄거나 는다. 비율은 \(\lambda = f'(y^*)\), 시상수는 \(1/|\lambda|\). 선형 방정식(3장)의 \(e^{-pt}\)가 여기서 다시 나온다.
정리 4.5 (선형화 판정) \(f\)가 연속 미분 가능하고 \(f(y^*) = 0\)일 때
  • \(f'(y^*) \lt 0\)이면 \(y^*\)는 점근 안정이다.
  • \(f'(y^*) > 0\)이면 \(y^*\)는 불안정이다.
  • \(f'(y^*) = 0\)이면 판정할 수 없다. 고차 항이 결정한다.

증명. \(f'(y^*) \lt 0\)이면 \(f'\)의 연속성으로 \(y^*\) 근처에서 \(f'\lt 0\)이고, 그래서 \(f\)는 감소 함수다. \(f(y^*) = 0\)이므로 \(y^*\) 바로 위에서 \(f \lt 0\), 바로 아래에서 \(f > 0\): 위상선 화살표가 양쪽에서 \(y^*\)를 향한다. 둘째도 같다. ∎

\(f(y)\)\(y^* = 0\)에서 \(f'\)위상선판정
\(-y^3\)0→ ● ←안정 (느리게)
\(y^3\)0← ○ →불안정
\(y^2\)0→ ◐ →반안정

표의 세 경우가 \(f'(y^*) = 0\)일 때 판정이 불가능한 이유입니다. \(f'\)이 0이어도 안정, 불안정, 반안정이 모두 가능합니다. 또 \(f' = 0\)이면 수렴이 지수적이 아니라 대수적으로 느려집니다. \(y' = -y^3\)의 해는 \(y = y_0/\sqrt{1 + 2y_0^2t} \sim 1/\sqrt{2t}\)로, \(e^{-t}\)보다 훨씬 천천히 0으로 갑니다.

예제 4.7 (평형점 세 개) \(y' = -y(y - 1)(y - 2)\)의 평형점을 분류하고, \(y(0) = 1.3\)인 해의 극한을 구하라.
  1. 평형점 0, 1, 2. \(f(y) = -(y^3 - 3y^2 + 2y)\), \(f'(y) = -(3y^2 - 6y + 2)\).
  2. \(f'(0) = -2 \lt 0\): 안정. \(f'(1) = -(3 - 6 + 2) = 1 > 0\): 불안정. \(f'(2) = -(12 - 12 + 2) = -2 \lt 0\): 안정.
  3. \(y(0) = 1.3\)은 불안정점 1과 안정점 2 사이이고 \(f(1.3) = -1.3(0.3)(-0.7) = 0.273 > 0\)이므로 증가하며 2로 간다. 1 바로 아래에서 출발하면 0으로 간다. 불안정점 1이 두 운명을 가르는 분수령이다.
  4. 안정점 근처의 교란은 시상수 \(1/|f'| = 0.5\)로 사라진다.

이처럼 안정 평형점 두 개 사이에 불안정 평형점이 끼어 있는 구조를 쌍안정(bistable)이라 합니다. 각 안정점으로 끌려가는 초기값의 집합을 그 점의 끌림 영역(basin of attraction)이라 하고, 불안정점이 끌림 영역의 경계가 됩니다. 8절에서 이 구조가 스위치가 됩니다.

수확이 있는 로지스틱과 안장–마디 분기

한 해에 얼마까지 잡아도 되는가

내재 성장률 \(r = 0.5\)/년, 수용력 \(K = 1000\)톤인 어장이 있습니다. 매년 일정량 \(h\)톤을 잡습니다(쿼터제). \(h = 80\)이면 개체군은 어디에 자리 잡고, \(h\)를 얼마까지 올릴 수 있을까요? 이 질문의 답은 해의 공식이 아니라 평형점의 개수가 바뀌는 순간에 있습니다.

$$y' = ry\Bigl(1 - \frac{y}{K}\Bigr) - h$$
수확은 개체 수와 무관한 상수 \(h\)만큼 성장률을 깎는다. \(f(y)\)의 그래프(아래로 볼록한 포물선)가 \(h\)만큼 통째로 내려간다.

평형점은 \(\frac{r}{K}y^2 - ry + h = 0\)의 근입니다.

$$y^*_\pm = \frac K2\left(1 \pm \sqrt{1 - \frac{4h}{rK}}\right),\qquad h_c = \frac{rK}{4}.$$
  • \(h \lt h_c\): 평형점 두 개. 포물선의 꼭대기가 0 위에 있으므로 큰 쪽 \(y^*_+\)에서 \(f' \lt 0\)(안정), 작은 쪽 \(y^*_-\)에서 \(f' > 0\)(불안정). \(y^*_-\)는 "이보다 적으면 멸종"하는 문턱이다.
  • \(h = h_c\): 두 평형점이 \(K/2\)에서 합쳐져 하나(반안정)가 된다.
  • \(h > h_c\): 평형점이 없다. \(f \lt 0\)이 어디서나 성립해, 어떤 초기 개체 수에서도 개체군이 유한 시간에 0이 된다.

\(h_c = rK/4\)는 \(f\)가 최대인 \(y = K/2\)에서의 성장률 \(r(K/2)(1/2)\)이고, 지속적으로 거둘 수 있는 최대 수확량이라 최대 지속 생산량(maximum sustainable yield, MSY)이라 부릅니다. 그런데 MSY에서 운영하는 것은 칼날 위에 서는 일입니다. 평형점이 반안정이라 아래로 조금만 교란되어도 붕괴로 이어집니다.

예제 4.8 (어장 관리) \(r = 0.5\), \(K = 1000\)일 때 (가) \(h = 80\)의 평형점, (나) \(h_c\), (다) \(h = 130\)이면 처음 \(y = K\)였던 개체군이 무너지는 시간을 구하라.
  1. (가) \(4h/(rK) = 320/500 = 0.64\), \(\sqrt{0.36} = 0.6\). \(y^*_+ = 500(1.6) = 800\)(안정), \(y^*_- = 500(0.4) = 200\)(불안정 문턱).
  2. (나) \(h_c = 0.5 \times 1000/4 = 125\)톤/년.
  3. (다) 평형점이 없으므로 결국 붕괴한다. 수치 적분으로 \(y = 1000\)에서 0까지 약 54.9년. 쿼터를 \(h_c\)보다 4%만 넘겼는데도 붕괴하며, 다만 매우 느리다. 평형점이 사라진 자리(\(y \approx K/2\)) 근처에서 \(f\)가 0에 가까워 해가 오래 머물기 때문이다(\(h = 150\)이면 20.6년).

(다)의 느린 붕괴는 위험합니다. 개체군이 수십 년 동안 서서히 줄어 "안정된 것처럼" 보이다가 갑자기 급락하기 때문입니다. 사라진 평형점이 남긴 이 느린 구간을 분기의 유령이라 부르고, 통과 시간은 \(h - h_c\)가 작을수록 \(1/\sqrt{h - h_c}\)에 비례해 길어집니다.

정의 4.5 (안장–마디 분기) 매개변수 \(\mu\)가 변할 때 평형점 두 개(안정 하나, 불안정 하나)가 다가와 합쳐진 뒤 사라지는 현상을 안장–마디 분기(saddle-node bifurcation)라 한다. 가장 간단한 꼴(정규형)은
$$y' = \mu - y^2:\qquad \mu > 0\text{이면 } y^* = \pm\sqrt\mu,\quad \mu = 0\text{이면 } y^* = 0,\quad \mu \lt 0\text{이면 평형점 없음.}$$
평형점의 위치를 매개변수에 대해 그린 그림을 분기도(bifurcation diagram)라 한다.

수확 모델을 \(y = K/2 + u\)로 옮기면 \(u' = (rK/4 - h) - \frac rK u^2\)로, 정확히 정규형입니다(\(\mu \propto h_c - h\)). 분기의 전체 목록(갈퀴, 횡단, 호프)과 이력 현상은 13장에서 다룹니다.

쿼터 대신 노력량으로 일정량이 아니라 개체 수에 비례해 잡으면(\(h = Ey\), 어선 수를 고정) \(y' = ry(1 - y/K) - Ey\)이고 평형점은 \(y^* = K(1 - E/r)\), 수확량은 \(EK(1 - E/r)\)입니다. \(E = r/2\)에서 최대 \(rK/4\)로 MSY는 같지만, \(E \lt r\)이면 평형점이 언제나 안정이고 갑작스러운 붕괴가 없습니다. 같은 최대 수확량이라도 규칙의 형태가 안정성을 바꿉니다.

쌍안정 스위치: 1비트를 기억하는 방정식

짧은 자극을 오래 기억하려면

세포는 짧은 신호(호르몬 펄스)를 받고 분화를 시작하면, 신호가 사라진 뒤에도 그 결정을 유지합니다. 전자 회로의 래치도 짧은 펄스로 상태를 바꾸고 유지합니다. 1차 선형 시스템(3장)은 입력이 사라지면 원래 상태로 돌아가므로 이런 기억을 할 수 없습니다. 기억에는 안정 평형점이 둘 필요합니다.

가장 간단한 모델은 다음과 같습니다(예제 4.7의 구조를 \(y = \pm1\) 대칭으로 옮긴 것).

$$y' = y - y^3 + s(t)$$
\(s = 0\)이면 평형점 \(-1\)(안정, "꺼짐"), \(0\)(불안정, 문턱), \(+1\)(안정, "켜짐"). \(f'(\pm1) = 1 - 3 = -2\), \(f'(0) = 1\). \(s(t)\)는 외부 입력.

상태가 \(-1\)에 있을 때 입력 \(s\)를 주면 \(f(y) = y - y^3 + s\)의 그래프가 위로 올라갑니다. 3차 함수의 극솟값은 \(y = -1/\sqrt3\)에서 \(-\frac{2}{3\sqrt3} + s\)이므로, \(s\)가

$$s_c = \frac{2}{3\sqrt3} \approx 0.385$$

를 넘으면 "꺼짐" 평형점이 문턱과 합쳐져 안장–마디 분기로 사라지고, 상태는 \(+1\) 근처의 유일한 평형점으로 넘어갑니다. 그 뒤 입력을 0으로 되돌려도 상태는 \(+1\)에 머뭅니다. 끄려면 \(s \lt -s_c\)인 음의 펄스가 필요합니다. 상태가 입력의 과거에 따라 달라지는 이 현상이 이력 현상(hysteresis)이고, 비교기에 되먹임을 건 슈미트 트리거가 잡음 속에서도 깨끗하게 스위칭하는 원리와 같습니다.

펄스는 충분히 크고 길어야 합니다. \(s > s_c\)인 펄스라도 너무 짧으면 상태가 문턱(가운데 불안정점) 근처까지만 갔다가, 펄스가 끝난 뒤 원래 쪽으로 미끄러져 돌아옵니다. 펄스가 끝나는 순간 상태가 문턱을 넘어 있느냐가 기준입니다. 수치로 확인하면 \(A = 0.8\)인 펄스는 길이가 약 1.9, \(A = 0.5\)이면 약 5 이상이어야 스위칭됩니다. 문턱 \(s_c\) 바로 위의 펄스는 사라진 평형점의 유령 근처에서 오래 머물기 때문입니다(7절). 반대로 \(s \lt s_c\)이면 아무리 오래 눌러도 스위칭되지 않고, 다만 평형점이 조금 이동할 뿐입니다.

이 도구가 쓰이는 곳

존재·유일성 정리는 "시뮬레이션 결과를 믿어도 되는가"의 수학적 근거이고, 위상선과 분기는 "매개변수를 바꾸면 무슨 일이 일어나는가"를 해를 풀지 않고 답하는 도구입니다.

열 폭주: 사라지는 평형점 리튬 이온 전지나 발열 반응기에서 온도 \(T\)는 \(CT' = Q(T) - k(T - T_a)\)를 따릅니다. 발열 \(Q(T)\)는 아레니우스 법칙으로 온도에 대해 지수적으로 늘고, 냉각은 선형입니다. 주변 온도 \(T_a\)가 낮으면 발열 곡선과 냉각 직선이 교차해 안정 평형점(정상 운전 온도)이 있지만, \(T_a\)가 오르거나 냉각 \(k\)가 나빠지면 두 곡선이 접했다가 떨어지며 평형점이 사라집니다. 7절과 같은 안장–마디 분기이고, 그 뒤 온도는 걷잡을 수 없이 오릅니다. 반응기 안전 설계에서 "임계 조건"을 계산하는 기본 아이디어입니다.

핵심 정리

  1. \(f\)가 연속이면 해가 존재(페아노)하고, 더해 \(y\)에 대해 립시츠(예: \(\partial f/\partial y\) 연속)이면 \(|t - t_0| \le \min(a, b/M)\)에서 해가 유일하다(피카르–린델뢰프). 유일하면 해곡선은 교차하지 않는다.
  2. 피카르 반복 \(y_{n+1} = y_0 + \int f(s, y_n)\,ds\)는 해를 구성한다. 오차는 \(ML^n|t - t_0|^{n+1}/(n+1)!\)로 줄고, \(y' = y\)이면 \(e^t\)의 테일러 다항식이 나온다.
  3. \(y' = \sqrt y\), \(y(0) = 0\)은 해가 무수히 많다(\(y = 0\)에서 립시츠가 아님). 물 새는 양동이 \(h' = -k\sqrt h\)는 유한 시간에 비고, 빈 상태에서는 과거가 결정되지 않는다.
  4. \(y' = y^2\)의 해 \(y_0/(1 - y_0t)\)는 \(T^* = 1/y_0\)에서 폭발한다. 해가 끝나는 이유는 폭발뿐이다. 선형 방정식은 폭발하지 않는다.
  5. 자율 방정식 \(y' = f(y)\)의 해는 시간 이동해도 해이고, 단조롭고, 평형점으로 가거나 무한대로 간다. 위상선(\(f\)의 부호 화살표)이 모든 해를 요약한다. 변곡점은 \(f' = 0\)인 높이.
  6. \(f'(y^*) \lt 0\)이면 안정, \(> 0\)이면 불안정, \(= 0\)이면 판정 불가(반안정 등). 교란은 \(e^{f'(y^*)t}\)로 변한다.
  7. 수확 모델 \(y' = ry(1 - y/K) - h\)는 \(h_c = rK/4\)(MSY)에서 안장–마디 분기를 겪는다. 넘으면 평형점이 사라져 붕괴하고, 바로 위에서는 유령 때문에 느리게 무너진다.
  8. 쌍안정 \(y' = y - y^3 + s\)는 \(|s| > 2/(3\sqrt3) \approx 0.385\)인 충분히 긴 펄스로 상태가 바뀌고 입력이 사라져도 유지된다: 기억, 스위치, 이력 현상.

확인 퀴즈

Q1. 정리 4.2(피카르–린델뢰프)가 유일한 해를 보장하는 초기값 문제는?

\(\partial f/\partial y = \frac13y^{-2/3}\)은 \(y = 1\) 근처에서 연속이므로 조건을 만족한다. 나머지는 모두 립시츠 조건이 깨지는 \(y = 0\)에서 출발한다. 실제로 \(y' = y^{1/3}\), \(y(0) = 0\)은 \(y = 0\)과 \(y = (2t/3)^{3/2}\) 두 해를 가진다.

Q2. \(y' = y^2\), \(y(0) = 2\)의 해는 언제 폭발하는가?

\(y = \frac{2}{1 - 2t}\)이므로 \(T^* = 1/y_0 = 1/2\). 초기값이 클수록 빨리 폭발한다.

Q3. \(y' = y\), \(y(0) = 1\)에 피카르 반복을 두 번 적용한 \(y_2(t)\)는?

\(y_1 = 1 + \int_0^t 1\,ds = 1 + t\), \(y_2 = 1 + \int_0^t(1 + s)\,ds = 1 + t + t^2/2\). 반복할 때마다 \(e^t\)의 테일러 항이 하나씩 늘어난다.

Q4. \(y' = (y - 1)(y - 3)\)의 평형점 중 안정한 것은?

\(f'(y) = 2y - 4\). \(f'(1) = -2 \lt 0\)이므로 안정, \(f'(3) = 2 > 0\)이므로 불안정. 위상선으로 봐도 \(1 \lt y \lt 3\)에서 \(f \lt 0\)(아래로), \(y \lt 1\)에서 \(f > 0\)(위로)이라 화살표가 1로 모인다.

Q5. 자율 방정식 \(y' = f(y)\)(\(f\)는 매끄러움)의 해에 대해 틀린 것은?

해는 평형점을 지날 수 없고(유일성), 평형점 사이에서는 \(f\)의 부호가 일정하므로 한 방향으로만 움직인다. 1차원 자율 방정식에서는 진동이 불가능하다.

Q6. \(r = 0.4\)/년, \(K = 500\)인 개체군에서 일정량 수확 모델의 최대 지속 생산량 \(h_c\)는?

\(h_c = rK/4 = 0.4 \times 500/4 = 50\). 이때 두 평형점이 \(K/2 = 250\)에서 합쳐진다.

Q7. \(y' = y^2\)의 평형점 \(y^* = 0\)의 성질은?

\(f = y^2 \ge 0\)이므로 0의 양쪽에서 화살표가 모두 위로 향한다. 아래(\(y \lt 0\))에서 출발한 해는 0으로 다가가고, 위에서 출발한 해는 멀어져 폭발한다. \(f'(0) = 0\)이면 선형화로는 판정할 수 없다.

Q8. 쌍안정 스위치 \(y' = y - y^3 + s\)가 \(y \approx -1\)에 있다. 일정한 입력 \(s\)를 걸어 계속 유지할 때, 상태가 \(+1\) 쪽으로 넘어가려면?

\(f\)의 극솟값 \(-\frac{2}{3\sqrt3} + s\)가 양수가 되어야 "꺼짐" 평형점이 사라진다(안장–마디 분기). \(0 \lt s \lt 0.385\)이면 평형점이 조금 이동할 뿐 상태는 \(-1\) 근처에 남는다.
