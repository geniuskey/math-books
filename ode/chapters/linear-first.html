1계 선형 방정식과 완전 방정식

2장의 변수분리는 \(y' = g(t)h(y)\)처럼 \(t\)와 \(y\)를 양쪽으로 갈라놓을 수 있을 때만 통했습니다. 그런데 전원이 걸린 RC 회로 \(RCv' + v = V(t)\)나 소금물이 드나드는 탱크처럼 입력이 시간에 따라 바뀌는 문제는 갈라지지 않습니다. 이 장은 공학에서 가장 자주 만나는 1계 방정식인 1계 선형 미분방정식 \(y' + p(t)y = g(t)\)를 단 하나의 곱셈, 적분 인자로 언제나 풀 수 있음을 보이고, 그 해가 "초기값을 잊어 가는 과도 성분 + 입력을 따라가는 정상 성분"으로 갈라진다는 구조를 읽습니다. 이어서 해곡선을 어떤 함수 \(\psi(x, y)\)의 등고선으로 보는 완전 방정식과, 비선형이지만 치환 한 번으로 선형이 되는 베르누이 방정식까지 다룹니다.

  • 1계 선형 방정식을 표준형 \(y' + p(t)y = g(t)\)로 바꾸고, 적분 인자 \(\mu = e^{\int p\,dt}\)를 유도해 일반해 공식을 쓴다.
  • RC·RL 회로를 키르히호프 법칙에서 세우고, 시상수 \(\tau\)를 해와 측정 곡선에서 읽는다.
  • 혼합 탱크를 물질 수지(들어온 양 − 나간 양)로 세우고, 부피가 변하는 경우까지 푼다.
  • 사인 입력에 대한 해를 과도 응답과 정상 상태 응답으로 나누고, 이득과 위상 지연을 계산한다.
  • 선형 방정식의 해가 \(y = y_h + y_p\)임을 증명하고, 해곡선 족 전체를 이 구조로 읽는다.
  • 완전 방정식을 \(M_y = N_x\)로 판정하고 퍼텐셜 \(\psi\)를 찾으며, 적분 인자로 완전하지 않은 방정식을 완전하게 만든다.
  • 베르누이 방정식을 \(v = y^{1-n}\)으로 선형화해 로지스틱 방정식을 다시 푼다.
이 수식이 없었다면RC 타이머와 저역 통과 필터

카메라 플래시가 충전되는 몇 초, 전등 스위치를 끄면 천천히 어두워지는 LED 조명, 오디오 앰프의 고음 잡음을 걸러 내는 필터, 마이크로컨트롤러가 전원을 켠 뒤 잠깐 기다리는 리셋 회로. 모두 저항 하나와 축전기 하나가 만드는 시상수 \(\tau = RC\)로 동작합니다. 설계자는 "몇 초 뒤 몇 볼트"를 정확히 알아야 하는데, 축전기 전압은 들어오는 전압과 자기 자신의 전압 차이로 변하므로 \(v' = (V - v)/RC\)라는 미분방정식을 풀어야 답이 나옵니다.

입력 \(V\)가 상수이면 2장의 변수분리로도 풀리지만, 입력이 사인파이거나 계단처럼 켜졌다 꺼지면 변수분리는 막힙니다. 양변에 \(e^{t/RC}\)를 곱하는 한 수, 적분 인자가 이 벽을 넘습니다. 적분 인자의 방법은 18세기에 오일러(Leonhard Euler) 등이 체계적으로 다루었고, 오늘날 회로·열·화학 반응·약물 동태의 1차 모델은 거의 모두 이 공식 하나로 풀립니다.

표준형: 선형이라는 것의 뜻

왜 이 방정식은 갈라지지 않는가

축전기에 사인파 전압을 걸면 \(v' + v = \sin t\)(시상수 1 s)가 됩니다. 2장처럼 \(dv/dt\)를 "\(t\)만의 함수 × \(v\)만의 함수"로 쓰려 해도 \(\sin t - v\)는 곱으로 갈라지지 않습니다. 하지만 이 방정식은 \(v\)와 \(v'\)에 대해 1차식이라는 아주 특별한 성질을 가집니다. 이 성질 하나가 풀이를 보장합니다.

정의 3.1 (1계 선형 방정식과 표준형) 미지 함수 \(y(t)\)와 그 도함수에 대해 1차인 방정식
$$a_1(t)\,y' + a_0(t)\,y = b(t)$$
를 1계 선형 미분방정식이라 한다. \(a_1(t) \ne 0\)인 구간에서 양변을 \(a_1\)로 나눈
$$y' + p(t)\,y = g(t), \qquad p = \frac{a_0}{a_1},\quad g = \frac{b}{a_1}$$
를 표준형(standard form)이라 한다. \(g \equiv 0\)이면 동차(homogeneous), 아니면 비동차(nonhomogeneous) 방정식이라 하고, \(g\)를 입력 또는 강제 항이라 부른다.

"선형"은 \(y\)의 그래프가 직선이라는 뜻이 아닙니다. \(y\)와 \(y'\)이 1차로, 서로 곱해지지 않고, 함수 안에 들어가지 않고 나타난다는 뜻입니다. 계수 \(p(t)\), \(g(t)\)는 \(t\)에 대해 아무리 복잡해도 괜찮습니다.

동차 방정식 \(y' + p(t)y = 0\)은 변수분리형입니다(2장). \(dy/y = -p(t)\,dt\)를 적분하면 \(\ln|y| = -\int p\,dt + c\), 즉

$$y_h(t) = C\,e^{-\int p(t)\,dt}.$$
\(C\)는 임의의 상수(\(C = 0\)이면 상수 해 \(y \equiv 0\)도 포함된다).

이 동차해가 다음 절의 열쇠입니다. 비동차 방정식을 풀 때 필요한 "마법의 곱수"는 바로 이 \(e^{-\int p}\)의 역수입니다.

적분 인자: 왼쪽을 곱의 도함수로 만들기

\(y' + 2y = 4\)를 적분하고 싶다

양변을 그냥 적분하면 \(y + 2\int y\,dt = 4t + C\)가 되는데, \(\int y\,dt\)는 \(y\)를 모르면 계산할 수 없습니다. 왼쪽 \(y' + 2y\)가 어떤 함수의 도함수 하나로 묶여 있다면 바로 적분할 수 있을 텐데요. 곱의 미분 \((\mu y)' = \mu y' + \mu' y\)가 그 모양과 닮았습니다.

양변에 아직 모르는 함수 \(\mu(t) > 0\)를 곱합니다.

$$\mu y' + \mu p\,y = \mu g.$$

왼쪽이 \((\mu y)' = \mu y' + \mu' y\)와 같아지려면 \(\mu' = p\mu\)이면 됩니다. 이것은 \(\mu\)에 대한 변수분리형 방정식이고, 해 하나 \(\mu = e^{\int p\,dt}\)를 고르면 충분합니다(적분 상수는 \(\mu\)에 상수배를 곱할 뿐이고, 양변에 같이 곱해지므로 지워집니다). 그러면 방정식은

$$\bigl(\mu(t)\,y\bigr)' = \mu(t)\,g(t)$$
왼쪽이 도함수 하나가 되었으므로 양변을 적분할 수 있다.
정리 3.1 (적분 인자와 일반해) \(p\), \(g\)가 구간 \(I\)에서 연속이면, 적분 인자(integrating factor) \(\mu(t) = e^{\int p(t)\,dt}\)에 대해 \(y' + p(t)y = g(t)\)의 모든 해는
$$y(t) = \frac{1}{\mu(t)}\left(\int \mu(t)\,g(t)\,dt + C\right)$$
꼴이다. 초기 조건 \(y(t_0) = y_0\)를 주면 \(\mu(t) = \exp\int_{t_0}^t p(s)\,ds\)로 잡아
$$y(t) = \frac{1}{\mu(t)}\left(y_0 + \int_{t_0}^{t} \mu(s)\,g(s)\,ds\right)$$
가 \(I\) 전체에서 정의되는 유일한 해다.

증명. 위의 계산을 거꾸로 따라가면 공식이 해임을 확인할 수 있다. 거꾸로 \(y\)가 임의의 해이면 \((\mu y)' = \mu y' + p\mu y = \mu g\)이므로 기본 정리로 \(\mu(t)y(t) - \mu(t_0)y(t_0) = \int_{t_0}^t \mu g\,ds\)이고, \(\mu(t_0) = 1\)이므로 \(y\)는 공식과 같다. 따라서 해는 하나뿐이다. ∎

이 정리는 4장에서 다룰 일반적인 존재·유일성 정리보다 훨씬 강합니다. 선형 방정식의 해는 계수가 연속인 구간 전체에서 존재하고, 도중에 무한대로 튀는 일이 없습니다. 비선형 방정식 \(y' = y^2\)의 해가 유한 시각에 폭발하는 것(4장)과 대조됩니다.

예제 3.1 (상수 계수) \(y' + 2y = 4\), \(y(0) = 0\)을 풀어라.
  1. \(p = 2\)이므로 \(\mu = e^{2t}\).
  2. 곱하면 \((e^{2t}y)' = 4e^{2t}\). 적분하면 \(e^{2t}y = 2e^{2t} + C\).
  3. \(y = 2 + Ce^{-2t}\). \(y(0) = 0\)에서 \(C = -2\), 따라서 \(y = 2(1 - e^{-2t})\).
  4. 검산: \(y' = 4e^{-2t}\), \(y' + 2y = 4e^{-2t} + 4 - 4e^{-2t} = 4\). ✓ RK4로 \(t = 1.3\)까지 적분한 값 1.851453도 공식과 소수 여섯째 자리까지 같다.
예제 3.2 (입력이 시간의 함수) \(y' + y = t\), \(y(0) = 1\)을 풀어라.
  1. \(\mu = e^t\). \((e^ty)' = te^t\).
  2. 부분 적분(CalculusBook 9장)으로 \(\int te^t\,dt = (t - 1)e^t + C\).
  3. \(y = t - 1 + Ce^{-t}\). \(y(0) = -1 + C = 1\)이므로 \(C = 2\): \(y = t - 1 + 2e^{-t}\).
  4. \(t\)가 커지면 \(2e^{-t}\)는 사라지고 해는 직선 \(t - 1\)을 따라간다. 입력 \(t\)를 시상수 1만큼 늦게 따라가는 셈이다. \(y(2) = 1 + 2e^{-2} \approx 1.2707\).
예제 3.3 (계수가 변할 때: 표준형부터) \(ty' + 2y = 4t^2\), \(y(1) = 2\)를 \(t > 0\)에서 풀어라.
  1. \(t\)로 나눠 표준형으로: \(y' + \frac{2}{t}y = 4t\). 그러므로 \(p = 2/t\)(나누기 전의 2가 아니다).
  2. \(\mu = e^{\int 2/t\,dt} = e^{2\ln t} = t^2\). \((t^2y)' = 4t^3\), \(t^2y = t^4 + C\).
  3. \(y = t^2 + C/t^2\). \(y(1) = 1 + C = 2\)이므로 \(y = t^2 + t^{-2}\).
  4. \(p = 2/t\)는 \(t = 0\)에서 불연속이므로 정리 3.1이 보장하는 구간은 \(t > 0\)이다. 실제로 해는 \(t \to 0^+\)에서 발산한다. \(y(2.5) = 6.41\)(RK4와 일치).

아래 시뮬레이터는 적분 인자가 하는 일을 직접 보여 줍니다. 왼쪽은 해 \(y(t)\), 오른쪽은 \(\mu y\)와 "\(y_0 + \int \mu g\)"입니다. 오른쪽 두 곡선이 정확히 겹친다는 것이 정리 3.1의 내용입니다. \(\mu\)를 곱하는 순간 \(y\)가 얽혀 있던 방정식이 그냥 적분으로 바뀝니다.

RC·RL 회로와 시상수

플래시 축전기는 언제 다 차는가

5 V 전원에 10 kΩ 저항과 100 μF 축전기를 직렬로 연결하고 스위치를 닫습니다. 축전기 전압이 4.5 V(90%)에 이르면 "충전 완료" LED를 켜려 합니다. 몇 초 뒤일까요? 전류는 전압 차 \(5 - v\)에 비례하는데, 충전될수록 그 차이가 줄어 전류도 줄어듭니다. 변화율이 현재 상태에 달려 있으니 미분방정식입니다.

모델. 키르히호프 전압 법칙: 고리를 한 바퀴 돌면 전압 강하의 합은 전원 전압과 같습니다. 저항의 강하는 \(Ri\)(옴의 법칙), 축전기의 강하는 \(v = q/C\)이고, 전류는 축전기에 쌓이는 전하의 변화율 \(i = dq/dt = C\,dv/dt\)입니다.

$$Ri + v = V_s \;\Longrightarrow\; RC\,\frac{dv}{dt} + v = V_s \;\Longrightarrow\; v' + \frac{1}{RC}\,v = \frac{V_s}{RC}.$$

\(\mu = e^{t/RC}\)를 곱하면 \((e^{t/RC}v)' = \frac{V_s}{RC}e^{t/RC}\), 적분해 \(v = V_s + Ce^{-t/RC}\)입니다. 처음 비어 있던(\(v(0) = 0\)) 축전기라면

$$v(t) = V_s\left(1 - e^{-t/\tau}\right),\qquad i(t) = \frac{V_s}{R}e^{-t/\tau},\qquad \tau = RC.$$
\(\tau\)의 단위는 \(\Omega\cdot\text{F} = \frac{\text{V}}{\text{A}}\cdot\frac{\text{A}\cdot\text{s}}{\text{V}} = \text{s}\). 방전(\(V_s = 0\), \(v(0) = V_0\))이면 \(v = V_0e^{-t/\tau}\).
정의 3.2 (시상수) 1차 시스템 \(\tau y' + y = u\)에서 \(\tau > 0\)를 시상수(time constant)라 한다. 계단 입력 후 출력은 남은 거리 \(u - y\)를 시간 \(\tau\)마다 \(1/e \approx 0.368\)배로 줄인다. 처음 기울기 \(\frac{u - y(0)}{\tau}\)로 계속 갔다면 정확히 \(\tau\) 뒤에 도착했을 것이다.

예제 3.4 (충전 완료까지의 시간) 위 문제(\(V_s = 5\) V, \(R = 10\) kΩ, \(C = 100\) μF)에서 \(v = 4.5\) V가 되는 시각과, 그때의 전류를 구하라.
  1. \(\tau = RC = 10^4 \times 10^{-4} = 1\) s.
  2. \(1 - e^{-t} = 0.9\)에서 \(t = \ln 10 \approx 2.303\) s(약 2.3τ).
  3. \(i = \frac{V_s}{R}e^{-t/\tau} = 0.5\ \text{mA} \times 0.1 = 0.05\) mA. 전류는 전압 차에 비례하므로 남은 거리 10%만큼만 흐른다.
에너지의 절반은 저항이 가져간다 충전이 끝나면 축전기에는 \(\frac12CV_s^2\)이 저장되고, 전원은 전하 \(CV_s\)를 전압 \(V_s\)로 밀어 넣었으니 \(CV_s^2\)의 일을 했습니다. 나머지 절반은 저항에서 열이 됩니다: \(\int_0^\infty i^2R\,dt = \frac{V_s^2}{R}\cdot\frac{\tau}{2} = \frac12CV_s^2\). 놀랍게도 \(R\)이 얼마든 같습니다. \(R\)은 충전 속도만 정합니다.

RL 회로. 축전기 대신 인덕터 \(L\)을 두면 인덕터 전압이 \(L\,di/dt\)이므로 \(L i' + Ri = V_s\), 즉 \(i' + \frac{R}{L}i = \frac{V_s}{L}\)입니다. 같은 꼴이고 시상수는 \(\tau = L/R\), 해는 \(i = \frac{V_s}{R}(1 - e^{-Rt/L})\)입니다. 예를 들어 \(L = 0.5\) H, \(R = 10\) Ω, \(V_s = 12\) V이면 \(\tau = 0.05\) s이고 전류는 0.25 s(5τ) 만에 최종값 1.2 A의 99.3%에 이릅니다. 인덕터는 전류의 급변을 막으므로, 스위치를 갑자기 끊으면 \(L\,di/dt\)가 매우 커져 불꽃이 튑니다. 릴레이 코일에 다이오드를 병렬로 다는 이유입니다.

혼합 탱크: 들어온 양 − 나간 양

호수의 오염은 얼마나 빨리 빠지는가

공장이 오염 물질 배출을 멈췄습니다. 호수에는 깨끗한 강물이 흘러들고 같은 양이 흘러 나갑니다. 오염 농도가 처음의 10%로 내려가는 데 몇 년이 걸릴까요? 호수를 "잘 섞인 탱크"로 보면 이것은 1계 선형 방정식 하나입니다. 같은 틀이 약물의 혈중 농도, 실내 공기의 CO₂ 환기, 화학 반응기의 농도에도 쓰입니다.

모델(물질 수지). 탱크 안의 용질 양을 \(Q(t)\)(kg), 부피를 \(V(t)\)(L)라 합니다. 농도 \(c_{\text{in}}\)(kg/L)의 용액이 유량 \(q_{\text{in}}\)(L/min)으로 들어오고, 잘 섞인 탱크 안의 용액이 유량 \(q_{\text{out}}\)으로 나갑니다. 나가는 용액의 농도는 탱크 안의 농도 \(Q/V\)와 같습니다.

$$\frac{dQ}{dt} = \underbrace{q_{\text{in}}\,c_{\text{in}}}_{\text{들어오는 양}} - \underbrace{q_{\text{out}}\,\frac{Q}{V(t)}}_{\text{나가는 양}},\qquad V(t) = V_0 + (q_{\text{in}} - q_{\text{out}})\,t.$$
표준형 \(Q' + \frac{q_{\text{out}}}{V(t)}Q = q_{\text{in}}c_{\text{in}}\). \(V/q_{\text{out}}\)은 탱크를 한 번 갈아 치우는 데 걸리는 시간으로, 유량이 같으면 바로 시상수다.
예제 3.5 (유입량 = 유출량) 100 L의 맑은 물이 든 탱크에 농도 0.5 kg/L의 소금물이 4 L/min으로 들어오고, 섞인 물이 4 L/min으로 나간다. \(Q(t)\)와 소금이 40 kg이 되는 시각을 구하라.
  1. \(V = 100\)으로 일정. \(Q' = 4(0.5) - 4\frac{Q}{100} = 2 - 0.04Q\), \(Q(0) = 0\).
  2. \(\mu = e^{0.04t}\), \((e^{0.04t}Q)' = 2e^{0.04t}\), \(Q = 50 + Ce^{-0.04t}\). \(C = -50\).
  3. \(Q(t) = 50(1 - e^{-t/25})\). 시상수는 \(V/q = 25\) min이고, 농도는 유입 농도 0.5 kg/L(소금 50 kg)로 다가간다. \(Q(25) = 50(1 - e^{-1}) \approx 31.6\) kg.
  4. \(Q = 40\): \(e^{-t/25} = 0.2\), \(t = 25\ln 5 \approx 40.2\) min.
예제 3.6 (부피가 변할 때) 같은 탱크(처음 100 L 맑은 물)에 0.5 kg/L 소금물이 3 L/min으로 들어오고 2 L/min으로 나간다. 50분 뒤 소금의 양과 농도는?
  1. \(V(t) = 100 + t\). \(Q' = 1.5 - \frac{2Q}{100 + t}\), 즉 \(Q' + \frac{2}{100 + t}Q = 1.5\).
  2. \(\mu = e^{\int 2/(100+t)\,dt} = (100 + t)^2\). \(\bigl((100 + t)^2Q\bigr)' = 1.5(100 + t)^2\).
  3. 적분: \((100 + t)^2Q = 0.5(100 + t)^3 + C\). \(Q(0) = 0\)에서 \(C = -0.5\times 10^6\).
  4. \(Q(t) = 0.5(100 + t) - \dfrac{5\times 10^5}{(100 + t)^2}\). \(t = 50\)에서 \(Q = 75 - 22.2 = 52.8\) kg, 부피 150 L, 농도 0.352 kg/L(RK4 52.777778과 일치).
  5. 계수 \(p(t) = 2/(100 + t)\)가 시간에 따라 변하므로 "시상수" 하나로 말할 수 없다. 이런 문제를 변수분리로는 풀 수 없고, 적분 인자가 필요하다.

호수 문제로 돌아가면, 유입이 맑은 물(\(c_{\text{in}} = 0\))이고 부피가 일정하면 \(Q = Q_0e^{-qt/V}\)이므로 10%가 되는 시간은 \(\frac{V}{q}\ln 10 \approx 2.3\frac{V}{q}\)입니다. 호수 물이 한 번 갈리는 시간의 2.3배입니다. 실제 호수는 잘 섞이지 않고 바닥 퇴적물이 오염 물질을 다시 내놓아 더 오래 걸리는 것이 보통입니다. 모델의 가정을 기억해야 하는 이유입니다.

RC 필터는 고음을 얼마나 줄이는가

RC 회로의 출력을 축전기 양단에서 뽑으면 빠르게 변하는 신호일수록 축전기가 따라가지 못해 작아집니다. 이것이 저역 통과 필터입니다. 입력이 \(\sin\omega t\)이면 출력은 처음에 초기 전압의 영향을 받다가, 곧 같은 진동수로 진동하되 작아지고 늦어진 사인파가 됩니다. 얼마나 작아지고 얼마나 늦어질까요?

\(k = 1/\tau\)로 쓰면 \(\tau v' + v = \sin\omega t\)는 \(y' + ky = k\sin\omega t\)입니다. 적분 인자로 풀 수 있지만, 해가 "같은 진동수의 사인파"일 것이라 짐작하고 \(y_p = A\cos\omega t + B\sin\omega t\)를 대입하는 편이 빠릅니다(8장의 미정계수법).

$$-A\omega\sin\omega t + B\omega\cos\omega t + kA\cos\omega t + kB\sin\omega t = k\sin\omega t$$
\(\cos\): \(B\omega + kA = 0\), \(\sin\): \(-A\omega + kB = k\). 풀면 \(A = -\dfrac{k\omega}{k^2 + \omega^2}\), \(B = \dfrac{k^2}{k^2 + \omega^2}\).

두 성분을 하나의 사인파로 합치면(\(B\sin + A\cos = R\sin(\omega t - \varphi)\)) 다음 정리가 됩니다.

정리 3.2 (1차 시스템의 사인 응답) \(k > 0\)일 때 \(y' + ky = k\sin\omega t\), \(y(0) = y_0\)의 해는
$$y(t) = \underbrace{G\sin(\omega t - \varphi)}_{\text{정상 상태 응답}} + \underbrace{\Bigl(y_0 + \frac{k\omega}{k^2 + \omega^2}\Bigr)e^{-kt}}_{\text{과도 응답}},\qquad G = \frac{k}{\sqrt{k^2 + \omega^2}} = \frac{1}{\sqrt{1 + (\omega\tau)^2}},\quad \varphi = \arctan\frac{\omega}{k} = \arctan(\omega\tau).$$
\(G\)를 이득, \(\varphi\)를 위상 지연이라 한다. 과도 응답은 시상수 \(\tau = 1/k\)로 사라지고, 정상 상태 응답은 초기값과 무관하다.

과도 응답(transient response)은 초기값의 "기억"이고 정상 상태 응답(steady-state response)은 입력의 "흉내"입니다. \(\omega\tau \ll 1\)(느린 입력)이면 \(G \approx 1\), \(\varphi \approx 0\)으로 출력이 입력을 거의 그대로 따라가고, \(\omega\tau \gg 1\)(빠른 입력)이면 \(G \approx 1/(\omega\tau)\)로 작아지고 위상이 거의 90° 늦어집니다. 경계인 \(\omega = 1/\tau\)에서 \(G = 1/\sqrt2 \approx 0.707\)(약 −3 dB), \(\varphi = 45°\)이며 이 진동수를 차단 주파수(cutoff frequency)라 합니다. 주파수 응답과 보드 선도는 10장에서 본격적으로 다룹니다.

예제 3.7 (차단 주파수에서의 응답) \(y' + y = \sin t\), \(y(0) = 0\)을 풀고 \(y(3)\)을 구하라.
  1. \(k = \omega = 1\)이므로 \(A = -\frac12\), \(B = \frac12\). \(y_p = \frac12(\sin t - \cos t) = \frac{1}{\sqrt2}\sin(t - 45°)\).
  2. \(y = y_p + Ce^{-t}\), \(y(0) = -\frac12 + C = 0\)에서 \(C = \frac12\).

완전 방정식: 해곡선은 퍼텐셜의 등고선

선형도 아니고 분리도 안 되는 방정식

\(\dfrac{dy}{dx} = -\dfrac{3x^2 + 2xy}{x^2 + 2y}\)는 \(y\)에 대해 선형이 아니고 변수도 갈라지지 않습니다. 그런데 이 방정식을 \((3x^2 + 2xy)\,dx + (x^2 + 2y)\,dy = 0\)으로 쓰고 보면, 왼쪽이 \(\psi = x^3 + x^2y + y^2\)의 전미분 \(d\psi = \psi_x\,dx + \psi_y\,dy\)와 똑같습니다. 그렇다면 해곡선 위에서 \(d\psi = 0\), 즉 \(\psi\)가 일정합니다. 해곡선은 지형도의 등고선이었습니다.

미분 형식 \(M(x, y)\,dx + N(x, y)\,dy = 0\)은 \(dy/dx = -M/N\)의 다른 표기입니다. \(x\)와 \(y\)를 대등하게 다루므로, 해곡선이 수직 접선을 가져도(\(N = 0\)) 문제없이 다룰 수 있다는 장점이 있습니다.

정의 3.3 (완전 방정식과 퍼텐셜) 영역 \(R\)에서 \(\psi_x = M\), \(\psi_y = N\)인 함수 \(\psi(x, y)\)가 있으면 \(M\,dx + N\,dy = 0\)을 완전 방정식(exact equation), \(\psi\)를 퍼텐셜 함수(potential function)라 한다. 이때 해는 음함수 \(\psi(x, y) = C\)로 주어진다.

왜 그런지는 연쇄 법칙 한 줄입니다(CalculusBook 편미분). \(y(x)\)가 해이면 \(\frac{d}{dx}\psi(x, y(x)) = \psi_x + \psi_y\,y' = M + Ny' = 0\)이므로 \(\psi\)는 해를 따라 상수입니다. 기하적으로는 기울기 벡터 \(\nabla\psi = (M, N)\)이 등고선에 수직이고, 방정식이 요구하는 접선 방향 \((N, -M)\)은 \(\nabla\psi\)와 수직입니다.

그러면 \(\psi\)가 있는지 어떻게 알까요? \(\psi\)가 매끄러우면 혼합 편도함수가 같아야 하므로(클레로 정리) \(M_y = \psi_{xy} = \psi_{yx} = N_x\)가 필요합니다. 놀랍게도 직사각형 같은 단순한 영역에서는 이것이 충분하기도 합니다.

정리 3.5 (완전성 판정) \(M\), \(N\), \(M_y\), \(N_x\)가 직사각형 영역 \(R\)에서 연속이면
$$M\,dx + N\,dy = 0 \text{ 이 } R\text{에서 완전} \iff \frac{\partial M}{\partial y} = \frac{\partial N}{\partial x} \ \text{ (}R\text{ 전체에서)}.$$

증명(충분성의 구성). \(\psi(x, y) = \int_{x_0}^x M(s, y)\,ds + h(y)\)로 두면 \(\psi_x = M\)이다. \(\psi_y = \int_{x_0}^x M_y(s, y)\,ds + h'(y) = \int_{x_0}^x N_x(s, y)\,ds + h'(y) = N(x, y) - N(x_0, y) + h'(y)\)이므로 \(h'(y) = N(x_0, y)\)로 잡으면 \(\psi_y = N\). \(h\)는 \(y\)만의 함수이므로 적분할 수 있다. ∎

이 증명이 그대로 풀이법입니다: \(M\)을 \(x\)로 적분하고, \(y\)로 미분해 \(N\)과 비교해서 빠진 \(h(y)\)를 찾습니다. 전자기학에서 보존력장의 퍼텐셜을 찾는 것과 똑같은 계산입니다(CalculusBook 벡터 미적분).

예제 3.8 (완전 방정식 풀기) \((3x^2 + 2xy)\,dx + (x^2 + 2y)\,dy = 0\), \(y(0) = 2\)를 풀어라.
  1. 판정: \(M_y = 2x\), \(N_x = 2x\). 같으므로 완전하다.
  2. \(\psi = \int(3x^2 + 2xy)\,dx = x^3 + x^2y + h(y)\).
  3. \(\psi_y = x^2 + h'(y) = N = x^2 + 2y\)이므로 \(h' = 2y\), \(h = y^2\). \(\psi = x^3 + x^2y + y^2\).
  4. \(\psi(0, 2) = 4\)이므로 해는 \(x^3 + x^2y + y^2 = 4\). \(y\)에 대한 이차식으로 풀어 \(y = \frac12\bigl(-x^2 + \sqrt{x^4 - 4x^3 + 16}\bigr)\)(\(y(0) = 2\)이므로 + 부호).

적분 인자로 완전하게 만들기

거의 완전한 방정식

\((3xy + y^2)\,dx + (x^2 + xy)\,dy = 0\)은 \(M_y = 3x + 2y\), \(N_x = 2x + y\)로 완전하지 않습니다. 하지만 해곡선 자체는 \(M\)과 \(N\)의 비율 \(-M/N\)만으로 정해지므로, 양변에 같은 함수 \(\mu(x, y)\)를 곱해도 해곡선은 바뀌지 않습니다. 잘 고른 \(\mu\)를 곱해 완전하게 만들 수 있을까요?

\(\mu M\,dx + \mu N\,dy = 0\)이 완전하려면 \((\mu M)_y = (\mu N)_x\), 즉 \(\mu_yM + \mu M_y = \mu_xN + \mu N_x\)이어야 합니다. 이것은 \(\mu\)에 대한 편미분방정식이라 일반적으로는 원래 문제보다 어렵습니다. 그러나 \(\mu\)가 한 변수만의 함수라고 가정하면 1계 상미분방정식이 됩니다.

정리 3.6 (한 변수 적분 인자)
  • \(\dfrac{M_y - N_x}{N}\)가 \(x\)만의 함수 \(F(x)\)이면 \(\mu(x) = e^{\int F(x)\,dx}\)가 적분 인자다.
  • \(\dfrac{N_x - M_y}{M}\)가 \(y\)만의 함수 \(G(y)\)이면 \(\mu(y) = e^{\int G(y)\,dy}\)가 적분 인자다.

증명. \(\mu = \mu(x)\)이면 \(\mu_y = 0\)이므로 조건은 \(\mu M_y = \mu'N + \mu N_x\), 즉 \(\mu'/\mu = (M_y - N_x)/N\). 오른쪽이 \(x\)만의 함수일 때만 이 식이 \(x\)만으로 풀리고, 해가 \(\mu = e^{\int F}\)다. 둘째도 같다. ∎

예제 3.10 \((3xy + y^2)\,dx + (x^2 + xy)\,dy = 0\)을 풀어라.
  1. \(\dfrac{M_y - N_x}{N} = \dfrac{(3x + 2y) - (2x + y)}{x(x + y)} = \dfrac{x + y}{x(x + y)} = \dfrac1x\). \(x\)만의 함수다.
  2. \(\mu = e^{\int dx/x} = x\)(\(x > 0\)). 곱하면 \((3x^2y + xy^2)\,dx + (x^3 + x^2y)\,dy = 0\). 확인: \(\partial_y(3x^2y + xy^2) = 3x^2 + 2xy = \partial_x(x^3 + x^2y)\). ✓
  3. \(\psi = \int(3x^2y + xy^2)\,dx = x^3y + \frac12x^2y^2 + h(y)\). \(\psi_y = x^3 + x^2y + h' = x^3 + x^2y\)이므로 \(h = 0\).
  4. 일반해 \(x^3y + \frac12x^2y^2 = C\). (1, 1)을 지나는 해는 \(C = 1.5\)이고, RK4로 \(x = 2\)까지 적분한 점에서 \(\psi\)를 계산하면 1.5000이 나온다.

선형 방정식은 특별한 경우다. \(y' + p(x)y = g(x)\)를 \((p(x)y - g(x))\,dx + dy = 0\)으로 쓰면 \(M_y = p\), \(N_x = 0\)이므로 \((M_y - N_x)/N = p(x)\)입니다. 정리 3.6이 주는 적분 인자는 \(\mu = e^{\int p\,dx}\), 바로 2절의 적분 인자입니다. 2절에서 "왼쪽을 곱의 도함수로 만든다"고 했던 것은 "미분 형식을 완전하게 만든다"는 것과 같은 일이었습니다. 이때 퍼텐셜은 \(\psi = \mu y - \int\mu g\,dx\)이고, \(\psi = C\)가 정리 3.1의 공식입니다.

적분 인자를 곱할 때 잃거나 얻는 해 \(\mu\)가 0이 되거나 정의되지 않는 곳에서는 해가 생기거나 사라질 수 있습니다. 예제 3.10에서 \(\mu = x\)를 곱하면 \(x = 0\)이 새로 "해"처럼 보이는데, 원래 방정식에서 \(x = 0\)은 \(N = 0\)이 되는 곳입니다. 또 \(y \equiv 0\)은 원래 방정식의 해(\(M = 0\))이고 일반해의 \(C = 0\)에 들어 있습니다. 2장에서 상수 해를 잃지 않도록 조심했던 것과 같은 주의가 필요합니다.

베르누이 방정식: 치환으로 선형이 되는 비선형

로지스틱 방정식을 적분 없이 풀 수 있을까

2장에서 로지스틱 방정식 \(y' = ry(1 - y/K)\)를 부분 분수로 풀었습니다. 계산이 길었죠. 이 방정식은 \(y' - ry = -\frac{r}{K}y^2\)으로, 선형 방정식에 \(y^2\) 항 하나가 붙은 꼴입니다. 이런 꼴은 \(1/y\)로 바꿔 보면 선형이 됩니다.

정리 3.7 (베르누이 방정식) \(n \ne 0, 1\)인 실수 \(n\)에 대해
$$y' + p(t)\,y = q(t)\,y^n$$
을 베르누이 방정식(Bernoulli equation)이라 한다. \(y > 0\)에서 \(v = y^{1-n}\)으로 치환하면 \(v\)는 1계 선형 방정식
$$v' + (1 - n)\,p(t)\,v = (1 - n)\,q(t)$$
를 만족한다.

증명. \(v' = (1 - n)y^{-n}y'\). 원래 식에 \(y^{-n}\)을 곱하면 \(y^{-n}y' + p\,y^{1-n} = q\), 즉 \(\frac{v'}{1 - n} + pv = q\). ∎

이 방정식은 1695년 야코프 베르누이(Jakob Bernoulli)가 제기했고, 라이프니츠(Gottfried Wilhelm Leibniz)가 선형 방정식으로 바꾸어 푼 것으로 알려져 있습니다. \(n = 0\)이면 이미 선형이고, \(n = 1\)이면 \(y' = (q - p)y\)로 변수분리형입니다.

예제 3.11 (로지스틱 방정식을 선형으로) \(y' = ry - \frac{r}{K}y^2\), \(y(0) = y_0 > 0\)을 풀어라.
  1. \(n = 2\), \(p = -r\), \(q = -r/K\). \(v = 1/y\)로 두면 \(v' + rv = r/K\).
  2. \(v = \frac1K + Ce^{-rt}\), \(C = \frac{1}{y_0} - \frac1K\).
  3. \(y = \dfrac{1}{v} = \dfrac{K}{1 + \bigl(\frac{K}{y_0} - 1\bigr)e^{-rt}}\). 2장의 결과와 같다.
  4. \(r = 0.8\), \(K = 10\), \(y_0 = 1\)이면 \(y(5) = 10/(1 + 9e^{-4}) \approx 8.585\)(RK4와 일치). 비선형인 \(y\)가 S자로 가는 동안 \(v = 1/y\)는 단순한 지수 감쇠로 \(1/K\)에 다가간다.
예제 3.12 (n = 3) \(y' = y - y^3\), \(y(0) = 0.2\)를 풀어라.
  1. \(n = 3\), \(v = y^{-2}\). \(v' = -2y^{-3}y' = -2y^{-2} + 2 = -2v + 2\), 즉 \(v' + 2v = 2\).
  2. \(v = 1 + Ce^{-2t}\), \(v(0) = 25\)이므로 \(C = 24\). \(y = (1 + 24e^{-2t})^{-1/2}\).
  3. \(y(2) = (1 + 24e^{-4})^{-1/2} \approx 0.8335\)(RK4 0.833456). 해는 평형점 1로 다가간다.

핵심 정리

  1. 1계 선형 방정식은 표준형 \(y' + p(t)y = g(t)\)로 쓴다. 표준형으로 바꾼 뒤에 \(p\)를 읽는다(\(ty' + 2y\)이면 \(p = 2/t\)).
  2. 적분 인자 \(\mu = e^{\int p\,dt}\)를 곱하면 \((\mu y)' = \mu g\)가 되어 \(y = \frac1\mu\bigl(\int\mu g\,dt + C\bigr)\). \(p, g\)가 연속인 구간 전체에서 해가 존재하고 유일하다.
  3. RC 회로 \(RCv' + v = V_s\), RL 회로 \(Li' + Ri = V_s\)의 시상수는 \(RC\), \(L/R\). \(\tau\)마다 남은 거리가 \(1/e\)배, 5τ면 99.3%. 측정에서는 63.2%점, 처음 접선, 반로그 직선으로 τ를 읽는다.
  4. 혼합 탱크는 \(Q' = q_{\text{in}}c_{\text{in}} - q_{\text{out}}Q/V(t)\). 부피가 변하면 계수가 시간의 함수가 되어 적분 인자가 필요하다.

Q3. 200 L 탱크에 소금 40 kg이 녹아 있다. 맑은 물이 10 L/min으로 들어오고 섞인 물이 10 L/min으로 나간다. 소금이 20 kg이 되는 시각은?

\(Q' = -\frac{10}{200}Q\)이므로 \(Q = 40e^{-t/20}\). 절반이 되는 시간은 \(20\ln 2 \approx 13.9\) min. 시상수 20 min과 반감기를 혼동하지 말 것.

Q4. \(y' + 3y = 3\sin 4t\)의 정상 상태 응답의 진폭과 위상 지연은?

\(k = 3\), \(\omega = 4\). \(G = 3/\sqrt{9 + 16} = 0.6\), \(\varphi = \arctan(4/3) \approx 53.1°\). 입력이 차단 주파수(ω = 3)보다 빠르므로 이득이 0.707보다 작고 지연이 45°보다 크다.

Q5. \((2xy + y^3)\,dx + (x^2 + 3xy^2)\,dy = 0\)의 퍼텐셜 함수는?

\(M_y = 2x + 3y^2 = N_x\)이므로 완전하다. \(\int M\,dx = x^2y + xy^3 + h(y)\), \(\psi_y = x^2 + 3xy^2 + h' = N\)이므로 \(h = 0\).

Q6. 베르누이 방정식 \(y' + y = y^3\)에 \(v = y^{-2}\)를 넣으면?

\(n = 3\), \(p = 1\), \(q = 1\). 정리 3.7로 \(v' + (1 - 3)(1)v = (1 - 3)(1)\), 즉 \(v' - 2v = -2\). 직접: \(v' = -2y^{-3}y' = -2y^{-3}(y^3 - y) = -2 + 2v\).

Q7. \(y_1\)과 \(y_2\)가 모두 \(y' + p(t)y = g(t)\)의 해이다(\(g \ne 0\)). 항상 참인 것은?

\(L[y_1 - y_2] = g - g = 0\). 합은 \(L[y_1 + y_2] = 2g\)이라 원래 방정식의 해가 아니다. 그래서 "특수해 하나 + 동차해"가 모든 해다.

Q8. \(y' + y = 3\), \(y(0) = 5\)일 때 \(y(\ln 2)\)는?

\(y = 3 + 2e^{-t}\). \(t = \ln 2\)이면 \(e^{-t} = 1/2\)이므로 \(y = 3 + 1 = 4\). 처음 거리 2가 반감기 \(\ln 2\)만에 절반이 되었다.
