Chapter 10

불연속 입력과 전달 함수

실제 기계와 회로의 입력은 매끄러운 사인파만이 아닙니다. 스위치를 켜는 순간 전압이 뛰어오르고, 망치가 쇠를 때리는 순간 힘이 아주 짧게 치솟습니다. 미정계수법은 이런 입력 앞에서 무력하지만, 9장의 라플라스 변환은 오히려 이런 입력에서 빛납니다. 이 장에서는 끊어지는 입력을 단위 계단 함수와 디랙 델타로 쓰고, 시스템을 "충격을 주었을 때의 반응" 하나로 요약하는 충격 응답, 그 반응으로 임의의 입력에 대한 출력을 쌓아 올리는 합성곱, 그리고 이 모든 것을 \(s\)의 유리 함수 하나에 담는 전달 함수를 다룹니다. 끝에서는 극점의 위치만 보고 오버슈트와 안정성을 읽고, 제어기의 첫걸음인 PID를 만져 봅니다.

  • 단위 계단 \(u(t-a)\)로 구간별 입력을 쓰고, t-이동 정리로 변환하여 스위치 회로와 구간별 강제항 문제를 푼다.
  • 디랙 델타를 좁은 펄스의 극한으로 이해하고, 거르기 성질과 \(\mathcal{L}\{\delta(t-a)\} = e^{-as}\)를 쓴다.
  • 충격 응답 \(h(t)\)와 합성곱 \((h*g)(t)\)으로 영상태 응답을 쓰고, 합성곱 정리 \(\mathcal{L}\{f*g\} = FG\)를 증명한다.
  • 전달 함수 \(H(s)\)의 극점과 영점을 구하고, s-평면의 극점 위치로 응답 모양과 BIBO 안정성을 판정한다.
  • 주파수 응답 \(H(i\omega)\)로 정상 상태 사인 응답을 구하고 보드 선도의 점근선을 그린다.
  • 1차·2차 시스템의 계단 응답 지표(시상수, 오버슈트, 첨두 시간, 정착 시간)를 극점에서 계산하고, P·I·D 항의 역할을 설명한다.
이 수식이 없었다면자동 제어 장치

자동차의 크루즈 컨트롤, 드론의 자세 안정, 엘리베이터가 층에 부드럽게 서는 일, 보일러의 온도 유지. 모두 센서로 출력을 재고 오차를 줄이도록 입력을 고치는 되먹임 제어입니다. 설계자가 미리 알아야 하는 것은 "목표값을 계단처럼 바꾸면 얼마나 넘치고 언제 가라앉는가", "어떤 진동수의 흔들림을 얼마나 키우는가"입니다. 장치마다 미분방정식을 처음부터 풀어서는 설계를 반복할 수 없습니다.

20세기 전반 벨 연구소의 블랙(Harold S. Black)이 음되먹임 증폭기를 만들고 보드(Hendrik W. Bode)가 주파수 응답으로 증폭기의 안정성을 분석하면서, 시스템을 전달 함수라는 \(s\)의 함수 하나로 다루는 방법이 자리 잡았습니다. 블록을 곱하고 되먹임 식 하나로 묶은 다음, 극점의 위치와 보드 선도로 설계합니다. 미분방정식은 그 뒤에 숨어 있습니다.

단위 계단 함수와 스위치

스위치를 켜는 순간

RC 회로가 \(t = 1\) s에 전원에 연결되고, \(t = 9\) s에 다시 끊긴다고 합시다. 입력 전압은 "0 → \(V\) → 0"으로 두 번 뛰는 함수입니다. 3장의 적분 인자로 풀려면 세 구간을 따로 풀고 경계에서 축전기 전압이 이어지도록 상수를 맞춰야 합니다. 스위치가 열 번 켜졌다 꺼지면 스무 구간입니다. 끊어지는 입력을 식 하나로 쓰는 방법이 필요합니다.

정의 10.1 (단위 계단 함수) \(a \ge 0\)에 대해
$$u(t - a) = \begin{cases} 0 & t \lt a \\ 1 & t \ge a \end{cases}$$
를 \(t = a\)에서 켜지는 단위 계단 함수(unit step function, Heaviside function)라 한다. \(u_a(t)\)나 \(H(t - a)\)로도 쓴다. 정의 9.2의 뜻에서 구간별 연속이고 지수 차수 0이다.

계단 함수는 스위치입니다. 어떤 함수에 \(u(t-a)\)를 곱하면 \(t = a\)부터 켜지고, \(1 - u(t-a)\)를 곱하면 \(t = a\)에서 꺼집니다. 두 계단의 차 \(u(t-a) - u(t-b)\)는 \([a, b)\)에서만 1인 창 함수입니다. 변환은 정의에서 바로 나옵니다.

$$\mathcal{L}\{u(t-a)\} = \int_a^\infty e^{-st}\,dt = \frac{e^{-as}}{s},\qquad \mathcal{L}\{u(t-a) - u(t-b)\} = \frac{e^{-as} - e^{-bs}}{s}\quad (s > 0).$$

스위치 문제를 다시 봅시다. RC 회로의 축전기 전압 \(v\)는 \(\tau v' + v = V_{\text{in}}(t)\)(\(\tau = RC\))를 따르고, \(V_{\text{in}} = V\bigl[u(t-1) - u(t-9)\bigr]\)입니다. 변환하면(\(v(0) = 0\))

$$(\tau s + 1)V(s) = V\frac{e^{-s} - e^{-9s}}{s}\quad\Rightarrow\quad V(s) = V\Big(e^{-s} - e^{-9s}\Big)\frac{1}{s(\tau s + 1)}.$$
\(\frac{1}{s(\tau s+1)} = \frac1s - \frac{1}{s + 1/\tau}\)의 역변환은 \(q(t) = 1 - e^{-t/\tau}\)(계단 응답). \(e^{-as}\)는 그것을 \(a\)만큼 늦춘다(정리 9.9).

그래서 \(v(t) = V\bigl[q(t-1)u(t-1) - q(t-9)u(t-9)\bigr]\)입니다. 경계에서 상수를 맞추는 일이 사라졌습니다. 스위치를 몇 번 켜고 끄든 \(v(t)\)는 늦춰진 계단 응답들의 합이고, 이것이 선형성(중첩)과 t-이동의 힘입니다. 아래 시뮬레이터에서 직접 스위치를 눌러 보세요. 누를 때마다 식에 항이 하나씩 붙습니다.

구간별 입력과 t-이동

9장의 정리 9.9는 "늦춰서 켠 신호" \(u(t-a)f(t-a)\)의 변환이었습니다. 실제 입력은 보통 \(u(t-a)g(t)\)처럼 늦추지 않은 함수를 \(t = a\)에서 켜는 꼴로 주어집니다. 이때는 \(g(t) = g((t - a) + a)\)로 다시 쓰면 됩니다.

정리 10.2 (t-이동의 두 꼴) \(a \ge 0\)일 때
$$\mathcal{L}\{u(t-a)f(t-a)\} = e^{-as}F(s),\qquad \mathcal{L}\{u(t-a)g(t)\} = e^{-as}\,\mathcal{L}\{g(t + a)\}.$$
역으로 \(\mathcal{L}^{-1}\{e^{-as}F(s)\} = u(t-a)f(t-a)\).

증명. 첫 식은 정리 9.9. 둘째 식은 \(f(t) = g(t+a)\)로 두면 \(f(t - a) = g(t)\)이므로 첫 식이 된다. ∎

구간별 함수를 계단으로 쓰는 요령은 "왼쪽에서부터 바뀌는 만큼 켜기"입니다. \(f(t) = f_1\)(\(t \lt a\)), \(f_2\)(\(a \le t \lt b\)), \(f_3\)(\(t \ge b\))이면

$$f(t) = f_1 + (f_2 - f_1)\,u(t-a) + (f_3 - f_2)\,u(t-b).$$
예제 10.1 (구간별 함수의 변환) \(f(t) = 2\)(\(0 \le t \lt 1\)), \(t\)(\(1 \le t \lt 3\)), \(0\)(\(t \ge 3\))의 변환을 구하라.
  1. 계단으로: \(f = 2 + (t - 2)u(t-1) + (0 - t)u(t-3)\).
  2. 정리 10.2의 둘째 꼴: \(\mathcal{L}\{(t-2)u(t-1)\} = e^{-s}\mathcal{L}\{(t+1) - 2\} = e^{-s}\Big(\frac{1}{s^2} - \frac1s\Big)\).
  3. \(\mathcal{L}\{t\,u(t-3)\} = e^{-3s}\mathcal{L}\{t + 3\} = e^{-3s}\Big(\frac{1}{s^2} + \frac3s\Big)\).
  4. \(F(s) = \dfrac2s + e^{-s}\Big(\dfrac{1}{s^2} - \dfrac1s\Big) - e^{-3s}\Big(\dfrac{1}{s^2} + \dfrac3s\Big)\). 검산: \(s = 1.5\)에서 수치 적분과 공식 모두 \(1.2566\). ✓
예제 10.2 (잠깐 미는 힘) 질량 1, 용수철 상수 1인 진동자를 \(t \in [0, \pi)\) 동안만 힘 1로 민다. \(y'' + y = 1 - u(t - \pi)\), \(y(0) = y'(0) = 0\).
  1. \((s^2 + 1)Y = \dfrac{1 - e^{-\pi s}}{s}\), \(Y = \bigl(1 - e^{-\pi s}\bigr)\dfrac{1}{s(s^2+1)}\).
  2. \(\dfrac{1}{s(s^2+1)} = \dfrac1s - \dfrac{s}{s^2+1}\)이므로 \(\mathcal{L}^{-1} = 1 - \cos t\).
  3. \(y(t) = (1 - \cos t) - \bigl(1 - \cos(t - \pi)\bigr)u(t - \pi) = (1 - \cos t) - (1 + \cos t)u(t-\pi)\).
  4. \(t \ge \pi\)에서 \(y = -2\cos t\): 힘을 뗀 뒤 진폭 2로 자유 진동한다. 반 주기 동안 같은 방향으로 밀어 에너지를 최대로 넣은 결과다. \(y\)와 \(y'\)은 \(t = \pi\)에서 연속이고(\(y(\pi) = 2\), \(y'(\pi) = 0\)), \(y''\)만 점프한다. RK4 수치해와 일치. ✓

디랙 델타: 망치로 치기

아주 짧고 아주 센 힘

망치로 용수철에 달린 질량을 칩니다. 접촉 시간은 수 밀리초, 힘은 수백 뉴턴입니다. 힘의 정확한 모양은 모르고 알 필요도 없습니다. 운동량을 바꾸는 것은 힘을 시간에 대해 쌓은 충격량(impulse) \(I = \int F\,dt\)뿐이기 때문입니다. "넓이는 \(I\)이고 폭은 0인 힘"을 식으로 어떻게 쓸까요?

폭 \(\varepsilon\), 높이 \(1/\varepsilon\)인 직사각형 펄스 \(d_\varepsilon(t - a) = \frac1\varepsilon\bigl[u(t-a) - u(t-a-\varepsilon)\bigr]\)는 넓이가 늘 1입니다. \(\varepsilon \to 0\)이면 높이는 무한대로 가고 폭은 0으로 가지만 넓이는 1로 남습니다. 이 극한을 디랙 델타(Dirac delta) \(\delta(t - a)\)라 부릅니다.

정의 10.3 (디랙 델타) \(\delta(t - a)\)는 연속 함수 \(\varphi\)와 함께 적분할 때
$$\int_0^\infty \varphi(t)\,\delta(t - a)\,dt = \lim_{\varepsilon\to 0^+}\int_0^\infty \varphi(t)\,d_\varepsilon(t - a)\,dt = \varphi(a)\qquad (a \gt 0)$$
가 되는 대상으로 정의한다. 이것을 거르기 성질(sifting property)이라 한다. \(\delta\)는 어떤 보통 함수로도 쓸 수 없고, 적분 안에서의 작용으로만 뜻을 가진다.

극한이 \(\varphi(a)\)인 까닭은 적분의 평균값 정리입니다. \(\int \varphi\,d_\varepsilon = \frac1\varepsilon\int_a^{a+\varepsilon}\varphi\,dt = \varphi(c_\varepsilon)\)이고 \(c_\varepsilon \in [a, a+\varepsilon]\)이 \(a\)로 가기 때문입니다. 델타는 디랙(Paul Dirac)이 양자역학에서 널리 쓰이게 했고, 엄밀한 이론은 훗날 슈바르츠(Laurent Schwartz)의 분포(distribution) 이론으로 세워졌습니다. 공학에서는 위 거르기 성질 하나만 쓰면 충분합니다.

정리 10.4 (델타의 변환) \(a \ge 0\)이면 \(\mathcal{L}\{\delta(t - a)\} = e^{-as}\), 특히 \(\mathcal{L}\{\delta(t)\} = 1\).

증명. 거르기 성질에 \(\varphi = e^{-st}\)를 넣는다. (\(a = 0\)은 펄스 \(d_\varepsilon(t)\)의 변환 \(\frac{1 - e^{-\varepsilon s}}{\varepsilon s} \to 1\)로 정의한다.) ∎

\(\mathcal{L}\{\delta\} = 1\)은 \(s \to \infty\)에서 0으로 가지 않으므로, 정리 9.3에 비추어 보면 델타가 보통 함수가 아님을 다시 확인할 수 있습니다. 또 \(u(t-a)\)의 "도함수"가 \(\delta(t-a)\)라는 것도 변환에서 보입니다: \(s\cdot\frac{e^{-as}}{s} - u(0^-)\cdot 0 = e^{-as}\).

예제 10.3 (망치로 친 감쇠 진동자) \(x'' + 2x' + 5x = \delta(t)\), \(x(0) = x'(0) = 0\).
  1. \((s^2 + 2s + 5)X = 1\), \(X = \dfrac{1}{(s+1)^2 + 4}\).
  2. \(x(t) = \tfrac12 e^{-t}\sin 2t\).
  3. 해석: \(x(0^+) = 0\)이지만 \(x'(0^+) = 1\)이다. 단위 충격량이 질량 1에 속도 1을 순간적으로 준 것이다. 즉 \(x'' + 2x' + 5x = \delta(t)\)(정지 상태에서 출발)는 동차 방정식에 \(x(0) = 0\), \(x'(0) = 1\)을 준 것과 같다.
예제 10.4 (진동을 한 번에 멈추는 망치) \(x'' + x = \delta(t - \pi/2)\), \(x(0) = 1\), \(x'(0) = 0\).
  1. \(s^2X - s + X = e^{-\pi s/2}\), \(X = \dfrac{s}{s^2+1} + e^{-\pi s/2}\dfrac{1}{s^2+1}\).
  2. \(x(t) = \cos t + \sin(t - \tfrac\pi2)\,u(t - \tfrac\pi2) = \cos t - \cos t\cdot u(t - \tfrac\pi2)\).
  3. \(t \ge \pi/2\)에서 \(x \equiv 0\). 질량이 평형점을 속도 \(-1\)로 지나는 순간 크기 1의 충격량으로 쳐서 속도를 정확히 0으로 만들었다. 같은 망치로 \(t = \pi\)(가장 멀리 간 순간)에 치면 진폭은 \(\sqrt2\)가 된다.

충격 응답

예제 10.3에서 \(\delta(t)\)에 대한 응답은 \(X(s) = \frac{1}{s^2 + 2s + 5}\), 즉 특성 다항식의 역수의 역변환이었습니다. 이 함수는 시스템 자체의 성질입니다. 입력이 무엇이든 시스템이 "한 번 맞았을 때 어떻게 우는가"를 기록한 지문과 같습니다.

정의 10.5 (충격 응답) 상수계수 선형 방정식 \(ay'' + by' + cy = g(t)\)에서 초기 조건이 모두 0이고 \(g = \delta(t)\)일 때의 해를 충격 응답(impulse response) \(h(t)\)라 한다. 변환하면
$$h(t) = \mathcal{L}^{-1}\Big\{\frac{1}{as^2 + bs + c}\Big\},$$
이것은 동차 방정식 \(ah'' + bh' + ch = 0\)에 \(h(0) = 0\), \(h'(0) = 1/a\)를 준 해와 같다.

질량–용수철에서 \(a = m\)이므로 충격량 1은 속도 \(1/m\)를 줍니다. 무거운 물체일수록 같은 망치에 덜 움직입니다. 충격 응답의 모양은 특성근, 즉 \(1/(as^2+bs+c)\)의 극점이 정합니다(그림 9-2). 이 사실을 5절 이후에 전달 함수의 언어로 다시 씁니다.

합성곱과 합성곱 정리: 과거 입력의 메아리

임의의 입력에 대한 응답을 충격 응답으로

충격 응답 \(h(t)\)를 실험으로 한 번 쟀다고 합시다(망치로 한 번 치고 기록). 이제 임의의 입력 \(g(t)\)를 넣었을 때의 출력을 다시 실험하지 않고 알 수 있을까요? 입력을 아주 짧은 펄스들의 열로 잘게 쪼개 보면 답이 보입니다.

시각 \(\tau\) 근처의 폭 \(\Delta\tau\)짜리 조각은 넓이 \(g(\tau)\Delta\tau\)인 충격입니다. 선형·시불변 시스템은 이 충격에 \(g(\tau)\Delta\tau\cdot h(t - \tau)\)로 반응합니다(크기만큼 곱하고 \(\tau\)만큼 늦춤). 모든 조각의 반응을 더하면

$$y(t) \approx \sum_{\tau_k \lt t} g(\tau_k)\,h(t - \tau_k)\,\Delta\tau \;\longrightarrow\; \int_0^t g(\tau)\,h(t - \tau)\,d\tau.$$
지금의 출력은 과거의 모든 입력이 남긴 메아리의 합이다. \(h(t - \tau)\)는 \(\tau\)초 전의 입력이 지금까지 얼마나 남아 있는지를 말하는 "기억의 무게"다.
정의 10.6 (합성곱) \(t \ge 0\)에서 구간별 연속인 \(f\), \(g\)의 합성곱(convolution)은
$$(f * g)(t) = \int_0^t f(\tau)\,g(t - \tau)\,d\tau.$$
\(\tau\)를 \(t - \tau\)로 치환하면 \(f * g = g * f\)(교환 법칙)이고, 결합·분배 법칙도 성립한다. 그러나 \(1 * f \ne f\)이다(예: \(1 * 1 = t\)).
정리 10.7 (합성곱 정리) \(f\), \(g\)가 구간별 연속이고 지수 차수이면
$$\mathcal{L}\{f * g\} = F(s)\,G(s).$$

증명. \(F(s)G(s) = \int_0^\infty e^{-s\tau}f(\tau)\,d\tau\int_0^\infty e^{-s\sigma}g(\sigma)\,d\sigma\). 안쪽에서 \(\sigma = t - \tau\)(\(\tau\) 고정)로 치환하면 \(\int_\tau^\infty e^{-st}g(t-\tau)\,dt\)이므로 \(FG = \int_0^\infty\!\int_\tau^\infty e^{-st}f(\tau)g(t-\tau)\,dt\,d\tau\). 적분 영역 \(0 \le \tau \le t \lt \infty\)에서 적분 순서를 바꾸면(절대 수렴으로 정당화) \(\int_0^\infty e^{-st}\Big[\int_0^t f(\tau)g(t-\tau)\,d\tau\Big]dt = \mathcal{L}\{f*g\}\). ∎

시간 쪽의 복잡한 적분이 \(s\) 쪽에서는 그냥 곱셈입니다. 이 정리 덕분에 "곱의 역변환"을 부분 분수 없이 쓸 수도 있습니다.

예제 10.5 (합성곱으로 역변환)
  1. \(\mathcal{L}^{-1}\Big\{\dfrac{1}{(s+1)(s+2)}\Big\} = e^{-t} * e^{-2t} = \displaystyle\int_0^t e^{-\tau}e^{-2(t-\tau)}\,d\tau = e^{-2t}\big(e^{t} - 1\big) = e^{-t} - e^{-2t}\). 부분 분수의 답과 같다. 수치 확인(\(t = 1.7\)): 두 값 모두 \(0.14931\). ✓
  2. \(\mathcal{L}^{-1}\Big\{\dfrac{1}{s(s^2+1)}\Big\} = 1 * \sin t = \displaystyle\int_0^t \sin\tau\,d\tau = 1 - \cos t\). 정리 9.6(\(F/s\)는 적분)과 같은 이야기다.
정리 10.8 (영상태 응답, 뒤아멜 원리) \(ay'' + by' + cy = g(t)\)의 해는
$$y(t) = \underbrace{y_{\text{zi}}(t)}_{\text{영입력 응답}} + \underbrace{(h * g)(t)}_{\text{영상태 응답}} = y_{\text{zi}}(t) + \int_0^t h(t-\tau)\,g(\tau)\,d\tau.$$
여기서 \(y_{\text{zi}}\)는 입력 없이 초기 조건만으로 생기는 응답, \(h * g\)는 초기 조건 0에서 입력만으로 생기는 응답이다.

증명. 변환하면 \(Y = \frac{(as + b)y(0) + ay'(0)}{as^2+bs+c} + \frac{1}{as^2+bs+c}G(s)\). 첫 항의 역변환이 \(y_{\text{zi}}\), 둘째 항은 \(H(s)G(s)\)이므로 정리 10.7로 \(h * g\). ∎

예를 들어 \(y'' + y = g(t)\)(정지 상태 출발)의 해는 어떤 \(g\)에 대해서도 \(y(t) = \int_0^t \sin(t - \tau)\,g(\tau)\,d\tau\)입니다. 8장의 매개변수 변환법이 같은 공식을 다른 길로 얻었던 것입니다.

전달 함수 H(s): 극점과 영점

정리 10.8의 영상태 응답을 \(s\) 쪽에서 쓰면 \(Y(s) = H(s)G(s)\)입니다. 시스템은 입력의 변환에 \(H(s)\)를 곱하는 장치가 됩니다.

정의 10.9 (전달 함수) 초기 조건이 모두 0인 선형 시불변 시스템에서 출력과 입력의 변환의 비
$$H(s) = \frac{Y(s)}{G(s)} = \mathcal{L}\{h(t)\}$$
를 전달 함수(transfer function)라 한다. \(a_ny^{(n)} + \cdots + a_0y = b_mg^{(m)} + \cdots + b_0g\)이면 \(H(s) = \dfrac{b_ms^m + \cdots + b_0}{a_ns^n + \cdots + a_0}\). 분자의 근을 영점(zero), 분모의 근을 극점이라 한다.

예제 10.6 (전달 함수와 극점·영점) \(y'' + 3y' + 2y = g' + 3g\)의 전달 함수, 극점, 영점, 충격 응답을 구하라.
  1. 초기 조건 0으로 변환: \((s^2 + 3s + 2)Y = (s + 3)G\)이므로 \(H(s) = \dfrac{s+3}{(s+1)(s+2)}\).
  2. 극점 \(-1, -2\), 영점 \(-3\).
  3. 가리기: \(H = \frac{2}{s+1} - \frac{1}{s+2}\), \(h(t) = 2e^{-t} - e^{-2t}\). 영점은 극점이 만드는 두 항의 비율을 정한다. 극점은 "어떤 모양의 항이 나오는가", 영점은 "그 항들이 얼마씩 섞이는가"를 맡는다.

s-평면의 극점 위치와 응답 모양, 안정성

방정식을 풀지 않고 거동을 알기

설계자가 받은 것은 전달 함수 \(H(s) = \frac{10}{s^2 + 2s + 10}\) 하나입니다. 충격을 주면 진동할까, 얼마나 빨리 가라앉을까, 혹시 발산하지는 않을까? 부분 분수를 끝까지 하지 않아도 극점 위치만으로 답할 수 있습니다.

\(H\)가 진분수 유리 함수이면 부분 분수로 \(h(t)\)는 극점 \(p_k\)마다 \(t^je^{p_kt}\) 꼴의 항들의 합입니다. 극점 \(p = \sigma + i\omega\)가 만드는 항의 크기는 \(|e^{pt}| = e^{\sigma t}\)이므로

  • \(\sigma \lt 0\)(왼쪽 반평면): 항이 \(e^{\sigma t}\)로 사라진다. \(1/|\sigma|\)이 그 항의 시상수다.
  • \(\sigma > 0\)(오른쪽 반평면): 항이 지수적으로 커진다.
  • \(\sigma = 0\)(허수축): 단순 극점이면 상수나 지속 진동, 겹친 극점이면 \(t\cos\omega t\)처럼 커진다(9장의 공진).
  • \(\omega \ne 0\)이면 진동하고, \(|\omega|\)가 각진동수다. 원점에서의 거리 \(|p|\)는 고유 진동수 \(\omega_n\), 음의 실수축과 이루는 각 \(\theta\)는 감쇠비 \(\zeta = \cos\theta\)를 준다.
정리 10.10 (BIBO 안정성) 유계인 모든 입력에 대해 출력이 유계일 때 시스템이 BIBO 안정(bounded-input bounded-output stable)이라 한다. 전달 함수가 진분수 유리 함수(약분 후)일 때, 시스템이 BIBO 안정일 필요충분조건은 모든 극점이 열린 왼쪽 반평면 \(\operatorname{Re}s \lt 0\)에 있는 것이다. 이는 \(\int_0^\infty |h(t)|\,dt \lt \infty\)와 같다.

아이디어. \(|g| \le M\)이면 \(|y(t)| = \big|\int_0^t h(\tau)g(t-\tau)\,d\tau\big| \le M\int_0^\infty|h|\). 극점이 모두 왼쪽이면 \(h\)는 지수적으로 감쇠해 이 적분이 유한하다. 거꾸로 허수축 위의 극점 \(i\omega\)가 있으면 유계 입력 \(\sin\omega t\)가 공진으로 무한히 커지는 출력을 만들고, 오른쪽 극점이 있으면 \(h\) 자체가 발산한다. ∎

주파수 응답 H(iω)와 보드 선도

사인 입력에 대한 정상 상태

스피커, 서스펜션, 건물의 진동 차단 장치를 평가할 때는 "주파수마다 입력을 몇 배로 키우고 얼마나 늦추는가"를 봅니다. 8장에서 강제 진동의 진폭과 위상을 미정계수로 구했습니다. 전달 함수가 있으면 \(s\) 자리에 \(i\omega\)를 넣는 것으로 끝납니다.

정리 10.11 (주파수 응답) \(H\)가 BIBO 안정이면 입력 \(g = \sin\omega t\)에 대한 출력은 과도 항이 사라진 뒤
$$y_{\text{ss}}(t) = |H(i\omega)|\,\sin\bigl(\omega t + \arg H(i\omega)\bigr)$$
가 된다. \(H(i\omega)\)를 주파수 응답(frequency response), \(|H(i\omega)|\)를 이득, \(\arg H(i\omega)\)를 위상이라 한다.

증명. \(\sin\omega t = \operatorname{Im}e^{i\omega t}\)이고 \(\mathcal{L}\{e^{i\omega t}\} = \frac{1}{s - i\omega}\). \(Y = \frac{H(s)}{s - i\omega}\)의 부분 분수에서 극점 \(i\omega\)의 가리기 계수가 \(H(i\omega)\)이므로 \(y = H(i\omega)e^{i\omega t} + (\text{H의 극점에서 오는 감쇠 항})\). 허수부를 취하면 된다(계수가 실수인 \(H\)에서). ∎

이득은 보통 데시벨 \(20\log_{10}|H(i\omega)|\)로, 진동수는 로그 눈금으로 그립니다. 이 두 그래프(이득·위상)를 보드 선도(Bode plot)라 합니다. 로그를 쓰면 곱이 합이 되어, 직렬 시스템의 보드 선도는 각 블록의 선도를 그냥 더한 것입니다.

  • 1차 \(H = \frac{1}{\tau s + 1}\): \(\omega \ll 1/\tau\)에서 0 dB, \(\omega \gg 1/\tau\)에서 기울기 \(-20\) dB/decade. 두 점근선이 만나는 꺾임 진동수(corner frequency) \(\omega_c = 1/\tau\)에서 실제 이득은 \(-3.01\) dB, 위상은 \(-45°\).
  • 2차 표준형: \(\omega \ll \omega_n\)에서 0 dB, \(\omega \gg \omega_n\)에서 \(-40\) dB/decade, \(\omega = \omega_n\)에서 위상 \(-90°\). \(\zeta \lt 1/\sqrt2\)이면 공진 봉우리가 \(\omega_r = \omega_n\sqrt{1 - 2\zeta^2}\)에 생기고 높이는 \(\frac{1}{2\zeta\sqrt{1-\zeta^2}}\)이다.
예제 10.7 (보드 선도 읽기)
  1. \(H = \frac{1}{s+1}\): \(\omega = 1\)에서 \(|H| = 1/\sqrt2\), \(-3.01\) dB, 위상 \(-45°\). \(\omega = 10\)에서 \(|H| = 1/\sqrt{101}\), \(-20.04\) dB, 위상 \(-84.3°\). 점근선 \(-20\log_{10}10 = -20\) dB와 0.04 dB 차이다.
  2. \(\zeta = 0.2\), \(\omega_n = 1\): \(\omega_r = \sqrt{0.92} \approx 0.959\), 봉우리 높이 \(\frac{1}{0.4\sqrt{0.96}} \approx 2.55\), 즉 \(+8.14\) dB. 8장의 공진 곡선과 Q 인자가 바로 이 봉우리다.

1차·2차 시스템의 계단 응답

설계 사양은 시간 영역에서 주어진다

"목표 속도를 바꾸면 10% 넘게 넘치지 말고, 4초 안에 2% 이내로 가라앉을 것." 제어 사양은 보통 이렇게 계단 응답의 모양으로 주어집니다. 이 숫자들을 극점 위치로 옮길 수 있다면, 사양은 s-평면의 허용 영역이 됩니다.

1차 시스템 \(H = \frac{1}{\tau s + 1}\)의 계단 응답은 \(\mathcal{L}^{-1}\{\frac{1}{s(\tau s+1)}\} = 1 - e^{-t/\tau}\)입니다. \(t = \tau\)에서 최종값의 \(1 - e^{-1} \approx 63.2\%\), 2% 이내로 들어오는 시각은 \(\tau\ln 50 \approx 3.91\tau\)(흔히 \(4\tau\)), 10%에서 90%까지의 상승 시간은 \(\tau\ln 9 \approx 2.20\tau\)입니다. 오버슈트는 없습니다.

2차 시스템 \(H = \frac{\omega_n^2}{s^2 + 2\zeta\omega_ns + \omega_n^2}\)에서 \(0 \lt \zeta \lt 1\)(부족 감쇠)이면 계단 응답은

$$y(t) = 1 - \frac{e^{-\zeta\omega_nt}}{\sqrt{1-\zeta^2}}\sin\bigl(\omega_dt + \varphi\bigr),\qquad \omega_d = \omega_n\sqrt{1-\zeta^2},\quad \cos\varphi = \zeta.$$
정리 10.12 (2차 계단 응답의 지표) \(0 \lt \zeta \lt 1\)일 때
$$t_p = \frac{\pi}{\omega_d},\qquad M_p = e^{-\pi\zeta/\sqrt{1-\zeta^2}},\qquad t_s \approx \frac{4}{\zeta\omega_n}\ (2\%\ \text{기준}).$$
첨두 시간 \(t_p\)는 첫 최댓값의 시각, 오버슈트(overshoot) \(M_p\)는 그때 최종값을 넘는 비율, 정착 시간(settling time) \(t_s\)는 응답이 최종값의 ±2% 안에 머물기 시작하는 시각이다.

증명. \(y'(t) = \frac{\omega_n}{\sqrt{1-\zeta^2}}e^{-\zeta\omega_nt}\sin\omega_dt\)(충격 응답 \(h\)와 같다)이 처음 0이 되는 \(t > 0\)은 \(\omega_dt = \pi\). 그때 \(\sin(\pi + \varphi) = -\sin\varphi = -\sqrt{1-\zeta^2}\)이므로 \(y(t_p) = 1 + e^{-\zeta\omega_n\pi/\omega_d}\). 정착 시간은 포락선 \(e^{-\zeta\omega_nt}/\sqrt{1-\zeta^2}\)이 0.02가 되는 시각을 근사한 것이다(\(\ln 50 \approx 3.9\)). ∎

오버슈트는 \(\zeta\)만의 함수이므로 그림 10-5의 각도가 정하고, 정착 시간은 실수부 \(\zeta\omega_n\)이 정합니다. 위 사양 "10% 이하, 4초 이내"는 \(\zeta \ge 0.59\)(\(\theta \le 53.8°\))이고 \(\zeta\omega_n \ge 1\)인 영역, 즉 쐐기와 세로선으로 둘러싼 s-평면의 왼쪽 부분이 됩니다.

예제 10.8 (지표 계산) \(\zeta = 0.5\), \(\omega_n = 1\)이면 \(\omega_d = \sqrt{0.75} = 0.866\), \(t_p = \pi/0.866 = 3.63\), \(M_p = e^{-\pi\cdot0.5/0.866} = e^{-1.814} = 0.163\)(16.3%), \(t_s \approx 4/0.5 = 8\). RK4로 재면 첨두 시간 3.63, 오버슈트 16.3%, 2% 정착 시각 8.08이다. 공식 \(t_s\)는 포락선을 쓴 근사라 실제와 조금 다르다.

PID 맛보기: 되먹임으로 극점 옮기기

느리고 덜 가는 모터

플랜트 \(G(s) = \frac{1}{(s+1)^2}\)(예: 관성과 마찰이 있는 모터의 속도)에 계단 입력을 그냥 넣으면 시상수 1인 극점 두 개 때문에 느리게 올라갑니다. 출력을 재서 오차 \(e = r - y\)에 비례하는 입력을 넣으면 빨라질까요? 남는 오차는 어떻게 없앨까요?

PID 제어기(proportional–integral–derivative controller)는 오차의 현재 값(P), 누적(I), 변화율(D)을 섞어 입력을 만듭니다.

$$u(t) = K_p\,e(t) + K_i\int_0^t e(\tau)\,d\tau + K_d\,e'(t),\qquad C(s) = K_p + \frac{K_i}{s} + K_ds.$$

그림 10-4의 되먹임 식으로 닫힌 루프는 \(T(s) = \frac{CG}{1 + CG}\)이고, 극점은 \(1 + C(s)G(s) = 0\)의 근입니다. 여기서는

$$s(s+1)^2 + K_ds^2 + K_ps + K_i = s^3 + (2 + K_d)s^2 + (1 + K_p)s + K_i = 0.$$
이득을 바꾸면 닫힌 루프 극점이 움직인다. 제어 설계란 결국 극점을 원하는 자리로 옮기는 일이다.
  • P만(\(K_i = K_d = 0\)): 최종값 정리로 \(y(\infty) = \lim_{s\to0}T(s) = \frac{K_p}{1 + K_p}\). 정상 상태 오차 \(\frac{1}{1+K_p}\)가 남는다. \(K_p\)를 키우면 오차는 줄지만 극점이 \(-1 \pm i\sqrt{K_p}\)로 위아래로 벌어져 오버슈트가 커진다.
  • I 추가: \(T(0) = 1\)이 되어 정상 상태 오차가 0이 된다(\(C\)의 \(1/s\)가 오차를 끝없이 쌓아 0이 될 때까지 입력을 민다). 대신 극점이 하나 늘어 너무 크면 불안정해진다.
  • D 추가: 분모의 \(s^2\) 계수 \(2 + K_d\)를 키워 감쇠를 더한다. 오버슈트를 누르는 브레이크다.
예제 10.9 (P 제어의 한계) \(K_p = 9\)이면 닫힌 루프 \(T = \frac{9}{s^2 + 2s + 10}\), 극점 \(-1 \pm 3i\), \(\omega_n = \sqrt{10}\), \(\zeta = 1/\sqrt{10} \approx 0.316\). 최종값 \(9/10 = 0.9\)(오차 10%), 오버슈트 \(e^{-\pi\zeta/\sqrt{1-\zeta^2}} \approx 35.1\%\)(최종값 기준). RK4로 잰 최댓값 1.216 = 0.9 × 1.351로 맞는다. 오차를 1%로 줄이려고 \(K_p = 99\)로 올리면 \(\zeta \approx 0.1\)이 되어 심하게 출렁인다. P만으로는 둘 다 잡을 수 없고, 그래서 I와 D가 필요하다.

PID는 단순하지만 산업 현장의 제어 루프 대부분이 이 꼴이라고 알려져 있습니다. 아래에서 세 손잡이를 돌려 보세요. 닫힌 루프 극점이 함께 움직이는 것이 보입니다.

핵심 정리

  1. 단위 계단 \(u(t-a)\)는 스위치다. 구간별 입력은 \(f_1 + (f_2 - f_1)u(t-a) + \cdots\)로 쓰고, \(\mathcal{L}\{u(t-a)f(t-a)\} = e^{-as}F(s)\), \(\mathcal{L}\{u(t-a)g(t)\} = e^{-as}\mathcal{L}\{g(t+a)\}\)로 변환한다. 응답은 늦춰진 계단 응답들의 합이다.
  2. 디랙 델타는 넓이 1인 펄스의 극한이고 \(\int\varphi(t)\delta(t-a)dt = \varphi(a)\), \(\mathcal{L}\{\delta(t-a)\} = e^{-as}\). 충격량 \(I\)는 질량 \(m\)에 속도 \(I/m\)를 순간적으로 준다.
  3. 충격 응답 \(h = \mathcal{L}^{-1}\{H\}\)는 시스템의 지문이다. 영상태 응답은 합성곱 \(y = h * g = \int_0^t h(t-\tau)g(\tau)d\tau\)이고, 합성곱 정리 \(\mathcal{L}\{f*g\} = FG\).
  4. 전달 함수 \(H(s) = Y/G\)(초기 조건 0). 직렬은 곱, 단위 되먹임은 \(CG/(1+CG)\). 극점은 응답에 나오는 항의 모양을, 영점은 그 섞임을 정한다.
  5. BIBO 안정 ⇔ 모든 극점이 \(\operatorname{Re}s \lt 0\). 극점의 실수부는 감쇠 속도, 허수부는 진동수, 각도는 감쇠비 \(\zeta = \cos\theta\), 거리는 \(\omega_n\).
  6. 안정한 시스템의 사인 정상 응답은 \(|H(i\omega)|\sin(\omega t + \arg H(i\omega))\). 보드 선도에서 1차는 \(-20\) dB/decade와 꺾임점 \(-3\) dB, 2차는 \(-40\) dB/decade와 \(\zeta \lt 0.707\)일 때의 공진 봉우리.
  7. 2차 계단 응답: \(t_p = \pi/\omega_d\), \(M_p = e^{-\pi\zeta/\sqrt{1-\zeta^2}}\), \(t_s \approx 4/(\zeta\omega_n)\). PID는 되먹임으로 닫힌 루프 극점을 옮긴다: P는 빠르게, I는 정상 오차 0, D는 감쇠.

확인 퀴즈

Q1. \(f(t) = 3\)(\(0 \le t \lt 2\)), \(0\)(\(t \ge 2\))의 라플라스 변환은?

\(f = 3 - 3u(t-2)\)이고 \(\mathcal{L}\{u(t-2)\} = e^{-2s}/s\). 검산: \(\int_0^2 3e^{-st}dt = 3(1 - e^{-2s})/s\).

Q2. \(\mathcal{L}^{-1}\Big\{\dfrac{e^{-3s}}{s^2}\Big\}\)은?

\(1/s^2 \leftrightarrow t\)이고 \(e^{-3s}\)는 3만큼 늦춰 켠다: \(u(t-3)f(t-3) = (t-3)u(t-3)\). \(t = 3\)에서 0부터 기울기 1로 오르는 경사다.

Q3. \(\displaystyle\int_0^\infty \cos(t)\,\delta(t - \pi)\,dt\)의 값은?

거르기 성질: 연속 함수에 델타를 곱해 적분하면 그 점의 값이 나온다. \(\cos\pi = -1\).

Q4. 정지해 있던 질량 2 kg인 용수철–질량계(\(2x'' + 8x = 6\delta(t)\))를 쳤을 때 \(x(t)\)는?

\((2s^2 + 8)X = 6\), \(X = \frac{3}{s^2 + 4} = \frac32\cdot\frac{2}{s^2+4}\). 충격량 6이 질량 2에 속도 3을 주고, \(\omega = 2\)이므로 진폭 \(3/2\).

Q5. \((1 * t)(t)\), 즉 \(\int_0^t 1\cdot(t - \tau)\,d\tau\)는?

직접 적분하면 \(t^2 - t^2/2 = t^2/2\). 합성곱 정리로도 \(\frac1s\cdot\frac{1}{s^2} = \frac{1}{s^3} \leftrightarrow t^2/2\). \(1 * f \ne f\)인 예다.

Q6. 전달 함수 \(H(s) = \dfrac{s - 1}{s^2 + s - 2}\)인 시스템에 대해 옳은 것은?

\(s^2 + s - 2 = (s-1)(s+2)\)이고 분자 \(s - 1\)과 약분된다. 정리 10.10은 약분 후의 극점으로 판정한다. 다만 내부에 숨은 불안정 모드가 초기 조건에서 커질 수 있어, 실제 설계에서는 불안정 극점–영점 상쇄를 피한다(11장의 상태 공간 관점).

Q7. \(H(s) = \dfrac{1}{s + 10}\)에 \(\sin 10t\)를 넣었을 때 정상 출력의 진폭과 위상은?

\(H(10i) = \frac{1}{10 + 10i}\), \(|H| = \frac{1}{10\sqrt2}\), \(\arg H = -45°\). 꺾임 진동수 \(\omega_c = 10\)에서 직류 이득 \(1/10\)보다 3 dB 낮다.

Q8. 2차 시스템의 계단 응답 오버슈트를 5% 이하로 하려면 대략 어떤 조건이 필요한가?

\(M_p = e^{-\pi\zeta/\sqrt{1-\zeta^2}} = 0.05\)를 풀면 \(\zeta \approx 0.690\). 오버슈트는 \(\zeta\)(극점의 각도)만의 함수이고 \(\omega_n\)과는 무관하다.
