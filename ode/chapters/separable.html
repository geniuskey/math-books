Chapter 02

변수분리형 방정식

1장에서 세운 방정식들, 붕괴 \(N' = -\lambda N\), 냉각 \(T' = -k(T - T_a)\), 낙하 \(mv' = mg - cv^2\), 로지스틱 \(P' = rP(1 - P/K)\)에는 공통점이 있습니다. 우변이 "\(t\)만의 함수 × \(y\)만의 함수"로 갈라집니다. 이런 방정식은 \(y\)가 들어 있는 것은 왼쪽으로, \(t\)가 들어 있는 것은 오른쪽으로 모은 뒤 양쪽을 따로 적분하면 풀립니다. 이 장의 변수분리형 방정식은 미분방정식에서 손으로 풀 수 있는 가장 넓은 부류이고, 반감기, 탄소 연대 측정, 사망 시각 추정, 탱크가 비는 시간처럼 공학과 과학의 고전적인 계산이 모두 여기서 나옵니다. 동시에 나눗셈 한 번에 해를 잃는 함정, 해가 유한 시간에 터지는 현상, 식으로 풀어 쓸 수 없는 음함수 해처럼 미분방정식 특유의 문제도 처음 만납니다.

  • \(y' = f(t)g(y)\)를 분리해 적분하고, \(g(y_0) = 0\)인 상수 해를 빠뜨리지 않는다.
  • 지수 붕괴와 성장을 풀고, 반감기·배가 시간과 붕괴 상수의 관계로 연대 측정을 계산한다.
  • 뉴턴 냉각 법칙을 풀고, 측정값 두 개로 냉각 상수와 과거의 시각을 추정한다.
  • 로지스틱 방정식을 부분 분수로 풀고, 수용력과 변곡점의 뜻을 설명한다.
  • 토리첼리 법칙으로 탱크가 비는 시간을 구하고, 탱크 모양의 영향을 계산한다.
  • 음함수 해와 해의 정의 구간을 구하고, 초기값에 따라 구간이 달라지는 것을 설명한다.
  • 직교 궤적을 구하고, 동차형 방정식을 \(v = y/x\) 치환으로 변수분리형으로 바꾼다.
이 수식이 없었다면방사성 탄소 연대 측정

고고학 유적에서 나온 숯 조각이 몇 년 전의 것인지 어떻게 알 수 있을까요? 대기 중에서는 우주선이 질소를 때려 방사성 탄소-14가 끊임없이 만들어지고, 살아 있는 생물은 호흡과 먹이로 대기와 같은 비율의 탄소-14를 몸에 유지합니다. 생물이 죽으면 공급이 끊기고, 몸에 남은 탄소-14는 "남은 양에 비례하는 빠르기로" 줄어듭니다. 이 한 문장이 미분방정식 \(N' = -\lambda N\)입니다.

변수를 분리해 풀면 \(N(t) = N_0e^{-\lambda t}\)이고, 남은 비율 \(N/N_0\)을 재면 시간이 거꾸로 계산됩니다. 1940년대 후반 미국의 화학자 리비(Willard Libby)가 이 방법을 개발했고, 그 공로로 1960년 노벨 화학상을 받았습니다. 탄소-14의 반감기는 약 5730년이라, 이 방법은 대략 5만 년 전까지의 유기물에 쓰입니다.

남은 C-14 비율 측정→N′ = −λN→변수분리: N = N₀e^(−λt)→t = ln(N₀/N)/λ

분리하고 적분하기, 그리고 상수 해

\(y' = -2ty\)를 손으로 풀기

1장에서 \(y = 3e^{-t^2}\)이 \(y' = -2ty\)의 해임을 대입으로 확인했습니다. 하지만 그 답은 어디서 왔을까요? 확인하는 것과 찾아내는 것은 다릅니다. 우변을 보면 \(t\)가 들어간 부분 \(-2t\)와 \(y\)가 들어간 부분 \(y\)가 곱으로 떨어져 있습니다. 이 구조를 이용할 수 있을까요?

정의 2.1 (변수분리형 방정식) 1계 방정식이
$$\frac{dy}{dt} = f(t)\,g(y)$$
꼴로 쓰이면 변수분리형 방정식(separable equation)이라 한다. 우변이 \(t\)만의 함수와 \(y\)만의 함수의 곱이다.

\(g(y) \ne 0\)인 곳에서 양변을 \(g(y)\)로 나누고, 라이프니츠 기호를 분수처럼 다루어 \(dt\)를 오른쪽으로 보내면

$$\frac{dy}{g(y)} = f(t)\,dt\quad\Longrightarrow\quad \int\frac{dy}{g(y)} = \int f(t)\,dt + C.$$
왼쪽은 \(y\)만, 오른쪽은 \(t\)만의 적분이다. 적분 상수는 한쪽에 하나만 붙이면 된다.

"\(dt\)를 넘긴다"는 조작이 수상해 보이지만, 연쇄 법칙으로 정당화됩니다.

정리 2.2 (변수분리법) \(f\)가 구간 \(I\)에서, \(g\)가 구간 \(J\)에서 연속이고 \(J\)에서 \(g \ne 0\)이라 하자. \(G\)를 \(1/g\)의 역도함수, \(F\)를 \(f\)의 역도함수라 하면, 값이 \(J\)에 있는 미분 가능한 함수 \(y(t)\)가 \(y' = f(t)g(y)\)의 해일 필요충분조건은 어떤 상수 \(C\)에 대해
$$G\bigl(y(t)\bigr) = F(t) + C$$
가 성립하는 것이다.

증명. 연쇄 법칙으로 \(\frac{d}{dt}G(y(t)) = G'(y)\,y' = \frac{y'}{g(y)}\). 따라서 \(y' = f(t)g(y) \iff \frac{y'}{g(y)} = f(t) \iff \frac{d}{dt}\bigl[G(y(t)) - F(t)\bigr] = 0 \iff G(y(t)) - F(t)\)가 상수. 마지막 동치는 평균값 정리의 따름정리(도함수가 0인 함수는 구간에서 상수)다. ∎

\(G(y) = F(t) + C\)를 \(y\)에 대해 풀 수 있으면 명시적 해, 풀 수 없으면 음함수 해로 남깁니다(6절). 이제 문제의 방정식을 풀어 봅시다.

예제 2.1 (\(y' = -2ty\), \(y(0) = 3\))
  1. 분리: \(y \ne 0\)이면 \(\dfrac{dy}{y} = -2t\,dt\).
  2. 적분: \(\ln|y| = -t^2 + C\).
  3. 풀기: \(|y| = e^Ce^{-t^2}\), 즉 \(y = Ae^{-t^2}\) (\(A = \pm e^C \ne 0\)).
  4. 상수 해: 나누기 전에 제외한 \(y \equiv 0\)도 해다(\(0' = 0 = -2t\cdot 0\)). 이것은 \(A = 0\)에 해당하므로 일반해를 \(y = Ae^{-t^2}\), \(A\)는 모든 실수로 쓰면 한꺼번에 담긴다.
  5. 초기 조건: \(y(0) = A = 3\). 해는 \(y = 3e^{-t^2}\). 예를 들어 \(y(1) = 3/e \approx 1.1036\)이고, RK4 적분값도 1.10364다.
예제 2.2 (나눗셈으로 잃는 해: \(y' = y^2 - 1\))
  1. ⓪ \(g(y) = y^2 - 1 = 0\)이면 \(y = \pm 1\). 상수 해 \(y \equiv 1\), \(y \equiv -1\).
  2. ①② \(y \ne \pm1\)에서 \(\dfrac{dy}{y^2 - 1} = dt\). 부분 분수 \(\dfrac{1}{y^2 - 1} = \dfrac12\Bigl(\dfrac{1}{y - 1} - \dfrac{1}{y + 1}\Bigr)\)로 \(\dfrac12\ln\Bigl|\dfrac{y - 1}{y + 1}\Bigr| = t + C\).
  3. ③ \(\dfrac{y - 1}{y + 1} = Be^{2t}\) (\(B \ne 0\)), 풀면 \(y = \dfrac{1 + Be^{2t}}{1 - Be^{2t}}\).
  4. 상수 해 점검: \(B = 0\)이면 \(y = 1\)이 되어 공식에 들어간다. 그러나 \(y \equiv -1\)은 어떤 \(B\)로도 나오지 않는다(\(B \to \infty\)일 때의 극한일 뿐). 따로 적어야 하는 해다.
  5. ④ \(y(0) = 0\)이면 \(B = -1\), \(y = \dfrac{1 - e^{2t}}{1 + e^{2t}} = -\tanh t\). \(y(0) = 3\)이면 \(B = \tfrac12\)이고, 분모 \(1 - \tfrac12e^{2t}\)이 \(t = \tfrac12\ln 2 \approx 0.347\)에서 0이 되어 해가 무한대로 터진다. 이 경우 해의 정의 구간은 \((-\infty, 0.347)\)이다.
상수 해를 잃으면 생기는 일 예제 2.2의 \(y \equiv -1\)은 "평형 상태"입니다. 물리적으로는 가장 중요한 해일 수 있습니다. 예를 들어 화학 반응의 평형 농도, 인구의 수용력, 낙하의 종단 속도가 모두 \(g(y) = 0\)에서 나오는 상수 해입니다. 이 상수 해들과 그 안정성을 체계적으로 다루는 것이 4장의 위상선입니다.

지수 성장과 붕괴, 반감기, 탄소 연대 측정

가장 단순한 변수분리형 방정식은 \(y' = ky\)입니다. 분리하면 \(dy/y = k\,dt\), 적분하면 \(\ln|y| = kt + C\), 그래서

$$y' = ky,\quad y(0) = y_0\quad\Longrightarrow\quad y(t) = y_0e^{kt}.$$
\(k > 0\)이면 지수 성장(exponential growth), \(k \lt 0\)이면 지수 붕괴(exponential decay). 상수 해 \(y \equiv 0\)은 \(y_0 = 0\)에 포함된다.

지수 함수의 결정적인 성질은 같은 시간마다 같은 비율로 변한다는 것입니다. \(y(t + \tau)/y(t) = e^{k\tau}\)는 \(t\)와 무관합니다. 그래서 붕괴에서는 "절반이 되는 시간"이, 성장에서는 "두 배가 되는 시간"이 언제 재든 같습니다.

정리 2.3 (반감기와 배가 시간) \(N' = -\lambda N\) (\(\lambda > 0\))의 해 \(N = N_0e^{-\lambda t}\)가 절반이 되는 시간 반감기(half-life)는
$$T_{1/2} = \frac{\ln 2}{\lambda} \approx \frac{0.693}{\lambda},\qquad N(t) = N_0\left(\tfrac12\right)^{t/T_{1/2}}.$$
마찬가지로 \(P' = kP\) (\(k > 0\))의 배가 시간은 \(T_2 = \ln 2/k\)이다. 연 이율 \(p\)%의 연속 복리로 원금이 두 배가 되는 시간이 약 \(70/p\)년이라는 "70의 법칙"이 여기서 나온다(\(p = 7\)이면 약 9.9년).

증명. \(N_0e^{-\lambda T} = N_0/2 \iff e^{\lambda T} = 2 \iff T = \ln 2/\lambda\). 그러면 \(e^{-\lambda t} = e^{-(\ln 2)t/T_{1/2}} = (1/2)^{t/T_{1/2}}\). ∎

방사성 붕괴가 지수 법칙을 따르는 이유는 확률에 있습니다. 원자 하나하나는 "나이"를 기억하지 않고, 짧은 시간 \(\Delta t\) 동안 붕괴할 확률이 늘 \(\lambda\Delta t\)로 같습니다. 원자가 \(N\)개면 그동안 평균 \(\lambda N\Delta t\)개가 붕괴하므로 \(\Delta N \approx -\lambda N\Delta t\), 즉 \(N' = -\lambda N\)입니다. 미분방정식은 원자가 아주 많을 때의 평균을 기술합니다. 아래 시뮬레이터에서 원자 수가 적으면 실제 붕괴가 곡선 둘레에서 들쭉날쭉한 것을 볼 수 있습니다.

예제 2.3 (탄소 연대 측정) 유적의 나무 숯에서 탄소-14의 비율이 살아 있는 나무의 30%로 측정되었다. 반감기를 5730년이라 할 때 이 나무는 몇 년 전에 베어졌는가?
  1. 붕괴 상수 \(\lambda = \ln 2/5730 \approx 1.2097\times 10^{-4}\) /년.
  2. \(N/N_0 = e^{-\lambda t} = 0.30\)이므로 \(t = \dfrac{\ln(1/0.30)}{\lambda} = 5730\cdot\dfrac{\ln(10/3)}{\ln 2} \approx 9950\)년.
  3. 감 잡기: 반감기 한 번이면 50%, 두 번이면 25%. 30%는 그 사이이므로 5730년과 11460년 사이에 있어야 한다. ✓
  4. 10%가 남았다면 \(t = 5730\cdot\ln 10/\ln 2 \approx 19{,}000\)년. 남은 비율이 아주 작아지면 측정 잡음이 커져, 수만 년이 이 방법의 한계가 된다.
의학에서의 반감기 갑상선 치료에 쓰는 아이오딘-131의 반감기는 약 8.02일입니다. 30일 뒤에는 \((1/2)^{30/8.02} \approx 0.075\), 즉 약 7.5%가 남습니다. 약물의 혈중 농도도 1차 반응으로 제거되면 같은 법칙을 따르며, 약리학에서는 이를 "제거 반감기"라 부르고 복용 간격을 정하는 데 씁니다. 반복 투여로 농도가 쌓이는 문제는 입력이 있는 방정식 \(C' = -kC + \text{투여}\)이고, 3장과 10장에서 다룹니다.

뉴턴 냉각 법칙: 커피와 사망 시각

커피가 마시기 좋은 온도가 되는 시각

90°C로 내린 커피가 20°C 방에서 10분 뒤 60°C가 되었습니다. 언제 40°C가 될까요? 30분 동안 30°C씩 식으면 될 것 같지만, 실제로는 식는 빠르기가 점점 줄어듭니다. 온도 차가 줄수록 열이 덜 빠져나가기 때문입니다.

물체와 주변 사이의 열 흐름이 온도 차에 비례한다고 가정하면(대류 열전달의 가장 단순한 모형), 물체 온도 \(T\)의 변화율은

$$\frac{dT}{dt} = -k\,(T - T_a),\qquad k > 0.$$
\(T_a\): 주변 온도(일정하다고 가정). \(k = hA/(mc_p)\): 열전달 계수 \(h\), 표면적 \(A\), 질량 \(m\), 비열 \(c_p\)로 정해진다. 이것이 뉴턴 냉각 법칙(Newton's law of cooling)이다.

분리하면 \(\dfrac{dT}{T - T_a} = -k\,dt\), 적분하면 \(\ln|T - T_a| = -kt + C\), 그래서

$$T(t) = T_a + (T_0 - T_a)\,e^{-kt}.$$
온도 차 \(T - T_a\)가 지수적으로 붕괴한다. 상수 해 \(T \equiv T_a\)(열평형)는 \(T_0 = T_a\)에 포함된다. 뜨거운 물체(\(T_0 > T_a\))는 식고, 차가운 물체는 데워진다. 같은 식이다.
예제 2.4 (커피 식히기) \(T_0 = 90\), \(T_a = 20\), \(T(10) = 60\)일 때 \(k\)와 40°C가 되는 시각을 구하라.
  1. \(60 = 20 + 70e^{-10k}\)에서 \(e^{-10k} = 4/7\), \(k = \tfrac{1}{10}\ln\tfrac74 \approx 0.0560\) /분.
  2. \(40 = 20 + 70e^{-kt}\)에서 \(e^{-kt} = 2/7\), \(t = \dfrac{\ln 3.5}{k} \approx 22.4\)분.
  3. 30분 뒤의 온도는 \(20 + 70e^{-30k} = 20 + 70(4/7)^3 \approx 33.1\)°C. 처음 10분에 30도 식었지만 다음 20분에는 27도만 식는다.
예제 2.5 (사망 시각 추정) 실내 온도 20°C인 방에서 밤 11시에 시신의 체온이 30°C, 자정에 28°C였다. 사망 당시 체온을 37°C라 하면 사망 시각은?
  1. 밤 11시를 \(t = 0\)(단위: 시간)으로 두면 \(T - 20 = 10e^{-kt}\). 자정: \(8 = 10e^{-k}\), \(k = \ln 1.25 \approx 0.2231\) /h.
  2. 사망 시각 \(t_d \lt 0\)에서 \(T = 37\): \(17 = 10e^{-kt_d}\), \(t_d = -\dfrac{\ln 1.7}{k} \approx -2.38\) h.
  3. 밤 11시에서 약 2시간 23분 전, 즉 밤 8시 37분경.
  4. 한계: 사망 직후 몇 시간은 체온이 거의 그대로 머무는 구간이 있고, 옷·체격·공기 흐름에 따라 \(k\)가 바뀐다는 것이 알려져 있다. 그래서 실제 법의학에서는 이 단순 모형을 보정한 경험식을 쓰고 결과를 시간 범위로 말한다. 모델의 가정을 아는 것이 결과를 쓰는 법을 정한다.

로지스틱 성장과 수용력

지수 성장은 영원할 수 없다

세균이 30분마다 두 배가 된다면 하루(48번 배가)면 처음의 \(2^{48} \approx 2.8\times 10^{14}\)배입니다. 실제 배양기는 영양분과 공간이 먼저 바닥납니다. 1장의 모델 맞추기 시뮬레이터에서 지수 모형이 무너진 곳이 바로 여기입니다. 개체 수가 많아질수록 성장이 느려지는 효과를 어떻게 식에 넣을까요?

1인당 증가율 \(P'/P\)이 상수 \(r\)이 아니라, 개체 수가 늘수록 줄어 어떤 값 \(K\)에서 0이 된다고 가정합니다. 가장 단순한 선택은 직선 \(P'/P = r(1 - P/K)\)이고, 이것이

$$\frac{dP}{dt} = rP\left(1 - \frac{P}{K}\right).$$
\(r\): 작은 개체 수에서의 증가율(내재적 증가율), \(K\): 수용력(carrying capacity). 이 식이 로지스틱 방정식(logistic equation)이다. 벨기에의 수학자 페르휠스트(Pierre-François Verhulst)가 1838년에 인구 모형으로 제안했다.

⓪ 상수 해는 \(P \equiv 0\)과 \(P \equiv K\)입니다. 나머지는 분리해서 부분 분수로 적분합니다(적분 기법은 CalculusBook 적분 기법).

$$\frac{K\,dP}{P(K - P)} = r\,dt,\qquad \frac{K}{P(K - P)} = \frac1P + \frac{1}{K - P}.$$
적분하면 \(\ln|P| - \ln|K - P| = rt + C\), 즉 \(\dfrac{P}{K - P} = Be^{rt}\).
정리 2.4 (로지스틱 방정식의 해) \(P' = rP(1 - P/K)\), \(P(0) = P_0 > 0\)의 해는
$$P(t) = \frac{K}{1 + A\,e^{-rt}},\qquad A = \frac{K - P_0}{P_0}.$$
\(0 \lt P_0 \lt K\)이면 \(P\)는 증가해 \(K\)로 다가가고, \(P_0 > K\)이면 감소해 \(K\)로 다가간다. \(t \to \infty\)이면 늘 \(P \to K\). \(0 \lt P_0 \lt K/2\)이면 \(P = K/2\)가 되는 시각 \(t^* = \frac{\ln A}{r}\)에서 성장이 가장 빠르고(변곡점), 그때의 성장률은 \(rK/4\)다.

변곡점의 증명. \(P' = rP - \frac{r}{K}P^2\)은 \(P\)의 이차식으로, \(P = K/2\)에서 최대 \(rK/4\)다. \(P = K/2\)를 해에 넣으면 \(Ae^{-rt^*} = 1\), \(t^* = \ln A/r\). ∎

예제 2.6 (로지스틱 계산) \(r = 0.5\) /일, \(K = 1000\), \(P_0 = 10\)일 때 \(P(10)\)과 변곡 시각을 구하라.
  1. \(A = (1000 - 10)/10 = 99\). \(P(t) = \dfrac{1000}{1 + 99e^{-0.5t}}\).
  2. \(P(10) = \dfrac{1000}{1 + 99e^{-5}} \approx 600\). 같은 \(r\)의 지수 모형이면 \(10e^5 \approx 1484\)로 이미 수용력을 넘는다.
  3. \(t^* = \ln 99/0.5 \approx 9.19\)일. 이때 \(P = 500\)이고 하루에 \(rK/4 = 125\)씩 늘고 있다.

토리첼리 법칙: 탱크가 비는 시간

물탱크 바닥의 구멍

지름 1 m, 물 높이 2 m인 원통형 탱크의 바닥에 반지름 2 cm인 구멍이 뚫렸습니다. 다 빠지는 데 얼마나 걸릴까요? 물이 많을 때는 세게, 적을 때는 약하게 나오므로 "부피 ÷ 유량"으로는 계산할 수 없습니다. 유량 자체가 수위에 따라 변하기 때문입니다.

수면에서 높이 \(h\)만큼 떨어진 물 한 덩이는 구멍을 지날 때 위치 에너지 \(mgh\)를 운동 에너지 \(\tfrac12mv^2\)로 바꾸므로 \(v = \sqrt{2gh}\)로 나옵니다. 이것이 토리첼리 법칙(Torricelli's law)입니다. 구멍의 넓이를 \(a\), 높이 \(h\)에서 탱크의 단면적을 \(A(h)\)라 하면 부피의 감소율 = 구멍을 빠져나가는 유량이므로

$$A(h)\,\frac{dh}{dt} = -a\sqrt{2gh}.$$
실제 구멍에서는 물줄기가 구멍보다 가늘게 오므라드는 등의 효과로 유량이 이보다 작아, 보정 계수(유출 계수, 날카로운 구멍에서 대략 0.6)를 곱해 쓴다.
정리 2.5 (원통 탱크가 비는 시간) 단면적 \(A\)가 일정하면 \(h(0) = h_0\)인 해는
$$\sqrt{h(t)} = \sqrt{h_0} - \frac{a}{A}\sqrt{\frac{g}{2}}\;t,\qquad T_{\text{empty}} = \frac{A}{a}\sqrt{\frac{2h_0}{g}}.$$
\(0 \le t \le T\)에서 유효하고, \(t \ge T\)에서는 \(h \equiv 0\)이다. 수위가 절반이 되는 시각은 \(T(1 - 1/\sqrt2) \approx 0.293\,T\)이다.
예제 2.7 (문제의 탱크)
  1. \(A = \pi(0.5)^2\), \(a = \pi(0.02)^2\)이므로 \(A/a = (0.5/0.02)^2 = 625\).
  2. \(T = 625\sqrt{2\cdot 2/9.8} \approx 625 \times 0.639 \approx 399\) s, 약 6분 40초(유출 계수를 무시한 이상적인 값).
  3. 수위가 1 m(절반)로 내려가는 데는 \(0.293T \approx 117\) s. 물의 위쪽 절반이 빠지는 데 전체 시간의 29%, 아래쪽 절반에 71%가 걸린다.
  4. 흥미로운 점: \(t = T\)에서 해는 \(h = 0\)인 평형해에 유한한 시간에 닿는다. 지수 붕괴는 0에 영원히 다가가기만 하는 것과 다르다. 우변 \(\sqrt h\)가 \(h = 0\)에서 미분 불가능해서 생기는 현상이고, 거꾸로 돌리면 "빈 탱크가 언제부터 비어 있었는지" 알 수 없다는 비유일성이 된다(4장의 물 새는 양동이).

음함수 해와 해의 정의 구간

\(y\)에 대해 풀리지 않는 답

\(y' = \dfrac{t}{y + e^y}\)을 분리하면 \((y + e^y)\,dy = t\,dt\), 적분하면 \(\tfrac12y^2 + e^y = \tfrac12t^2 + C\)입니다. 이 식은 \(y = \ldots\) 꼴로 풀 수 없습니다. 그래도 이것을 "해"라고 부를 수 있을까요? 그리고 해는 \(t\)가 얼마까지 살아 있을까요?

정의 2.6 (음함수 해) 관계식 \(G(t, y) = 0\)이 어떤 구간에서 미분 가능한 함수 \(y = \phi(t)\)를 정하고 그 \(\phi\)가 방정식을 만족하면, \(G(t, y) = 0\)을 방정식의 음함수 해(implicit solution)라 한다. 변수분리법의 결과 \(G(y) = F(t) + C\)는 대개 음함수 해다.

음함수 해에서도 값을 계산할 수 있습니다. 위 예에서 \(y(0) = 0\)이면 \(C = 1\)이고, \(y(1)\)은 방정식 \(\tfrac12y^2 + e^y = 1.5\)의 근입니다. 뉴턴 방법으로 풀면 \(y(1) \approx 0.3610\)이고, 원래 미분방정식을 RK4로 적분한 값과 일치합니다. 음함수 정리(CalculusBook 편미분)에 따르면 \(\partial G/\partial y = y + e^y \ne 0\)인 곳에서 이 관계식이 \(y\)를 \(t\)의 함수로 정합니다.

예제 2.8 (원과 정의 구간) \(y' = -t/y\), \(y(0) = 2\).
  1. 분리: \(y\,dy = -t\,dt\), 적분: \(y^2 = -t^2 + C\). 음함수 해 \(t^2 + y^2 = C\)는 원이다.
  2. \(y(0) = 2\)에서 \(C = 4\). 원 전체가 해가 아니라 위쪽 반원 \(y = \sqrt{4 - t^2}\)만 해다(초기점이 \(y > 0\)인 쪽에 있다).
  3. 정의 구간: \(y = 0\)이 되는 \(t = \pm2\)에서 \(y' = -t/y\)가 정의되지 않는다. 그래서 해의 구간은 열린 구간 \((-2, 2)\)이다. 예를 들어 \(y(1.5) = \sqrt{1.75} \approx 1.3229\)(RK4 확인).
정의 2.7 (최대 정의 구간) 초기값 문제의 해를 더 넓은 구간으로 늘일 수 없을 때, 그 구간을 해의 최대 정의 구간(maximal interval of existence)이라 한다. 해의 공식이 다른 곳에서 정의되더라도, 초기점 \(t_0\)를 포함하고 끊기지 않은 한 조각만이 그 초기값 문제의 해다.

선형 방정식에서는 계수가 연속인 구간 전체에서 해가 살아 있지만(3장), 비선형 방정식에서는 정의 구간이 초기값에 따라 달라지고, 방정식만 봐서는 알 수 없습니다.

예제 2.9 (초기값이 정하는 폭발 시각) \(y' = 2ty^2\), \(y(0) = y_0\).
  1. ⓪ 상수 해 \(y \equiv 0\). ①② \(-\dfrac1y = t^2 + C\), \(C = -1/y_0\). ③ \(y = \dfrac{y_0}{1 - y_0t^2}\).
  2. \(y_0 > 0\): 분모가 \(t = \pm1/\sqrt{y_0}\)에서 0. 정의 구간 \((-1/\sqrt{y_0}, 1/\sqrt{y_0})\). \(y_0\)이 클수록 빨리 터진다. \(y_0 = 1\)이면 \((-1, 1)\)이고 \(y(0.9) = 1/0.19 \approx 5.263\)(RK4 확인).
  3. \(y_0 \lt 0\): 분모 \(1 + |y_0|t^2 > 0\)이므로 모든 \(t\)에서 정의된다. 공식은 같아도 출발점에 따라 운명이 다르다.
  4. \(y_0 > 0\)인 공식은 \(|t| > 1/\sqrt{y_0}\)에서도 값을 주지만(음수 가지), 그 가지는 초기점과 이어져 있지 않으므로 이 초기값 문제의 해가 아니다.

직교 궤적

등전위선과 전기력선

평면 위 전하 배치의 등전위선들이 곡선 족으로 주어졌습니다. 전기력선은 등전위선과 모든 점에서 직각으로 만납니다(전기장은 퍼텐셜의 기울기 방향이므로). 등전위선의 식에서 전기력선의 식을 얻을 수 있을까요? 같은 질문이 등온선과 열 흐름선, 지도의 등고선과 물이 흐르는 길(최급강하선)에도 나옵니다.

정의 2.8 (직교 궤적) 곡선 족의 모든 곡선과 만나는 점마다 직각으로 교차하는 곡선을 그 족의 직교 궤적(orthogonal trajectory)이라 한다.

구하는 순서는 기계적입니다. ① 곡선 족 \(F(x, y) = c\)를 미분해 \(c\)를 지운 미분방정식 \(y' = m(x, y)\)를 얻는다. ② 두 직선이 수직이면 기울기의 곱이 \(-1\)이므로, 직교 궤적은 \(y' = -1/m(x, y)\)를 만족한다. ③ 이 방정식을 푼다. 대개 변수분리형이 된다.

예제 2.10 (포물선 족 \(y = cx^2\)의 직교 궤적)
  1. ① \(y' = 2cx\)이고 \(c = y/x^2\)이므로 \(y' = \dfrac{2y}{x}\). 상수 \(c\)가 사라진 이 식이 족 전체의 미분방정식이다.
  2. ② 직교 궤적: \(y' = -\dfrac{x}{2y}\).
  3. ③ 분리: \(2y\,dy = -x\,dx\), 적분: \(y^2 = -\tfrac12x^2 + k\), 즉 \(x^2 + 2y^2 = k\). 타원 족이다.
  4. 점 \((1, 1)\)에서 확인: 포물선 \(y = x^2\)의 기울기 2, 타원 \(x^2 + 2y^2 = 3\)의 기울기 \(-x/(2y) = -1/2\). 곱 \(-1\). ✓

동차형 방정식: \(v = y/x\)로 분리하기

분리되지 않는 방정식

\(y' = \dfrac{x + y}{x - y}\)는 우변을 \(x\)만의 함수와 \(y\)만의 함수의 곱으로 쓸 수 없습니다. 그런데 분자와 분모를 \(x\)로 나누면 \(\dfrac{1 + y/x}{1 - y/x}\)가 되어, 우변이 비율 \(y/x\)에만 의존합니다. 방향장으로 보면 원점을 지나는 각 직선 위에서 기울기가 모두 같다는 뜻입니다. 이 대칭을 이용할 수 있을까요?

정의 2.9 (동차형 방정식) 1계 방정식이 \(y' = F\!\left(\dfrac yx\right)\) 꼴로 쓰이면 동차형 방정식(homogeneous equation)이라 한다. 우변이 \(x, y\)를 같은 배로 늘여도 변하지 않는 함수(0차 동차 함수)다. (1장의 "동차 선형 방정식"과 이름만 같고 다른 개념이다.)
정리 2.10 (동차형의 치환) \(v = y/x\)로 놓으면 \(y = xv\), \(y' = v + xv'\)이므로 동차형 방정식은
$$x\frac{dv}{dx} = F(v) - v\quad\Longrightarrow\quad \int\frac{dv}{F(v) - v} = \ln|x| + C$$
인 변수분리형이 된다. \(F(v_0) = v_0\)인 \(v_0\)가 있으면 직선 \(y = v_0x\)가 상수 해에 해당하는 해다.
예제 2.11 (로그 나선) \(y' = \dfrac{x + y}{x - y}\).
  1. \(F(v) = \dfrac{1 + v}{1 - v}\). \(F(v) - v = \dfrac{1 + v - v + v^2}{1 - v} = \dfrac{1 + v^2}{1 - v}\). \(F(v) = v\)인 실수 \(v\)는 없다.
  2. 분리: \(\dfrac{1 - v}{1 + v^2}\,dv = \dfrac{dx}{x}\). 적분: \(\arctan v - \tfrac12\ln(1 + v^2) = \ln|x| + C\).
  3. 되돌리기: \(\tfrac12\ln(1 + v^2) + \ln|x| = \ln\sqrt{x^2 + y^2}\)이므로 \(\arctan\dfrac yx = \ln\sqrt{x^2 + y^2} + C\).
  4. 극좌표 \(r, \theta\)로 쓰면 \(\theta = \ln r + C\), 즉 \(r = r_0e^{\theta}\). 해곡선은 로그 나선이다. 점 \((1, 0)\)에서 출발해 \(x = 1.2\)까지 RK4로 적분하면 \(\theta = \ln r = 0.2031\)로 일치한다.
예제 2.12 (원점을 지나는 쌍곡선) \(y' = \dfrac{x^2 + y^2}{2xy}\).
  1. \(F(v) = \dfrac{1 + v^2}{2v}\), \(F(v) - v = \dfrac{1 - v^2}{2v}\).
  2. 분리: \(\dfrac{2v\,dv}{1 - v^2} = \dfrac{dx}{x}\). 적분: \(-\ln|1 - v^2| = \ln|x| + C\), 즉 \((1 - v^2)\,x = B\).
  3. 되돌리기: \(\Bigl(1 - \dfrac{y^2}{x^2}\Bigr)x = B\) → \(x^2 - y^2 = Bx\). 상수 해 \(v = \pm1\)은 직선 \(y = \pm x\)(\(B = 0\)).
  4. 검산: \(2x - 2yy' = B = (x^2 - y^2)/x\)에서 \(y' = \dfrac{x^2 + y^2}{2xy}\). ✓ 점 \((1, 0.5)\)를 지나는 해는 \(B = 0.75\)이고 \(y(2) = \sqrt{2.5} \approx 1.5811\)(RK4 확인).

이 도구가 쓰이는 곳

변수분리형의 해 \(e^{-t/\tau}\)는 공학에서 가장 자주 보는 곡선입니다. "어떤 양의 감소율이 그 양에 비례한다"는 가정이 성립하는 곳마다 같은 식이 나오고, 그 시간 척도 \(\tau = 1/k\)(시상수)가 설계의 핵심 숫자가 됩니다.

반도체 공정의 열처리와 냉각 웨이퍼를 고온 공정 뒤 식힐 때, 식히는 빠르기는 웨이퍼와 주변의 온도 차에 비례하는 뉴턴 냉각으로 첫 근사를 합니다. 시상수 \(1/k\)를 알면 "몇 초 뒤에 다음 공정으로 넘길 수 있는가"가 정해집니다. 실제 장비에서는 복사 열전달(\(T^4\)에 비례하는 비선형 항)이 더해지지만, 그것도 \(T' = -\epsilon(T^4 - T_a^4)\)의 변수분리형이라 같은 방법으로 분석됩니다.

핵심 정리

  1. \(y' = f(t)g(y)\)는 \(\int dy/g(y) = \int f\,dt + C\)로 푼다. 근거는 연쇄 법칙 \(\frac{d}{dt}G(y) = y'/g(y)\)다.
  2. 나누기 전에 \(g(y_0) = 0\)인 상수 해를 찾는다. 일반해 공식에 들어가지 않으면 따로 적는다(\(y' = y^2 - 1\)의 \(y = -1\)).
  3. \(y' = ky\)의 해 \(y_0e^{kt}\). 반감기 \(T_{1/2} = \ln 2/\lambda\), 배가 시간 \(\ln 2/k\). 탄소 연대 \(t = \ln(N_0/N)/\lambda\).
  4. 뉴턴 냉각 \(T = T_a + (T_0 - T_a)e^{-kt}\). 온도 차가 지수 붕괴한다. 측정 두 번으로 \(k\)를 구하고 과거 시각을 추정한다.
  5. 로지스틱 \(P = K/(1 + Ae^{-rt})\), \(A = (K - P_0)/P_0\). 모든 양의 해가 \(K\)로 가고, \(K/2\)에서 성장률이 최대 \(rK/4\)다.
  6. 토리첼리 \(A(h)h' = -a\sqrt{2gh}\). 원통은 \(T = (A/a)\sqrt{2h_0/g}\)이고, 해가 유한 시간에 0에 닿는다.
  7. 변수분리의 결과는 음함수 해인 경우가 많다. 해의 최대 정의 구간은 초기값에 따라 달라지며(\(y' = 2ty^2\)), 초기점을 포함한 한 조각만 해다.
  8. 직교 궤적은 족의 방정식 \(y' = m\)에서 \(y' = -1/m\)을 푼다. 동차형 \(y' = F(y/x)\)는 \(v = y/x\)로 \(xv' = F(v) - v\)인 변수분리형이 된다.

확인 퀴즈

Q1. 다음 중 변수분리형이 아닌 것은?

\(e^{t+y} = e^te^y\), \(ty^2 + t = t(y^2 + 1)\), \(\sin t/y = \sin t\cdot(1/y)\)는 모두 곱으로 갈라진다. \(t + y\)는 합이라 갈라지지 않는다. 이것은 1계 선형 방정식이고 3장의 적분 인자로 푼다.

Q2. \(y' = y(y - 2)\)를 \(y(y - 2)\)로 나누어 풀 때 따로 확인해야 하는 해는?

\(g(y) = y(y - 2) = 0\)인 \(y = 0, 2\)에서는 나눌 수 없고, 그 상수 함수들이 바로 해(평형해)다. 일반해 공식에 들어가는지 따로 확인해야 한다.

Q3. 반감기가 10일인 물질이 처음의 1/8로 줄어드는 데 걸리는 시간은?

\(1/8 = (1/2)^3\)이므로 반감기 세 번, 30일. 지수 붕괴는 같은 시간마다 같은 비율로 줄어든다.

Q4. 80°C인 물체가 20°C 방에서 5분 뒤 50°C가 되었다. 다시 5분 뒤(처음부터 10분 뒤)의 온도는?

온도 차가 60 → 30으로 5분마다 절반이 된다. 다음 5분 뒤 차이는 15, 온도는 \(20 + 15 = 35\)°C. 일정하게 30도씩 식는 것이 아니다.

Q5. 로지스틱 방정식 \(P' = 0.4P(1 - P/2000)\)에서 개체 수가 가장 빠르게 늘 때의 \(P\)와 그 성장률은?

\(P' = rP(1 - P/K)\)는 \(P\)의 포물선이고 \(P = K/2 = 1000\)에서 최대 \(rK/4 = 0.4\cdot 2000/4 = 200\)이다.

Q6. 원통 탱크(토리첼리 법칙)의 처음 수위를 4배로 하면 비는 시간은?

\(T = (A/a)\sqrt{2h_0/g} \propto \sqrt{h_0}\). 물이 4배지만 수위가 높을 때는 훨씬 빠르게 흘러나오므로 시간은 \(\sqrt4 = 2\)배다.

Q7. \(y' = y^2\), \(y(0) = 2\)의 해와 최대 정의 구간은?

\(-1/y = t + C\), \(C = -1/2\)이므로 \(y = 1/(1/2 - t) = 2/(1 - 2t)\). \(t = 1/2\)에서 터지고, 초기점 \(t = 0\)을 포함하는 조각은 \((-\infty, 1/2)\)이다. 다른 조각은 이 초기값 문제의 해가 아니다.

Q8. 곡선 족 \(xy = c\)의 직교 궤적은?

\(y + xy' = 0\)에서 \(y' = -y/x\). 직교 궤적은 \(y' = x/y\), 분리하면 \(y\,dy = x\,dx\), \(y^2 = x^2 - k\), 즉 \(x^2 - y^2 = k\)다. 두 쌍곡선 족이 서로 직교한다.
