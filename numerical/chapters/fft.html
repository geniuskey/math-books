Chapter 08

이산 푸리에 변환과 FFT

5~7장은 다항식으로 근사했습니다. 그런데 하루의 기온, 회전하는 기계의 진동, 소리처럼 되풀이되는 데이터에는 다항식보다 사인과 코사인이 어울립니다. 등간격으로 잰 주기 데이터를 삼각함수로 보간하면 그 계수가 이산 푸리에 변환(DFT)이고, DFT는 \(N\times N\) 행렬 곱이라 \(N^2\)번의 곱셈이 듭니다. 1965년에 널리 알려진 고속 푸리에 변환(FFT)은 같은 결과를 \(N\log_2 N\)에 비례하는 연산으로 냅니다. 백만 개의 표본이면 수만 배 빠릅니다. 이 장은 DFT의 정의와 단위근의 기하, 표본화가 만드는 앨리어싱, FFT의 짝·홀 분할과 나비 연산, FFT로 합성곱과 큰 수 곱셈을 빠르게 하는 법, 그리고 실제 신호의 스펙트럼을 읽을 때 만나는 누설과 창 함수까지 다룹니다.

  • 등간격 주기 데이터의 삼각 보간 계수가 DFT임을 이산 직교성으로 보인다.
  • DFT를 단위근의 행렬 \(F_N\)으로 쓰고, 역변환과 파스발 등식을 안다.
  • 표본화 주파수와 나이퀴스트 주파수로 앨리어싱을 예측한다.
  • 쿨리–튜키 FFT를 짝·홀 분할로 유도하고, 나비 연산과 비트 반전 순서를 따라가며 \(O(N\log N)\)을 확인한다.
  • 합성곱 정리로 다항식 곱셈과 큰 수 곱셈을 FFT로 계산하고, 원형 합성곱의 감김을 제로 패딩으로 막는다.
  • 스펙트럼 누설을 창 함수로 줄이고, 제로 패딩이 해상도를 높이지 않는 이유를 설명하며, 스펙트럴 미분의 지수적 정확도를 측정한다.
이 수식이 없었다면와이파이와 LTE·5G의 OFDM

스마트폰의 LTE·5G와 와이파이는 OFDM이라는 방식으로 데이터를 보냅니다. 수백~수천 개의 서로 다른 주파수(부반송파)에 비트를 나눠 실어 한꺼번에 보내는 방식인데, 송신기는 매 심볼마다 역 DFT로 그 주파수들을 합쳐 하나의 파형을 만들고, 수신기는 DFT로 다시 갈라냅니다. 부반송파가 2048개라면 DFT를 직접 계산할 때 심볼 하나에 약 400만 번의 복소 곱셈이 필요하고, 이를 초당 수만 번 해야 합니다. FFT는 같은 일을 약 1만 1천 번의 곱셈으로 끝냅니다.

FFT의 아이디어는 가우스(Carl Friedrich Gauss)의 1805년 무렵 미출판 원고에 이미 있었다고 알려져 있지만, 널리 퍼진 것은 쿨리(James Cooley)와 튜키(John Tukey)의 1965년 논문 뒤입니다. 그 뒤로 디지털 오디오, MRI 영상 재구성, 레이더, 지진파 분석, 큰 수의 곱셈까지 FFT 위에 올라섰습니다.

N개 주파수의 데이터→DFT: N² 곱셈→FFT: (N/2) log₂N 나비→실시간 무선 통신·영상·오디오

주기 데이터의 삼각 보간

하루 24번 잰 기온

기상 관측소가 한 시간마다 기온을 잽니다. 기온은 하루를 주기로 되풀이되므로 측정 사이의 값을 보간할 때 다항식은 어울리지 않습니다. 다항식은 구간 밖으로 가면 무한히 커지고, 0시와 24시의 값과 기울기가 맞아야 한다는 주기 조건을 모릅니다. 주기가 있는 함수의 자연스러운 재료는 \(\cos kx\)와 \(\sin kx\)입니다.

주기를 \(2\pi\)로 맞추고 한 주기를 \(N\)등분한 점 \(x_j = 2\pi j/N\)(\(j = 0, \dots, N - 1\))에서 값 \(f_j\)를 안다고 합시다. 복소 지수 \(e^{ikx} = \cos kx + i\sin kx\)로 쓰면 계산이 훨씬 간단해집니다. 핵심은 등간격 점에서 지수 함수들이 이산적으로 직교한다는 사실입니다.

정리 8.1 (이산 직교성) 정수 \(k, l\)에 대해
$$\sum_{j=0}^{N-1} e^{ikx_j}\,\overline{e^{ilx_j}} = \sum_{j=0}^{N-1} e^{2\pi i(k - l)j/N} = \begin{cases} N, & k \equiv l \pmod N\\ 0, & \text{그 밖}\end{cases}$$

증명. \(q = e^{2\pi i(k - l)/N}\)이라 하면 합은 등비급수 \(\sum_{j=0}^{N-1}q^j\)이다. \(k \equiv l\)이면 \(q = 1\)이라 합이 \(N\). 아니면 \(q \ne 1\), \(q^N = 1\)이므로 \((1 - q^N)/(1 - q) = 0\). ∎

7장의 언어로 말하면 등간격 점 위의 내적 \(\langle u, v\rangle = \sum_j u(x_j)\overline{v(x_j)}\)에서 \(e^{ikx}\)들이 직교 기저입니다. 그래서 보간 계수가 정규 방정식을 풀 필요 없이 내적 하나로 나옵니다. 단, \(k\)와 \(k + N\)은 표본점에서 구별되지 않습니다(\(e^{i(k+N)x_j} = e^{ikx_j}\)). 이것이 3절의 앨리어싱입니다.

정리 8.2 (삼각 보간) \(N\)이 짝수일 때
$$p(x) = \frac1N\sum_{k=-N/2+1}^{N/2-1} F_k\,e^{ikx} + \frac{1}{N}F_{N/2}\cos\frac{Nx}{2},\qquad F_k = \sum_{j=0}^{N-1} f_j\,e^{-ikx_j}$$
\(F_{k}\)는 \(k\)에 대해 주기 \(N\)이므로 \(F_{-k} = F_{N-k}\)로 읽는다. \(f_j\)가 실수이면 \(F_{-k} = \overline{F_k}\)이고 \(p\)도 실수이다. 나이퀴스트 항 \(\cos(Nx/2)\)는 \(\pm N/2\) 두 지수를 반씩 나눈 것이다.
는 \(p(x_j) = f_j\)를 만족하는 차수 \(N/2\) 이하의 유일한 실 삼각 다항식이다. 계수 \(F_k\)의 계산이 다음 절의 이산 푸리에 변환이다.
예제 8.1 (네 점의 삼각 보간) \(N = 4\), \(x_j = 0, \frac\pi2, \pi, \frac{3\pi}2\)에서 \(f = (2, 1, 0, 1)\).
  1. \(e^{-ikx_j} = (-i)^{kj}\). \(F_0 = 2 + 1 + 0 + 1 = 4\).
  2. \(F_1 = 2 + 1\cdot(-i) + 0\cdot(-1) + 1\cdot(i) = 2\). \(F_2 = 2 - 1 + 0 - 1 = 0\). \(F_3 = F_{-1} = \overline{F_1} = 2\).
  3. \(p(x) = \frac14\bigl(4 + 2e^{ix} + 2e^{-ix}\bigr) + 0 = 1 + \cos x\). 확인: \(1 + \cos 0 = 2\), \(1 + \cos\frac\pi2 = 1\), \(1 + \cos\pi = 0\). 데이터는 사실 \(1 + \cos x\)의 표본이었고, 삼각 보간이 그것을 정확히 되살렸다.

DFT의 정의, 행렬, 단위근

표본의 위치 \(x_j\)를 잊고 숫자의 배열만 남기면 정의가 깔끔해집니다.

정의 8.3 (이산 푸리에 변환) \(\omega_N = e^{-2\pi i/N}\)이라 하자. 복소 벡터 \(\mathbf x = (x_0, \dots, x_{N-1})\)의 이산 푸리에 변환(discrete Fourier transform, DFT)은
$$X_k = \sum_{j=0}^{N-1} x_j\,\omega_N^{jk},\qquad k = 0, 1, \dots, N - 1$$
이고, 역변환은 \(x_j = \frac1N\sum_{k=0}^{N-1}X_k\,\omega_N^{-jk}\)이다. 행렬로 \(\mathbf X = F_N\mathbf x\), \((F_N)_{kj} = \omega_N^{jk}\)이며 \(F_N^{-1} = \frac1N\overline{F_N}\)이다.

\(\omega_N\)은 1의 원시 \(N\)제곱근, 곧 복소 평면의 단위원을 \(N\)등분한 점입니다(MathBook: 복소수는 회전이다). \(F_N\)의 \(k\)번째 행은 단위원을 시계 방향으로 한 걸음에 \(k/N\)바퀴씩 도는 수열이고, \(X_k\)는 신호를 그 회전과 짝지어 더한 값입니다. 신호에 그 빠르기로 도는 성분이 있으면 화살표들이 한 방향으로 모여 \(|X_k|\)가 커지고, 없으면 서로 상쇄됩니다. 역변환이 켤레를 쓰는 이유는 정리 8.1 그대로입니다. \(\overline{F_N}F_N = NI\)이므로 \(F_N/\sqrt N\)은 유니터리 행렬입니다. 여기서 두 가지 성질이 바로 나옵니다.

정리 8.4 (파스발 등식과 조건수) \(\sum_j|x_j|^2 = \frac1N\sum_k|X_k|^2\)이다. \(F_N/\sqrt N\)이 유니터리이므로 \(\kappa_2(F_N) = 1\), 곧 DFT는 완벽하게 조건이 좋은 문제다. 실제로 배정밀도 FFT로 변환했다가 역변환하면 상대 오차가 \(N = 2^{10}\)에서 \(3.8\times10^{-16}\), \(N = 2^{18}\)에서도 \(5.3\times10^{-16}\)에 머문다.
예제 8.2 (손으로 DFT) \(\mathbf x = (1, 2, 3, 4)\), \(N = 4\), \(\omega_4 = -i\).
$$F_4 = \begin{bmatrix} 1 & 1 & 1 & 1\\ 1 & -i & -1 & i\\ 1 & -1 & 1 & -1\\ 1 & i & -1 & -i\end{bmatrix},\qquad F_4\begin{bmatrix}1\\2\\3\\4\end{bmatrix} = \begin{bmatrix} 10\\ -2 + 2i\\ -2\\ -2 - 2i\end{bmatrix}.$$

\(X_0 = 10\)은 합(평균의 \(N\)배). 실수 입력이므로 \(X_3 = \overline{X_1}\). 파스발: \(1 + 4 + 9 + 16 = 30\), \(\frac14(100 + 8 + 4 + 8) = 30\). 직접 계산은 \(16\)번의 곱셈이 들었다. 4절에서 이를 줄인다.

표본 간격이 \(\Delta t\)초이면 \(X_k\)는 주파수 \(k/(N\Delta t)\) Hz 성분입니다. 곧 주파수 눈금의 간격(주파수 분해능)은 \(\Delta f = 1/(N\Delta t) = 1/T\), 관측 시간의 역수입니다. 실수 신호에서는 \(k\)와 \(N - k\)가 켤레라서 \(k = 0, \dots, N/2\)만 보면 충분하고, 진폭 \(A\)인 사인파 \(A\cos(2\pi k_0j/N)\)는 \(|X_{k_0}| = |X_{N-k_0}| = AN/2\)로 나타납니다. 그래서 진폭을 읽을 때는 \(2|X_k|/N\)을 그립니다.

표본화와 앨리어싱, 나이퀴스트

7 Hz가 3 Hz로 보인다

진동 센서를 초당 10번 읽었더니 3 Hz의 진동이 보였습니다. 그런데 실제 기계는 7 Hz로 떨고 있었습니다. 측정은 정확했고 계산에도 실수가 없었습니다. 표본만 보고는 두 진동을 구별할 방법이 원리적으로 없습니다.

표본화 주파수 \(f_s = 1/\Delta t\)로 \(\cos(2\pi f t)\)를 뜨면 표본은 \(\cos(2\pi fj/f_s)\)입니다. \(f\)에 \(f_s\)의 정수배를 더하거나 부호를 바꿔도 표본은 같습니다(\(\cos(2\pi(f + mf_s)j/f_s) = \cos(2\pi fj/f_s + 2\pi mj)\)). 그래서 표본이 보여 줄 수 있는 주파수는 \([0, f_s/2]\)뿐이고, 그 밖의 주파수는 이 구간 안으로 접혀 들어옵니다. 이것이 앨리어싱(aliasing)입니다. 7 Hz를 \(f_s = 10\)으로 뜨면 \(|7 - 10| = 3\) Hz로 보입니다.

정리 8.5 (표본화 정리, 나이퀴스트–섀넌) 연속 신호 \(x(t)\)의 푸리에 변환이 \(|f| \lt B\) 밖에서 0이면(대역 제한), \(f_s \gt 2B\)로 뜬 표본으로부터
$$x(t) = \sum_{n=-\infty}^{\infty} x(n\Delta t)\,\mathrm{sinc}\!\left(\frac{t - n\Delta t}{\Delta t}\right),\qquad \mathrm{sinc}(u) = \frac{\sin\pi u}{\pi u}$$
로 \(x\)를 정확히 복원할 수 있다. \(f_s/2\)를 나이퀴스트 주파수(Nyquist frequency)라 한다.

겉보기 주파수는 \(f_{\text{alias}} = |f - f_s\cdot\mathrm{round}(f/f_s)|\)입니다. 실무의 처방은 두 가지입니다. 표본화 전에 아날로그 저역 통과 필터(앤티앨리어싱 필터)로 \(f_s/2\) 위의 성분을 지우거나, 관심 대역보다 충분히 빠르게 뜹니다. CD 오디오가 사람의 가청 한계 약 20 kHz의 두 배를 조금 넘는 44.1 kHz를 쓰는 이유입니다. 일단 표본에 섞여 들어온 앨리어스는 어떤 계산으로도 되돌릴 수 없습니다(MathBook: 연속을 격자로 자르기).

쿨리–튜키 FFT: 짝·홀 분할과 나비 연산

백만 점의 스펙트럼

\(N = 2^{20} \approx 10^6\)개 표본의 DFT를 정의대로 계산하면 복소 곱셈이 \(N^2 \approx 1.1\times10^{12}\)번입니다. 초당 \(10^9\)번 곱하는 컴퓨터로 18분이 넘게 걸립니다. 그런데 \(F_N\)의 원소는 \(N^2\)개가 아니라 \(N\)가지 값(\(\omega_N\)의 거듭제곱)뿐입니다. 이 반복되는 구조를 이용할 수 없을까요?

\(N\)이 짝수일 때 합을 짝수 번째와 홀수 번째로 나눕니다. \(\omega_N^2 = \omega_{N/2}\)이므로

$$X_k = \sum_{m=0}^{N/2-1} x_{2m}\,\omega_{N/2}^{mk} + \omega_N^k\sum_{m=0}^{N/2-1} x_{2m+1}\,\omega_{N/2}^{mk} = E_k + \omega_N^k\,O_k.$$
\(E_k\), \(O_k\)는 각각 짝수 표본, 홀수 표본의 \(N/2\)점 DFT다. 이들은 \(k\)에 대해 주기 \(N/2\)이고, \(\omega_N^{k + N/2} = -\omega_N^k\)이다.
정리 8.6 (나비 연산) \(k = 0, \dots, N/2 - 1\)에 대해
$$X_k = E_k + \omega_N^kO_k,\qquad X_{k + N/2} = E_k - \omega_N^kO_k.$$
곧 길이 \(N\)의 DFT는 길이 \(N/2\)의 DFT 두 개와, 곱셈 한 번(회전 인자(twiddle factor) \(\omega_N^k\))과 덧셈·뺄셈 한 번씩인 나비 연산(butterfly) \(N/2\)개로 계산된다.

이를 \(N = 2^p\)까지 되풀이하는 것이 기수 2 쿨리–튜키 FFT(Cooley–Tukey FFT)입니다. 비용을 \(T(N)\)이라 하면 \(T(N) = 2T(N/2) + cN\), \(T(1) = 0\)이므로 \(T(N) = cN\log_2N\)입니다. 정확히는 \(\log_2N\)단계마다 나비가 \(N/2\)개, 복소 곱셈 \(\frac N2\log_2N\)번입니다(\(\omega^0 = 1\) 같은 자명한 곱셈을 빼면 더 적다).

재귀를 펼쳐 놓으면 입력이 \(x_0, x_4, x_2, x_6, x_1, x_5, x_3, x_7\)(\(N = 8\)) 순서로 맨 아래에 놓입니다. 짝·홀 분할을 세 번 했으니 인덱스를 2진수로 쓰고 비트를 뒤집은 순서입니다(\(1 = 001_2 \to 100_2 = 4\)). 그래서 실제 구현은 먼저 배열을 비트 반전 순서로 바꾼 뒤, 길이 2, 4, 8, …의 나비를 제자리에서 계산합니다. 추가 메모리가 필요 없습니다.

함수 FFT(x)                             // 제자리, N = 2^p
  for i = 0 … N−1                        // 1단계: 비트 반전 순서로 재배열
    j ← bitreverse(i, p)
    if i < j then swap(x[i], x[j])
  len ← 2
  while len ≤ N                         // log₂N 단계
    w ← exp(−2πi / len)                   // 이 단계의 회전 인자 밑
    for s = 0, len, 2·len, … < N          // 블록마다
      t ← 1
      for k = 0 … len/2 − 1              // 나비 len/2개
        a ← x[s+k];  b ← t · x[s+k+len/2]
        x[s+k] ← a + b;  x[s+k+len/2] ← a − b
        t ← t · w
    len ← 2·len
  반환 x                                // 역변환: w의 부호를 바꾸고 N으로 나눈다
예제 8.3 (예제 8.2를 FFT로) \(\mathbf x = (1, 2, 3, 4)\).
  1. 짝수 표본 \((1, 3)\)의 2점 DFT: \(E = (1 + 3,\ 1 - 3) = (4, -2)\). 홀수 표본 \((2, 4)\): \(O = (6, -2)\).
  2. 회전 인자 \(\omega_4^0 = 1\), \(\omega_4^1 = -i\). \(X_0 = 4 + 6 = 10\), \(X_2 = 4 - 6 = -2\).
  3. \(X_1 = -2 + (-i)(-2) = -2 + 2i\), \(X_3 = -2 - (-i)(-2) = -2 - 2i\). 예제 8.2와 같다. 자명하지 않은 곱셈은 \((-i)\cdot(-2)\) 하나뿐이었다.

회전 인자 \(t \leftarrow t\cdot w\)를 반복 곱으로 만들면 반올림 오차가 쌓이므로, 정밀한 구현은 미리 \(\cos\), \(\sin\) 표를 만들어 둡니다. 그렇게 하면 FFT의 상대 오차는 \(O(\varepsilon_{\text{mach}}\log N)\)으로, 정의대로 계산한 DFT보다 오히려 정확합니다. \(N\)이 2의 거듭제곱이 아니어도 \(N = N_1N_2\)로 인수분해되면 같은 분할이 되고(혼합 기수), 소수 \(N\)도 블루스타인 방법 등으로 \(O(N\log N)\)에 계산됩니다. FFTW 같은 라이브러리는 기계에 맞는 분할 순서를 실행 중에 골라 씁니다.

빠른 합성곱과 다항식·큰 수 곱셈

백만 자리 곱셈

두 \(n\)자리 수를 초등학교 방식으로 곱하면 자릿수 곱이 \(n^2\)번입니다. 원주율을 수조 자리까지 계산하는 프로그램은 백만 자리가 훌쩍 넘는 수를 수없이 곱해야 합니다. \(n^2 = 10^{12}\)번의 곱셈을 매번 할 수는 없습니다. 곱셈의 정체를 다시 보면, 자릿수 배열의 합성곱입니다.

다항식 \(a(x) = \sum a_ix^i\)와 \(b(x) = \sum b_jx^j\)의 곱의 계수는 \(c_k = \sum_{i + j = k}a_ib_j\), 곧 계수 배열의 (선형) 합성곱(convolution) \(\mathbf c = \mathbf a * \mathbf b\)입니다. 정수 \(123 \times 45\)는 \(x = 10\)에서의 다항식 곱 \((3 + 2x + x^2)(5 + 4x)\)입니다. 직접 계산은 \(O(nm)\)인데, DFT는 합성곱을 곱셈으로 바꿉니다.

정리 8.7 (합성곱 정리) 길이 \(N\)의 원형 합성곱 \((\mathbf a \circledast \mathbf b)_k = \sum_{j=0}^{N-1}a_jb_{(k - j)\bmod N}\)에 대해
$$\mathrm{DFT}(\mathbf a \circledast \mathbf b) = \mathrm{DFT}(\mathbf a)\odot\mathrm{DFT}(\mathbf b)\qquad(\odot\text{는 성분별 곱}).$$

증명. \(\sum_k\sum_ja_jb_{k-j}\omega^{k\cdot l} = \sum_ja_j\omega^{jl}\sum_k b_{k-j}\omega^{(k-j)l}\). 안쪽 합은 \(k - j\)를 \(N\)을 법으로 한 바퀴 돌므로 \(B_l\)이다. ∎

원형 합성곱은 끝을 넘어간 항이 앞으로 감겨 들어옵니다. 다항식 곱셈에 필요한 것은 선형 합성곱이므로, 두 배열 뒤에 0을 붙여 길이를 \(N \ge n + m - 1\)로 늘리면 감겨 들 항이 모두 0이 되어 두 합성곱이 같아집니다.

함수 FFT_곱셈(a, b)                       // 길이 n, m의 계수 배열
  N ← n + m − 1 이상인 가장 작은 2의 거듭제곱
  A ← FFT(a 뒤에 0을 붙여 길이 N)
  B ← FFT(b 뒤에 0을 붙여 길이 N)
  C ← A ⊙ B                                 // N번의 곱셈
  c ← IFFT(C)의 앞 n + m − 1개
  반환 c                                    // 정수 계수면 반올림. 큰 수면 받아올림 처리
예제 8.4 (다항식과 정수)
  1. \((1 + 2x + 3x^2)(4 + 5x)\): \(\mathbf a = (1, 2, 3)\), \(\mathbf b = (4, 5)\), \(N = 4\). 합성곱 \(\mathbf c = (4,\ 5 + 8,\ 10 + 12,\ 15) = (4, 13, 22, 15)\), 곧 \(4 + 13x + 22x^2 + 15x^3\).
  2. 제로 패딩 없이 길이 3의 원형 합성곱을 하면 \(15x^3\)항이 \(x^0\)자리로 감겨 \((19, 13, 22)\)이 된다. 틀린 답이다.
  3. \(123\times45\): 낮은 자리부터 \((3, 2, 1) * (5, 4) = (15, 22, 13, 4)\). 받아올림: \(15 \to 5\) 올림 1, \(22 + 1 = 23 \to 3\) 올림 2, \(13 + 2 = 15 \to 5\) 올림 1, \(4 + 1 = 5\). 답 \(5535\).

비용은 FFT 세 번과 곱셈 \(N\)번, 합쳐서 \(O(N\log N)\)입니다. 큰 수 곱셈에서는 합성곱 값이 \(n\cdot 9^2\)까지 커지므로 부동소수점 반올림이 정수 반올림을 망치지 않도록 한 칸에 담는 자릿수를 조절하거나, 반올림 오차가 없는 수론적 변환(유한체에서의 DFT)을 씁니다. 같은 원리로 신호의 FIR 필터, 이미지 흐림(MathBook: 모든 것은 주파수의 합), 확률 분포의 합의 분포를 FFT로 계산합니다. 필터 길이가 수십 이하이면 직접 합성곱이 더 빠르고, 수백 이상이면 FFT가 이깁니다.

스펙트럼 누설, 창 함수, 제로 패딩

봉우리가 번지고 작은 성분이 묻힌다

2절의 시뮬레이터는 주파수를 정수 Hz로만 골랐습니다. 실제 신호의 주파수는 관측 시간에 정수 개의 주기가 들어맞을 이유가 없습니다. 10.5 Hz를 1초 동안 재면 스펙트럼의 봉우리가 낮아지고 옆 칸으로 넓게 번져, 근처의 약한 성분을 덮어 버립니다.

DFT는 관측한 \(N\)개 표본이 한 주기인 주기 신호라고 가정합니다. 주기가 정수 개 들어맞지 않으면 끝과 처음이 이어지는 곳에 불연속이 생기고, 불연속의 계수는 \(1/k\)로 느리게 줄었습니다(7장 정리 7.10). 수학적으로는 무한한 사인파에 길이 \(N\)의 사각 창을 곱한 것이고, 곱셈은 주파수 영역에서 창의 스펙트럼 \(|\sin(\pi k)/\sin(\pi k/N)|\)과의 합성곱입니다. 사인파 하나의 에너지가 모든 칸으로 새어 나가는 이 현상을 스펙트럼 누설(spectral leakage)이라 합니다.

처방은 신호의 양 끝을 부드럽게 0으로 줄이는 창 함수(window function) \(w_j\)를 곱한 뒤 DFT하는 것입니다. 끝의 불연속이 사라져 누설이 빠르게 줄어드는 대신, 봉우리의 폭(주엽)이 넓어집니다. 주파수 분해능과 누설 억제를 맞바꾸는 셈입니다.

표의 값은 창의 스펙트럼을 아주 촘촘히 계산해 잰 것입니다. "칸 사이 손실"은 주파수가 두 칸의 정중앙(예: 10.5)에 있을 때 봉우리가 얼마나 낮아지는지입니다. 사각 창으로 \(N = 64\), 10.5 Hz를 재면 진폭 1이 0.646(−3.79 dB)으로 읽히고 약 20칸 떨어진 곳에서도 −26 dB가 남지만, 한 창은 0.849(−1.42 dB)로 읽히고 같은 곳에서 −93 dB까지 떨어집니다.

제로 패딩(zero padding)은 표본 뒤에 0을 붙여 더 긴 DFT를 하는 것입니다. 같은 연속 스펙트럼(창을 곱한 신호의 이산 시간 푸리에 변환)을 더 촘촘한 간격으로 표본하는 효과라, 봉우리의 위치와 높이를 더 정확히 읽을 수 있습니다. 하지만 분해능, 곧 가까운 두 주파수를 구별하는 능력은 관측 시간 \(T\)로 정해진 \(1/T\)에서 나아지지 않습니다. 정보는 0을 붙인다고 늘지 않습니다. 두 성분이 1칸보다 가까우면 더 오래 측정하는 수밖에 없습니다.

응용: 오디오, 이미지 압축, 스펙트럴 미분

오디오 스펙트럼. 음악 분석기와 음성 인식은 신호를 짧은 구간(예: 44.1 kHz에서 2048표본, 약 46 ms)으로 잘라 한 창을 곱하고 FFT를 반복합니다. 이것이 단시간 푸리에 변환이고, 그 크기를 시간–주파수 평면에 그린 것이 스펙트로그램입니다. 구간 길이가 주파수 분해능(\(44100/2048 \approx 21.5\) Hz)과 시간 분해능을 맞바꿉니다.

이미지 압축 맛보기. JPEG은 영상을 \(8\times8\) 블록으로 나눠 각 블록에 2차원 이산 코사인 변환(DCT)을 합니다. DCT는 신호를 좌우 대칭으로 늘여 붙인 뒤의 DFT라, 블록 경계의 불연속이 없어 누설이 적고 에너지가 낮은 주파수 몇 개에 모입니다. 높은 주파수 계수를 거칠게 양자화하거나 버려서 용량을 줄입니다(MathBook: 모든 것은 주파수의 합). 7장의 체비쇼프 계수가 바로 DCT로 계산되었다는 것도 같은 이야기입니다.

스펙트럴 미분. 주기 함수를 미분하면 \(e^{ikx}\)의 계수가 \(ik\)배가 됩니다. 그래서 FFT → \(ik\) 곱하기 → 역 FFT로 표본점에서의 도함수를 얻습니다(짝수 \(N\)에서 나이퀴스트 계수는 0으로 둔다). 매끄러운 주기 함수에서는 7장의 해석적 함수처럼 계수가 기하급수로 줄기 때문에 오차가 \(N\)에 대해 지수적으로 줄어듭니다. 9장의 차분 공식과 비교해 봅시다.

그 밖에. 7장에서 미룬 등간격 주기 데이터의 삼각 최소제곱은 DFT 계수를 \(|k| \le n\)까지만 남기는 것입니다(이산 직교성 덕분에 정규 방정식이 대각). 2차원 FFT는 푸아송 방정식을 주기 경계에서 \(O(N^2\log N)\)에 풀고(16장), MRI는 측정한 k-공간 데이터를 2차원 역 FFT로 영상으로 바꿉니다.

핵심 정리

  1. 등간격 점 \(x_j = 2\pi j/N\)에서 \(e^{ikx}\)들은 이산 직교한다. 그래서 주기 데이터의 삼각 보간 계수는 내적 하나, 곧 DFT \(F_k = \sum f_je^{-ikx_j}\)로 바로 나온다.
  2. DFT는 \(X = F_N\mathbf x\), \((F_N)_{kj} = \omega_N^{jk}\), \(\omega_N = e^{-2\pi i/N}\). 역변환은 \(\frac1N\overline{F_N}\)이고 \(F_N/\sqrt N\)은 유니터리(파스발, \(\kappa = 1\)). 주파수 간격은 \(1/T\), 실수 신호의 진폭은 \(2|X_k|/N\)으로 읽는다.
  3. 표본화 주파수 \(f_s\)에서 \(f\)와 \(f + mf_s\), \(-f\)는 구별되지 않는다. 보이는 대역은 \([0, f_s/2]\)(나이퀴스트)이고 그 밖의 성분은 접혀 들어온다. 앨리어싱은 표본화 전에 막아야 한다.
  4. 쿨리–튜키 FFT: \(X_k = E_k + \omega_N^kO_k\), \(X_{k+N/2} = E_k - \omega_N^kO_k\). \(\log_2N\)단계 × 나비 \(N/2\)개 = \(O(N\log N)\). 입력은 비트 반전 순서, 계산은 제자리.
  5. DFT는 원형 합성곱을 성분별 곱으로 바꾼다. 길이 \(\ge n + m - 1\)로 제로 패딩하면 선형 합성곱(다항식 곱, 큰 수 곱)을 \(O(N\log N)\)에 얻는다. 패딩이 모자라면 끝 항이 앞으로 감긴다.
  6. 정수 개 주기가 아니면 스펙트럼 누설이 생긴다. 창 함수(한, 블랙먼)는 부엽을 −31 dB, −58 dB 수준으로 낮추는 대신 주엽을 넓힌다. 제로 패딩은 스펙트럼을 촘촘히 표본할 뿐 분해능 \(1/T\)는 그대로다.
  7. 매끄러운 주기 함수의 스펙트럴 미분(FFT → \(ik\) → 역 FFT)은 오차가 \(N\)에 대해 지수적으로 준다. \(e^{\sin x}\)는 \(N = 32\)에서 \(4\times10^{-15}\).

확인 퀴즈

Q1. \(\mathbf x = (1, 0, -1, 0)\)의 DFT \(X = (X_0, X_1, X_2, X_3)\)는?

\(\omega_4 = -i\). \(X_0 = 1 - 1 = 0\), \(X_1 = 1 + (-1)(-1) = 2\), \(X_2 = 1 + (-1)(1) = 0\), \(X_3 = 1 + (-1)(-1) = 2\). 신호가 \(\cos(\pi j/2)\)이므로 \(k = 1\)과 \(k = 3 = -1\)에 \(N/2 = 2\)씩 나타난다.

Q2. 초당 1000번 표본화한 신호에서 스펙트럼에 120 Hz 봉우리가 보였다. 실제 신호가 될 수 없는 주파수는?

겉보기 주파수는 \(|f - 1000m|\)이다. 880 → 120, 1120 → 120. 620 Hz는 \(|620 - 1000| = 380\)으로 보인다. 나이퀴스트 500 Hz 위의 성분은 500을 기준으로 접혀 들어온다.

Q3. \(N = 4096\)일 때 기수 2 FFT의 나비 연산 수는?

\(\log_2 4096 = 12\)단계, 단계마다 \(N/2 = 2048\)개. \(12\times2048 = 24576\). 직접 DFT의 \(N^2 = 16{,}777{,}216\)과 비교하면 약 680배 적다.

Q4. 8점 FFT의 비트 반전 재배열에서 인덱스 3은 어디로 가는가?

\(3 = 011_2\)을 뒤집으면 \(110_2 = 6\). 전체 순서는 0, 4, 2, 6, 1, 5, 3, 7이다.

Q5. 길이 300과 길이 200의 배열을 FFT로 선형 합성곱하려 한다. 감김 없이 쓸 수 있는 가장 짧은 2의 거듭제곱 FFT 길이는?

결과 길이는 \(300 + 200 - 1 = 499\)이므로 \(N \ge 499\), 2의 거듭제곱으로 512. 256으로 하면 원형 합성곱의 감김이 생긴다.

Q6. 1초 동안 잰 신호에 10.0 Hz와 10.4 Hz 성분이 있다. 두 성분을 구별하려면?

분해능은 관측 시간의 역수 \(1/T = 1\) Hz다. 0.4 Hz 차이를 가르려면 \(T\)가 적어도 \(1/0.4 = 2.5\)초, 창의 주엽 폭까지 생각하면 그 몇 배가 필요하다. 제로 패딩과 표본화 주파수는 \(T\)를 바꾸지 않고, 창은 주엽을 오히려 넓힌다.

Q7. 사각 창 대신 한 창을 쓸 때의 변화로 옳은 것은?

창 함수는 누설(부엽)과 분해능(주엽 폭)을 맞바꾼다. 한 창의 주엽 반폭은 2칸으로 사각의 1칸보다 넓다. 정수 칸 주파수의 한 창 스펙트럼은 이웃 두 칸에 −6 dB씩 퍼지지만 그 밖의 칸에는 새지 않는다.

Q8. 매끄러운 주기 함수의 도함수를 스펙트럴 방법으로 계산할 때 오차의 거동은?

해석적 주기 함수의 푸리에 계수는 기하급수로 줄기 때문에, 계수를 N/2까지 쓰는 스펙트럴 미분의 오차도 지수적으로 준다. 예제 8.5에서 e^(sin x)는 N = 32에서 10⁻¹⁵ 수준이었다.
