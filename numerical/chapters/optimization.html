Chapter 15

수치 최적화

최적화는 "가장 좋은 것"을 찾는 일입니다. 오차가 가장 작은 곡선, 무게가 가장 가벼운 빔, 손실이 가장 작은 신경망. 수학적으로는 함수 \(f(\mathbf x)\)의 최솟값을 찾는 문제이고, 미적분은 그 답이 \(\nabla f = \mathbf 0\)인 곳에 있다고 말해 줍니다. 그러나 \(\nabla f = \mathbf 0\)은 대개 풀 수 없는 비선형 연립방정식이고, 도함수가 아예 없거나, 변수가 수백만 개이거나, 데이터가 너무 많아 \(f\) 한 번 계산하기도 버겁습니다. 이 장은 내리막을 따라 한 걸음씩 가는 반복법의 공학입니다. 1차원 구간을 줄이는 황금 분할에서 출발해 경사 하강과 직선 탐색, 조건수가 만드는 지그재그와 모멘텀, 곡률을 쓰는 뉴턴과 그 값싼 대용품 BFGS, 도함수 없는 넬더–미드, 곡선 맞춤의 레벤버그–마쿼트, 제약 조건, 데이터가 많을 때의 확률적 경사 하강, 그리고 국소 최솟값의 함정에서 빠져나오는 담금질 기법까지 갑니다.

  • 단봉 함수에서 황금 분할 탐색이 구간을 매번 0.618배로 줄이는 이유를 설명하고, 포물선 보간과 결합한 브렌트 방법의 아이디어를 안다.
  • 하강 방향과 아르미호 조건을 정의하고, 되돌아가기 직선 탐색을 손으로 수행한다.
  • 이차 함수에서 경사 하강의 수렴률 \((\kappa - 1)/(\kappa + 1)\)을 조건수로 설명하고, 모멘텀이 이를 \((\sqrt\kappa - 1)/(\sqrt\kappa + 1)\)로 줄이는 효과를 측정한다.
  • 뉴턴 방법의 2차 수렴과 헤세 행렬이 양정치가 아닐 때의 실패를 알고, BFGS의 할선 조건과 갱신 공식을 쓴다.
  • 넬더–미드 심플렉스의 반사·확장·수축·축소 규칙을 따라가고, 비선형 최소제곱을 가우스–뉴턴과 레벤버그–마쿼트로 푼다.
  • 벌칙법·라그랑주 승수·KKT 조건으로 제약 최적화를 다루고, 확률적 경사 하강과 담금질 기법이 왜 필요한지 설명한다.

음성 인식기와 번역기 안의 신경망은 수십억 개의 숫자로 이루어져 있고, 그 숫자들은 누가 손으로 정한 것이 아니라 "예측이 틀린 정도"를 나타내는 함수를 줄이는 방향으로 수없이 조금씩 고쳐서 얻었습니다. 항공기 날개와 자동차 차체의 모양, 반도체 공정의 조건, GPS 수신기가 위성 신호에서 위치를 뽑는 계산, 실험 데이터에 모델 곡선을 맞추는 일도 모두 어떤 함수를 가장 작게 만드는 문제입니다. 이 함수들은 식으로 풀리지 않으니, 답은 반복으로만 얻습니다.

기울기를 따라 내려가는 생각은 코시(Augustin-Louis Cauchy)가 1847년에 연립방정식을 풀려고 제안한 것으로 알려져 있습니다. 20세기 중반 이후 컴퓨터와 함께 준뉴턴 방법(BFGS), 넬더–미드 심플렉스, 레벤버그–마쿼트 같은 오늘날의 표준 도구가 나왔고, SciPy의 minimize와 least_squares, MATLAB의 fminunc·fminsearch·lsqnonlin, 딥러닝 프레임워크의 옵티마이저가 그것들을 구현합니다.

1차원 최소화: 황금 분할 탐색과 포물선 보간

도함수 없이 골짜기 바닥 찾기

배관의 지름을 키우면 재료비가 늘고 펌프 동력비가 줄어듭니다. 총비용 \(f(d)\)는 어딘가에서 최소가 되지만, \(f\)를 한 번 계산하려면 유동 시뮬레이션을 한 번 돌려야 해서 도함수는 구할 수 없습니다. 함숫값 비교만으로 최소점을 가둬 갈 수 있을까요? 3장의 이분법은 부호 하나로 근을 가뒀습니다. 최솟값을 가두려면 점이 몇 개 필요할까요?

근은 부호가 바뀌는 두 점이면 가둬지지만, 최솟값은 세 점이 필요합니다. \(a \lt c \lt b\)이고 \(f(c) \lt f(a)\), \(f(c) \lt f(b)\)이면 연속함수의 최솟값은 \((a, b)\) 안에 있습니다. 가운데가 양 끝보다 낮은 "골짜기 모양"이기 때문입니다.

정의 15.1 (단봉 함수와 최소 가둠) \([a, b]\)의 어떤 점 \(x^*\)에 대해 \(f\)가 \([a, x^*]\)에서 감소하고 \([x^*, b]\)에서 증가하면 \(f\)를 \([a, b]\)에서 단봉 함수(unimodal function)라 한다. 단봉 함수에서 두 내부 점 \(c \lt d\)를 비교하면 \(f(c) \lt f(d)\)일 때 \(x^* \in [a, d]\), 그렇지 않으면 \(x^* \in [c, b]\)이다.

두 내부 점을 비교할 때마다 구간의 일부를 버립니다. 남는 점 하나는 다음 단계에서 다시 쓰고 싶습니다. 그러면 단계마다 \(f\)를 한 번만 새로 계산하면 됩니다. 구간 길이를 1로 두고 내부 점을 \(c = 1 - \tau\), \(d = \tau\)에 놓았다고 합시다. \([0, \tau]\)가 남으면 옛 \(c = 1 - \tau\)가 새 구간의 \(d\) 자리 \(\tau\cdot\tau\)에 와야 하므로 \(1 - \tau = \tau^2\), 곧

$$\tau^2 + \tau - 1 = 0 \quad\Longrightarrow\quad \tau = \frac{\sqrt5 - 1}{2} = 0.6180339\ldots$$
황금비 \(\varphi = 1.618\ldots\)의 역수 \(1/\varphi\). 이 비율로 점을 놓으면 버리고 남은 구간 안에서 옛 점이 다시 같은 비율의 자리에 놓인다.
function golden(f, a, b, tol)
  t = (sqrt(5) - 1) / 2                // 0.618...
  c = b - t*(b - a);  fc = f(c)
  d = a + t*(b - a);  fd = f(d)
  while b - a > tol
    if fc < fd then                   // 최소는 [a, d]
      b = d;  d = c;  fd = fc
      c = b - t*(b - a);  fc = f(c)
    else                               // 최소는 [c, b]
      a = c;  c = d;  fc = fd
      d = a + t*(b - a);  fd = f(d)
  return (a + b) / 2
정리 15.2 (황금 분할 탐색의 수렴) \(f\)가 \([a_0, b_0]\)에서 단봉이면 황금 분할 탐색의 \(k\)번째 구간은 최소점을 포함하고 길이가 \(\tau^k(b_0 - a_0)\), \(\tau = 0.618\)이다. 따라서 오차는 1차 수렴(점근 상수 0.618)하고, 구간 길이를 \(\varepsilon\) 이하로 만드는 데 필요한 함수 계산은 약 \(\log(\varepsilon/(b_0 - a_0))/\log\tau\)번이다.

왜 이분법보다 느린가. 이분법은 한 번에 1/2로 줄였다. 최소 탐색은 비교에 점 두 개가 필요하고 한 점만 재사용할 수 있으므로 함수 계산당 0.618이 최선이다(점 두 개를 매번 새로 놓으면 계산 두 번에 1/2, 곧 계산당 \(1/\sqrt2 \approx 0.707\)). 피보나치 탐색이 정해진 계산 횟수에서 아주 조금 더 낫지만 극한에서 같은 비율이다. ∎

$$x_3 = x_1 - \frac12\,\frac{(x_1 - x_0)^2(f_1 - f_2) - (x_1 - x_2)^2(f_1 - f_0)}{(x_1 - x_0)(f_1 - f_2) - (x_1 - x_2)(f_1 - f_0)}$$

예제 15.1의 함수에 \(x = 0, 1, 2\)에서 출발해 적용하면 오차가 \(9.8\times10^{-2}\), \(3.7\times10^{-2}\), \(1.2\times10^{-2}\), \(4.8\times10^{-4}\), \(7.6\times10^{-5}\), \(1.1\times10^{-6}\), \(5.9\times10^{-9}\), \(1.3\times10^{-10}\)으로 줄어듭니다. 여덟 번에 황금 분할의 서른 번 이상보다 정확합니다. 수렴 차수는 \(p^3 = p + 1\)의 실근 \(p \approx 1.3247\)로 알려진 초선형입니다. 그 대신 포물선이 위로 볼록하거나 세 점이 거의 일직선이면 엉뚱한 곳으로 뛰거나 분모가 0이 됩니다. 그래서 실무의 브렌트 방법(Brent's method)은 최소 가둠 구간을 늘 유지하면서, 포물선 걸음이 구간 안에 떨어지고 충분히 줄어들 때만 받아들이고 그렇지 않으면 황금 분할 걸음을 씁니다. 3장의 브렌트 근 찾기와 같은 "빠른 방법 + 안전망" 설계입니다. 경사 하강과 직선 탐색: 아르미호 조건

얼마나 멀리 걸을까

여러 변수 함수에서 가장 가파른 내리막은 \(-\nabla f\) 방향입니다(CalculusBook 15장). 방향은 알았지만 걸음 크기가 문제입니다. 너무 크면 골짜기 건너편 벽으로 올라가 버리고, 너무 작으면 영원히 걷습니다. \(f(x, y) = x^2 + 10y^2\)에서 \((1, 1)\)부터 걸음 \(\alpha = 1\)로 \(-\nabla f = (-2, -20)\)을 따라가면 함숫값이 11에서 3611로 뜁니다. 매 걸음 적당한 \(\alpha\)를 싸게 고르는 규칙이 필요합니다.

일반적인 반복은 \(\mathbf x_{k+1} = \mathbf x_k + \alpha_k\mathbf p_k\)입니다. \(\mathbf p_k\)는 방향, \(\alpha_k > 0\)은 걸음 크기입니다. \(\nabla f_k^{\mathsf T}\mathbf p_k \lt 0\)이면 \(\mathbf p_k\)를 하강 방향(descent direction)이라 합니다. 테일러 전개 \(f(\mathbf x_k + \alpha\mathbf p_k) = f(\mathbf x_k) + \alpha\nabla f_k^{\mathsf T}\mathbf p_k + O(\alpha^2)\)에서 충분히 작은 \(\alpha\)는 반드시 \(f\)를 줄입니다. 경사 하강(gradient descent)은 \(\mathbf p_k = -\nabla f_k\)를 씁니다.

걸음 크기는 1변수 함수 \(\varphi(\alpha) = f(\mathbf x_k + \alpha\mathbf p_k)\)를 줄이는 1차원 문제, 곧 직선 탐색(line search)입니다. 앞 절의 방법으로 \(\varphi\)를 정확히 최소화할 수도 있지만 그것은 낭비입니다. 우리가 원하는 것은 충분히 줄이는 것뿐입니다.

정의 15.3 (아르미호 조건과 되돌아가기) 상수 \(0 \lt c \lt 1\)(흔히 \(c = 10^{-4}\))에 대해
$$f(\mathbf x_k + \alpha\mathbf p_k) \le f(\mathbf x_k) + c\,\alpha\,\nabla f_k^{\mathsf T}\mathbf p_k$$
를 아르미호 조건(Armijo condition, sufficient decrease)이라 한다. 오른쪽은 기울기 \(\varphi'(0)\)를 \(c\)배로 완만하게 만든 직선이다. 되돌아가기 직선 탐색(backtracking)은 \(\alpha = 1\)에서 시작해 이 조건을 만족할 때까지 \(\alpha \leftarrow \rho\alpha\)(흔히 \(\rho = 1/2\))로 줄인다.
function backtrack(f, x, p, g, c = 1e-4, rho = 0.5)
  alpha = 1;  fx = f(x);  slope = dot(g, p)   // slope < 0 이어야 한다
  while f(x + alpha*p) > fx + c*alpha*slope
    alpha = rho * alpha
  return alpha

function gradient_descent(f, grad, x, tol)
  while norm(grad(x)) > tol
    g = grad(x);  p = -g
    x = x + backtrack(f, x, p, g) * p
  return x

  1. \(\nabla f = (2x, 20y) = (2, 20)\), \(\|\nabla f\|^2 = 404\), \(f(\mathbf x_0) = 11\). 아르미호 직선은 \(11 - 0.0404\,\alpha\).

  3. \(\alpha = 1/16\): 새 점 \((0.875, -0.25)\), \(f = 1.3906 \le 10.9975\). 채택.
  4. 둘째 걸음도 \(\alpha = 1/16\)에서 \((0.765625, 0.0625)\), \(f = 0.6252\). 셋째는 \(\alpha = 1/8\)에서 \((0.574219, -0.09375)\), \(f = 0.4176\). \(y\)는 부호를 바꾸며 출렁이고 \(x\)는 느리게 준다. 다음 절의 주제다.

아르미호 조건은 "너무 긴 걸음"만 막습니다. "너무 짧은 걸음"은 되돌아가기가 \(\alpha = 1\)에서 출발해 필요한 만큼만 줄이는 것으로 막습니다. 준뉴턴 방법처럼 \(\alpha = 1\)이 자연스러운 방법에는 기울기 조건 \(\nabla f(\mathbf x_k + \alpha\mathbf p_k)^{\mathsf T}\mathbf p_k \ge c_2\nabla f_k^{\mathsf T}\mathbf p_k\)(\(c \lt c_2 \lt 1\))를 더한 울프 조건(Wolfe conditions)을 씁니다. 이 두 조건만으로 다음이 보장됩니다.

정리 15.4 (되돌아가기 경사 하강의 수렴) \(f\)가 아래로 유계이고 \(\nabla f\)가 립시츠 상수 \(L\)을 가지면(\(\|\nabla f(\mathbf x) - \nabla f(\mathbf y)\| \le L\|\mathbf x - \mathbf y\|\)), 되돌아가기 경사 하강이 고르는 걸음은 \(\alpha_k \ge \min\{1,\ 2\rho(1 - c)/L\}\)이고 \(\sum_k\|\nabla f_k\|^2 \lt \infty\), 따라서 \(\|\nabla f_k\| \to 0\)이다.

증명의 핵심. 립시츠 조건에서 \(f(\mathbf x - \alpha\mathbf g) \le f(\mathbf x) - \alpha(1 - \frac{L\alpha}{2})\|\mathbf g\|^2\)이므로 \(\alpha \le 2(1 - c)/L\)이면 아르미호 조건이 성립한다. 되돌아가기는 그런 \(\alpha\)를 \(\rho\)배 이상 지나쳐 줄이지 않는다. 그러면 매 걸음 \(f\)가 \(c\,\alpha_{\min}\|\nabla f_k\|^2\) 이상 줄고, \(f\)가 아래로 유계이므로 그 합은 유한하다. ∎

정리는 정류점(\(\nabla f = \mathbf 0\))으로 간다는 것만 말합니다. 그것이 최솟값인지, 얼마나 빨리 가는지는 말하지 않습니다. 속도는 함수의 모양, 정확히는 헤세 행렬의 조건수가 정합니다.

조건수와 지그재그, 그리고 모멘텀

좁고 긴 골짜기

예제 15.2에서 \(y\)는 금방 0 근처로 갔지만 \(x\)는 한 걸음에 10~25%씩밖에 줄지 않았습니다. 골짜기가 \(y\) 방향으로는 가파르고(\(\partial^2 f/\partial y^2 = 20\)) \(x\) 방향으로는 완만해서(\(= 2\)), 가파른 쪽 벽에 맞춰 걸음을 줄이면 완만한 쪽으로는 거의 나아가지 못합니다. 이 비 \(20/2 = 10\)이 무엇을 정하는지 정확히 알아봅시다.

최솟값 근처의 매끄러운 함수는 이차 함수 \(f(\mathbf x) = \frac12\mathbf x^{\mathsf T}A\mathbf x\)(\(A\)는 대칭 양정치)처럼 보입니다. 고유값을 \(0 \lt \mu = \lambda_{\min} \le \dots \le \lambda_{\max} = L\)이라 하고 조건수 \(\kappa = L/\mu\)를 둡니다(12장의 행렬 조건수와 같은 양). 등고선은 축 길이 비가 \(\sqrt\kappa\)인 타원입니다.

정리 15.5 (이차 함수에서 경사 하강의 수렴률) 이차 함수에 고정 걸음 \(\alpha\)의 경사 하강을 쓰면 오차는 \(\mathbf e_{k+1} = (I - \alpha A)\mathbf e_k\)이고, 가장 좋은 고정 걸음 \(\alpha = 2/(L + \mu)\)에서
$$\|\mathbf e_{k+1}\| \le \frac{\kappa - 1}{\kappa + 1}\,\|\mathbf e_k\|.$$
정확한 직선 탐색을 쓰면 함숫값에 대해 \(f(\mathbf x_{k+1}) - f^* \le \left(\frac{\kappa - 1}{\kappa + 1}\right)^2\bigl(f(\mathbf x_k) - f^*\bigr)\)이다(칸토로비치 부등식).

증명의 핵심. \(I - \alpha A\)의 고유값은 \(1 - \alpha\lambda_i\)다. 그 절댓값의 최대 \(\max(|1 - \alpha\mu|, |1 - \alpha L|)\)는 두 값이 같아지는 \(\alpha = 2/(L + \mu)\)에서 가장 작고, 그 값이 \((L - \mu)/(L + \mu)\)다. 13장의 반복 해법에서 스펙트럼 반지름이 수렴률을 정한 것과 같은 계산이다. 실제로 경사 하강은 \(A\mathbf x = \mathbf 0\)에 쓴 리처드슨 반복이다. ∎

\(\kappa = 100\)이면 수렴률은 \(99/101 = 0.980\)이고, 오차를 \(10^{-6}\)배로 줄이려면 \(\ln 10^{-6}/\ln 0.980 = 691\)걸음이 필요합니다. \(\kappa\)에 비례하는 걸음 수입니다. 정확한 직선 탐색도 소용없습니다. 걸음마다 그 방향으로는 최소가 되므로 다음 기울기는 지금 방향에 수직이고, 경로는 직각으로 꺾이는 지그재그가 됩니다.

예제 15.3 (지그재그의 비율) \(f = \frac12(x^2 + 10y^2)\)(\(\kappa = 10\))를 \((10, 1)\)에서 정확한 직선 탐색으로 경사 하강하라.
  1. \(f_0 = \frac12(100 + 10) = 55\). 걸음 크기는 \(\alpha = \mathbf g^{\mathsf T}\mathbf g/\mathbf g^{\mathsf T}A\mathbf g\)(이차 함수에서 \(\varphi'(\alpha) = 0\)의 해).
  2. \(\mathbf x_1 = (8.1818, -0.8182)\), \(f_1 = 36.8182\). \(\mathbf x_2 = (6.6942, 0.6694)\), \(f_2 = 24.6469\). \(\mathbf x_3 = (5.4771, -0.5477)\), \(f_3 = 16.4992\).
  3. 비율 \(f_{k+1}/f_k = 0.6694\)가 매번 같고, 이는 정리 15.5의 상한 \((9/11)^2 = 0.6694\)와 정확히 같다. 이 출발점은 최악의 경우다. \(y\)의 부호가 매번 바뀌는 것이 지그재그다.

지그재그를 줄이는 오래된 처방은 관성입니다. 언덕을 구르는 무거운 공은 가파른 벽 사이를 오가는 성분은 서로 상쇄하고, 골짜기를 따라 일정하게 미는 성분은 쌓아 갑니다.

정의 15.6 (모멘텀, 무거운 공 방법) \(\mathbf x_{k+1} = \mathbf x_k - \alpha\nabla f(\mathbf x_k) + \beta(\mathbf x_k - \mathbf x_{k-1})\), \(0 \le \beta \lt 1\). 마지막 항이 직전 걸음을 \(\beta\)만큼 이어 가는 모멘텀(momentum, heavy ball)이다. 폴랴크(Boris Polyak)의 이름과 함께 알려져 있다.
정리 15.7 (모멘텀의 가속) 이차 함수에서 \(\alpha = 4/(\sqrt L + \sqrt\mu)^2\), \(\beta = \left(\frac{\sqrt\kappa - 1}{\sqrt\kappa + 1}\right)^2\)로 두면 오차는 점근적으로 걸음마다
$$\frac{\sqrt\kappa - 1}{\sqrt\kappa + 1}$$
배로 줄어든다. \(\kappa = 100\)이면 \(9/11 = 0.818\), 오차 \(10^{-6}\)까지 약 69걸음으로 경사 하강의 691걸음보다 10배 적다. 필요한 걸음 수가 \(\kappa\)가 아니라 \(\sqrt\kappa\)에 비례한다. 13장의 켤레 기울기법이 같은 \(\sqrt\kappa\) 법칙을 직선 탐색과 A-직교 방향으로 얻는다.

네스테로프(Yurii Nesterov)의 가속 경사법은 기울기를 "모멘텀으로 미리 가 본 점"에서 재는 변형으로, 이차 함수가 아닌 볼록 함수에서도 비슷한 가속을 보장합니다. 딥러닝 옵티마이저의 momentum=0.9가 이 \(\beta\)입니다. 다만 \(\beta\)를 너무 크게 두면 공이 골짜기 바닥을 지나쳐 오래 출렁입니다.

뉴턴 방법과 헤세 행렬

곡률을 알면 한 번에

이차 함수 \(f = \frac12\mathbf x^{\mathsf T}A\mathbf x - \mathbf b^{\mathsf T}\mathbf x\)의 최소점은 \(A\mathbf x = \mathbf b\)의 해입니다. 기울기만 쓰는 방법은 수백 걸음이 걸리지만, \(A\)를 알면 연립방정식 한 번으로 끝납니다. 일반 함수에서도 매 점에서 이차 근사를 만들고 그 최소점으로 건너뛰면 어떨까요?

\(\mathbf x_k\) 근처의 2차 테일러 근사 \(m(\mathbf p) = f_k + \nabla f_k^{\mathsf T}\mathbf p + \frac12\mathbf p^{\mathsf T}\nabla^2 f_k\,\mathbf p\)를 최소화하면 \(\nabla^2 f_k\,\mathbf p = -\nabla f_k\)입니다. \(\nabla^2 f\)는 2계 편도함수의 행렬, 곧 헤세 행렬(Hessian)입니다(CalculusBook 15장: 임계점 판정).

정의 15.8 (최적화의 뉴턴 방법) \(\nabla^2 f(\mathbf x_k)\,\mathbf p_k = -\nabla f(\mathbf x_k)\)를 풀고 \(\mathbf x_{k+1} = \mathbf x_k + \alpha_k\mathbf p_k\)로 간다. \(\alpha_k = 1\)이면 순수 뉴턴, 직선 탐색으로 고르면 감쇠 뉴턴이다. 이것은 4장의 다변수 뉴턴 방법을 방정식 \(\nabla f = \mathbf 0\)에 쓴 것이다(야코비안 = 헤세 행렬).
정리 15.9 (뉴턴 방법의 2차 수렴) \(\nabla^2 f\)가 립시츠 연속이고 최소점 \(\mathbf x^*\)에서 양정치이면, \(\mathbf x^*\)에 충분히 가까운 곳에서 순수 뉴턴 방법은 \(\|\mathbf x_{k+1} - \mathbf x^*\| \le C\|\mathbf x_k - \mathbf x^*\|^2\)으로 수렴한다. 또 뉴턴 걸음은 좌표의 선형 변환에 영향을 받지 않으므로(아핀 불변) 조건수가 수렴 속도에 들어가지 않는다.

증명의 핵심. \(\nabla f(\mathbf x^*) = \mathbf 0\)에서 \(\mathbf x_{k+1} - \mathbf x^* = \nabla^2 f_k^{-1}\bigl[\nabla^2 f_k(\mathbf x_k - \mathbf x^*) - (\nabla f_k - \nabla f(\mathbf x^*))\bigr]\)이고, 괄호 안은 적분형 테일러 나머지로 \((M/2)\|\mathbf x_k - \mathbf x^*\|^2\) 이하다(\(M\)은 헤세 행렬의 립시츠 상수). 3장 정리 3.8의 다변수판이다. ∎

대가는 둘입니다. 첫째, 헤세 행렬을 계산하고 \(n\times n\) 연립방정식을 풀어야 하므로 한 걸음에 약 \(n^3/3\)번(촐레스키, 12장)의 연산이 듭니다. 둘째, 헤세 행렬이 양정치가 아니면 이차 근사에 최솟값이 없고, \(\mathbf p_k\)가 오르막이나 안장점 쪽을 가리킬 수 있습니다. 그래서 실무의 뉴턴 방법은 직선 탐색을 붙이고, \(\nabla^2 f_k\)가 양정치가 아니면 \(\nabla^2 f_k + \tau I\)처럼 대각을 키워 양정치로 만듭니다(수정 뉴턴). 큰 \(\tau\)에서는 걸음이 \(-\nabla f/\tau\), 곧 짧은 경사 하강이 됩니다.

준뉴턴 방법: BFGS

헤세 행렬 없이 곡률 배우기

변수가 1000개인 설계 문제에서 헤세 행렬은 50만 개(대칭이라 절반)의 2계 도함수이고, 한 걸음에 \(10^9\)번 가까운 연산의 선형계를 풀어야 합니다. 그런데 매 걸음 기울기는 어차피 계산합니다. 두 점의 기울기 차이에는 곡률 정보가 들어 있습니다. 그것만으로 뉴턴에 가까운 속도를 낼 수 있을까요?

1차원에서 \(f''(x_{k+1}) \approx (f'_{k+1} - f'_k)/(x_{k+1} - x_k)\), 곧 할선 기울기입니다(3장의 할선법). 다변수에서 \(\mathbf s_k = \mathbf x_{k+1} - \mathbf x_k\), \(\mathbf y_k = \nabla f_{k+1} - \nabla f_k\)라 하면 헤세 행렬의 근삿값 \(B_{k+1}\)에 대해 할선 조건 \(B_{k+1}\mathbf s_k = \mathbf y_k\)를 요구합니다. 방정식은 \(n\)개인데 미지수는 \(n(n+1)/2\)개이므로, 지금의 \(B_k\)에서 가장 조금 바꾸는 것을 고릅니다. 4장의 브로이든 방법도 같은 생각이었습니다. 최적화에서 가장 성공한 공식은 1970년에 브로이든, 플레처, 골드파브, 샤노(Broyden, Fletcher, Goldfarb, Shanno)가 각각 발표한 BFGS 갱신입니다.

정의 15.10 (BFGS 갱신) 역헤세 근사 \(H_k \approx (\nabla^2 f_k)^{-1}\)를 두고 \(\mathbf p_k = -H_k\nabla f_k\), 울프 조건을 만족하는 \(\alpha_k\)로 걸은 뒤 \(\rho_k = 1/(\mathbf y_k^{\mathsf T}\mathbf s_k)\)로
$$H_{k+1} = \bigl(I - \rho_k\,\mathbf s_k\mathbf y_k^{\mathsf T}\bigr)\,H_k\,\bigl(I - \rho_k\,\mathbf y_k\mathbf s_k^{\mathsf T}\bigr) + \rho_k\,\mathbf s_k\mathbf s_k^{\mathsf T}.$$
\(H_{k+1}\mathbf y_k = \mathbf s_k\)(할선 조건)를 만족한다. 행렬–벡터 곱과 바깥곱만 쓰므로 한 걸음에 \(O(n^2)\) 연산, 선형계 풀이가 없다. 흔히 \(H_0 = I\)로 시작한다.
정리 15.11 (BFGS의 성질) (1) \(H_k\)가 대칭 양정치이고 \(\mathbf y_k^{\mathsf T}\mathbf s_k > 0\)이면 \(H_{k+1}\)도 대칭 양정치다. 따라서 \(\mathbf p_k\)는 언제나 하강 방향이다. 울프 조건의 기울기 조건이 \(\mathbf y_k^{\mathsf T}\mathbf s_k > 0\)을 보장한다. (2) 최소점에서 헤세 행렬이 양정치이고 립시츠 연속이면 BFGS는 초선형으로 수렴한다: \(\|\mathbf x_{k+1} - \mathbf x^*\|/\|\mathbf x_k - \mathbf x^*\| \to 0\).

(1)의 핵심. 임의의 \(\mathbf z \ne \mathbf 0\)에 대해 \(\mathbf w = \mathbf z - \rho_k(\mathbf s_k^{\mathsf T}\mathbf z)\mathbf y_k\)라 하면 \(\mathbf z^{\mathsf T}H_{k+1}\mathbf z = \mathbf w^{\mathsf T}H_k\mathbf w + \rho_k(\mathbf s_k^{\mathsf T}\mathbf z)^2\). 두 항 모두 0 이상이고, 둘 다 0이려면 \(\mathbf s_k^{\mathsf T}\mathbf z = 0\)이고 \(\mathbf w = \mathbf z = \mathbf 0\)이어야 한다. ∎

function bfgs(f, grad, x, tol)
  H = I;  g = grad(x)
  while norm(g) > tol
    p = -H * g
    alpha = line_search(f, x, p, g)      // 울프 조건, 처음 시도는 alpha = 1
    s = alpha * p;  x = x + s
    g_new = grad(x);  y = g_new - g;  g = g_new
    if dot(y, s) > 0 then                // 곡률 조건이 깨지면 갱신을 건너뛴다
      r = 1 / dot(y, s)
      H = (I - r*s*y') * H * (I - r*y*s') + r*s*s'
  return x

변수가 수만 개 이상이면 \(n\times n\) 행렬 \(H\)를 저장하는 것조차 부담입니다. L-BFGS(limited-memory BFGS)는 최근 \(m\)개(흔히 5~20)의 \((\mathbf s, \mathbf y)\) 쌍만 저장하고 \(H\nabla f\)를 두 번의 루프로 직접 계산합니다. 메모리와 연산이 \(O(mn)\)이라, 기상 자료 동화나 큰 회귀 모델처럼 변수가 수백만 개인 문제의 표준입니다.

도함수 없는 방법: 넬더–미드 심플렉스

시뮬레이터는 기울기를 주지 않는다

회로 시뮬레이터나 유한 요소 해석 프로그램은 설계 변수를 넣으면 성능 숫자 하나를 돌려줄 뿐입니다. 결과에 잡음이 섞이거나 매끄럽지 않은 경우도 많습니다. 9장의 수치 미분으로 기울기를 어림할 수도 있지만 변수마다 계산이 한 번씩 더 들고, 잡음이 있으면 차분 몫이 엉망이 됩니다. 함숫값의 크기 비교만으로 여러 변수에서 내려갈 수 있을까요?

1965년 넬더와 미드(John Nelder, Roger Mead)가 발표한 방법은 \(n\)차원에서 꼭짓점 \(n + 1\)개의 심플렉스(2차원에서는 삼각형)를 굴립니다. 가장 나쁜 꼭짓점을 나머지의 무게중심 반대편으로 뒤집고, 그쪽이 좋으면 더 늘리고, 나쁘면 줄입니다. 삼각형이 골짜기를 따라 아메바처럼 기어가다 바닥에서 오그라듭니다.

정의 15.12 (넬더–미드 방법의 한 단계) 꼭짓점을 \(f(\mathbf x_1) \le \dots \le f(\mathbf x_{n+1})\)로 정렬하고, 가장 나쁜 점을 뺀 무게중심 \(\bar{\mathbf x}\)를 구한다.
  1. 반사 \(\mathbf x_r = \bar{\mathbf x} + (\bar{\mathbf x} - \mathbf x_{n+1})\). \(f_1 \le f_r \lt f_n\)이면 \(\mathbf x_{n+1}\)을 \(\mathbf x_r\)로 바꾼다.
  2. 확장: \(f_r \lt f_1\)이면 \(\mathbf x_e = \bar{\mathbf x} + 2(\bar{\mathbf x} - \mathbf x_{n+1})\)을 계산해 \(f_e \lt f_r\)이면 \(\mathbf x_e\), 아니면 \(\mathbf x_r\)을 받는다.
  3. 수축: \(f_r \ge f_n\)이면 \(f_r \lt f_{n+1}\)일 때 바깥 수축 \(\bar{\mathbf x} + \frac12(\mathbf x_r - \bar{\mathbf x})\), 아니면 안쪽 수축 \(\bar{\mathbf x} + \frac12(\mathbf x_{n+1} - \bar{\mathbf x})\)을 시도해, 더 나으면 받는다.
  4. 축소: 수축도 실패하면 모든 점을 가장 좋은 점 쪽으로 절반 당긴다: \(\mathbf x_i \leftarrow \mathbf x_1 + \frac12(\mathbf x_i - \mathbf x_1)\).
예제 15.5 (넬더–미드 세 단계) \(f(x, y) = x^2 - 4x + y^2 - y - xy\)(최소점 \((3, 2)\), \(f^* = -7\)), 처음 삼각형 \((0, 0)\), \((1.2, 0)\), \((0, 0.8)\).
  1. \(f\) 값은 \((1.2, 0)\): −3.36, \((0, 0.8)\): −0.16, \((0, 0)\): 0. 가장 나쁜 점 \((0, 0)\)을 뺀 무게중심 \(\bar{\mathbf x} = (0.6, 0.4)\). 반사점 \((1.2, 0.8)\), \(f_r = -4.48\)은 가장 좋은 −3.36보다 좋으므로 확장점 \((1.8, 1.2)\)을 보면 \(f_e = -5.88\). 확장 채택.
  2. 새 삼각형에서 가장 나쁜 점 \((0, 0.8)\), 무게중심 \((1.5, 0.6)\). 반사점 \((3, 0.4)\), \(f_r = -4.44\)는 가장 좋은 −5.88과 둘째 −3.36 사이. 반사 채택.
  3. 가장 나쁜 점 \((1.2, 0)\), 무게중심 \((2.4, 0.8)\). 반사점 \((3.6, 1.6)\), \(f_r = -6.24\)로 최고 기록. 확장점 \((4.8, 2.4)\)은 \(f_e = -4.32\)로 더 나쁘므로 반사점을 받는다.
  4. 계속하면 51단계 뒤 삼각형의 지름이 \(10^{-6}\) 아래로 줄고 가장 좋은 꼭짓점은 \((3.0000004, 2.0000001)\)이다.

넬더–미드는 단순하고 잡음에 강해서 지금도 MATLAB의 fminsearch와 SciPy의 method="Nelder-Mead"로 널리 쓰입니다. 그러나 이론적 보장이 약합니다. 맥키넌(K. McKinnon)은 1998년에 2변수의 매끄러운 볼록 함수에서도 심플렉스가 최소점이 아닌 점으로 오그라드는 예를 보였습니다. 차원이 커지면(\(n \gtrsim 10\)) 매우 느려지기도 합니다. 그래서 도함수 없는 최적화의 현대적 방법(패턴 탐색, 대리 모델 기반 방법)은 수렴이 증명된 규칙을 쓰고, 넬더–미드는 "변수 몇 개, 기울기 없음, 빨리 대충"에 쓰는 도구로 남았습니다. 실패하면 다시 시작(재시작)하는 것이 흔한 처방입니다.

비선형 최소제곱: 가우스–뉴턴과 레벤버그–마쿼트

감쇠 곡선에 모델 맞추기

방사성 시료나 RC 회로의 방전 측정값 \((t_i, y_i)\)에 \(y = a\,e^{-bt}\)를 맞추고 싶습니다. 7장의 최소제곱은 모델이 매개변수에 대해 선형일 때였습니다. 여기서 \(b\)는 지수 안에 있습니다. 로그를 취해 직선으로 맞추는 요령은 잡음의 무게를 비틀고, 음수 측정값이 있으면 아예 쓸 수 없습니다. 제곱합 \(S(a, b) = \sum_i(a e^{-bt_i} - y_i)^2\)을 직접 최소화해야 합니다.

잔차 벡터 \(\mathbf r(\boldsymbol\beta)\), \(r_i = m(t_i; \boldsymbol\beta) - y_i\)와 그 야코비안 \(J_{ij} = \partial r_i/\partial\beta_j\)를 두면 \(S = \|\mathbf r\|^2\)의 기울기는 \(2J^{\mathsf T}\mathbf r\), 헤세 행렬은 \(2J^{\mathsf T}J + 2\sum_i r_i\nabla^2 r_i\)입니다. 맞춤이 좋으면 잔차 \(r_i\)가 작으므로 둘째 항을 버릴 수 있습니다. 2계 도함수 없이 뉴턴 방법을 흉내 내는 셈입니다.

정의 15.13 (가우스–뉴턴과 레벤버그–마쿼트) 가우스–뉴턴 걸음은 선형 최소제곱 \(\min_{\boldsymbol\delta}\|J\boldsymbol\delta + \mathbf r\|^2\)의 해, 곧
$$J^{\mathsf T}J\,\boldsymbol\delta = -J^{\mathsf T}\mathbf r$$
이다(실무에서는 7장처럼 \(J\)의 QR로 푼다). 레벤버그–마쿼트 걸음은 감쇠 매개변수 \(\lambda \ge 0\)을 더해
$$\bigl(J^{\mathsf T}J + \lambda\,\operatorname{diag}(J^{\mathsf T}J)\bigr)\boldsymbol\delta = -J^{\mathsf T}\mathbf r$$
를 풀고, \(S\)가 줄면 걸음을 받고 \(\lambda \leftarrow \lambda/10\), 늘면 버리고 \(\lambda \leftarrow 10\lambda\)로 다시 푼다.

\(\lambda \to 0\)이면 가우스–뉴턴(빠르지만 무모함), \(\lambda\)가 크면 \(\boldsymbol\delta \approx -J^{\mathsf T}\mathbf r/\lambda\)(조심스러운 짧은 경사 하강)입니다. 레벤버그(Kenneth Levenberg, 1944)는 \(\lambda I\)를, 마쿼트(Donald Marquardt, 1963)는 변수의 단위에 맞춰 대각 성분을 늘리는 \(\lambda\operatorname{diag}\)를 제안했습니다. 이것은 "이차 근사를 믿을 수 있는 반경 안에서만 걷는다"는 신뢰 영역(trust region) 방법의 원조이기도 합니다. \(\lambda\)는 그 반경의 역수 구실을 합니다.

예제 15.6 (지수 감쇠 맞춤) 데이터 \(t = 0, 1, 2, 3, 4\), \(y = 2.00, 1.25, 0.72, 0.46, 0.27\), 모델 \(a e^{-bt}\), 어림 출발 \((a, b) = (3, 3)\), \(S = 3.003\).
  1. 가우스–뉴턴: 첫 걸음이 \((1.998, -5.122)\)로 가서 \(S = 2.5\times10^{18}\). \(b \lt 0\)이면 모델이 \(e^{5t}\)로 폭발한다. 이후 \(a \approx 0\) 근처를 헤매다 발산한다.
  2. 레벤버그–마쿼트(\(\lambda_0 = 0.01\)): 첫 걸음에서 \(\lambda = 0.01, 0.1, 1\)의 걸음은 \(S\)를 \(1.3\times10^{18}\), \(5.9\times10^{15}\), \(1.8\times10^{4}\)으로 키워 모두 버리고, \(\lambda = 10\)에서 \((2.914, 2.289)\), \(S = 2.505\)로 줄어 받는다.
  3. 이후 \(\lambda = 1, 0.1, 0.01, \dots\)로 줄며 \((2.485, 0.414)\), \(S = 0.631\) → \((2.054, 0.477)\), \(S = 1.09\times10^{-2}\) → \((2.0087, 0.4954)\), \(S = 1.498\times10^{-3}\) → \((2.00835, 0.49628)\), \(S = 1.4911\times10^{-3}\)에서 멈춘다.
  4. 최적 잔차 \(0.0084, -0.0273, 0.0243, -0.0068, 0.0059\)는 부호가 섞여 있고 크기가 비슷하다. 모델이 데이터를 잘 설명한다는 신호다. 출발점이 좋은 \((1, -0.5)\)이면 가우스–뉴턴도 6걸음 안에 같은 답에 간다.

제약 최적화: 벌칙법, 라그랑주 승수, KKT 조건

예산 안에서 가장 좋은 설계

빔의 무게를 최소화하되 응력은 허용값 이하, 두께는 0 이상이어야 합니다. 포트폴리오의 위험을 최소화하되 비중의 합은 1이어야 합니다. 제약이 없는 방법들은 이런 조건을 모릅니다. 무시하고 풀면 두께가 음수인 빔이 나옵니다. 제약을 지키면서 최적을 찾는 방법은 크게 두 갈래입니다. 제약을 목적 함수에 벌금으로 넣어 제약 없는 문제로 바꾸거나, 최적점이 만족해야 할 방정식을 직접 풉니다.

문제를 \(\min f(\mathbf x)\), 등식 제약 \(h_j(\mathbf x) = 0\), 부등식 제약 \(g_i(\mathbf x) \le 0\)으로 씁니다. 가장 단순한 길은 벌칙법(penalty method)입니다.

$$Q(\mathbf x; \mu) = f(\mathbf x) + \frac{\mu}{2}\sum_j h_j(\mathbf x)^2 + \frac{\mu}{2}\sum_i \max\bigl(0,\ g_i(\mathbf x)\bigr)^2$$
제약을 어기면 그 제곱에 비례하는 벌금을 낸다. \(\mu\)를 키워 가며 \(Q\)를 앞 절들의 방법으로 최소화하고, 앞 단계의 답을 다음 단계의 출발점으로 쓴다.

최적점에서는 \(f\)의 등고선이 제약 곡면에 접합니다. 그렇지 않다면 제약면을 따라 조금 움직여 \(f\)를 더 줄일 수 있기 때문입니다. 접한다는 것은 두 기울기가 평행하다는 뜻, 곧 라그랑주 승수(Lagrange multiplier) 조건 \(\nabla f + \lambda\nabla h = \mathbf 0\)입니다(CalculusBook 15장: 라그랑주 승수). 부등식이 섞이면 이것이 다음과 같이 확장됩니다.

정리 15.14 (KKT 조건, 1차 필요조건) \(\mathbf x^*\)가 국소 최소점이고 적절한 제약 자격 조건(예: 활성 제약의 기울기들이 일차 독립)이 성립하면, 승수 \(\lambda_j\), \(\mu_i\)가 있어
$$\nabla f(\mathbf x^*) + \sum_j\lambda_j\nabla h_j(\mathbf x^*) + \sum_i\mu_i\nabla g_i(\mathbf x^*) = \mathbf 0,\qquad h_j(\mathbf x^*) = 0,\quad g_i(\mathbf x^*) \le 0,\quad \mu_i \ge 0,\quad \mu_i\,g_i(\mathbf x^*) = 0.$$
마지막 식(상보성)은 "제약이 걸려 있지 않으면(\(g_i \lt 0\)) 그 승수는 0"이라는 뜻이다. \(\mu_i \ge 0\)은 걸린 제약의 벽이 \(f\)가 줄어드는 방향을 막고 있다는 뜻이다. 카루시, 쿤, 터커(Karush, Kuhn, Tucker)의 이름을 땄다.
예제 15.7 (벌칙법이 승수를 알려 준다) \(\min x^2 + y^2\), \(h = x + y - 1 = 0\). 참 답은 \((0.5, 0.5)\), \(\nabla f + \lambda\nabla h = (1, 1) + \lambda(1, 1) = \mathbf 0\)에서 \(\lambda = -1\).
  1. \(Q = x^2 + y^2 + \frac\mu2(x + y - 1)^2\). 대칭이라 \(x = y\)이고 \(\partial Q/\partial x = 2x + \mu(2x - 1) = 0\)에서 \(x_\mu = \dfrac{\mu}{2 + 2\mu}\).
  2. \(\mu = 1, 10, 100\)이면 \(x_\mu = 0.25,\ 0.4545,\ 0.4950\). 제약 위반 \(h = 2x_\mu - 1 = -1/(1 + \mu)\)은 \(1/\mu\)처럼 준다. 벌칙법의 답은 늘 조금 제약을 어긴다.
  3. \(\mu\,h(\mathbf x_\mu) = -\mu/(1 + \mu) = -0.5,\ -0.909,\ -0.990\)은 참 승수 \(-1\)로 간다. 벌금의 기울기가 승수 역할을 하는 것이다.
  4. 대가: \(Q\)의 헤세 행렬 \(2I + \mu\begin{bmatrix}1&1\\1&1\end{bmatrix}\)의 고유값은 \(2\)와 \(2 + 2\mu\), 조건수 \(1 + \mu\). 정확하게 하려고 \(\mu\)를 키울수록 문제가 나빠진다(3절의 지그재그).

이 병을 고친 것이 증강 라그랑주 방법(augmented Lagrangian)입니다. \(Q\)에 승수 항 \(\lambda h\)를 더해 두고, 매 단계 \(\lambda \leftarrow \lambda + \mu h(\mathbf x)\)로 승수를 고치면 \(\mu\)를 무한히 키우지 않아도 정확한 답에 갑니다. 반대 방향의 장벽법(내점법)은 \(-\mu\sum\log(-g_i)\)를 더해 안쪽에서 벽에 다가가며, 선형·이차 계획법의 대규모 해법이 이 계열입니다. 부등식 예: \(\min(x - 2)^2 + (y - 1)^2\), \(g = x + y - 1 \le 0\)의 답은 \((2, 1)\)을 직선에 수직으로 내린 \((1, 0)\)이고 \(\nabla f = (-2, -2)\)이므로 \(\nabla f + \mu\nabla g = \mathbf 0\)에서 \(\mu = 2 \ge 0\). 제약이 걸려 있고 승수가 양수, KKT를 만족합니다.

확률적 경사 하강: 데이터가 너무 많을 때

기울기 한 번에 백만 장의 사진

기계 학습의 손실 함수는 데이터 하나하나의 손실을 평균한 \(F(\mathbf w) = \frac1N\sum_{i=1}^N\ell_i(\mathbf w)\)입니다. \(N\)이 백만이면 기울기를 한 번 계산하는 데 백만 번의 계산이 듭니다. 그런데 처음에는 대충의 방향만 알아도 됩니다. 사진 100장으로 어림한 기울기로 만 번 걷는 것과 백만 장 전체의 정확한 기울기로 한 번 걷는 것, 어느 쪽이 나을까요?

정의 15.15 (확률적 경사 하강과 미니배치) 매 걸음 \(\{1, \dots, N\}\)에서 크기 \(B\)의 미니배치 \(\mathcal B_k\)를 무작위로 뽑아
$$\mathbf w_{k+1} = \mathbf w_k - \alpha_k\,\mathbf g_k,\qquad \mathbf g_k = \frac1B\sum_{i\in\mathcal B_k}\nabla\ell_i(\mathbf w_k)$$
로 간다. 데이터 전체를 한 바퀴 도는 것을 1 에포크(epoch)라 한다. 줄여서 SGD(stochastic gradient descent).

\(\mathbf g_k\)는 참 기울기의 불편 추정량입니다: \(\mathbb E[\mathbf g_k] = \nabla F(\mathbf w_k)\). 그 분산은 데이터별 기울기의 분산 \(\sigma^2\)에 대해 약 \(\sigma^2/B\)입니다(복원 추출). 그래서 배치를 4배로 늘리면 잡음의 표준편차가 절반이 되지만 비용은 4배입니다. 잡음 때문에 SGD는 고정 걸음으로는 최소점에 멈추지 못하고, 걸음 크기에 비례하는 반경 안에서 계속 흔들립니다. 정확히 수렴시키려면 걸음을 줄여야 하고, 로빈스–먼로(Robbins–Monro) 조건 \(\sum\alpha_k = \infty\), \(\sum\alpha_k^2 \lt \infty\)(예: \(\alpha_k \propto 1/k\))가 표준적인 충분조건입니다. 첫 조건은 어디든 갈 수 있을 만큼 걷는다는 것, 둘째는 잡음의 누적이 유한하다는 것입니다.

실무에서 SGD가 이기는 이유는 비용 계산에 있습니다. 데이터에 중복이 많으면(비슷한 사진이 많으면) 작은 배치의 기울기도 이미 좋은 방향이고, 같은 계산량으로 훨씬 많은 걸음을 걷습니다. 딥러닝에서는 모멘텀과 좌표별 걸음 크기 조절을 합친 Adam 같은 변형이 표준이며, 걸음 크기 일정(learning rate schedule)을 조절하는 것이 학습의 중요한 기술입니다.

국소 최솟값과 전역 최적화: 담금질 기법

가장 가까운 골짜기가 가장 깊은 골짜기는 아니다

지금까지의 방법은 모두 내리막만 갑니다. 출발점이 속한 골짜기의 바닥에 도착하면 거기서 멈춥니다. 단백질 구조, 회로 배치, 일정표 짜기 같은 문제의 목적 함수에는 골짜기가 셀 수 없이 많습니다. 더 깊은 골짜기로 가려면 때로는 오르막을 받아들여야 합니다. 얼마나, 언제 받아들일까요?

볼록 함수에서는 모든 국소 최솟값이 전역 최솟값이라 이 걱정이 없습니다(선형·이차 계획법, 최소제곱이 여기에 속합니다). 볼록이 아니면 전역 최솟값을 보장하는 일반적인 효율적 방법은 없다고 보는 것이 안전합니다. 실무의 처방은 여러 출발점(다중 시작)에서 국소 방법을 돌려 가장 좋은 것을 고르거나, 무작위성을 일부러 넣는 것입니다. 후자의 대표가 금속을 천천히 식혀 결정 결함을 없애는 열처리에서 이름을 딴 담금질 기법(simulated annealing)입니다. 1983년 커크패트릭, 겔라트, 베키(Kirkpatrick, Gelatt, Vecchi)가 최적화에 쓰면서 널리 알려졌습니다.

정의 15.16 (메트로폴리스 수락 규칙과 냉각) 현재 점 \(\mathbf x\) 근처에서 무작위 후보 \(\mathbf x'\)를 뽑고 \(\Delta = f(\mathbf x') - f(\mathbf x)\)라 할 때, 온도 \(T\)에서
$$P(\text{수락}) = \begin{cases}1 & \Delta \le 0,\\ e^{-\Delta/T} & \Delta > 0\end{cases}$$
로 받아들인다. \(T\)를 \(T_{k+1} = \gamma T_k\)(\(\gamma\)는 1보다 조금 작은 수)처럼 천천히 낮춘다.

뜨거울 때(\(T\)가 클 때)는 거의 모든 오르막을 받아들여 넓게 돌아다니고, 식으면 내리막만 받는 국소 탐색이 됩니다. 높이 1의 언덕을 넘을 확률은 \(T = 1\)에서 \(e^{-1} = 0.368\), \(T = 0.1\)에서 \(e^{-10} = 4.5\times10^{-5}\)입니다. 그래서 얕은 골짜기에서는 일찍 빠져나오고, 깊은 골짜기에 머무는 시간이 상대적으로 길어집니다. 이론적으로는 \(T_k \propto 1/\log k\)처럼 아주 느리게 식히면 전역 최솟값에 확률 1로 간다는 결과가 있지만, 그 속도는 실용적이지 않습니다. 실무에서는 등비 냉각과 재가열을 섞어 쓰고, 결과를 "보장된 최적"이 아니라 "좋은 해"로 받아들입니다. 유전 알고리즘, 입자 군집 최적화, 베이즈 최적화도 같은 문제를 다른 방식으로 다룹니다.

핵심 정리

  1. 최솟값은 세 점으로 가둔다. 황금 분할 탐색은 한 점을 재사용해 함수 계산마다 구간을 0.618배로 줄이고(1차 수렴), 포물선 보간은 초선형(차수 약 1.32)이다. 브렌트 방법이 둘을 합친다.
  2. 하강 방향 \(\mathbf p\)와 아르미호 조건 \(f(\mathbf x + \alpha\mathbf p) \le f + c\alpha\nabla f^{\mathsf T}\mathbf p\)을 만족하는 되돌아가기 걸음이면, 립시츠 기울기 아래 \(\|\nabla f_k\| \to 0\)이 보장된다.
  3. 이차 함수에서 경사 하강의 수렴률은 \((\kappa - 1)/(\kappa + 1)\), 걸음 수는 \(\kappa\)에 비례하고 지그재그한다. 모멘텀(무거운 공)은 이를 \((\sqrt\kappa - 1)/(\sqrt\kappa + 1)\)로, 걸음 수를 \(\sqrt\kappa\)에 비례하게 줄인다.
  4. 뉴턴 방법 \(\nabla^2 f\,\mathbf p = -\nabla f\)는 2차 수렴하고 아핀 불변이지만, 한 걸음에 \(O(n^3)\)이 들고 헤세 행렬이 양정치가 아니면 직선 탐색과 수정이 필요하다.
  5. BFGS는 할선 조건 \(H_{k+1}\mathbf y_k = \mathbf s_k\)를 만족하는 역헤세 근사를 \(O(n^2)\)로 갱신하고, \(\mathbf y^{\mathsf T}\mathbf s > 0\)이면 양정치를 유지하며 초선형 수렴한다. 큰 문제에는 L-BFGS.
  6. 넬더–미드는 함숫값 비교만으로 심플렉스를 반사·확장·수축·축소한다. 단순하고 잡음에 강하지만 수렴 보장이 약하다.
  7. 비선형 최소제곱의 가우스–뉴턴은 \(J^{\mathsf T}J\boldsymbol\delta = -J^{\mathsf T}\mathbf r\), 레벤버그–마쿼트는 \(\lambda\)로 가우스–뉴턴과 경사 하강 사이를 오가며 먼 출발점에서도 수렴한다.
  8. 제약 최적화: 벌칙법은 \(\mu \to \infty\)에서 제약 해로 가며 \(\mu h\)가 승수를 어림하지만 조건수가 \(\mu\)에 비례해 나빠진다. 최적점은 KKT 조건(정류, 실현 가능, \(\mu_i \ge 0\), 상보성)을 만족한다.
  9. SGD는 미니배치 기울기(분산 \(\sigma^2/B\))로 값싸게 많이 걷고, 걸음을 줄여야 정확히 수렴한다. 볼록이 아닌 문제의 국소 최솟값에서는 다중 시작이나 담금질(\(e^{-\Delta/T}\)로 오르막 수락)로 빠져나온다.

확인 퀴즈

Q1. 길이 1인 구간에서 황금 분할 탐색을 시작했다. 함수를 새로 10번 계산한 뒤(처음 두 점 이후) 구간 길이는 대략?

새 계산 한 번마다 구간이 \(\tau = 0.618\)배가 된다. \(0.618^{10} = 0.0081\). \(2^{-10}\)은 이분법의 근 가두기 속도이고, 최소 가두기에서는 계산 한 번으로 절반을 얻을 수 없다.

Q2. 아르미호 되돌아가기(\(\rho = 1/2\))에서 \(\alpha = 1\)이 조건을 어겼다. 다음에 시도하는 값과, 이 조건이 막는 것은?

되돌아가기는 \(\alpha \leftarrow \rho\alpha\)로 줄인다. 아르미호 조건은 "기울기로 예측한 감소의 \(c\)배 이상 줄어야 한다"는 충분 감소 조건으로, 골짜기 건너편으로 넘어가는 긴 걸음을 거른다. 너무 짧은 걸음은 울프 조건의 기울기 조건이 막는다.

Q3. 헤세 행렬의 고유값이 1과 400인 이차 함수에서, 최적 고정 걸음의 경사 하강과 최적 모멘텀의 오차 수렴률은 각각?

\(\kappa = 400\). 경사 하강 \((\kappa - 1)/(\kappa + 1) = 399/401 = 0.995\), 모멘텀 \((\sqrt\kappa - 1)/(\sqrt\kappa + 1) = 19/21 = 0.905\). 오차 \(10^{-6}\)까지 각각 약 2760걸음과 140걸음이다.

Q4. 뉴턴 방법의 오차가 \(10^{-2}\)에서 \(10^{-4}\)가 되었다. 2차 수렴(상수 약 1)이라면 다음 오차는?

\(e_{k+1} \approx Ce_k^2\)이므로 \((10^{-4})^2 = 10^{-8}\). 맞는 자릿수가 매 걸음 두 배가 된다. 예제 15.4의 마지막 걸음들이 이렇다.

Q5. BFGS 갱신이 \(H_{k+1}\)의 양정치성을 지키려면 무엇이 필요한가?

\(H_k\)가 양정치이고 곡률 조건 \(\mathbf y^{\mathsf T}\mathbf s > 0\)이면 \(\mathbf z^{\mathsf T}H_{k+1}\mathbf z = \mathbf w^{\mathsf T}H_k\mathbf w + \rho(\mathbf s^{\mathsf T}\mathbf z)^2 > 0\)이다. 울프 조건의 기울기 조건이 이를 보장한다.

Q6. 레벤버그–마쿼트에서 \(\lambda\)를 매우 크게 하면 걸음은 어떻게 되는가?

\((J^{\mathsf T}J + \lambda D)\boldsymbol\delta = -J^{\mathsf T}\mathbf r\)에서 \(\lambda\)가 크면 \(\boldsymbol\delta \approx -D^{-1}J^{\mathsf T}\mathbf r/\lambda\), 기울기 반대 방향의 짧은 걸음이다. \(\lambda \to 0\)이 가우스–뉴턴이다.

Q7. \(\min x^2 + y^2\), \(x + y = 1\)을 벌칙법 \(Q = f + \frac\mu2(x + y - 1)^2\)으로 \(\mu = 9\)에서 풀면 \(x_\mu\)와 승수 어림 \(\mu h\)는?

\(x_\mu = \mu/(2 + 2\mu) = 9/20 = 0.45\), \(h = 2x_\mu - 1 = -0.1\), \(\mu h = -0.9\). \(\mu \to \infty\)이면 0.5와 참 승수 −1로 간다. 이때 \(Q\)의 조건수는 \(1 + \mu = 10\)이다.

Q8. 담금질 기법에서 온도 \(T = 0.5\)일 때 함숫값이 1만큼 늘어나는 후보를 받아들일 확률은?

메트로폴리스 규칙 \(e^{-\Delta/T} = e^{-1/0.5} = e^{-2} = 0.135\). 온도가 낮을수록 같은 오르막을 받아들일 확률이 지수적으로 준다.
