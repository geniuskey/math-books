비선형 연립방정식과 다항식의 근

3장의 \(f(x) = 0\)은 미지수가 하나였습니다. 회로의 마디 전압, 로봇 팔의 관절 각, GPS 수신기의 위치와 시계 오차는 미지수가 여럿이고 방정식도 여럿입니다. 이 장은 \(\mathbf F(\mathbf x) = \mathbf 0\)을 푸는 법입니다. 도함수는 야코비안 행렬이 되고, 나눗셈은 선형계 풀기가 됩니다. 뉴턴 방법이 그대로 일반화되지만, 다차원에서는 근을 가둘 수 없으므로 출발점에서 멀 때 길을 잃지 않게 하는 장치(감쇠, 연속법)와 야코비안을 아끼는 방법(브로이든)이 필요합니다. 후반부는 특별한 비선형 방정식인 다항식을 다룹니다. 값을 싸게 계산하는 호너 방법, 근을 하나씩 떼어 내는 수축, 모든 근을 한꺼번에 주는 동반 행렬, 그리고 복소평면에서 뉴턴 방법이 그리는 프랙털입니다.

  • 야코비안으로 \(\mathbf F\)를 선형화해 다변수 뉴턴 방법을 유도하고, 한 단계를 선형계 \(J\mathbf s = -\mathbf F\)로 계산한다.
  • 뉴턴 방향이 \(\|\mathbf F\|^2\)의 하강 방향임을 보이고, 직선 탐색을 단 감쇠 뉴턴으로 먼 출발점에서도 수렴시킨다.
  • 할선 조건과 브로이든 갱신으로 야코비안 계산 없이 초선형 수렴을 얻고, 비용을 함수 계산 수로 비교한다.
  • 호너 방법으로 다항식과 도함수를 \(n\)번의 곱셈으로 계산하고, 수축 순서가 근의 정확도를 좌우하는 이유를 안다.
  • 동반 행렬의 고유값이 다항식의 근임을 보이고, 복소 뉴턴 방법의 끌개 영역과 그 프랙털 경계를 설명한다.
  • 호모토피 연속법으로 쉬운 문제에서 어려운 문제로 해를 따라가고, 회로·로봇 팔·GPS 문제를 세운다.
이 수식이 없었다면회로 시뮬레이터와 GPS 수신기

트랜지스터 수만 개짜리 칩을 만들기 전에 엔지니어는 SPICE 같은 회로 시뮬레이터로 동작을 확인합니다. 시뮬레이터가 맨 먼저 하는 일은 직류 동작점, 곧 모든 마디의 키르히호프 전류 법칙을 동시에 만족하는 전압을 찾는 일이고, 다이오드와 트랜지스터의 지수 특성 때문에 이것은 미지수 수만 개의 비선형 연립방정식입니다. 시뮬레이터는 이를 뉴턴–랩슨 방법으로 풉니다. 매 반복 거대한 희소 선형계(12장)를 풀고, 지수 함수가 폭주하지 않게 걸음을 제한합니다.

주머니 속 GPS 수신기도 같은 일을 합니다. 위성 네 개 이상까지의 의사거리를 재면, 수신기의 위치 세 좌표와 시계 오차 하나를 미지수로 하는 비선형 방정식이 생깁니다. 거리 \(\sqrt{(x - x_i)^2 + \cdots}\)가 제곱근이라 선형이 아니고, 수신기는 이것을 매초 뉴턴(가우스–뉴턴) 반복 몇 번으로 풉니다.

두 곡선의 교점

원과 지수 곡선이 만나는 곳

원 \(x^2 + y^2 = 4\)와 곡선 \(y = 1 - e^x\)은 두 점에서 만납니다. 둘 다 그래프로는 쉽게 보이지만, 식을 하나로 합쳐 \(x\)만의 방정식으로 만들기는 번거롭고, 미지수가 셋, 백, 만 개가 되면 아예 불가능합니다. 방정식 여러 개를 동시에 고쳐 나가는 방법이 필요합니다.

미지수 \(n\)개, 방정식 \(n\)개를 벡터로 씁니다. \(\mathbf x = (x_1, \dots, x_n)\), \(\mathbf F(\mathbf x) = (f_1(\mathbf x), \dots, f_n(\mathbf x))\)이고 \(\mathbf F(\mathbf x) = \mathbf 0\)을 푸는 것이 목표입니다. 이 장의 기본 예제는

$$\mathbf F(x, y) = \begin{bmatrix} x^2 + y^2 - 4 \\ e^x + y - 1 \end{bmatrix} = \mathbf 0$$
근은 \(\mathbf r_1 = (1.0041687385,\ -1.7296372870)\)과 \(\mathbf r_2 = (-1.8162640688,\ 0.8373677999)\) 두 개다(아래에서 계산).

1차원과 결정적으로 다른 점이 하나 있습니다. 근을 가둘 수 없습니다. 1차원에서는 부호가 바뀌는 구간이 근을 보장했지만, 평면에서 \(f_1\)과 \(f_2\)의 부호 조합만으로는 두 곡선의 교점을 가두는 간단한 방법이 없습니다. 그래서 다차원의 근 찾기는 거의 모두 뉴턴 방법과 그 변형이고, 좋은 출발점과 전역 수렴 장치가 중요해집니다.

3장의 고정점 반복도 그대로 일반화됩니다. \(\mathbf x = \mathbf G(\mathbf x)\) 꼴로 고쳐 쓰고 반복하면, 고정점 근처에서 \(\mathbf G\)의 야코비안 노름이 1보다 작을 때(더 정확히는 스펙트럼 반지름 \(\rho(G'(\mathbf r)) \lt 1\)일 때) 선형으로 수렴합니다. 13장의 야코비·가우스–자이델 반복은 이 틀을 선형계에 쓴 것입니다.

다변수 뉴턴 방법과 야코비안

1차원 뉴턴 방법은 \(f\)를 접선으로 바꿨습니다. 다변수에서는 각 \(f_i\)를 접평면으로 바꿉니다(CalculusBook 13장: 접평면). 모든 \(f_i\)의 1차 테일러 전개를 한꺼번에 쓰면 행렬 하나가 나옵니다.

정의 4.1 (야코비안 행렬) \(\mathbf F: \mathbb R^n \to \mathbb R^n\)의 야코비안(Jacobian matrix)은 편도함수를 늘어놓은 \(n\times n\) 행렬
$$J(\mathbf x) = \begin{bmatrix} \partial f_1/\partial x_1 & \cdots & \partial f_1/\partial x_n \\ \vdots & & \vdots \\ \partial f_n/\partial x_1 & \cdots & \partial f_n/\partial x_n \end{bmatrix}$$
이다. \(i\)번째 행은 \(\nabla f_i\)이고, \(\mathbf F(\mathbf x + \mathbf s) = \mathbf F(\mathbf x) + J(\mathbf x)\mathbf s + O(\|\mathbf s\|^2)\)이다.

선형 근사가 0이 되는 \(\mathbf s\)를 찾으면 됩니다. \(\mathbf F(\mathbf x_k) + J(\mathbf x_k)\mathbf s = \mathbf 0\), 곧 선형 연립방정식입니다.

정의 4.2 (다변수 뉴턴 방법) 어림값 \(\mathbf x_0\)에서
$$J(\mathbf x_k)\,\mathbf s_k = -\mathbf F(\mathbf x_k), \qquad \mathbf x_{k+1} = \mathbf x_k + \mathbf s_k$$
를 되풀이한다. 식으로는 \(\mathbf x_{k+1} = \mathbf x_k - J(\mathbf x_k)^{-1}\mathbf F(\mathbf x_k)\)이지만, 역행렬을 만들지 않고 선형계를 푼다(LU 분해, LinearBook: LU 분해).
function newton_system(F, J, x, tol, maxit)
  for k = 1 .. maxit
    Fx = F(x)
    if norm(Fx) <= tol then return x
    A  = J(x)                     // n x n, 편도함수 n^2개
    s  = lu_solve(A, -Fx)         // 역행렬 대신 LU: 약 (2/3) n^3 번 연산
    x  = x + s
    if norm(s) <= tol * (1 + norm(x)) then return x
  fail("수렴하지 않음")
정리 4.3 (다변수 뉴턴의 2차 수렴) \(\mathbf F\)가 근 \(\mathbf r\) 근처에서 연속 미분 가능하고, 야코비안이 립시츠 연속(\(\|J(\mathbf x) - J(\mathbf y)\| \le \gamma\|\mathbf x - \mathbf y\|\))이며 \(J(\mathbf r)\)이 가역이면, \(\mathbf r\)에 충분히 가까운 \(\mathbf x_0\)에서 뉴턴 방법은 수렴하고
$$\|\mathbf x_{k+1} - \mathbf r\| \le \gamma\,\|J(\mathbf x_k)^{-1}\|\,\|\mathbf x_k - \mathbf r\|^2.$$

증명의 핵심. \(\mathbf e_k = \mathbf x_k - \mathbf r\)이라 하면 \(\mathbf e_{k+1} = \mathbf e_k - J_k^{-1}\mathbf F(\mathbf x_k) = J_k^{-1}\bigl[J_k\mathbf e_k - (\mathbf F(\mathbf x_k) - \mathbf F(\mathbf r))\bigr]\). 적분형 평균값 정리 \(\mathbf F(\mathbf x_k) - \mathbf F(\mathbf r) = \int_0^1 J(\mathbf r + \tau\mathbf e_k)\,d\tau\;\mathbf e_k\)를 넣으면 괄호 안은 \(\int_0^1 [J_k - J(\mathbf r + \tau\mathbf e_k)]\,d\tau\,\mathbf e_k\)이고, 립시츠 조건으로 크기가 \(\tfrac{\gamma}{2}\|\mathbf e_k\|^2\) 이하다. 근 근처에서 \(\|J_k^{-1}\|\)이 유계이므로 2차 수렴이다. ∎

상수에 \(\|J^{-1}\|\)이 들어 있다는 점이 1차원의 \(1/|f'(r)|\)에 해당합니다. 야코비안이 특이 행렬에 가까우면(두 곡선이 거의 접하면) 수렴 반경이 좁고 근 자체의 조건수도 나쁩니다. 1차원 중근의 다차원판입니다.

감쇠 뉴턴: 직선 탐색으로 길 잃지 않기

한 걸음에 잔차가 3500배

예제의 \(\mathbf F\)를 \((0.1, -0.1)\)에서 풀면 뉴턴의 첫 걸음이 \((9.55, -10.55)\)로 날아가 \(\|\mathbf F\|\)가 3.98에서 14041로 커집니다. 방향은 맞을지 모르는데 걸음이 너무 큰 것은 아닐까요? 1차원이라면 가둠 구간으로 막았겠지만 다차원에는 그런 울타리가 없습니다.

무엇을 기준으로 "나아졌다"고 할지 정해야 합니다. 자연스러운 잣대는 잔차의 크기, 곧 가치 함수(merit function) \(\phi(\mathbf x) = \tfrac12\|\mathbf F(\mathbf x)\|^2\)입니다. 근에서 \(\phi = 0\)이고 그 밖에서는 양수입니다. 다행히 뉴턴 방향은 언제나 \(\phi\)를 줄이는 방향입니다.

정리 4.4 (뉴턴 방향은 하강 방향) \(J(\mathbf x)\)가 가역이고 \(\mathbf F(\mathbf x) \ne \mathbf 0\)이면 뉴턴 걸음 \(\mathbf s = -J^{-1}\mathbf F\)는
$$\nabla\phi(\mathbf x)\cdot\mathbf s = (J^T\mathbf F)\cdot\mathbf s = \mathbf F^T J\,(-J^{-1}\mathbf F) = -\|\mathbf F\|^2 \lt 0$$
를 만족한다. 따라서 충분히 작은 \(t > 0\)에 대해 \(\phi(\mathbf x + t\mathbf s) \lt \phi(\mathbf x)\)이다.

그러니 방향은 그대로 두고 걸음 길이 \(t \in (0, 1]\)만 고르면 됩니다. \(t = 1\)부터 시도해서 잔차가 충분히 줄지 않으면 반으로 줄이는 직선 탐색(line search, backtracking)이 표준입니다. "충분히"의 기준이 아르미호 조건으로, 15장 최적화에서 다시 만납니다.

function damped_newton(F, J, x, tol)
  loop
    Fx = F(x);  if norm(Fx) <= tol then return x
    s  = lu_solve(J(x), -Fx)
    t  = 1
    while norm(F(x + t*s)) > (1 - 1e-4 * t) * norm(Fx)   // 아르미호식 충분 감소
      t = t / 2
      if t < 1e-10 then fail("‖F‖의 국소 최솟값에 갇힘?")
    x = x + t * s                // 근 근처에서는 t = 1, 곧 순수 뉴턴
예제 4.2 (감쇠가 바꾸는 것) \(\mathbf x_0 = (0.1, -0.1)\), \(\|\mathbf F(\mathbf x_0)\| = 3.980\). 뉴턴 걸음 \(\mathbf s = (9.4505, -10.4495)\).
  1. \(t = 1\): \(\|\mathbf F\| = 14041\). \(t = 0.5\): 127.5. \(t = 0.25\): 12.37. \(t = 0.125\): 1.254 < 3.98이므로 받아들인다. \(\mathbf x_1 = (1.2813, -1.4062)\).
  2. 그 뒤로는 \(t = 1\)이 계속 받아들여져 순수 뉴턴이 된다. \(\|\mathbf F\|\): 1.25, 0.200, \(3.4\times10^{-3}\), \(1.5\times10^{-6}\), \(3.2\times10^{-13}\), 0. 6번 만에 가까운 근 \(\mathbf r_1\)에 닿는다.
  3. 감쇠 없는 뉴턴은 \((9.55, -10.55)\), \((8.55, -2.05)\), \((7.55, 11.68)\), …으로 크게 돌아다니다가 16번째에 먼 근 \(\mathbf r_2\)에 닿는다.
감쇠는 만능이 아니다. 프로이덴슈타인–로스 시험 문제 \(f_1 = -13 + x + ((5 - y)y - 2)y\), \(f_2 = -29 + x + ((y + 1)y - 14)y\)(근 \((5, 4)\))를 \((0.5, -2)\)에서 풀면, 감쇠 뉴턴은 \(y \approx -0.897\)의 골짜기에 갇혀 60번 뒤에도 \(\|\mathbf F\| = 7.6\)에서 멈춘다. \(\phi\)의 국소 최솟값 근처에서는 \(J\)가 특이에 가까워 하강 방향이 거의 쓸모없어진다. 이때는 신뢰 영역 방법, 연속법, 다른 출발점이 필요하다.

브로이든 방법: 야코비안 없이

편도함수 2500개를 매번?

미지수가 50개면 야코비안은 편도함수 2500개입니다. 식으로 미분하기 어려우면 차분으로 근사하는데, 그러려면 \(\mathbf F\)를 한 번 반복에 51번 계산해야 합니다. 1차원 할선법이 도함수를 지난 두 점의 기울기로 바꿨듯이, 지난 걸음의 정보로 야코비안을 고쳐 쓸 수 있을까요?

1차원 할선 기울기 \(b_{k+1}\)는 \(b_{k+1}(x_{k+1} - x_k) = f(x_{k+1}) - f(x_k)\)를 만족했습니다. 다차원판은 \(\mathbf s_k = \mathbf x_{k+1} - \mathbf x_k\), \(\mathbf y_k = \mathbf F(\mathbf x_{k+1}) - \mathbf F(\mathbf x_k)\)에 대한 할선 조건(secant condition)

$$B_{k+1}\,\mathbf s_k = \mathbf y_k$$
\(n\)개의 식으로 \(n^2\)개 성분을 정할 수 없으므로, 할선 조건을 만족하는 행렬 가운데 \(B_k\)에서 가장 적게 바꾼 것을 고른다.
정리 4.5 (브로이든 갱신) 할선 조건 \(B\mathbf s_k = \mathbf y_k\)를 만족하는 행렬 가운데 프로베니우스 노름 \(\|B - B_k\|_F\)를 최소로 하는 것은
$$B_{k+1} = B_k + \frac{(\mathbf y_k - B_k\mathbf s_k)\,\mathbf s_k^T}{\mathbf s_k^T\mathbf s_k}$$
이다. 이 계수 1 수정(rank-one update)으로 반복하는 방법을 브로이든 방법(Broyden's method)이라 한다.

증명의 핵심. 할선 조건을 만족하는 임의의 \(B\)에 대해 \(B_{k+1} - B_k = (B - B_k)\dfrac{\mathbf s\mathbf s^T}{\mathbf s^T\mathbf s}\)이고, \(\mathbf s\mathbf s^T/\mathbf s^T\mathbf s\)는 사영 행렬이라 노름이 1이다. 따라서 \(\|B_{k+1} - B_k\|_F \le \|B - B_k\|_F\). \(\mathbf s\)에 수직인 방향에서는 \(B_{k+1}\)이 \(B_k\)와 똑같이 작용한다. ∎

브로이든 방법은 매 반복 \(\mathbf F\)를 한 번만 계산합니다. 셔먼–모리슨 공식으로 \(B^{-1}\)을 직접 갱신하면 선형계 풀기도 \(O(n^2)\)으로 줄어듭니다. 대가는 수렴 속도입니다. 근 근처에서 \(B_k\)가 참 야코비안으로 수렴한다는 보장은 없지만, 걸음 방향에서만큼은 충분히 정확해져 초선형으로 수렴한다는 것이 알려져 있습니다(2차는 아니다). 같은 이유로 처음 \(B_0\)이 나쁘면(예: 단위 행렬) 느려지거나 실패할 수 있어, 보통 \(B_0\)만은 차분 야코비안으로 만듭니다.

다항식: 호너 방법

다항식 값 하나에 곱셈 몇 번?

\(p(x) = a_n x^n + \cdots + a_1 x + a_0\)을 그대로 계산하면 \(x^k\)마다 곱셈 \(k\)번, 모두 \(n(n+1)/2\)번입니다. 거듭제곱을 앞에서 이어 받아도 \(2n - 1\)번이 듭니다. 뉴턴 방법은 반복마다 \(p\)와 \(p'\)이 필요하고, 차수 수십의 다항식을 수백만 번 계산하는 일(그래픽스, 신호 처리, 라이브러리 함수 근사)도 흔합니다.

괄호를 안쪽부터 묶으면 됩니다. \(2x^4 - 3x^3 + x - 5 = (((2x - 3)x + 0)x + 1)x - 5\). 이것이 호너 방법(Horner's method)입니다.

정리 4.6 (호너 방법과 조립제법) \(b_n = a_n\), \(b_k = a_k + x_0\,b_{k+1}\)(\(k = n-1, \dots, 0\))으로 계산하면 \(p(x_0) = b_0\)이고, 동시에
$$p(x) = (x - x_0)\,q(x) + b_0, \qquad q(x) = b_n x^{n-1} + b_{n-1}x^{n-2} + \cdots + b_1$$
이다. 곱셈 \(n\)번, 덧셈 \(n\)번이 든다. 같은 계산을 \(q\)에 한 번 더 하면 \(p'(x_0) = q(x_0)\)이다.

증명. \((x - x_0)q(x) + b_0\)을 전개해 \(x^k\)의 계수를 비교하면 \(b_k - x_0 b_{k+1} = a_k\)로 점화식과 같다. 미분하면 \(p'(x) = q(x) + (x - x_0)q'(x)\)이라 \(p'(x_0) = q(x_0)\). ∎

일반적인 다항식에 대해서는 곱셈 \(n\)번보다 적게 쓰는 방법이 없다는 것이 증명되어 있습니다. 반올림 오차도 작아서, 계산값은 계수를 상대적으로 약 \(2n\varepsilon\)만큼 흔든 다항식의 정확한 값입니다(후방 안정, 2장). 3장 예제 3.7의 \((x - 1)^7\) 잡음은 호너의 잘못이 아니라 전개된 계수의 크기 \(\sum|a_k x^k| = 128\)이 값 \(|p(x)|\)보다 엄청나게 크기 때문이었습니다.

function horner2(a, x)            // a[n], ..., a[0]: 높은 차수부터
  p = a[n]; d = 0
  for k = n-1 down to 0
    d = d * x + p                // q의 호너 → p'(x)
    p = p * x + a[k]             // p의 호너
  return (p, d)                  // 곱셈 2n번으로 p와 p'

수축: 근을 하나씩 떼어 내기와 그 오차

근 \(r\)을 하나 찾으면 조립제법의 몫 \(q(x) = p(x)/(x - r)\)은 차수가 하나 낮고 나머지 근을 모두 가집니다. 이제 \(q\)의 근을 찾고, 또 나누고… 이렇게 차수를 줄여 가는 것을 수축(deflation)이라 합니다. 문제는 찾은 \(r\)이 정확하지 않다는 데 있습니다. \(r\)의 작은 오차가 \(q\)의 계수를 흔들고, 그 흔들림이 다음 근들로 옮아갑니다.

윌킨슨(James H. Wilkinson)의 분석에 따르면 높은 차수부터 계수를 만드는 앞쪽 수축(조립제법)은 크기가 작은 근부터 떼어 낼 때 안정하고, 큰 근부터 떼면 작은 근들이 크게 망가질 수 있습니다. 실무에서는 두 가지를 더 합니다. ① 수축된 다항식에서 찾은 근을 원래 다항식에 대고 뉴턴 몇 번으로 다듬는다(polishing). ② 가능하면 수축 대신 아래의 동반 행렬처럼 모든 근을 한꺼번에 구한다.

  1. 작은 근부터(매번 \(x_0 = 0\)에서 뉴턴): \(2^{-15} = 3.05\times10^{-5}\)부터 1까지 차례로 나오고, 16개 모두의 상대 오차가 \(2.2\times10^{-15}\) 이하다.
  2. 큰 근부터(매번 \(x_0 = 1 + \max|a_k|\)에서 뉴턴): 1, 0.5, 0.25, 0.125까지는 상대 오차 \(3.5\times10^{-6}\) 이하로 맞지만 다섯째가 0.06332(참값 0.0625, 1.3% 오차)이고, 그 뒤로는 \(-0.0273\), \(0.641\), \(-0.623\), \(-0.854\), \(\dots\), \(109.2\) 같은 엉뚱한 값이 나온다. 수축된 다항식이 더 이상 원래 근을 갖지 않고(복소근이 생겨), 실수 출발점의 뉴턴이 1000번 안에 멈추지 못하는 단계도 생긴다.

동반 행렬: 모든 근을 고유값으로

방향을 거꾸로 생각해 봅시다. 행렬의 고유값은 특성 다항식의 근입니다. 그렇다면 주어진 다항식을 특성 다항식으로 갖는 행렬을 만들고, 그 고유값을 안정한 행렬 알고리즘으로 구하면 다항식의 근이 모두 나옵니다. 14장에서 보듯 고유값을 특성 다항식으로 구하는 것은 나쁜 생각이지만, 이 반대 방향은 좋은 생각입니다.

정의 4.7 (동반 행렬) 최고차 계수가 1인 \(p(z) = z^n + a_{n-1}z^{n-1} + \cdots + a_1 z + a_0\)의 동반 행렬(companion matrix)은
$$C = \begin{bmatrix} -a_{n-1} & -a_{n-2} & \cdots & -a_1 & -a_0 \\ 1 & 0 & \cdots & 0 & 0 \\ 0 & 1 & \cdots & 0 & 0 \\ \vdots & & \ddots & & \vdots \\ 0 & 0 & \cdots & 1 & 0 \end{bmatrix}$$
이다. 첫 행에 계수, 바로 아래 대각선에 1이 있는 상헤센베르크 행렬이다.
정리 4.8 \(\det(zI - C) = p(z)\). 따라서 \(C\)의 고유값은 \(p\)의 근(중복도 포함)과 같다. 근 \(r\)에 대한 고유벡터는 \((r^{n-1}, r^{n-2}, \dots, r, 1)\)이다.

확인. \(\mathbf v = (r^{n-1}, \dots, 1)\)이면 \(C\mathbf v\)의 둘째 성분부터는 \(r^{n-1}, \dots, r\), 곧 \(r\mathbf v\)의 성분이다. 첫 성분은 \(-a_{n-1}r^{n-1} - \cdots - a_0 = r^n - p(r)\)이므로 \(p(r) = 0\)이면 \(C\mathbf v = r\mathbf v\). ∎

MATLAB의 roots와 NumPy의 numpy.roots가 바로 이렇게 동반 행렬의 고유값을 계산합니다. 고유값은 이동 QR 알고리즘으로 구합니다(14장). \(H - \mu I = QR\)로 분해하고 \(H \leftarrow RQ + \mu I\)로 바꾸는 닮음 변환을 되풀이하면 아래 대각 성분이 0으로 가고 대각에 고유값이 드러납니다. 동반 행렬은 이미 헤센베르크 꼴이라 한 단계가 \(O(n^2)\)이고 전체 비용은 \(O(n^3)\), 대신 출발점 걱정도 수축 순서 걱정도 없습니다.

예제 4.6 (x³ − 2x − 5의 동반 행렬) \(a_2 = 0\), \(a_1 = -2\), \(a_0 = -5\)이므로 \(C = \begin{bmatrix} 0 & 2 & 5 \\ 1 & 0 & 0 \\ 0 & 1 & 0 \end{bmatrix}\). 복소 이동(윌킨슨 이동) QR을 돌리면 마지막 아래 대각 성분 \(|h_{32}|\)이 1, 1.24, 0.684, 0.486, \(5.87\times10^{-3}\), \(1.06\times10^{-6}\), \(2.81\times10^{-14}\)으로 줄어 7단계 만에 고유값 \(-1.0472757 - 1.1359399i\)가 떨어져 나온다(끝의 세 값은 2차 수렴). 남은 2×2 블록에서 한 단계 더 하면 \(2.0945514815\)와 \(-1.0472757 + 1.1359399i\)가 나온다. 근이 \(1, 2, \dots, 10\)인 다항식이면 QR 27단계로 모든 근이 상대 오차 \(1.2\times10^{-10}\) 이하로 나온다.

복소 평면의 뉴턴 방법과 프랙털

뉴턴 방법은 복소수에서도 똑같이 쓸 수 있습니다. \(z_{k+1} = z_k - p(z_k)/p'(z_k)\). 실근이 없는 \(z^2 + 1\)도 복소 출발점에서 \(\pm i\)로 수렴합니다. 사실 이것은 2변수 뉴턴과 같은 것입니다. \(z = x + iy\), \(p = u + iv\)로 쓰면 \(p(z) = 0\)은 \(u(x, y) = 0\), \(v(x, y) = 0\)의 연립방정식이고, 코시–리만 방정식 \(u_x = v_y\), \(u_y = -v_x\) 때문에 그 야코비안 \(\begin{bmatrix} u_x & u_y \\ v_x & v_y\end{bmatrix}\)은 복소수 \(p'(z)\)를 곱하는 회전·확대 행렬이 됩니다(MathBook: 복소수). 2변수 뉴턴 시뮬레이터의 둘째 연립방정식이 바로 \(z^3 = 1\)의 실수·허수 부분입니다.

정의 4.9 (끌개 영역) 근 \(r\)의 끌개 영역(basin of attraction)은 뉴턴 반복이 \(r\)로 수렴하는 출발점 \(z_0\) 전체의 집합이다. 단순근은 정리 3.8에 의해 둘레에 작은 원판을 포함한다.

\(z^3 - 1\)의 세 근 \(1\), \(e^{\pm 2\pi i/3}\)의 끌개 영역을 색칠하면 놀라운 그림이 나옵니다. 근 가까이에서는 각 영역이 넓고 매끄럽지만 경계에서는 세 색이 끝없이 뒤섞입니다. 이 질문은 케일리(Arthur Cayley)가 1879년에 2차식은 쉽고 3차식은 어렵다고 적으며 던진 것으로 알려져 있고, 컴퓨터 그래픽이 생긴 뒤에야 그 모양이 보였습니다. 이유는 복소 동역학의 정리가 말해 줍니다. 유리 함수 반복에서 각 끌개 영역의 경계는 모두 같은 집합(쥘리아 집합)이라서, 경계의 어느 점이든 그 아무리 작은 근방에도 세 영역이 모두 들어 있습니다.

  • 실수축 위의 출발점은 실수축을 떠나지 않으므로 실근 1로 간다(0과 0으로 가는 점들 제외). \(z_0 = -1\)이면 \(-0.3333\), \(2.7778\), \(1.8950\), \(1.3562\), \(1.0854\), \(1.0065\), \(1.00004\).
  • \(z_0 = 1 + i\)는 \(0.6667 + 0.5i\), \(0.5788 - 0.1275i\), \(1.2470 + 0.3136i\), \(1.0090 + 0.1137i\), \(\dots\)로 돌아서 1로 가고, \(z_0 = 0.1 + 0.01i\)는 0 가까이라 \(p'\)이 작아 첫 걸음에 \(32.4 - 6.53i\)로 크게 튄 뒤 13번 만에 1로 돌아온다.
  • \(z^3 - 2z + 2\)에서는 3장의 순환 \(0 \to 1 \to 0\)이 끌어당기는 주기 궤도라서, 그 둘레에 어떤 근으로도 수렴하지 않는 출발점의 열린 영역이 생긴다(시뮬레이터의 회색 영역).

연속법: 쉬운 문제에서 어려운 문제로

좋은 출발점이 없을 때

뉴턴 방법은 출발점이 근에 가까워야 합니다. 그런데 근을 모르니 출발점도 모릅니다. 답을 아는 쉬운 문제에서 시작해 문제를 조금씩 바꿔 가며, 바뀐 문제의 해를 바로 앞 해에서 출발한 뉴턴으로 따라가면 어떨까요?

매개변수 \(t \in [0, 1]\)로 두 문제를 잇는 호모토피(homotopy) \(\mathbf H(\mathbf x, t)\)를 만듭니다. \(t = 0\)에서는 해를 알고, \(t = 1\)에서는 원래 문제 \(\mathbf F\)가 됩니다. 대표적인 두 가지는

$$\mathbf H_N(\mathbf x, t) = \mathbf F(\mathbf x) - (1 - t)\,\mathbf F(\mathbf x_0), \qquad \mathbf H_C(\mathbf x, t) = t\,\mathbf F(\mathbf x) + (1 - t)(\mathbf x - \mathbf x_0)$$
뉴턴 호모토피 \(\mathbf H_N\)과 볼록 호모토피 \(\mathbf H_C\). 둘 다 \(t = 0\)에서 해가 \(\mathbf x_0\)이다.

해 \(\mathbf x(t)\)는 \(\mathbf H(\mathbf x(t), t) = \mathbf 0\)을 만족하는 곡선(해 경로)을 그립니다. 연속법(continuation method)은 이 경로를 작은 걸음으로 따라갑니다. 각 걸음은 예측(앞 해, 또는 접선 방향으로 외삽)과 수정(그 점에서 \(\mathbf H(\cdot, t_{k+1}) = 0\)에 대한 뉴턴 몇 번)입니다. 뉴턴 호모토피를 \(t\)로 미분하면 \(J\dot{\mathbf x} + \mathbf F(\mathbf x_0) = 0\), 곧 \(\dot{\mathbf x} = -J^{-1}\mathbf F(\mathbf x_0)\)입니다. 경로를 따라 잔차가 \(\mathbf F(\mathbf x(t)) = (1 - t)\mathbf F(\mathbf x_0)\)로 방향을 바꾸지 않고 줄어드니, 연속법은 뉴턴 방향을 아주 작은 걸음으로 따라가는 "연속 뉴턴"인 셈입니다.

function continuation(H, Hx, x0, N)
  x = x0                           // H(x0, 0) = 0
  for k = 1 .. N
    t = k / N
    repeat 3~5 times                 // 수정자: t를 고정한 뉴턴
      x = x - lu_solve(Hx(x, t), H(x, t))
  return x                         // t = 1: F(x) = 0의 해

\(t\)를 단조롭게 늘리는 이 단순한 방법은 경로가 되돌아갈 때(\(t\)가 최댓값을 찍고 줄어드는 전환점) 실패합니다. 전환점에서는 \(\partial\mathbf H/\partial\mathbf x = J\)가 특이 행렬이 되어 \(t\)를 더 늘린 문제에 가까운 해가 없습니다. 해결책은 \(t\)도 미지수로 보고 경로의 호의 길이를 매개변수로 삼는 의사 호 길이 연속법입니다. 아래 시뮬레이터가 이 방법을 씁니다.

예제 4.7 (연속법으로 가까운 근 찾기) 예제 4.2의 \(\mathbf x_0 = (0.1, -0.1)\)에서 뉴턴 호모토피를 호 길이 0.1 걸음으로 따라가면 경로가 \(t = 0.1, 0.2, 0.4, 0.7\)에서 \((0.409, -0.501)\), \((0.545, -0.720)\), \((0.718, -1.047)\), \((0.885, -1.422)\)을 거쳐 22걸음 만에 \(t = 1\)에서 \(\mathbf r_1 = (1.0041687, -1.7296373)\)에 닿는다. 순수 뉴턴이 크게 돌아 먼 근으로 간 것과 달리, 출발점과 "이어진" 근을 찾는다. 이 문제에서는 여러 출발점에서 시험해 봐도 전환점이 없었다. 프로이덴슈타인–로스 문제를 \((0.5, -2)\)에서 뉴턴 호모토피로 따라가면 경로가 \(t \approx 0.59\)에서 꺾여 무한대로 달아난다. 호모토피를 잘 고르는 것도 기술이다.

로봇 팔의 역기구학

두 마디 팔(길이 \(L_1, L_2\), 관절 각 \(\theta_1, \theta_2\))의 끝 위치는 \(x = L_1\cos\theta_1 + L_2\cos(\theta_1 + \theta_2)\), \(y = L_1\sin\theta_1 + L_2\sin(\theta_1 + \theta_2)\)입니다(정기구학). 원하는 위치 \((p_x, p_y)\)를 주고 각을 구하는 역기구학은 \(\mathbf F(\theta_1, \theta_2) = (x - p_x, y - p_y) = \mathbf 0\)이고, 야코비안의 행렬식은 \(\det J = L_1L_2\sin\theta_2\)입니다. 팔이 완전히 펴지거나 접히면(\(\theta_2 = 0, \pi\)) 특이 자세라 뉴턴이 불안정해집니다.

\(L_1 = L_2 = 1\), 목표 \((1, 1)\), 출발 \((\theta_1, \theta_2) = (0.3, 1.0)\)이면 뉴턴 반복은 \((-0.0675, 1.7115)\), \((-0.00243, 1.5752)\), \((-1.96\times10^{-6}, 1.570801)\), \((-4.3\times10^{-12}, 1.5707963268)\)으로 4번 만에 \((0, \pi/2)\)에 닿습니다. 목표가 팔이 닿지 않는 곳이면 해가 없고 뉴턴은 진동합니다. 이때는 \(\|\mathbf F\|^2\)를 최소화하는 감쇠 최소제곱 걸음 \((J^TJ + \lambda I)\mathbf s = -J^T\mathbf F\)(레벤버그–마쿼트, 15장)가 팔을 목표 쪽으로 쭉 뻗게 해 줍니다.

GPS: 의사거리 방정식

위성 \(i\)의 위치 \(\mathbf s_i\)를 알고 신호의 도착 시각으로 거리 \(\rho_i\)를 재는데, 수신기의 값싼 시계에는 오차 \(b\)(거리로 환산)가 있습니다. 미지수는 위치 \(\mathbf x\)와 \(b\)이고, \(f_i(\mathbf x, b) = \|\mathbf x - \mathbf s_i\| + b - \rho_i = 0\)입니다. 3차원이면 미지수 4개라 위성이 4개 이상 필요합니다. 야코비안의 \(i\)번째 행은 \((\text{위성에서 수신기로의 단위 벡터}, 1)\)입니다. 위성이 더 많으면 최소제곱(가우스–뉴턴, 7장·15장)으로 풉니다.

예제 4.9 (평면 GPS) 평면에서 위성 세 개 \((0, 10)\), \((8, 6)\), \((-7, 7)\)과 의사거리 \(\rho = (8.562258,\ 8.562258,\ 9.933981)\)(참 위치 \((1, 2)\), 시계 오차 \(b = 0.5\)로 만든 값)이 있다. \((x, y, b) = (0, 0, 0)\)에서 뉴턴 방법을 쓰면
  1. \((1.138708,\ 2.277417,\ 0.839675)\), \(\|\mathbf F\| = 0.337\)
  2. \((1.001843,\ 2.003686,\ 0.505336)\), \(\|\mathbf F\| = 5.6\times10^{-3}\)
  3. \((1.0000003,\ 2.0000007,\ 0.5000010)\), \(\|\mathbf F\| = 1.0\times10^{-6}\)
  4. \((1, 2, 0.5)\), \(\|\mathbf F\| = 3.3\times10^{-14}\)

핵심 정리

  1. \(\mathbf F(\mathbf x) = \mathbf 0\)의 다변수 뉴턴은 \(J(\mathbf x_k)\mathbf s_k = -\mathbf F(\mathbf x_k)\)를 풀어 \(\mathbf x_{k+1} = \mathbf x_k + \mathbf s_k\). 역행렬이 아니라 선형계를 푼다. \(J(\mathbf r)\)이 가역이면 2차 수렴, 상수에 \(\|J^{-1}\|\)이 들어간다.
  2. 다차원에서는 근을 가둘 수 없다. 뉴턴 방향은 \(\tfrac12\|\mathbf F\|^2\)의 하강 방향(\(\nabla\phi\cdot\mathbf s = -\|\mathbf F\|^2\))이므로, 걸음을 반씩 줄이는 직선 탐색(감쇠 뉴턴)으로 먼 출발점에서도 수렴을 돕는다. 다만 \(\|\mathbf F\|\)의 국소 최솟값에 갇힐 수 있다.
  3. 브로이든 방법은 할선 조건 \(B_{k+1}\mathbf s_k = \mathbf y_k\)를 만족하는 최소 변경 계수 1 갱신으로 야코비안을 대신한다. 반복마다 \(\mathbf F\) 한 번, 초선형 수렴. 미지수가 많을수록 차분 뉴턴보다 싸다.
  4. 호너 방법은 \(b_k = a_k + x_0 b_{k+1}\)로 곱셈 \(n\)번에 \(p(x_0)\)을 주고, 같은 표가 몫 \(p(x)/(x - x_0)\)이다. 한 번 더 하면 \(p'(x_0)\). 뉴턴–호너는 반복마다 호너 두 줄이다.
  5. 수축은 작은 근부터 떼어 내야 안정하다. 큰 근부터 떼면 작은 근들이 망가질 수 있고, 찾은 근은 원래 다항식으로 다듬는다.
  6. 동반 행렬의 고유값은 다항식의 근이다. roots는 이동 QR 알고리즘으로 모든 근을 \(O(n^3)\)에 출발점 없이 구한다.
  7. 복소 뉴턴은 코시–리만 덕분에 2변수 뉴턴과 같다. \(z^3 - 1\)의 끌개 영역 경계는 프랙털(쥘리아 집합)이라 경계 근처의 출발점은 어느 근으로 갈지 예측하기 어렵다. 끌어당기는 순환이 있으면 수렴하지 않는 열린 영역이 생긴다.
  8. 연속법은 해를 아는 쉬운 문제에서 원래 문제로 \(\mathbf H(\mathbf x, t)\)를 바꾸며 해 경로를 예측–수정으로 따라간다. 전환점에서는 \(J\)가 특이해지므로 호 길이 매개변수를 쓴다.

확인 퀴즈

Q1. 다변수 뉴턴 방법의 한 반복에서 실제로 계산하는 것은?

식으로는 x − J⁻¹F지만, 역행렬을 만드는 것은 LU 풀기보다 약 3배 비싸고 덜 정확하다. 성분별 뉴턴은 방정식 사이의 결합을 무시해 일반적으로 수렴하지 않는다. 기울기 방향 JTF는 최급 강하(15장)다.

Q2. \(\mathbf F(x, y) = (x^2 + y^2 - 4,\ e^x + y - 1)\)의 \((1, -1)\)에서의 야코비안 행렬식은?

J = [[2x, 2y], [eˣ, 1]] = [[2, −2], [e, 1]]. 행렬식 2·1 − (−2)·e = 2 + 2e = 7.437. 0이 아니므로 뉴턴 걸음이 하나로 정해진다.

Q3. 감쇠 뉴턴에서 뉴턴 걸음 \(\mathbf s = -J^{-1}\mathbf F\)가 \(\phi = \tfrac12\|\mathbf F\|^2\)을 줄이는 방향인 이유는?

∇φ = JTF이므로 ∇φ·s = FTJ(−J⁻¹F) = −‖F‖². J가 가역이고 F ≠ 0이면 언제나 음수, 충분히 작은 걸음은 반드시 잔차를 줄인다. J의 대칭성은 필요 없다.

Q4. 브로이든 갱신된 행렬 \(B_{k+1}\)이 반드시 만족하는 것은?

할선 조건 B s = y. 이것을 만족하는 행렬 중 Bk에서 프로베니우스 노름으로 가장 적게 바꾼 것이 브로이든 갱신이다. 참 야코비안과 같아진다는 보장은 없다(예제 4.3).

Q5. 차수 10인 일반 다항식의 값을 호너 방법으로 계산할 때 곱셈과 덧셈의 수는?

bₖ = aₖ + x·bₖ₊₁을 10번, 각각 곱셈 하나와 덧셈 하나. 항마다 거듭제곱을 새로 계산하면 1 + 2 + … + 10 = 55번, 거듭제곱을 이어 받으면 19번이다.

Q6. \(p(x) = x^3 - 6x^2 + 11x - 6\)의 근 \(x = 1\)로 조립제법 수축을 하면 몫은?

b = 1, −6 + 1 = −5, 11 − 5 = 6, −6 + 6 = 0. 마지막이 0이라 1이 근이고, 몫 x² − 5x + 6 = (x − 2)(x − 3)이 나머지 근 2, 3을 가진다.

Q7. 행렬 \(\begin{bmatrix} 3 & -2 \\ 1 & 0 \end{bmatrix}\)의 고유값은?

z² + a₁z + a₀의 동반 행렬 첫 행이 [−a₁, −a₀] = [3, −2]이므로 a₁ = −3, a₀ = 2, 곧 z² − 3z + 2 = (z − 1)(z − 2). 직접 det(zI − C) = z(z − 3) + 2로 확인할 수 있다.

Q8. \(z^3 - 1\)에 대한 뉴턴 방법의 끌개 영역에 대해 옳은 것은?

세 영역의 경계는 같은 쥘리아 집합이라 경계 근처에서 세 색이 끝없이 섞인다. 실수 출발점은 실수축에 머물러 1로 간다. 수렴하지 않는 열린 영역은 z³ − 2z + 2처럼 끌어당기는 순환이 있을 때 생긴다.
