반복 해법

12장의 LU 분해는 \(n^3/3\)번의 곱셈과 \(n^2\)칸의 메모리로 연립방정식을 정확히 풉니다. \(n = 10^3\)이면 문제없지만 열전도·구조·유체 시뮬레이션의 \(n\)은 \(10^6\)을 넘고, 행렬은 한 행에 0이 아닌 원소가 다섯 개쯤뿐입니다. 이런 행렬은 분해하는 대신 곱하기만 하면서 해에 다가가는 것이 낫습니다. 이 장은 가장 오래된 반복(야코비, 가우스–자이델)이 왜 수렴하는지를 스펙트럼 반지름으로 정확히 말하고, 매개변수 하나로 수십 배 빨라지는 SOR, 방정식을 그릇의 바닥 찾기로 바꾼 켤레 기울기법, 그 속도를 다시 몇 배 올리는 전처리, 비대칭 행렬의 GMRES, 그리고 격자 크기와 무관한 횟수로 끝나는 다중 격자까지 다룹니다.

  • 분할 \(A = M - N\)으로 야코비·가우스–자이델·SOR을 쓰고, 반복 행렬의 스펙트럼 반지름으로 수렴 여부와 속도를 판정한다.
  • 대각 우세·대칭 양정치 조건에서 수렴을 증명하고, 영의 정리로 최적 이완 계수 \(\omega^*\)를 계산한다.
  • \(A\mathbf x = \mathbf b\)를 이차 형식의 최소화로 바꾸고, 최급 강하의 지그재그와 켤레 기울기법의 A-직교 방향을 비교한다.
  • CG의 수렴이 조건수 \(\sqrt\kappa\)뿐 아니라 고유값 분포 전체에 달려 있음을 실험으로 확인한다.
  • 야코비·불완전 촐레스키 전처리와 GMRES(아놀디 과정, 재시작)의 원리를 설명한다.
  • 고주파 오차는 완화로, 저주파 오차는 거친 격자로 없애는 다중 격자의 아이디어를 이해한다.

자동차 충돌 해석, 일기예보의 압력 방정식, 반도체 소자의 전위 분포, 영상의 매끄러운 합성은 모두 결국 거대한 희소 연립방정식 \(A\mathbf x = \mathbf b\)를 풉니다. 밀집 행렬로 다루면 \(n = 10^6\)에서 저장에만 8 TB, 소거에 \(3\times10^{17}\)번의 곱셈이 듭니다. 반복 해법은 같은 문제를 \(A\)와 벡터의 곱 수백 번, 곧 원소 수십억 번의 연산으로 풉니다.

큰 희소 행렬: 왜 분해하지 않는가

금속판의 온도, 격자 1000 × 1000

정사각형 판의 가장자리 온도를 정해 두고 안쪽의 정상 상태 온도를 구합니다. 판을 한 변 \(N\)칸으로 나누면 각 격자점의 온도는 상하좌우 네 이웃의 평균이라는 식(라플라스 방정식의 5점 차분, 16장) 하나로 묶입니다. \(N = 1000\)이면 미지수가 \(10^6\)개입니다. 12장의 띠 촐레스키로 풀면 얼마나 들까요?

격자점을 행 순서로 번호 매기면 \(n = N^2\)차 행렬 \(A\)의 각 행에는 대각 원소 4와 이웃 네 개의 \(-1\)만 있습니다. 0이 아닌 원소 수(nnz)는 약 \(5n\)입니다. 이런 행렬을 희소 행렬(sparse matrix)이라 합니다. 문제는 분해입니다. 위아래 이웃이 \(N\)칸 떨어져 있어 띠 폭이 \(N\)이고, 촐레스키 인수는 띠 안을 거의 다 채웁니다(채움(fill-in), 12장).

야코비와 가우스–자이델

한 식에서 한 미지수씩

\(i\)번째 방정식 \(\sum_j a_{ij}x_j = b_i\)를 \(x_i\)에 대해 풀면 \(x_i = (b_i - \sum_{j\ne i} a_{ij}x_j)/a_{ii}\)입니다. 오른쪽의 다른 미지수에 지금의 추측값을 넣으면 \(x_i\)의 새 추측이 나옵니다. 이것을 되풀이하면 해에 다가갈까요? 그리고 새 값을 언제부터 쓸까요?

두 가지 선택이 있습니다. 한 바퀴를 도는 동안 이전 값만 쓰는 것이 야코비 방법(Jacobi method), 방금 계산한 \(x_1^{(k+1)}, \dots, x_{i-1}^{(k+1)}\)을 즉시 쓰는 것이 가우스–자이델 방법(Gauss–Seidel method)입니다.

정의 13.1 (야코비와 가우스–자이델) \(a_{ii} \ne 0\)일 때
$$\text{야코비: } x_i^{(k+1)} = \frac{1}{a_{ii}}\Bigl(b_i - \sum_{j\ne i} a_{ij}x_j^{(k)}\Bigr),\qquad \text{G–S: } x_i^{(k+1)} = \frac{1}{a_{ii}}\Bigl(b_i - \sum_{j \lt i} a_{ij}x_j^{(k+1)} - \sum_{j \gt i} a_{ij}x_j^{(k)}\Bigr).$$
야코비는 새 벡터를 따로 저장해야 하지만 모든 \(i\)를 동시에(병렬로) 계산할 수 있다. 가우스–자이델은 벡터 하나를 제자리에서 덮어쓰며, 계산 순서가 결과를 바꾼다.
function gauss_seidel(A, b, x, tol, maxit)
  for k = 1 .. maxit
    for i = 1 .. n                          // 희소 행렬이면 i행의 0 아닌 원소만
      s = b[i]
      for j in nonzeros(row i), j != i
        s = s - A[i][j] * x[j]               // j < i 는 이미 새 값
      x[i] = s / A[i][i]                     // 야코비는 여기서 xnew[i]에 쓴다
    if norm(b - A x) <= tol * norm(b) then return x
  return x                                  // 수렴 실패: 호출자가 확인

2 × 2에서 기하가 분명해집니다. 두 방정식은 평면의 두 직선이고 해는 교점입니다. 가우스–자이델의 첫 갱신은 \(x_2\)를 고정한 채 \(x_1\)을 바꿔 첫째 직선 위로 수평 이동하고, 둘째 갱신은 둘째 직선 위로 수직 이동합니다. 계단을 타고 교점으로 내려가는 셈입니다. 야코비는 두 좌표를 동시에 바꾸므로 두 직선 어느 쪽에도 놓이지 않은 점으로 대각선 이동합니다.

예제 13.1 (3 × 3 손계산) \(4x_1 - x_2 + x_3 = 5,\ -x_1 + 4x_2 - 2x_3 = 1,\ x_1 - 2x_2 + 5x_3 = 12\)의 해는 \((1, 2, 3)\)이다. \(\mathbf x^{(0)} = \mathbf 0\)에서 출발한다.
  1. 야코비 1회: \(x_1 = 5/4 = 1.25\), \(x_2 = 1/4 = 0.25\), \(x_3 = 12/5 = 2.4\).
  2. 가우스–자이델 1회: \(x_1 = 1.25\), 이 값을 곧바로 써서 \(x_2 = (1 + 1.25)/4 = 0.5625\), \(x_3 = (12 - 1.25 + 2\cdot0.5625)/5 = 2.375\).
  3. 여덟 번까지의 최대 오차 \(\|\mathbf x^{(k)} - \mathbf x\|_\infty\)는 아래 표와 같다. 가우스–자이델은 매번 약 \(0.16\)배, 야코비는 \(0.5\)–\(0.65\)배씩 준다. 다음 절에서 이 비율이 반복 행렬의 스펙트럼 반지름 \(\rho_J = 0.626\), \(\rho_{GS} = 0.158\)임을 본다.

분할과 반복 행렬, 스펙트럼 반지름

세 방법을 한 틀에 넣습니다. \(A\)를 쉽게 풀리는 부분 \(M\)과 나머지로 분할해 \(A = M - N\)이라 쓰면 \(A\mathbf x = \mathbf b\)는 \(M\mathbf x = N\mathbf x + \mathbf b\)이고, 이를 반복식으로 읽습니다.

정의 13.2 (분할과 반복 행렬) \(A = M - N\), \(M\)은 가역이고 \(M\mathbf z = \mathbf r\)이 싸게 풀린다고 하자. 정상 반복법(stationary iterative method)
$$M\mathbf x_{k+1} = N\mathbf x_k + \mathbf b \iff \mathbf x_{k+1} = \mathbf x_k + M^{-1}(\mathbf b - A\mathbf x_k)$$
의 반복 행렬(iteration matrix)은 \(G = M^{-1}N = I - M^{-1}A\)이다. \(A = D - L - U\)(대각, 순하삼각의 부호 반대, 순상삼각의 부호 반대)로 쓰면 야코비는 \(M = D\), 가우스–자이델은 \(M = D - L\), SOR은 \(M = \frac1\omega D - L\)이다.

오른쪽 꼴이 핵심입니다. 모든 정상 반복법은 "잔차 \(\mathbf r_k = \mathbf b - A\mathbf x_k\)를 \(M^{-1}\)로 근사 풀이해 더한다"는 한 줄이고, \(M\)이 \(A\)에 가까울수록 한 번에 많이 나아갑니다. 오차 \(\mathbf e_k = \mathbf x_k - \mathbf x\)는 \(\mathbf b\)와 무관하게 \(\mathbf e_{k+1} = G\mathbf e_k\), 곧 \(\mathbf e_k = G^k\mathbf e_0\)를 따릅니다.

정리 13.3 (수렴의 필요충분조건) 정상 반복이 모든 \(\mathbf x_0\)에서 수렴할 필요충분조건은 스펙트럼 반지름(spectral radius) \(\rho(G) = \max_i|\lambda_i(G)|\)가 1보다 작은 것이다. 또 어떤 노름에서든 \(\lim_{k\to\infty}\|G^k\|^{1/k} = \rho(G)\)이므로, 오차를 \(10^{-m}\)배로 줄이는 데 점근적으로 \(m/(-\log_{10}\rho)\)회가 든다.

증명의 핵심. \(G\)가 대각화 가능하면 \(\mathbf e_0 = \sum c_i\mathbf v_i\)에서 \(G^k\mathbf e_0 = \sum c_i\lambda_i^k\mathbf v_i\)이므로 모든 \(|\lambda_i| \lt 1\)일 때만 모든 \(\mathbf e_0\)가 0으로 간다(\(|\lambda_i| \ge 1\)이면 \(\mathbf e_0 = \mathbf v_i\)가 반례). 일반적인 경우에는 조르당 블록 \(J = \lambda I + E\)의 거듭제곱 \(J^k = \sum_{j} \binom kj \lambda^{k-j}E^j\)가 \(|\lambda| \lt 1\)이면 다항식 × 지수 감소로 0이 된다. ∎

필요충분조건은 고유값을 알아야 쓸 수 있습니다. 실무에서는 행렬을 보고 바로 판정할 수 있는 충분조건이 더 유용합니다.

정리 13.4 (대각 우세와 대칭 양정치)
  1. \(A\)가 엄격한 대각 우세(strictly diagonally dominant), 곧 모든 행에서 \(|a_{ii}| \gt \sum_{j\ne i}|a_{ij}|\)이면 야코비와 가우스–자이델은 모든 시작점에서 수렴한다.
  2. \(A\)가 대칭 양정치(SPD)이면 가우스–자이델, 그리고 \(0 \lt \omega \lt 2\)인 SOR이 수렴한다.
  3. (카한) 어떤 행렬이든 \(\rho(G_\omega) \ge |\omega - 1|\)이다. 따라서 SOR이 수렴하려면 \(0 \lt \omega \lt 2\)가 필요하다.

①의 증명. 야코비의 \(G_J = D^{-1}(L + U)\)의 \(i\)행 절댓값 합은 \(\sum_{j\ne i}|a_{ij}|/|a_{ii}| \lt 1\)이므로 \(\rho(G_J) \le \|G_J\|_\infty \lt 1\). 가우스–자이델은 \(\mathbf e_{k+1}\)의 성분 중 절댓값이 가장 큰 \(i\)번째를 보면 \(|e_i^{(k+1)}| \le \sum_{j \lt i}\frac{|a_{ij}|}{|a_{ii}|}|e_j^{(k+1)}| + \sum_{j \gt i}\frac{|a_{ij}|}{|a_{ii}|}|e_j^{(k)}|\)에서 같은 결론이 나온다. ③의 증명. \(\det G_\omega = \det(D - \omega L)^{-1}\det((1-\omega)D + \omega U) = (1 - \omega)^n\)이고, 행렬식은 고유값의 곱이므로 \(\rho^n \ge |1 - \omega|^n\). ∎

예제 13.2 (예제 13.1의 반복 행렬) 예제 13.1의 \(A\)는 엄격한 대각 우세다(행마다 \(4 \gt 2\), \(4 \gt 3\), \(5 \gt 3\)).
  1. \(G_J = D^{-1}(L+U)\)의 행 합은 \(2/4,\ 3/4,\ 3/5\)이므로 \(\|G_J\|_\infty = 0.75\). 정리 13.4의 상한이다.
  2. 실제 스펙트럼 반지름은 \(\rho(G_J) = 0.626\), \(\rho(G_{GS}) = 0.158\)이다(반복 행렬에 거듭제곱을 많이 해서 얻은 값). 오차를 \(10^{-6}\)배 줄이는 데 점근적으로 야코비 \(6/0.203 \approx 30\)회, 가우스–자이델 \(6/0.801 \approx 7.5\)회가 든다. 표의 8회 오차 \(2.7\times10^{-6}\)과 맞다.
  3. \(\rho_{GS}\)가 \(\rho_J^2 = 0.392\)보다 작다. \(\rho_{GS} = \rho_J^2\)은 다음 절의 "일관된 순서" 행렬(삼중대각, 5점 격자 등)에서 성립하는 관계이고, 이 \(A\)는 그런 꼴이 아니다.
주의: 잔차와 오차 반복을 멈추는 기준은 보통 상대 잔차 \(\|\mathbf r_k\|/\|\mathbf b\|\)입니다. 그런데 \(\mathbf e_k = -A^{-1}\mathbf r_k\)이므로 \(\|\mathbf e_k\|/\|\mathbf x\| \le \kappa(A)\,\|\mathbf r_k\|/\|\mathbf b\|\)입니다(2장). 조건수가 \(10^6\)이면 잔차가 \(10^{-8}\)이어도 오차는 \(10^{-2}\)일 수 있습니다. 또 \(\rho\)가 1에 가까운 반복에서는 연속한 두 반복값의 차이가 작다고 해서 해에 가깝다는 뜻이 아닙니다. 차이에 \(1/(1 - \rho)\)를 곱한 것이 오차의 크기입니다.

SOR과 최적 이완 계수

가우스–자이델이 늘 모자라게 간다면

위 시뮬레이터의 '결합 강함'에서 가우스–자이델은 매번 같은 방향으로 조금씩, 모자라게 갑니다. 그렇다면 G–S가 제안하는 이동을 \(\omega\)배로 과하게 밀어 주면 어떨까요? 얼마나 밀어야 가장 빠를까요?

축차 과이완(successive over-relaxation, SOR)은 가우스–자이델 값 \(\tilde x_i\)와 이전 값 \(x_i^{(k)}\)의 가중 평균을 씁니다.

$$x_i^{(k+1)} = (1 - \omega)\,x_i^{(k)} + \omega\,\tilde x_i,\qquad \tilde x_i = \frac{1}{a_{ii}}\Bigl(b_i - \sum_{j \lt i}a_{ij}x_j^{(k+1)} - \sum_{j \gt i}a_{ij}x_j^{(k)}\Bigr).$$
\(\omega = 1\)이면 가우스–자이델, \(\omega \gt 1\)은 과이완, \(\omega \lt 1\)은 부족 이완. 반복 행렬은 \(G_\omega = (D - \omega L)^{-1}\bigl((1-\omega)D + \omega U\bigr)\).

놀랍게도 많은 실용 행렬에서 \(\rho(G_\omega)\)를 \(\omega\)의 함수로 정확히 쓸 수 있습니다. 조건은 행렬이 일관된 순서(consistently ordered)를 갖는 것인데, 삼중대각 행렬과 5점 격자 행렬(자연 순서나 적흑 순서)이 여기에 속합니다.

정리 13.5 (영의 정리) \(A\)가 일관된 순서를 갖고 \(G_J\)의 고유값 \(\mu\)가 모두 실수이며 \(\rho_J = \rho(G_J) \lt 1\)이라 하자. 그러면 \(G_\omega\)의 고유값 \(\lambda\)와 \(\mu\)는
$$(\lambda + \omega - 1)^2 = \lambda\,\omega^2\mu^2$$
로 이어지고, 특히 \(\rho_{GS} = \rho_J^2\)이다. \(\rho(G_\omega)\)를 최소로 하는 값과 그때의 스펙트럼 반지름은
$$\omega^* = \frac{2}{1 + \sqrt{1 - \rho_J^2}},\qquad \rho(G_{\omega^*}) = \omega^* - 1.$$
\(\omega \ge \omega^*\)에서는 \(\rho(G_\omega) = \omega - 1\)로 직선이고, \(\omega \lt \omega^*\)에서는 \(\rho = \bigl(\tfrac12\omega\rho_J + \sqrt{\tfrac14\omega^2\rho_J^2 - \omega + 1}\bigr)^2\)이다.

아이디어. 고유값 관계를 \(\lambda\)의 이차방정식 \(\lambda - \omega\mu\sqrt\lambda + (\omega - 1) = 0\)(\(\sqrt\lambda\)에 대해)으로 보면, 판별식이 음수가 되는 \(\omega\)부터 두 근 \(\sqrt\lambda\)가 켤레 복소수가 되어 \(|\sqrt\lambda|^2 = \omega - 1\)(근의 곱), 곧 \(|\lambda| = \omega - 1\)이다. 판별식이 정확히 0이 되는 \(\omega\), 곧 \(\omega^2\rho_J^2 = 4(\omega - 1)\)의 작은 근이 \(\omega^*\)이다. ∎

2차원 푸아송 문제(한 변 \(N\)점, \(h = 1/(N+1)\))에서는 \(\rho_J = \cos\pi h\)이므로 \(\sqrt{1 - \rho_J^2} = \sin\pi h\)이고

$$\rho_J \approx 1 - \frac{\pi^2h^2}{2},\qquad \rho_{GS} \approx 1 - \pi^2h^2,\qquad \omega^* = \frac{2}{1 + \sin\pi h},\qquad \rho_{SOR} \approx 1 - 2\pi h.$$

1에서 떨어진 거리가 \(h^2\)에서 \(h\)로 바뀝니다. 오차를 일정 배 줄이는 반복 수가 \(O(N^2)\)에서 \(O(N)\)으로 줄어든다는 뜻입니다.

예제 13.3 (N = 31 판의 SOR) \(h = 1/32\).
  1. \(\rho_J = \cos(\pi/32) = 0.99518\), \(\rho_{GS} = 0.99039\), \(\omega^* = 2/(1 + \sin(\pi/32)) = 1.8215\), \(\rho_{SOR} = 0.8215\).
  2. 오차를 \(10^{-6}\)배 줄이는 점근적 횟수 \(\ln 10^{-6}/\ln\rho\): 야코비 2863, 가우스–자이델 1432, 최적 SOR 71.
  3. 무작위 해 \(\mathbf x^*\)로 실험하면 가우스–자이델 1091회, \(\omega^*\)의 SOR 83회였다. 가우스–자이델이 예측보다 빠른 것은 \(\mathbf e_0\)에 가장 느린 모드의 성분이 작기 때문이고, SOR이 조금 느린 것은 \(\omega^*\)에서 \(G_\omega\)가 대각화되지 않아(겹근) 초반에 \(k\rho^k\) 꼴로 줄기 때문이다. 같은 실험에서 가장 적은 횟수(70회)는 \(\omega = 1.77\)에서 나왔다.

매개변수 없이 빠른 방법

SOR은 \(\omega^*\)를 알 때만 빠르고, \(\omega^*\)는 모델 문제에서나 공식으로 나옵니다. 행렬이 대칭 양정치이기만 하면 아무 매개변수 없이 빠른 방법은 없을까요? 실마리는 연립방정식을 최솟값 문제로 바꾸는 데 있습니다.

정리 13.6 (연립방정식 = 이차 함수의 최소화) \(A\)가 SPD이면 \(A\mathbf x = \mathbf b\)의 해 \(\mathbf x^*\)는
$$\phi(\mathbf x) = \tfrac12\mathbf x^{\mathsf T}A\mathbf x - \mathbf b^{\mathsf T}\mathbf x$$
의 유일한 최솟점이다. \(\nabla\phi = A\mathbf x - \mathbf b = -\mathbf r\)이고 \(\phi(\mathbf x) - \phi(\mathbf x^*) = \tfrac12\|\mathbf x - \mathbf x^*\|_A^2\), 여기서 \(\|\mathbf e\|_A = \sqrt{\mathbf e^{\mathsf T}A\mathbf e}\)는 A-노름(energy norm)이다.

\(\phi\)의 등고선은 \(A\)의 고유벡터를 축으로 하는 타원이고, 긴 축과 짧은 축의 길이 비는 \(\sqrt\kappa\)(\(\kappa = \lambda_{\max}/\lambda_{\min}\))입니다. 잔차 \(\mathbf r\)은 가장 가파른 내리막 방향입니다. 그 방향의 직선 \(\mathbf x + \alpha\mathbf r\) 위에서 \(\phi\)를 최소로 하는 \(\alpha\)는 \(\frac{d}{d\alpha}\phi = -\mathbf r^{\mathsf T}\mathbf r + \alpha\,\mathbf r^{\mathsf T}A\mathbf r = 0\)에서 나옵니다.

function steepest_descent(A, b, x, tol)
  r = b - A x
  while norm(r) > tol * norm(b)
    q = A r                                // 반복마다 행렬–벡터 곱 한 번
    alpha = dot(r, r) / dot(r, q)          // 직선 위의 정확한 최솟점
    x = x + alpha * r
    r = r - alpha * q                      // b - A x 를 다시 계산하지 않는다
  return x
정리 13.7 (최급 강하의 수렴) SPD 행렬에서 정확한 직선 탐색을 쓰는 최급 강하법(steepest descent)은
$$\|\mathbf e_{k+1}\|_A \le \frac{\kappa - 1}{\kappa + 1}\,\|\mathbf e_k\|_A$$
를 만족한다(칸토로비치 부등식에서 나온다). 연속한 두 잔차는 서로 수직이다(\(\mathbf r_{k+1}^{\mathsf T}\mathbf r_k = 0\)). 그래서 길쭉한 골짜기에서는 벽 사이를 오가는 지그재그가 된다.
예제 13.4 (2 × 2 최급 강하) \(A = \begin{bmatrix}5 & 2\\ 2 & 2\end{bmatrix}\)(고유값 6, 1, \(\kappa = 6\)), \(\mathbf b = (7, 4)\), 해 \((1, 1)\), \(\mathbf x_0 = \mathbf 0\).
  1. \(\mathbf r_0 = (7, 4)\), \(A\mathbf r_0 = (43, 22)\), \(\alpha_0 = 65/389 = 0.16710\), \(\mathbf x_1 = (1.16967,\ 0.66838)\).
  2. \(\mathbf r_1 = (-0.18509,\ 0.32391)\). \(\mathbf r_0^{\mathsf T}\mathbf r_1 = 7(-0.18509) + 4(0.32391) = 0\)으로 수직이다. \(\alpha_1 = 0.98485\), \(\mathbf x_2 = (0.98738,\ 0.98738)\).
  3. A-노름 오차는 3.3166, 0.37258, 0.041855, 0.0047020, …로 매번 정확히 0.1123배다. 2차원에서는 지그재그가 두 방향을 번갈아 오가므로 비가 일정하다. 상한 \((\kappa - 1)/(\kappa + 1) = 5/7 = 0.714\)는 최악의 시작점에서 나온다.

켤레 기울기법

지그재그의 원인은 새 방향으로 최소화하면서 이전 방향에서 얻은 최소성을 망치는 데 있습니다. 해결책은 방향들을 \(A\)에 대해 서로 "수직"으로 고르는 것입니다. \(\mathbf p_i^{\mathsf T}A\mathbf p_j = 0\)(\(i \ne j\))이면 \(\mathbf p_i, \mathbf p_j\)를 A-켤레(A-conjugate)라 합니다. \(A = R^{\mathsf T}R\)로 좌표를 \(\mathbf y = R\mathbf x\)로 바꾸면 타원 등고선이 원이 되고, A-켤레 방향은 그 좌표에서 평범한 직교 방향입니다. 원 위에서 서로 수직인 방향으로 한 번씩 최소화하면 \(n\)번 만에 중심에 닿습니다.

A-켤레 방향을 미리 구하는 것은 비쌉니다(그람–슈미트에 모든 이전 방향이 필요). 켤레 기울기법(conjugate gradient, CG)의 기적은 새 잔차를 바로 직전 방향 하나에 대해서만 A-켤레로 만들어도 모든 이전 방향과 저절로 A-켤레가 된다는 것입니다.

function cg(A, b, x, tol)
  r = b - A x;  p = r;  rr = dot(r, r)
  while sqrt(rr) > tol * norm(b)
    q = A p
    alpha = rr / dot(p, q)                 // p 방향의 정확한 최소화
    x = x + alpha * p
    r = r - alpha * q
    rr_new = dot(r, r)
    beta = rr_new / rr                     // 새 방향을 p와 A-켤레로
    p = r + beta * p
    rr = rr_new
  return x                               // 반복당: 곱 1번, 내적 2번, 벡터 갱신 3번
정리 13.8 (CG의 구조) \(A\)가 SPD이고 \(\mathbf r_k \ne 0\)이면
  1. 잔차들은 서로 직교하고(\(\mathbf r_i^{\mathsf T}\mathbf r_j = 0\)), 방향들은 서로 A-켤레다(\(\mathbf p_i^{\mathsf T}A\mathbf p_j = 0\)), \(i \ne j\).
  2. \(\mathrm{span}\{\mathbf p_0, \dots, \mathbf p_{k-1}\} = \mathrm{span}\{\mathbf r_0, A\mathbf r_0, \dots, A^{k-1}\mathbf r_0\} = \mathcal K_k(A, \mathbf r_0)\), 크릴로프 부분공간(Krylov subspace).
  3. \(\mathbf x_k\)는 \(\mathbf x_0 + \mathcal K_k\) 안에서 \(\|\mathbf x - \mathbf x^*\|_A\)를 최소로 하는 점이다. 따라서 정확한 산술에서 많아야 \(n\)번에 끝난다.

증명의 핵심. 귀납법. \(\mathbf r_{k+1} = \mathbf r_k - \alpha_kA\mathbf p_k\)와 \(\alpha_k\)의 정의로 \(\mathbf r_{k+1} \perp \mathbf r_k\), \(\beta_k\)의 정의로 \(\mathbf p_{k+1} \perp_A \mathbf p_k\)가 바로 나온다. \(j \lt k\)에 대해서는 \(A\mathbf p_j \in \mathcal K_{j+2} = \mathrm{span}\{\mathbf r_0, \dots, \mathbf r_{j+1}\}\)이고 \(\mathbf r_{k+1}\)은 이미 그 모든 잔차와 직교하므로 \(\mathbf r_{k+1}^{\mathsf T}A\mathbf p_j = 0\), 따라서 \(\mathbf p_{k+1}^{\mathsf T}A\mathbf p_j = 0\). 잔차가 \(\mathcal K_k\)에 직교한다는 것이 곧 A-노름 최소의 조건(갈료르킨 조건)이다. ∎

최소성에서 수렴 속도가 나옵니다. \(\mathbf x_k - \mathbf x^* = P_k(A)(\mathbf x_0 - \mathbf x^*)\)이고 \(P_k\)는 \(P_k(0) = 1\)인 \(k\)차 다항식 중 무엇이든 될 수 있으므로, 고유벡터로 전개하면

$$\frac{\|\mathbf e_k\|_A}{\|\mathbf e_0\|_A} \le \min_{P_k(0) = 1}\ \max_{\lambda \in \sigma(A)} |P_k(\lambda)|.$$
\(\sigma(A)\)는 \(A\)의 고유값 집합. CG는 고유값 위에서 작은 값을 갖는 다항식을 스스로 찾는다.
정리 13.9 (CG의 수렴 한계)
  1. (조건수) 고유값이 \([\lambda_{\min}, \lambda_{\max}]\)에 있으면, 이 구간에서 체비쇼프 다항식(7장)을 쓰면 \(\|\mathbf e_k\|_A \le 2\Bigl(\dfrac{\sqrt\kappa - 1}{\sqrt\kappa + 1}\Bigr)^k\|\mathbf e_0\|_A\). 오차를 \(10^{-m}\)배 줄이는 데 약 \(1.15\,m\sqrt\kappa\)회.
  2. (서로 다른 고유값) \(A\)의 서로 다른 고유값이 \(m\)개뿐이면 \(P(\lambda) = \prod_i(1 - \lambda/\lambda_i)\)가 모든 고유값에서 0이므로 CG는 \(m\)번 만에 끝난다.

최급 강하의 \((\kappa - 1)/(\kappa + 1) \approx 1 - 2/\kappa\)가 CG에서는 \(1 - 2/\sqrt\kappa\)로 바뀝니다. \(\kappa = 10^4\)이면 오차를 10배 줄이는 데 최급 강하는 약 11500회, CG는 약 115회입니다. 푸아송 문제의 \(\kappa \approx 4/(\pi h)^2\)를 넣으면 CG의 반복 수는 \(O(N)\), 최적 SOR과 같은 차수이면서 \(\omega\)를 고를 필요가 없습니다.

전처리: 문제를 풀기 쉬운 꼴로 바꾸기

격자를 두 배로 하면 반복도 두 배

푸아송 문제의 CG 반복 수는 \(\sqrt\kappa \propto N\)에 비례합니다. 3차원 격자 \(200^3\)이면 천 번을 넘고, 재료 상수가 1000배 차이 나는 문제에서는 \(\kappa\)가 함께 커져 반복이 열 배 넘게 늘어납니다(아래 표). \(A\) 대신 조건수가 작은 다른 행렬을 풀 수 있다면?

\(A\)와 비슷하면서 \(M\mathbf z = \mathbf r\)이 싸게 풀리는 SPD 행렬 \(M\)을 전처리기(preconditioner)라 합니다. \(M^{-1}A\mathbf x = M^{-1}\mathbf b\)는 같은 해를 갖고, \(M \approx A\)이면 \(M^{-1}A \approx I\)라 고유값이 1 근처에 모입니다. 대칭을 유지하려면 \(M = LL^{\mathsf T}\)로 쓰고 \(L^{-1}AL^{-\mathsf T}\)에 CG를 적용하는데, 식을 정리하면 \(L\)이 사라지고 매 반복 \(M\mathbf z = \mathbf r\) 하나만 더 푸는 전처리 CG(PCG)가 됩니다.

function pcg(A, b, x, M, tol)
  r = b - A x;  z = solve(M, r);  p = z;  rz = dot(r, z)
  while norm(r) > tol * norm(b)
    q = A p
    alpha = rz / dot(p, q)
    x = x + alpha * p;  r = r - alpha * q
    z = solve(M, r)                        // 전처리: M z = r (싸게!)
    rz_new = dot(r, z);  beta = rz_new / rz
    p = z + beta * p;  rz = rz_new
  return x

\(M = A\)면 한 번에 끝나지만 \(M\)을 푸는 것이 원래 문제이고, \(M = I\)면 공짜지만 효과가 없습니다. 쓸모 있는 전처리기는 그 사이의 절충입니다.

정의 13.10 (야코비 전처리와 불완전 촐레스키)
  • 야코비(대각) 전처리 \(M = D = \mathrm{diag}(A)\). 행과 열의 크기를 맞추는 역할을 하며, 계수가 크게 다른 영역이 섞인 문제에서 효과가 크다. 대각이 상수인 행렬에서는 효과가 없다.
  • 불완전 촐레스키 IC(0): 촐레스키 분해를 하되 \(A\)에서 0이었던 자리에 생기는 채움은 버린다. 인수 \(\tilde L\)은 \(A\)의 하삼각과 같은 희소 패턴을 가져 저장·풀이 비용이 nnz에 비례하고, \(M = \tilde L\tilde L^{\mathsf T} \approx A\)이다. 5점 격자 행렬에서는 대각만 다시 계산하면 된다: \(d_p = a_{pp} - a_{p,p-1}^2/d_{p-1} - a_{p,p-N}^2/d_{p-N}\).

크릴로프 부분공간과 GMRES

바람이 부는 열 방정식

오염 물질이 바람에 실려 가며 퍼지는 대류–확산 방정식 \(-\Delta u + \beta u_x = f\)를 격자로 나누면, 대류 항 때문에 행렬이 비대칭이 됩니다. CG는 대칭 양정치를 가정하므로 쓸 수 없습니다. 실제로 억지로 돌리면 잔차가 줄지 않고 커집니다. 비대칭 행렬에서도 크릴로프 공간의 아이디어를 살릴 수 있을까요?

CG가 한 일을 다시 보면, \(\mathbf x_k\)를 크릴로프 공간 \(\mathbf x_0 + \mathcal K_k(A, \mathbf r_0)\)에서 골랐습니다. 이 공간은 행렬–벡터 곱만으로 만들어지므로 비대칭이어도 쓸 수 있습니다. 바뀌는 것은 "가장 좋은 점"의 기준입니다. A-노름은 SPD에서만 노름이므로, 대신 잔차의 2-노름을 최소화합니다. 이것이 GMRES(generalized minimal residual)입니다.

이를 위해 먼저 크릴로프 공간의 정규직교 기저를 만듭니다. \(\mathbf r_0, A\mathbf r_0, A^2\mathbf r_0, \dots\)를 그대로 쓰면 거듭제곱법처럼 모두 지배 고유벡터 쪽으로 쏠려 거의 평행해지므로, 새 벡터를 만들 때마다 그람–슈미트로 직교화합니다. 이것이 아놀디 과정(Arnoldi iteration)입니다.

function gmres(A, b, x0, m, tol)          // m: 재시작 길이
  r = b - A x0;  beta = norm(r);  v[1] = r / beta
  for j = 1 .. m                           // 아놀디: A V_m = V_(m+1) H
    w = A v[j]
    for i = 1 .. j
      H[i][j] = dot(w, v[i]);  w = w - H[i][j] * v[i]
    H[j+1][j] = norm(w);  v[j+1] = w / H[j+1][j]
    // 작은 최소제곱 문제: min_y ‖beta e1 - H y‖, 기븐스 회전으로 갱신
    if |잔차 추정| <= tol * norm(b) then break
  x = x0 + V y
  if 수렴하지 않았으면 x0 = x 로 다시 시작   // GMRES(m)
정리 13.11 (GMRES) 아놀디 과정은 \(AV_k = V_{k+1}\bar H_k\)를 만족하는 정규직교 기저 \(V_k\)와 \((k+1)\times k\) 헤센베르크 행렬 \(\bar H_k\)를 만든다. \(\mathbf x_k = \mathbf x_0 + V_k\mathbf y\)로 두면 \(\|\mathbf b - A\mathbf x_k\|_2 = \|\beta\mathbf e_1 - \bar H_k\mathbf y\|_2\)이므로 \(n\)차원 문제가 \((k+1)\times k\) 최소제곱 문제로 줄어든다. 잔차 노름은 단조 감소하며, 정확한 산술에서 많아야 \(n\)번에 끝난다. 한편 \(k\)번째 반복은 벡터 \(k\)개를 저장하고 \(k\)번의 내적을 하므로 비용이 \(k\)에 비례해 커진다.

비용이 계속 커지므로 실무에서는 \(m\)번마다 지금까지의 해를 새 출발점으로 삼아 다시 시작합니다. 이 재시작 GMRES(m)은 메모리를 \(m\)개 벡터로 묶는 대가로 크릴로프 공간에 쌓인 정보를 버리므로 더 많은 반복이 필요하고, 때로는 정체합니다. 대칭 행렬에서는 아놀디의 \(H\)가 삼중대각이 되어 직교화가 직전 두 벡터로 충분하며(란초시 과정), 이것이 CG가 짧은 점화식으로 끝나는 이유입니다. 비대칭에서 짧은 점화식을 원하면 BiCGSTAB 같은 방법을 쓰지만 최소성은 포기합니다.

다중 격자: 매끄러운 오차는 거친 격자에서

잔차는 금방 주는데 해는 그대로

가우스–자이델로 판의 온도를 풀면 처음 몇 번은 잔차가 쑥 줄다가 곧 거의 멈춥니다. 남은 오차를 그려 보면 판 전체에 걸친 완만한 언덕 모양입니다. 왜 매끄러운 오차만 남을까요? 그리고 매끄러운 것은 적은 점으로 표현할 수 있다는 사실을 이용할 수 있을까요?

1차원 모델 \(-u'' = f\)(\(N\)점, \(h = 1/(N+1)\))에서 오차를 사인 모드 \(\sin(k\pi x)\)로 전개해 봅시다. 가중 야코비 \(\mathbf x \leftarrow \mathbf x + \omega D^{-1}\mathbf r\)는 각 모드를 독립적으로 줄이며, 그 배율은

$$g_k = 1 - 2\omega\sin^2\frac{k\pi h}{2},\qquad k = 1, \dots, N.$$
\(\omega = 2/3\)이면 고주파 절반(\(k \ge N/2\))에서 \(|g_k| \le 1/3\)이다. 그러나 \(k = 1\)에서는 \(g_1 \approx 1 - \frac{\omega\pi^2h^2}{2}\), \(N = 63\)이면 0.9992로 거의 줄지 않는다.

그래서 완화 반복은 해법으로는 느리지만 평활화(smoothing)로는 훌륭합니다. 몇 번만 돌리면 고주파 오차가 사라지고 매끄러운 오차가 남습니다. 매끄러운 오차는 격자 간격을 두 배로 한 거친 격자에서도 잘 표현되며, 거기서는 같은 모드가 상대적으로 두 배 높은 주파수라 평활화가 다시 효과적입니다. 이 관찰을 재귀로 엮은 것이 다중 격자법(multigrid)입니다.

function vcycle(h, u, f)
  if 격자가 가장 거칠면 return solve_exact(A_h, f)
  u = smooth(A_h, u, f, nu)                // 가우스–자이델 2번: 고주파 제거
  r = f - A_h u
  rc = restrict(r)                         // 2h 격자로 (가중 평균)
  ec = vcycle(2h, 0, rc)                   // 오차 방정식 A_2h e = rc 를 재귀로
  u = u + prolong(ec)                      // h 격자로 (선형 보간)
  u = smooth(A_h, u, f, nu)
  return u
정리 13.12 (다중 격자의 격자 무관 수렴, 개요) 푸아송 같은 타원형 문제에서 적절한 평활기와 제한·보간 연산을 쓰면 V-사이클 한 번의 오차 축소율은 \(h\)와 무관한 상수 \(\rho_{MG} \lt 1\)로 묶인다. 한 사이클의 비용은 \(O(n)\)이므로 정해진 정확도까지 총비용이 \(O(n)\), 곧 미지수 하나당 상수 번의 연산이다. 핵심은 두 성질의 결합이다. 평활기가 고주파를 줄이고(평활 성질), 거친 격자가 저주파를 정확히 표현한다(근사 성질).

핵심 정리

  1. 큰 희소 행렬은 분해하면 채움으로 메모리와 연산이 폭발한다. 반복법은 행렬–벡터 곱(비용 ∝ nnz)만 쓰며, 목표는 반복 횟수를 줄이는 것이다.
  2. 정상 반복 \(\mathbf x_{k+1} = \mathbf x_k + M^{-1}\mathbf r_k\)의 오차는 \(\mathbf e_{k+1} = G\mathbf e_k\), \(G = I - M^{-1}A\). 수렴의 필요충분조건은 \(\rho(G) \lt 1\)이고, 오차를 \(10^{-m}\)배 줄이는 데 약 \(m/(-\log_{10}\rho)\)회가 든다.
  3. 엄격한 대각 우세이면 야코비·G–S가, SPD이면 G–S와 \(0 \lt \omega \lt 2\)의 SOR이 수렴한다. 일관된 순서의 행렬에서 \(\rho_{GS} = \rho_J^2\), \(\omega^* = 2/(1 + \sqrt{1 - \rho_J^2})\), \(\rho = \omega^* - 1\).
  4. 푸아송 문제에서 야코비·G–S는 \(O(N^2)\)회, 최적 SOR과 CG는 \(O(N)\)회, 다중 격자는 \(N\)과 무관한 횟수가 필요하다.
  5. SPD 연립방정식은 \(\phi = \tfrac12\mathbf x^{\mathsf T}A\mathbf x - \mathbf b^{\mathsf T}\mathbf x\)의 최소화다. 최급 강하는 \((\kappa - 1)/(\kappa + 1)\)로, CG는 \((\sqrt\kappa - 1)/(\sqrt\kappa + 1)\)로 수렴한다.
  6. CG는 크릴로프 공간에서 A-노름 오차를 최소화한다. 서로 다른 고유값이 \(m\)개면 \(m\)번에 끝나고, 몇 개의 큰 고유값은 몇 번의 반복으로 "잡아 낸다". 반올림은 이 성질을 늦춘다.
  7. 전처리 \(M \approx A\)는 고유값을 1 근처에 모아 반복을 줄인다. 야코비는 계수 크기 차이를, IC(0)는 채움을 버린 분해로 구조를 잡는다.
  8. 비대칭 행렬에는 아놀디 기저 위에서 잔차를 최소화하는 GMRES를 쓰고, 메모리 때문에 재시작한다. 다중 격자는 평활화로 고주파를, 거친 격자로 저주파를 없애 \(O(n)\) 비용에 푼다.

확인 퀴즈

Q1. 반복 행렬의 스펙트럼 반지름이 \(\rho = 0.9\)이다. 오차를 \(10^{-6}\)배로 줄이려면 대략 몇 번 반복해야 하는가?

\(0.9^k = 10^{-6}\)에서 \(k = 6/(-\log_{10}0.9) = 6/0.0458 \approx 131\). 반복 한 번에 맞는 자릿수가 약 0.046개 늘어나는 셈이다.

Q2. \(A = \begin{bmatrix}4 & -1\\ -1 & 4\end{bmatrix}\)에 야코비 방법을 쓸 때 \(\rho(G_J)\)와 \(\rho(G_{GS})\)는?

\(G_J = \begin{bmatrix}0 & 1/4\\ 1/4 & 0\end{bmatrix}\)의 고유값은 \(\pm1/4\). 삼중대각(일관된 순서) 행렬이므로 \(\rho_{GS} = \rho_J^2 = 1/16\). G–S가 같은 정확도에 절반의 반복으로 닿는다.

Q3. 영의 정리에서 \(\rho_J = 0.8\)이면 최적 이완 계수 \(\omega^*\)와 \(\rho(G_{\omega^*})\)는?

\(\sqrt{1 - 0.64} = 0.6\), \(\omega^* = 2/1.6 = 1.25\), \(\rho = \omega^* - 1 = 0.25\). 가우스–자이델의 \(\rho_J^2 = 0.64\)보다 훨씬 작다. 2 × 2 시뮬레이터의 '결합 강함'이 바로 이 경우다.

Q4. 100 × 100 SPD 행렬의 고유값이 1, 2, 3, 4 네 값뿐이다. 정확한 산술에서 CG는 많아야 몇 번 만에 끝나는가?

\(P(\lambda) = (1 - \lambda)(1 - \lambda/2)(1 - \lambda/3)(1 - \lambda/4)\)는 \(P(0) = 1\)이고 모든 고유값에서 0이다. CG의 오차는 이런 다항식 중 가장 좋은 것으로 줄어드므로 4번째 반복에서 0이 된다.

Q5. 조건수가 \(\kappa = 10^4\)인 SPD 문제에서 최급 강하와 CG의 "오차 10배 축소당 반복 수"의 비는 대략?

최급 강하의 축소율 \(1 - 2/\kappa\), CG의 \(1 - 2/\sqrt\kappa\). 반복 수는 각각 \(\kappa\)와 \(\sqrt\kappa\)에 비례하므로 비는 \(\sqrt\kappa = 100\)이다.

Q6. 대각 원소가 모두 4인 2차원 푸아송 행렬에 야코비(대각) 전처리를 쓴 PCG의 반복 수는 전처리 없는 CG와 비교해?

\(M = 4I\)는 문제 전체를 1/4배 할 뿐 \(M^{-1}A\)의 고유값 분포(비율)를 바꾸지 않는다. 야코비 전처리는 계수가 영역마다 크게 다를 때 효과가 있다.

Q7. \(N = 63\) 격자에서 가중 야코비(ω = 2/3)가 가장 매끄러운 오차 모드 \(k = 1\)을 한 번에 줄이는 배율은 약 얼마인가?

\(g_1 = 1 - \tfrac43\sin^2(\pi/128) = 0.9992\). 고주파는 1/3 이하로 줄지만 저주파는 거의 그대로라서, 다중 격자는 이를 거친 격자에서 처리한다.

Q8. 완전 GMRES 대신 재시작 GMRES(m)를 쓰는 주된 이유는?

완전 GMRES의 잔차는 단조 감소하고 가장 적은 반복으로 끝나지만, 아놀디 기저 전체를 저장하고 매번 모든 벡터와 직교화해야 한다. 재시작은 메모리를 묶는 대신 반복이 늘고 정체할 수도 있다.
