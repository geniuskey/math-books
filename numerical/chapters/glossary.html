열여섯 장의 알고리즘을 한곳에 모았습니다. 문제 앞에서 실제로 묻는 것은 늘 넷입니다. 어떤 방법을 쓸까, 오차는 h나 반복 수에 따라 얼마나 줄까, 비용은 얼마일까, 언제 터질까. 고르기 도우미 → 오차·비용 한눈표 → 수렴 차수 → 안정성 조건 → 용어 검색 → 종합 퀴즈 순서입니다.

수렴 차수 경주: 10⁻¹⁵까지 몇 번?

가로축
모델: eₙ₊₁ = C·eₙᵖ. 선형(p = 1)은 위 슬라이더의 C, 초선형은 C = 1로 둡니다. 함수 계산 수는 선형·할선 1, 뉴턴 2(f, f′)로 셉니다. 해볼 것: ① e₀를 10⁻³으로 줄이면 2차·3차는 한두 번 덜 걸리고, 선형은 줄어든 자릿수만큼 꼬박 덜 걸립니다. ② '함수 계산 수'에서 할선법이 뉴턴을 앞지르는지 보세요(효율 지수 1.618 대 1.414). ③ C = 0.95는 ρ(G)가 1에 가까운 야코비 반복이나 |λ₂/λ₁| ≈ 1인 거듭제곱법의 모습입니다.

안정성이 정하는 걸음 폭

ODE 칸은 t ∈ [0, 10]을 가는 데 필요한 최소 걸음 수(명시적 방법은 h ≤ ℓ/|λ|, ℓ은 위 표의 음의 실수축 안정 구간 길이)이고, PDE 칸은 Δt의 상한입니다. 해볼 것: ① |λ|를 10⁶으로 올리면 명시적 방법의 걸음 수가 수백만이 됩니다. 느린 성분만 보고 싶은 강성 문제라면 BDF는 정확도가 허락하는 만큼 크게 걷습니다(11장). ② Δx를 반으로 줄이면 열 FTCS의 Δt는 4분의 1, 이류·파동의 Δt는 2분의 1이 됩니다. 확산이 명시적 방법에 더 가혹한 이유입니다(16장).
