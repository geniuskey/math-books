3차 정확한 공식이 왜 터지는가

두 걸음짜리 명시적 공식 \(y_{n+2} + 4y_{n+1} - 5y_n = h(4f_{n+1} + 2f_n)\)을 생각해 봅시다. 테일러 전개로 확인하면 국소 절단 오차가 \(O(h^4)\), 즉 3차 정확합니다. 애덤스–배시포스 2단계(2차)보다 한 차수 높고 계산량은 같습니다. 그런데 \(y' = -y\)에 \(h = 0.1\)로 돌리면 \(y(1)\)의 오차가 7, \(h = 0.05\)로 줄이면 \(4.7\times10^{6}\)입니다. 걸음을 줄일수록 더 틀립니다. 무엇이 빠졌을까요?

ODEBook 5장의 정리 5.3은 오일러 방법에 대해 "국소 오차 \(O(h^2)\)가 쌓여 전역 오차 \(O(h)\)"라는 것을 보였습니다. 그 증명에서 몰래 쓴 성질이 하나 있습니다. 앞선 오차가 다음 걸음에서 많아야 \(1 + hL\)배로 커진다는 것, 곧 오차가 걸음마다 폭발하지 않는다는 성질입니다. 수렴하려면 이것과 "한 걸음이 맞다"는 성질이 둘 다 필요합니다.

정의 11.1 (일관성·차수, 일단계 방법) 일단계 방법을 \(y_{n+1} = y_n + h\,\Phi(t_n, y_n; h)\)로 쓰자(\(\Phi\)를 증분 함수(increment function)라 한다). 참 해 \(y(t)\)를 대입했을 때 남는 양
$$\tau_{n+1} = \frac{y(t_{n+1}) - y(t_n)}{h} - \Phi(t_n, y(t_n); h)$$
를 (단위 걸음당) 국소 절단 오차라 한다. \(h \to 0\)에서 \(\tau \to 0\)이면 일관성(consistency)이 있다고 하고, \(\tau = O(h^p)\)이면 p차라 한다. 일관성은 \(\Phi(t, y; 0) = f(t, y)\)와 같다.
정리 11.2 (일단계 방법의 수렴) \(\Phi\)가 \(y\)에 대해 립시츠 상수 \(L_\Phi\)를 가지고 방법이 p차로 일관적이면, 유한 구간 \([t_0, T]\)에서 전역 오차는
$$\max_n |y(t_n) - y_n| \le \frac{e^{L_\Phi (T - t_0)} - 1}{L_\Phi}\,\max_n|\tau_n| = O(h^p).$$

증명의 핵심. \(E_{n+1} = E_n + h\bigl(\Phi(y(t_n)) - \Phi(y_n)\bigr) + h\tau_{n+1}\)이므로 \(|E_{n+1}| \le (1 + hL_\Phi)|E_n| + h|\tau|\). 오일러 때와 똑같이 등비급수로 더하면 된다. 룽게–쿠타 방법의 \(\Phi\)는 \(f\)를 유한 번 합성한 것이라 \(f\)가 립시츠이면 \(\Phi\)도 립시츠다. 따라서 일단계 방법은 일관적이기만 하면 언제나 수렴한다. ∎

다단계 방법은 사정이 다릅니다. \(k\)단계 선형 다단계 방법(linear multistep method)은

$$\sum_{j=0}^{k} \alpha_j\, y_{n+j} = h \sum_{j=0}^{k} \beta_j\, f_{n+j}, \qquad f_{n+j} = f(t_{n+j}, y_{n+j}),\quad \alpha_k = 1$$
\(\beta_k = 0\)이면 명시적, \(\beta_k \ne 0\)이면 음적이다. 특성 다항식 \(\rho(\zeta) = \sum \alpha_j\zeta^j\), \(\sigma(\zeta) = \sum\beta_j\zeta^j\)로 방법을 요약한다.

꼴이고, 다음 값이 \(k\)개의 이전 값으로 정해지는 차분 방정식입니다. \(h = 0\)으로 두면 \(\sum\alpha_j y_{n+j} = 0\), 해는 \(\rho\)의 근 \(\zeta_i\)에 대해 \(\zeta_i^n\) 꼴입니다. 참 해에 해당하는 근은 \(\zeta = 1\)(일관성 조건 \(\rho(1) = 0\))이고 나머지는 계산이 만들어 낸 기생 해입니다. 반올림 오차나 출발값 오차가 이 기생 해를 조금이라도 깨우면, \(|\zeta_i| > 1\)일 때 그것이 \(|\zeta_i|^n\)으로 자랍니다. \(n = (T - t_0)/h\)이므로 걸음을 줄일수록 더 많이 자랍니다.

정의 11.3 (근 조건과 영 안정성) \(\rho(\zeta)\)의 모든 근이 \(|\zeta| \le 1\)이고, \(|\zeta| = 1\)인 근은 모두 단근이면 방법이 근 조건(root condition)을 만족한다고 하고, 이런 방법을 영 안정(zero-stable)이라 한다. 일단계 방법은 \(\rho(\zeta) = \zeta - 1\)이라 언제나 영 안정이다.
정리 11.4 (달퀴스트 동등성 정리) 출발값 오차가 \(h \to 0\)에서 0으로 가는 선형 다단계 방법이 수렴할 필요충분조건은 일관성과 영 안정성이다. 또한 영 안정인 \(k\)단계 방법의 차수는 \(k\)가 홀수면 \(k + 1\), 짝수면 \(k + 2\)를 넘지 못하고, 명시적이면 \(k\)를 넘지 못한다(달퀴스트 제1 장벽).

이 "일관성 + 안정성 ⇔ 수렴"은 수치해석 전체를 꿰는 원리입니다. 16장에서 편미분방정식의 격자 방법에 대해 같은 모양의 랙스 동등성 정리를 다시 만납니다(16장). 문제 상자의 공식은 \(\rho(\zeta) = \zeta^2 + 4\zeta - 5 = (\zeta - 1)(\zeta + 5)\)이라 기생 근 \(-5\)가 있습니다. 2단계 명시적 공식이 3차라는 것 자체가 제1 장벽(명시적이면 차수 ≤ 2)을 넘었으니, 영 안정일 수가 없었던 것입니다.

룽게–쿠타 계열과 부처 표

기울기 계산 네 번으로 4차, 그다음은?

RK4는 기울기를 네 번 재서 4차를 얻습니다. 그럼 다섯 번 재면 5차가 될까요? 그렇지 않습니다. 5차를 얻으려면 최소 여섯 번이 필요합니다. 계수가 수십 개인 공식을 설계하고 검증하려면 공식을 적는 표준 형식과 차수를 확인하는 체계적인 조건이 필요합니다.

\(s\)단 명시적 룽게–쿠타 방법은 단계 기울기 \(k_i\)를 앞선 기울기의 조합으로 차례로 계산하고, 마지막에 가중 평균으로 걷습니다.

정의 11.5 (룽게–쿠타 방법과 부처 표)
$$k_i = f\Bigl(t_n + c_i h,\ y_n + h\sum_{j=1}^{i-1} a_{ij}k_j\Bigr),\quad i = 1, \dots, s, \qquad y_{n+1} = y_n + h\sum_{i=1}^{s} b_i k_i.$$
계수를 \(\begin{array}{c|c} \mathbf c & A \\ \hline & \mathbf b^{\mathsf T}\end{array}\) 꼴의 표로 적은 것을 부처 표(Butcher tableau)라 한다. 명시적 방법은 \(A\)가 순하삼각(대각 포함 위쪽이 0)이다. 보통 \(c_i = \sum_j a_{ij}\)로 둔다(행 합 조건).

차수 조건은 방법의 한 걸음과 참 해의 테일러 전개를 \(h\)의 거듭제곱별로 맞춘 것입니다. 스칼라 자율 방정식만 보면 조건이 실제보다 적게 보이므로, 부처는 연립 방정식의 전개에 나타나는 항을 뿌리 있는 나무(rooted tree)로 분류했습니다. 차수 \(q\)의 나무 하나가 조건 하나이고, 나무의 개수는 \(q = 1, 2, 3, 4, 5\)에서 1, 1, 2, 4, 9개입니다.

정리 11.6 (4차까지의 차수 조건) \(c_i = \sum_j a_{ij}\)일 때 명시적 룽게–쿠타 방법이 p차일 필요충분조건은 아래 표에서 차수 \(\le p\)인 조건이 모두 성립하는 것이다.
차수조건
1\(\sum b_i = 1\)
2\(\sum b_ic_i = \tfrac12\)
3\(\sum b_ic_i^2 = \tfrac13,\quad \sum b_ia_{ij}c_j = \tfrac16\)
4\(\sum b_ic_i^3 = \tfrac14,\ \ \sum b_ic_ia_{ij}c_j = \tfrac18,\ \ \sum b_ia_{ij}c_j^2 = \tfrac1{12},\ \ \sum b_ia_{ij}a_{jk}c_k = \tfrac1{24}\)
누적 조건 수는 p = 1, …, 8에서 1, 2, 4, 8, 17, 37, 85, 200개로 빠르게 늘어난다. 또한 부처 장벽에 따라 명시적 방법에서 \(s = p\)는 \(p \le 4\)까지만 가능하고, 5차는 6단, 6차는 7단, 7차는 9단이 필요하다.
예제 11.2 (고전 RK4가 4차임을 표로 확인) \(\mathbf b = (\tfrac16, \tfrac13, \tfrac13, \tfrac16)\), \(\mathbf c = (0, \tfrac12, \tfrac12, 1)\), \(a_{21} = a_{32} = \tfrac12\), \(a_{43} = 1\).
  1. \(\sum b_i = \tfrac16 + \tfrac13 + \tfrac13 + \tfrac16 = 1\). \(\sum b_ic_i = \tfrac13\cdot\tfrac12 + \tfrac13\cdot\tfrac12 + \tfrac16 = \tfrac12\).
  2. \(\sum b_ic_i^2 = \tfrac13\cdot\tfrac14\cdot 2 + \tfrac16 = \tfrac13\). \(\sum b_ia_{ij}c_j\): \(a_{32}c_2 = \tfrac14\), \(a_{43}c_3 = \tfrac12\)이므로 \(\tfrac13\cdot\tfrac14 + \tfrac16\cdot\tfrac12 = \tfrac16\).
  3. \(\sum b_ic_i^3 = \tfrac23\cdot\tfrac18 + \tfrac16 = \tfrac14\). \(\sum b_ic_ia_{ij}c_j = \tfrac13\cdot\tfrac12\cdot\tfrac14 + \tfrac16\cdot 1\cdot\tfrac12 = \tfrac18\).
  4. \(\sum b_ia_{ij}c_j^2 = \tfrac13\cdot\tfrac12\cdot\tfrac14 + \tfrac16\cdot\tfrac14 = \tfrac1{12}\). \(\sum b_ia_{ij}a_{jk}c_k\): 유일한 사슬 \(4 \to 3 \to 2\)가 \(\tfrac16\cdot 1\cdot\tfrac12\cdot\tfrac12 = \tfrac1{24}\).
  5. 여덟 조건이 모두 성립하므로 4차다. 5차 조건(9개 중 하나 \(\sum b_ic_i^4 = \tfrac15\))은 \(\tfrac23\cdot\tfrac1{16} + \tfrac16 = \tfrac5{24} \ne \tfrac15\)라 깨진다.
예제 11.3 (쿠타 3차 한 걸음) 쿠타의 3차 방법 \(k_1 = f(t, y)\), \(k_2 = f(t + \tfrac h2, y + \tfrac h2k_1)\), \(k_3 = f(t + h, y - hk_1 + 2hk_2)\), \(y_{n+1} = y_n + \tfrac h6(k_1 + 4k_2 + k_3)\)로 \(y' = y^2\), \(y(0) = 1\), \(h = 0.1\)을 한 걸음 계산하라(참 해 \(1/(1 - t)\)).
  1. \(k_1 = 1\), \(k_2 = (1.05)^2 = 1.1025\), \(k_3 = (1 - 0.1 + 0.2205)^2 = 1.1205^2 = 1.255520\).

    1. 어느 쪽으로 걸을까. 추정한 것은 낮은 차수 쪽 오차지만, 채택된 걸음은 높은 차수 쪽 값으로 진행합니다. 이것을 국소 외삽(local extrapolation)이라 합니다. 도르만드–프린스 5(4)는 5차로, 보가키–샴핀 3(2)는 3차로 걷습니다.

  t ← t0;  y ← y0;  h ← 초기 추정        // 예: 0.01·|y0| / |f(t0, y0)|
  while t < T
    h ← min(h, T − t)
    k[1..s] ← 단계 기울기 (부처 표 A, c)
    y_hi ← y + h·Σ bᵢ kᵢ                  // 높은 차수: 채택되면 이 값으로 진행
    e    ← h·Σ (bᵢ − b̂ᵢ) kᵢ               // 오차 추정 (추가 f 계산 없음)
    err  ← max over i of |eᵢ| / (atol + rtol·max(|yᵢ|, |y_hiᵢ|))

    RK4는 한 걸음에 기울기를 네 번 재고, 다음 걸음에서는 그것을 모두 버립니다. \(f\) 한 번 계산이 유체 시뮬레이션 한 판처럼 비싸다면 아깝습니다. 지난 몇 걸음의 기울기 \(f_{n}, f_{n-1}, \dots\)는 이미 손에 있습니다. 그것으로 다음 걸음을 4차로 걸을 수 있을까요?

    \(y(t_{n+1}) = y(t_n) + \int_{t_n}^{t_{n+1}} f(t, y(t))\,dt\)에서 피적분 함수를 이미 아는 점들을 지나는 보간 다항식(5장)으로 바꾸고 정확히 적분합니다. 보간점으로 \(t_n, t_{n-1}, \dots, t_{n-k+1}\)을 쓰면 구간 밖으로 외삽하는 명시적 공식, \(t_{n+1}\)까지 넣으면 음적 공식이 됩니다.

    정의 11.8 (애덤스 방법) \(k\)단계 애덤스–배시포스(Adams–Bashforth, AB) 방법(명시적, 차수 \(k\))과 애덤스–몰턴(Adams–Moulton, AM) 방법(음적, 차수 \(k + 1\)):
    $$\begin{aligned} \text{AB2: } & y_{n+1} = y_n + \tfrac{h}{2}(3f_n - f_{n-1}), \\ \text{AB4: } & y_{n+1} = y_n + \tfrac{h}{24}(55f_n - 59f_{n-1} + 37f_{n-2} - 9f_{n-3}), \\ \text{AM2 (사다리꼴): } & y_{n+1} = y_n + \tfrac{h}{2}(f_{n+1} + f_n), \\ \text{AM4: } & y_{n+1} = y_n + \tfrac{h}{24}(9f_{n+1} + 19f_n - 5f_{n-1} + f_{n-2}). \end{aligned}$$
    국소 오차의 주항은 \(C_{p+1}h^{p+1}y^{(p+1)}\)이고 오차 상수는 AB2 \(\tfrac5{12}\), AM2 \(-\tfrac1{12}\), AB4 \(\tfrac{251}{720}\), AM4 \(-\tfrac{19}{720}\)이다. 같은 차수에서 음적 공식의 오차 상수가 훨씬 작다.

    AB2의 계수는 \(f_{n-1}, f_n\)을 지나는 직선 \(p(t) = f_n + (t - t_n)(f_n - f_{n-1})/h\)를 \([t_n, t_n + h]\)에서 적분하면 \(h f_n + \tfrac h2(f_n - f_{n-1}) = \tfrac h2(3f_n - f_{n-1})\)으로 바로 나옵니다. 다단계 방법에는 실무상 두 가지 일이 따라붙습니다. 첫째, 출발: 처음 \(k - 1\)개의 값은 RK4 같은 일단계 방법으로 만듭니다. 둘째, 걸음 폭 바꾸기: 계수가 등간격을 가정하므로 \(h\)를 바꾸려면 보간을 다시 하거나 계수를 다시 계산해야 합니다.

    음적인 AM은 \(y_{n+1}\)을 풀어야 합니다. 강성이 없는 문제에서는 뉴턴 반복까지 필요 없고, AB로 예측한 값을 AM의 우변에 넣어 한 번 수정하는 것으로 충분합니다.

    // PECE: AB(k) 예측 → f 계산 → AM 수정 → f 계산
for n = k−1, k, …
  y_p ← yₙ + h·Σ βⱼᴬᴮ fₙ₋ⱼ              // P: 예측 (외삽)
  f_p ← f(tₙ₊₁, y_p)                    // E: 계산
  yₙ₊₁ ← yₙ + h·(β₀ᴬᴹ f_p + Σ βⱼᴬᴹ fₙ₊₁₋ⱼ)  // C: 수정
  fₙ₊₁ ← f(tₙ₊₁, yₙ₊₁)                  // E: 다음 걸음용
  est ← |yₙ₊₁ − y_p| · |C_AM| / |C_AB − C_AM|   // 밀른의 오차 추정
end for

    AB4는 AB2보다 두 차수 높지만, \(y' = -y\)처럼 단순한 감쇠 문제에서 \(h = 0.5\)로 돌리면 AB2는 줄어드는데 AB4는 진동하며 커집니다. 차수가 높을수록 외삽이 공격적이라 안정 영역이 좁아집니다. 방법을 고를 때 차수만큼 중요한 것이 안정성 영역의 모양입니다.

    시험 방정식 \(y' = \lambda y\)에 선형 다단계 방법을 쓰면 \(\sum(\alpha_j - z\beta_j)y_{n+j} = 0\)(\(z = h\lambda\))입니다. 이 차분 방정식의 해는 안정성 다항식(stability polynomial) \(\pi(\zeta; z) = \rho(\zeta) - z\sigma(\zeta)\)의 근 \(\zeta_i(z)\)의 거듭제곱입니다. 룽게–쿠타의 \(|R(z)| \le 1\)에 해당하는 조건이 "모든 근이 단위원 안"입니다.

    정의 11.9 (다단계 방법의 절대 안정 영역) \(\pi(\zeta; z)\)의 모든 근이 \(|\zeta| \le 1\)이고 \(|\zeta| = 1\)인 근은 단근인 \(z \in \mathbb C\)의 집합을 절대 안정 영역이라 한다. 영역의 경계는 \(\zeta = e^{i\theta}\)를 대입한 경계 궤적 \(z(\theta) = \rho(e^{i\theta})/\sigma(e^{i\theta})\), \(0 \le \theta \lt 2\pi\) 위에 있다.
    정의 11.10 (A-안정, A(α)-안정, L-안정) 절대 안정 영역이 왼쪽 반평면 전체를 포함하면 A-안정, 음의 실수축을 중심으로 반각 \(\alpha\)인 쐐기 \(\{|\arg(-z)| \lt \alpha\}\)를 포함하면 A(α)-안정, A-안정이면서 \(|R(z)| \to 0\)(\(z \to -\infty\))이면 L-안정(L-stable)이라 한다. L-안정 방법은 아주 빠른 성분을 한 걸음 만에 지운다.
    정리 11.11 (달퀴스트 제2 장벽) A-안정인 선형 다단계 방법은 음적이어야 하고 차수가 2 이하이다. 2차 A-안정 방법 중 오차 상수의 절댓값이 가장 작은 것은 사다리꼴 공식(\(C_3 = -\tfrac1{12}\))이다.

    사다리꼴 공식은 A-안정이지만 \(R(z) = \frac{1 + z/2}{1 - z/2} \to -1\)(\(z \to -\infty\))이라 L-안정은 아닙니다. 아주 빠른 성분이 지워지지 않고 부호만 바꾸며 남아 회로 시뮬레이터에서 "링잉"이라 불리는 가짜 진동을 만듭니다. BDF1(음적 오일러)과 BDF2는 L-안정입니다. 3차 이상의 BDF는 제2 장벽 때문에 A-안정일 수 없지만 큰 각도의 A(α)-안정을 가집니다.

    강성과 BDF: 음적 방법의 뉴턴 반복

    세 물질의 반응을 40초 동안

    로버트슨의 화학 반응 모형은 강성 문제의 시험대로 널리 쓰입니다. \(A \to B\)(속도 0.04), \(B + C \to A + C\)(속도 \(10^4\)), \(2B \to B + C\)(속도 \(3\times10^7\)). 농도 \(y_1, y_2, y_3\)은

    \(y_1' = -0.04y_1 + 10^4y_2y_3,\quad y_2' = 0.04y_1 - 10^4y_2y_3 - 3\times10^7y_2^2,\quad y_3' = 3\times10^7y_2^2\)

    을 따르고 \(y(0) = (1, 0, 0)\)입니다. 중간 물질 \(y_2\)는 \(t \approx 0.005\)에서 최댓값 \(3.6\times10^{-5}\)에 닿은 뒤 아주 천천히 줄어듭니다. 해가 이렇게 느린데 도르만드–프린스 5(4)(tol = \(10^{-4}\))로 \(t = 40\)까지 가는 데 34,557걸음(버린 걸음 1,550)이 걸립니다. 같은 tol의 BDF2는 154걸음입니다.

    원인은 야코비안 \(J = \partial f/\partial y\)의 고유값입니다. \(t = 40\) 부근에서 \(J\)의 고유값은 \(0\)(질량 보존 \(y_1 + y_2 + y_3 = 1\)), \(-0.0214\), \(-3393\)입니다. 해의 변화는 \(-0.02\)짜리 느린 모드가 정하지만, 명시적 방법의 걸음은 \(h|\lambda_{\max}| \lesssim 3.3\)(DP5의 실수축 안정 경계)에 묶여 \(h \approx 10^{-3}\)을 넘지 못합니다. \(40/10^{-3} = 4\times10^4\)걸음, 관찰한 걸음 수와 맞습니다. 강성비 \(3393/0.0214 \approx 1.6\times10^5\)가 걸음 수의 비가 됩니다.

    정의 11.12 (후방 차분 공식, BDF) \(k\)단계 BDF(backward differentiation formula)는 \(y_{n+1}, y_n, \dots, y_{n+1-k}\)를 지나는 보간 다항식의 도함수를 \(t_{n+1}\)에서 \(f(t_{n+1}, y_{n+1})\)과 같게 놓은 음적 공식이다.
    $$\begin{aligned} \text{BDF1: } & y_{n+1} - y_n = hf_{n+1}, \\ \text{BDF2: } & y_{n+1} - \tfrac43y_n + \tfrac13y_{n-1} = \tfrac23hf_{n+1}, \\ \text{BDF3: } & y_{n+1} - \tfrac{18}{11}y_n + \tfrac9{11}y_{n-1} - \tfrac2{11}y_{n-2} = \tfrac6{11}hf_{n+1}. \end{aligned}$$
    애덤스가 \(f\)를 보간해 적분한다면, BDF는 \(y\)를 보간해 미분한다. 차수는 \(k\)이고 \(k \le 6\)에서 영 안정이다.

    음적 공식은 매 걸음 비선형 방정식 \(G(y_{n+1}) = y_{n+1} - \gamma h f(t_{n+1}, y_{n+1}) - \psi_n = 0\)(\(\psi_n\)은 과거 값의 조합, BDF2에서 \(\gamma = \tfrac23\))을 풉니다. 강성 문제에서는 단순 고정점 반복 \(y \leftarrow \psi + \gamma hf(y)\)가 \(\gamma h\|J\| \lt 1\)일 때만 수렴하므로, 바로 그 걸음 제한을 다시 불러옵니다. 그래서 뉴턴 반복(3장, 4장)을 씁니다.

    function bdf_step(f, J, t, ψ, γh, y_guess)
  y ← y_guess                         // 과거 값의 외삽(예측자)
  M ← I − γh·J(t, y)                   // 반복 행렬: 걸음마다 한 번만
  LU ← factor(M)                       // 12장의 LU 분해, 여러 반복에서 재사용
  for it = 1, 2, …, maxit
    G ← y − γh·f(t, y) − ψ
    Δ ← solve(LU, −G)                  // 전진·후진 대입만: O(m²)
    y ← y + Δ
    if ‖Δ‖ ≤ 작은 수·‖y‖ then return y
  end for
  return 실패 → h를 줄여 다시

    위 구현은 반복 행렬을 걸음마다 한 번만 분해하는 단순화 뉴턴입니다. 수렴은 1차로 떨어지지만 \(m\)차원 계에서 분해 \(O(m^3)\)를 반복마다 하지 않아도 되어 훨씬 싸고, 실제 코드는 야코비안을 여러 걸음 동안 재사용하기도 합니다. 큰 계에서 이 분해가 비용의 대부분이라 희소 LU(12장)나 반복 해법(13장)이 강성 ODE 풀이기의 심장이 됩니다.

    예제 11.6 (강성 스칼라 문제의 BDF2 한 걸음) \(y' = -1000(y - \cos t)\), \(y(0) = 1\), \(h = 0.1\)(\(h\lambda = -100\)). 출발값 \(y_0 = 1\), \(y_1 = y(0.1) = 0.995103\)(정확한 값)에서 \(y_2\)를 구하라.
    1. BDF2: \(y_2 - \tfrac43y_1 + \tfrac13y_0 = \tfrac23(0.1)(-1000)(y_2 - \cos 0.2)\). 우변이 \(y_2\)에 대해 1차식이라 뉴턴 한 번에 정확히 풀린다.
    2. \(\gamma h\lambda\)의 크기 \(\tfrac23\cdot 100 = 66.667\)을 써서 \(y_2(1 + 66.667) = \tfrac43(0.995103) - \tfrac13 + 66.667(0.980067)\), \(y_2 = 0.980265\).
    3. 참값 \(y(0.2) = 0.980264\)(과도 성분 \(e^{-1000t}\)은 이미 사라졌고 해는 \(\cos t + \sin t/1000\)에 가깝다). 오차 \(4.0\times10^{-7}\). 명시적 오일러라면 증폭률 \(|1 - 100| = 99\)로 즉시 폭발한다.

    심플렉틱 적분: 스퇴르머–베를레와 장기 에너지

    정확한 방법이 오래 돌리면 진다

    진자 \(\theta'' = -\sin\theta\)를 진폭 2 rad에서 놓고 \(h = 0.2\)로 적분합니다. RK4의 에너지 오차는 \(t = 100\)에서 \(3.2\times10^{-4}\), \(t = 1000\)에서 \(3.2\times10^{-3}\), \(t = 10^4\)에서 \(3.2\times10^{-2}\)으로 시간에 비례해 쌓입니다. 2차밖에 안 되는 스퇴르머–베를레는 처음부터 최대 \(1.1\times10^{-2}\)이지만, \(t = 10^4\)에서도 여전히 \(1.1\times10^{-2}\)입니다. 긴 시간에서는 2차 방법이 4차 방법을 이깁니다.

    ODEBook 5장 8절에서 심플렉틱 오일러가 용수철의 수정된 에너지를 정확히 지킨다는 것을 보았습니다. 실무에서 가장 많이 쓰는 심플렉틱 방법은 그것을 대칭으로 만든 2차 방법입니다.

    정의 11.13 (스퇴르머–베를레 / 속도 베를레) \(q'' = a(q)\)(해밀토니언 \(H = \tfrac12p^2 + V(q)\), \(a = -V'\))에 대해
    $$p_{n+1/2} = p_n + \tfrac h2a(q_n),\qquad q_{n+1} = q_n + hp_{n+1/2},\qquad p_{n+1} = p_{n+1/2} + \tfrac h2a(q_{n+1}).$$
    걸음당 힘 계산은 1회(\(a(q_{n+1})\)을 다음 걸음에 재사용)이고 2차이다. 위치만 쓰면 \(q_{n+1} - 2q_n + q_{n-1} = h^2a(q_n)\), 곧 2계 도함수의 중앙 차분이며 이 꼴을 립프로그(leapfrog)라고도 한다.
    정리 11.14 (베를레의 기하학적 성질) 스퇴르머–베를레의 한 걸음 사상 \(\Phi_h: (q_n, p_n) \mapsto (q_{n+1}, p_{n+1})\)은 (1) 심플렉틱(symplectic)이고(2차원에서는 야코비 행렬식이 1, 곧 위상 공간 넓이 보존), (2) 시간 가역적이다(\(\Phi_{-h} = \Phi_h^{-1}\)). 후방 오차 해석에 따르면 \(\Phi_h\)는 \(\tilde H = H + h^2H_2 + h^4H_4 + \cdots\)라는 수정된 해밀토니언의 정확한 흐름에 지수적으로 작은 오차까지 가깝다. 따라서 에너지 오차 \(|H(q_n, p_n) - H_0| = O(h^2)\)가 지수적으로 긴 시간 동안 유계로 머문다.

    넓이 보존의 이유. 세 단계 각각이 "한 변수만 다른 변수의 함수만큼 민다"는 전단 사상이다. 예를 들어 \((q, p) \mapsto (q, p + \tfrac h2a(q))\)의 야코비 행렬은 \(\begin{bmatrix}1 & 0\\ \tfrac h2a'(q) & 1\end{bmatrix}\)이고 행렬식이 1이다. 행렬식 1인 사상의 합성도 행렬식이 1이다. ∎

    RK4가 에너지를 잃는 이유는 반대로 설명됩니다. RK4의 한 걸음은 넓이를 아주 조금 줄이는 사상이라(선형 진동자에서 걸음당 넓이 비가 \(1 - h^6/72 + h^8/576\)), 그 작은 수축이 매 걸음 같은 방향으로 쌓입니다. 베를레의 오차는 크지만 한 방향으로 쌓이지 않습니다. 그래서 분자 동역학(수십억 걸음), 행성계의 장기 안정성 연구, 입자 가속기의 궤도 추적, 게임 물리 엔진이 베를레나 그 고차 합성(요시다 4차 등)을 씁니다.

    경계값 문제: 슈팅 방법과 유한 차분

    끝 조건이 양쪽에 있다

    연소 이론의 브라투 문제 \(y'' + \lambda e^{y} = 0\), \(y(0) = y(1) = 0\)은 열이 온도에 대해 지수적으로 발생하는 판의 정상 온도입니다. 지금까지의 방법은 모두 \(t_0\)에서 \(y\)와 \(y'\)을 알고 앞으로 걷는 초기값 문제용입니다. 여기서는 \(y'(0)\)을 모르고 대신 \(y(1)\)을 압니다. 그리고 \(\lambda = 1\)이면 해가 두 개, \(\lambda \gt 3.5138\)이면 하나도 없습니다(ODEBook: 경계값 문제).

    첫 번째 방법은 모르는 기울기 \(s = y'(0)\)을 맞힐 때까지 쏘아 보는 것입니다. 초기값 문제 \(y'' = -\lambda e^y\), \(y(0) = 0\), \(y'(0) = s\)를 RK4로 풀어 끝값 \(y(1; s)\)를 얻고, 빗나간 정도 \(F(s) = y(1; s) - 0\)의 근을 3장의 근 찾기로 구합니다.

    정의 11.15 (슈팅 방법) 경계값 문제 \(y'' = g(x, y, y')\), \(y(a) = \alpha\), \(y(b) = \beta\)에 대해 \(F(s) = y(b; s) - \beta\)로 두고 \(F(s) = 0\)을 할선법 \(s_{k+1} = s_k - F(s_k)\dfrac{s_k - s_{k-1}}{F(s_k) - F(s_{k-1})}\)이나 뉴턴 방법(\(F'(s)\)는 변분 방정식 \(w'' = g_y w + g_{y'}w'\), \(w(a) = 0\), \(w'(a) = 1\)의 \(w(b)\))으로 푸는 방법을 슈팅 방법(shooting method)이라 한다.
    예제 11.7 (브라투 λ = 1의 슈팅) RK4(200걸음)로 \(F(0) = -0.46316\), \(F(1) = 0.36270\)이다.
    1. 할선 1회: \(s_2 = 1 - 0.36270\cdot\frac{1 - 0}{0.36270 + 0.46316} = 0.560826\), \(F = 9.4\times10^{-3}\).
    2. 할선 2회: \(s_3 = 0.549085\), \(F = -2.2\times10^{-4}\). 3회: \(s_4 = 0.5493529\), \(F = 1.2\times10^{-7}\). 4회: \(F = 1.5\times10^{-12}\).
    3. 정확한 해 \(y = -2\ln\dfrac{\cosh((x - \frac12)\theta/2)}{\cosh(\theta/4)}\)(\(\theta = \sqrt{2\lambda}\cosh(\theta/4)\), \(\theta = 1.51716\))의 \(y'(0) = 0.549353\)과 일치한다. 최고 온도 \(y(0.5) = 0.140539\).
    4. 다른 근 \(\theta = 10.9387\)에 해당하는 두 번째 해는 \(y'(0) = 10.8469\), \(y(0.5) = 4.0915\)이다. 할선법을 \(s = 10, 11\)에서 출발하면 그쪽으로 간다.

    슈팅은 간단하지만 약점이 있습니다. 초기값 문제가 불안정하면(해가 \(e^{Lx}\)로 벌어지면) \(F(s)\)가 \(s\)에 극도로 민감해져 반올림 오차만으로도 맞출 수 없습니다. 구간을 여러 조각으로 나눠 조각마다 쏘고 이음매를 맞추는 다중 슈팅이 처방입니다. 두 번째 방법은 구간 전체를 한꺼번에 푸는 것입니다.

    정의 11.16 (유한 차분 방법) \(x_i = ih\), \(h = 1/N\)에서 \(y''(x_i) \approx (y_{i-1} - 2y_i + y_{i+1})/h^2\)(9장의 중앙 차분, 오차 \(O(h^2)\))로 바꾸면 미지수 \(y_1, \dots, y_{N-1}\)에 대한 비선형 연립방정식
    $$G_i(\mathbf y) = \frac{y_{i-1} - 2y_i + y_{i+1}}{h^2} + \lambda e^{y_i} = 0,\qquad y_0 = y_N = 0$$
    을 얻는다. 야코비안 \(\partial G_i/\partial y_j\)는 대각 \(-2/h^2 + \lambda e^{y_i}\), 비대각 \(1/h^2\)인 삼중대각 행렬이라 뉴턴 한 번이 토머스 알고리즘(12장)으로 \(O(N)\)에 끝난다.

    핵심 정리

    1. 수렴 = 일관성 + 안정성. 일단계 방법은 일관적이면 수렴한다(정리 11.2). 다단계 방법은 \(\rho(\zeta)\)의 근이 단위원 안에 있고 경계의 근이 단근이어야(영 안정) 수렴한다(달퀴스트 동등성 정리).
    2. 룽게–쿠타 방법은 부처 표 \((A, \mathbf b, \mathbf c)\)로 정의된다. p차 조건은 뿌리 있는 나무마다 하나씩, 4차까지 8개이며, 5차에는 6단이 필요하다(부처 장벽).
    3. 임베디드 쌍은 두 가중치의 차이로 국소 오차를 공짜로 추정하고, 높은 차수 쪽으로 진행하며, \(h \leftarrow h\cdot\min(5, \max(0.2, 0.9\,\mathrm{err}^{-1/(q+1)}))\)로 걸음을 조절한다. 척도는 atol + rtol·|y|.
    4. 애덤스–배시포스(명시적, k차)와 애덤스–몰턴(음적, k+1차)은 f의 보간 다항식을 적분한다. 걸음당 f 계산 1~2회로 고차를 얻고, PECE의 예측–수정 차이가 오차 추정(밀른 장치)이 된다.
    5. 다단계 방법의 안정 영역은 \(\rho(\zeta) - z\sigma(\zeta)\)의 근이 단위원 안인 z의 집합이다. 명시적 방법은 차수가 높을수록 영역이 좁다. A-안정 다단계 방법은 2차가 한계다(달퀴스트 제2 장벽).
    6. 강성 문제에서 명시적 방법의 걸음은 \(h|\lambda_{\max}|\)의 안정 경계에 묶인다. BDF(\(k \le 6\), BDF1·2는 L-안정)는 \(I - \gamma hJ\)의 LU 분해를 재사용하는 단순화 뉴턴으로 걸음마다 음적 방정식을 푼다. 로버트슨 문제에서 걸음 수가 200배 이상 준다.
    7. 스퇴르머–베를레는 전단 사상의 합성이라 넓이를 보존하고 시간 가역적이다. 수정된 해밀토니언 덕에 에너지 오차가 \(O(h^2)\) 띠 안에 머물러, 긴 시간에서는 표류가 \(t\)에 비례하는 RK4를 이긴다.
    8. 경계값 문제는 슈팅(초기값 문제 + 할선/뉴턴)이나 유한 차분(삼중대각 뉴턴, \(O(h^2)\))으로 푼다. 초기값 문제가 불안정하면 유한 차분이나 다중 슈팅이 필요하다.

    확인 퀴즈

    Q1. 2단계 방법 \(y_{n+2} - 3y_{n+1} + 2y_n = h(\dots)\)의 \(\rho(\zeta)\)의 근은 1과 2이다. 이 방법에 대해 옳은 것은?

    기생 근 2가 단위원 밖에 있어 근 조건이 깨진다. 오차의 기생 성분이 2ⁿ으로 자라고 n = (T − t₀)/h이므로 h를 줄일수록 더 나빠진다. 달퀴스트 동등성 정리에 따라 수렴하지 않는다.

    Q2. 3단 명시적 RK의 가중치가 \(\mathbf b = (\tfrac14, 0, \tfrac34)\), \(\mathbf c = (0, \tfrac13, \tfrac23)\)이다. \(\sum b_ic_i\)와 \(\sum b_ic_i^2\)의 값은?

    \(\sum b_ic_i = \tfrac34\cdot\tfrac23 = \tfrac12\), \(\sum b_ic_i^2 = \tfrac34\cdot\tfrac49 = \tfrac13\). 2차 조건과 3차 조건 하나가 맞는다(이것은 호인의 3차 방법이며 \(a_{32} = \tfrac23\)이면 나머지 조건 \(\sum b_ia_{ij}c_j = \tfrac34\cdot\tfrac23\cdot\tfrac13 = \tfrac16\)도 성립한다).

    Q3. 3(2) 임베디드 쌍에서 오차 추정이 허용 오차의 8배였다(err = 8). 안전 계수 0.9를 쓰면 다음 시도의 h는 지금의 몇 배인가?

    낮은 차수 q = 2이므로 국소 오차 ∝ h³, 지수는 1/(q + 1) = 1/3. 0.9·8−1/3 = 0.9/2 = 0.45. 이 걸음은 버리고 0.45h로 다시 계산한다.

    Q4. 비싼 f를 쓰는 강성 없는 문제에서, 4차 정확도를 원할 때 걸음당 f 계산이 가장 적은 방법은?

    AB4는 과거 기울기 네 개를 재활용해 걸음당 f를 1회만 계산한다. RK4는 4회. BDF4는 음적이라 뉴턴 반복이 필요하고 강성 문제용이다. 베를레는 2차다.

    Q5. A-안정이면서 3차인 선형 다단계 방법에 대해 옳은 것은?

    A-안정 선형 다단계 방법의 차수는 2 이하다. BDF3는 A(86.03°)-안정일 뿐이고, AM3의 실수축 안정 구간은 (−6, 0)이다. 3차 이상의 A-안정 방법을 원하면 음적 룽게–쿠타(가우스, 라다우)로 가야 한다.

    Q6. 강성 계 \(y' = f(y)\)(차원 m)를 BDF로 풀 때 단순 고정점 반복 대신 뉴턴 반복을 쓰는 이유는?

    y ← ψ + γh f(y)는 축소 사상일 때, 곧 γh·‖J‖ < 1일 때 수렴한다. 강성 문제의 ‖J‖가 크므로 이는 명시적 방법의 안정 조건과 같은 제한이다. 뉴턴 반복은 (I − γhJ)의 LU 분해로 이 제한을 없앤다.

    Q7. 진자를 h = 0.1로 10⁶ 걸음 적분해 에너지를 지켜야 한다. 가장 알맞은 선택과 이유는?

    RK4의 에너지 표류는 시간에 비례해 쌓인다. 베를레는 심플렉틱이라 수정된 해밀토니언을 따라가며 에너지 오차가 유계다. 음적 오일러는 오히려 에너지를 인위적으로 소산시킨다.

    Q8. 유한 차분으로 2점 경계값 문제를 푸는데 N = 20에서 최대 오차가 \(8\times10^{-4}\)였다. 중앙 차분을 쓸 때 N = 80이면 오차는 대략?

    중앙 차분은 O(h²). h가 1/4이 되면 오차는 1/16: 8×10⁻⁴/16 = 5×10⁻⁵. 브라투 표에서도 N을 두 배로 할 때마다 정확히 1/4씩 줄었다.
