Chapter 06

스플라인과 곡선

5장의 결론은 "등간격 데이터에 고차 다항식을 쓰지 말라"였습니다. 그렇다면 점이 수백 개인 측정 데이터나 글자의 윤곽선은 무엇으로 이어야 할까요? 답은 낮은 차수의 다항식을 조각조각 이어 붙이고, 이음매에서 매끄러움을 맞추는 것입니다. 이 장은 가장 단순한 꺾은선에서 시작해, 오버슈트 없이 단조성을 지키는 PCHIP, 곡률까지 연속인 3차 스플라인과 그 삼중대각 선형계, 경계 조건의 선택, 스플라인이 "가장 덜 휜 곡선"이라는 정리를 다룹니다. 후반부는 함수의 그래프가 아닌 곡선, 곧 글꼴과 CAD와 애니메이션 경로를 그리는 베지에 곡선과 B-스플라인입니다.

  • 조각별 선형 보간의 오차 \(\frac{h^2}{8}\max|f''|\)를 유도하고, 차수를 올리는 대신 간격을 줄이는 전략을 설명한다.
  • 조각별 3차 에르미트 보간에서 기울기를 고르는 방법(PCHIP)이 단조성을 지키는 이유를 안다.
  • 3차 스플라인의 연속 조건에서 이차 도함수에 대한 삼중대각계를 유도하고 토머스 알고리즘으로 \(O(n)\)에 푼다.
  • 자연·고정·not-a-knot 경계 조건의 차이와 수렴 차수(\(O(h^2)\) 대 \(O(h^4)\))를 실험으로 확인한다.
  • 자연 스플라인이 굽힘 에너지 \(\int s''^2\)를 최소로 하는 보간 함수임을 증명한다.
  • 베지에 곡선을 드 카스텔조 알고리즘으로 계산하고, B-스플라인이 국소 제어를 주는 이유를 기저 함수의 받침으로 설명한다.
이 수식이 없었다면자동차 차체와 화면의 글꼴

컴퓨터 이전의 조선소와 항공기 공장에서는 길고 얇은 나무 자를 스플라인이라 불렀습니다. 자를 바닥의 못이나 무거운 추 사이에 끼우면 자는 탄성 에너지가 가장 작은 모양으로 휘어 점들을 매끄럽게 잇습니다. 1946년 쇤베르크(Isaac Schoenberg)가 이 이름을 빌려 조각별 다항식 이론을 세웠고, 그 3차 스플라인이 실제로 "굽힘 에너지 최소" 성질을 가진다는 것이 이 장의 정리 6.8입니다.

1950년대 말~1960년대에 프랑스 자동차 회사의 두 엔지니어, 시트로엥의 드 카스텔조(Paul de Casteljau)와 르노의 베지에(Pierre Bézier)는 차체의 곡면을 도면 대신 숫자로 전달하는 방법을 각자 만들었습니다. 오늘날 이 글을 표시하는 글꼴의 윤곽선(TrueType은 2차, PostScript·CFF 글꼴은 3차 베지에), 벡터 그림, CSS 애니메이션의 cubic-bezier() 곡선, CAD의 NURBS가 모두 그 후손입니다.

점 수백 개·윤곽선→고차 다항식은 출렁임→조각별 3차 + 이음매 연속→스플라인·베지에·B-스플라인

고차 보간의 대안: 조각별 다항식

점 50개를 한 다항식으로 이을 수는 없다

온도 센서가 1초마다 값을 기록해 50개의 점을 얻었습니다. 5장의 결과대로 49차 보간 다항식은 양 끝에서 폭발하고, 점 하나만 바꿔도 곡선 전체가 흔들립니다. 노드를 체비쇼프 점으로 옮길 수도 없습니다. 측정 시각은 이미 정해져 있으니까요.

해결책은 전체 구간을 노드로 나눈 각 작은 구간마다 낮은 차수의 다항식을 쓰는 것입니다. 노드 \(a = x_0 \lt x_1 \lt \dots \lt x_n = b\)로 나누고 \(h_i = x_{i+1} - x_i\), \(h = \max h_i\)라 합시다. 가장 단순한 것은 이웃한 두 점을 직선으로 잇는 조각별 선형 보간(piecewise linear interpolation)입니다.

정리 6.1 (조각별 선형 보간의 오차) \(f \in C^2[a, b]\)이고 \(\ell\)이 노드에서 \(f\)와 같은 조각별 선형 함수면
$$\max_{[a,b]}|f - \ell| \le \frac{h^2}{8}\max_{[a,b]}|f''|.$$

증명. 한 구간 \([x_i, x_{i+1}]\)에서 \(\ell\)은 두 점의 1차 보간이므로 5장 정리 5.6에서 \(f(x) - \ell(x) = \frac{f''(\xi)}{2}(x - x_i)(x - x_{i+1})\). \(|(x - x_i)(x - x_{i+1})|\)의 최댓값은 가운데에서 \(h_i^2/4\)이다. ∎

다항식 보간과 결정적으로 다른 점은 오차가 \(f''\)에만 의존하고 차수가 고정이라는 것입니다. \(n\)을 늘리면 \(h \to 0\)이므로 오차는 \(O(h^2)\)로 반드시 줄어듭니다. 룽게 현상이 없습니다. 또 한 점의 값을 바꾸면 이웃한 두 구간만 바뀝니다(국소성).

예제 6.1 (사인의 꺾은선 근사) \([0, \pi]\)를 10등분해 \(\sin x\)를 조각별 선형 보간하라. 최대 오차는?
  1. \(h = \pi/10 = 0.314159\), \(|\sin''| \le 1\)이므로 한계 \(h^2/8 = 0.012337\).
  2. 실제 최대 오차는 \(\pi/2\)를 가운데에 둔 구간에서 생긴다. 노드가 \(0.4\pi, 0.5\pi, 0.6\pi\)이므로 \(\pi/2\)가 노드이고, 최대는 \(x \approx 1.4143\)(구간 \([0.4\pi, 0.5\pi]\)의 가운데 근처)에서 \(0.012160\)이다.
  3. 한계와 거의 같다. \(f''\)이 구간 안에서 거의 일정할 때 한계는 날카롭다. 오차 \(10^{-6}\)을 원하면 \(h \approx \sqrt{8\times10^{-6}} = 0.0028\), 약 1100개 구간이 필요하다. 1차는 단순하지만 느리다. 더 높은 정확도는 구간 안의 다항식을 3차로 올려서 얻는다.

그런데 꺾은선은 노드에서 기울기가 끊깁니다. 자동차 차체나 로봇 궤적에서 기울기의 불연속은 반사광의 꺾임이나 가속도의 충격으로 나타납니다. 그래서 구간마다 3차 다항식을 쓰고 이음매에서 기울기(\(C^1\))나 곡률(\(C^2\))까지 맞춥니다. 아래 시뮬레이터에서 세 가지를 비교해 보세요. 3차 스플라인은 3절에서 유도합니다.

조각별 3차 에르미트와 단조성(PCHIP)

센서 보정표가 거꾸로 꺾이면 안 된다

열전대의 전압–온도 보정표는 단조 증가합니다. 그런데 보정점이 고르지 않게 놓여 있으면 매끄러운 보간 곡선이 데이터 사이에서 살짝 내려갔다가 올라갈 수 있습니다. 그러면 같은 전압에 온도 두 개가 대응해 역함수가 망가집니다. 매끄러우면서도 데이터의 모양(단조성)을 지키는 보간이 필요합니다.

5장 8절의 에르미트 보간을 구간마다 씁니다. 각 노드에서 값 \(y_i\)와 기울기 \(d_i\)를 정하면 구간 \([x_i, x_{i+1}]\)의 3차식은 \(s = (x - x_i)/h_i\)로

$$p_i(x) = y_i H_{00}(s) + h_i d_i H_{10}(s) + y_{i+1}H_{01}(s) + h_i d_{i+1}H_{11}(s),$$
\(H_{00} = 2s^3 - 3s^2 + 1\), \(H_{10} = s^3 - 2s^2 + s\), \(H_{01} = -2s^3 + 3s^2\), \(H_{11} = s^3 - s^2\)(에르미트 기저). 값과 기울기가 이웃 구간과 공유되므로 결과는 \(C^1\)이다.

남은 문제는 기저 \(d_i\)를 어떻게 정하느냐입니다. \(f'\)을 안다면 그대로 쓰고(에르미트 데이터), 모른다면 데이터에서 추정해야 합니다. 구간의 기울기 \(\delta_i = (y_{i+1} - y_i)/h_i\)를 쓰는 다음 규칙이 프리치–칼슨(Fritsch–Carlson, 1980) 계열의 PCHIP(Piecewise Cubic Hermite Interpolating Polynomial)입니다.

정의 6.2 (PCHIP 기울기) 내부 노드 \(x_k\)에서
$$d_k = \begin{cases} 0, & \delta_{k-1}\delta_k \le 0 \ \ (\text{극값이거나 평평함}),\\[2pt] \dfrac{w_1 + w_2}{\dfrac{w_1}{\delta_{k-1}} + \dfrac{w_2}{\delta_k}}, & \text{그 밖}, \end{cases}\qquad w_1 = 2h_k + h_{k-1},\ w_2 = h_k + 2h_{k-1}.$$
가중 조화 평균이다. 한쪽 기울기가 작으면 \(d_k\)도 작아져 곡선이 급히 꺾이지 않는다. 등간격이면 \(\frac{2}{d_k} = \frac{1}{\delta_{k-1}} + \frac{1}{\delta_k}\). 끝점은 세 점 공식 \(((2h_0 + h_1)\delta_0 - h_0\delta_1)/(h_0 + h_1)\)을 쓰되 부호가 \(\delta_0\)와 다르면 0으로, 너무 크면 \(3\delta_0\)으로 자른다(MATLAB pchip, SciPy PchipInterpolator의 방식).
정리 6.3 (단조성 조건, 프리치–칼슨) 구간에서 \(\delta_i \ne 0\)이고 \(\alpha = d_i/\delta_i\), \(\beta = d_{i+1}/\delta_i\)라 하자. \(\alpha, \beta \ge 0\)이고 \(\alpha^2 + \beta^2 \le 9\)이면 그 구간의 3차 에르미트 보간은 단조다. \(\delta_i = 0\)이면 \(d_i = d_{i+1} = 0\)일 때 상수다.

핵심 아이디어. \(p_i'\)은 \(s\)의 2차식이고, \(p_i'/\delta_i\)가 \([0, 1]\)에서 음이 되지 않을 조건을 \((\alpha, \beta)\) 평면에 그리면 원 \(\alpha^2 + \beta^2 \le 9\)를 품는 영역이 된다. 조화 평균 규칙은 \(\alpha, \beta\)를 0 이상 3 이하로 두어 이 영역 안에 머문다(등간격이면 \(\alpha, \beta \le 2\)). ∎

예제 6.2 (계단 모양 데이터) \(x = 0, 1, \dots, 5\), \(y = 0,\ 0.1,\ 0.2,\ 3,\ 3.1,\ 3.2\). 구간 기울기는 \(\delta = 0.1,\ 0.1,\ 2.8,\ 0.1,\ 0.1\).
  1. \(d_1\): \(0.1\)과 \(0.1\)의 조화 평균 \(= 0.1\). \(d_2\): \(2/d_2 = 1/0.1 + 1/2.8 = 10.357\), \(d_2 = 0.1931\). 대칭으로 \(d_3 = 0.1931\), \(d_4 = 0.1\). 끝점 \(d_0 = (3\cdot0.1 - 0.1)/2 = 0.1\), \(d_5 = 0.1\).
  2. 가파른 구간 \([2, 3]\)의 양 끝 기울기가 \(0.19\)로 작게 잡혔다. 곡선은 평평하게 들어와서 구간 안에서 가파르게 오르고 다시 평평하게 나간다. PCHIP의 범위는 정확히 \([0, 3.2]\)이다.
  3. 같은 데이터의 자연 3차 스플라인은 \(x \approx 1.58\)에서 \(-0.135\)로 내려가고 \(x \approx 3.42\)에서 \(3.335\)로 넘친다. 데이터 범위를 벗어나는 오버슈트이고, 단조성도 깨진다.

대가도 있습니다. PCHIP는 \(C^1\)일 뿐 곡률이 이음매에서 끊기고, 매끄러운 함수에 대한 정확도는 3차 스플라인보다 낮습니다(4절의 표에서 \(O(h^3)\) 근처). 모양을 지키는 것이 중요하면 PCHIP, 매끄러운 함수의 정확도가 중요하면 스플라인입니다.

3차 스플라인의 유도: 삼중대각계

곡률까지 이어 붙이려면 기울기를 어떻게 골라야 하나

PCHIP는 기울기를 각 노드에서 따로 정했습니다. 이음매에서 이차 도함수(곡률)까지 연속이 되도록 기울기를 함께 정하면 나무 자 스플라인처럼 매끄러운 곡선이 됩니다. 이 조건은 모든 구간을 한꺼번에 엮는 연립방정식이 됩니다.

정의 6.4 (3차 스플라인) 노드 \(x_0 \lt \dots \lt x_n\)에서 함수 \(s\)가 (1) 각 구간 \([x_i, x_{i+1}]\)에서 3차 다항식이고, (2) \(s(x_i) = y_i\)이며, (3) \(s, s', s''\)이 \([x_0, x_n]\)에서 연속이면 \(s\)를 3차 스플라인(cubic spline)이라 한다.

미지수를 셉시다. 구간 \(n\)개에 3차식 하나당 계수 4개, 모두 \(4n\)개입니다. 조건은 보간 \(2n\)개(각 구간의 양 끝), 내부 노드 \(n - 1\)개에서 \(s'\), \(s''\) 연속 \(2(n - 1)\)개, 합 \(4n - 2\)개. 두 개가 모자랍니다. 이 두 자유도를 정하는 것이 4절의 경계 조건입니다.

미지수를 노드의 이차 도함수 \(M_i = s''(x_i)\)(모멘트(moment), 보의 굽힘 모멘트에서 온 이름)로 잡으면 계산이 깔끔해집니다. \(s''\)은 각 구간에서 1차식이므로 \(M_i\)와 \(M_{i+1}\)을 잇는 직선이고, 두 번 적분해 보간 조건을 넣으면

$$s(x) = M_i\frac{(x_{i+1} - x)^3}{6h_i} + M_{i+1}\frac{(x - x_i)^3}{6h_i} + \Bigl(y_i - \frac{M_ih_i^2}{6}\Bigr)\frac{x_{i+1} - x}{h_i} + \Bigl(y_{i+1} - \frac{M_{i+1}h_i^2}{6}\Bigr)\frac{x - x_i}{h_i}.$$
이 꼴은 \(s\)의 보간과 \(s''\)의 연속을 저절로 만족한다. 남은 조건은 \(s'\)의 연속뿐이다.

이 식을 미분해 \(x_i\)에서 왼쪽 구간과 오른쪽 구간의 \(s'\)을 같게 놓으면 내부 노드마다 방정식 하나가 나옵니다.

정리 6.5 (모멘트 방정식) \(\delta_i = (y_{i+1} - y_i)/h_i\)라 하면 \(i = 1, \dots, n-1\)에 대해
$$h_{i-1}M_{i-1} + 2(h_{i-1} + h_i)M_i + h_iM_{i+1} = 6(\delta_i - \delta_{i-1}).$$
경계 조건 두 개를 더하면 계수 행렬은 삼중대각이고 각 행에서 대각 원소 \(2(h_{i-1} + h_i)\)가 비대각 원소의 합 \(h_{i-1} + h_i\)의 두 배라 엄격한 대각 우세다. 따라서 해는 유일하고, 피벗팅 없는 가우스 소거가 안정적이다.

삼중대각계는 \(O(n)\)에 풀립니다. 소거할 원소가 행마다 하나뿐이기 때문입니다. 이 방법을 토머스 알고리즘(Thomas algorithm)이라 부르고, 12장 직접 해법에서 띠 행렬의 일반 이론으로 다시 다룹니다.

// 토머스 알고리즘: a[i] M[i−1] + b[i] M[i] + c[i] M[i+1] = d[i],  i = 1..m
c′[1] ← c[1] / b[1];   d′[1] ← d[1] / b[1]
for i = 2 to m                          // 전진 소거: a[i]를 지운다
  w ← b[i] − a[i] · c′[i−1]
  c′[i] ← c[i] / w
  d′[i] ← (d[i] − a[i] · d′[i−1]) / w
M[m] ← d′[m]
for i = m−1 downto 1                    // 후진 대입
  M[i] ← d′[i] − c′[i] · M[i+1]

연산 약 \(8m\)번. 일반 가우스 소거의 \(m^3/3\)과 비교하면 점 1000개에서 수만 배 빠르다.

예제 6.3 (자연 스플라인 손계산) \((0, 0)\), \((1, 1)\), \((2, 0)\), \((3, 1)\)을 지나는 자연 스플라인(\(M_0 = M_3 = 0\))을 구하라.
  1. \(h_i = 1\), \(\delta = 1, -1, 1\). 방정식: \(i = 1\): \(4M_1 + M_2 = 6(-1 - 1) = -12\). \(i = 2\): \(M_1 + 4M_2 = 6(1 + 1) = 12\).
  2. 토머스: \(c'_1 = 1/4\), \(d'_1 = -3\). \(w = 4 - 1\cdot\tfrac14 = 3.75\), \(d'_2 = (12 + 3)/3.75 = 4\). 후진: \(M_2 = 4\), \(M_1 = -3 - \tfrac14\cdot 4 = -4\).
  3. \([0, 1]\)에서 \(s(x) = -4\frac{x^3}{6} + \bigl(1 + \tfrac46\bigr)x\), \(s(0.5) = -0.0833 + 0.8333 = 0.75\). 같은 방법으로 \(s(1.5) = 0.5\), \(s(2.5) = 0.25\).
  4. 네 점을 지나는 3차 다항식 \(p(x) = x - x(x-1) + \tfrac23x(x-1)(x-2)\)은 \(p(0.5) = 1\), \(p(1.5) = 0.5\), \(p(2.5) = 0\)이다. 스플라인이 데이터의 지그재그를 더 얌전하게 따른다.

경계 조건: 자연·고정·not-a-knot

모자란 두 조건을 어떻게 채울까

미지수 \(4n\)개에 조건 \(4n - 2\)개였습니다. 양 끝에서 하나씩 조건을 더해야 하는데, 선택에 따라 끝 근처의 곡선 모양과 정확도의 차수가 달라집니다. 라이브러리의 기본값도 제각각입니다.

정의 6.6 (경계 조건)
  • 자연(natural): \(M_0 = M_n = 0\). 끝에서 자가 곧게 풀려 있는 상태. 방정식 첫 행과 끝 행이 \(M_0 = 0\), \(M_n = 0\).
  • 고정(clamped, complete): \(s'(x_0) = f'(a)\), \(s'(x_n) = f'(b)\)를 지정. 첫 행 \(2h_0M_0 + h_0M_1 = 6(\delta_0 - f'(a))\), 끝 행 \(h_{n-1}M_{n-1} + 2h_{n-1}M_n = 6(f'(b) - \delta_{n-1})\).
  • not-a-knot: 첫 두 구간과 마지막 두 구간이 같은 3차식이 되도록 \(s'''\)을 \(x_1\)과 \(x_{n-1}\)에서 연속으로. \(x_1, x_{n-1}\)이 사실상 이음매(knot)가 아니게 된다. 노드가 4개면 결과는 3차 보간 다항식 자체다. MATLAB spline과 SciPy CubicSpline의 기본값이다.
  • 주기(periodic): \(s'\), \(s''\)이 \(x_0\)과 \(x_n\)에서 같도록. 닫힌 곡선이나 주기 신호에 쓴다(행렬 모서리에 원소가 생기는 순환 삼중대각계).
정리 6.7 (스플라인의 수렴 차수) \(f \in C^4[a, b]\)이고 노드가 등간격(또는 간격 비가 유계)이면, 고정 스플라인은
$$\max|f - s| \le \frac{5}{384}h^4\max|f^{(4)}|$$ 를 만족하고, not-a-knot 스플라인도 \(O(h^4)\)이다. 자연 스플라인은 \(f''(a) = f''(b) = 0\)이 아니면 끝 근처에서 \(M_0 = 0\)이라는 틀린 정보 때문에 오차가 \(O(h^2)\)로 떨어진다(내부에서는 그 영향이 지수적으로 줄어든다).

\(f = e^x\), \([0, 2]\)에서 실제로 잰 최대 오차입니다(\(n\) = 구간 수). 자연 스플라인은 \(e^x\)의 끝 곡률 \(f''(2) = e^2 \ne 0\)을 0으로 강제하므로 끝에서 틀립니다.

최소 굽힘 에너지: 스플라인은 가장 덜 휜다

나무 자는 왜 그 모양이 되는가

얇은 탄성 막대의 굽힘 에너지는 곡률의 제곱을 길이에 대해 적분한 것에 비례하고, 기울기가 작으면 곡률은 \(y''\)과 거의 같습니다. 못(데이터 점)에 걸린 자는 이 에너지를 최소로 하는 모양을 택합니다. 수학적으로 그 모양이 3차 스플라인일까요?

정리 6.8 (최소 굽힘 에너지, 홀러데이) \(s\)를 데이터 \((x_i, y_i)\)의 자연 3차 스플라인이라 하자. 같은 점을 지나는 임의의 \(g \in C^2[a, b]\)에 대해
$$\int_a^b s''(x)^2\,dx \le \int_a^b g''(x)^2\,dx$$ 이고, 등호는 \(g = s\)일 때만 성립한다. 고정 스플라인은 끝 기울기가 같은 \(g\)들 가운데 같은 성질을 가진다.

증명. \(e = g - s\)라 하면 \(e(x_i) = 0\)이고 \(\int g''^2 = \int s''^2 + 2\int s''e'' + \int e''^2\). 가운데 항이 0임을 보이면 된다. 부분적분하면 \(\int_a^b s''e'' = [s''e']_a^b - \int_a^b s'''e'\). 자연 조건 \(s''(a) = s''(b) = 0\)으로 첫 항이 사라진다. 각 구간에서 \(s'''\)은 상수 \(c_i\)이므로 \(\int s'''e' = \sum_i c_i\bigl(e(x_{i+1}) - e(x_i)\bigr) = 0\). 그러므로 \(\int g''^2 = \int s''^2 + \int e''^2 \ge \int s''^2\)이고, 등호는 \(e'' \equiv 0\), 곧 \(e\)가 일차식이면서 노드에서 0일 때, 즉 \(e \equiv 0\)일 때뿐이다. ∎

예제 6.3의 데이터로 확인해 봅시다. 자연 스플라인의 \(s''\)은 각 구간에서 \(M_i\)와 \(M_{i+1}\)을 잇는 직선이므로 한 구간의 적분은 \(h(M_i^2 + M_iM_{i+1} + M_{i+1}^2)/3\)입니다. \(M = (0, -4, 4, 0)\)이면 \(\tfrac{16}{3} + \tfrac{16}{3} + \tfrac{16}{3} = 16\). 같은 네 점을 지나는 3차 다항식은 \(p'' = 4x - 6\)이라 \(\int_0^3(4x - 6)^2dx = 36\). 스플라인이 절반 이하로 덜 휩니다. 1절 시뮬레이터의 두 에너지 값이 바로 이것입니다.

이 정리의 뜻 스플라인은 "우연히 매끄러운" 곡선이 아니라 변분 문제의 해다. 이 관점은 7장의 평활 스플라인(데이터와의 거리 + λ·굽힘 에너지 최소화)과 16장 유한 요소법의 약형식(에너지 최소화 → 연립방정식)으로 이어진다. 실제 탄성 막대의 에너지는 \(\int\kappa^2\,ds\)이고 \(y''\)과 다르므로, 기울기가 클 때는 물리적인 자와 스플라인이 조금 다르다.

매개변수 곡선, 베지에 곡선과 드 카스텔조 알고리즘

글자 'S'는 함수의 그래프가 아니다

지금까지의 보간은 \(y = f(x)\) 꼴이었습니다. 하지만 글자 윤곽, 자동차 측면 선, 카메라 경로는 되돌아오고 수직으로 서고 고리를 만듭니다. 이런 모양은 \(x\)와 \(y\)를 모두 매개변수 \(t\)의 함수로 쓰는 매개변수 곡선 \(\mathbf B(t) = (x(t), y(t))\)로만 그릴 수 있습니다. 또 디자이너는 곡선이 지날 점보다 모양을 당기는 손잡이를 원합니다.

정의 6.9 (베지에 곡선) 제어점(control point) \(\mathbf P_0, \dots, \mathbf P_n\)에 대해
$$\mathbf B(t) = \sum_{k=0}^{n}\binom{n}{k}t^k(1 - t)^{n-k}\,\mathbf P_k, \qquad 0 \le t \le 1$$
를 \(n\)차 베지에 곡선(Bézier curve)이라 한다. 가중치 \(b_{k,n}(t) = \binom nk t^k(1-t)^{n-k}\)는 번스타인 다항식이다. 모두 0 이상이고 합이 \((t + 1 - t)^n = 1\)이다.

여기서 바로 성질 세 가지가 나옵니다. (1) 끝점 보간: \(\mathbf B(0) = \mathbf P_0\), \(\mathbf B(1) = \mathbf P_n\). 가운데 제어점은 지나지 않고 당기기만 합니다. (2) 끝 접선: \(\mathbf B'(0) = n(\mathbf P_1 - \mathbf P_0)\), \(\mathbf B'(1) = n(\mathbf P_n - \mathbf P_{n-1}).\) 그래서 그림 프로그램의 "손잡이"가 곧 \(\mathbf P_1\), \(\mathbf P_2\)입니다. (3) 볼록 껍질: 가중치가 음이 아니고 합이 1이므로 곡선은 제어점의 볼록 껍질 안에 있습니다. 충돌 검사나 화면 잘라내기에서 곡선 대신 제어 다각형을 검사할 수 있습니다.

계산은 번스타인 다항식을 직접 쓰지 않고 선분의 내분을 되풀이합니다.

정리 6.10 (드 카스텔조 알고리즘) \(\mathbf P_k^{(0)} = \mathbf P_k\)라 하고 \(r = 1, \dots, n\)에 대해
$$\mathbf P_k^{(r)} = (1 - t)\,\mathbf P_k^{(r-1)} + t\,\mathbf P_{k+1}^{(r-1)}, \qquad k = 0, \dots, n - r$$ 로 두면 \(\mathbf P_0^{(n)} = \mathbf B(t)\)이다. 또 이때 \(\mathbf P_0^{(0)}, \mathbf P_0^{(1)}, \dots, \mathbf P_0^{(n)}\)과 \(\mathbf P_0^{(n)}, \mathbf P_1^{(n-1)}, \dots, \mathbf P_n^{(0)}\)은 각각 \([0, t]\)와 \([t, 1]\) 부분의 베지에 제어점이다(분할).

증명의 핵심. 귀납법. \(\mathbf P_k^{(r)}\)이 \(\mathbf P_k, \dots, \mathbf P_{k+r}\)의 \(r\)차 베지에 곡선이라 가정하면, 파스칼 항등식 \(b_{j,r}(t) = (1-t)b_{j,r-1}(t) + t\,b_{j-1,r-1}(t)\)이 점화식과 정확히 같은 꼴이다. ∎

// 드 카스텔조: 제어점 P[0..n], 매개변수 t  (O(n²), 덧셈과 내분만)
Q ← P                                   // 복사
for r = 1 to n
  for k = 0 to n − r
    Q[k] ← (1 − t) · Q[k] + t · Q[k+1]
return Q[0]

볼록 결합만 쓰므로 반올림 오차에 강하다. 계수 \(\binom nk\)를 만들 필요도 없다.

예제 6.4 (3차 베지에 한 점) \(\mathbf P_0 = (0, 0)\), \(\mathbf P_1 = (1, 2)\), \(\mathbf P_2 = (3, 2)\), \(\mathbf P_3 = (4, 0)\)에서 \(\mathbf B(0.5)\)와 \(\mathbf B(0.25)\)를 구하라.
  1. \(t = 0.5\), 1단계(중점): \((0.5, 1)\), \((2, 2)\), \((3.5, 1)\). 2단계: \((1.25, 1.5)\), \((2.75, 1.5)\). 3단계: \(\mathbf B(0.5) = (2, 1.5)\).

  3. \(t = 0.25\): 1단계 \((0.25, 0.5)\), \((1.5, 2)\), \((3.25, 1.5)\). 2단계 \((0.5625, 0.875)\), \((1.9375, 1.875)\). 3단계 \(\mathbf B(0.25) = (0.90625, 1.125)\).

B-스플라인과 국소 제어

손잡이 규칙을 일일이 지키지 않고 매끄러운 곡선을

베지에 조각을 \(C^2\)로 이으려면 이음매마다 손잡이 위치에 제약이 붙고, 디자이너가 점 하나를 옮길 때마다 이웃 손잡이를 다시 맞춰야 합니다. 반대로 3절의 보간 스플라인은 \(C^2\)이지만 한 점을 옮기면 (빠르게 줄긴 해도) 전체가 움직입니다. 매끄러움이 저절로 보장되면서 제어점 하나가 근처만 움직이는 곡선이 있을까요?

답은 기저 함수 자체를 조각별 다항식으로 만들고, 그 기저가 짧은 구간에서만 0이 아니게 하는 것입니다. 매듭(knot) 열 \(t_0 \le t_1 \le \dots\)에서 다음 점화식으로 기저를 정의합니다.

정의 6.11 (B-스플라인 기저, 콕스–드 부어 점화식)
$$N_{j,0}(t) = \begin{cases}1, & t_j \le t \lt t_{j+1}\\ 0, & \text{그 밖}\end{cases}, \qquad N_{j,p}(t) = \frac{t - t_j}{t_{j+p} - t_j}N_{j,p-1}(t) + \frac{t_{j+p+1} - t}{t_{j+p+1} - t_{j+1}}N_{j+1,p-1}(t).$$
분모가 0이면 그 항을 0으로 둔다. \(p\)차 B-스플라인(B-spline) 곡선은 \(\mathbf C(t) = \sum_j N_{j,p}(t)\,\mathbf P_j\)이다. 이 장에서는 \(p = 3\)(3차)을 쓴다.
정리 6.12 (B-스플라인 기저의 성질) (가) 국소 받침: \(N_{j,p}\)는 \([t_j, t_{j+p+1})\) 밖에서 0이다. 따라서 3차에서 제어점 \(\mathbf P_j\)는 매듭 구간 4개에만 영향을 준다. (나) 단위 분할: 유효 구간에서 \(N_{j,p} \ge 0\), \(\sum_j N_{j,p} = 1\)이므로 곡선은 볼록 껍질 안에 있다. (다) 매끄러움: 매듭이 겹치지 않으면 \(N_{j,p}\)는 \(C^{p-1}\)이다. 3차면 제어점을 어디에 두어도 곡선은 저절로 \(C^2\)다.

핵심 아이디어. (가)와 (나)는 \(p\)에 대한 귀납법으로, 점화식의 두 가중치가 0 이상이고 이웃 항끼리 합이 1이 되는 데서 나온다. (다)는 \(N_{j,p}\)가 상자 함수를 \(p\)번 "번지게" 한(등간격이면 상자 함수의 \(p+1\)중 합성곱) 함수라서 한 번 번질 때마다 매끄러움이 하나씩 오르는 데서 나온다. ∎

등간격 매듭(\(t_j = j\))의 3차 B-스플라인 한 조각은 행렬로 간단히 쓸 수 있습니다. \(u \in [0, 1]\)에서

$$\mathbf C(u) = \frac16\Bigl[(1-u)^3\mathbf P_0 + (3u^3 - 6u^2 + 4)\mathbf P_1 + (-3u^3 + 3u^2 + 3u + 1)\mathbf P_2 + u^3\mathbf P_3\Bigr].$$
조각의 시작점은 \((\mathbf P_0 + 4\mathbf P_1 + \mathbf P_2)/6\)로, 제어점을 지나지 않고 그 근처를 지난다. 끝점을 지나게 하려면 매듭 열의 양 끝을 네 번 겹친다(clamped). 이때 첫 조각과 끝 조각은 베지에 곡선과 같아진다.

B-스플라인에 가중치를 붙여 유리 함수로 만든 것이 NURBS(Non-Uniform Rational B-Spline)로, 원과 원뿔 곡선을 정확히 표현할 수 있어 CAD 데이터 교환의 표준 표현이 되었습니다. 3절의 보간 스플라인도 B-스플라인 기저로 쓸 수 있습니다. 보간 조건 \(\mathbf C(x_i) = y_i\)가 제어점에 대한 띠 행렬 계가 되고, 이것이 라이브러리들의 내부 구현 방식 중 하나입니다.

핵심 정리

  1. 고차 다항식 대신 구간마다 낮은 차수를 쓰면 차수는 고정, 간격 \(h\)만 줄이므로 룽게 현상이 없다. 조각별 선형은 \(\frac{h^2}{8}\max|f''|\).
  2. 조각별 3차 에르미트는 값과 기울기를 이웃과 공유해 \(C^1\)이다. PCHIP는 기울기를 조화 평균(극값에서는 0)으로 골라 오버슈트 없이 단조성을 지킨다.
  3. 3차 스플라인은 \(C^2\) 조각별 3차식이다. 모멘트 \(M_i = s''(x_i)\)에 대한 방정식 \(h_{i-1}M_{i-1} + 2(h_{i-1} + h_i)M_i + h_iM_{i+1} = 6(\delta_i - \delta_{i-1})\)은 대각 우세 삼중대각계로, 토머스 알고리즘으로 \(O(n)\)에 풀린다.
  4. 미지수 \(4n\)개에 조건 \(4n - 2\)개, 모자란 둘이 경계 조건이다. 고정·not-a-knot은 \(O(h^4)\), 자연 조건은 끝 곡률이 0이 아니면 \(O(h^2)\).
  5. 자연 스플라인은 같은 점을 지나는 모든 \(C^2\) 함수 가운데 \(\int g''^2\)이 가장 작다(부분적분 한 번의 증명).
  6. 베지에 곡선은 번스타인 가중치의 볼록 결합이다. 끝점을 지나고 끝 접선이 \(n(\mathbf P_1 - \mathbf P_0)\)이며, 드 카스텔조의 내분 반복으로 안정적으로 계산하고 분할한다.
  7. 조각 베지에의 이음매는 손잡이 배치로 \(C^0\), \(G^1\), \(C^1\)이 정해지며, \(C^1\)도 곡률 연속을 보장하지 않는다.
  8. B-스플라인 기저는 콕스–드 부어 점화식으로 만들고, 받침이 매듭 구간 \(p+1\)개라 국소 제어를 주며 3차면 저절로 \(C^2\)이다.

확인 퀴즈

Q1. 조각별 선형 보간의 간격을 \(h\)에서 \(h/3\)으로 줄이면 오차 한계는 몇 배가 되는가?

한계 (h²/8)·max|f″|이 h²에 비례하므로 (1/3)² = 1/9. 1/81은 고정 3차 스플라인(h⁴)의 경우다.

Q2. 노드 \(n+1\)개(구간 \(n\)개)의 3차 스플라인에서 보간과 연속 조건만으로는 몇 개의 조건이 모자라는가?

미지수 4n개, 조건은 보간 2n + 내부 노드의 s′·s″ 연속 2(n − 1) = 4n − 2개. 모자란 2개를 양 끝의 경계 조건으로 채운다.

Q3. 등간격 \(h = 1\)인 네 점 \((0,0)\), \((1,1)\), \((2,0)\), \((3,1)\)의 자연 스플라인에서 \(M_1\)은?

4M₁ + M₂ = −12, M₁ + 4M₂ = 12를 풀면 M₁ = −4, M₂ = 4. 토머스 알고리즘의 d′₁ = −3은 중간값일 뿐이다.

Q4. 스플라인 모멘트 방정식을 피벗팅 없이 풀어도 안정적인 이유는?

2(hᵢ₋₁ + hᵢ) > hᵢ₋₁ + hᵢ. 엄격한 대각 우세 행렬은 가역이고 소거 중 피벗이 작아지지 않는다. 대칭(등간격 등)이지만 대칭만으로는 충분하지 않다.

Q5. 데이터 \(y = 0, 0.1, 0.2, 3, 3.1, 3.2\)를 보간할 때 결과가 데이터 범위 \([0, 3.2]\)를 벗어나지 않는 방법은?

PCHIP는 조화 평균 기울기로 단조 구간에서 단조성을 지켜 범위가 정확히 [0, 3.2]다. 자연 스플라인은 −0.135까지 내려가고 3.335까지 올라간다.

Q6. 자연 스플라인이 같은 점을 지나는 \(C^2\) 함수 가운데 최소로 만드는 양은?

Q7. 제어점 \((0,0), (1,2), (3,2), (4,0)\)인 3차 베지에 곡선의 \(\mathbf B(0.5)\)는?

(P₀ + 3P₁ + 3P₂ + P₃)/8 = (16/8, 12/8) = (2, 1.5). 드 카스텔조로 중점을 세 번 잡아도 같다. (1.25, 1.5)는 2단계의 중간점이다.

Q8. 3차 B-스플라인 곡선에서 제어점 하나를 옮기면 곡선의 어느 부분이 바뀌는가?

기저 Nⱼ,₃의 받침이 [tⱼ, tⱼ₊₄), 곧 매듭 구간 p + 1 = 4개다. 제어점이 같은 하나의 베지에 곡선이라면 끝점을 뺀 전체가 바뀐다.
