Chapter 16

편미분방정식의 수치 해법

온도, 압력, 전위, 농도처럼 공간과 시간에 함께 퍼져 있는 양은 편미분방정식을 따릅니다. ODEBook 16장(편미분방정식 입문)은 열·파동·라플라스 방정식을 변수분리로 풀고, 마지막에 명시적 차분법 FTCS와 그 안정 조건 \(r \le 1/2\), 파동의 CFL 조건을 맛보았습니다. 이 장은 거기서 출발합니다. 막대 대신 판을, 사인 급수 대신 큰 희소 연립방정식을, 명시적 방법 대신 음적 방법을 씁니다. 모든 방법을 같은 세 질문으로 다룹니다. 얼마나 정확한가(차수), 오차가 자라지 않는가(안정성), 얼마나 비싼가(비용). 그리고 이 세 질문을 묶는 랙스 동등성 정리, 이류 방정식에서 드러나는 수치 확산과 분산, 그리고 복잡한 모양을 다루는 유한 요소법과 보존 법칙을 지키는 유한 체적법까지 갑니다. 이 장은 책의 마지막 본문 장이라, 끝에서 책 전체를 돌아봅니다.

  • 테일러 전개로 차분 근사의 오차 차수를 구하고, 격자 수렴 실험으로 2차 정확도를 확인한다.
  • 푸아송 방정식을 5점 스텐실로 이산화해 희소 선형계를 만들고, 그 크기·구조·풀이 비용(야코비·SOR·직접법)을 견준다.
  • 열 방정식의 FTCS·BTCS·크랭크–니콜슨을 비교하고, 폰 노이만 분석으로 각 방법의 증폭 인자와 안정 조건을 유도한다.
  • 랙스 동등성 정리로 일관성·안정성·수렴의 관계를 설명한다.
  • 이류 방정식에서 중앙 차분이 불안정한 이유, 풍상 차분의 수치 확산, 랙스–벤드로프의 진동, CFL 조건을 설명한다.
  • 1차원 문제를 약형식과 모자 함수로 유한 요소 강성 행렬로 조립하고, 유한 체적법의 보존 성질을 안다.

스마트폰 칩 안의 뜨거운 점이 어디에 생기는지, 엔진 블록이 시동 뒤 몇 분 만에 데워지는지, 날개 위를 지나는 공기의 압력 분포가 어떤지, 트랜지스터 안의 전자 농도가 어떻게 분포하는지는 모두 편미분방정식의 해입니다. 이런 문제의 영역은 직사각형이 아니고 물성도 균일하지 않아서, 변수분리나 급수로는 풀 수 없습니다. 공학자는 영역을 수만~수십억 개의 칸이나 요소로 자르고, 미분을 이웃 값의 차이로 바꾸어 거대한 연립방정식으로 만든 뒤 컴퓨터로 풉니다.

미분방정식을 격자로 바꾸는 생각의 수학적 토대 가운데 하나는 쿠랑, 프리드리히스, 레위(Courant, Friedrichs, Lewy)의 1928년 논문입니다. 1950년대에는 랙스(Peter Lax)의 동등성 정리와 폰 노이만(John von Neumann)의 안정성 분석이, 1960년대 이후에는 구조 공학에서 자란 유한 요소법이 자리 잡았습니다. 오늘날 상용 열·구조 해석 프로그램, 전산 유체 역학(CFD) 코드, 반도체 소자 시뮬레이터는 이 장의 방법을 수백만 배 큰 규모로 돌립니다.

격자와 유한 차분 근사

미분을 이웃 값의 차이로

길이 1 m인 막대에 열원 \(f(x)\)가 있고 양 끝이 0 °C일 때의 정상 온도는 \(-u'' = f\), \(u(0) = u(1) = 0\)을 따릅니다. 컴퓨터는 함수 \(u(x)\)를 저장할 수 없고 점 몇 개의 값만 저장할 수 있습니다. 점 \(N - 1\)개의 값만으로 방정식을 어떻게 쓰고, 점을 두 배로 늘리면 답은 얼마나 좋아질까요?

구간을 간격 \(h = 1/N\)로 나눈 격자(grid, mesh) \(x_i = ih\) 위에서 \(u_i \approx u(x_i)\)를 미지수로 둡니다. 9장의 중앙 차분을 2계 도함수에 쓰면, 테일러 전개 \(u(x \pm h) = u \pm hu' + \frac{h^2}{2}u'' \pm \frac{h^3}{6}u''' + \frac{h^4}{24}u'''' + \cdots\)를 더해 홀수 항이 지워지고

$$\frac{u(x + h) - 2u(x) + u(x - h)}{h^2} = u''(x) + \frac{h^2}{12}u''''(\xi).$$
좌변을 \(\delta^2 u/h^2\)로 적는다. 버린 항이 국소 절단 오차이고 \(h^2\)에 비례한다(2차 정확). 이 공식을 이웃 세 점의 무게 \((1, -2, 1)/h^2\)로 보는 것을 스텐실이라 한다.

이를 각 내부 점에 쓰면 \(-u_{i-1} + 2u_i - u_{i+1} = h^2 f_i\), \(i = 1, \dots, N - 1\)이고, 경계값 \(u_0 = u_N = 0\)을 넣으면 삼중대각 연립방정식 \(T\mathbf u = h^2\mathbf f\)입니다. 행렬 \(T = \operatorname{tridiag}(-1, 2, -1)\)은 대칭 양정치이며, 12장의 토머스 알고리즘으로 \(O(N)\) 연산에 풀립니다.

정의 16.1 (일관성과 정확도 차수) 차분 방정식에 참 해 \(u(x_i)\)를 넣었을 때 남는 값 \(\tau_i\)를 국소 절단 오차라 하고, \(h \to 0\)일 때 \(\tau \to 0\)이면 그 방법이 미분방정식과 일관적(consistent)이라 한다. \(\tau = O(h^p)\)이면 \(p\)차 정확하다.
정리 16.2 (1차원 푸아송 차분법의 수렴) \(u \in C^4\)이면 위 차분 해의 오차는 \(\max_i|u_i - u(x_i)| \le \frac{h^2}{96}\max|u''''|\)이다.

증명의 핵심. 오차 \(e_i = u_i - u(x_i)\)는 \(T\mathbf e/h^2 = -\boldsymbol\tau\)를 만족한다. 그러므로 \(\|\mathbf e\|_\infty \le \|(T/h^2)^{-1}\|_\infty\|\boldsymbol\tau\|_\infty\). \((T/h^2)^{-1}\)의 성분은 모두 양수이고 행 합은 \(-w'' = 1\)의 차분 해 \(x_i(1 - x_i)/2\)(이 이차식에서는 차분이 정확하다)이므로 최대 \(1/8\)이다. \(|\tau| \le \frac{h^2}{12}\max|u''''|\)와 곱하면 된다. 절단 오차가 작다는 것(일관성)과 역행렬이 \(h\)에 무관하게 유계라는 것(안정성)이 합쳐져 수렴이 된다. 5절의 랙스 동등성 정리의 원형이다. ∎

푸아송 방정식: 5점 스텐실과 희소 선형계

칩 위의 정상 온도 분포

정사각형 판의 네 변 온도가 정해져 있고 판 안에 발열 부품이 있습니다. 정상 상태 온도는 \(-\nabla^2 u = f\)(푸아송 방정식, \(f = 0\)이면 라플라스 방정식)를 따릅니다. ODEBook에서는 이웃 평균을 되풀이해 판의 온도를 구했습니다. 그 되풀이가 실제로는 어떤 연립방정식을 푸는 것이고, 격자를 키우면 얼마나 비싸지는지 정량적으로 봅시다.

\(x\)와 \(y\) 방향에 앞 절의 중앙 차분을 각각 쓰면, 간격 \(h\)의 정사각 격자 점 \((x_i, y_j)\)에서

$$-\frac{u_{i+1,j} + u_{i-1,j} + u_{i,j+1} + u_{i,j-1} - 4u_{i,j}}{h^2} = f_{i,j}.$$
가운데 점과 동서남북 네 이웃, 다섯 점의 5점 스텐실. 절단 오차는 \(\frac{h^2}{12}(u_{xxxx} + u_{yyyy})\), 2차 정확하다. \(f = 0\)이면 "각 점의 값은 네 이웃의 평균"이다.

한 변에 내부 점이 \(n = N - 1\)개면 미지수는 \(n^2\)개, 행렬은 \(n^2\times n^2\)입니다. \(n = 100\)이면 미지수 9801개(\(N = 100\)), 밀집 행렬로 저장하면 약 \(10^8\)개의 칸이지만 0이 아닌 값은 5만 개 미만입니다. 그래서 행렬을 만들지 않고 스텐실만으로 계산하는 희소 방법이 중요합니다. 밀집 가우스 소거는 \((n^2)^3/3 \approx 3\times10^{11}\)번, 띠 촐레스키는 띠 너비 \(n\)을 이용해 약 \(n^2\cdot n^2/2 = 5\times10^7\)번입니다. 3차원이면 차이가 훨씬 커집니다.

정리 16.3 (이산 최대 원리) \(f = 0\)인 5점 차분 해는 각 내부 점의 값이 네 이웃의 평균이므로, 최댓값과 최솟값을 경계에서만 가진다. 따라서 차분 해는 유일하고(같은 경계값의 두 해의 차는 0), 경계값의 범위를 벗어나지 않는다. ODEBook 정리 16.5의 평균값 성질을 격자로 옮긴 것이다.
예제 16.2 (윗변만 뜨거운 판) 단위 정사각형의 윗변 100 °C, 나머지 세 변 0 °C, \(f = 0\).
  1. 판을 90°씩 돌린 네 문제를 겹치면 경계가 모두 100 °C인 문제가 되고 그 해는 어디나 100이다. 정중앙은 네 문제에서 같은 값이므로 \(u(\frac12, \frac12) = 25\). 이 논증은 차분 방정식에도 그대로 성립해서, 5점 차분 해의 중앙값도 어떤 \(N\)(짝수)에서나 정확히 25다(계산 결과 \(N = 4, 8, 16\)에서 25.00000000).
  2. 점 \((0.5, 0.75)\)의 참값(급수해)은 54.053. 차분 해는 \(N = 4, 8, 16\)에서 52.679, 53.608, 53.933, 오차 1.37, 0.445, 0.120으로 비가 3.1, 3.7이다. 윗변 양 끝 모서리에서 경계값이 불연속(100과 0)이라 해가 매끄럽지 않아 처음에는 2차보다 느리게 준다.

열 방정식: 명시적 FTCS, 음적 BTCS, 크랭크–니콜슨

안정 조건이 계산을 묶는다

ODEBook에서 FTCS는 \(r = \alpha\Delta t/\Delta x^2 \le 1/2\)일 때만 안정했습니다. 막대를 \(\Delta x = 1/1000\)로 자르면 \(\alpha = 1\)일 때 \(\Delta t \le 5\times10^{-7}\), 시각 1까지 가는 데 200만 걸음이 필요합니다. 답의 정확도로는 \(\Delta t = 10^{-3}\)이면 충분한데도 말입니다. 11장의 강성 ODE와 같은 상황입니다. 처방도 같습니다. 음적 방법.

공간을 먼저 차분화하면 열 방정식 \(u_t = \alpha u_{xx}\)는 내부 점 \(n\)개의 연립 ODE \(\mathbf u' = -\frac{\alpha}{\Delta x^2}T\mathbf u\)가 됩니다(선의 방법(method of lines)). \(T\)의 고유값은 \(4\sin^2\frac{k\pi\Delta x}{2}\)(\(k = 1, \dots, n\))로, 가장 큰 것이 약 4라 이 ODE의 고유값은 \(0\)에 가까운 것부터 \(-4\alpha/\Delta x^2\)까지 퍼져 있습니다. 강성비가 \(\Delta x^{-2}\)에 비례하는 전형적인 강성 계입니다. 이 ODE에 11장의 세 방법을 쓰면 세 가지 PDE 방법이 나옵니다.

정의 16.4 (FTCS, BTCS, 크랭크–니콜슨) \(r = \alpha\Delta t/\Delta x^2\), \(\delta^2u_i = u_{i+1} - 2u_i + u_{i-1}\)라 하자.
$$\begin{aligned} \text{FTCS (전진 오일러):}\quad & u_i^{k+1} = u_i^k + r\,\delta^2u_i^k\\ \text{BTCS (후진 오일러):}\quad & u_i^{k+1} - r\,\delta^2u_i^{k+1} = u_i^k\\ \text{크랭크–니콜슨 (사다리꼴):}\quad & u_i^{k+1} - \tfrac r2\,\delta^2u_i^{k+1} = u_i^k + \tfrac r2\,\delta^2u_i^k \end{aligned}$$
행렬로 쓰면 BTCS는 \((I + rT)\mathbf u^{k+1} = \mathbf u^k\), CN은 \((I + \frac r2T)\mathbf u^{k+1} = (I - \frac r2T)\mathbf u^k\). 매 걸음 삼중대각 연립방정식을 하나 푼다. 국소 절단 오차는 FTCS·BTCS가 \(O(\Delta t + \Delta x^2)\), CN이 \(O(\Delta t^2 + \Delta x^2)\)이다.

크랭크–니콜슨 방법은 1947년 크랭크와 니콜슨(John Crank, Phyllis Nicolson)이 발표했습니다. 음적 방법의 대가는 매 걸음의 선형계인데, 1차원에서는 토머스 알고리즘(12장)으로 \(O(n)\), 곧 FTCS 한 걸음과 같은 차수의 비용입니다. 다차원에서는 희소 선형계를 반복법이나 교대 방향 음적법(ADI: 방향마다 삼중대각계를 번갈아 푸는 방법)으로 풉니다.

function crank_nicolson_step(u, r)          // u: 내부 점 n개, 양끝 0
  for i = 1 .. n                             // 오른쪽: (I - r/2 T) u
    d[i] = u[i] + (r/2) * (u[i-1] - 2*u[i] + u[i+1])
  sub = -r/2;  diag = 1 + r;  sup = -r/2      // 왼쪽: (I + r/2 T)
  return thomas(sub, diag, sup, d)          // O(n): 12장

폰 노이만 안정성 분석

ODEBook 16장은 FTCS의 증폭 인자 \(G(\theta) = 1 - 4r\sin^2\frac\theta2\)를 구해 \(r \le \frac12\)을 얻었습니다. 같은 계산을 모든 선형 상수 계수 차분법에 할 수 있습니다. 이것이 폰 노이만 안정성 분석(von Neumann stability analysis)입니다.

정의 16.5 (증폭 인자) 무한하거나 주기적인 격자에서 격자 푸리에 모드 \(u_j^k = G^k e^{\mathrm ij\theta}\)(\(-\pi \le \theta \le \pi\), \(\theta = \xi\Delta x\))를 차분법에 넣으면 한 걸음의 곱 인자 \(G(\theta)\)가 정해진다. 이를 증폭 인자(amplification factor)라 한다. 모든 \(\theta\)에서 \(|G(\theta)| \le 1\)(또는 \(\le 1 + C\Delta t\))이면 폰 노이만 의미에서 안정하다.

\(\delta^2 e^{\mathrm ij\theta} = (e^{\mathrm i\theta} - 2 + e^{-\mathrm i\theta})e^{\mathrm ij\theta} = -4s^2e^{\mathrm ij\theta}\), \(s = \sin\frac\theta2\)를 쓰면 세 방법의 증폭 인자가 곧바로 나옵니다.

$$G_{\text{FTCS}} = 1 - 4rs^2,\qquad G_{\text{BTCS}} = \frac{1}{1 + 4rs^2},\qquad G_{\text{CN}} = \frac{1 - 2rs^2}{1 + 2rs^2},\qquad G_{\text{참}} = e^{-r\theta^2}.$$
참 해의 모드 \(e^{\mathrm i\xi x}\)는 한 걸음 \(\Delta t\)에 \(e^{-\alpha\xi^2\Delta t} = e^{-r\theta^2}\)배가 된다. 낮은 모드(\(\theta \to 0\))에서 세 인자 모두 이 값과 맞고, 차이는 높은 모드에서 난다.
정리 16.6 (열 방정식 차분법의 안정성) FTCS는 \(r \le \frac12\)일 때만 안정하다. BTCS와 크랭크–니콜슨은 모든 \(r > 0\)에서 안정하다(무조건 안정). 또 \(r \to \infty\)일 때 가장 높은 모드에서 \(G_{\text{BTCS}}(\pi) = 1/(1 + 4r) \to 0\)이지만 \(G_{\text{CN}}(\pi) = (1 - 2r)/(1 + 2r) \to -1\)이다.

증명. \(0 \le s^2 \le 1\). BTCS의 분모는 1 이상이라 \(0 \lt G \le 1\). CN은 \(|1 - 2rs^2| \le 1 + 2rs^2\)이 늘 성립한다. FTCS는 ODEBook 정리 16.6. 극한은 \(s = 1\)을 넣으면 된다. ∎

정리의 둘째 부분이 앞 절 CN의 지그재그를 설명합니다. \(r = 20\)이면 \(G_{\text{CN}}(\pi) = -39/41 = -0.951\). 톱니 모드는 사라지지 않고 걸음마다 부호만 바꾸며 거의 그대로 남습니다. 참 해에서는 이 모드가 \(e^{-20\pi^2}\)배, 사실상 즉시 사라져야 합니다. 사각 펄스처럼 높은 모드를 많이 가진 자료에서 이것이 눈에 보입니다. BTCS처럼 \(|G| \to 0\)인 성질을 11장에서 L-안정이라 불렀습니다. 실무에서는 처음 몇 걸음을 BTCS로 걸어 높은 모드를 죽인 뒤 CN으로 바꾸는 요령(래너처 시작)을 씁니다.

폰 노이만 분석은 이류 방정식에도 그대로 쓰입니다(6절). 아래 시뮬레이터에서 두 방정식의 증폭 인자를 비교하세요.

절단 오차가 작은데 왜 틀리나

FTCS를 \(r = 0.6\)으로 돌리면, 매 걸음 미분방정식을 \(O(\Delta t + \Delta x^2)\) 오차로 근사합니다. 격자를 아무리 줄여도(같은 \(r\)) 국소 오차는 0으로 갑니다. 그런데 답은 폭발합니다. 반대로, 국소 오차가 작고 폭발하지 않으면 답이 맞는다고 믿어도 될까요?

수치 해가 참 해에 다가가는 것(수렴)은 우리가 원하는 성질이지만 직접 확인하기 어렵습니다. 참 해를 모르기 때문입니다. 반면 일관성은 테일러 전개로, 안정성은 폰 노이만 분석으로 확인할 수 있습니다. 다음 정리가 둘을 수렴에 잇습니다.

정리 16.7 (랙스 동등성 정리) 잘 놓인(해가 존재·유일하고 처음 자료에 연속적으로 의존하는) 선형 초기값 문제와 그것에 일관적인 선형 차분법에 대해, 그 차분법이 수렴할 필요충분조건은 안정한 것이다. 여기서 안정성은 고정된 시간 \(T\)까지 \(k\Delta t \le T\)인 모든 \(k\)에 대해 \(\|S^k\| \le C_T\)(한 걸음 연산자 \(S\)의 거듭제곱이 격자에 무관하게 유계)라는 뜻이다. 1956년 랙스와 리히트마이어(Lax, Richtmyer)가 발표했다.

"안정 ⇒ 수렴"의 핵심. 오차 \(\mathbf e^k\)는 \(\mathbf e^{k+1} = S\mathbf e^k + \Delta t\,\boldsymbol\tau^k\)를 따르므로 \(\mathbf e^k = \Delta t\sum_{m \lt k}S^{k-1-m}\boldsymbol\tau^m\). 안정성으로 \(\|\mathbf e^k\| \le C_T\,T\max\|\boldsymbol\tau^m\|\)이고, 일관성으로 이것이 0으로 간다. 정리 16.2와 ODEBook의 오일러 오차 정리(전역 오차 = 국소 오차 × 증폭의 합)가 같은 구조다. ∎

이 정리에서 실용적인 결론 두 가지가 나옵니다. 첫째, 안정한 방법의 수렴 차수는 절단 오차의 차수와 같습니다. 예제 16.3의 BTCS 1차, CN 2차가 그 예입니다. 그래서 새 코드를 검증할 때는 (1) 절단 오차의 차수를 손으로 구하고, (2) 폰 노이만으로 안정성을 확인한 뒤, (3) 격자 수렴 실험으로 그 차수가 실제로 나오는지 봅니다. 둘째, 일관적이지만 불안정한 방법은 어떤 격자에서도 쓸모가 없습니다. 격자를 줄이면 국소 오차는 줄지만 증폭 횟수가 늘어 결국 반올림 오차까지 키웁니다.

모양 그대로 실어 나르기

강물에 떨어진 염료, 바람에 실린 오염 물질, 파이프 속의 온도 펄스는 흐름을 따라 모양을 유지한 채 움직입니다. 가장 단순한 모형 \(u_t + au_x = 0\)의 해는 \(u(x, t) = u_0(x - at)\), 처음 모양을 속도 \(a\)로 옮긴 것입니다. 해를 손으로 쓸 수 있는 이 쉬운 방정식이 수치적으로는 놀라울 만큼 어렵습니다. 가장 자연스러운 중앙 차분이 무조건 불안정하기 때문입니다.

\(C = a\Delta t/\Delta x\)를 쿠랑 수라 합니다. 시간 전진·공간 중앙 차분 \(u_j^{k+1} = u_j^k - \frac C2(u_{j+1}^k - u_{j-1}^k)\)의 증폭 인자는 \(G = 1 - \mathrm iC\sin\theta\)이고 \(|G|^2 = 1 + C^2\sin^2\theta > 1\)입니다. 어떤 \(\Delta t\)를 써도 불안정합니다. 열 방정식에는 확산이 높은 모드를 눌러 주지만, 이류에는 그런 힘이 없어 중앙 차분의 작은 증폭이 그대로 쌓입니다.

처방은 정보가 오는 쪽을 보는 것입니다. \(a > 0\)이면 해는 왼쪽에서 옵니다.

정의 16.8 (풍상 차분과 랙스–벤드로프) \(a > 0\)일 때
$$\text{풍상:}\quad u_j^{k+1} = u_j^k - C\,(u_j^k - u_{j-1}^k),\qquad \text{랙스–벤드로프:}\quad u_j^{k+1} = u_j^k - \frac C2(u_{j+1}^k - u_{j-1}^k) + \frac{C^2}{2}(u_{j+1}^k - 2u_j^k + u_{j-1}^k).$$
풍상(upwind) 차분은 1차 정확, \(|G|^2 = 1 - 2C(1 - C)(1 - \cos\theta)\). 랙스–벤드로프(Lax–Wendroff, 1960)는 테일러 전개 \(u_{tt} = a^2u_{xx}\)를 써서 2차 정확, \(|G|^2 = 1 - 4C^2(1 - C^2)\sin^4\frac\theta2\). 둘 다 \(0 \le C \le 1\)에서 안정하다.

풍상 차분은 안정하지만 대가가 있습니다. 풍상 식에 참 해를 넣고 테일러 전개하면, 이 방법이 실제로 더 정확하게 푸는 방정식(수정 방정식(modified equation))은

$$u_t + au_x = \underbrace{\frac{a\,\Delta x}{2}(1 - C)}_{D_{\text{num}}}\,u_{xx} + O(\Delta x^2)$$
이류 방정식에 없던 확산항이 생겼다. 이것이 수치 확산(numerical diffusion)이다. \(\Delta x = 0.01\), \(C = 0.8\), \(a = 1\)이면 \(D_{\text{num}} = 0.001\). \(C = 1\)이면 사라지고, 그때 풍상 차분은 \(u_j^{k+1} = u_{j-1}^k\), 정확히 한 칸 이동이다.

랙스–벤드로프는 이 확산항을 지웠지만 다음 항인 3계 도함수 항(분산)이 남아, 파장마다 속도가 달라집니다. 짧은 파장이 뒤처지며 급한 경사 뒤에 물결 같은 진동이 생깁니다. 실제로 계산해 보면 다음과 같습니다.

정리 16.9 (CFL 조건) 명시적 차분법이 수렴하려면 수치적 의존 영역이 참 의존 영역을 포함해야 한다. 이웃 한 칸만 쓰는 방법에서 이것은 \(|C| = |a|\Delta t/\Delta x \le 1\)이다. 이 조건은 필요조건이며 충분조건이 아니다(중앙 차분 FTCS는 \(C \le 1\)이어도 불안정하다).

CFL 조건의 의미는 "한 걸음에 정보가 한 칸보다 멀리 가면 안 된다"입니다. 빠른 흐름(\(a\) 큼)이나 가는 격자(\(\Delta x\) 작음)는 시간 걸음을 직접 줄입니다. 3차원 CFD 코드가 비싼 이유의 상당 부분이 이것이고, 음적 방법이 여기서도 쓰입니다. 다만 이류에서는 큰 \(C\)의 음적 방법이 정확도를 크게 잃으므로, 열 방정식만큼 쉽게 걸음을 키우지는 못합니다.

파동 방정식: 립프로그와 수치 분산

ODEBook 16장은 파동 방정식 \(u_{tt} = c^2u_{xx}\)의 중앙 차분 \(u_i^{k+1} = 2u_i^k - u_i^{k-1} + C^2\delta^2u_i^k\)와 CFL 조건 \(C = c\Delta t/\Delta x \le 1\)을 보였습니다. 시간과 공간 모두 중앙 차분이라 앞뒤 두 시각을 "뛰어넘는" 꼴이어서 흔히 립프로그(leapfrog) 방법이라 부릅니다. 여기서는 그 다음 질문, 안정한 범위 안에서도 무엇이 틀리는가를 봅니다.

시작에는 두 시각이 필요합니다. \(u^0 = f\)와 \(u_t(x, 0) = g\)에서 테일러 전개로 \(u_i^1 = u_i^0 + \Delta t\,g_i + \frac{C^2}{2}\delta^2u_i^0\)을 만들면 2차 정확도가 유지됩니다. 모드 \(u_j^k = e^{\mathrm i(\xi j\Delta x - \omega k\Delta t)}\)를 넣으면 수치 분산 관계

$$\sin\frac{\omega\Delta t}{2} = C\sin\frac{\xi\Delta x}{2}$$
참 관계는 \(\omega = c\xi\)(모든 파장이 같은 속도 \(c\)). \(C \le 1\)이면 우변이 1 이하라 \(\omega\)가 실수, 곧 진폭이 유지된다(안정, 감쇠 없음). 수치 위상 속도는 \(\omega/\xi\)이다.

구멍 뚫린 브래킷의 응력

차분법은 바둑판 격자를 좋아합니다. 그러나 엔진 브래킷, 치아 임플란트, 반도체 패키지는 곡선 경계와 구멍과 서로 다른 재료로 되어 있습니다. 경계에 맞춰 크기가 다른 삼각형으로 영역을 채우고 싶지만, 삼각형 격자에서는 "이웃 값의 차이"를 어떻게 써야 할지 분명하지 않습니다. 미분 대신 적분으로 방정식을 다시 쓰면 길이 열립니다.

\(-u'' = f\), \(u(0) = u(1) = 0\)에 경계에서 0인 아무 시험 함수 \(v\)를 곱해 적분하고 부분 적분하면 경계항이 사라져

$$\int_0^1 u'v'\,dx = \int_0^1 fv\,dx\qquad\text{모든 } v \text{ (}v(0) = v(1) = 0\text{)에 대해}.$$
이를 약형식(weak form)이라 한다. \(u\)는 2계 도함수 없이 1계 도함수만 있으면 된다. 구조역학에서는 가상 일의 원리, 에너지로 보면 \(\frac12\int u'^2 - \int fu\)의 최소화와 같다.

유한 요소법(finite element method, FEM)은 \(u\)와 \(v\)를 유한 차원 공간에서 고릅니다. 가장 단순한 공간은 마디 \(x_i\)에서 1, 다른 마디에서 0이고 그 사이는 직선인 모자 함수(hat function) \(\varphi_i\)들로 만든 조각별 선형 함수입니다. \(u_h = \sum_j U_j\varphi_j\)를 넣고 \(v = \varphi_i\)로 두면(갤러킨 방법)

$$\sum_j\underbrace{\Bigl(\int\varphi_i'\varphi_j'\,dx\Bigr)}_{K_{ij}}U_j = \underbrace{\int f\varphi_i\,dx}_{F_i},\qquad K\mathbf U = \mathbf F.$$
\(K\)를 강성 행렬(stiffness matrix), \(\mathbf F\)를 하중 벡터라 한다. 이름은 구조 해석의 스프링 강성에서 왔다. \(\varphi_i'\)는 이웃 요소에서만 0이 아니므로 \(K\)는 희소하다.
정리 16.10 (갤러킨 최적성) 유한 요소 해 \(u_h\)는 에너지 노름 \(\|w\|_E = (\int w'^2)^{1/2}\)에서 조각별 선형 함수 가운데 참 해에 가장 가깝다: \(\|u - u_h\|_E = \min_{v_h}\|u - v_h\|_E\). 따라서 \(\|u - u_h\|_E = O(h)\)이고, 최대 오차는 \(O(h^2)\)이다. 또 1차원의 이 문제에서는 하중을 정확히 적분하면 마디 값 \(U_i = u(x_i)\)가 정확하다.

증명의 핵심. 약형식에서 갤러킨 식을 빼면 \(\int(u - u_h)'\varphi_i' = 0\), 곧 오차가 근사 공간에 에너지 내적으로 수직이다(갤러킨 직교성). 7장의 최소제곱에서 잔차가 열공간에 수직인 것과 같은 그림이고, 수직 사영이 최단 거리다. 마디 정확성은 이 문제의 그린 함수가 조각별 선형이라 근사 공간에 들어 있기 때문이다. ∎

예제 16.5 (요소 넷) \(-u'' = 1\), \(n = 4\) 요소, \(h = 1/4\).
  1. 요소 강성 \(\frac1h\begin{bmatrix}1&-1\\-1&1\end{bmatrix} = \begin{bmatrix}4&-4\\-4&4\end{bmatrix}\)을 네 요소에 대해 조립하고 경계 마디를 지우면 \(K = \begin{bmatrix}8&-4&0\\-4&8&-4\\0&-4&8\end{bmatrix}\), 하중 \(F_i = h = 0.25\).
  2. 풀면 \(\mathbf U = (0.09375,\ 0.125,\ 0.09375)\). 참 해 \(u = x(1 - x)/2\)의 마디 값과 정확히 같다.
  3. 마디 사이에서는 직선이라 최대 오차는 \(7.81\times10^{-3}\)(요소 중앙). \(n = 8, 16, 32\)에서 최대 오차는 4분의 1씩(2차), 에너지 노름 오차는 \(7.22\times10^{-2}\)에서 반씩(1차) 준다.

2차원에서는 삼각형 요소 위의 조각별 선형 함수를 쓰고, 요소 강성 행렬은 3×3이 됩니다. 정사각 격자의 직각삼각형으로 라플라스 방정식을 풀면 5점 스텐실과 같은 행렬이 나옵니다. 유한 요소법은 차분법을 포함하면서 임의의 모양과 재료, 고차 요소, 오차 추정에 따른 적응 세분화로 확장됩니다. 구조 해석의 상용 코드, 전자기장 해석, 열 해석 대부분이 이 방법입니다.

유한 체적법 맛보기: 보존을 정확히

유체의 질량·운동량·에너지, 반도체의 전하는 보존됩니다. 칸의 양이 변하는 것은 칸의 경계를 드나드는 흐름(플럭스) 때문뿐입니다. 보존 법칙 \(u_t + F(u)_x = 0\)을 칸 \([x_{j-1/2}, x_{j+1/2}]\)에서 적분하면 칸 평균 \(\bar u_j\)에 대해

$$\frac{d\bar u_j}{dt} = -\frac{F_{j+1/2} - F_{j-1/2}}{\Delta x}$$
\(F_{j+1/2}\)는 칸 경계를 지나는 수치 플럭스. 한 칸이 잃는 양은 이웃 칸이 정확히 얻으므로, 모든 칸을 더하면 내부 플럭스가 소거되어 총량은 반올림 오차까지 정확히 보존된다.

이것이 유한 체적법(finite volume method)의 뼈대입니다. 무엇을 \(F_{j+1/2}\)로 쓰느냐가 방법을 정합니다. 이류 \(F = au\)에서 바람이 불어오는 쪽 칸의 값 \(F_{j+1/2} = a\bar u_j\)를 쓰면 정확히 앞 절의 풍상 차분이 되고, 예제 16.4의 표에서 모든 방법의 총량이 0.200000으로 보존된 것도 그 식들이 이런 플럭스 차이 꼴이기 때문입니다. 비선형 보존 법칙(충격파가 생기는 기체 역학)에서는 칸 경계마다 작은 리만 문제를 풀어 플럭스를 정하는 고두노프 계열 방법이 표준이고, 보존형으로 쓰지 않으면 충격파의 속도가 틀리게 나옵니다. 임의의 다각형 칸에서도 경계 면의 플럭스만 계산하면 되므로, 상용·공개 CFD 코드 대부분이 유한 체적법을 씁니다.

응용: 열 해석, 유체, 반도체 소자

  • 전자 기기의 열 해석. 칩과 기판의 온도는 발열원이 있는 열 방정식 \(\rho c\,u_t = \nabla\cdot(k\nabla u) + q\)를 따릅니다. 재료마다 열전도도 \(k\)가 수백 배 다르고 층이 얇아 격자가 매우 불균일하므로 강성이 심합니다. 그래서 BTCS나 CN 같은 음적 시간 진행과, 매 걸음 큰 희소 선형계를 푸는 전처리 켤레 기울기법(13장)의 조합이 표준입니다. 정상 상태만 원하면 2절의 푸아송 문제 하나입니다.
  • 전산 유체 역학. 나비에–스토크스 방정식은 이류(6절)·확산(3절)·압력의 푸아송 방정식(2절)을 모두 품고 있습니다. 많은 코드가 유한 체적법으로 보존을 지키고, 이류 항에는 풍상 계열의 고해상도 방법을, 시간 걸음은 CFL 수로 고르며, 매 걸음 압력의 푸아송 방정식을 다중 격자법으로 풉니다. 수치 확산이 실제 점성보다 커지지 않게 격자를 고르는 것이 결과를 믿기 위한 첫 점검입니다.
  • 반도체 소자 시뮬레이션. 트랜지스터 안의 전위는 전하 밀도를 원천으로 하는 푸아송 방정식을, 전자·정공 농도는 표류–확산 연속 방정식을 따릅니다. 농도가 깊이에 따라 수십 자릿수 변하기 때문에 보통의 중앙 차분은 음의 농도를 만들기 쉽습니다. 1969년 샤르페터와 굼멜(Scharfetter, Gummel)이 제안한 이산화는 칸 사이의 전류를 지수 함수 꼴로 정확히 맞춰 이 문제를 피하며, 오늘날 소자 시뮬레이터의 기본 구성 요소로 알려져 있습니다. 결과 연립방정식은 비선형이라 4장의 뉴턴 방법으로, 그 안의 선형계는 희소 직접법이나 반복법으로 풉니다.

이 책은 한 문장에서 출발했습니다. 컴퓨터는 유한한 수와 유한한 단계로 근사한다. 좋은 수치해석은 오차를 예측하고, 통제하고, 비용과 바꾸는 기술이다. 1장에서 그 "유한한 수"는 0.1 + 0.2가 0.3이 아니게 만드는 기계 엡실론 \(2^{-52}\)이었고, 이 장의 마지막에서 "유한한 단계"는 판을 자른 격자와 시간 걸음이었습니다. 무대가 숫자 하나에서 수백만 개의 미지수로 넓어졌을 뿐, 묻는 질문은 같았습니다.

우리는 그 질문을 몇 개의 공통 언어로 다루었습니다. 오차 차수 \(O(h^p)\)는 보간(5–6장), 미분과 적분(9–10장), ODE와 PDE(11장, 이 장)에서 로그–로그 그래프의 기울기로 되풀이해 나타났습니다. 수렴 차수는 이분법의 1차, 뉴턴의 2차, 할선법의 1.618(3–4장)에서 시작해 반복 해법과 최적화의 수렴률 \((\kappa - 1)/(\kappa + 1)\)과 \(\sqrt\kappa\) 가속(13장, 15장)으로 이어졌습니다. 조건수는 2장에서 문제의 민감도로 등장해 연립방정식의 오차 한계(12장), 최소제곱의 QR(7장), 경사 하강의 지그재그(15장), 격자를 줄일수록 나빠지는 푸아송 행렬(이 장)까지 따라왔습니다. 그리고 안정성은 2장의 점화식과 근의 공식에서 11장의 안정성 영역, 이 장의 증폭 인자와 랙스 동등성 정리까지, "작은 오차가 자라지 않는가"라는 한 질문의 여러 얼굴이었습니다.

핵심 정리

  1. 중앙 차분 \(\delta^2u/h^2 = u'' + \frac{h^2}{12}u''''\)은 2차 정확하다. 격자를 두 배로 하면 오차가 4분의 1이 되는지 보는 격자 수렴 실험이 PDE 코드 검증의 기본이다.
  2. 5점 스텐실은 \(n^2\times n^2\) 블록 삼중대각 희소 행렬을 만든다. 이산 최대 원리가 성립하고, 조건수가 \(h^{-2}\)에 비례해 야코비는 \(N^2\), 최적 SOR은 \(N\)에 비례하는 반복이 든다. 다중 격자는 격자와 무관한 반복 수를 낸다.
  3. 열 방정식의 선의 방법은 강성 ODE다. FTCS(전진 오일러)는 \(r \le 1/2\), BTCS(후진 오일러)와 크랭크–니콜슨(사다리꼴)은 무조건 안정이고 1차원에서 한 걸음 \(O(n)\)(토머스). CN은 2차지만 큰 \(r\)에서 높은 모드가 \(G \to -1\)로 진동한다.
  4. 폰 노이만 분석은 격자 푸리에 모드의 증폭 인자 \(G(\theta)\)를 구해 \(|G| \le 1\)을 확인한다. 열: \(G = 1 - 4rs^2\), \(1/(1 + 4rs^2)\), \((1 - 2rs^2)/(1 + 2rs^2)\).
  5. 랙스 동등성 정리: 잘 놓인 선형 문제에서 일관적인 차분법은 안정할 때 그리고 그때만 수렴한다. 안정한 방법의 수렴 차수는 절단 오차의 차수다.
  6. 이류의 중앙 차분은 \(|G|^2 = 1 + C^2\sin^2\theta\)로 무조건 불안정하다. 풍상은 수치 확산 \(\frac{a\Delta x}{2}(1 - C)u_{xx}\)를 가진 1차, 랙스–벤드로프는 진동(분산)을 가진 2차이며 둘 다 \(C \le 1\)(CFL)에서 안정하다. 단조 선형 방법은 1차가 한계다(고두노프).
  7. 파동의 립프로그는 \(C \le 1\)에서 안정하고 감쇠가 없지만, 수치 분산 \(\sin\frac{\omega\Delta t}{2} = C\sin\frac{\xi\Delta x}{2}\) 때문에 짧은 파장이 늦다. 1차원에서는 \(C = 1\)이 정확하다.
  8. 유한 요소법은 약형식 \(\int u'v' = \int fv\)를 모자 함수 공간에서 풀어 강성 행렬 \(K\mathbf U = \mathbf F\)를 조립한다. 갤러킨 해는 에너지 노름에서 최선 근사다. 유한 체적법은 칸 경계의 플럭스로 보존을 정확히 지킨다.

확인 퀴즈

Q1. 2차 정확한 차분법으로 \(N = 20\)에서 최대 오차가 \(2\times10^{-3}\)이었다. \(N = 80\)이면 대략?

\(h\)가 1/4이 되면 오차는 \((1/4)^2 = 1/16\)배, \(2\times10^{-3}/16 = 1.25\times10^{-4}\). \(5\times10^{-4}\)은 1차 방법일 때의 답이다.

Q2. 2차원 정사각형 판을 한 변에 내부 점 100개로 나눈 5점 차분 행렬의 크기와 한 행의 0 아닌 값의 최대 개수는?

미지수는 \(100^2 = 10^4\)개. 각 식은 자기와 네 이웃만 쓰므로 한 행에 최대 5개. 밀집 저장이면 \(10^8\)칸이지만 0 아닌 값은 5×10⁴개 미만이다.

Q3. \(\Delta x = 0.01\), \(\alpha = 1\)인 열 방정식을 FTCS로 안정하게 풀 수 있는 가장 큰 \(\Delta t\)는?

\(r = \Delta t/\Delta x^2 \le 1/2\)에서 \(\Delta t \le 10^{-4}/2\). BTCS나 CN이면 제한이 없고, \(\Delta t\)는 정확도로만 고른다.

Q4. 크랭크–니콜슨으로 \(r = 10\)일 때 가장 높은 격자 모드(\(\theta = \pi\))의 증폭 인자는?

\(G = (1 - 2r)/(1 + 2r) = -19/21\). 절댓값이 1보다 작아 안정하지만 거의 줄지 않고 부호만 바꿔 톱니 진동이 남는다. \(1/41\)은 BTCS, \(-39\)는 FTCS의 \(1 - 4r\)이다.

Q5. 랙스 동등성 정리에 따르면, 일관적인 선형 차분법이 수렴하지 않는다면 그 원인은?

잘 놓인 선형 문제에서 일관성이 있으면 수렴 ⇔ 안정성이다. 차수가 낮은 것은 수렴이 느린 것이지 수렴하지 않는 것이 아니다.

Q6. \(u_t + u_x = 0\)을 풍상 차분, \(\Delta x = 0.02\), \(C = 0.5\)로 풀 때 수정 방정식의 수치 확산 계수는?

\(D = \frac{a\Delta x}{2}(1 - C) = \frac{1\cdot0.02}{2}\cdot0.5 = 0.005\). \(C = 1\)이면 0이 되어 풍상 차분이 정확한 한 칸 이동이 된다.

Q7. 파동 방정식의 립프로그 방법에서 \(C \lt 1\)일 때 짧은 파장 성분에 일어나는 일은?

\(\sin(\omega\Delta t/2) = C\sin(\xi\Delta x/2)\)에서 \(C \le 1\)이면 \(\omega\)가 실수(감쇠 없음)이고, \(c_{\text{num}}/c \lt 1\)이 짧은 파장일수록 작다. 예를 들어 \(C = 0.5\), 파장당 4칸이면 0.920이다.

Q8. \(-u'' = f\)를 조각별 선형 유한 요소(\(n\)개 요소, 간격 \(h\))로 풀 때 강성 행렬은?

요소 강성 \(\frac1h\begin{bmatrix}1&-1\\-1&1\end{bmatrix}\)을 조립하면 \(\frac1h\operatorname{tridiag}(-1, 2, -1)\). 첫 보기는 \(\int\varphi_i\varphi_j\)의 질량 행렬이다. 하중 \(f = 1\)이면 \(F_i = h\)라 차분법과 같은 식이 된다.
