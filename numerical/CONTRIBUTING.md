# NumericalBook 챕터 작성 가이드

NumericalBook은 [MathBook(foundations)](../foundations/CONTRIBUTING.md), [LinearBook](../linear/CONTRIBUTING.md), [CalculusBook](../calculus/CONTRIBUTING.md), [ODEBook](../ode/CONTRIBUTING.md)과 같은 엔진(`MB`)으로 쓰는 수치해석 교과서다. **이 문서에 없는 규칙과 `MB` API 전체는 `../foundations/CONTRIBUTING.md`를 따르고, 빌드·수식 규칙은 `../calculus/CONTRIBUTING.md`와 같다.** 문체·구성·그림·시뮬레이터 수준의 본보기는 `../ode/chapters/numerical.html`과 `../calculus/chapters/fundamental.html`이다.

## 기여물의 라이선스

코드는 MIT, 교재 콘텐츠는 CC BY 4.0. 다른 교재의 문장·그림·연습문제를 옮겨 오지 않는다. 역사·수치는 확인된 사실만 쓴다(확실하지 않으면 쓰지 않는다).

## 구조

빌드 없이 열리는 정적 페이지다. `index.html` + `chapters/<slug>.html` + `css/style.css`(MathBook 스타일, 색만 초록 `#2b8a3e`·보라 `#862e9c`) + `js/common.js`(전역 `MB`, 장 목록 `CHAPTERS`). classic script만 쓴다(ES module 금지).

- 용어는 `js/glossary-data.js`에 추가한다(시리즈 공통 v1: `ko`, `en`, `abbr`, `def`, `chapters`). 본문에서 처음 나오는 용어는 `<span class="term">…</span>`.
- 엔진의 `MB.rk4`·`MB.euler`, 행렬·고유값·SVD(`MB.mat`), 복소수(`MB.cx`), FFT 헬퍼를 쓸 수 있다. 하지만 **이 책은 알고리즘 자체가 주인공이므로, 장에서 다루는 알고리즘은 장 스크립트 안에 직접 짧게 구현해 단계별로 보여 준다**(엔진 함수는 정답 비교용). `js/common.js`는 고치지 않는다.

## 원칙: 알고리즘 → 한 단계씩 → 오차 → 쓰임

NumericalBook은 공대·자연대 3학년 수치해석 한 학기(+ 수치 선형대수, 최적화, PDE 수치해법 입문)를 **빠짐없이** 다룬다. 모든 방법을 **아이디어(그림) → 알고리즘(의사코드) → 한 단계씩 돌려 보기 → 오차와 수렴 속도 측정(로그–로그 그래프) → 실패하는 경우 → 공학·과학에서 쓰이는 곳**의 순서로 다룬다. 책 전체의 줄기는 "컴퓨터는 유한한 수와 유한한 단계로 근사한다. 좋은 수치해석은 **오차를 예측하고, 통제하고, 비용과 바꾸는 기술**"이라는 관점이다. 오차 차수 O(hᵖ), 수렴 차수, 조건수, 안정성, 비용(연산 수)이 장마다 다시 등장하는 공통 언어다.

- 한국어, 대상은 공대 3학년과 계산 코드를 쓰는 엔지니어·연구자. 영어 원어는 `<span class="en">(Machine Epsilon)</span>`처럼 병기.
- 장 첫머리는 `.origin`("이 수식이 없었다면")으로 연다. 각 절은 가능하면 `.problem`으로 시작한다.
- 흐름: 문제 → 아이디어 그림(SVG) → **조작하는 시뮬레이터** → 알고리즘(`<pre class="code">` 의사코드 블록: 주석은 `<span class="c">`, 키워드는 `<span class="k">`; 수식 구분자 금지, `<`·`>`·`&`는 엔티티로) → 정의·정리(KaTeX) → **손으로 푸는 예제**(`.callout` 안에 단계별, 반복 표 포함) → 쓰이는 곳(`.uses`) → 핵심 정리 → 확인 퀴즈(6–8문항).
- 교과서다운 엄밀함: 정리·정의는 `<div class="callout deep"><strong>정리 3.2 (뉴턴 방법의 2차 수렴)</strong> …</div>`처럼 **장 번호.순번**. 오차 한계는 증명의 핵심 아이디어까지 쓴다. 예제 `예제 3.1`, 그림 `그림 3-1.`. **본문의 모든 수치(반복 표, 오차 값, 수렴 차수)는 실제로 계산해서 넣는다**(node로 돌려 확인). 부동소수점 값은 JavaScript가 IEEE 754 배정밀도라는 점을 활용해 실제 값을 보여 준다.
- 장마다 시뮬레이터 6–8개. "다음 단계" 버튼·자동 재생으로 반복을 한 단계씩 보여 주고, 반복 표(`<table>`)와 오차 그래프(로그 축)를 함께 갱신한다. `MB.plane`(끄는 점), `MB.chart`, `MB.loop`.
- 앞 책과 겹치는 곳은 더 깊이 다루고 링크한다: 뉴턴 방법 `../../calculus/chapters/optimization.html`, 테일러 `../../calculus/chapters/taylor.html`, 사다리꼴·심프슨 `../../calculus/chapters/techniques.html`, LU·QR·수치 선형대수 `../../linear/chapters/lu.html`, `qr.html`, `numerical.html`, `svd.html`, ODE 수치 해법 기초 `../../ode/chapters/numerical.html`, PDE `../../ode/chapters/pde.html`, MathBook `../../foundations/chapters/numerics.html`, `fourier.html`. 링크 전에 파일·앵커가 실제로 있는지 확인한다.
- 색은 CSS 변수와 `MB.palette()`만. 라이트/다크 모두 확인. 폭 360px에서 가로 스크롤 금지(넓은 표는 `overflow-x:auto` 상자 안에). SVG는 `viewBox`만 주고 width/height 생략.
- 시뮬레이터 `id`는 `sim-<장 접두사>-<이름>`, 요소 id·장 전용 CSS 클래스도 같은 접두사. 절 `id`는 의미 있는 영어 슬러그.

## 장별 설계

각 장은 아래 절을 모두 다룬다(순서·제목은 다듬어도 된다). 시뮬레이터 아이디어는 최소 목록이다.

**01 부동소수점과 오차** — 0.1 + 0.2 ≠ 0.3 / 정수와 고정소수점의 한계 / IEEE 754 배정밀도의 부호·지수·가수 비트 / 수직선 위 부동소수점 수의 분포(간격이 커진다) / 기계 엡실론과 반올림 단위, ulp / 오버플로·언더플로·비정규 수, Inf·NaN / 절대·상대 오차, 유효 숫자 / 자릿수 상쇄(이차방정식 근의 공식, 1 − cos x) / 오차의 누적과 합산 순서, 카한 합산 / 실제 사고 사례는 확인된 것만(패트리어트 미사일 시간 누적 오차, 아리안 5 변환 오버플로). 시뮬: 비트 편집기(64비트 클릭 → 값), 부동소수점 수직선 확대, 엡실론 찾기 반복, 상쇄 오차 그래프(x → 0), 합산 순서·카한 비교, 0.1을 n번 더하기.
**02 조건수와 안정성** — 문제의 민감도와 알고리즘의 품질 구분 / 상대 조건수 κ = |x f′(x)/f(x)| / 함수별 조건수(빼기, 근, 다항식 근의 윌킨슨 예) / 전방 오차와 후방 오차, 후방 안정 / 안정·불안정 알고리즘(점화식 ∫xⁿeˣ⁻¹, 지수 함수의 급수 합 x < 0) / 다시 쓰기로 구하기(log1p, expm1, 근의 공식 변형) / 행렬 조건수 맛보기(12장 예고) / 혼합 정밀도와 반올림 오차 모형 fl(x ∘ y) = (x ∘ y)(1 + δ). 시뮬: 입력 교란 → 출력 퍼짐 조건수 실험, 윌킨슨 다항식 근 흔들기, 점화식 앞/뒤 방향, e^(−x) 급수 vs 1/e^x, 조건수 지도, 후방 오차 그림.
**03 방정식의 근 찾기** — 근 가두기와 이분법(오차 한계, 반복 수) / 고정점 반복과 축소 사상, |g′| < 1 / 수렴 차수 정의와 실험 측정 / 뉴턴 방법: 유도, 2차 수렴 증명 아이디어, 중근에서 1차로 / 할선법(황금비 차수 1.618) / 가위치법과 일리노이 수정 / 브렌트 방법(조합) / 멈춤 조건(잔차 vs 간격) / 실패 사례(순환, 발산, 평평한 곳) / 응용: 제곱근(바빌로니아), 역수 계산, 케플러 방정식, 유체 마찰 계수(콜브룩). 시뮬: 이분법 단계, 고정점 거미줄 그림, 뉴턴 접선 단계, 방법별 오차 로그 비교(수렴 차수 기울기), 뉴턴 실패 갤러리, 케플러 방정식 풀이.
**04 비선형 연립방정식과 다항식의 근** — 두 곡선의 교점 / 다변수 뉴턴과 야코비안, 선형계 풀기 / 감쇠 뉴턴(직선 탐색) / 브로이든(준뉴턴) / 다항식: 호너 방법(연산 수), 수축과 오차, 동반 행렬의 고유값으로 근 찾기 / 복소 평면의 뉴턴 방법과 끌개 영역(뉴턴 프랙털) / 연속법(호모토피) / 응용: 회로의 동작점, 로봇 팔 역기구학, GPS 위치 결정. 시뮬: 2변수 뉴턴(등고선 두 개와 반복점), 뉴턴 프랙털(z³ − 1), 호너 단계 표, 수축 오차, 로봇 팔 역기구학, 연속법 경로.
**05 다항식 보간** — 점을 지나는 다항식의 존재와 유일성 / 반데르몽드 행렬과 조건수 / 라그랑주 형식과 기저 / 뉴턴 형식과 분할 차분표, 점 추가 / 보간 오차 공식 f⁽ⁿ⁺¹⁾(ξ)/(n+1)! ∏(x − xᵢ) / 룽게 현상 / 체비쇼프 노드와 최적성 / 무게중심 공식(안정적인 계산) / 에르미트 보간 / 응용: 표 보간, 로그표, 인공위성 궤도력. 시뮬: 점 끌기 보간 다항식, 라그랑주 기저 함수, 분할 차분표 작성, 룽게 현상 n 슬라이더, 등간격 vs 체비쇼프 ∏(x − xᵢ), 오차–n 그래프.
**06 스플라인과 곡선** — 고차 보간의 대안: 조각별 다항식 / 조각별 선형과 오차 O(h²) / 조각별 3차 에르미트(PCHIP, 단조성) / 3차 스플라인 유도: 연속 조건, 삼중대각계 / 경계 조건(자연·고정·not-a-knot) / 최소 굽힘 에너지 성질 / 매개변수 곡선, 베지에 곡선과 드 카스텔조 알고리즘 / B-스플라인과 국소 제어 / 응용: 글꼴, CAD, 애니메이션 경로, 카메라 궤적. 시뮬: 점 끌기 스플라인 vs 다항식, 경계 조건 비교, PCHIP 오버슈트 없음, 드 카스텔조 단계, 베지에 제어점 편집, B-스플라인 국소 제어.
**07 최소제곱 근사와 직교 다항식** — 잡음 데이터와 보간의 실패 / 선형 최소제곱과 정규 방정식 / 정규 방정식의 조건수 제곱 문제 vs QR / 다항식 차수와 과적합, 검증 오차 / 가중 최소제곱, 강건 회귀(이상치) / 함수 근사: 연속 최소제곱, 직교 다항식(르장드르, 체비쇼프), 그람–슈미트 / 체비쇼프 전개와 계수 감소 / 최소최대(minimax) 근사, 등진동 성질(레메즈 아이디어) / 응용: 센서 보정, 라이브러리 함수 근사. 시뮬: 데이터 맞춤 차수 슬라이더(학습·검증 오차), 잔차 수직 사영 그림, 정규 방정식 vs QR 정확도, 이상치 끌기와 강건 회귀, 체비쇼프 계수 막대, 최소최대 오차 등진동.
**08 이산 푸리에 변환과 FFT** — 주기 데이터의 삼각 보간 / DFT 정의와 행렬, 단위근 / 표본화와 앨리어싱, 나이퀴스트 / 쿨리–튜키 FFT: 짝·홀 분할, 나비 연산, O(N log N) / 빠른 합성곱과 다항식 곱셈 / 스펙트럼 누설과 창 함수 / 제로 패딩 / 응용: 오디오 스펙트럼, 이미지 압축 맛보기, 큰 수 곱셈, 스펙트럴 미분. 시뮬: 신호 합성 → 스펙트럼, 앨리어싱(표본화 주파수 슬라이더), FFT 나비 그림 단계, O(N²) vs O(N log N) 시간 측정, 창 함수와 누설, FFT 합성곱.
**09 수치 미분** — 차분 몫 / 전진·후진·중앙 차분과 테일러 전개로 오차 차수 / 절단 오차 vs 반올림 오차: 최적 h ≈ √ε, ∛ε / 고계 도함수와 차분 스텐실 / 리처드슨 외삽 / 잡음 데이터의 미분 문제와 평활화 / 복소 스텝 미분 / 자동 미분(전진 모드: 이중수, 후진 모드: 역전파) / 응용: 속도 추정, 민감도 해석, 신경망 학습. 시뮬: 할선 → 접선과 h, 오차–h 로그 V자 그래프, 스텐실 계수 계산기, 리처드슨 표, 잡음 데이터 미분, 이중수 자동 미분 단계.
**10 수치 적분** — 구적법의 아이디어 / 뉴턴–코츠: 사다리꼴, 심프슨, 3/8, 오차 항 / 합성 공식과 수렴 차수 측정 / 오일러–매클로린과 롬베르크 적분 / 가우스 구적법: 노드와 가중치, 2n−1차 정확도, 르장드르 근 / 적응 구적법(구간 쪼개기) / 특이점과 무한 구간(변수 변환) / 다차원 적분과 차원의 저주, 몬테카를로와 1/√N / 응용: 확률 계산, 물리량 적분. 시뮬: 사다리꼴·심프슨 그림, 오차–n 로그 기울기, 롬베르크 표, 가우스 노드 위치, 적응 구적법 구간 트리, 몬테카를로 π.
**11 미분방정식의 수치 해법** — ODEBook 5장(오일러·RK4·강성 맛보기)을 전제로 더 깊이 / 일단계 방법의 일관성·안정성·수렴(랙스 원리 아이디어) / 룽게–쿠타 계열과 부처 표 / 임베디드 RK와 오차 제어(간격 조절 공식) / 다단계 방법: 애덤스–배시포스, 애덤스–몰턴, 예측자–수정자 / 안정성 영역 그림(복소 hλ 평면), A-안정 / 강성과 BDF, 음적 방법의 뉴턴 반복 / 심플렉틱 적분과 장기 에너지 / 경계값 문제: 슈팅 방법과 유한 차분 / 응용: 궤도 역학, 화학 반응(로버트슨), 회로 시뮬레이터. 시뮬: 안정성 영역 지도(방법 선택), 부처 표 → 방법 실행, 적응 간격 오차 제어, 애덤스 예측–수정, 강성 로버트슨 문제 명시적 vs BDF, 슈팅/유한 차분 BVP.
**12 연립방정식의 직접 해법** — LinearBook 소거·LU 장을 전제로 수치적 관점 / 가우스 소거의 연산 수 n³/3 / 부분 피벗팅의 필요성(작은 피벗 예), 완전 피벗팅 / PA = LU와 여러 우변 / 촐레스키 분해(대칭 양정치) / 띠 행렬과 토머스 알고리즘 O(n) / 벡터·행렬 노름과 조건수, 오차 한계 ‖δx‖/‖x‖ ≤ κ ‖δb‖/‖b‖ / 힐베르트 행렬 / 반복 개선 / 희소 행렬과 채움(fill-in), 재배열 / 응용: 회로망 해석, 구조 해석, 유한 요소 강성 행렬. 시뮬: 피벗팅 유무 비교, LU 단계, 조건수와 오차 증폭(2×2 직선 교점), 힐베르트 행렬 κ 증가, 토머스 알고리즘, 희소 채움 시각화.
**13 반복 해법** — 큰 희소 행렬 / 야코비와 가우스–자이델 / 분할 행렬과 반복 행렬, 스펙트럼 반지름 수렴 조건, 대각 우세 / SOR과 최적 ω / 최급 강하와 이차 형식 / 켤레 기울기법: A-직교 방향, n단계 종료, 수렴 속도 √κ / 전처리(야코비, 불완전 촐레스키 아이디어) / 크릴로프 부분공간, GMRES 개요 / 다중 격자 아이디어(매끄러운 오차와 거친 격자) / 응용: 2차원 푸아송, 이미지 처리. 시뮬: 2×2 반복 경로(야코비/G-S/SOR), ω 슬라이더와 반복 수, 최급 강하 지그재그 vs CG, 오차 모드 평활화(고주파가 먼저 사라짐), 2D 푸아송 반복 히트맵, 수렴 곡선 비교.
**14 고유값의 수치 계산** — 특성 다항식으로 구하면 안 되는 이유 / 거듭제곱법과 수렴 속도 |λ₂/λ₁| / 역반복과 이동(shift), 레일리 몫 반복의 3차 수렴 / 게르시고린 원판 / 수축 / QR 알고리즘: 닮음 변환, 하우스홀더로 헤센베르크 만들기, 이동 QR / 대칭 행렬과 야코비 회전 / 특이값 계산 개요, 저계수 근사 / 응용: 페이지랭크, 진동 모드, 주성분 분석, 양자 에너지 준위. 시뮬: 거듭제곱법 벡터 회전, 이동과 수렴 속도, 게르시고린 원판 편집기, QR 반복으로 하삼각이 0이 되는 히트맵, 페이지랭크 작은 웹 그래프, 레일리 몫 수렴 표.
**15 수치 최적화** — 1차원: 황금 분할 탐색, 포물선 보간 / 경사 하강과 직선 탐색(아르미호 조건) / 조건수와 지그재그, 모멘텀 / 뉴턴 방법과 헤세 / 준뉴턴 BFGS / 도함수 없는 방법: 넬더–미드 심플렉스 / 비선형 최소제곱: 가우스–뉴턴, 레벤버그–마쿼트 / 제약 최적화: 벌칙법, 라그랑주 승수, KKT 개요 / 확률적 경사 하강(미니배치) / 국소 최솟값과 전역 최적화(담금질 기법) / 응용: 곡선 맞춤, 기계 학습, 설계 최적화. 시뮬: 황금 분할 구간 축소, 로젠브록 함수에서 방법 비교(경로), 학습률·모멘텀, 넬더–미드 심플렉스 애니메이션, 레벤버그–마쿼트 곡선 맞춤, 담금질 기법 탈출.
**16 편미분방정식의 수치 해법** — ODEBook 16장의 FTCS를 전제로 더 깊이 / 격자와 유한 차분 근사 / 푸아송 방정식: 5점 스텐실과 희소 선형계 / 열 방정식: 명시적(FTCS), 음적(BTCS), 크랭크–니콜슨, 비용과 정확도 / 폰 노이만 안정성 분석 / 랙스 동등성 정리 / 이류 방정식: 중앙 차분의 불안정, 풍상 차분, 수치 확산, 랙스–벤드로프, CFL / 파동 방정식 립프로그 / 유한 요소법 입문: 약형식, 모자 함수, 강성 행렬(1차원) / 유한 체적 맛보기 / 응용: 열 해석, 유체, 반도체 소자 시뮬레이션. 시뮬: 푸아송 판 온도(경계 편집), FTCS/BTCS/CN 비교, 폰 노이만 증폭 인자 그래프, 이류 방법 비교(사각 펄스), CFL 수 슬라이더 파동, 1차원 FEM 모자 함수 조립.
**17 용어집 & 종합 퀴즈** — 문제 유형 → 알고리즘 고르기 도우미, 방법별 오차 차수·비용 한눈표, 수렴 차수 비교, 안정성 조건 모음, 용어 검색, 전 범위 종합 퀴즈(장마다 2문항).

소스에는 `<title>`과 `<meta name="description">`(한 줄)만 쓴다. canonical·Open Graph 태그는 `tools/build.mjs`가 `numerical/book.json`의 `meta`로 생성하고, 수식은 빌드가 `tools/katex.mjs`로 미리 렌더링한다. 그래서 다음을 지킨다. 어기면 `npm test`나 빌드가 실패한다.

- canonical·`og:` 태그, KaTeX `<link>`/`<script>`를 소스에 넣지 않는다.
- **스크립트가 수식을 DOM에 넣지 않는다.** 인라인 `<script>` 안에 `\(`·`\[`·`$$`가 있으면 검사가 실패한다. 시뮬레이터의 식 출력은 HTML(`<sup>`, `<sub>`, `·`, `−`, `√`, `∫`)로 만든다. `MB.tex`는 쓰지 않는다.
- 수식 안에서 `<` 바로 뒤에 글자가 오면 브라우저가 태그로 읽는다. `a<b` 대신 `a \lt b` 또는 `a < b`(공백).
- 수식 안의 HTML 엔티티는 `&amp; &lt; &gt; &nbsp; &middot; &times; &minus;`와 숫자 엔티티만 쓴다.
