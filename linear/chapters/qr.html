Chapter 09

그람–슈미트와 QR

8장의 최소제곱은 정규 방정식 \(A^{\mathsf T}A\hat{\mathbf x} = A^{\mathsf T}\mathbf b\)로 풀렸습니다. 식은 깔끔하지만 컴퓨터는 이 식을 그대로 믿으면 안 됩니다. \(A^{\mathsf T}A\)를 만드는 순간 문제의 까다로움(조건수)이 제곱되기 때문입니다. 해결책은 기저를 바꾸는 것입니다. 서로 수직이고 길이가 1인 벡터들, 즉 정규직교 기저로 바꾸면 계수는 내적 한 번으로 읽히고, 사영은 곱셈 몇 번이 되고, 반올림 오차는 커지지 않습니다. 이 장은 아무 기저나 정규직교 기저로 바꾸는 그람–슈미트 과정에서 출발해, 그 기록인 \(A = QR\) 분해, 그리고 실제 소프트웨어가 쓰는 하우스홀더 반사와 기븐스 회전까지 갑니다.

  • 정규직교 기저에서는 좌표가 내적 \(c_i = \mathbf q_i\cdot\mathbf b\)로 바로 나오고 \(Q^{\mathsf T}Q = I\)임을 이해하고, 비스듬한 기저와 비교한다.
  • 직교 행렬이 길이·각도·내적을 보존하는 회전과 반사라는 것을 보이고, \(Q^{-1} = Q^{\mathsf T}\)를 계산에 쓴다.
  • 그람–슈미트 과정을 단계별로 실행해 정규직교 기저를 만들고, 그 계수를 모아 \(A = QR\)을 구한다.
  • 고전·수정 그람–슈미트와 하우스홀더 QR의 직교성 손실을 실험으로 비교하고 그 원인을 설명한다.
  • 하우스홀더 반사와 기븐스 회전으로 아래쪽 원소를 0으로 만드는 원리를 그림으로 이해한다.
  • 최소제곱을 \(R\hat{\mathbf x} = Q^{\mathsf T}\mathbf b\)로 풀고, 정규 방정식보다 정확한 이유를 \(\kappa(A^{\mathsf T}A) = \kappa(A)^2\)로 설명한다.
  • 함수에도 그람–슈미트를 적용해 르장드르·체비쇼프 다항식을 만들어 본다.

GPS 수신기는 위성 네 개 이상에서 받은 신호로 위치 (x, y, z)와 시계 오차를 구합니다. 하늘에 보이는 위성이 여덟, 열 개면 방정식이 미지수보다 많고 측정값에는 잡음이 섞여 있으니 모든 식을 정확히 만족하는 답은 없습니다. 실험실의 검량선, 센서 보정, 궤도 결정, 기계 학습의 선형 회귀도 같은 꼴, 즉 과결정 최소제곱 문제입니다.

교과서의 정규 방정식으로 풀면 잘 될 때도 있지만, 변수들이 서로 비슷할수록(조건수가 클수록) 유효 숫자가 두 배 빠르게 사라집니다. 그래서 수치 소프트웨어는 \(A\)를 정규직교 행렬 \(Q\)와 위삼각 행렬 \(R\)의 곱으로 쪼갠 뒤 \(R\hat{\mathbf x} = Q^{\mathsf T}\mathbf b\)를 풉니다. MATLAB의 A\b도 \(A\)가 정사각이 아니면 QR 분해로 최소제곱 해를 구합니다.

정규직교 기저는 계산을 공짜로 만든다

좌표를 구하는 데 연립방정식이 필요할까

평면의 벡터 \(\mathbf b\)를 기저 \(\mathbf u_1, \mathbf u_2\)로 \(\mathbf b = c_1\mathbf u_1 + c_2\mathbf u_2\)처럼 쓰려면 보통 2×2 연립방정식을 풀어야 합니다. 1000차원이면 1000×1000 시스템입니다. 신호를 주파수 성분으로, 이미지를 기저 패턴으로 나눌 때마다 이 비용을 치러야 할까요?

기저 벡터들이 서로 수직이고 길이가 1이면 이야기가 완전히 달라집니다. 양변에 \(\mathbf q_i\)를 내적하면 다른 항은 모두 0이 되고 \(c_i\)만 남기 때문입니다.

정의 9.1 (정규직교) 벡터 \(\mathbf q_1, \dots, \mathbf q_n\)이 \(\mathbf q_i\cdot\mathbf q_j = 0\) (\(i \ne j\)), \(\mathbf q_i\cdot\mathbf q_i = 1\)을 만족하면 정규직교(orthonormal)라 한다. 이들을 열로 갖는 행렬 \(Q\)는 \(Q^{\mathsf T}Q = I\)를 만족한다. \(Q^{\mathsf T}Q\)의 \((i, j)\) 칸이 바로 \(\mathbf q_i\cdot\mathbf q_j\)이기 때문이다.
정리 9.1 (정규직교 기저에서의 좌표) \(\mathbf q_1, \dots, \mathbf q_n\)이 \(\mathbb R^n\)의 정규직교 기저이면 모든 \(\mathbf b\)에 대해 $$\mathbf b = (\mathbf q_1\cdot\mathbf b)\,\mathbf q_1 + \cdots + (\mathbf q_n\cdot\mathbf b)\,\mathbf q_n, \qquad \|\mathbf b\|^2 = \sum_i (\mathbf q_i\cdot\mathbf b)^2 .$$

증명. \(\mathbf b = \sum_j c_j\mathbf q_j\)에 \(\mathbf q_i\)를 내적하면 \(\mathbf q_i\cdot\mathbf b = \sum_j c_j(\mathbf q_i\cdot\mathbf q_j) = c_i\). 행렬로 쓰면 \(Q\mathbf c = \mathbf b\)의 해가 \(\mathbf c = Q^{\mathsf T}\mathbf b\)이다. 길이는 \(\|\mathbf b\|^2 = \mathbf c^{\mathsf T}Q^{\mathsf T}Q\mathbf c = \mathbf c^{\mathsf T}\mathbf c\). 두 번째 식(파스발 등식)은 "에너지는 성분 에너지의 합"이라는 뜻이다. ∎

연립방정식 \(n^3\)이 내적 \(n\)번, 즉 곱셈 \(n^2\)번으로 줄었습니다. 아래 시뮬레이터에서 두 기저를 비교해 보세요. 정규직교 기저에서는 \(\mathbf b\)에서 각 축으로 수직으로 내린 발(내적)이 곧 좌표입니다. 비스듬한 기저에서는 수직으로 내린 값과 실제 좌표(평행사변형으로 읽은 값)가 다릅니다.

직교 행렬: 길이와 각을 지키는 변환

회전을 여러 번 곱해도 물체가 찌그러지지 않으려면

게임 엔진이나 드론의 자세 추정은 매 프레임 회전 행렬을 곱합니다. 회전은 물체의 길이와 각을 바꾸지 않아야 합니다. 어떤 행렬이 그런 성질을 갖는지, 그리고 그 성질을 수치적으로 어떻게 확인하는지가 문제입니다.

정의 9.2 (직교 행렬) 정사각 행렬 \(Q\)가 \(Q^{\mathsf T}Q = I\)를 만족하면 직교 행렬(orthogonal matrix)이라 한다. 열이 \(\mathbb R^n\)의 정규직교 기저를 이루고, 역행렬은 전치 \(Q^{-1} = Q^{\mathsf T}\)이다. (직사각 \(m\times n\) 행렬이 \(Q^{\mathsf T}Q = I_n\)을 만족하면 "정규직교 열을 가진 행렬"이라 부르며, 이때 \(QQ^{\mathsf T}\)는 \(I\)가 아니라 열공간으로의 사영이다.)
정리 9.2 (직교 변환은 기하를 보존한다) \(Q^{\mathsf T}Q = I\)이면 모든 \(\mathbf x, \mathbf y\)에 대해 \((Q\mathbf x)\cdot(Q\mathbf y) = \mathbf x\cdot\mathbf y\), 따라서 \(\|Q\mathbf x\| = \|\mathbf x\|\)이고 두 벡터 사이 각도 그대로다. 정사각 직교 행렬은 \(\det Q = \pm 1\)이며, \(+1\)이면 회전, \(-1\)이면 반사가 섞인 변환이다.

증명. \((Q\mathbf x)^{\mathsf T}(Q\mathbf y) = \mathbf x^{\mathsf T}Q^{\mathsf T}Q\mathbf y = \mathbf x^{\mathsf T}\mathbf y\). 행렬식은 \(1 = \det(Q^{\mathsf T}Q) = (\det Q)^2\)에서 나온다. ∎

직교 행렬을 곱해도 길이가 그대로라는 사실은 수치 계산에서 결정적입니다. 계산 도중 생긴 작은 오차 벡터 \(\boldsymbol\delta\)도 \(\|Q\boldsymbol\delta\| = \|\boldsymbol\delta\|\)라서 커지지 않습니다. 조건수로 말하면 \(\kappa(Q) = 1\), 가장 좋은 값입니다. 반면 소거에서 쓰는 행렬은 피벗이 작으면 오차를 키울 수 있었습니다(3장 부분 피벗팅). QR 알고리즘들이 안정한 이유가 여기에 있습니다.

그람–슈미트: 기울어진 기저를 바로 세우기

주어진 벡터들에서 정규직교 기저를 만들려면

측정 행렬의 열, 다항식 \(1, x, x^2\), 안테나 배열의 조향 벡터처럼 우리가 가진 기저는 대개 서로 비스듬합니다. 같은 공간을 생성하면서 서로 수직인 기저로 바꿀 수 있을까요?

아이디어는 단순합니다. 벡터를 하나씩 받아, 이미 만든 방향 성분을 빼고, 남은 것을 길이 1로 맞춥니다. 1장에서 본 사영 \((\mathbf v\cdot\mathbf q)\mathbf q\)가 "이미 있는 방향 성분"입니다.

$$\mathbf v_j = \mathbf a_j - \sum_{i \lt j} (\mathbf q_i\cdot\mathbf a_j)\,\mathbf q_i, \qquad \mathbf q_j = \frac{\mathbf v_j}{\|\mathbf v_j\|}$$
\(\mathbf v_j\)는 \(\mathbf a_j\)에서 앞선 방향 \(\mathbf q_1, \dots, \mathbf q_{j-1}\)으로의 사영을 뺀 나머지다. 그래서 \(\mathbf v_j\)는 앞의 모든 \(\mathbf q_i\)와 수직이다. \(\mathbf a_j\)가 앞의 벡터들의 결합이면 \(\mathbf v_j = \mathbf 0\)이 되어 멈춘다(열이 종속).
정리 9.3 (그람–슈미트) \(\mathbf a_1, \dots, \mathbf a_n\)이 선형 독립이면 위 과정은 정규직교 벡터 \(\mathbf q_1, \dots, \mathbf q_n\)을 만들고, 모든 \(k\)에 대해 \(\operatorname{span}\{\mathbf q_1, \dots, \mathbf q_k\} = \operatorname{span}\{\mathbf a_1, \dots, \mathbf a_k\}\)이다.

증명의 아이디어. 귀납법. \(\mathbf q_1, \dots, \mathbf q_{j-1}\)이 정규직교라 하자. \(i \lt j\)에 대해 \(\mathbf q_i\cdot\mathbf v_j = \mathbf q_i\cdot\mathbf a_j - (\mathbf q_i\cdot\mathbf a_j)(\mathbf q_i\cdot\mathbf q_i) = 0\). \(\mathbf v_j = \mathbf 0\)이면 \(\mathbf a_j\)가 \(\mathbf a_1, \dots, \mathbf a_{j-1}\)의 결합이 되어 독립성에 모순이므로 나눌 수 있다. 생성 공간이 같은 것은 \(\mathbf q_j\)가 \(\mathbf a_1, \dots, \mathbf a_j\)의 결합이고 거꾸로 \(\mathbf a_j\)가 \(\mathbf q_1, \dots, \mathbf q_j\)의 결합이기 때문이다. ∎

이 과정은 덴마크의 그람(1883)과 독일의 슈미트(1907)의 이름으로 불리지만, 같은 계산은 라플라스의 연구에도 나타납니다. 아래에서 두 벡터로 한 단계씩 따라가 보세요.

A = QR: 그람–슈미트의 기록

4장에서 소거의 기록이 \(A = LU\)였듯, 그람–슈미트의 기록은 \(A = QR\)입니다. 식 \(\mathbf v_j = \mathbf a_j - \sum_{i\lt j} r_{ij}\mathbf q_i\)를 \(\mathbf a_j\)에 대해 다시 쓰면

$$\mathbf a_j = r_{1j}\mathbf q_1 + r_{2j}\mathbf q_2 + \cdots + r_{jj}\mathbf q_j, \qquad r_{ij} = \mathbf q_i\cdot\mathbf a_j\ (i \lt j),\quad r_{jj} = \|\mathbf v_j\|$$
\(\mathbf a_j\)는 \(\mathbf q_1, \dots, \mathbf q_j\)만으로 쓰이고 뒤의 \(\mathbf q\)는 쓰이지 않는다. 그래서 계수를 모은 \(R\)은 위삼각 행렬이다.
정리 9.4 (QR 분해) 열이 선형 독립인 \(m\times n\) 행렬 \(A\)는 \(A = QR\)로 쓸 수 있다. \(Q\)는 \(m\times n\)이고 정규직교 열을 가지며(\(Q^{\mathsf T}Q = I_n\)), \(R\)은 대각 원소가 양수인 \(n\times n\) 위삼각 행렬이다. 이 조건 아래 분해는 하나뿐이다.

증명의 아이디어. 존재는 그람–슈미트가 보여 준다. 유일성: \(A = Q_1R_1 = Q_2R_2\)이면 \(Q_2^{\mathsf T}Q_1 = R_2R_1^{-1}\)은 위삼각이면서 직교 행렬이다. 위삼각 직교 행렬은 대각 원소가 ±1인 대각 행렬뿐이고, 대각이 양수라는 조건이 +1로 정한다. ∎

그리고 \(R = Q^{\mathsf T}A\)입니다. \(A = QR\)의 양변에 \(Q^{\mathsf T}\)를 곱하면 \(Q^{\mathsf T}Q = I\)이니까요. \(R\)의 칸은 정말로 "각 열을 각 방향에 내적한 값"입니다. 아래에서 3×3 행렬을 넣고 열을 하나씩 처리해 보세요.

고전 vs 수정 그람–슈미트: 직교성이 새는 곳

컴퓨터가 만든 Q는 정말 직교일까

정확한 산수에서는 그람–슈미트가 완벽한 정규직교 벡터를 만듭니다. 하지만 컴퓨터의 수는 유효 숫자 16자리뿐입니다. 열들이 거의 평행하면 큰 수에서 큰 수를 빼서 작은 \(\mathbf v_j\)를 얻는데, 이때 앞쪽 유효 숫자가 상쇄되어 사라집니다. 그렇게 만든 \(\mathbf q_j\)는 앞의 \(\mathbf q_i\)와 더 이상 수직이 아닐 수 있습니다.

같은 수식을 순서만 바꿔 계산하는 두 방법이 있습니다.

하우스홀더 반사와 기븐스 회전

직교성을 잃지 않고 아래를 0으로 만들려면

소거는 행을 빼서 아래 원소를 0으로 만들었습니다. 같은 일을 직교 행렬만 곱해서 할 수 있다면, 오차가 커지지 않는 상태로 위삼각 \(R\)에 도달할 것입니다. \(Q_n\cdots Q_2Q_1A = R\)이면 \(A = (Q_1^{\mathsf T}Q_2^{\mathsf T}\cdots Q_n^{\mathsf T})R = QR\)입니다.

열 벡터 \(\mathbf x\)를 첫 좌표축 위로, 즉 \((\pm\|\mathbf x\|, 0, \dots, 0)\)으로 보내는 직교 변환이 필요합니다. 길이를 지키면서 방향만 바꾸는 방법은 두 가지, 반사와 회전입니다.

정의 9.3 (하우스홀더 반사) 0이 아닌 \(\mathbf v\)에 대해 \(H = I - 2\dfrac{\mathbf v\mathbf v^{\mathsf T}}{\mathbf v^{\mathsf T}\mathbf v}\)를 하우스홀더 반사(Householder reflection)라 한다. \(\mathbf v\)에 수직인 초평면을 거울로 삼아 비추는 변환으로, \(H = H^{\mathsf T} = H^{-1}\), \(\det H = -1\)이다.
정리 9.5 (한 열을 축 위로) \(\mathbf x \ne \mathbf 0\), \(\alpha = -\operatorname{sign}(x_1)\|\mathbf x\|\), \(\mathbf v = \mathbf x - \alpha\mathbf e_1\)로 두면 \(H\mathbf x = \alpha\mathbf e_1\)이다.

증명. \(\|\mathbf x\| = |\alpha|\)이므로 \(\mathbf v^{\mathsf T}\mathbf v = 2(\|\mathbf x\|^2 - \alpha x_1)\), \(\mathbf v^{\mathsf T}\mathbf x = \|\mathbf x\|^2 - \alpha x_1\). 따라서 \(H\mathbf x = \mathbf x - 2\frac{\mathbf v^{\mathsf T}\mathbf x}{\mathbf v^{\mathsf T}\mathbf v}\mathbf v = \mathbf x - \mathbf v = \alpha\mathbf e_1\). 기하학으로는 \(\mathbf x\)와 \(\alpha\mathbf e_1\)이 길이가 같으니 둘을 잇는 선분의 수직이등분면이 거울이다. ∎

부호 \(-\operatorname{sign}(x_1)\)은 장식이 아닙니다. 반대 부호를 고르면 \(\mathbf x\)가 이미 \(\mathbf e_1\) 근처일 때 \(\mathbf v = \mathbf x - \|\mathbf x\|\mathbf e_1\)의 첫 성분이 거의 같은 두 수의 차가 되어 상쇄 오차가 생깁니다. 아래 시뮬레이터에서 직접 볼 수 있습니다.

정의 9.4 (기븐스 회전) 두 좌표 \(i, k\) 평면에서만 각 \(\theta\)만큼 도는 직교 행렬 \(G(i, k, \theta)\)를 기븐스 회전(Givens rotation)이라 한다. \(r = \sqrt{a^2 + b^2}\), \(c = a/r\), \(s = b/r\)로 두면 \(\begin{bmatrix}c & s\\ -s & c\end{bmatrix}\begin{bmatrix}a\\ b\end{bmatrix} = \begin{bmatrix}r\\ 0\end{bmatrix}\). 원소 하나를 0으로 만들고, 다른 행은 건드리지 않는다.

QR로 푸는 최소제곱

정규 방정식은 왜 위험한가

다항식 \(c_0 + c_1x + \cdots + c_dx^d\)로 측정값을 맞추는 문제는 \(A\mathbf c \approx \mathbf b\), \(A\)는 열이 \(1, x, x^2, \dots\)인 반데르몽드 행렬입니다. 구간 \([0, 1]\)에서 \(x^7\)과 \(x^8\)은 모양이 거의 같아 열이 거의 평행합니다. 정규 방정식 \(A^{\mathsf T}A\mathbf c = A^{\mathsf T}\mathbf b\)는 이 까다로움을 제곱해 버립니다.

8장에서 최소제곱 해 \(\hat{\mathbf x}\)는 잔차 \(\mathbf b - A\hat{\mathbf x}\)가 열공간에 수직이 되는 점이었습니다(8장). \(A = QR\)을 넣으면 수직 조건이 아주 간단해집니다.

정리 9.6 (QR 최소제곱) 열이 독립인 \(A = QR\)에 대해 최소제곱 해는 \(R\hat{\mathbf x} = Q^{\mathsf T}\mathbf b\)의 해이다.

증명. 정규 방정식 \(A^{\mathsf T}A\hat{\mathbf x} = A^{\mathsf T}\mathbf b\)에 \(A = QR\)을 넣으면 \(R^{\mathsf T}Q^{\mathsf T}QR\hat{\mathbf x} = R^{\mathsf T}Q^{\mathsf T}\mathbf b\), 즉 \(R^{\mathsf T}R\hat{\mathbf x} = R^{\mathsf T}Q^{\mathsf T}\mathbf b\). \(R\)이 가역이라 \(R^{\mathsf T}\)를 지우면 끝이다. 계산에서는 \(A^{\mathsf T}A\)를 만들지 않고 후진 대입 한 번으로 푼다. ∎

$$\kappa(A^{\mathsf T}A) = \kappa(A)^2, \qquad \text{정규 방정식의 상대 오차} \sim \varepsilon\,\kappa(A)^2, \qquad \text{QR의 상대 오차} \sim \varepsilon\,\kappa(A)\ (\text{잔차가 작을 때})$$
\(A\)의 특이값이 \(\sigma_i\)이면 \(A^{\mathsf T}A\)의 특이값은 \(\sigma_i^2\)이다(14장). 배정밀도에서 \(\kappa(A) = 10^8\)이면 정규 방정식은 \(\kappa^2 = 10^{16}\)으로 유효 숫자를 모두 잃지만, QR은 아직 8자리를 지킨다. 잔차가 크면 QR의 오차에도 \(\kappa^2\)에 비례하는 항이 생기지만, 이는 문제 자체의 민감도이고 어느 알고리즘도 피할 수 없다.

함수에도 그람–슈미트: 직교 다항식

벡터 공간의 공리만 있으면 그람–슈미트는 어디서나 돌아갑니다. 연속 함수 \(f, g\)의 내적을 \(\langle f, g\rangle = \int_{-1}^{1} f(x)g(x)\,dx\)로 정하면 함수도 수직일 수 있습니다. 단항식 \(1, x, x^2, x^3, \dots\)은 위의 다항식 적합이 보여 주었듯 서로 아주 비슷한 "비스듬한 기저"입니다. 이것에 그람–슈미트를 적용하면

$$P_0 = 1,\quad P_1 = x,\quad P_2 = \tfrac12(3x^2 - 1),\quad P_3 = \tfrac12(5x^3 - 3x),\ \dots$$
관례에 따라 \(P_n(1) = 1\)이 되도록 크기를 맞춘 르장드르 다항식. \(\langle P_m, P_n\rangle = 0\) (\(m \ne n\)). 가중치 \(1/\sqrt{1-x^2}\)를 넣으면 체비쇼프 다항식 \(T_n(\cos t) = \cos nt\)가 나온다.

예를 들어 \(P_2\): \(x^2\)에서 \(P_0\) 성분 \(\langle x^2, 1\rangle/\langle 1, 1\rangle = (2/3)/2 = 1/3\)을 빼고, \(P_1\) 성분은 \(\langle x^2, x\rangle = 0\)이라 뺄 것이 없으니 \(x^2 - \tfrac13\), 크기를 맞추면 \(\tfrac12(3x^2-1)\)입니다. 푸리에 급수의 \(\sin nx, \cos nx\)도 같은 의미의 정규직교 기저이고, 계수를 내적(적분)으로 읽는 것은 정리 9.1 그대로입니다(MathBook 푸리에 장).

신호 처리의 적응 빔포밍과 에코 제거에서는 데이터 행이 하나씩 들어올 때마다 \(R\)을 기븐스 회전으로 갱신하는 QR 분해 기반 RLS(QRD-RLS) 알고리즘이 쓰이며, 회전을 처리 소자의 격자에 흘려보내는 시스톨릭 배열 구현이 알려져 있습니다. 행렬 전체를 다시 분해하지 않고 회전 몇 번으로 끝나기 때문입니다.

핵심 정리

  1. 정규직교 기저에서는 좌표가 내적이다: \(c_i = \mathbf q_i\cdot\mathbf b\), 즉 \(\mathbf c = Q^{\mathsf T}\mathbf b\). 길이는 \(\|\mathbf b\|^2 = \sum c_i^2\)(파스발).
  2. 직교 행렬 \(Q^{\mathsf T}Q = I\)는 길이·각·내적을 보존하는 회전(det = 1)과 반사(det = −1)이고, \(Q^{-1} = Q^{\mathsf T}\), \(\kappa(Q) = 1\). 오차를 키우지 않는다.
  3. 그람–슈미트: 앞서 만든 방향 성분을 빼고 길이 1로 맞춘다. \(\mathbf v_j = \mathbf a_j - \sum_{i \lt j}(\mathbf q_i\cdot\mathbf a_j)\mathbf q_i\). 생성 공간은 단계마다 같다.
  4. \(A = QR\): \(R = Q^{\mathsf T}A\)는 위삼각이며 \(r_{ij} = \mathbf q_i\cdot\mathbf a_j\), \(r_{jj} = \|\mathbf v_j\|\). 열이 독립이면 대각이 양수인 분해는 하나뿐이다.
  5. 컴퓨터에서 직교성 손실은 CGS ≈ εκ², MGS ≈ εκ, 하우스홀더 ≈ ε. 재직교화(두 번 하기)가 CGS를 살린다.
  6. 하우스홀더 반사 \(I - 2\mathbf v\mathbf v^{\mathsf T}/\mathbf v^{\mathsf T}\mathbf v\)는 한 열의 아래를 한꺼번에, 기븐스 회전은 원소 하나씩 0으로 만든다. 부호 \(\alpha = -\operatorname{sign}(x_1)\|\mathbf x\|\)가 상쇄를 막는다.
  7. 최소제곱은 \(R\hat{\mathbf x} = Q^{\mathsf T}\mathbf b\)로 푼다. 정규 방정식은 \(\kappa(A^{\mathsf T}A) = \kappa(A)^2\) 때문에 유효 숫자를 두 배 빨리 잃는다.
  8. 함수 공간에서도 같다. 단항식에 그람–슈미트를 하면 르장드르·체비쇼프 다항식, 푸리에 기저는 그 자체로 정규직교다.

확인 퀴즈

Q1. \(\mathbf q_1 = \tfrac{1}{\sqrt2}(1, 1)\), \(\mathbf q_2 = \tfrac{1}{\sqrt2}(1, -1)\)일 때 \(\mathbf b = (4, 2)\)의 좌표 \((c_1, c_2)\)는?

정규직교 기저이므로 좌표는 내적이다. \(c_1 = (4 + 2)/\sqrt2 = 3\sqrt2\), \(c_2 = (4 - 2)/\sqrt2 = \sqrt2\). 확인: \(c_1^2 + c_2^2 = 18 + 2 = 20 = \|\mathbf b\|^2\).

Q2. 정사각 행렬 \(Q\)가 \(Q^{\mathsf T}Q = I\)를 만족한다. 항상 옳은 것이 아닌 것은?

\(\det Q = \pm 1\)이다. 반사(예: 하우스홀더 행렬)는 \(\det = -1\)이다. 정사각일 때는 한쪽 역행렬이 곧 역행렬이므로 \(QQ^{\mathsf T} = I\)도 성립한다(직사각이면 성립하지 않는다).

Q3. \(\mathbf a_1 = (1, 0, 0)\), \(\mathbf a_2 = (2, 3, 0)\)에 그람–슈미트를 적용하면 \(r_{12}\)와 \(\mathbf q_2\)는?

\(\mathbf q_1 = \mathbf a_1\), \(r_{12} = \mathbf q_1\cdot\mathbf a_2 = 2\). \(\mathbf v_2 = (2, 3, 0) - 2(1, 0, 0) = (0, 3, 0)\), \(r_{22} = 3\), \(\mathbf q_2 = (0, 1, 0)\). 따라서 \(R = \begin{bmatrix}1 & 2\\ 0 & 3\end{bmatrix}\).

Q4. \(A = QR\)에서 \(R\)이 위삼각인 이유로 가장 알맞은 것은?

그람–슈미트는 \(\mathbf q_j\)를 \(\mathbf a_1, \dots, \mathbf a_j\)로 만들므로 거꾸로 \(\mathbf a_j \in \operatorname{span}\{\mathbf q_1, \dots, \mathbf q_j\}\). 그래서 \(r_{ij} = 0\) (\(i \gt j\)).

Q5. \(\kappa(A) = 10^6\)인 최소제곱 문제를 배정밀도(\(\varepsilon \approx 10^{-16}\))로 푼다. 잔차가 작을 때 기대할 수 있는 해의 유효 숫자는 대략?

정규 방정식의 상대 오차 \(\sim \varepsilon\kappa^2 = 10^{-4}\), QR은 \(\sim\varepsilon\kappa = 10^{-10}\). \(A^{\mathsf T}A\)를 만드는 순간 조건수가 제곱된다.

Q6. \(\mathbf x = (0.999, 0.01)\)을 하우스홀더 반사로 x축 위로 보낼 때, \(\alpha = +\|\mathbf x\|\)를 고르면 생기는 문제는?

\(\|\mathbf x\| \approx 0.99905\)이므로 \(v_1 = 0.999 - 0.99905\)에서 앞자리가 모두 사라진다. \(\alpha = -\operatorname{sign}(x_1)\|\mathbf x\|\)이면 \(v_1 = x_1 + \operatorname{sign}(x_1)\|\mathbf x\|\)로 같은 부호끼리 더하므로 상쇄가 없다. 수학적으로는 두 선택 모두 맞다.

Q7. 함수의 내적 \(\langle f, g\rangle = \int_{-1}^1 fg\,dx\)에서 \(x^2\)에 그람–슈미트를 적용할 때 \(P_1 = x\) 방향으로 뺄 성분이 0인 이유는?

대칭 구간에서 짝함수와 홀함수의 내적은 0이다. 그래서 르장드르 다항식은 짝수 차수는 짝함수, 홀수 차수는 홀함수만 섞인다.

Q8. 행이 하나씩 계속 들어오는 실시간 최소제곱(예: 적응 필터)에서 \(R\)을 갱신하기에 가장 알맞은 도구는?

새 행을 \(R\) 아래에 붙이면 거의 위삼각인 행렬이 된다. 기븐스 회전 n번이면 다시 위삼각이 되고, 직교 변환이라 오차도 커지지 않는다. QRD-RLS가 이 방식이다.
